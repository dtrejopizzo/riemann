# papers-nuevos — background collection by theme

Third-party papers (mostly arXiv source packages named by identifier) gathered as background for rows A
and D. The folder name ("new papers") and the subfolder names `A` and `mas-papers` are kept because
verification scripts in phases 107, 114 and 116 read files by these paths.

| Subfolder | Theme |
|---|---|
| [`A/`](A/) | Connes–Consani: arithmetic site, scaling site, F₁, Riemann–Roch and Jacobian of Spec Z̄; Haran |
| [`deninger-programme/`](deninger-programme/) | Deninger: foliated dynamical systems for arithmetic schemes |
| [`foliated-dynamics/`](foliated-dynamics/) | Leafwise cohomology, dynamical zeta functions; Meyer's spectral interpretation |
| [`deninger-connes-consani-bridge/`](deninger-connes-consani-bridge/) | Morishita: Deninger's systems and Connes–Consani adelic spaces |
| [`arithmetic-intersection-theory/`](arithmetic-intersection-theory/) | Arithmetic Hodge index, quadratic Riemann–Roch, arithmetic surfaces |
| [`mas-papers/`](mas-papers/) | Tropical geometry and characteristic-one algebra |
| [`weil-form-and-explicit-formula/`](weil-form-and-explicit-formula/) | Weil positivity, explicit formula, Li coefficients (PDFs) |

Per-file authors, titles, identifiers and uses: [../README.md](../README.md).
