# Tropical geometry and characteristic one

arXiv sources on tropical complexes and surfaces (Cartwright), tropical Hodge theory (Amini–Piquerez), the tropical Lefschetz (1,1) theorem (Jell–Rau–Shaw), tropical Riemann–Roch (Sumi), Jacobians of tropical curves (Mikhalkin–Zharkov), homological algebra in characteristic one (Connes–Consani) and non-additive geometry (Haran); plus Yoshitomi, *Generators of modules in tropical geometry* (`1001.0448v3.pdf`). The name ("more papers") is kept because phase 114/116 scripts read files by this path.
