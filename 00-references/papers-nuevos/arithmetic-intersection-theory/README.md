# Arithmetic intersection theory

arXiv sources on the arithmetic Hodge index theorem (Yuan–Zhang 1304.3538, 1304.3539; Carney 1810.06342), quadratic Riemann–Roch formulas (Déglise–Fasel 2403.09266), the Riemann–Hurwitz formula for arithmetic surfaces (Zhu 2510.08033) and numerical cohomology for arithmetic surfaces (He 2512.01811). Formerly `papers-nuevos/D`.
