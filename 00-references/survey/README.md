# Literature survey for row D

This folder holds a literature survey written for row D (Weil positivity of the window form on the
declared carrier). A brief fixes the target and the properties a candidate object must have; five
reports then cover separate domains of the literature, and a synthesis merges them. Each report was
checked against the routes-tried index so that families already tried are marked as such. The
survey describes third-party work and records whether it supplies the missing object; no new
theorem is claimed here.

## Contents

- `BRIEF.md` — target statement, scope and filtering criteria for the survey.
- `S1_WEIL_CONNES_SCHOOL.md` — Weil positivity and the explicit-formula / trace-formula school.
- `S2_SPECTRAL_DEBRANGES_OPERATORS.md` — spectral and operator approaches, de Branges spaces,
  Sonine spaces, Kreĭn spaces, Nyman–Beurling and related topics.
- `S3_ANALYTIC_FOURIER_POSITIVITY.md` — analytic number theory and Fourier analysis around positivity.
- `S4_ARITHMETIC_GEOMETRY_F1_HODGE.md` — arithmetic geometry, F₁ and Hodge-index analogues.
- `S5_CROSSFIELD_MISSING_OBJECT.md` — cross-field search for an already-built object with the
  required properties.
- `SYNTHESIS.md` — merged conclusions of S1–S5.
