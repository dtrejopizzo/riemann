# papers-ref-2 (Connes–Consani–Moscovici references)

This folder holds the arXiv source packages of four third-party papers on the spectral approach
to the zeros of the zeta function via ζ-cycles, prolate operators and semilocal adelic operators.
They are the main external sources for the semilocal constructions studied in the row D phases
(for example the Sonin space and the prolate wave operator). Each subfolder contains the LaTeX
source and figures as distributed by arXiv.

## Contents

- `arXiv-2106.01715v1/` — A. Connes, C. Consani, "Spectral triples and ζ-cycles" (source and figures).
- `arXiv-2112.05500v1/` — A. Connes, H. Moscovici, "Prolate spheroidal operator and Zeta".
- `arXiv-2310.18423v2/` — A. Connes, C. Consani, "Zeta zeros and prolate wave operators:
  semilocal adelic operators".
- `arXiv-2402.13082v1/` — A. Connes, "Heat expansion and zeta".
