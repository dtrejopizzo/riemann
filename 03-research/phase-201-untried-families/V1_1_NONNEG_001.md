# V1_1_NONNEG_001 — Lemma V1.1′ (phase 201, stage 3, family B-V1): nonnegative rank of the threshold matrix of the layer m − kn = ε

Persistent line of stage 3. Object: SPEC_201_001 §C.1 unchanged.
Data and scripts: `V1_1_NONNEG_001_data/` (`v11_rplus.py`, `run_battery.py`, `v11_results.json`).

## Summary (≤250 words)

**Verdict: NO-GO PROVED (criterion M1, and also M2 and M3).** The matrix M_T^X(g) of SPEC_201 §C.1 is, **for
every comb X, every T, every test g and every threshold κ_∞**, a direct sum of blocks indexed by the product
j = kn, and each block has at most 3 columns, {(j−1,−1),(j,0),(j+1,+1)}. The reason is that column (m,ε)
determines j = m − ε. Nonnegative rank is additive over direct sums, and a nonnegative matrix with ≤ 3
columns satisfies r₊ = rank: with rank ≤ 2 it always holds, and with rank 3 = number of columns it also
holds. Hence **I_T^X(g) ≡ 0 identically** (Theorem V1.1′-0, PROVED, elementary).

The EXACT computation confirms it on 1,080 matrices (30 pairs (X,T) × 6 tests × 6 thresholds; rational
arithmetic on entries rationalized to 2⁻⁴⁰). In all of them an exact nonnegative factorization of size = rank
is exhibited, with rank up to 70, and I = 0 always. Without the threshold, diagonal invariance leaves r₊
unchanged. With κ > 0, c changes the support (c = 1.1, 2) but not I.

Consequences:
- (T201-b) holds with j_T = 0 for **any** comb, including every falsifier, so it separates nothing.
- (T201-a) with β_T(0) = 0 would assert 𝔞_T^X(g) ≥ 0 at every certified negative witness of the battery
  (Epstein T = 8/5, DH T = 9/5, a_P, cΛ), where I = 0. Those witnesses are explicit falsifiers of
  (T201-a): **M2**.
- The threshold does not rescue cΛ: **M3**.

B-V1 as defined is now closed. Index entry for ROUTES-TRIED in §6.

## 1. Reading of the definition (SPEC_201 §C.1, literal)

- Rows: R_T = {(k,n) : kn ≤ N_T, v_n^X ≠ 0}, with N_T = ⌊e^{2T}⌋.
- Columns: C_T × {−1,0,+1} = {(m,ε) : 1 ≤ m ≤ N_T+1}.
- Entry: M[(k,n),(m,ε)] = (v_n^X g(log(m/k)) − κ_∞(g;m,k))₊ · 1{m − kn = ε}.
- Invariant: I_T^X(g) = r₊(M) − rank(M).

## 2. Theorem V1.1′-0 (PROVED): the excess is identically zero

**Statement.** Let E ⊂ ℤ be the set of shifts and let M be any nonnegative matrix with support contained in
{((k,n),(m,ε)) : m − kn = ε, ε ∈ E}. Then:
1. M = ⊕_j M_j, where j ranges over the products kn and M_j is the submatrix with rows {(k,n) : kn = j} and
   columns {(j+ε, ε) : ε ∈ E}.
2. r₊(M) = Σ_j r₊(M_j) and rank(M) = Σ_j rank(M_j).
3. If |E| ≤ 3, then r₊(M_j) = rank(M_j) for every j, and therefore r₊(M) = rank(M).

In particular, for E = {−1,0,1} (SPEC_201) one has I_T^X(g) = 0 for every X, T, g ∈ P_T and every choice of
κ_∞.

**Proof.**
- (1) Column (m,ε) can only have nonzero entries in rows with kn = m − ε. The value j = m − ε is fixed by
  the column, so the column sets of distinct blocks are disjoint. Rows are also partitioned, because kn is
  fixed by the row. Hence M is block-diagonal after permuting rows and columns.
- (2) For the rank it is immediate. For r₊, let M = Σ_ℓ u_ℓ v_ℓᵀ with u_ℓ, v_ℓ ≥ 0. Each summand satisfies
  u_ℓ v_ℓᵀ ≤ M entrywise, because there is no cancellation. If u_ℓ had support in rows of block j and v_ℓ in
  columns of another block j′ ≠ j, the summand would be positive at a position where M is 0. Hence the
  support of each summand lies within a single block. Grouping the summands by block gives
  r₊(M) ≥ Σ r₊(M_j), and the opposite inequality is trivial.
- (3) Every nonnegative matrix with c columns satisfies r₊ ≤ c, via the factorization M_j = M_j · I_c. If
  rank M_j = 3 = c, then r₊ = rank. If rank M_j ≤ 2, then r₊ = rank: the cone generated by the columns lies
  in a subspace of dimension ≤ 2, and a pointed polyhedral cone of dimension ≤ 2 has at most 2 extreme rays,
  which are columns (Cohen–Rothblum 1993, CITED; only the trivial planar case is used here). ∎

**Remarks.**
- The proof **uses nothing** about the entries: not v_n^X, not its sign, not g, not κ_∞, not the Euler
  product. Hence it cannot see any difference between combs. The "intermediate node kn" of (T201-b) is not a
  factorization node: it is a **cut** that decouples the matrix.
- SPEC_201 §C.2 point 2 required rank ≥ 3 for the excess to possibly be nonzero. That requirement holds
  globally (rank up to 70), but it should hold **per block and with more columns than the rank**. With
  |E| = 3 that is impossible.
- The "additive layer" ε = ±1 does not couple distinct products. Column (m,+1) only sees rows with
  kn = m − 1, and column (m,−1) only those with kn = m + 1. No column combines two products j ≠ j′. For a
  real coupling to exist, the same column m would have to be in contact with kn = m and with k′n′ = m ± 1.
  Indexing by (m,ε) prevents this by construction, because it separates the three column blocks.

## 3. EXACT computation (confirmation of the theorem on the battery)

**Method** (`v11_rplus.py`).
1. The combs are built as follows:
   - Λ, a_P and cΛ from Λ(n) = log p;
   - Epstein's Λ_Q from `phase-200-sign-object/LEMMA_E_EPSTEIN_001_data/lambdaQ_exact.json`, as rational
     coefficients of log p;
   - DH's b_n with the recurrence from `CERT_DH_001_data/cert_dh.py` (a_n = Re χ(n) + κ Im χ(n),
     κ = (√(10−2√5)−2)/(√5−1));
   - Beurling with the synthetic system of SPEC_201 §C.5, primes {2, 3, 5.1, 7.05, 11.03, 13.02} and their
     powers.
2. v_n^X = 2X(n)/√n. Each entry v_n g(log(m/k)) − κ is evaluated with mpmath to 30 digits and rationalized
   to ℚ with denominator 2⁴⁰. The rank and the factorization are then computed **exactly** over ℚ with
   `fractions`. The walls, i.e. entries whose value is exactly 0 after rounding, are treated as 0. The
   theorem makes the rounding irrelevant.
3. Rank: exact Gaussian elimination on the full matrix (up to 86 × 111).
4. r₊:
   - lower bound: rank;
   - upper bound: **exactly certified** nonnegative factorization, block by block. A subset S of the block's
     columns is sought, with |S| = rank of the block, such that every other column is a nonnegative
     combination of S (normal system solved over ℚ and exact verification of the equality and the sign).
     That gives M_j = M_j[:,S]·H with H ≥ 0.
   - When the bounds coincide, r₊ is EXACT.
5. κ_∞: the spec defines it as a local integral of gK_∞. The theorem makes its value irrelevant, so it was
   **swept** as requested by the task: constants κ ∈ {0, 0.05, 0.2, 0.5, −0.1} and a random κ(m,k) per cell
   in [−0.3, 0.6]. This covers arbitrary support patterns, including those produced by the true κ_∞.
6. Test functions g:
   - g(x) = (1−t²)² Σ_j c_j P_{2j}(t), with t = x/2T: the "bump" (c = (1)) and 5 random Legendre vectors of
     degree ≤ 8;
   - A = B = 0 and the f∗f̃ structure were not imposed, because the theorem holds for every g.
   - The battery's certified witness vectors (Epstein degree 56, DH Legendre ≤ 259, Mori μ = 15) **were not
     loaded**: Theorem V1.1′-0 gives I = 0 on them too, without computation. They are left as an optional
     redundant check for the audit.

## 4. Requested checks

**(a) Diagonal invariance on the data (EXACT).** For Λ at T = ½log15, bump and κ = 0.05, the rows were
rescaled by d_{(k,n)} = (1+kn)/3 > 0. Before: rank 21, r₊ 21. After: rank 21, r₊ 21, with the same support.
Consistent with the mandatory correction of SPEC_201 §C.0 (PROVED). Here it carries no information, because
I = 0 regardless.

**(b) Does the threshold introduce the dependence on the comb? Yes, in the support; no, in I (EXACT).** For
T = ½log5 and the bump, the support of M^{cΛ} was compared with that of M^{Λ}:

| c \ κ | 0 | 0.05 | 0.2 | 0.5 |
|---|---|---|---|---|
| 0.9 | same | same | same | same |
| 1.1 | same | **different** | **different** | same |
| 2 | same | **different** | **different** | **different** |

With κ = 0 the support is invariant (this is diagonal invariance). With κ > 0 the zero pattern depends on c
near the wall v·g ≈ κ/c, as predicted by SPEC §C.4. But changing the support within blocks of ≤ 3 columns
does not change I, which remains 0. **The threshold is exactly what introduces the dependence on the comb,
and that dependence is invisible to I.** This confirms M3.

## 5. Decision: death criteria applied literally

- **Lemma's question.** Does there exist (T, g) with rank ≥ 3 and I_T^Λ ≠ I_T^X for each falsifier X? **No.**
  It is impossible for every (T, g, κ) by Theorem V1.1′-0 (PROVED). The data confirm this EXACTLY in 1,080
  cases.
- **M1 (holds, PROVED).** I_T^Λ = I_T^X = 0 for every X in the battery, at every T and every g, not only
  those sampled. Record: "NO-GO of support/threshold for r₊ in the m≈kn layer", now **for every N** and not
  only up to N = 36.
- **M2 (holds).** The certified negative witnesses, namely Epstein T = 8/5 with
  𝔞 ∈ [−0.06193952, −0.06193951], DH T = 9/5 with 𝔞 = −2.38·10⁻⁷, and cΛ and a_P in their windows, have
  I^X = 0 = I^Λ. Any (T201-a) with β_T(0) = 0 would give 𝔞^X ≥ 0 on them. They are **explicit falsifiers of
  (T201-a)** in the form stated in the spec, not for lack of separation but because the inequality itself is
  false. (T201-a) could only be true with β_T(0) > 0, and then it carries no sign.
- **M3 (holds, PROVED).** I^{cΛ} = I^Λ on every test, not only outside a measure-zero set. The additive
  threshold moves the support (§4b), but it is not enough.
- **M4, M5 (no need to evaluate).** I is constant, so M5 holds trivially: I is a function, constant, of 𝔞.
  M4 is vacuous: the optimal factorization is the block-diagonal one and bears no relation to the dual LP.
- **(T201-b)** is true with j_T = 0 for **every** comb, with or without sign. The "monochromatic
  rectangle / mixed sign splits the node" argument does not materialize, because with 3 columns per block a
  split node still has r₊ = rank. The spec's next question **is not launched**, because no separation
  occurred.

**Final label: NO-GO PROVED for B-V1 as defined in SPEC_201 §C.1.**

## 6. What is closed and what is not (for the ROUTES-TRIED index, "Phase 201" section)

**Closed (NO-GO PROVED):** the invariant r₊ − rank of **every** nonnegative matrix with support in the
relation m − kn = ε, with columns indexed by (m,ε) and |E| ≤ 3. Any threshold, comb, test or sign gives
excess 0. The reason is structural: indexing by (m,ε) splits the matrix into blocks by product j = kn.

**Variants that this proof also closes (do not retry):**
- any E with |E| ≤ 3;
- any diagonal rescaling (SPEC §C.0);
- any threshold κ, local or global;
- columns indexed by (m,ε) with any weight.

**What the proof does not cover (OPEN, descriptive only; a new written reason is required before attempting
it):**
- (i) |E| ≥ 4. The blocks remain decoupled by j, so the per-block excess would be an invariant of the fiber
  {(k,n) : kn = j} alone. That fiber is a single multiplicative contribution with no additive coupling
  between products, so the underlying objection persists.
- (ii) Indexing the columns only by m, without ε. Then column m sees both kn = m and kn = m ± 1 at the same
  time, and the blocks couple in a chain j, j+1, j+2, …, giving a "staircase" tridiagonal-band matrix.

  This is the only modification that creates real additive coupling. It must be checked against the index
  for whether it is equivalent to an already-registered route of additive contact m≈kn (phases 186/194–198,
  semiring principle) before being proposed.
