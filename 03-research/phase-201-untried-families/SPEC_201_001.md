## C. Chosen family: B-V1, nonnegative rank of the threshold matrix of the m≈kn layer

### C.0 Justification of the choice

1. It is the only one that passes G1 and Theorem 3′ simultaneously *by structure*. r_+ is a semialgebraic
   invariant. For M ≥ 0 of size 4×4 and rank 3, the values r_+ = 3 and r_+ = 4 both occur on open sets
   (Cohen–Rothblum 1993, CITED). So there is no generic value, and the "constant on a dense open set"
   conclusion of Theorem 3′ does not apply.
2. Its S6 is native, not grafted. The positive part (·)_+ sees the **sign** of the comb's coefficients, and
   Λ_cosh is exactly a comb with signs (LEMMA_E: + at Ω_𝒩 = 2, − at Ω_𝒩 = 4). For Λ of ζ all coefficients
   are ≥ 0. This is a property of ζ that is missing in Epstein and DH, as C-Guo requires, and it is a
   *sign* property, not a value property.
3. Its first lemma is finite, exact (rational arithmetic or by intervals), and names all the falsifiers.
4. B-V2 is second because its main risk (branch 4: the recurrence holds for every dense set) is structural.
   B-V1's (branch 2) is verifiable in the first lemma.

**Mandatory correction to FAMILIES_B §4 (PROVED, elementary).** For D₁, D₂ positive diagonals,
r_+(D₁MD₂) = r_+(M), because if M = UV with U, V ≥ 0, then D₁MD₂ = (D₁U)(VD₂). Consequently:
- (a) weights v_n placed as a row factor are invisible;
- (b) r_+ does not distinguish Λ from cΛ, c > 0, in any multiplicative construction on the weights;
- (c) FAMILIES_B's "slack matrix of the weighted pattern polytope" does not separate cΛ.

The only way out is an **additive threshold**: the comb's weights compete, within each entry, against a
fixed-scale term (the archimedean Γ_ℝ). That way c changes the zero pattern of the positive part.

### C.1 Exact definition of the object

Notation (P47, def:W/def:PD/eq:nuw, unchanged):
- T > 0;
- N_T = ⌊e^{2T}⌋;
- comb v_n = 2Λ(n)/√n;
- for a generic comb X, v_n^X = 2X(n)/√n (X ∈ {Λ, a_P, cΛ, Λ_Beurling, Epstein's Λ_Q, DH's b_n});
- test g ∈ P_T, i.e. g even, supported on [−2T, 2T], with g = f ∗ f̃ for f ∈ C_c^∞[−T,T] and moments A = B = 0;
- K_∞ is the archimedean kernel (Lévy + C₀) of lem:K/eq:m, so that the archimedean part of the form is
  ∫ g(x)K_∞(x)dx plus the constant terms.

**Indices (the semiring layer).**
- Rows: R_T = {(k,n) : k, n ≥ 1, kn ≤ N_T, v_n^X ≠ 0}.
- Columns: C_T = {m : 1 ≤ m ≤ N_T + 1}.
- Layer relation: (k,n) ∼_ε m ⟺ m − kn = ε, with ε ∈ {−1, 0, +1}.

**Threshold matrix.**

  M_T^X(g)[(k,n), (m,ε)] = ( v_n^X · g(log m − log k) − κ_∞(g; m, k) )_+ · 1{(k,n) ∼_ε m},

with κ_∞(g; m, k) = ∫_{log(m/k) − δ_T}^{log(m/k) + δ_T} g(x)K_∞(x)dx and δ_T = ½ log(1 + 1/N_T), half the
minimum spacing of log ℕ in the window. Columns are indexed by pairs (m, ε), so the matrix has three column
blocks, one for each additive shift.

Four observations about the definition:
- **Neither 𝔞_T nor its summed kernel appears.** Each entry compares a single comb contribution with a
  single local archimedean cell. The form is the *sum* Σ_n v_n g(log n) + ∫gK_∞ + …, and the matrix sums
  nothing (S1).
- **The additive coupling comes from m ∼_ε kn.** For ε = 0 the entry reads g at log(m/k) = log n, which is
  the contact position of n, and the block is multiplicative. For ε = ±1 it reads g at
  log((kn ± 1)/k) = log n + O(1/kn): the entry compares v_n with the kernel **at the point shifted by the
  near-additive coincidence**. For Beurling (non-integer positions) the ε = ±1 blocks are empty or have a
  different zero pattern (S2, G1).
- **The sign of v_n^X enters literally.** If v_n^X < 0 (Λ_cosh at Ω_𝒩 = 4, DH's b_n with χ(n) = −1), the
  entry (v·g − κ)_+ is 0 where g > 0 and can be positive where g < 0. So the support of M changes in a way
  that is not linear in the comb (S6, O2).
- **r_+ is not a datum (C-data).** M depends on g, so r_+(M_T^X(g)) is a function of the test and not a
  constant of the comb (O5).

**Integer invariant.**

  I_T^X(g) := r_+( M_T^X(g) ) − rank_ℝ( M_T^X(g) ) ∈ ℤ_{≥0}.

This is the **nonnegative excess**. Subtracting the ordinary rank removes the part Theorem 3′ controls (the
ordinary rank of a matrix with piecewise-analytic entries is generic on each sign cell). What remains is a
purely semialgebraic invariant.

### C.2 Why I_T(g) has no generic value in g

1. **Piecewise constancy (PROVED, elementary).** Let Σ(g) be the sign pattern of the entries of the previous
   matrix before the positive part, on the finite set R_T × C_T. Each entry is a continuous linear function
   of g, so P_T is split into open polyhedral cells (cones) C_σ = {g : Σ(g) = σ}, plus walls of codimension
   ≥ 1. Within each cell, M_T(g) has fixed support and entries linear in g.
2. **Within a cell, r_+ is not generic either (CITED + ARGUED).** The set {M ≥ 0 with fixed support, rank = r,
   r_+ = s} is semialgebraic. For rank ≥ 3 there are pairs (r, s) with s > r that occupy open sets of the
   rank-r variety (Cohen–Rothblum 1993; example of regular octagons in extension complexity theory, CITED
   from memory; this must be verified before use in P47). For rank ≤ 2 one always has r_+ = rank (CITED), so
   the excess is 0: **the first lemma must work where rank M ≥ 3.**
3. **Contrast with Theorem 3′.** Theorem 3′ requires real analytic entries of finitely many functionals of E.
   Here:
   - (a) (·)_+ is not analytic on the walls;
   - (b) r_+ is neither a rank nor a nullity of an analytic matrix, but the minimum of a factorization under
     inequality constraints, i.e. a projection of a semialgebraic set.

   Neither hypothesis of Theorem 3′ holds. **This is the new written reason** against the rank-counting
   closure in 𝔇₁/𝔇₂ (AUDIT_200_DCONS).

The dependence on g is therefore one of **sign and support**: the pattern σ(g) plus the semialgebraic
position within the cell. It is not an analytic dependence.

### C.3 Target theorem

Two pieces are needed: an inequality linking I_T with 𝔞_T, and a PROVED fact about I_T.

**(T201-a) Excess inequality (OPEN, the heart of it).** There exists an explicit function
β_T : ℤ_{≥0} → ℝ_{≥0} with β_T(0) = 0 such that, for every g ∈ P_T,

  𝔞_T^Λ(g) ≥ − β_T( I_T^Λ(g) ) · ‖g‖_{P_T},

and β_T(j) = 0 for j ≤ j_T (integer threshold).

**(T201-b) Constructive upper bound of r_+ (what might be PROVED).** For every g ∈ P_T,
r_+(M_T^Λ(g)) ≤ rank + j_T. This would be proved by **exhibiting an explicit nonnegative factorization** of
M_T^Λ(g) through the layer: column (m, ε) factors through the "intermediate node" kn. The number of distinct
intermediate nodes in the window is the number of products kn ≤ N_T with n ∈ supp Λ, and that gives
r_+ ≤ #{kn} directly, via the Yannakakis factorization through an extended polytope. The question is whether
the excess stays bounded by j_T *because Λ ≥ 0*. For Λ, all active entries of an intermediate node share the
sign of v_n, so the node is a monochromatic rectangle and enters the factorization at cost 1. With
mixed-sign coefficients (Λ_cosh, b_n) the same node splits, and the cost grows.

**Combination.** (T201-b) gives I_T^Λ(g) ≤ j_T for every g, and with (T201-a) that gives 𝔞_T^Λ(g) ≥ 0 on
P_T, i.e. L′♯ at T.

**Why it is not REF-D.**
- I_T is defined without the form: neither 𝔞_T nor its summed kernel appears (C.1). (T201-b) is a statement
  about nonnegative factorizations of a matrix of local pieces, and is proved with a monochromatic-rectangle
  argument that uses only "v_n ≥ 0 for Λ" and the structure of the layer m = kn ± ε.
- Positivity is not transported: "Λ ≥ 0" is trivially true, but does not by itself imply 𝔞_T ≥ 0, because
  a_P and cΛ are also ≥ 0 (C-E′, Lemma B.2). That is why (T201-a) must use the **threshold against K_∞** and
  the ε = ±1 layer. The new content is in (T201-a).
- **Honest warning.** If (T201-a) can only be proved by writing 𝔞_T as a signed sum of M's entries, it falls
  into branch 2 and the family dies (see C.6). The point of (T201-a) is that the *integer excess* controls
  negativity, not that it rewrites it.

**Caution fact.** (T201-b) as written does not distinguish Λ from a_P (a_P is also ≥ 0). The separation of
a_P must come from the threshold: deleting p changes which intermediate nodes exceed κ_∞. The first lemma
decides whether that happens.

### C.5 First lemma, finite and computationally decidable

**Lemma V1.1′ (OPEN; decided by a finite exact computation).** Do there exist T and g ∈ P_T such that

  rank M_T^Λ(g) = rank M_T^X(g) ≥ 3  and  I_T^Λ(g) ≠ I_T^X(g)

for X ranging over the battery? The goal is to find the smallest T achieving this, in these windows:
- **a_P:** T ∈ [0.60, ½log P] with P ∈ {2, 3} (N_T ≤ 3: tiny matrices, so it is better to start with P = 5, 7,
  with T ≤ ½log 7 ≈ 0.973);
- **Beurling:** T ≤ ½log15 (N_T ≤ 15; Mori's μ = 15 calibrator window);
- **Epstein 11:** T = 8/5 (N_T = 24);
- **DH 12:** T = 9/5 (N_T = 36);
- **cΛ:** c ∈ {1.15, 2}, with T = 1 and T = ½log 5 (the same T as rows 8 and 10 of the battery).

**Decisive outcome.** A **yes** with the signature "I_T^Λ ≤ I_T^X at every negative witness of the battery"
(i.e. Λ's excess below each falsifier's exactly where the falsifier's form is negative) is the first
non-generic integer separation aligned with the sign. A yes without alignment is a separation without sign
content.

**Script sketch** (`scratch/v11_rplus.py`, written in stage 3):
1. Generate the exact combs v_n^X for n ≤ N_T (Λ, a_P, cΛ, Λ_Q, b_n^{DH}, Beurling with primes
   {2, 3, 5.1, 7.05, …} fixed by the FAMILIES_A §4 rule).
2. Tests g: take the certified witness vectors from the battery (vec_T*.json from phase-198
   CERT_FALSIFIERS_001, Epstein degree 56, DH Legendre ≤ 259) and Mori's witness. These are tests in P_T with
   certified 𝔞^X < 0. Add a cloud of random tests from P_T (Legendre basis projected to A = B = 0) to sample
   σ cells.
3. Compute κ_∞(g; m, k) with mpmath or Arb (kernel from lem:K/eq:m) and assemble M_T^X(g) with interval
   arithmetic. Discard g if any entry contains 0 in its interval (wall): there r_+ is not determined.
4. Compute the rank by exact elimination over ℚ, with rounded rational intervals.
5. For exact r_+ (size ≤ ~40 × 110, small rank), combine three tools:
   - (i) **lower bound** via the rectangle covering number of the support pattern (Boolean rank ≤ r_+), with
     a SAT or ILP solver; the fooling-set bound; the Fawzi–Parrilo bound (psd rank / SDP) as a real lower
     bound;
   - (ii) **upper bound** via explicit factorizations: NMF with a rational certificate, and the kn-node
     factorization of (T201-b);
   - (iii) when (i) and (ii) disagree, exact decision of r_+ ≤ s by quantifier elimination (Vavasis: this is
     NP-hard, but feasible for rank ≤ 4 and small sizes; Moitra's algorithm, O((mn)^{O(r²)})).
6. Output: a table (X, T, g, rank, I^Λ, I^X, certified 𝔞^X(g)), compared with:
   - Mori μ = 15: W_T(g*) = 4.978·10⁻⁷⁰, with J = −1.42·10⁻³⁴;
   - Epstein T = 8/5: [−0.0619395254, −0.0619395173];
