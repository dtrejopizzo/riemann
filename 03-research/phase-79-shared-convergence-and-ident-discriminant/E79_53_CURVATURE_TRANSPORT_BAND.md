## 1. Why this audit was needed

E79.52 localized the residual burden to one coefficient:

```text
residual(sigma; N) ~ a_N sigma + b_N + g_N (sigma-1.375)^2.          (53-1)
```

The first instinct is to expect a curvature coefficient to scale like `N^-2`,
but that was only a guess. E79.53 audits the scaling directly.

## 2. Probe

Companion files:

```text
E79_53_CURVATURE_TRANSPORT_BAND_PROBE.py
E79_53_curvature_transport_band_results.json
```

For each build the probe tests the band quality of

```text
N^p |g_N|,   p in {1.0, 1.5, 2.0, 2.5, 3.0},                        (53-2)
```

and picks the exponent with the narrowest audited band.

## 3. Result

On the zeta side, the best exponent is already

```text
p = 1.0,                                                             (53-3)
```

with

```text
N |g_N| = 0.01196, 0.01409, 0.01008, 0.01283, 0.01159,              (53-4)
band ratio = 1.40.
```

By comparison:

```text
N^2 |g_N| has band ratio 1.94,
N^3 |g_N| has band ratio 3.87.                                       (53-5)
```

So the naive `N^-2` picture was simply the wrong scale.

On the planted build, every tested exponent has a huge band; even the best one
(`p=1`) still has band ratio about `52.9`. So the planted hard rows remain far
from any comparable transport law.

## 4. Reading

This is a real simplification:

```text
the slope transports like N^-1,
and the curvature mode also transports like N^-1.                    (53-6)
```

So the residual side is much more coherent than it first looked. The true
burden is now concentrated even more tightly in the remaining level term.

## 5. Consequence

After E79.52-E79.53, the residual anatomy is:


That is a strikingly small finite object.
