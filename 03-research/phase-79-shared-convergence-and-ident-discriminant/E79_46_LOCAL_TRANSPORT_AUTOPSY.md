# E79.46 - No fixed low-complexity local transport law explains the zeta packet sequence

**Scope:** `GAP-Z` only, autopsy of the most naive transport-law idea left open
after E79.45.  
**Class:** AUTOPSIA HONESTA.  
**What we know after this document that we did not know before:** the zeta-side
packet sequence from E79.44 is not generated by any fixed local transport rule
of the simplest natural kind (small shift plus small add/remove sets) on the
4-shell terminal window.

## 1. The transport hope

After E79.45, the next tempting idea was:

```text
maybe the first packet is primitive, but it still moves by a simple local law
from one section to the next.                                         (46-1)
```

The audited zeta-side local support sequence is

```text
N= 8   {1,2,3}
N=10   {0,1,2,3}
N=12   {0}
N=14   {1,2,3}
N=16   {1,3}.                                                         (46-2)
```

E79.46 asks whether a single fixed local rule can generate this sequence.

## 2. Probe

Companion files:

```text
E79_46_LOCAL_TRANSPORT_AUTOPSY_PROBE.py
E79_46_local_transport_autopsy_results.json
```

The probe tests the most natural low-complexity family:

```text
T(S) = clip( (S + shift) U A ) \ R,                                   (46-3)
```

where

```text
shift in {-1,0,1},
A,R subset {0,1,2,3},  |A|,|R| <= 2,                                 (46-4)
```

and `clip` truncates back to the 4-shell window.

So each candidate rule is a fixed combination of:

```text
- one local shift,
- one small permanent birth set A,
- one small permanent death set R.                                    (46-5)
```

The probe measures exact hits across the four transitions in `(46-2)` and the
total symmetric-difference error.

## 3. Result

No rule in the family `(46-3)-(46-4)` reproduces all four zeta transitions
exactly.

The best rule found still misses part of the sequence, so:

```text
the packet motion is not a fixed low-complexity shift/add/remove automaton on
the terminal 4-shell window.                                          (46-6)
```

In fact the best audited rule is already poor:

```text
shift = -1,  A = {1,3},  R = {2},
exact hits = 0 out of 4 transitions,
total symmetric-difference error = 5.                                 (46-6a)
```

## 4. Reading

This is a useful autopsy, not a disappointment.

It says the next structural object is not just:

```text
"primitive packet + trivial transport".                               (46-7)
```

So if there is a transport law at all, it has to depend on something richer
than the packet support alone, for example:

```text
- sigma-weighted shell amplitudes,
- the signed residual after packet subtraction,
- or section-dependent data from ZERO^extra itself.                   (46-8)
```

## 5. Consequence

Together, E79.44-E79.46 now rule out three increasingly hopeful simplifications:

```text
- the packet is not a one-sigma accident;
- it is not the first term of a second packet expansion in the same grammar;
- it does not move by a fixed low-complexity local automaton.         (46-9)
```

That leaves a sharper frontier:

```text
the first raw packet is primitive, but the next law must involve more than the
support sequence itself.                                              (46-10)
```
