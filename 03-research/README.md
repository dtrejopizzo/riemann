# The Research Program (Phases 0–213)

This folder is the core of the project: a single continuous research program, run as a sequence of
numbered phases after nine early exploratory computational programs
(see [`../01-context/`](../01-context/), *Research Programs 1–9*).

Each `phase-*/` folder is a self-contained block of work with its own README: the question, the
results with their status labels (PROVED / CITED / CONDITIONAL / ARGUED / OPEN / NO-GO / NUMERICAL),
the documents, and the relation to other phases. Phases 0–107 build the Weil-form framework and its
obstructions; phases 108–133 close rows A, B and C on the declared carrier; phases 134 onward are the
work on row D (Weil positivity of the window form), which remains OPEN.

## How the phases connect to the papers

The results distilled from these phases are in [`../04-papers/`](../04-papers/)
(catalogued in [`../04-papers/README.md`](../04-papers/README.md)). Every route already tried is indexed in
[`../05-meta-and-planning/ROUTES-MASTER-INDEX.md`](../05-meta-and-planning/ROUTES-MASTER-INDEX.md).
