## 1. The blueprint's finding that opens the campaign (to be verified, not assumed)

Paper 46 Definition 6.8(R5) asks for a duality `F ↦ F^∨` that carries the primitive
sector off itself, and shows the only duality rows A–C construct — `†` — preserves
it. **(R5) was posed for involutions compatible with `⋆`.** But Weil's duality
`D ↦ K − D` is not an algebra map at all: it is an **affine involution of the
divisor group**, translation by the canonical class composed with negation. On
the correspondence algebra the divisor group is the additive group of classes, and
`E ↦ K − E` moves the primitive sector off itself for **any** `K` with
`M(K) ≠ 0`. So (R5) is not a missing involution; it is a missing **class** `K`,
and the constraint that pins `K` is (R3): the RR shape
`χ(E) = ½ E·(E − K) + χ(O)` requires `ℓ(M(E)) = −½ I_∞(E,K)` to be **linear in
the ruling data**, i.e. `K` must pair with every class through the rulings alone:

    I_∞(F, K) = 0  for every primitive F         ⟺   K ∈ P^{⊥_{I_∞}} .

By the comparison theorem this forces `Φ_K(ρ) = 0` at every zero (Task D.6(iii)
proves the equivalence), i.e. `Φ_K = ξ · e` with `e` entire. The canonical choice
`e ≡ 1`:

**Definition (the canonical class, candidate).**  `K` is the real even function
on the modulus group with `Φ_K(s) = ξ(s)`, `ξ(s) = ½ s(s−1) π^{−s/2} Γ(s/2) ζ(s)`.
Equivalently `K(t) = (2π)^{−1} ∫ Ξ(τ) e^{−iτt} dτ` with `Ξ(τ) = ξ(½ + iτ)`:
**Pólya's kernel** `K(t) = Σ_{n≥1} (4π²n⁴e^{9t/2} − 6πn²e^{5t/2}) e^{−πn²e^{2t}}`
(normalization to be fixed and checked numerically: `∫K = ξ(½)`,
`Φ_K(0) = Φ_K(1) = ξ(0) = ½`). Classical facts to import with citation: `K` is
even, real, `K(t) > 0` for all `t`, `K(t) ~ 4π² e^{9|t|/2} e^{−πe^{2|t|}}`.

Expected consequences (each is a task, none is assumed):

* `K ∉ D_A^{rad}` (not compactly supported) — so `I_∞` must first be **extended**
  to a completed class `D^W` (the Weil test class) on which the explicit formula
  is CLASSICAL; this is why Paper 43 Thm 14.1(d) `(D_A^{prim})^{⊥} = 0` at charts
  is consistent with `K ≠ 0` in the completion. The Hodge-index shape rows A–C
  lack at every chart exists in the colimit completion.
* `I_∞(F,K) = ½(Φ_F(0) + Φ_F(1)) = ½ deg F`, where `deg F := I_∞(F, A)`,
  `A := e_+ + e_-` the ruling class with `I_∞(F,A) = Φ_F(0)+Φ_F(1)`.
  Numerically `K ≡ ½(e_+ + e_-)`, `I_∞(K,K) = 2ξ(0)ξ(1) = ½`, `T_∞(K) = 1`.
* `Frob_n ⋆ K` pairs through rulings only, with weights `n^{±1/2}` — the
  Frobenius acts on the canonical class as it does on rulings in `C × C`.
* **The radical of the extended form is nonzero:**
  `𝓝_∞ := rad(I_∞|_{D^W}) = {N : Φ_N = s(1−s)ξ(s)e(s), e entire} = ΠK ⋆ D^W`
  (to be proved, both inclusions), and `𝓝_∞ ∩ D_A^{rad} = 0` — Paper 45
  Thm 12.2 — **by zero counting**: a Paley–Wiener function has `O(r)` zeros in
  `|s| < r` and `ξ` has `~ (r/2π) log r`. This reconciles Thm 12.2 with the new
  radical and identifies the "principal classes" of the surface: the ideal
  generated by `ΠK`.
* Effective classes (`E ≥ 0` pointwise, `E ≠ 0`) have `deg E > 0`; principal
  classes have `deg = 0`; hence **no nonzero principal class is effective**, and
  no nonzero primitive class is effective. These are the two facts Weil's
  argument needs from "effective".
* **Openness of the ample cone from Chebyshev alone.** For `F ∈ D_A^{rad}` and
  `E ≥ 0`: `|I_∞(E,F)| ≤ C_F · deg E` with `C_F` depending only on `F`, because
  `t ↦ T_∞(τ_t F^†)` is `O(e^{|t|/2})` unconditionally (`ψ(x) = O(x)`, no
  zero-free region). Hence `F + mA` is "ample" for `m > C_F`: positive against
  every effective class.

## 2. Theorem targets (labels prescribed; report may refute any of them, and must say so as in phases 131–134)

**D.6 — Extension and the canonical class.** `PROVED` / `CLASSICAL`.
 (i) Define `D^W` (real functions on `R` with `g, g'` of decay `O(e^{−(½+ε)|t|})`
     — Weil's class, or the sharper class the report finds convenient) and prove
     that `I_∞` extends from `D_A^{rad}` to `D^W` with (9.9) valid (CLASSICAL
     explicit formula for that class; cite the exact source; the absolutely

 (ii) `K ∈ D^W`, `K > 0`, even, `Φ_K = ξ`, `M(K) = (½,½)`, `I_∞(F,K) = ½ deg F`
     for all `F ∈ D^W`, `I_∞(K,K) = ½`, `T_∞(K) = 1`. Numerical check in a script.
 (iii) `P^{⊥_{I_∞}} ∩ D^W = {G : Φ_G(ρ) = 0 ∀ρ} = ξ·(entire) ∩ Mellin(D^W)`, with
     the independence argument written out (the distribution
     `Σ_ρ c_ρ ρ(1−ρ) e^{(ρ−½)t}` vanishes only if all `c_ρ = 0`; convergence
     stated).
 (iv) `Frob_n ⋆ K` ruling weights.
 Falsifier remark: (i)–(iv) hold verbatim for `Ξ_a` with `K_a`,
 `Φ_{K_a} = ξ(s+a)ξ(s−a)`, `K_a = (e^{at}K) ⋆ (e^{−at}K) > 0`. They carry no sign.

**D.7 — The radical, principal and effective classes.** `PROVED` / `PROVED-IN-REPOSITORY`.
 (i) `𝓝_∞ = ΠK ⋆ D^W` (or the precise closure the report can prove; state the
     class exactly).
 (ii) `𝓝_∞ ∩ D_A^{rad} = 0` by zero counting — a **new proof** of Paper 45
     Thm 12.2 to be compared with the recorded one.
 (iii) effective ⇒ `deg > 0`; principal ⇒ `deg = 0`; primitive ⇒ not effective.

**D.8 — The affine duality and the transfer theorem (supersedes Def 6.8).** `PROVED` (conditional transfer) + `RESTATEMENT`.
 Define the affine involution `σ_K : E ↦ K − E` on `D^W`. Prove `σ_K` satisfies
 (R5). Then state and prove:

 > **Theorem D.8 (Hodge-index transfer).** Suppose a function
 > `h^0 : D^W → R_{≥0}` satisfies
 >  (a) `h^0(E) ≥ 0`;
 >  (b′) `h^0(E) > 0 ⇒ E ≡ E' (mod 𝓝_∞)` for some `E' ≥ 0`;
 >  (c) `h^0(E) + h^0(K − E) ≥ ½ I_∞(E,E) − ½ I_∞(E,K) + χ` for a constant `χ`.
 > Then `I_∞(F,F) ≤ 0` for every primitive `F ∈ D_A^{rad}`, hence RH
 > (Paper 45 Thm 10.4).

 Proof to be written exactly along Hartshorne V.1.9 with `H = A`, `H' = F + mA`,
 `m > C_F` from D.7(iv), `E = nF` and `E = K − nF`; every step cites D.6–D.7.
 Then: **(R1)–(R5) of Definition 6.8 are superseded by (a),(b′),(c)**; record
 that (R5) is satisfied by `σ_K`, and that the duality was never the obstruction.
 Falsifier remark: the transfer theorem holds verbatim for `Ξ_a`; since `Ξ_a`
 has off-line zeros, **no `h^0` with (a),(b′),(c) exists for `Ξ_a`**. Whatever
