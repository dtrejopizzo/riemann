# E81.002 - Exact bordered secular reduction

## 1. Finite determinant identity

For fixed `L,N`, write the verified finite representation as

```text
F_{L,N}(z)
 = det([zI-D_{L,N}, x_{L,N}; q_{L,N}^T,c_{L,N}])
   /det(zI-D_{L,N}),                                   (1.1)
```

The transfer is

```text
T_{L,N}(z)=F_{L,N}(z)/(z-d_{b,N}).                     (1.3)
```

### Proposition 1.1

Define the denominator-free secular function

```text
G_{L,N}(z)
 = c_{L,N}-q_{L,N}^T(zI-D_{L,N})^{-1}x_{L,N}.          (1.2)
```

Then

```text
F_{L,N}(z)=G_{L,N}(z),                                 (1.4)

G'_{L,N}(z)/G_{L,N}(z)
 = q_{L,N}^T(zI-D_{L,N})^{-2}x_{L,N}
   /[c_{L,N}-q_{L,N}^T(zI-D_{L,N})^{-1}x_{L,N}].       (1.5)
```

### Proof

The Schur complement of `zI-D` in the bordered matrix gives (1.4).  Since

```text
d/dz (zI-D)^{-1}=-(zI-D)^{-2},
```

one has `G'=q^T(zI-D)^{-2}x`.  Division by `G`, which is nonzero on the safe
domain, proves (1.5). `QED`

If `c_{L,N}!=0`, one may set

```text
K_{L,N}=D_{L,N}+c_{L,N}^{-1}x_{L,N}q_{L,N}^T
```

and recover `G=c det(zI-K)/det(zI-D)`.  This optional representation is not
used in estimates because `c_{L,N}` may be zero or very small.

## 2. Bilateral core factorization

Put `u=s-1/2`.  Substituting (1.1)--(1.3) into the bilateral core
characteristic gives

```text
C_{L,N}(s)
 = A_{L,N}(s) Q_{L,N}(s),                              (2.1)

A_{L,N}(s)
 = sinh(Lu/2)^2
   /[Z^ext_{L,N}(-iu)(iu-d_{b,N})(-iu-d_{b,N})],       (2.2)

Q_{L,N}(s)
 = G_{L,N}(iu)G_{L,N}(-iu).                            (2.3)
```

Every factor in (2.2) is explicit and build-neutral.  All dependence on the
finite CCM entries is contained in the single secular function `G_{L,N}`.

### Corollary 2.1 - normalized secular endpoint

For a safe base point `s_*`,

```text
C_{L,N}(s)/C_{L,N}(s_*)
 = [A_{L,N}(s)/A_{L,N}(s_*)]
   [Q_{L,N}(s)/Q_{L,N}(s_*)].                          (2.4)
```

Consequently RDI-ANCHOR is equivalent to the outer limit

```text
Q_L(s)/Q_L(s_*)
 /
{ [E_L(s)/E_L(s_*)]/[A_L(s)/A_L(s_*)] }
 -> 1,                                                 (2.5)
```

provided the fixed-`L` projective limits of the displayed factors exist.

## 3. Logarithmic form

Differentiating (2.1) gives the exact identity

```text
d/ds log C_{L,N}
 = d/ds log A_{L,N}
   + i G'_{L,N}(iu)/G_{L,N}(iu)
   - i G'_{L,N}(-iu)/G_{L,N}(-iu).                    (3.1)
```

Using (1.5), this contains no determinant and no matrix inverse other than the
explicit diagonal Cauchy denominators.  The arithmetic anchor becomes

```text
i R_{L,N}(iu)-i R_{L,N}(-iu)
 - [H_L-d/ds log A_{L,N}] -> 0,                         (3.2)

R_{L,N}(z)
 = q^T(zI-D)^{-2}x/[c-q^T(zI-D)^{-1}x],                (3.3)
```

in the iterated or cofinal limit.

## 4. What has and has not been reduced

The determinant problem is now a scalar residue problem:

```text
G_{L,N}(z)
 = c_{L,N}-sum_j a_{j,L,N}/(z-d_{j,L}),

a_{j,L,N}=q_{j,L,N}x_{j,L,N}.                          (4.1)
```

Finite real-rootedness and convergence of the pole cloud do not determine
these residues.  The bilateral characteristic sees them only through the
symmetrized spectral shift generated by the zeros of `G`; E81.003 makes this
quotient explicit.
