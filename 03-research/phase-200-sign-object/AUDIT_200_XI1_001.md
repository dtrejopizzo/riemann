## Summary (≤200 words)

**Verdict: NO-GO PROVED for d_T as defined. Ξ1 falls into branch 4 of Φ200 (blind to ζ) and, by Lemma
Ξ1.1, also into branch 2.**

(1) **Fell absorption** (CITED; two-line proof in §1): λ_G⊗π ≅ λ_G⊗1. With this, the module generated by f_g⊗δ_e
is ℓ²(G)⊗ℂf_g, giving **d_T(g) = 1 for all g ≠ 0**. The dimension does not jump, and depends neither on T, nor Λ, nor h.
C-τ and C-θ fail.

(2) G = ℚ⋊ℚ^×_{>0} is ICC and amenable, so L(G) ≅ R, the hyperfinite II₁ factor (Connes 1976). The same holds for
G_K. The factor sees neither the primes, nor ζ, nor h.

(3) V^*Ш = 2log|x|Ш is a distribution or an unbounded operator on L²(ℝ), not an element of L(G), so τ is not
defined. By V2.4, an E_T of the required type has rank one, and R has no minimal projectors. If E_T lives in B(L²(ℝ)),
τ(PEP) = |⟨f_g,ψ⟩|² is a Gram form: REF-D.

(4) Cl(K) does not appear in K⋊K^×. Moreover, K⋊K^×/𝒪_K^× is ill defined, because −1 acts nontrivially on K. The
class group lives in K^×\𝔸_f^×/Ô^×.

(5) There is nothing to salvage: the L²-Betti numbers of an infinite amenable group are 0 (Cheeger–Gromov).

## 1. Is Ξ1 new? Is the "new reason" real?

**Index.** Ξ1 does not appear literally under that name. Its neighbors are these:
- **G5H-122**: ax+b over ℓ²(ℕ), with the determinant anomaly. Closed.
- **INV_V_001**: Heisenberg–Hecke algebra in L²(ℝ), the same representation Ξ1 uses (a^{½}f(ax+b)). Its relevant
  results are NO-GO 𝒦_Ш and "the dilation subalgebra only gives symbols."
- **Phase 158**: the adele class space is a restatement.
- **Bost–Connes/KMS family**: DEAD (README l.250).

Reason (ii) of the spec says "Beurling has no G here." That is true, but it has no effect, because the proposed
invariant does not depend on Λ (see below). Reason (i), "dimension instead of KMS," is new only in name. The problem
is that the dimension is poorly suited to the object. Two facts show this.

**(a) ICC, type II₁, continuous dimension. CITED/PROVED.** The conjugacy classes of G are infinite:
- (b,1) with b ≠ 0 is conjugate to (ab,1) for every a ∈ ℚ^×_{>0};
- (b,a) with a ≠ 1 is conjugate to (b + c(1−a), a) for every c ∈ ℚ.

Hence L(G) is a type II₁ factor with trace τ. The dimensions of L(G)-modules take all values in [0,∞]. No
value is forced to be an integer or discrete. So the claim in §D Filter A, "C-θ and C-τ: the dimension jumps," does
not follow from anything. In a type II₁ factor, dimension is the trace of a projector, and that trace is continuous.

**(b) Fell absorption: d_T is constant. PROVED.** Let π be the representation on L²(ℝ). The operator
W(δ_x⊗ξ) = δ_x⊗π(x)^{−1}ξ is unitary on ℓ²(G)⊗L²(ℝ) and intertwines λ⊗π with λ⊗1 (Fell 1962; Bekka–de la Harpe–Valette,
*Kazhdan's property (T)*, Cor. E.2.6, CITED). Since W(δ_e⊗f_g) = δ_e⊗f_g, the closed G-invariant subspace generated by
f_g is W^{−1}(ℓ²(G)⊗ℂf_g). That subspace is an L(G)-module isomorphic to ℓ²(G). Consequently,

  **d_T(g) = dim_{L(G)} ℓ²(G) = 1 for all g ≠ 0, and d_T(0) = 0.**

The only discontinuity is at g = 0, and it is trivial. The conclusion does not change if only L²(ℝ) is used, without
the ℓ²(G) factor. In that case one must take the G-invariant subspace generated by f_g in L²(ℝ). π is irreducible for the
real ax+b group (CITED, Gelfand–Naimark), G is dense, and π is strongly continuous. Hence that subspace is all of L²(ℝ), for
every g ≠ 0.

Conclusion: **d_T depends neither on T, nor Λ, nor on the comb.** It takes the same value for ζ, Beurling, a_P, cΛ, and DH. That is
exactly branch 4 of Φ200: the value of Ψ at ζ coincides with its value on a family that is constant against ζ.

## 2. Literature: the factor L(G)

- **Amenability.** G is solvable (it is an abelian-by-abelian extension), hence amenable.
- **Classification.** Connes (1976, *Ann. of Math.* 104, 73–115, "Classification of injective factors") proves that L(G)
  is injective. For a countable amenable ICC group this gives L(G) ≅ R, the unique hyperfinite II₁ factor (uniqueness by
  Murray–von Neumann in the hyperfinite case; injective ⟹ hyperfinite by Connes). CITED.
- **G_K.** K⋊K^× is also solvable and ICC, so L(G_K) ≅ R.

Consequences:
- **At the level of the factor, Ξ1 sees neither the primes, nor ℚ^×, nor ζ, nor h.** L(ℚ⋊ℚ^×), L(ℤ[1/2]⋊2^ℤ), and L(G_K) are all the same
  factor R.
- The only nontrivial thing left is the concrete action of G: subalgebras, inclusions, specific projectors. But a
  projector depending on g and Λ must be built by hand.
- If it is built from the window form 𝒲, the result is REF-D (branch 2). If it is built from the comb
  Σ Λ(n)·(…), it is linear in a (branch 1 by Φ.1).
- §D acknowledges this ("the object is only saved if E_T is not built from 𝒲"), but gives no third source.

## 3. The Chebyshev element V^*Ш and Lemma Ξ1.1

- **Ш and V^*Ш are not in L(G).** Ш = Σ_n δ_n is a distribution on ℝ. V^*Ш = 2log|x|Ш (V2.3) is another distribution.
  As operators, they are unbounded multiplications, or forms, on L²(ℝ).
- **What an element of L(G) is.** It is a left convolution by a function in ℓ²(G) on ℓ²(G). There is no canonical
  homomorphism from "operators on L²(ℝ)" to L(G). After Fell absorption, operators acting only on the L²(ℝ) factor
  lie in the **commutant**, since they commute with λ⊗1.
- **Consequence.** "τ(V^*Ш ⊗ 1)" is not defined. This is a **type error** in the spec. At most one can regard
  1⊗V^*Ш as an operator affiliated with L(G)′ ≅ B(L²(ℝ))⊗… . But that algebra is of type I_∞ or II_∞ with no
  canonical normalization, and the trace of V^*Ш gives ∞ (log|x| is unbounded on the support of Ш).
- **V2.4** (AUDIT_196: stronger than stated). A Hermitian kernel satisfying the transfer property is c·𝟏⊗𝟏,
  i.e. of rank one. There are two cases:
  - If E_T is taken in L(G) ≅ R: R has no minimal projectors, so there is no analogue of "rank one."
  - If E_T is taken in B(L²(ℝ)): E_T = |ψ⟩⟨ψ| and τ(P_gE_TP_g) = |⟨f_g,ψ⟩|², which is a Gram form linear in the test.
    By G0, that falls into REF-D or is a certificate (branch 2).
- **Therefore Lemma Ξ1.1 falls into case (a): NO-GO.** Moreover, the target decomposition
  𝔞_T = ‖g‖²τ(PEP) − ε_T has no content: P_g = W^{−1}(1⊗|f_g⟩⟨f_g|)W, and with this τ(P_gE_TP_g) reduces to
  ‖g‖²·(a scalar independent of g) or to the Gram form above.

## 4. Sensitivity to h

- **The class group does not enter K⋊K^×.** In K⋊K^× the elements are numbers, not ideals. Cl(K) = I_K/P_K lives in the
  monoid of ideals acting on lattices, or in K^×\𝔸_{K,f}^×/Ô_K^×. The spec confuses ideals with elements. The claim
  "the module decomposes according to Cl(K) via the action of ideals on lattices" does not follow from the definition of
  G_K.
- **G_K = K⋊K^×/𝒪_K^× is ill formed.** 𝒪_K^× ⊇ {±1} acts nontrivially on K (x ↦ −x), so the quotient does not
  act on K. One would need to require the torsion-free part, or pass to the quotient K/{±1}, which is no longer a well-defined
  semidirect-product group.
- **Even with a correction, h does not appear.**
  - By §2, L(G_K) ≅ R.
  - By §1(b), d ≡ 1, so the formula "d = ½d_principal + ½d_non-principal" holds trivially: ½+½ = 1. It
    measures nothing.
  - For h to actually appear one needs a Bost–Connes/Ha–Paugam-type system (C*(K/𝒪)⋊ideals, KMS states). That
    is the DEAD family in the index.
- **Channel C-E′ (h=1 ⟺ cyclic module) is false.** By Fell absorption, the module is cyclic for every h.
