## 2. Exact Lemma K1.1 (PROVED)

Let 𝔒^{(n)}[Ψ̌] := ∫∫_{x,y>T} Ψ̌(x)Ψ̌(y) δ(x + y − 2T − log n) dx dy be the reflected pairing of atom n, and let
Ψ̌_c := Σ_{N≥μ} c_N N^{−½} τ_{log N}g be the translates part (without gauge mirror or polar part), as in the naive statement.

**Lemma K1.1′ (exact).** For every n ≥ 2,
 𝔒^{(n)}[Ψ̌_c] = Σ_{P ≥ μ²} (c∗c)(P) P^{−½} G(log(μn/P)),  (c∗c)(P) := Σ_{NN′=P, N,N′≥μ} c_N c_{N′},
and the only P that contribute are P ∈ (n, μ²n) ∩ [μ², ∞), i.e. **P ∈ [μ², μ²n)** if n < μ². In Dirichlet series,
 Σ_P (c∗c)(P)P^{−s} = (ζ(s)M_μ(s) − 1)²,  M_μ(s) = Σ_{m<μ}μ(m)m^{−s} (GG_001).

*Proof.* By bilinearity, 𝔒^{(n)}[Ψ̌_c] = Σ_{N,N′} c_N c_{N′}(NN′)^{−½} ∫ g(x − log N) g(2T + log n − x − log N′) dx. With
u = x − log N and g even, the integral is ∫ g(u) g(2T + log n − log NN′ − u) du = G(log μ + log n − log NN′) = G(log(μn/NN′))
(2T = log μ). Group by P = NN′. G(t) ≠ 0 requires |t| < log μ, i.e. n < P < μ²n. Since c_N = 0 for 2 ≤ N < μ and
N, N′ ≥ μ, P ≥ μ² (the term P = 1, N = N′ = 1 is not in Ψ̌_c). The series is the square of Σ_{N≥μ}c_N N^{−s} =
ζM_μ − 1 (GG_001). □

**Corollary K1.1″ (when it vanishes, PROVED).** If n < μ, all contributing P satisfy log(μn/P) ∈ (−log μ,
log(n/μ)], so 𝔒^{(n)}[Ψ̌_c] depends only on G in the annulus |t| ∈ [log(μ/n), log μ). In particular
**𝔒^{(n)}[Ψ̌_c] = 0 for every g supported in [−½log(μ/n), ½log(μ/n)]**. This is the correct version of the "invisibility
of the gap": it is a reduced-support statement, not an arithmetic cancellation.

**Does it cancel with g of full support? NO (PROVED).** The values G(log(μn/P)) for different P in [μ², μ²n) are not
tied by any linear relation valid on the whole core (G = g∗g sweeps a cone whose linear span contains arbitrary smooth
even functions on (−log μ, log μ), by polarization g₁∗g₂ + g₂∗g₁), and the coefficients (c∗c)(P) are not all
zero. Exact data (integer arithmetic, not numerical) for μ = 15, n = 2, P ∈ [225, 450):
 (c∗c)(P) ≠ 0 at P = 225 (+1), 255 (−2), 285 (−2), 289 (+1), 315 (+2), 323 (+2), 330 (+2), 345 (−2), 357 (−2), 361 (+1),
 374 (−2), 390 (+2), 391 (+2), 399 (−2), 418 (−2), 435 (−2), 437 (+2), 441 (+1), 442 (−2).
P = 225 comes only from c_15² = (−μ(15))² = 1. The identity Σ_{m|N}μ(m) = [N=1] was already used in full to produce the gap
(FF.0); no Möbius identity remains that cancels (c∗c) on [μ², μ²n): its generating series is (ζM_μ − 1)², whose
coefficients on [μ², μ²n) are, by the formula c_N = −Σ_{d|N, d≤N/μ}μ(N/d) (valid for N < μ², PROVED from FF.0), bilinear
sums of μ over the hyperbola NN′ = P. **The contribution of n < μ to the reflected pairing is, exactly, a smoothed sum
of Möbius correlation Σ_{NN′∈[μ²,μ²n)} μ-sums · G(log(μn/NN′))**: the main risk flagged in the spec
(§C.6) is realized. Label: **NO-GO class C6** if one wants to control it by a bound; there is no exact identity that cancels it.

**Comb-genericity.** K1.1′ uses only c_N (Möbius lattice) and g; it does not use Λ, nor residue, nor Γ_ℝ: it holds identically for cΛ
(c ≠ 1), because c_N does not depend on c (FF_001 §4: the recombination does break for cΛ in Ψ̌_log, but K1.1′ does not use it). It is
**comb-generic** in the sense of the rule. Gauge and polar: the cross terms Ψ̌_c × Φ_{φ₀}(−·) and Ψ̌_c × e^{±x/2} in
𝔒^{(n)} do not vanish (Φ_{φ₀}(−x) is supported on x ≥ T with mass near the boundary, which is exactly where the reflected
pairing has weight); they remain gauge-free functionals (§3, reason ii).

## 3. Boundary reflection identity: NO-GO (PROVED)

Spec goal: W_T(g) = 𝔒^∞_μ[Ψ̌] + 𝔇_μ[Ψ̌] − 𝔒^{Λ,≥μ}_μ[Ψ̌], with 𝔇_μ a "diagonal" Toeplitz form with weight
𝔴_μ ≥ log 2μ.

**Step 1 (PROVED, Paper 47 thm:ext-half, given Guo2026).** W_T(Ef) = 𝒲[Ψ̌_f], the full Weil form **on the line**:
 𝒲[Ψ] = (1/2π)∫m|Ψ̂|² − Σ_{n≥2} v_n c_Ψ(log n) + 2A(Ψ)B(Ψ),  c_Ψ(t) = ∫Ψ(x)Ψ(x + t)dx.
𝒲 is invariant under translations and under t ↦ −t (def:ext). Its comb is Toeplitz: atom n pairs x with x + log n.

**Step 2 (PROVED).** In FF.1 coordinates, the atom n of 𝒲 pairs translates by **ratio**: c_{Ψ̌_c}(log n) =
Σ_{N,N′}c_N c_{N′}(NN′)^{−½} G(log(nN/N′)), nonzero when N′/N ∈ (n/μ, nμ). For n = 2 < μ this includes the whole shifted
diagonal N′ ≈ 2N, N ≥ μ: the window atom is present at scale O(‖Ψ̌_c‖²/√μ)·v_2, with no gap. Integer example
μ = 15: c_22c_44 = c_26c_52 = c_33c_66 = c_39c_78 = (−1)(−1) = 1 (N′ = 2N exact, G(0) = ‖g‖² > 0). The "gap" [2, μ)
of the c_N protects the **product** NN′, never the **ratio** N′/N. (Clause (2) of the spec confuses the two
structures: the reflection x + y − 2T turns ratios into products only for the Hankel half.)

**Step 3 (PROVED): no diagonal 𝔇_μ closes the identity.** Let 𝔇_μ[Ψ] = ∫_T^∞ 𝔴_μ(x)|Ψ(x)|²dx with 𝔴_μ locally
bounded. Take g_ε ∈ core a bump of width ε centered at x₁ ∈ (−a, a), ‖g_ε‖ = 1, and φ₀ the gauge from the proof of
lem:ext-mob. Then (i) the archimedean part of 𝒲[Ψ̌] grows like C·log(1/ε)·‖Ψ̌_c‖² (m(τ) ~ log|τ|), (ii) 𝔇_μ stays
O(sup 𝔴_μ·‖Ψ̌‖²), (iii) 𝔒^∞ (continuous CM kernel, integrable at 0) and 𝔒^{Λ,≥μ} stay bounded by O(‖Ψ̌‖²) uniformly in
ε. Hence W_T(g_ε) − (𝔒^∞ + 𝔇 − 𝔒^{Λ,≥μ}) → +∞·(sign of ‖Ψ̌_c‖² ≠ 0). Alternatively, without a singularity: take
Ψ̌ far from the boundary (bump centered at x₀ ≫ T); the three Hankel pieces decay in x₀ (k_∞(2(x₀−T)) → 0, and the
atoms n ≥ μ only see 2(x₀ − T) = log n), while 𝒲 is translation invariant: 𝔇_μ would have to equal the full
Weil form of the bump, which is not diagonal (it contains −v_n c(log n) for every n). So the leftover term is exactly
 𝒲[Ψ̌] − 𝔒^{Hankel}_μ[Ψ̌] = (archimedean Toeplitz − archimedean Hankel) − Σ_{n≥2}v_n c_Ψ̌(log n) + Σ_{n≥μ}(Hankel n) + polar,
which contains **all** atoms n < μ in Toeplitz form. The identity becomes tautological only if 𝔇_μ := 𝒲 − 𝔒^∞ +
𝔒^{Λ,≥μ}, and then 𝔇_μ ≥ 0 is the target positivity (REF-D).

**Step 4 (PROVED): 𝔒_μ violates P1 (gauge).** prop:ext-gauge: Φ_φ is in the radical of 𝒲 (full Toeplitz), so
𝒲[Ψ̌ + Φ_φ(−·)] = 𝒲[Ψ̌]. The radical of a Toeplitz form is not the radical of its Hankel half: by Lemma 1 of CA_A_007,
𝔞(F) = 2𝔞(f) + 2H(f), and canceling the left side does not cancel H. Concretely 𝔒^∞_μ[Φ_φ(−·)] = 2Σ_j|∫_T^∞Φ_φ(−x)e^{−(2j+½)(x−T)}dx|²,
which is > 0 for every φ ∈ 𝒢_T with Φ_φ(−·) ≢ 0 (a CM square vanishes only if all Laplace moments at ½ + 2j
vanish, which by Müntz–Szász forces Φ_φ(−·) = 0, since Σ 1/(½ + 2j) = ∞). So 𝔒^∞_μ depends on the representative:
the 0.0645 jump leak of AUDIT_199's gauge falsifier sees it. K1 fails P1 by construction.

**Status of the steps:** 1 PROVED (cited, Guo2026 via thm:ext-half); 2 PROVED; 3 PROVED; 4 PROVED. Conclusion for item 2
of the spec: **the boundary reflection identity is false**; the only true version is tautological (REF-D).
