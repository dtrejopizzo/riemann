## Summary (≤150 words)

Over ideals, the N block of system (3.1) is a confluent Vandermonde with columns (𝔞,𝔟), N𝔞·N𝔟 = N. Its generic rank
(one variable x_𝔭 per prime ideal) is min(t, D_N), with D_N = number of distinct ideals 𝔟 in the block. Its evaluated
rank (x_𝔭 ↦ log N𝔭) is min(t, d_N), with d_N = number of distinct norms. Then δ_N = min(t,D_N) − min(t,d_N) (PROVED).
At T = 8/5 (X = 24) one gets δ = 0 for ℤ. For ℚ(i) (h = 1) δ equals 4, 31, 41 for t = 2, 3, 4, and for ℚ(√−5) (h = 2)
it equals 8, 52, 77 (NUMERICAL, exact). That δ ≠ 0 already at h = 1 shows that δ measures **splitting** (the multiplicity
of ideals of equal norm) and not the class number. Moreover δ depends on how the generic lift is chosen: with one
variable per rational prime, δ ≡ 0. The system does not contain the test, so δ is a datum of the field. **Verdict: NO.**
P201.2 stays NO-GO (PROVED) as a sign object.

## 1. Exact formula for δ_N (PROVED)

**System.** Fix X = ⌊e^{2T}⌋ and an order t. The unknowns are a_{𝔞,𝔟}, for ideals 𝔞, 𝔟 with N𝔞, N𝔟 ≤ X. For each
N and each k = 0,…,t−1 impose the condition

  L_{N,k}(a) = Σ_{N𝔞·N𝔟 = N} a_{𝔞,𝔟} · ℓ(𝔟)^k = 0.

In the **generic lift** put ℓ(𝔟) = Σ_𝔭 ord_𝔭(𝔟)·x_𝔭 in R = ℚ[x_𝔭], with one variable per prime ideal. In the
**evaluation** put x_𝔭 ↦ log N𝔭, so that ℓ(𝔟) ↦ log N𝔟. This is the literal analogue of the construction of
D_CONSTRUCTION §6, with ideals in place of integers.

**Lemma 1.** The system is block-diagonal in N. Block V_N has in column (𝔞,𝔟) the vector (ℓ(𝔟)^k)_{k<t}.

*Proof.* Each column appears in exactly one N. ∎

**Theorem 1 (exact δ_N).** Let D_N = #{𝔟 : there exists 𝔞 with N𝔞·N𝔟 = N and N𝔞, N𝔟 ≤ X} and d_N = #{N𝔟 : 𝔟 as above}. Then

  rank_gen V_N = min(t, D_N),  rank_ev V_N = min(t, d_N),  δ_N = h⁰_ev − h⁰_gen = min(t, D_N) − min(t, d_N) ≥ 0.

*Proof.* Columns with the same 𝔟 are identical. So the rank of V_N is that of the Vandermonde (y_j^k)_{k<t, j}
over the *distinct* nodes y_j. That rank is min(t, #distinct nodes), because the maximal minors are products of
differences y_i − y_j ≠ 0.

In the generic case, distinct ideals have distinct exponent vectors, so the linear forms ℓ(𝔟) are distinct. There are
then D_N distinct nodes in Frac(R).

In the evaluated case, log N𝔟 = log N𝔟′ ⟺ N𝔟 = N𝔟′, so there are d_N distinct nodes. No transcendence is used: the
nodes collapse exactly when the norms coincide, and in no other case.

The number of columns is the same on both sides, so δ_N = rank_gen − rank_ev. ∎

**Corollaries.**
- (a) t = 1: δ ≡ 0.
- (b) For t ≥ max_N D_N, the defect stabilizes at δ = Σ_N (D_N − d_N). That sum counts, block by block, the surplus
  ideals 𝔟 over the distinct norms: it is the part of the multiplicity r_K(n) = (1∗χ_K)(n) that exceeds 1, for each
  n | N admissible.
- (c) Over ℤ, r(n) = 1, so D_N = d_N and δ ≡ 0. This recovers Thm 6* of the audit.

**Decision on (2): δ ≠ 0 already for h = 1.** By Theorem 1, δ is a function of the table n ↦ r_K(n) in the window.
r_K(n) > 1 occurs as soon as there is a split prime p ≤ X, whether h = 1 or h = 2. So δ measures **splitting**, not
the class number.

The defect also does not separate Euler from non-Euler. δ depends only on the sets of norms with multiplicity, and
never on how the ideals are distributed among classes. For example, 𝔭₃ and 𝔭̄₃ in ℚ(√−5) are both non-principal and
contribute the same as 𝔭₅ and 𝔭̄₅ in ℚ(i), which are principal.

A class-restricted version, with columns restricted to 𝔟 in a class C (what a single-form Epstein would read), again
gives min(t, D_N^C) − min(t, d_N^C). That expression depends only on how many ideals of C share a norm, which is
splitting information within the class. No multiplicative term in the class appears (ARGUED). This is consistent
with LEMMA_12_1: separation by class goes through class characters, which act on *values*, not on ranks.

## 3. Does δ depend on the test? (PROVED, confirms the audit)

The system is built using only (X, t, the set of ideals with their factorizations). g does not appear. So δ = δ(K, X, t),
and in that respect it is identical to Theorem 3 of AUDIT_200_DCONS: an integer that does not see the test cannot
give the sign of I_∞(E,E) over P_T. It is a C datum (arithmetic of the field). **Confirmed: NO-GO as a sign object.**

There is a second defect, independent of the above: δ is not even intrinsic to the field. It depends on how the
generic lift is chosen.
- With one variable per prime ideal (x_𝔭 ≠ x_𝔭̄), the generic nodes of 𝔭 and 𝔭̄ are distinct and δ > 0.
- With one variable per rational prime, i.e. ℓ(𝔟) := Σ_p v_p(N𝔟) x_p, which is the natural lift if the positions
  are log N(𝔞), the generic nodes already coincide when the norms coincide. Then D_N = d_N and δ ≡ 0.

The "defect" is, therefore, the difference between two lift conventions, x_𝔭 ↦ log N𝔭 versus x_p ↦ log p, and
not a rank drop caused by the arithmetic of the logarithms (PROVED with the same argument as Theorem 1).

D_CONSTRUCTION's claim that "over ideals of O_K 𝔇 does exist" (Prop 6.4, ARGUED) reduces to this: a δ ≠ 0 does
exist, but it is a combinatorial artifact of the lift, present equally at h = 1 and h = 2, and blind to the test.

## 4. P201.2 verdict and what it teaches

**Verdict: NO** (NO-GO, PROVED). The literal answer to the map's question ("does the rank drop in some block with
repeated norms?") is yes. But the condition the map sets for the "Yes" branch, namely separating h = 1 from h = 2 by
structure (S5), **fails**: ℚ(i), with h = 1, has δ ≠ 0. So the "No" branch of MAP_200 §6 holds: S5 is not localized
over O_K by this route, and SPEC-𝔇 loses its only direction with data.

What it teaches (ARGUED):
1. A Vandermonde rank only sees **node coincidences**. Over positions log N𝔞, the coincidences are exactly
   r_K(n) > 1, i.e. prime splitting, which is a local Euler datum (χ_K(p) = 1). No rank invariant of a system of the
   type (3.1) can see the class group beyond splitting. To see it there must be coefficients that distinguish
   classes, such as the class characters of LEMMA_12_1, and those enter as values, not as coincidences.
2. The discontinuity (S5 ✓) is obtained, but at cost C. It is discontinuous in K (it jumps with every new split
   prime below X) and constant in the test. This is another instance of Theorem 3′: rank-type χ ⇒ blind to the test.
3. For the ROUTES-TRIED index: "Siegel–Dyson over ideals (positions log N𝔞), rank defect by norm coincidence" stays
   **NO-GO**. The defect equals splitting, vanishes with the rational-prime lift, and does not depend on the test.
   Reopening this requires class-dependent coefficients (character values), and that is no longer a rank.
