## 0. Summary (≤250 words)

R11.1 is formalized as an optimization problem. The LP of Paper 47 (def:PD) has fixed **data**
(weights v_n = 2Λ(n)/√n, archimedean kernel K, polar multipliers ĝ₀, ĝ₁) and **variables** (μ in the
primal; ν, β in the dual). A «relation of the multiplicative collapse» (Λ∗1 = log, r(p)r(q) = r(pq), vanishing of
ℓ_r outside p^k, …) is an equality between **data**, not between variables. **Theorem C1 (PROVED):** adding to the dual
any family of such relations with free multipliers leaves the value D_T exactly unchanged: every new column
is the function identically zero in τ. The «block test» is therefore degenerate and is decided without numerics.
**Theorem C2 (PROVED):** the only non-empty reading is the **robust** one (certifying the same value for an entire class
𝒱 of weights); there the cuts do raise the value, but (i) Λ∗1 = log on [1, e^{2T}] determines v_n over the whole window
(Möbius recursion), so the cut class is the singleton {v_ζ} and the robust value is exactly λ_P(T) for ζ;
(ii) any subfamily (e.g. only order 2 at m ≈ kn) gives a robust value ≤ λ_P(T). The cuts never exceed the
LP of ζ and its optimum is, by thm:Z, the explicit formula on flat-top tests. **Verdict:** R11.1 is a
**reformulation** of def:PD/thm:Z (REF-D), not a new channel; it does not contradict N_018 (the multipliers multiply
zero). NO-GO PROVED for the class 𝒦_cut. New restriction **C-data**. Next lemma: none in this channel; it is
suggested to close R11.1 and move on to R11.2.

## 2. The LP of Paper 47 (written explicitly)

Notation of P47 (def:PD, thm:A, prop:weak, thm:D1). For fixed T, s_T(τ) is the symbol of 𝔞_T:
s_T(τ) = m(τ) − Σ_{n ∈ 𝒩_T} v_n cos(τ log n) (+ polar term), with 𝒩_T = {n : log n < 2T}, m from eq:m.

**(P)** λ_P = inf { ∫ s_T dμ : μ even probability measure, μ̌(u) = 0 for |u| ≥ 2T, ∫ĝ₀dμ = ∫ĝ₁dμ = 0 }.

**(D)** D_T = sup { inf_τ [ s_T(τ) + ν̂(τ) + β₀ĝ₀(τ) + β₁ĝ₁(τ) ] : ν finite even measure, supp ν ⊆ {|u| ≥ 2T}, β ∈ ℝ² }.

prop:weak: c ≤ λ_P ≤ λ_A; thm:D1: D_T = λ_P, with finitely atomic certificates.

**Block version (Galerkin, M modes).** Basis {φ_1,…,φ_M} of 𝒫_T ∩ L²(I_T) (codim 2 from the Tate moments).
Primal: λ_P^{(M)} = min_{x≠0} xᵀ A x / xᵀ G x, A_{ij} = 𝔞_T(φ_i, φ_j). Explicit matrix form:
  A = A^∞ + A^pol − Σ_{n∈𝒩_T} v_n C^{(n)},   C^{(n)}_{ij} = c_{φ_i,φ_j}(log n)
(c = symmetrized cross-correlation evaluated at log n). SDP dual:
  max { λ : A − λG ⪰ 0 }  (= the degree-2 SOS in x; the "squares" are the spectral decomposition of A − λG).
This dual is exact (value = λ_P^{(M)}) by SDP duality with Slater (G ≻ 0).

**What is data and what is a variable.** In (P)/(D) and in the block SDP: **variables** = μ (or x), ν, β, λ, the Gram
matrix of the SOS. **Data** = m, K, ĝ₀, ĝ₁, (v_n)_n, (C^{(n)})_n. This distinction is what decides R11.1.

## 3. The candidate relations, done properly

The instructions already warn that c_g(log N) does not factorize; the multiplicative structure lives in the
coefficients, not in c_g. Honest inventory of linear relations in the data:

**(i) Position semigroup.** log m + log n = log mn: c_g evaluated at a sum of positions is c_g at the
product position. It is a tautology over ℝ (the position log mn *is* log m + log n); it does not relate distinct data.
It holds for every Beurling comb (comb-generic). Null column (see §4).

**(ii) Poisson/parity.** c_g(−u) = c_g(u) for real g; θ_ℤ self-dual. Parity is already imposed in def:PD (μ, ν
even). Poisson self-duality is the FE, already incorporated in m and in the polar term (l.396: «do not retry
Poisson-on-ℤ as an identity»). Redundant by construction.

**(iii) Λ∗1 = log.** For every N ≥ 1: Σ_{d|N} Λ(d) = log N, or in weights: Σ_{d|N} (√d/2) v_d = log N.
This is the only one of the three that distinguishes ζ from Epstein h ≥ 2 (Λ_Q∗r_Q ≠ log·r_Q, SPEC_005 §2, LEMMA_E), from a_P and
from cΛ (c≠1). The order-≥2 collapse relations of H.3 (vanishing of ℓ_r outside p^k; for ζ, r ≡ 1, they are
1·1 = 1) are algebraic consequences of (iii) or numerical tautologies.

**(iii′) Restriction to m ≈ kn.** For N = m·n with m, n in the window and m/n ≈ k, (iii) reads
Λ(N) = log N − Σ_{d|N, d<N} Λ(d); for N = pq: Λ(pq) = 0 = log pq − log p − log q. It is the identity
"log is additive", valid in ℝ.

None of (i)–(iii′) involves μ, x, ν, β: they are all equalities between fixed numbers (or, in (i), between fixed
functions of u).

## 4. Theorem C1: the cuts are null columns (PROVED)

**Correct formalism for a "cut with free multiplier".** A cut in a conic program is an equality
a_kᵀ z = b_k on the primal variable z; its multiplier κ_k ∈ ℝ appears in the dual by adding κ_k·(a_k, b_k)
to the certifying combination. If a_k = 0 (the relation does not involve variables), then the cut is 0 = b_k:
either it is true (b_k = 0, empty cut) or the primal is infeasible (not the case, since ζ satisfies (iii)).

To write (iii) "inside" the dual as the question asks (𝔞_T − λI = Σ squares + Σ_N κ_N·rel_N), one must
convert rel_N into a function of τ (or an M×M matrix). The only possible forms are
  rel_N(τ) := ψ_N(τ)·[ Σ_{d|N} Λ(d) − log N ]  or  rel_N := Ψ_N·[ Σ_{d|N} Λ(d) − log N ]  (Ψ_N an arbitrary matrix),
because the relation is a scalar evaluated at fixed data. For ζ the bracket is 0.

**Theorem C1 (PROVED).** Let ℛ be any family of exact linear (or polynomial) relations among the data
(v_n, m, K, ĝ_j) that hold for ζ. Let D_T^ℛ be the value of the dual of def:PD (or of the block SDP) to which
terms Σ_k κ_k·rel_k are added with free κ_k ∈ ℝ and rel_k(τ) = ψ_k(τ)·R_k(data), R_k(data_ζ) = 0. Then
D_T^ℛ = D_T = λ_P(T) (and in block form, λ^{(M),ℛ} = λ_P^{(M)}).

*Proof.* Each added term is κ_k ψ_k(τ)·0 ≡ 0, for every κ_k and every ψ_k. The feasible set of the extended dual
coincides with the original one (in the sense that the achievable values of inf_τ[…] are the same). ∎

**Corollary C1.1 (block test, PROVED, no numerics).** The test requested in §2 of the question (block SDP at
T = ½log5 with and without the cuts (iii)) gives **equal** value, identically, for every M and every basis. A
numerical run would only verify that the matrix of the added column is 0 to machine precision; by methodological
discipline (numerics only when strictly necessary) it is not run. There is no script.

**Does it contradict N_018?** No. N_018 says that Möbius identities + Cauchy–Schwarz/Bochner do not produce the sign.
C1 says something stronger for this class: its multipliers have nothing to act on. The SDP "adds
optimized squares", but those squares were already available in the dual without cuts (thm:D1: the block
SOS is already optimal). The cuts do not change the cone. So the "free multipliers that do change the
value" scenario from the question does not materialize: it would require the relation to touch a variable.

## 5. Theorem C2: the only non-empty reading is robust, and it reproduces the LP of ζ (PROVED)

For a relation between weights to act, the weights must be **variables**: it is the problem of simultaneously
certifying for a class of combs. For a set 𝒱 of admissible weight vectors
(v_n)_{n∈𝒩_T} (with the same m, K, polar term), define:

  λ_rob(𝒱) := inf_{v∈𝒱} λ_P(T; v).

This is the quantity that a "comb-generic certificate" bounds (l.40, l.396: certificates valid for Beurling).
A cut ℛ defines 𝒱_ℛ = {v ∈ 𝒱 : R_k(v) = 0 ∀k}, and obviously λ_rob(𝒱_ℛ) ≥ λ_rob(𝒱): **here indeed** the cuts raise
the bound (this is the "use of exact Λ" from the question). But:

**Lemma C2.a (determination by Möbius; PROVED).** If v satisfies (iii) for every N ∈ 𝒩_T, then
v_n = 2Λ(n)/√n for every n ∈ 𝒩_T.
*Proof.* Writing a(n) := (√n/2)v_n, (iii) is a∗1 = log on [1, e^{2T}). The truncated Dirichlet convolution
is unipotent triangular in the divisibility order: a(N) = log N − Σ_{d|N,d<N} a(d), so a is
determined by recursion from a(1) = log 1 = 0; equivalently a = μ∗log = Λ. ∎

**Theorem C2 (PROVED).** (i) With ℛ = {(iii) for every N ∈ 𝒩_T}: 𝒱_ℛ = {v_ζ} and λ_rob(𝒱_ℛ) = λ_P(T; v_ζ). (ii) For
every subfamily ℛ′ ⊆ ℛ (e.g. only N = pq with p ≈ kq, the "m ≈ kn" cut of R11.1): v_ζ ∈ 𝒱_ℛ′, hence
λ_rob(𝒱_ℛ′) ≤ λ_P(T; v_ζ). (iii) In every reading, the maximum achievable value with cuts is λ_P(T; v_ζ) = D_T, and its
optimal certificate is that of def:PD for ζ.
*Proof.* (i) by C2.a; (ii) inf over a set that contains v_ζ; (iii) combines (i), (ii) and thm:D1. ∎

**Consequence.** The cuts interpolate between the comb-generic value (low, signless: l.40, INV_H_001 H3) and the
value of ζ, which they reach exactly when the entire window is cut. They never exceed it. The optimal
certificate is then the certificate of ζ, which by thm:Z (up to an arbitrarily small uniform correction) is the
explicit formula on flat-top tests, f_w(τ) = Σ_ρ ŵ(τ−γ_ρ). The cuts do not introduce information not already
present in v_ζ: they are an encoding of v_ζ via its relations (Möbius) rather than via its values.

**Observation C2.b (localization m ≈ kn, PROVED).** For N = pq, relation (iii′) says a(pq) = log pq − a(p) − a(q)
− a(1); with a(p) = log p (which in turn follows from (iii) at N = p) this gives a(pq) = 0. So the "m ≈ kn layer"
of the cuts only forces **zeros** of the comb at integers with two factors (Λ(pq) = 0): this is the information "the
comb is supported on prime powers", which is the only part of (M) that reaches the form (H.3). In a
generic Beurling comb this is also imposed by construction (support on generalized prime powers). The relation does
not correlate the **value** at p with the value at q nonlinearly: the product r(p)r(q) = r(pq) of SPEC_005
§5.3 is, for ζ, the tautology 1·1 = 1.

## 6. Decision on thm:Z (point 3 of the question)

**Question:** is R11.1 a reformulation of thm:Z or something new?

**Decision (PROVED in the form of C1 + C2):** **reformulation.** There are two readings and both fall:
- *Fixed reading* (ζ data): the cuts are null columns (C1). The dual is literally def:PD; its optimum is
  thm:Z. Nothing new.
- *Robust reading* (weight class): the cuts reconstruct v_ζ (C2.a) and the robust value converges from below
  to that of def:PD for ζ. The limiting certificate is thm:Z. This is exactly the closed family of index l.40
  ("the dual class is D"), seen from the side of the restrictions.

Also: the statement of SPEC_005 "a use of (M) that acts on the certificate and not on the form" is incorrect as
a formalism: in a conic program with fixed data, every piece of information about the data acts on the form (via the
data) or on nothing. There is no third place. This is recorded as a restriction.

**Relation to C-hom.** Consistent: C-hom says that (M) enters 𝔞_T only as a linear cancellation in Λ; C1/C2 say
that this cancellation, reinjected as a cut, contributes nothing beyond the vector Λ itself. Both are faces of
the symbol's rigidity (EI_003; l.396 "window collapse lemma").

## 7. New restriction C-data (PROVED)

**C-data.** In the LP/SDP certification of def:PD (or any Galerkin block), every exact relation between the
**data** of the problem (weights v_n, archimedean kernel, polar terms) added with a free multiplier is a
null column: it does not change the dual value. A relation can only change the value if the data become
variables (robust reading over a class 𝒱), and then the value is bounded above by the value of the
LP of the exact comb, with optimal certificate = thm:Z. Operative corollary: **no sign object can live in
"restrictions on the certificate" other than restrictions on μ, ν, β**; the only admissible restrictions on
variables in def:PD are (support of ν outside [−2T, 2T], parity, Tate moments), all already present.

Filter for future rounds: before proposing "cuts", "relation multipliers", "arithmetic restrictions in the
dual", check whether the relation contains a variable of (P)/(D). If not: C-data ⇒ empty.
