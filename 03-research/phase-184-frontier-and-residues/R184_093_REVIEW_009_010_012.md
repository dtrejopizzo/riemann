## 1. R184_010 — Theorem L*

### 1.1 Construction and Lemma D1 — CORRECT
- Well defined: z_k depends only on U_1..U_{k−1} (via S_{k−1}), U_k is independent of 𝓕_{k−1}. With V = U_k+½ ~ U(0,1):
  E[⌊z+V⌋] = ⌊z⌋ + P(V ≥ 1−{z}) = z. Thus E[ν_k | 𝓕_{k−1}] = 0 and ν_k ∈ (−1,1). **Note:** it is only a martingale difference;
  ν_k is NOT independent of the past (its conditional variance is {z_k}(1−{z_k}), which depends on the past). Azuma only
  needs the former: correct.
- Recursion: ε_k = b − p_k^a = ν_k + z_k − p_k^a = ν_k − S_{k−1}p_k^a, so S_k = S_{k−1} + ν_k p_k^{−a} − S_{k−1} = ν_k p_k^{−a}. Correct.
- |ε_k| < 1 + (p_k/p_{k−1})^a < 1 + 2^a < 1+√2 < 3 (Bertrand); for k = 1, S_0 = 0. b ≥ 0 because z_k > 0. Correct.
- |ε_p| ≥ ‖p^a‖ holds automatically (b is an integer); it is not an additional restriction. c_{p,1}(y) = y, so 𝒦_θ(3). Correct.

### 1.2 Theorem D — CORRECT (with two minor remarks)
- Abel: Σ_{k≤K}(S_k−S_{k−1})f(p_k) = S_K f(p_K) + Σ_{k<K} S_k(f(p_k)−f(p_{k+1})). Fine; S_K f(p_K) = O(p_K^{−a}).
- Variance per block [P,2P): ψ(X/t) has ≍ X/P + 1 jumps and continuous variation ≍ X/P; with Δ² ≤ 2|Δ| this gives P^{−2a}(X/P+1);
  the trivial bound Δ² ≤ 4 per prime gives P^{1−2a}/log P. Maximum at P ≍ √X: V ≪ X^{½−a}. Verified. (The bound is also
  of the correct order for P > √X: the jumps actually give Δ² ≍ 1.)
- Azuma + union bound: t = A√(V log X), failure ≤ 2X^{−A²/2}; with A² > 6, ≤ 2Y·Y^{−3} over [Y,2Y], summable over Y = 2^j. Correct.
- Remark (minor): audit note 3 asks for O(1) variation of r over all of [1,∞): that is **false**
  (r′ ≍ 1/Y gives ∫dY/Y = ∞), but the proof only uses O(1) per dyadic block, which does hold (r(Y) = O(1/Y), r′ = O(1/Y)). Does not affect anything.
- Remark (minor): Σ_{p≤X} ε_p: the random part has variance Σ g_k²p_k^{−2} < ∞ (Heath-Brown: Σ_{p≤x} g² ≪ x^{23/18+ε},
  CITED), so it is an L²-bounded martingale: it converges a.s., O(1), better than O(√log). The tail bound Σ_{p>X}ε_p p^{−1−a}
  ≪ X^{−1−a} is deterministic and x = X^{1+a} ✓ (1/(1−θ) = 1+a).

### 1.3 Exponent conversion — CORRECT
x^θ = X^a; a + (1−2a)/4 = (1+2a)/4; (1−θ)(1+2a) = 1+θ. (1+θ)/4 < (1−θ)/2 ⟺ θ < 1/3 ⟺ a < ½ (consistent: the restriction
θ < 1/3 is not a loss, it is the domain a < ½). (1+θ)/4 > θ ⟺ θ < 1/3 ✓.

### 1.4 MAJOR — Corollary 3 and row 7: the "not reopened" argument is invalid
- O164.201a / O184.001a (R164_201 l.126; R184_001 items 2, 11) asks for: a discrete system with error O(x^{θ′}),
  **θ′ ≤ 1/3**, and a zero with β > ½. It does not ask for θ′ = θ.
- R184_010 row 7 justifies "not reopened" with "(1+θ)/4 > θ". That answers a different question (whether the rounding reaches the
  exponent of the lattice, which is what Theorem L measures). If the **full** system inherited the exponent of the
  linear model, we would have θ′ = (1+θ)/4 ∈ (¼, ⅓) with zeros of ζ(w) at Re s = (1+θ)/2 > ½: that **would**
  answer O164.201a. §5 and the file's own note 7 admit this; the state table and Corollary 3 contradict it.
- Required correction: row 7 should read "O184.001a is **reduced** to O184.010a (the full system); it is not reopened
  **because the full system is OPEN**, not because (1+θ)/4 > θ". Corollary 3 should be limited to "consistent with Theorem L
  (θ + δ(θ) < (1+θ)/4, e.g. θ = 0.2: 0.218 < 0.3)".

### 1.5 Corollary 2 — PROVED only in narrow form; the "concrete reason" is ARGUED
- What is PROVED: there is no sign-blind inequality of the form rms_{[Y,2Y]} T₁ ≫ (Σ_{q≤Q}‖q^a‖²q^{−2a})^{1/2−o(1)} with
  Q ≥ Y^{1/2+δ} (or any bound ≫ Y^{(1/2+δ)(½−a)}), because the dither violates it. That is a legitimate counterexample.
- Not PROVED: "a sequence with bounded partial sums is nearly orthogonal to all [the sieves] simultaneously" and
  "no large sieve over prime moduli in (Y^{1/2+δ}, Y^{1−ε}) can hold". A large sieve **by range** (restricting
  the sum T₁ to q in that range, with q < Y^{1/2} removed) is not refuted by Theorem D, which controls
  the full sum; the dither over the restricted range requires redoing Abel summation (the lower boundary term S_{k₀} f(p_{k₀}) is
  O(Y^{−a/2}), harmless, so it is easy, but it is not written out). Label: the explanation is **ARGUED/heuristic**;
  the NO-GO statement should be phrased as "no sign-blind Bessel bound that includes the diagonal mass from q > Y^{1/2+δ}".
- The sentence "the gap is not technical" remains PROVED for the **method** of R164_201 §3.5, not for L* (which concerns the full
  system). The file says this in row 6; the header "refutes L*" should read "refutes the linear form of L*".

### 1.6 MAJOR (record) — "the order-≥2 chaos and levels k ≥ 2 converge ∀a > 0" is false
- R164_201 §1 (l.~38) and R184_001 §1.1 + table §1.3 row 1 ("k ≥ 2: O(x^{θ+ε}) PROVED") claim that everything beyond
  the linear term converges for every a > 0. With independent rounding:
  - order-2 chaos at level 1: Var = Σ_{pq≤X}(pq)^{−2a}Φ² ≍ X^{1−2a}(log log X)/log X, **the same order** as the linear term;
    the total over all orders is Σ_{m≤X}μ²(m)m^{−2a} ≍ X^{1−2a} (the "E_p = 2" of R163_803 Lemma 3 enters through the Euler
    product Π(1+p^{−2a}), i.e. through **all** orders, not only the linear one);
  - Witt level k (linear): Var ≍ Σ_{p≤X^{1/k}} p^{−2ka}, divergent if a < 1/(2k), i.e. θ < 1/(2k+1); it contributes
    x^θ·X^{1/(2k)−a} = x^{(1−θ)/(2k)} > x^θ for θ < 1/(2k+1) (k = 2: θ < 1/5).
- This does not change the exponent (1−θ)/2 of the random method nor Theorem L (lower bound), but it does change the sentence "the only
  piece that depends on θ is the linear chaos" (R184_001 item 1, R164_201 state item 1). R184_010 §5 depends on the
  composites **not** converging: that is the correct claim, and it contradicts the record without flagging it. An erratum should be required in
  R164_201 §1 and R184_001 §1.1/§1.3.

### 1.7 §5 and independent verdict: can the dither lower the 1/3 frontier?
**My verdict: no, in the full system; the heuristic of §5 is correct in the exponent, and the exponential structure
does not "automatically handle the composites": that is exactly the obstruction.**

(a) Check of §5 (ARGUED, I confirm it). For m = p₁⋯p_k, ε_{p_i}p_i^{−a} = ΔS_i is a first difference; Abel summation
in each variable only gains where Φ(X/m) is smooth in that variable, i.e. p_i ≳ (X/(m/p_i))^{1/2}. The region "rough in all variables"
for p₁<…<p_k is p_k²·p₁⋯p_{k−1} ≲ X; maximizing Σ log p_i there gives p_i ≍ X^{1/(k+1)}, mass X^{(k/(k+1))(1−2a)}. The
products ν_{i₁}⋯ν_{i_k} of distinct indices are orthogonal (the maximal index is unique and E[ν|𝓕]=0), and E[ν²|𝓕] =
{z}(1−{z}) is generically ≍ 1, so there is no hidden cancellation. k → ∞ slowly: X^{(1−2a)/2−o(1)}. Matches §5.

(b) Exponential reading (independent). ζ_𝒫(s) = ζ(w)·exp(L(w) + R(w)), L(w) = Σ_p ε_p p^{−a−w}. With the dither,
L(σ+it) = Σ_k ν_k p_k^{−a}(p_k^{−w} − p_{k+1}^{−w}) + (boundary): a martingale variable with variance
≍ Σ_p p^{−2a−2σ} min(1, (|t|log p/p)²) ≍ |t|^{1−2a−2σ} (for σ < ½−a). By Prop 2.2 of R184_001 (necessity), error
O(x^{θ′}) requires |ζ_𝒫| ≪ |t| in Re s > θ′, i.e. Re L(w) ≤ O(log|t|) in Re w > c := (θ′−θ)/(1−θ). For θ′ = (1+θ)/4,
c = (1−2a)/4 < ½ − a, and Re L has fluctuations of size |t|^{(1−2a)/4}: by martingale anticoncentration, a.s.
limsup Re L(c+it)/|t|^{(1−2a)/4−ε} = +∞ ⇒ |ζ_𝒫| super-polynomial ⇒ error ≠ O(x^{(1+θ)/4}). The threshold where Var L(σ+it)
stops growing is σ = ½ − a, which corresponds exactly to θ′ = θ + (1−θ)(½−a) = (1−θ)/2: **the L\* exponent**.
The two computations (a) and (b) agree: the linear model is small because it measures the linear coefficient of exp(L), not exp(L) itself.
- Label: (b) is **ARGUED**; gaps: (i) uniform anticoncentration of Re L over t (standard, writable),
  (ii) the levels k ≥ 2 (R(w)) are not absolutely convergent at Re w = c for a < 1/4 (§1.6) and must be bounded
  or diffused separately, (iii) ζ(w) for 0 < Re w < ½ is polynomial-size, harmless.
- For **deterministic** roundings, version (b) gives a new route to L*_comp: L(σ+it) is a Dirichlet polynomial with
  Σ|ε_p|²p^{−2a−2σ} = ∞ (Lemma W); Re L has zero mean in t and a large second moment (Montgomery–Vaughan); a
  fourth moment is missing to force (Re L)_+ large (Hölder/Paley–Zygmund). I propose recording this as **O184.093a (OPEN,
  ARGUED-tractable)**: "L*_comp via the growth of exp(L) + Prop 2.2". It is more promising than the large sieve.
- Consequence: the dither does **not** move the frontier below 1/3; O184.010a should be closed NEGATIVE for the random
  dither once (i)–(ii) are written out.
