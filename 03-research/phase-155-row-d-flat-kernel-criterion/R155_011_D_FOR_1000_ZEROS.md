## §2 Protocol

### 2.1 The class ~~(above the TK ceiling, as ordered)~~ (a fine lattice, as ordered) [amended per R155_012]

`w ≡ 1` on `[−2T,2T]`; for `u > 2T` (even extension)

```
w(u) = Σ_{i=1..4} y_i ψ_{s_i}(u−2T) + Σ_{j=2..J+1} x_j β((u−u_j)/h),
ψ_s(v) = (1+sv+½s²v²)e^{−sv}, s ∈ {3, 6, 12, 24},
β = cardinal cubic B-spline (C², support 4h), u_j = 2T + jh, h = 2T/M, M = 24.
```

`Σ_i y_i = 1` makes `w` C² across the window edge, so `ŵ = O(t⁻⁴)` (`lem:smooth`). `J` is chosen so
the shoulder reaches `≈ 6.5` units past the edge (`J = 142, 135, 126, 113` at
`T = ½log3, 0.58, 0.62, log2`), giving `U = sup supp w ≈ 7.7–8.0`. Bounds `|x_j| ≤ 3` (an `‖w‖_∞`
budget) and `Σ|y|+Σ|x| ≤ 60` (an `∫|w|` budget); **no monotonicity and no sign constraint** outside
the flat top, since `lem:Rrig` forbids `ŵ ≥ 0` and the optimum needs cancellation. The two
primitivity multipliers `(β₀−2, β₁)` enter as two free columns `ĝ₀, ĝ₁` (Thm `Zexh`(ii)), with
`|β| ≤ 50`; a run with them switched off is kept as the `λ^W` control.

~~Effective order is `M = 24` **by construction** (the lattice step is `2T/24`), against the
`h = 0.25 ⇒ M ≈ 4.4` of `R155_009` that sat inside Theorem N's impossibility region.~~

[amended per R155_012]: **struck — category error.** `prop:TK`/`thm:N` hypothesise a finite even measure supported on
the lattice `{±jd : j ≥ M}`, and the proof uses only that (`ν̂` is then `P`-periodic with modes
`|j| ≥ M`, so `∫ν̂φ = 0` against every `φ = |q(e^{idτ})|²`). Here `ν_w` has an absolutely continuous
part that is neither atomic, nor lattice-supported, nor periodic, and its atoms sit at `{log n}`

### 2.2 The oracle (FIND)

By Thm Z(ii) and the identity (even `w`, symmetric zeros)

```
f_w(τ) = Σ_ρ ŵ(τ−γ_ρ) = 4 ∫_0^U w(u) cos(τu) Z(u) du, Z(u) = Σ_{γ>0} cos(γu),
```

`Z` is computed **once** on a knot-aligned Gauss–Legendre panel set (`≈ 17 500` nodes, panels
`≤ 0.01`, 12 nodes each), after which every LP row and every fine evaluation is one matrix product.
Verified against the closed-form transforms of `revlib2.zero_side` to `1.8·10⁻¹¹`.

The LP maximises `c` subject to `f_w(τ_i) ≥ c` on a `δ = 0.005` grid (`0.02` when
`τ_max = 59.54`), then runs cutting planes against a localised fine scan until the LP value and the
fine minimum agree.

### 2.3 The certification of the interval minimum

`f_w` is band-limited of type `U = sup supp w`, so by the Taylor step inside the proof of
`lem:bern`,

```
min_ℝ f ≥ min_grid f − ‖f″‖_∞ δ²/8, ‖f″‖_∞ ≤ B₂ := 4∫_0^U u²|w(u)||Z(u)| du,
```

and `B₂` is computed on the same quadrature with a rigorous running-max envelope for `|Z|` (fine
`u`-grid `2·10⁻⁵`, slack `Σγ·du`). This is `lem:bern` with the *computed* second derivative in place
of the Bernstein bound `U²‖f‖_∞`, which is the sharper of the two forms its own proof supplies.
Measured `B₂ = 1.9·10² … 6.9·10³`, so at `δ_fine = 10⁻⁴` the slack is `2·10⁻⁷ … 9·10⁻⁶`.

**This certifies the minimum over the LP's τ-interval only, never over `ℝ`.** That distinction is
the whole content of §0.2.

[amended per R155_012]: **the pad as implemented was not an enclosure.** `check.py:41-45` refines only the 60
smallest coarse nodes and then subtracts `B₂(δ/50)²/8` as if the grid were dense over the whole
interval. Two consequences. (a) For the **negative** runs nothing changes: a grid minimum is already
an upper bound for the infimum, so those values are statements about the interval — and hence about
`ℝ`, since `inf_ℝ f ≤ inf_{[0,τ_max]} f` — with no pad at all. (b) For the one **positive** run the
enclosure had to be redone densely: `dense.py` evaluates the prime side at every node of a

`min ≥ +1.3743932·10⁻³ − 2.58·10⁻⁵ = +1.3486·10⁻³`. `check.py` now reports
`pad_localised_NOT_an_enclosure` beside a genuine coarse-grid enclosure.

### 2.4 The prime side (PROVE)

The *same* `f_w` from (7.2):
`m(τ) + ∫_{2T}^∞(1−w)K cos τu du − Σ_n v_n w(log n) cos(τ log n) + 2∫ w cosh(u/2) cos τu du`,
plus `(β₀−2)ĝ₀ + β₁ĝ₁`. The full prime-power sum runs to `e^{U_max} = e^{14} ≈ 1.2·10⁶`
(93 372 prime powers) — **no truncation at `e^U`**, which is the `1.6·10⁻⁴` artefact `R155_008`
recorded, since the `ψ` edges are not compactly supported. Two independent implementations:
`f_prime` (Gauss–Legendre order 800 on each B-spline support, as ordered) and `f_prime_fast` (one
shared panel set); they agree to `2.7·10⁻¹⁰`.

### 2.5 Deviation from the compute budget, declared

The rule is "each LP seconds, total ≤ 10 min wall, single process". The LPs obey it (12–64 s
each, 8 runs, one process at a time). The **prime-side checks do not**: each `check.py` run takes
`≈ 3.5 min` (the far scan to `τ = 300` at `δ = 0.005` against 93 372 prime powers), so the eight
checks plus the insight pass took `≈ 35 min` of single-process wall time. The machine stayed at one
core, `< 0.4 GB` resident, no swap. Recorded here rather than hidden; if the budget is to be held
strictly, the far scan can be dropped to `τ ≤ 100` at a cost of one line of evidence.
