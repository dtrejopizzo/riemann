> ```
> inf_{τ∈ℝ} [ σ_T(τ) + ν̂(τ) + β₀ĝ₀(τ) + β₁ĝ₁(τ) ] < 0.

> Consequently **no dual certificate of Paper 46 Def. 3.1 supported on a lattice of step `2T/M, M ≤ 8`, has

supported in `{|j| ≥ M}` (`u_j = jd ≥ 2T ⟺ j ≥ M`) and `φ` has modes in `{|j| ≤ M−1}`,
`∫_W ν̂φ = 0` (Lemma 4.1 of `R155_001`). Integrating `f ≥ c` against `φ ≥ 0` over `W` and dividing by

> ```

### 2.3 The enclosure, in full

Everything is computed in `mpmath`'s interval context at 25 digits; the only non-interval inputs are the
rational `τ₀` and the decimal `q`, which are *data of the certificate*, not approximations: **any** `(τ₀,q)`
gives a valid upper bound, so their provenance (a double-precision eigenvector) is irrelevant to the proof.

**(i) The archimedean multiplier.** By Paper 46 Thm 2.2(i),
`m(τ) = C₀ + Σ_{k≥0} t_k(τ)`, `t_k(τ) = τ²/(a_k(τ²+4a_k²))`, `a_k = k+¼`, and by the Gauss digamma theorem
`C₀ = ψ(¼) − \logπ = −γ − π/2 − 3\log2 − \logπ`, enclosed from `iv.euler`, `iv.pi`, `iv.log`. The first
`K = 100` terms are summed in interval arithmetic; the tail is bracketed by

> **Lemma 2.2.** With `A = K − ¼` and `t(a) = τ²/(τ²a + 4a³)`,
> `Σ_{k≥K} t(a_k) ∈ [ Λ − E, Λ ]`, `Λ = ½\log(1 + τ²/(4A²))`, `E = \frac1{24}\,τ²(τ²+12A²)/(τ²A+4A³)²`.
>
> *Proof.* `a_k = k+¼` are the midpoints of the unit cells `[a_k−½, a_k+½]`, whose union is `[A,∞)`.
> `t > 0`, `t' < 0` and `t'' > 0` on `(0,∞)`: writing `u = τ²a+4a³`, `t = τ²/u`,
> `t'' = τ²(2u'² − u''u)/u³` and `2u'²−u''u = 2τ⁴+24τ²a²+192a⁴ > 0`. For a convex function the midpoint
> rule under-estimates, so `Σ_{k≥K}t(a_k) ≤ ∫_A^∞ t = Λ` (the primitive of `t` is
> `\log(2a/\sqrt{τ²+4a²})`), and the deficit is at most `\frac1{24}∫_A^∞|t''| = \frac1{24}|t'(A)| = E`. ∎

At `K = 100` and `|τ| ≤ 28` this costs `E ≤ 2.4·10⁻⁷`, and it is carried inside the interval, not estimated
afterwards.

**(ii) The multipliers.** `ĝ₀(τ) = I(½,τ)+I(−½,τ)` and `ĝ₁(τ) = ∂_sI(½,τ) − ∂_sI(−½,τ)` with
`I(s,τ) = ∫_0^{2T}e^{su}\cos(τu)du = [e^{2Ts}(s\cos2Tτ + τ\sin2Tτ) − s]/(s²+τ²)`; both are evaluated as
closed-form interval expressions (no quadrature, no cancellation: `s²+τ² ≥ ¼`).

**(iii) Quadrature.** Composite Simpson with `n` subintervals on one period, with the classical remainder
`|E_n| ≤ P h⁴ C₄/180`, `h = P/n`, `C₄ ≥ \sup|(Xφ)^{(4)}|`, `X ∈ {σ_T, ĝ₀, ĝ₁}`, using
```
 |m^{(j)}(τ)| ≤ 2^{-j} j!\,ζ(j+1,¼) (ψ^{(j)}(z) = (−1)^{j+1}j!Σ(z+n)^{−j−1}, |z+n| ≥ Re z+n)
 |(v₂\cos(τ\log2))^{(j)}| ≤ v₂(\log2)^j
 |ĝ₀^{(j)}| ≤ 2\cosh T (2T)^{j+1}/(j+1), |ĝ₁^{(j)}| ≤ 2\sinh T (2T)^{j+2}/(j+2)
 |φ^{(j)}| ≤ (d(M−1))^j Σ_l|γ_l| ≤ (d(M−1))^j (Σ_k|q_k|)² (γ_l = Σ_k q_k\bar q_{k−l})
```
and `C₄(X) = Σ_{j≤4}\binom4j \sup|X^{(4−j)}|\sup|φ^{(j)}|`. At `M = 8`: `C₄(σ_T) = 1.834·10⁴`,
`C₄(ĝ₀) = 122.59`, `C₄(ĝ₁) = 47.57`, and with `n = 4096` (for `σ_T`) and `n = 12288` (for `ĝ₀,ĝ₁`) the
remainders are `7.26·10⁻⁵`, `5.99·10⁻⁹`, `2.32·10⁻⁹` — the asymmetry is deliberate: `a` needs only
`10⁻⁴`, while `b` is multiplied by `B = 5·10⁴` and needs `10⁻⁹`.

**(iv) Denominator.** `∫_Wφ = P‖q‖²` **exactly** (orthogonality of `e^{ijdτ}` over a period), so no
quadrature error enters the denominator.

Runtime `42.5 s` for `M = 8` (one process); `35–61 s` for `M = 3,5,6,7` (the longer ones ran concurrently with §3).

## §4. Task (c) — an a priori bound on `β`

### 4.1 Statement

> **Theorem B (a priori multiplier bound). `PROVED`, explicit constants.**
> Fix `T` and the weights `v`. Suppose there exist `r₀ > 0`, `V⋆ < ∞` and finitely many unit vectors
> `F_1,…,F_N ∈ H^1_0(I_T)` such that, with `w_i := (Q_0(F_i), Q_1(F_i))` and `V_i := \mathfrak a_T(F_i)`,
> ```
> { |w| ≤ r₀ } ⊆ conv{w_1,…,w_N} and V_i ≤ V⋆ for all i.
> ```
> Then **every** dual certificate `(ν,β)` of value `c` satisfies
> ```
> ‖β‖_2 ≤ (V⋆ − c)/r₀, in particular ‖β‖_∞ ≤ (V⋆ − c)/r₀.
> ```

*Proof.* For `F ∈ H^1_0(I_T)` with `‖F‖ = 1`, `μ_F := |\hat F|²dτ/2π` is an even probability measure with
`\check μ_F = c_F` supported in `[−2T,2T]` (`c_F(±2T) = 0` by continuity), so for any certificate measure
`ν` (supported in `{|u| ≥ 2T}`) one has `∫\hatν\,dμ_F = ∫\check μ_F\,dν = 0` (Paper 46 Prop. 3.2's proof),
while `∫\hat g_j dμ_F = ∫ g_j c_F = Q_j(F)` (Lemma 6.1) and `∫σ_T dμ_F = \mathfrak a_T(F)`. Integrating
`f ≥ c` against `μ_F`:
```
 \mathfrak a_T(F) + β·w(F) ≥ c, i.e. β·w(F) ≥ c − V(F).
```
The relaxed feasible set (even probability measures with `\check μ = 0` off the window) is convex and both
`μ ↦ ∫σ_Td μ` and `μ ↦ \mathfrak m(μ)` are affine, so for `w = Σλ_iw_i` in the convex hull the measure
`μ = Σλ_iμ_{F_i}` is admissible with moment `w` and value `≤ V⋆`; hence `β·w ≥ c − V⋆` for every
`|w| ≤ r₀`. Applying this to `w` and `−w` gives `|β·w| ≤ V⋆ − c` for `|w| ≤ r₀`, and taking the supremum
over the disc, `r₀‖β‖_2 ≤ V⋆ − c`. ∎

### 4.2 The witnesses, and the value bound

Take `ψ_k(t) = (T²−t²)t^k`, `k = 0,1,2,3`, a basis of a 4-dimensional subspace of `H^1_0(I_T)`; all the
quantities below are elementary integrals of `polynomial × e^{±t/2}`. For a unit `F` in that span,
`Q_0(F) = AB` and `Q_1(F) = A'B − AB'` with `A = ∫Fe^{t/2}`, `B = ∫Fe^{−t/2}`, `A' = ∫tFe^{t/2}`,
`B' = ∫tFe^{−t/2}` (Paper 46 Lemma 6.1). The value is bounded by

> **Lemma 4.2.** For unit `F ∈ H^1_0(I_T)` with `L := ‖F'‖`,
> `\mathfrak a_T(F) ≤ C₀ + A_T + \frac{L²}2∫_0^{u_0}u²K(u)du + 2∫_{u_0}^∞K(u)du`, for every `u_0 > 0`, and
> the right side is minimised at `u_0 = 2/L`. Here `∫_{u_0}^∞K = \log\coth\frac{u_0}2 + π − 2\arctan e^{u_0}`
> (Paper 46 Thm 2.2(iii)).
>
> *Proof.* `\mathfrak a_T(F) = C₀ + \mathrm{Lev}(c_F) − Σv_nc_F(\log n) ≤ C₀ + A_T + ∫_0^∞(1−\mathrm{Re}\,c_F)K`

> `1 − \mathrm{Re}\,c_F(u) = \frac1{2π}∫(1−\cos τu)|\hat F|² ≤ \min\{2, \frac{u²}2‖F'‖²\}`; split at `u_0`.
> The derivative in `u_0` is `K(u_0)[\frac{L²}2u_0² − 2]`, zero exactly at `u_0 = 2/L`. ∎

For each of `48` directions `θ` the witness is the top generalised eigenvector of

## §6. Task (e) — the ceiling converges to `λ^P`, with an explicit error term

### 6.1 The periodisation is a test kernel

> **Lemma R1 (`PROVED`).** Let `μ` be feasible for (P) (even probability, `\checkμ(u) = 0` for `|u| ≥ 2T`),
> `M ∈ ℕ`, `d = 2T/M`, `P = 2π/d = πM/T`. Define the periodisation `ρ` on `ℝ/Pℤ` by
> `ρ(E) = Σ_{k∈ℤ}μ(E + kP)`. Then `ρ` is a probability measure whose Fourier coefficients are
> `\hatρ(j) = \checkμ(jd)`, hence `\hatρ(j) = 0` for `|j| ≥ M`. Consequently `ρ` is absolutely continuous
> with a **non-negative trigonometric polynomial density of degree `≤ M−1` in `θ = dτ`**, and by Fejér–Riesz
> `dρ = P^{-1}|q(e^{idτ})|²dτ` for some `q` of degree `≤ M−1`: **`ρ` is a test kernel of order `M`.**
>
> *Proof.* `ρ` is a finite positive measure of mass `μ(ℝ) = 1`; its `j`-th Fourier coefficient is
> `∫_{[τ_0,τ_0+P)}e^{−ijdτ}dρ = ∫_ℝ e^{−ijdτ}dμ(τ) = \checkμ(jd)` because `e^{−ijd(τ+kP)} = e^{−ijdτ}`
> (`dP = 2π`) and `μ` is even. Since `|jd| ≥ 2T ⟺ |j| ≥ M`, only finitely many coefficients are non-zero,
> so `ρ` equals a trigonometric polynomial (as a distribution, hence as a measure); it is `≥ 0` because `ρ`
> is; Fejér–Riesz factorises it. ∎

This is the exact converse of the dual-side observation "a lattice `ν` makes `\hatν` periodic"
(`phase-154/R154_025:284`): there the lattice makes the *dual* variable periodic; here the same lattice makes
the *primal* variable's periodisation band-limited. The two are the same Poisson summation read in opposite
directions, and the gap `|j| ≥ M` matches exactly.

### 6.2 The rate

> **Theorem R (`PROVED`).** Let `μ` be feasible for (P), `W = [−P/2, P/2]`, `π_W(τ) = τ − kP ∈ W` the
> folding map. Then for every `β ∈ ℝ²`,
> ```
> Ceil(M,T;β) := \inf_{τ_0,φ}Q(τ_0,φ,β) ≤ ∫σ_T\,dμ + Δ(M,β)\,μ(\{|τ| > P/2\}),
> Δ(M,β) := \big[m(P/2) − C₀\big] + 2A_T + 2|β_0|\hat g_0(0) + 2|β_1|\hat g_1(0).
> ```
> Consequently, for every fixed `β`, `\limsup_{M→∞}Ceil(M,T;β) ≤ λ^P`.
>
> *Proof.* Take `τ_0 = −P/2` and `φ` the test kernel of Lemma R1 (`∫_Wφ` normalised). Since the infimum
> over test kernels is at most the value at this one,
> `Ceil(M,T;β) ≤ ∫_W S_β\,dρ = ∫_ℝ S_β(π_W τ)\,dμ(τ)` with `S_β = σ_T + β·\hat g`. Now
> `∫S_β dμ = ∫σ_Tdμ` because `μ` has zero moments, and `π_Wτ = τ` on `|τ| ≤ P/2`, so
> ```
> ∫_ℝ S_β∘π_W\,dμ − ∫σ_T dμ = ∫_{|τ|>P/2}\big(S_β∘π_W − S_β\big)d μ
> ≤ \big(\sup_W S_β − \inf_ℝ S_β\big)\,μ(|τ|>P/2).
> ```
> Finally `\sup_WS_β ≤ m(P/2) + A_T + |β_0|\hat g_0(0)+|β_1|\hat g_1(0)` (`m` increasing, `|\hat g_j| ≤ \hat g_j(0)`)
> and `\inf_ℝ S_β ≥ C₀ − A_T − |β_0|\hat g_0(0) − |β_1|\hat g_1(0)`, giving `Δ`. For the limit: choose `μ`
> with `∫σ_Tdμ ≤ λ^P + δ`. Then `∫m\,dμ < ∞`, so by dominated convergence
> `(m(R)−C₀)\,μ(|τ|>R) ≤ ∫_{|τ|>R}(m−C₀)dμ → 0`; since `Δ(M,β) = (m(P/2)−C₀) + O_β(1)` and
> `μ(|τ|>P/2) → 0`, the product tends to `0`, so `\limsup_M Ceil(M,T;β) ≤ λ^P + δ` for every `δ > 0`. ∎

> **Corollary R2 (`PROVED`).** Fix `B > 0` and put `Ceil_B(M,T) := \sup_{‖β‖_∞ ≤ B}\inf_{τ_0,φ}Q`. Then
> `Δ` is bounded uniformly on the box, so `\limsup_M Ceil_B(M,T) ≤ λ^P`. If moreover `λ^P > 0`, then by
> Theorem B every certificate of value `c ≥ 0` has `‖β‖_∞ ≤ V⋆/r₀`, so with `B := V⋆/r₀` one has
> `Ceil_B(M,T) ≥ c(M)`, and `c(M) ↑ λ^P` along the nested lattices `2T/2^kM_0` with growing range
> (`thm:D1(iii)`; the union of those lattices is dense in `[2T,∞)`). Hence
> ```
> \lim_{M→∞} Ceil_B(M,T) = λ^P.
> ```

> **Corollary R3 (`PROVED`; this is the `M→∞` half of MAJOR-4).** The test-kernel subfamily
> `\{|q|²1_{window}\}` is **not lossy in the limit**: its optimal value converges to the same `λ^P` as the
