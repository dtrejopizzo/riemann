## §1 The truncated universe

### 1.1 Definitions

Fix `N ≥ 1`. Let `0 < γ_1 < γ_2 < … < γ_N` be the first `N` ordinates of the non-trivial zeros of
`ζ` (for `N = 1000`, `γ_1000 = 1419.422480946`; nothing below uses any property of these numbers
beyond `0 < γ_1 < … < γ_N`, so every statement holds for an arbitrary finite multiset of positive
reals with positive integer multiplicities). Put

```
Z_N = {±γ_j : j ≤ N} (a symmetric multiset, |Z_N| = 2N)
μ_N = Σ_{j≤N} (δ_{γ_j} + δ_{−γ_j}) (a positive finite measure on ℝ)
```

For even `h ∈ L¹(ℝ)` write `ĥ(t) = ∫_ℝ h(u)e^{itu}du = ∫ h(u)\cos(tu)du`. The **truncated Weil
functional** is

```
W_N(h) := Σ_{γ ∈ Z_N} ĥ(γ) = Σ_{j≤N} 2 ĥ(γ_j) = ∫_ℝ ĥ dμ_N.
```

The **prime side of the toy universe** is the inverse transform of `μ_N`, the tempered distribution
(here in fact a bounded real-analytic function)

```
g_N(u) := Σ_{j≤N} 2\cos(γ_j u) = μ̂_N(u), g_N(0) = 2N, |g_N| ≤ 2N.
```

`g_N` is an almost periodic function with `2N` frequencies; it plays the role that
`2\cosh(u/2) − Σ_n v_nδ_{\log n} − ½K(|u|)` plays for ζ through the explicit formula.

The **truncated structure function** is the even entire function of order 1, genus 0,

```
Ξ_N(t) = Π_{j≤N} (1 − t²/γ_j²), Ξ_N(0)=1, {zeros of Ξ_N} = Z_N,
```

and the associated **Kreĭn/de Branges structure function** is `E_N(z) = Π_{j≤N}(1 − z/γ_j)(1 + z/γ_j)`
composed with the usual Hermite–Biehler normalisation; the de Branges space `ℋ(E_N)` attached to a
finite symmetric real zero set is finite dimensional, of dimension `2N`. **That finite
dimensionality is the whole content of §2** (see Remark 2.5).

## §2 The flat-top question: row D is intrinsically infinite

The content of row D for ζ is not Theorem 1.3 but Paper 47 Cor. `cor:RH`: RH ⟺ for every window `T`
there is a flat-top weight `w` whose smoothing `f_w(τ) = Σ_ρ ŵ(τ − γ_ρ)` of the **whole** zero
measure is `≥ 0` on ℝ. The natural question — the one the finite universe raises — is
whether the truncated smoothing can already be non-negative.

**Setting.** Fix `T > 0`. Following Paper 47 Def. `def:W`, let

```
𝒲_T = { w : ℝ → ℝ even, continuous, w ≡ 1 on [−2T,2T], |w(u)| ≤ C e^{−(½+δ)|u|} for some C,δ>0 }
```

and for a finite symmetric multiset `Z` of non-zero reals put

```
f_{w,Z}(τ) := Σ_{γ∈Z} ŵ(τ − γ) (= Σ_{j≤N}[ŵ(τ−γ_j)+ŵ(τ+γ_j)] when Z = Z_N).
```

`f_{w,Z} = ŵ ⋆ μ_Z` is continuous and `∫_ℝ f_{w,Z}(τ)dτ = |Z| · 2π w(0) = 2π|Z|`.

### 2.1 The dictionary

**Lemma 2.1 (`PROVED`).** Let `w ∈ 𝒲_T` and `Z` a finite symmetric multiset of reals, and set
`φ := w · g_Z` with `g_Z(u) = Σ_{γ∈Z}e^{iγu} = Σ_{γ∈Z}\cos(γu)` (real, even, bounded by `|Z|`).
Then `φ` is continuous, `φ ∈ L¹(ℝ)`, `φ̂ = f_{w,Z}`, `φ(0) = |Z|`, `φ(u) = g_Z(u)` on `[−2T,2T]`,
and `φ(u) → 0` as `|u| → ∞`. Moreover

```
f_{w,Z} ≥ 0 on ℝ ⟺ φ is positive definite.
```

*Proof.* Continuity, the `L¹` bound (`|φ| ≤ |Z|·|w|` with `w` exponentially decaying) and the values
at `0` and on the window are immediate from `w ≡ 1` there. `φ̂ = ŵ ⋆ μ_Z = f_{w,Z}` by the
convolution theorem (`μ_Z` finite, `w ∈ L¹`). ("⇐") If `φ` is positive definite then its spectral
measure is non-negative, and `φ ∈ L¹` continuous forces that measure to be `φ̂ dτ/2π`, so `φ̂ ≥ 0`.
("⇒") If `φ̂ = f_{w,Z} ≥ 0`, then `∫φ̂ = 2π φ(0) < ∞` by the Gauss–Weierstrass summability argument
used in Paper 47 `lem:Rrig` (Fejér/Gauss means of `φ` converge uniformly on compacta and monotone
convergence applies to the non-negative `φ̂`), so `φ̂ dτ/2π` is a finite positive measure with
Fourier transform `φ`, and `φ` is positive definite by Bochner. ∎

So the question "is there a flat-top certificate for the finite universe?" is exactly:

> **is there a continuous positive-definite function on ℝ which agrees with `g_N` on `[−2T,2T]`,
> tends to `0` at infinity, and is of the special form `w·g_N` with `w ∈ 𝒲_T`?**

Two remarks on what does *not* settle this. (a) **Kreĭn's extension theorem does not forbid it**:
a continuous positive-definite function on an interval always extends to ℝ, and in the
indeterminate case there are many extensions, including absolutely continuous ones; the interval
datum alone is therefore not an obstruction. (b) **The pointwise inequality
`|φ(u+a) − φ(u)|² ≤ 2φ(0)(φ(0) − \mathrm{Re}\,φ(a))`, which proves `lem:Rrig`, does not settle it
either** for `N ≥ 2`: it bites only when some `|φ(a)| = φ(0)` with `|a| ≤ 2T`, i.e. when all
`γ_j a` are simultaneously `≡ 0` (or all `≡ π`) mod `2π`. For `N = 1` this *does* settle it — take
`a = π/γ_1`, which lies in the window as soon as `2T ≥ π/γ_1`; then `φ(a) = −φ(0)`, equality in
`|φ(a)| ≤ φ(0)` forces `φ(u+a) = −φ(u)` for all `u`, hence `|φ(na)| = φ(0) = 2` for every `n`,
contradicting `φ → 0`. For `N ≥ 2` the simultaneous-alignment condition fails for every `a`, and
this route stops. The correct instrument is not a single pair of points but a whole lattice.

### 2.2 The theorem

**Theorem 2.2 (no finite zero universe admits a flat-top certificate) — `PROVED`.**
Let `T > 0`, let `Z` be a finite symmetric multiset of non-zero reals with `|Z| = d ≥ 2`
(multiplicities allowed), and let `w : ℝ → ℝ` be even, continuous, integrable, with `w ≡ 1` on
`[−2T, 2T]` and `w(u) → 0` as `|u| → ∞`. Then

```
f_{w,Z}(τ) = Σ_{γ∈Z} ŵ(τ − γ)
```

takes **negative values on ℝ**. In particular for every `N ≥ 1`, every `T > 0` and every
`w ∈ 𝒲_T`, the truncated smoothing `f_{w,N} = Σ_{j≤N}[ŵ(·−γ_j)+ŵ(·+γ_j)]` of the first `N` zeros
is **not** non-negative. No hypothesis of compact support, of regularity beyond continuity, of
genericity in `T`, or on the exponential sums `Σ_γ e^{isγ}` is used.

*Proof.* Suppose `f_{w,Z} ≥ 0`. By Lemma 2.1, `φ = w g_Z` is a continuous positive-definite
function with `φ(0) = d`, `φ ≡ g_Z` on `[−2T,2T]` and `φ(u) → 0`.

**Step 1 (choice of the lattice) — *[amended per R155_015]*.** The multiset `Z` may have
repetitions, so one must work with its **distinct** values. Let `w_1,…,w_r` be the distinct elements
of `Z`, with multiplicities `m_1,…,m_r ≥ 1`, `Σ_j m_j = d` and `r ≤ d`. Put `z_j = e^{i w_j a}` for
a step `a > 0` to be chosen, so that

```
g_Z(ka) = Σ_{j≤r} m_j z_j^{\,k} for all k ∈ ℤ.
```

Because `Z` is symmetric **with multiplicity**, the list `(z_j, m_j)` is closed under conjugation:
`z̄_j = z_{j'}` with `m_{j'} = m_j`. Each of the finitely many conditions `z_j = z_{j'}` (`j ≠ j'`)
excludes a discrete set of `a`; choose

```
a ∈ (0, 2T/d] with the r numbers z_1,…,z_r pairwise distinct
```

(possible: all but countably many `a` in that interval qualify). Since `r ≤ d` we have
`r·a ≤ d·a ≤ 2T`, so `g_Z(ka) = φ(ka)` for `|k| ≤ r`.

**Step 2 (the kernel of the window Toeplitz matrix) — *[amended per R155_015]*.** Put
`c_k := φ(ka) ∈ ℝ` (real because `φ` is real and even). For `|k| ≤ r` we have
`c_k = g_Z(ka) = Σ_{j≤r} m_j z_j^{\,k}`. Let `A := [c_{i−j}]_{0 ≤ i,j ≤ r}`, an `(r+1)×(r+1)`
Hermitian matrix, which by the previous sentence is the weighted Gram matrix `A = V^*DV` of the `r`
unimodular nodes, `V_{j,i} = z_j^{\,i}`, `D = \mathrm{diag}(m_1,…,m_r)`, `m_j > 0`. Since the `z_j`
are distinct, the `r × (r+1)` Vandermonde-type matrix `V` has rank `r`, and `D` is positive
definite, so `\mathrm{rank}\,A = r` and

```
\ker A = { v ∈ ℂ^{r+1} : Σ_{i=0}^{r} v_i z_j^{\,i} = 0 for j = 1,…,r } = ℂ·v,
v = coefficient vector of P(z) = Π_{j=1}^{r}(z − z_j), deg P = r.
```

`P` has conjugation-symmetric roots (Step 1), so `v ∈ ℝ^{r+1}`, `v_r = 1`, and
`|v_0| = Π_j|z_j| = 1 ≠ 0`.

**Step 3 (the recursion forced by positive definiteness) — *[amended per R155_015]*.**
Fix `m > r`. Positive definiteness of `φ` gives that the Gram matrix of `φ` at the points
`{0, a, 2a, …, ra, ma}` is positive semidefinite; it has the block form
`M = [[A, b],[b^*, c_0]]` with `b_i = φ(ia − ma) = c_{m−i}`. For `v ∈ \ker A` and `x = (v, t)`,
`x^*Mx = 2\,\mathrm{Re}(\bar t\, b^*v) + |t|^2 c_0 ≥ 0` for all `t ∈ ℂ`; choosing the phase of `t`
adversely and letting `|t| → 0` gives `b^*v = 0`, i.e.

```
Σ_{i=0}^{r} v_i\, c_{m−i} = 0. (★)
```

The same relation holds for the sequence `k ↦ g_Z(ka)`: indeed
`Σ_i v_i z^{m−i} = z^{m−r}·z^{r}P(1/z)`, which vanishes at `z = z_j` because `1/z_j = \bar z_j` is
again a root of `P`; multiplying by `m_j` and summing over `j` gives `Σ_i v_i g_Z((m−i)a) = 0`.

**Step 4 (induction) — *[amended per R155_015]*.** By Step 2, `c_k = g_Z(ka)` for
`0 ≤ k ≤ r`. Assume `c_k = g_Z(ka)` for all `0 ≤ k ≤ m−1` (some `m > r`). In (★) all terms with `i ≥ 1` involve `c_{m−i}` with `m−i ≤ m−1`,
hence equal `g_Z((m−i)a)`; subtracting the corresponding relation for `g_Z` and using `v_0 ≠ 0`
gives `c_m = g_Z(ma)`. Therefore

```
φ(ma) = g_Z(ma) for every integer m ≥ 0.
```

**Step 5 (Cesàro mean) — *[amended per R155_015]*.** The `z_j` are **distinct** points
of the unit circle, so `z_j\bar z_{j'} ≠ 1` for `j ≠ j'` and the Cesàro averages of
`(z_j\bar z_{j'})^{m}` tend to `0` (a geometric sum; no equidistribution is needed, so the name
"Weyl" was decoration). Hence

```
lim_{M→∞} (1/M) Σ_{m=1}^{M} |g_Z(ma)|² = Σ_{j≤r} m_j² ≥ r ≥ 1 > 0,
```

and therefore `\limsup_m |g_Z(ma)| ≥ \sqrt{Σ_j m_j²} ≥ \sqrt r > 0`. But `φ(ma) = w(ma)g_Z(ma)` and
`|φ(ma)| ≤ d·|w(ma)| → 0` by hypothesis. Contradiction. Hence `f_{w,Z} ≥ 0` is impossible; being
continuous with `∫ f_{w,Z} = 2πd > 0`, `f_{w,Z}` therefore takes negative values. ∎

**Corollary 2.3 (`PROVED`) — *[amended per R155_015]*.** The **conclusion** of Paper 47
`cor:nontermwise`(ii) *in the weak form* "`f_{w,Z}` is not non-negative" holds with its three
hypotheses (compact support, `J ≠ 0`, `Σ_{γ∈Z}\cos(Uγ) ≠ 0`) deleted; the case Paper 47 explicitly
leaves open ("for weights that are not compactly supported, or when the amplitude vanishes …") is
closed negatively *in that form*. **This is not an unconditional strengthening of the refined
statement.** Theorem 2.2 is non-constructive: Step 5 contradicts positive definiteness along a
lattice in the `u` variable and says nothing about the location of the negative values in `τ`. The
refinement "`f_{w,Z}(τ) < 0` for **arbitrarily large `τ`**" is *not* a consequence of Theorem 2.2;
it still requires Prop. 2.7 and hence Prop. 2.7's hypotheses (edge regularity, non-vanishing
amplitude `J_s A_Z(s)`). The two are complementary: Theorem 2.2 gives the sign with no fine print,
Prop. 2.7 gives the location under fine print. Likewise `R155_008 §7bis` consequence (b), restricted by `R155_010` to compactly
supported `w`, holds in full and now has a proof.

**Corollary 2.4 (row D is intrinsically infinite) — `PROVED`.** For every window `T`, every
flat-top certificate `f_w ≥ c ≥ 0` of Paper 47 Cor. `cor:RH`/`cor:zeros` is a statement about the
**complete, infinite** zero multiset: no truncation of the sum `Σ_ρ ŵ(τ−γ_ρ)` to finitely many
zeros is non-negative, at any `T`, for any admissible `w`, and for any truncation height. The
positivity, when it holds, is produced by the infinitely many far zeros — quantitatively, by the
fact that the zero counting density `∼ (2π)^{−1}\log(t/2π)` gives `μ_ζ` infinite mass, matching the
`m(τ) = \log(τ/2π) + O(τ^{−1})` growth of Paper 47's symbol `σ_T`.

*[amended per R155_015 — quantitative form, the implication the original draft missed.]*
Theorem 2.2 combined with Paper 47 `lem:smooth`(iii) **locates** the defect of every truncation.
Suppose a genuine certificate `f_w ≥ c > 0` exists for ζ at some window `T`, with

Theorem 2.2 `f_{w,Γ}` is negative **somewhere**. Hence

```
every negative value of the truncation f_{w,Γ} lies at |τ| ≳ Γ/2,
```

i.e. the defect is pushed out to the edge of the controlled range and nowhere else. With the
cubic-B-spline shoulder of §3(iv) (`‖x‖_1`, `M` lattice points, `k = 2`) the threshold at which

sign changes of truncated smoothings occur only just outside the evaluated domain.

### 2.3 The asymptotic route (kept: it says *where* the sign change is) — `PROVED`

Theorem 2.2 is non-constructive about the location of the negative values. The integration-by-parts
route of Paper 47 `cor:nontermwise`(ii) locates them, and generalises as follows.

**Proposition 2.7** *[amended per R155_015: phase corrected, boundary hypothesis added]*.
Let `w ∈ 𝒲_T` be such that, for some integer `k ≥ 0`, `w^{(k)}` is continuous on ℝ, **`w^{(j)}(u) → 0`
as `|u| → ∞` for every `0 ≤ j ≤ k`** (automatic for compactly supported `w`, and a genuine
hypothesis otherwise — it is what makes the `k+2` integrations by parts legitimate for the
non-compactly-supported weights to which this proposition is applied), and `dw^{(k+1)}` is a finite
signed measure whose singular part is a finite sum of atoms
`Σ_{s ∈ S} J_s(δ_s + δ_{−s})`, `S ⊂ (0,∞)` finite, `J_s ≠ 0` (the generic case: `S ∋ 2T` is the
window edge, `S ∋ U` the support edge). Then, as `τ → +∞`,

```
ŵ(t) = |t|^{−k−2} Σ_{s∈S} 2J_s \cos(st + φ_k) + o(|t|^{−k−2}),
φ_k = \arg\big((−1)^{k} i^{−(k+2)}\big) [amended per R155_015],
f_{w,Z}(τ) = τ^{−k−2}\, Ψ(τ) + o(τ^{−k−2}),
Ψ(τ) = 2 Σ_{s∈S} J_s\, A_Z(s)\, \cos(sτ + φ_k), A_Z(s) := Σ_{γ∈Z}\cos(sγ).
```

`Ψ` is a real trigonometric polynomial with zero mean; it is not identically zero iff
`J_s A_Z(s) ≠ 0` for some `s ∈ S`, and in that case `\inf Ψ < 0`, so `f_{w,Z}(τ) < 0` for
arbitrarily large `τ`.

*Proof.* Integrate by parts `k+2` times as in Paper 47 `lem:smooth`(i), the boundary terms vanishing
at each stage by the hypothesis `w^{(j)} → 0` (`j ≤ k`) together with `w^{(k+1)} ∈ BV`; this gives
`ŵ(t) = (−1)^{k+2}(it)^{−(k+2)}∫ e^{itu}dw^{(k+1)}(u) = (−1)^{k}(it)^{−(k+2)}∫ e^{itu}dw^{(k+1)}(u)`.
The factor `(−1)^{k}`, dropped in the original draft (and inherited from Paper 47
`cor:nontermwise`(ii)), shifts `φ_k` by `π` for **odd** `k`; it is harmless to the sign conclusion
but wrong as a formula, and is corrected in the display above. the atomic part contributes the displayed cosines
(pairing `±s` by evenness) and the absolutely continuous part contributes `o(1)` by
Riemann–Lebesgue. Sum over the finitely many `γ ∈ Z`, using
`Σ_γ \cos(s(τ−γ)+φ_k) = \mathrm{Re}[e^{i(sτ+φ_k)}Σ_γ e^{−isγ}]` and `Σ_γ e^{−isγ} = A_Z(s)` real
by symmetry of `Z`. A non-zero real trigonometric polynomial with zero mean takes negative values
on a relatively dense set, so `\limsup_{τ→∞} −τ^{k+2}f_{w,Z}(τ) > 0`. ∎

**Corollary 2.8 (the exceptional set, for the record).** If `S = {2T}` (a weight whose only
finite-regularity point is the window edge), the hypothesis of Prop. 2.7 is `A_Z(2T) =
Σ_{j≤N}2\cos(2Tγ_j) ≠ 0`. The map `T ↦ A_{Z_N}(2T)` is a finite cosine sum, hence real-analytic
and not identically zero (it equals `2N` at `T = 0`); its zero set is therefore **discrete** in ℝ.
So for every `N` and every `T` outside a discrete set, `f_{w,N}` changes sign at large `τ`, with
the rate `τ^{−k−2}` and the oscillation frequency `2T`. Theorem 2.2 makes the exceptional set
empty; Prop. 2.7 adds the *location and size* of the violation, which is what a numerical run
actually sees (`R155_011 §0.2`: `f_w(17.436) = −7.321` just outside the trained domain).

## §3 What this dictates for the shape of `D` for ζ

Necessary facts only; each with a proof or a precise reference.

**(i) Never termwise.** `ŵ ≥ 0` is impossible for every `w ∈ 𝒲_T` (Paper 47 `lem:Rrig` =
`R155_008` Lemma R, `PROVED`). Hence `f_w ≥ 0` is always a statement of cancellation across the
zeros, and — by Theorem 2.2 — a statement about infinitely many of them. The quantitative shadow is
measured: individual terms of size `≈ 1` against a value of `10⁻³`, three orders of cancellation
(`R155_011 §0.5`, `R155_012 §8`, `DIAGNOSTIC`).

**(ii) The tail of `f_w` is the prime comb at the window edge.** *[amended per R155_015:
the quantity `2T` plays two distinct roles, conflated in the original draft; they are separated
here.]* **Role 1 — tail frequency (in `τ`).** By Prop. 2.7 the leading tail of `f_w` oscillates at
the frequencies `s ∈ S` of the singular part of `dw^{(k+1)}`; for a weight whose only
finite-regularity point is the window edge, `S = {2T}`, so the tail frequency is `2T` with
amplitude `J_{2T}A_Z(2T)`, i.e. the pair (edge regularity of `w`, exponential sum
`Σ_ρ e^{−2iTγ_ρ}`). **Role 2 — window half-width (in `u`).** Independently, the window is
`|u| ≤ 2T` and the prime comb `Σ_n v_nδ_{\log n}` is sampled at `u = \log n`, so the window edge
meets the comb exactly when `\log n = 2T`, i.e. `T = ½\log n`. The two occurrences of `2T` are a
frequency and a length; the coincidence discussed below is entirely Role 2. The
statement dual to it, which is the one with arithmetic content, is exact and elementary from Paper
47 (7.2) (`eq:fw`): the prime side of `f_w` is

```
f_w(τ) = C_0 + ∫_0^∞ (1 − w(u)\cos τu)K(u)du − Σ_{n≥2} v_n w(\log n)\cos(τ\log n)
 + 2∫_ℝ w(u)\cosh(u/2)\cos(τu)du, v_n = 2Λ(n)/√n,
```

so `w` is evaluated on the prime comb `Σ_n v_n δ_{\log n}` **pointwise**, and the window edge
`u = 2T` sits *on* that comb exactly when `2T = \log n` for a prime power `n`, i.e. `T = ½\log n`
(Role 2 above; this is the parametrisation used in (E) and (C) below). Two proved
consequences of that coincidence are already in the corpus and are the precise form of the
"edge-on-comb" statement:

* **(E)** `A_T = Σ_{n<e^{2T}}v_n` is left-continuous and jumps by exactly `v_n` at `T = ½\log n`,
 so the multiplier-free verification threshold `τ_env = 2πe^{A_T}` is multiplied by `e^{v_n}`
 there (`R155_008 §7`, `PROVED`; matched 6/6 to 5 s.f.);
* **(C)** `f_w(τ)` itself is **continuous** in `T` across every prime entry at a fixed shape family
 and fixed domain, because `w(2T) = 1` makes the entering coefficient `v_n w(\log n)` continuous
 (`R155_008 §7` as amended by `R155_010`, `PROVED`). *What jumps at a prime entry is the length of
 the interval to be defended, not the data of the certificate.*
* **(Thm SC, Paper 47)** a non-negative sub-comb of mass `A < −C_0 = 5.372` gives a negative form
 for all `T ≥ T_0(A)`: positivity is a property of the **complete initial segment** of the comb,
 never of a selection of primes — the prime-side mirror of Corollary 2.4.

So the shape constraint is: `D` must couple the *complete* prime comb below `e^{2T}` to the
*complete* zero set, and the window edge is where the two couplings meet.

**(iii) Contacts sit on the class Nyquist comb.** If `w` is supported in `[−U,U]` then
`f_w = ŵ ⋆ μ` is band-limited to `[−U,U]` in the `τ` variable, so its oscillation scale is bounded
below by `2π/U`; at a Chebyshev-optimal weight (Paper 47 Thm `thm:O`, non-attainment) `f_w`
equioscillates at that scale, and the contact set is the comb of step `≈ 2π/U`. This is
**necessary** and carries no information about zero positions (`R155_012 §8`, correcting
`R155_011 §5`); at `T = ½\log 3` the entire multiplier-free verification interval `[0, 16.75]` lies
essentially below `γ_1 = 14.135`, so the contacts cannot be in any meaningful relation to the
zeros.

**(iv) How many zeros are needed to *evaluate* `f_w` (never to certify it).** With `w ∈ 𝒲_T ∩ C^k_c`
supported in `[−U,U]` and `V = V(w^{(k+1)})`, Paper 47 `lem:smooth`(iii) gives, uniformly for
`|τ| ≤ Γ/2`,

```
Σ_{|γ_ρ| > Γ} |ŵ(τ − γ_ρ)| ≪_U V Γ^{−k−1}\logΓ,
```

so `f_{w,N}` approximates `f_w` within `c` as soon as `Γ = γ_N` satisfies `V Γ^{−k−1}\logΓ ≪ c`.
The corrected form of the `R155_011 §8 (P1)` residual lemma, as required by `R155_012 §7`, is an
**upper bound only**: for a shoulder built on a cubic-B-spline lattice of step `h = 2T/M` with
coefficients `x`, `|ŵ_{\text{lattice}}(t)| ≤ 32‖x‖_1 h^{−3}t^{−4}`, hence
`Σ_{|γ|>Γ}|ŵ(τ−γ)| ≤ C‖x‖_1 h^{−3}Γ^{−3}\logΓ` and `Γ ≳ (‖x‖_1M³/c)^{1/3}`; the measured residual
is `10³` smaller because the `\mathrm{sinc}^4` factors oscillate and the lattice sum cancels, so
the `h^{−3}` conflict between lattice fineness and zero economy is a **worst-case** conflict, not a
law. Combined with Paper 47 Thm `thm:N` (`M ≤ 8` cannot certify at `½\log3`) this is a two-sided
constraint on the class. **And by Theorem 2.2 none of this can ever become a certificate**: `N` is
a budget for *evaluating* `f_w`, never for *proving* `f_w ≥ 0`.

### The Answer to the question, in plain terms

*You asked for the row D that, together with rows A/B/C, gives RH for the small universe of the
first 1000 zeros. It exists, it is exact, and it is empty: the certificate is the zero set itself,
the measure `μ_1000 = Σ_{j≤1000}(δ_{γ_j}+δ_{−γ_j})`. Once one grants that those 1000 numbers are
real, positivity of the truncated Weil functional is an identity — `Σ_j|F̂(γ_j)|² ≥ 0` — its
certificate is unique, and it costs one line to write down. Rows A and B do not even have a
statement in that universe; row C becomes a definition. So the finite universe contains no
mathematics that can be transported to ζ. And now we know exactly why, and it is a theorem, not an
impression: the *real* row D for ζ — the flat-top smoothing `Σ_ρ ŵ(τ−γ_ρ) ≥ 0` of Paper 47's
Theorem Z, which is the only form a certificate can take — is impossible for any finite set of
zeros whatsoever, at every window, for every admissible weight, with no fine print. The reason is
structural: a finite zero set makes the relevant Toeplitz forms of finite rank, which forces any
positive-definite extension to repeat the zero comb for ever instead of decaying, and a flat-top
weight must decay. For the true zero set of ζ that rank is never finite, which is precisely why the
certificate can exist there. The practical consequence for our programme is sharp: a table of zeros
is a tool for *evaluating* a candidate `f_w`, never for *proving* it, and the remaining problem is
the one Paper 47 calls Problem B — to exhibit, for each window, a one-sided smoothing of the
complete zero measure, built from the complete prime comb.*
