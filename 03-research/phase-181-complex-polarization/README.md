# Phase 181 — complex polarization of the logarithmic prime current

The phase asks whether a complex polarization ‖(X+iB)F‖² = ‖XF‖² + ‖BF‖² +
i⟨F,[X,B]F⟩, built from the position operator X and a bounded sine-shift
current B_c realizing the oriented commutator [X,V_p] = (log p)V_p, can
supply the missing positivity for the Euler-logarithm (von Mangoldt) term
without the obstructions found for Robertson's inequality in phase 178.

## Results
- The oriented square identity for X and B retains the commutator linearly
  (unlike Robertson), and the Euler-logarithm coefficients c_{p^k} realize
  the oriented Hermitian von Mangoldt current exactly as a bounded
  sine-shift operator. **PROVED**
- The positive square B_c² necessarily contains a ratio comb at every
  frequency log(m/n), m≠n multiplicatively independent, with coefficients
  that are sums of nonnegative products and so cannot cancel (support
  obstruction theorem). **PROVED**
- These ratio frequencies are absent from the Weil explicit-formula form and
  cannot be removed while retaining Hilbert-space positivity except by
  mechanisms (Clifford/Schur) already excluded elsewhere in the corpus.
- Overall: the oriented current construction itself is **PROVED**; closure
  of row D via this complex-square mechanism is **NO-GO**.
