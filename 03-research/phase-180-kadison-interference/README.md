# Phase 180 — Kadison equality and oriented Euler-Poisson interference

The phase tests whether equality in the Kadison-Schwarz inequality for a
random-unitary Poisson channel Φ(X) = Σ π_j α_j(X) can force the physical
boundary (Frobenius) term to vanish, by proving an exact pairwise formula
for the Kadison defect and evaluating it on the two natural carriers
(logarithmic translations, and the additive-multiplicative affine carrier).

## Results
- Exact pairwise formula for the Kadison defect Φ(X*X) − Φ(X)*Φ(X) as a sum
  of positive squared differences, vanishing iff α_j(X) = α_k(X) for all
  j,k in a faithful representation. **PROVED**
- On the logarithmic-translation channel, all translations commute, so the
  Kadison defect for any translation-type operator is identically zero;
  equality holds trivially and carries no information before invoking
  Λ*1 = log, the Gamma place, Tate moments, or first-contact minimality.
  **PROVED**
- On the affine additive-multiplicative carrier, the dilation covariance
  relation V_pS = S^pV_p makes exact Kadison equality for V_p impossible in
  the faithful integer representation. **PROVED**
- Overall mechanism: the multiplicative-domain/Kadison-equality idea does
  not produce the missing first-contact equality. **PROVED NO-GO**
