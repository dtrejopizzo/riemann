## 2. (D1) Strong duality: the outside-window dual is exact

### 2.1 The two programmes

Fix `T > 0` and weights `v_n ≥ 0` for `n < e^{2T}`. Write `σ_T(τ) = m(τ) − Σ_n v_n cos(τ log n)`,
`m(τ) = Re ψ(¼ + iτ/2) − log π`, and `g_0(u) = cosh(u/2)1_{|u|<2T}`, `g_1(u) = u sinh(u/2)1_{|u|<2T}`, with
`ĝ_j(τ) = ∫g_j(u)cos(τu)du`.

**Primal (P).** `λ_min(A_T(v)) = inf{ ∫_R σ_T dμ : μ ∈ M_+(R)` even, `μ(R) = 1`, `μ̌(u) = 0 ∀|u| ≥ 2T`, `∫ĝ_j dμ = 0, j = 0,1 }`,
where `μ̌(u) = ∫cos(τu)dμ(τ)`.

*Proof of (P).* For `F ∈ P_T`, `‖F‖ = 1`, put `μ = |F̂|²dτ/2π`; then `μ̌ = c_F = Φ` and Theorem A gives
`⟨A_TF,F⟩ = ∫σ_Tdμ`. Conversely if `μ` is feasible then `Φ = μ̌` is continuous, positive definite, `Φ(0) = 1`, supported in
`[−2T,2T]`, so by **Boas–Kac** (Duke **11** (1945) 45–65) `Φ = c_F` with `F ∈ L²(−T,T)`; the two moment conditions are
`Φ̂` having a zero of order `≥ 2` at `±i/2`, i.e. `F ∈ P_T` (`R154_005 §5.2`). ∎ (`RESTATEMENT` of Theorem A + R1.)

**Dual (D).** `D_T(v) := sup{ inf_{τ∈R}[σ_T(τ) + ν̂(τ) + β_0ĝ_0(τ) + β_1ĝ_1(τ)] }` over finite even signed Borel measures
`ν` with `supp ν ⊆ {|u| ≥ 2T}` and `β ∈ R²`. Weak duality `D_T ≤ λ_min` is immediate (integrate the certificate against a
feasible `μ`). Round 1 asserted equality "by LP duality"; round 2 correctly downgraded it to `OPEN`.

### 2.2 Theorem D1 (`PROVED`, new)

> **Theorem D1 (zero duality gap; attainment by finite atomic sequences).** For every `T > 0` and every finite family of
> weights, `D_T(v) = λ_min(A_T(v))`, and the supremum is already exhausted by **finitely atomic** `ν`:
> for every `ε > 0` there are `N`, positions `u_1,…,u_N ≥ 2T`, reals `a_1,…,a_N`, `β ∈ R²` with
> `inf_τ[σ_T(τ) + Σ_j 2a_j cos(u_jτ) + β·ĝ(τ)] > λ_min(A_T(v)) − ε`.
> By Theorem O the supremum is **never attained**.

*Proof.* Three steps.

**(i) Finite relaxations.** For a finite `U = {u_1 < … < u_N} ⊂ [2T,∞)` let
`P(U) := inf{∫σ_Tdμ : μ ∈ M_+(R)` even`, μ(R) = 1, μ̌(u_i) = 0 ∀i, ∫ĝ_jdμ = 0}` and let `D(U)` be the corresponding
certificate value (atoms only at `±u_i`). `P(U) ≤ λ_min` because the primal feasible set of (P) is contained in that of `P(U)`,
and `D(U) ≤ D_T ≤ λ_min`.

**(ii) `P(U) = D(U)`: a finite moment problem with `b` in the interior of the moment cone.**
Write `f_0 ≡ 1`, `f_i(τ) = cos(u_iτ)` (`1 ≤ i ≤ N`), `f_{N+1} = ĝ_0`, `f_{N+2} = ĝ_1`, `m = N+2`, `b = (1,0,…,0) ∈ R^{m+1}`,
and `M = {(⟨f_k,μ⟩)_k : μ ∈ M_+(R)}`, a convex cone. The Lagrangian dual of `P(U) = inf{⟨σ_T,μ⟩ : μ ≥ 0, ⟨f,μ⟩ = b}` is
`sup{⟨y,b⟩ : σ_T − Σ_ky_kf_k ≥ 0` on `R}`, i.e. exactly `D(U)` after `a_i = −y_i/2`, `β_j = −y_{N+1+j}`.
Since `M` is a convex cone containing `0`, `b ∉ int M` would give `y ≠ 0` with `⟨y,z⟩ ≥ ⟨y,b⟩` for all `z ∈ M`, hence
(taking `z = 0`, `z = tf(τ)`, `t ↑ ∞`) `y_0 ≤ 0` and
  `G(τ) := y_0 + Σ_i y_i cos(u_iτ) + y_{N+1}ĝ_0(τ) + y_{N+2}ĝ_1(τ) ≥ 0` for all `τ`.
*Claim: this forces `y = 0`.* The Besicovitch mean of `G` over `[0,X]` tends to `y_0` (each `cos(u_iτ)` has mean `0` because
`u_i ≥ 2T > 0`; `ĝ_j(τ) → 0` by Riemann–Lebesgue since `g_j ∈ L¹`). As `G ≥ 0`, the mean is `≥ 0`, so `y_0 = 0` and
`X^{-1}∫_0^X G → 0` with `G ≥ 0`, i.e. `X^{-1}∫_0^X|G| → 0`. Testing against `cos(u_iτ)` (bounded) gives
`y_i/2 = lim X^{-1}∫_0^X G cos(u_iτ)dτ = 0` for every `i`. There remains `g := y_{N+1}g_0 + y_{N+2}g_1` with `ĝ ≥ 0`.
Two integrations by parts of `ĝ(τ) = ∫_{-2T}^{2T}g(u)cos(τu)du` (`g` even, real-analytic on `[−2T,2T]`) give
  `ĝ(τ) = 2g(2T)\frac{\sin 2Tτ}{τ} + 2g'(2T)\frac{\cos 2Tτ}{τ²} + O(τ^{-3})`.
If `g(2T) ≠ 0` the first term changes sign for arbitrarily large `τ` and dominates: `ĝ < 0` somewhere, contradiction. Hence
`g(2T) = 0`, and then the same argument on the next order forces `g'(2T) = 0`. But
`g(2T) = y_{N+1}\cosh T + 2T y_{N+2}\sinh T`, `g'(2T) = ½y_{N+1}\sinh T + y_{N+2}(\sinh T + T\cosh T)`, whose determinant is
  **`\sinh T\cosh T + T(\cosh²T − \sinh²T) = \sinh T\cosh T + T > 0`**,
so `y_{N+1} = y_{N+2} = 0`. Thus `y = 0`, a contradiction; hence `b ∈ int M`.
Now the value function `w(b') := inf{⟨σ_T,μ⟩ : μ ≥ 0, ⟨f,μ⟩ = b'}` is convex on `R^{m+1}`, finite at every point of the conic
hull of the curve `{f(τ)}` (a compactly supported `μ` has `⟨σ_T,μ⟩ < ∞`), and `> −∞` everywhere (`σ_T` is bounded below and
`⟨f_0,μ⟩ = b'_0` bounds the mass). The conic hull is convex with the same interior as `M`, so `b ∈ int(dom w)`; a finite convex
function is continuous, hence lsc, on the interior of its domain, and lsc of the value function at `b` is exactly the absence of
a duality gap: `P(U) = w(b) = w^{**}(b) = D(U)`.

**(iii) The limit.** Choose finite sets `U_1 ⊂ U_2 ⊂ …` with `∪_nU_n` dense in `[2T,∞)`. Then `P(U_n) ≤ λ_min` is
nondecreasing. Pick `μ_n` feasible for `P(U_n)` with `⟨σ_T,μ_n⟩ ≤ P(U_n) + 1/n ≤ λ_min + 1`. Since `σ_T(τ) → +∞` and `σ_T` is
bounded below, `{μ_n}` is tight; pass to a weakly-* convergent subsequence `μ_n → μ`, a probability measure. For fixed
`u ∈ U_N` and all `n ≥ N`, `μ̌_n(u) = 0`, and `cos(u·)` is bounded continuous, so `μ̌(u) = 0`; `μ̌` is continuous, so `μ̌ ≡ 0` on
`[2T,∞)`. Likewise `∫ĝ_jdμ = 0` (`ĝ_j` bounded continuous, `→0`). So `μ` is feasible for (P), and by lower semicontinuity of
`μ ↦ ∫σ_Tdμ` along weak-* convergence (`σ_T` continuous, bounded below),
`λ_min ≤ ∫σ_Tdμ ≤ liminf⟨σ_T,μ_n⟩ = lim P(U_n) ≤ λ_min`. Hence `P(U_n) → λ_min`, and by (ii)
`D_T ≥ sup_n D(U_n) = sup_n P(U_n) = λ_min ≥ D_T`. ∎

**Consequences.**
1. **Round 2's `OPEN` item 1 is closed**, and with it repair **RC**: the `62×`/`206×` "class ceiling" of `R154_002 §1`,
   which was conditional on strong duality, is now unconditional.
2. Theorem O and Theorem D1 fit exactly: the sup equals `λ_min` but is never attained, so *every* maximising sequence
   degenerates — and D1 says the degeneration may be taken **finitely atomic**, which is what the LPs compute.
3. **The certificate route is complete**: `A_T(v) ≥ 0` (for `v` with `λ_min > 0`) is *provable* by a finite certificate, always.
   The only question is the rate. This is the exact answer to the question round 2 left open, and it removes the last
   structural reason to doubt the route.

## 3. (D2) The certificate at `T = ½log3`

### 3.1 The method: lattice atoms give a periodic `ν̂`, hence a cheap exact tail

Round 2's provable tail used `|ν̂(τ)| ≤ TV(ν)`, forcing `m(τ_max) ≥ Σv_n + TV(ν)`, i.e. `τ_max ≈ 2π e^{Σ v + ‖ν‖}`; with the
`‖a‖₁ ≈ 60` that good certificates need this is `e^{120}` — hopeless. Round 3 removes it:

> **Lemma D2.1 (periodic tail; `PROVED`).** Put the atoms on the lattice `u_j = jd`, `d = 2T/M`, `j = M,…,J`
> (so `u_M = 2T` exactly). Then `ν̂(τ) = Σ_j 2a_j\cos(u_jτ)` is periodic with period `P = 2π/d`, so its global minimum
> `−ρ := \min_{[0,P]}ν̂` is computed on **one period**. Since `m` is increasing, `|ĝ_0(τ)| ≤ 2\cosh T/τ + \sinh T/τ²`,
> `|ĝ_1(τ)| ≤ 8T\sinh T/τ`, for all `τ ≥ τ_max`
> **`σ_T(τ) + ν̂(τ) + β·ĝ(τ) ≥ m(τ_max) − Σ_nv_n − ρ − |β_0|(2\cosh T/τ_{max} + \sinh T/τ_{max}²) − |β_1|·8T\sinh T/τ_{max}`.**

`ρ` is bounded by `2‖a‖₁` but is in practice `≈ 2.4`, i.e. `25×` smaller; the tail then needs only `τ_max ≈ 200`.
The LP carries `ρ`, `|β_0|`, `|β_1|` as variables and the tail inequality as **one linear row**, so the optimiser trades
certificate strength against tail cost automatically. The compact part `[0,τ_max]` is verified by adaptive Lipschitz
branch-and-bound with the global constant
  **`L = ψ'(¼)/2 + Σ_nv_n\log n + 2Σ_j|a_j|u_j + |β_0|∫|u|\cosh(u/2)du + |β_1|∫u²|\sinh(u/2)|du`**
(`|m'(τ)| ≤ ½|ψ'(¼+iτ/2)| ≤ ½ψ'(¼) = 8.5987`; the last two integrals over `[−2T,2T]` are `G_0 = 1.29953`, `G_1 = 0.37653`
at `T = ½log3`), and the one-period minimum is certified by the same grid+Lipschitz device with constant `2Σ_j|a_j|u_j`.

## 4. (D3) The shape of near-optimal certificates

Read off the `M = 16` and `M = 19` optima (`structure` block of `sweepM.pkl`, printed in `scripts/round3/`):

1. **The multipliers converge to the explicit formula's polar term.** `β_0 = 2.4463, 2.1384, 2.00052, 2.00078` and
   `β_1 = −1.4070, −0.3885, −0.00520, −0.00803` for `M = 8,12,16,19`: **`β_0 → 2`, `β_1 → 0`.** Since
   `∫Φ(u)\cosh(u/2)du = ½(\hatΦ(i/2) + \hatΦ(−i/2))`, the value `β_0 = 2` means the optimal certificate adds back
   **exactly `\hatΦ(i/2) + \hatΦ(−i/2)`** — the two polar contributions of the Weil explicit formula, each with
   coefficient `1`, and nothing of the first-order multiplier. The dual optimum is not an arbitrary Lagrange vector: it
   **reconstitutes the full explicit formula from its primitive (pole-free) restriction**. `DIAGNOSTIC-NUMERIC`, but the
   convergence is monotone and to `4·10⁻⁴` at `M = 19`.
2. **The contact set is an interval, and it grows with `M`.** For `M ≥ 16` the certificate satisfies
   `σ_T + ν̂ + β·ĝ = c` to `10⁻³` on the whole band `[0, 13.2]` (to `10⁻⁴` on `[0,12.6]` at `M = 19`), i.e. the dual
   **touches the bound on a set of positive measure**, not at isolated points; the measure of `{f − c < 10⁻⁴}` inside
   `[0,30]` grows `13.81 → 15.21 → 16.73 → 19.32` for `M = 8,12,16,19`. This is exactly the complementary slackness of
   Theorem O made visible: `D = f − λ_min` must vanish on `supp μ_★` (and `μ_★ = |\hat F_★|²dτ/2π` is absolutely
   continuous), the contact interval must therefore grow as `c ↑ λ_min`, and Theorem O says it can **never** become all
   of `R`. The band's right end sits just beyond the last sign change of `σ_T` (`τ = 10.531`).
3. **No arithmetic structure in the positions.** The atoms do not concentrate at `\log n`: the weights alternate in sign
   at `70%` of consecutive lattice sites, and their magnitude decays smoothly in `u` — mean `|a_j|` is
   `0.270, 0.193, 0.153, 0.121, 0.077, 0.023` on `u ∈ [2T,3), [3,6), [6,12), [12,22), [22,32), [32,42)` — with
   `\max|a_j| = 0.713` at `u = 1.2359` (the third lattice point), i.e. **the mass sits at the window edge and decays**,
   which is the `ν_{tot}`-imitation that Theorem O forbids from succeeding. There is no `\log 2`-spacing, no `3`-smooth
   pattern, no equal-amplitude pattern: the near-optimal `ν` is a smooth signed density sampled on the lattice, not a
   "magic measure".
4. **`ν̂` is a Fejér-like object**: `ν̂(0) = 1.735`, `\max ν̂ = 50.66` (a narrow spike at `τ = 50.43`),
   `\min ν̂ = −2.62`, mean `0` (no atom at `u = 0` is allowed). The whole construction is a one-sided approximation
   problem: a mean-zero trigonometric polynomial with a prescribed positive bump on `[0,13]` and a floor `−ρ` elsewhere.
