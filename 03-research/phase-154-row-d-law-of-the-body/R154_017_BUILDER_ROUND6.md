## 2. What was built

**The programme is unchanged** from `R154_015 §2` (Lemma F1, two contacts `n = 2,3`, `½log3 < T ≤ log 2`):

    max c  s.t.  c ≤ f(τ) on [0,τ₁];  c ≤ h_k(x) on [τ₁,τ₁+P), k = 0..N;
    variables (c, a_M..a_J, β₀, β₁, t₀ ≥ |β₀|, t₁ ≥ |β₁|),  u_j = j·2T/M,  P = 2π/d,  d = 2T/M.

**(G1) `r6lp.py` / `r6polish.py` — row generation.** Start from a coarse uniform row set
(`h₀ = 0.03` on `[0,τ₁]`, `0.02–0.08` on the period); solve; **separate** by locating *every* local minimum of `f`
and of each `h_k` on a scan grid of step `h_sep = 5·10⁻³` (`≈ 60` points per shortest oscillation
`2π/u_max ≈ 0.297`) and refining each one to `≈ 10⁻¹⁰` by six rounds of 9-point local grids — an exact
local-minimum finder, strictly sharper than evaluating any uniform `2·10⁻⁵` grid; append the violated minima as
rows; **purge** rows whose slack exceeds `2·10⁻²` and whose dual multiplier is zero, except a protected uniform
*base* grid (without the base the LP goes unbounded — measured, `sw_C058M24.log` first attempt) and rows younger
than 5 iterations.

**(G2) `r6cg.py` — row *and column* generation.** Start from every 8-th lattice atom. After each solve, price the
whole pool: for an atom `u ∉ S` the reduced cost is `d(u) = Σ_i λ_i·(−2cos(u τ_i))` with `λ` the row duals, and
since `a_u` is a **free** variable any `|d(u)| > 0` means adding `u` strictly improves the LP. Add the 60 largest.
Atoms outside `S` carry `a_j = 0`, so **every iterate is a legitimate member of the same certificate class** and
`truemin` (the refined global minimum of that iterate) is an honest *lower* bound — i.e. an actual, if bad,
certificate value.

**(G3) `r6ub.py` — the decisive upper bound, written and launched, no output.** Any *dual-feasible* weight vector
bounds `c*(M)` from above: weights `y_i ≥ 0` with `Σy_i = 1`, `Σ_i y_i cos(u_j τ_i) = 0` for every atom,
`Σ_i y_i ĝ_0(τ_i) = Σ_i y_i ĝ_1(τ_i) = 0`, give `c*(M) ≤ Σ_i y_i·base(τ_i)`. This is a moment problem with only
`n+3` **constraints** (basis `n+3` square) and one column per `τ`-point, which simplex handles far better than the
primal. **A negative value here would settle the round's question outright** — it would say that *no* certificate
of the class with that atom budget is positive, without ever having to converge the primal. All five runs
(`M = 24,32,44,64,96`, `h = 0.02`, 21 004–79 504 columns) were launched and **killed before any of them printed**;
`sw_ub058M*.log` contain only their headers. **This is the first thing round 7 should run.**

## 5. Shape transfer inside a contact set: **REFUTED** (the audit's item 5)

`R154_015 §6` concluded: *"shape transfer works within a contact set and not across one … this is why steps 2–5
would be cheap."* `R154_016` row 3i labelled the positive half untested. It is now tested and it is **false**.

| transfer | source certificate | target | polished value (cutting-plane polish, converged) |
|---|---|---|---|
| **across** contacts `{2} → {2,3}` | round 4's `½log3` certificate | `T = 0.58` | `−4.2088·10⁻¹` (round 5) |
| **within** contacts `{2,3} → {2,3}` | round 5's **own-LP** `T = 0.58` certificate (`lp_Q058.pkl`) | `T = 0.62` | **`−4.0402·10⁻¹`** (`sw_P062from058.log`, 10 `it`s, gap `1.2·10⁻⁷`) |
| control: no transfer | `lp_Q058.pkl` | `T = 0.58` | `−3.1802·10⁻³` |

The two transfers are **within 4 % of each other** and both are `≈ 127×` worse than the un-transferred control. So
the destructive step is **the lattice rescaling `d = 2T/M` itself**, exactly the alternative the auditor named, and
**not** the change of contact set. Consequence: there is no cheap ladder. Every `T` costs a full atom LP, which
multiplies the §4 cost table by the number of steps. `R154_015 §6`'s last bullet must be relabelled (§6 below).
