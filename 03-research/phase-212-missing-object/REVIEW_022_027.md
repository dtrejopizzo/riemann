## (A) ROUND_025_B §2–§3 and ROUND_027_C Lemmas 1.2–1.3

**A1. `K_T` closed and convex.** CONFIRMED. For each fixed `F`, `w ↦ a^w_T(F)` is affine on `ℝ^{N_T}` (finite sum).
`K_T` is an intersection of closed half-spaces.

**A2. Bound `|w_n| ≤ C(log n + 1)`.** CORRECTABLE: the statement is true, but the written proof has a gap.
Test `F = f ± f(·−log n)` with `f` smooth of width `h`. One checks: `‖F‖² = 2‖f‖²`, `c_F(log n) = ±‖f‖²`, and
`c_F(log m) = 0` for `m ≠ n` if `h <` half the gap. Moreover `Arch(F) ≤ (log(1/h) + C)‖F‖²` for smooth profiles.
*Gap.* The correction `F + α_+u_+ + α_−u_−`, which brings the test into `P_T`, produces the cross terms
`−2α Σ_m w_m c_{F,u}(log m)` and `−α² Σ_m w_m c_u(log m)`. Both depend on **all** the `w_m`, which are not yet bounded.
The claim "the correction is `O(h^{1/2}‖f‖)`" is not enough.
*Repair.* Let `W := max_{m∈N_T}|w_m|`, which is finite because the vector is finite. One has
`|c_{F,u}(log m)| ≤ ‖F‖_{L¹}‖u‖_∞ ≤ C_u h^{1/2}`, and `|Arch(F,u)| ≤ ‖F‖_{L¹}‖(m û)ˇ‖_∞` because `u` is smooth.
From this follows `W ≤ 2(log(1/h)+C) + C_u(h^{1/2}+h)N W`, with `N = |N_T| < e^{2T}` and `C_u ≤ e^{O(T)}`.
Taking `h = e^{−cT}` with `c` large gives `W ≤ C(T+1)` in the window `T`.
To bound `w_n` one uses the restriction (A3) to the smallest window containing `n`, `T_n = ½log(n+1)`.
This yields `|w_n| ≤ C(log n + 1)` with `C` absolute, for every `w ∈ K_{T′}` and every `T′ ≥ T_n`.
Corrected statement: the same as the original, with the proof in two steps (window bound depending on `T` and then restriction).
For Tychonoff only the compactness of each `K_T` is needed.

**A3. Restriction `w ∈ K_{T′} ⟹ w|_{N_T} ∈ K_T`.** CONFIRMED. The extension by zero of `F ∈ P_T ∩ D_T` lies in
`P_{T′} ∩ D_{T′}` and has the same `F̂`, so `Arch` does not change. Since `c_F` is continuous with support in `[−2T,2T]`,
`c_F(±2T) = 0`, and `N_T` is defined with strict inequality. Hence the new contacts do not count.

**A4. Lemma 1.3 (passage to the limit).** CONFIRMED, with exact hypotheses: `T_j → ∞`, `ω_j → 0` and
`a^{(ω_j)}_{T_j} ≥ 0` on `P_{T_j} ∩ D_{T_j}`. For `T_j ≥ T`, A3 gives `(v_n cos(ω_j log n))_{n∈N_T} ∈ K_T`.
The vector converges to `v|_{N_T}` in a finite-dimensional space, and A1 gives `v|_{N_T} ∈ K_T`, that is `λ_A(T) ≥ 0`.
No uniformity or boundedness is needed.

**A5. Existence by Tychonoff.** CONFIRMED, with A2 in its repaired form. Take `T_k ↑ ∞`. The `K_{T_k}` are compact
and non-empty, and the restrictions are continuous, so the inverse limit is non-empty. One obtains `w ∈ ℝ^{ℕ≥2}` with
`w|_{N_T} ∈ K_T` for every `T`: it suffices to restrict from some `T_k ≥ T` with A3.

**A6. Duality `K_T ≠ ∅ ⟺ (−1,0) ∉ cl C_T`.** CONFIRMED, with two clarifications.
- `C_T` is a convex cone. `Arch(ρ) := Σλ_i Arch(F_i)` is well defined in `(−∞,∞]`, because
  `Arch(F_i) ≥ C_0‖F_i‖²` and `Σλ_i < ∞`. Moreover `|c_ρ(log n)| ≤ tr ρ`.
- (⟹) If `(1,−w) ∈ C_T*`, the product with `(−1,0)` equals `−1 < 0`, and that is impossible in the closure.
- (⟸) Separate the point `(−1,0)` from the closed cone `cl C_T`. One obtains `y = (λ,z)` with `λ > 0`, and takes `w = −z/λ`.
- That rank-one tests suffice is due to linearity.
- The variant `w ≥ 0`, with the cone `C_T − {0}×ℝ^N_+`, is correct.
- The reading "there exists an exact `ρ`" is correctly NOT VERIFIED in the memo, because it is not known whether `C_T` is closed.

## (B) ROUND_027_C §§1–2, §4

**B1. Identity (2.1)–(2.2).** CONFIRMED for real `F ∈ P_T ∩ D_T` (the complex case reduces to this one by Lemma 1.1(b)).
Re-derivation:
- One has `c_G = e^{iωu}c_F` and `c_F` is even. Then `Arch(F) − Arch(G) = −∫_0^∞(1−cos ωu)K c_F`, which gives (2.1).
- To pass to (2.2) one uses `2Re(A B̄)(G) = ∫_ℝ c_G(u)·2cosh(u/2)du = 2∫_0^∞ cos(ωu) c_F 2cosh(u/2)`.
- Since `F ∈ P_T`, `∫_ℝ c_F 2cosh(u/2) = 2A(F)B(F) = 0`. Hence `a_T(G) = W_T(G) + ∫_0^∞(1−cos ωu)4cosh(u/2)c_F`.
- The integrals converge: `(1−cos)K = O(u)` near 0 and the support is compact.
Remark: `G ∉ P_T`; (2.2) uses `W_T` on `D_T`, which is the definition of P46 eq:W.

**B2. Polar term `−2ω²A′B′ + O(ω³)`.** CONFIRMED, and it can be sharpened to `O(ω⁴)`.
- Expansion: `A(G) = iωA′ − ω²A″/2 + O(ω³)` and `B̄(G) = −iωB′ − ω²B″/2 + O(ω³)`.
- The coefficient of `ω³` in `A B̄` is purely imaginary, so `−2Re(A B̄)(G) = −2ω²A′B′ + O(ω⁴)`.
- Check by the other route: `∫_ℝ u²c_F 2cosh(u/2) = 2(A″B − 2A′B′ + AB″) = −4A′B′` on `P_T`.
- Bound: `|A′B′| ≤ ‖F‖²(∫t²e^{t}∫t²e^{−t})^{1/2} = ‖F‖²∫_{−T}^{T}t²e^{t}dt`, correct by Cauchy–Schwarz and symmetry.
- The archimedean correction `−(ω²/2)∫u²Kc_F` is `O(ω²)` because `∫_0^∞u²K < ∞`.

**B3. Corollary 1.4.** CONFIRMED, with `μ` a **probability** measure (that is `g(0) = 1`; otherwise `Arch` does not average).
One has `a^{v·g}_T(F) = ∫a^{(ω)}_T(F)dμ(ω)` because the sum is finite and `Arch` does not depend on `ω`.
By Bochner, every positive-definite, continuous, even `g` with `g(0)=1` admits that form. It suffices that `a^{(ω)} ≥ 0` μ-almost everywhere.

**B4. Triangular attenuation.**
- The transform `∝ sinc²(ωT)` is CONFIRMED (triangle of half-width `2T`).
- The logical implication "mean `< 0` at some `F` ⟹ there exists `ω ∈ supp μ_F` with `a^{(ω)}_T(F) < 0`" is CONFIRMED.
- The value `−0.04…−0.15` and the positivity for `k ≤ 1` are NOT VERIFIED: they are numerics from other memos and were not recomputed.
  The claim "the `ω` is necessarily large" depends on that positivity.
- The mechanism "what decides is the bounded spectral support of `μ`" is ARGUED, not proved. Correct label in the memo.

## (C) ROUND_024_B §2–§3 and ROUND_022_A Part 1

**C1. `E = S_ζ ∘ ι`.** CONFIRMED against the literal definition (P46 def:ext: `Φ_f(x) = e^{x/2}Σ_{n≥1}f(ne^x)`,
`Ef = Φ_f|_{I_T}`) and against R160_D4_R2 Thm. 4.3 (`S_ζh(t) = Σ m^{−1/2}h(t+log m)`).
Computation: `S_ζ(ιf)(x) = Σ n^{−1/2}e^{(x+log n)/2}f(ne^x) = Φ_f(x)`. Clarification: `E = (S_ζ ι f)|_{I_T}`, with restriction.
Also correct are `ι^{−1}g_0 = (2π²u⁴ − 3πu²)e^{−πu²}` and `g∗φ = ι(f_φ)`.

**C2. `K_Pó = S_ζ g_0`.** FALSE by a factor 2; CORRECTABLE.
- P47 thm:K: `K(t) = Σ(4π²n⁴e^{9t/2} − 6πn²e^{5t/2})e^{−πn²e^{2t}}`, with `Φ_K = ξ`. Hence `K_Pó = 2 S_ζ g_0`.
- Exact computation in the convention `Φ_F(s) = ∫F e^{(s−½)t}`:
  `Φ_{g_0}(s) = ∫_0^∞ f_0(u)u^{s−1}du = π^{−s/2}[Γ(s/2+2) − (3/2)Γ(s/2+1)] = ¼ s(s−1)π^{−s/2}Γ(s/2)`.
  The memo writes `½`. Consequently `Φ_{S_ζ g_0} = ½ξ`.
- NUMERICAL (`review_022_polya.py`, 25 digits): `K_P46/S_ζg_0 = 2` at `t = −0.7, 0, 0.4`, and `Φ_{S_ζg_0}(½+iz)/ξ = 0.5` at
  `z = 0, 3, 10`.
- ROUND_024_A §2(a) uses `M(t) ≈ −16π⁴e^{17t/2}e^{−πe^{2t}}`, which corresponds to `2S_ζg_0` (with `S_ζ g_0` one would get `−8π⁴`). The error
  is a transcription error and affects the headers of 022_A, 024_A and 024_B and `f_0`.
- It does not affect radicality, localization or any sign: it is a scalar.
- Correction: `g_0(t) := (4π²e^{9t/2} − 6πe^{5t/2})e^{−πe^{2t}}`.

**C3. Lemma (U).** CORRECTABLE.
- Under its hypotheses (`Φ_h` holomorphic in a strip containing `[0,1]` and `ζΦ_h` vanishing at `0`, `1` and at the zeros), the
  conclusion is correct. The function lies in the radical of the pairing `I` of P47 (thm:radical, eq:comparison: `I` carries the
  terms `Φ(0)Φ(1)`) and, in particular, `𝒲(S_ζh,·) = 0`.
- Verified cases:
  - `h = g = (−∂²+¼)g_0`: the multiplier is `s(1−s)`. There is a zero of `Φ_g` at `s = 0`, and a double zero at `s = 1` that
    compensates the pole of `ζ`. Valid in the strip `−1 < Re s < 2`.
  - `h = c_F` with `F ∈ P_T`: `Φ_{c_F}` has double zeros at `0` and `1`. Valid.
- **Gauge case misclassified.** For `φ ∈ 𝒢_T` one has
  `Φ_{S_ζιφ}(1) = 𝓜φ′(1) = ∫_0^∞φ(u)log u du` and `Φ(0) = ζ(0)∫_0^∞φ(u)u^{−1}du`. Neither vanishes in general.
  NUMERICAL (`review_022_gauge.py`): `−2.4·10⁻⁷` and `−1.1·10⁻⁶` for a concrete admissible `φ`.
  Hence the gauge does **not** satisfy (U). It lies in the radical of the complete form `𝒲`, which only requires `Φ(ρ) = 0`
  (P46 prop:ext-gauge, via Guo), and not in the `𝒩` of P47.
- Correction: (U′) `𝒲(S_ζh,·) = 0` requires only that `ζΦ_h` vanish at the zeros. "`∈ 𝒩`" additionally requires vanishing at `0` and `1`.
- The sentence "radicality does NOT distinguish the entries" is **false** in that sense. `M∗φ` has zero polar values;
  the gauge, in general, does not.

**C4. Inclusion `Π_T(M∗φ) ∈ Π_T E·span{ψ_k : k ≲ 4N} + error`.** CORRECTABLE. It can be completed, with these changes:
- (i) The concentration is correct: `f_g(ue^{−s})` has scale `e^{s} ≤ λe^{−δ}` and its transform has scale
  `e^{−s} ≤ λe^{−δ}`. The masses outside `[−λ,λ]` are `≤ poly(λ)e^{−πe^{2δ}}`, by self-duality of `e^{−πu²}` in the
  convention `e^{−2πixξ}` of def:ext.
- (ii) **The sign of the index is reversed.** Landau–Pollak gives `‖f − P_K f‖ ≲ ε/√d_{K+1}`. One needs `d_{K+1}` NOT
  to be small, that is, `K` must be **after** the drop: `K = 4N + O(log N·log(1/ε′))`, not `4N − O(…)`.
  With `d_{K+1} ≥ ε_δ^{2θ}` the error is `≤ 2ε_δ^{1−θ}` and `K ≤ 4N + C θ log N·πe^{2δ}`. For the width of the drop one cites
  the non-asymptotic version of Landau–Widom (Osipov, Bonami–Jaming–Karoui).
  Then "`k ≲ 4N`" holds only if `e^{2δ}log N ≲ N`, that is `δ ≤ T − ½log log N + O(1)`. For `δ` near `T` the
  required span is `O(N log N)`.
- (iii) `‖Ef‖_{L²(I_T)}² ≤ N H_N ‖f‖²` (Cauchy–Schwarz with `≤ N` terms and `∫|f(ne^x)|²e^x dx = ‖f‖²/n`). CONFIRMED for
  `f` supported in `[−λ,λ]`. For the part of `f_φ` outside `[−λ,λ]` a norm with Gaussian weight is needed: the
  sum over `n` is no longer finite.
- An error term is missing: the cutoff layer, `(1−χ)(M∗φ)` on `I_T`, of size `≍ e^{−c e^{2(δ−η)}}` (see D2).
  The correct error is `O(poly(N)(ε_δ^{1−θ} + e^{−ce^{2(δ−η)}})‖φ‖_{L¹})`, with `‖φ‖_{L¹}` and not `‖φ‖`.

## (D) ROUND_024_A §2 and §4

**D1. `a_T(G + sχF) = W_*(G) − 2sW_*(G,R) + s²W_*(R)`.** FALSE as written; CORRECTABLE.
- `χF` is not in `P_T`, and `a_T = W_T − 2Re(AB̄)` (P46 eq:W).
- Since `A(F) = Φ_F(1) = 0` and `B(F) = Φ_F(0) = 0` for `F = M∗φ`, one has `A(χF) = −A(R)` and `B(χF) = −B(R)`. Hence:
  `a_T(G + sχF) = W_*(G) − 2sW_*(G,R) + s²[W_*(R) − 2A(R)B(R)]`, with `G ∈ P_T ∩ D_T` real.
- Alternative exact form: `W_T(G + sχF) =` the memo's expression, unchanged.
- The intermediate identity `a_T(χF + G) = W_*(G − R)` is false by the same term: `−2A(R)B(R)` is missing.
- That term is `O(e^{T}w)‖R‖²`, of the same order as piece (d) of the memo, so it does not change the orders.
- The minimum in `s` requires `W_*(R) − 2A(R)B(R) > 0`, not `W_*(R) > 0`.
- The radicality `W_*(F,·) ≡ 0` is correct: `Φ_{M∗φ} = Φ_MΦ_φ` vanishes at `0`, `1` and the zeros (P47 thm:radical).

**D2. Orders of the pieces of `W_*(R)`.** CORRECTABLE.
- (a) Width of the layer. Finite order: `w ≍ e^{−2D}`, CONFIRMED, because the local rate is `2πe^{2D}`.
  Flat cutoff: the maximum of `−η/x − Ax` is at `x_* = (η/A)^{1/2}`, which is the **position**, not the width as the memo states.
  The width is `w ≍ η^{1/4}A^{−3/4}`. The conclusion `w ≍ A^{−3/4}` with fixed `η` and `κ = 3/2` is correct.
- (b) `Arch_*(R) = (log(1/w) + O(1))‖R‖²`. The lower bound can be proved: if `‖R‖_{L¹}² ≤ Cw‖R‖²`, then
  `∫_{|τ|<ε/w}|R̂|² ≤ 2Cε‖R‖²`. The upper bound requires regularity of `R` at scale `w`. It remains ARGUED.
- (c) The bound (2.1) `|Σv_n c_R(log n)| ≤ CTe^{−T}max(1,e^{2T}w)‖R‖²` is CONFIRMED: `≤ Nw + 1` integers, `v_n ≤ 4Te^{−(T−η)}` and
  `|c_R| ≤ ‖R‖²`, without using the distribution of primes.
  But the next line ("for `e^{2T}w ≥ 1` the factor is `CTe^{3T}w²`") is **inconsistent** with (2.1), which gives `CTe^{T}w`.
  With the finer bound `∫|c_R| ≤ ‖R‖_{L¹}² ≤ w‖R‖²` one gets `CTe^{T}w²`. In no case `e^{3T}`.
  `ρ` of §2(e) uses (2.1), so the dominance conclusions survive.
- (d) `|A(R)|,|B(R)| ≤ e^{T/2}‖R‖_{L¹}` is CONFIRMED. The part `W_*(u,R)` remains NOT VERIFIED because `u` was not defined in the memo.
- Note: `R = (1−χ)F` includes the tail of `F` outside `I_T`. With `η = e^{−2T}` (case ROUND_019_A) that tail is not
  negligible compared with the layer (`Aη ≍ 2π`). The memo includes it in (c), and that is fine.
