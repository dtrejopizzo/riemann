# Brief for every construction memo in phase 211

Read first: STATEMENT_001.md, README.md, DOSSIER_001.md (§1 definitions, §2 tools, §3 barriers,
§4 shape of the solution, §6 corrections). Then 05-meta-and-planning/ROUTES-TRIED-INDEX/README.md
and the index file relevant to your object. Then the grid
03-research/phase-162-row-d-first-contact-closure/grid/R162_2300_MASTER_GRID.md (grep your keywords).

Rules.
1. Sandbox: the target is (★) λ_A(T) ≥ 0 for every T, a statement about one explicit quadratic
   form. Never name, invoke, or reason from any equivalence of (★) with another statement; never
   reduce to zeros; never argue "this is as hard as…". If a line of reasoning needs it, drop it.
2. Routes-tried: nothing in the index is retried unless the memo states, in a section "Corpus
   check", exactly what hypothesis, object or method class differs and why that difference avoids
   the recorded failure.
3. Labels on every claim: PROVED / CITED / CONDITIONAL / ARGUED / OPEN / NO-GO / NUMERICAL.
   A PROVED claim comes with a complete proof. A computation validates a point; it proves nothing.
4. Falsifier test (mandatory for any sign step): the argument must FAIL for (a) cΛ with c ≠ 1,
   (b) a_P (primes below P deleted), (c) a Beurling generalized-prime system whose zeta function
   continues to the line, (d) a finite modification of the weights v_n. If the argument survives
   any of these, it is wrong; say where.
5. Pure mathematics. If a tool does not exist, build it and prove it; if a step fails, record
   exactly which inequality or identity fails and by how much, then pivot.
6. Write the memo in plain mathematical prose; no author names, dates, model names or process
   roles in the file. File: 03-research/phase-211-sign-sandbox/ROUND_001_<X>.md.
7. End with: "Result" (one of PROVED piece / NO-GO with class / PIVOT with reason), "What was
   proved", "What failed and why", "Next concrete step".
