### H1 — **FATAL** — D.22.4 / D.22.5: `L_S` is misidentified; with its `L_S` the shadow is **zero**

**Location.** Definition D.22.4 ("Let `L_S := O_{K,S}` be the ring of `S`-integers, a projective
`O_K`-module"), Theorem D.22.5(i),(iii),(v), Corollary D.22.6, README row "D.22 … `PROVED` — O-9

Definition 6bis.1 (`main.md:2676`)".

**Why it is wrong.** Paper 44's `L_S` is **not** the ring of `S`-integers. `44/main.md:2668–2672`
defines it as *"the integral lattice `L_S = ∏_{p∈S_f}Z_p ⊂ X_S`"* — a product of **completions**.
Its substitution changes the object, and it changes it fatally: Definition D.22.1 defines
`Frob_{𝔓^k}` only for `𝔓 ∈ S_f`, so every `𝔫` in D.22 has `P(𝔫) ⊆ S_f`; but `O_{K,S}` is by

`𝔫O_{K,S} = O_{K,S}` for every admissible `𝔫`, the inclusion `𝔫L_S ↪ L_S` is the identity, the cone

not `O_K/𝔫` and `\log N𝔫`. D.22.5(i),(iii) are **false as stated**, (ii)'s triangle is the trivial

patched the statement instead of the definition, and the patch gives `𝔫' = O_K` always.

error is **not** inherited from Paper 44, which is correct; it was introduced by the transport.

### H2 — **MAJOR** — Theorem D.24.5: the general biconditional is **false as stated**

**Location.** Theorem D.24.5, second paragraph: *"for **any** `h⁰ : D^W → R_{≥0}` that factors through
`M` …, (c) holds for some `χ ∈ R` **iff** `I_∞(F,F) ≤ 0` for every primitive `F ∈ C_c^∞`, i.e. iff RH."*

**Why it is wrong.** The `(⇐)` direction fails. Take `ψ ≡ 0` (admissible: the hypothesis is only
`h⁰ ≥ 0` and factoring through `M`). Then (c) reads `0 ≥ ½I_∞(E,E) − ½I_∞(E,K) + χ` for all `E`; at
`E = mK` the right side is `¼m² − ¼m + χ → +∞`, so **no `χ` exists, under RH or otherwise**. RH is
therefore not sufficient for (c) for a general bidegree-function; only the `(⇒)` direction is general.
The proof text in fact proves only `(⇒)` in the general case — the `(⇐)` paragraph is written for
`h_c = \max(·,0)` and silently reused.

**Severity.** MAJOR: a theorem labelled `PROVED` is false in the generality stated. It does **not**
propagate: every downstream use (AT-1(ii), Proposition D.24.10(iv), D.25 §3) uses only `(⇒)`.

**Minimal repair.** Split: *(i) For every `h⁰ = ψ∘M ≥ 0`, (c) for some `χ` implies `I_∞(F,F) ≤ 0` on
primitive `F ∈ C_c^∞`, hence RH (Paper 45 Thm 10.4).* *(ii) Conversely, for `ψ(a,b) = a⁺b⁺` and
`χ ≤ 1/8`, RH implies (c).* State (ii) for exactly the class of `ψ` with
`ψ(a,b)+ψ(c−a,c−b) ≥ ab − \tfrac{c}{2}(a+b) + χ` on `R²`, which is what the proof gives.

### H3 — **MAJOR** — D.23.6: the collapse is a property of its realization `r`, not of the Frobenius family; the blueprint's actual instruction was not carried out

**Findings.**

   `D^W`. Paper 46 Theorem 11.8(iii) (`:2229`) observes only that the *weights* `n^{±½}` of

   "named regularization" box, and then the README and D.25 report the consequence as a fact about
   the Frobenius family. That is an overstatement and it is the phase's headline.

   `contact_{fin}(Frob_𝔫) = Λ_K(𝔫)N𝔫^{−½}` and `\deg_{det} = \log N𝔫` to `Frob_𝔫`; `r` remembers

3. **The blueprint's instruction was not executed.** `R140_000` D.23.2 asks to *"restrict `I_∞` to the

   The two statements concern different forms and are not in contradiction, but a round whose
   conclusion is *"the Euler-product structure is non-detecting"* must address 8bis.4a explicitly and

**Severity.** MAJOR (interpretation and completeness, not arithmetic error). The theorems as
*mathematics* stand.

**Minimal repair.** (i) Restate the headline everywhere as: *"the **Pólya realization** `r` of the

### H9 — **MAJOR (proof)** — Theorem D.23.4 works in the wrong order

**Location.** Theorem D.23.4's proof: *"Let `K_0 = Q(\sqrt{−D_0})` be the imaginary quadratic field of
the fundamental discriminant underlying `−D` … `r_Q(n) = \#\{𝔞 ⊆ O_{K_0} : N𝔞 = n, [𝔞] = 1\}` … Since
`h(−D_0) > 1` …"*

**Why.** For non-fundamental `−D` the form class group of discriminant `−D` is the ring class group of
the **order** `O_{−D}`, not `Cl(O_{K_0})`, and the ideal–form correspondence is with proper
`O_{−D}`-ideals; Chebotarev must be applied to the ring class field. Moreover the two class numbers differ in general — the
order's class number is `h(O_{−D}) = h(K_0)f\prod_{𝔭|f}(1−(\tfrac{D_0}{𝔭})𝔭^{−1})/[O_{K_0}^×:O_{−D}^×]`,
so `h(−D) > 1` does **not** imply `h(−D_0) > 1` (any non-maximal order over a class-number-one field,
e.g. `−D = −32`, `h(−32) = 2`, over `−D_0 = −4` with `h(−4) = 1`) — so the hypothesis the proof invokes is not the
hypothesis stated.

**Minimal repair.** State everything for the order `O_{−D}` of discriminant `−D`: proper ideals,
ring class group `Cl(O_{−D})` of order `h(−D) > 1`, Chebotarev in the ring class field, primes not
dividing the conductor. The conclusion is unaffected. **Recommended addition:** the explicit witness
verified in §0.8 above (`Q = x²+5y²`, `r_Q(3) = r_Q(7) = 0`, `21 = 1²+5·2²`), which makes the theorem
checkable by inspection and removes the Chebotarev import for the statement "there exist `p,q`".
