## AUDIT 1 — R164_401

### (a) Lemma 1

**Normalisation.** For σ>1, ∫_0^∞ Θ_N(x)x^{s/2}dx/x = π^{−s/2}Γ(s/2)f(s) (Fubini on |N|). The variable is s/2, so Mellin inversion reads

  Θ_N(x) = (1/2πi)∫_{(c)} ξ_f(s)x^{−s/2} **ds/2**.

The text drops the factor ½. With the factor in place, the residues Res_{s=1}ξ = 1 and Res_{s=0}ξ = −1 contribute ½x^{−1/2} and −½. That gives exactly the displayed relation Θ_N(x) = x^{−1/2}Θ_N(1/x) + ½x^{−1/2} − ½. The sentence "contribute x^{−1/2} and −1" is wrong by a factor of 2, but the formula is right. **F1 (cosmetic):** insert ds/2.

**Polar data and Θ.** The polar data match the asymptotics of Θ. The pole at 1 with residue 1 corresponds to Θ_m(x) ~ x^{−1/2} as x→0. The pole at 0 with residue −1 corresponds to Θ_m(x) → 1 as x→∞, which is the δ_0 of mass 1. Θ_N(x) = O(e^{−πx}) as x→∞, because supp N ⊂ [1,∞). So δ_0 must carry mass exactly 1, and m must carry both signs of λ, giving 1 + 2Σ_{n≥1}. ✓

**Contour shift.** On σ = c and σ = 1−c, ξ_f decays like e^{−π|t|/4}|t|^{O(1)} (Stirling, and the FE). If s(s−1)ξ_f has finite order, Phragmén–Lindelöf in the strip gives polynomial-times-exponential decay uniformly in the strip. So the horizontal segments vanish and the shift is legitimate. Finite order is enough. Some growth hypothesis is necessary: without one, Hamburger-type statements fail (classical). ✓

**Temperedness.** It is automatic. Absolute convergence at σ = 1+ε gives |N|[1,x] ≤ x^{1+ε}∫λ^{−1−ε}d|N|, so m is a tempered measure. ✓

**Density.** The argument is correct as written. For γ_x(y) = e^{−πxy²}, the difference quotients (γ_{x+h} − γ_x)/h → ∂_xγ_x in 𝒮. Iterating, D kills y^{2k}e^{−πy²} for all k. Polynomials times e^{−πy²} are dense in 𝒮 (the Hermite expansion of a Schwartz function converges in 𝒮), and the even ones are dense in 𝒮_even. D is even, so D = 0. The alternative route via the Laplace transform in t, namely that span{e^{−πty²}: t>0} is dense in 𝒮_even, is equivalent: the Taylor expansion at t = 1 produces the same functions. No gap. ✓

**Converse.** Riemann's argument run backwards. The theta relation, together with the exponential decay of Θ_N at ∞, gives meromorphic continuation, the FE, the polar data and finite order. ✓

**F2 (cosmetic).** In Theorem R's proof, state that m̂_f = m_f is *also* a consequence of finite order. It is, so no change in content.

### (b) Lemma 2: checked line by line

- **Supports.** supp ψ ⊂ [−½−a, ½+a] and supp φ ⊂ [−1−2a, 1+2a]. This is inside (−X,X) ⟺ a < (X−1)/2. ✓ This is where X>1 is used.
- **Parseval.** η = m − 𝖢 is a tempered measure and φ̂ = |ψ̂|² ∈ 𝒮. So ∫|ψ̂|²dη converges absolutely, and ⟨η,φ̂⟩ = ⟨η̂,φ⟩ holds by definition of the distributional transform. ✓
- **Self-duality of η.** η̂ = η, by linearity, since 𝖢 is self-dual (Poisson summation). ✓
- **Carrier of η₋.** On ℝ∖ℤ, 𝖢 = 0, so η = m ≥ 0 there. Hence η₋ is carried by ℤ, and since η = 0 on (−X,X), by ℤ∖(−X,X). The origin is excluded. A continuous part "on ℤ" is impossible, because ℤ is countable and any measure on it is atomic. ✓
- **Zeros of ψ̂.** ψ̂(n) = 0 for n ∈ ℤ∖{0} (sinc). ψ̂(0) = χ̂(0) is irrelevant, because |η|({0}) = 0. ✓
- **Disjoint zero sets.** η₊ is carried by (ℤ∖0) ∪ Z_ℝ(χ̂_j) for j = 1,2. Hence it is carried by (ℤ∖0) ∪ (Z(χ̂₁) ∩ Z(χ̂₂)), and only real zeros matter. Z(χ̂₁) is countable (χ̂₁ is entire and ≢ 0). With χ₂ = e^{2πib·}χ₁ we have Z(χ̂₂) = Z(χ̂₁) + b. Choosing b ∉ Z − Z, a countable set, gives an empty intersection. So mass of η₊ on Z(χ̂₁) ∩ Z(χ̂₂) cannot occur: that set is empty. Complex-valued χ₂ is harmless, because only |ψ̂|² enters. ✓

No gap. The argument is the Cohn–Elkies / Beurling–Selberg band-limited-square device.

### (c) Lemma 3

Correct. m̂ = Σa_ne^{−2πin·} is 1-periodic as a distribution, so m is 1-periodic, which gives a_{n+1} = a_n. Positivity is not used. ✓

### Theorem R: a needed fix

**F3.** Hypothesis (c) says "poles exactly those of ξ (simple poles at 0, 1)". This must state the residues explicitly: Res_{s=1}ξ_f = 1, or equivalently Res_{s=1}f = 1. The FE then forces residue −1 at 0. N({1}) = 1 does **not** fix the residue.

With residue r, the dictionary gives m_f = rδ_0 + N + Ň self-dual. If r ≠ 1, the window does not give m_f = 𝖢 on (−X,X): there is an excess (r−1)δ_0, and Lemma 2 does not apply. The status-table wording "poles exactly those of ξ" already intends this. The theorem statement in §0 should say "with ξ's residues", as the brief does.

With F3: **Theorem R PROVED.**

### (e) Prior art and the reconciliation with Radchenko–Viazovska

All citations below are from memory, with no page checked. They are flagged [mem].

- Hamburger (1921) [mem]: FE + Γ_ℝ + support on ℕ + finite order ⇒ cζ. Lemma 3 is a distributional proof of it.
- Bochner, *Some properties of modular relations*, Ann. of Math. 53 (1951) [mem]: modular relation ⟺ FE for general frequencies. This is Lemma 1.
- Chandrasekharan–Narasimhan, Ann. of Math. 74 (1961) [mem]: the same equivalence in Hecke form.
- Kahane–Mandelbrojt, Ann. Sci. ÉNS 75 (1958) [mem]: the FE with general frequencies admits large solution families. Consistent with the signed f_t.
- Córdoba, *Dirac combs*, Lett. Math. Phys. 17 (1989) [mem]: a positive measure whose support and spectrum are uniformly discrete is a finite combination of shifted combs.
- Lev–Olevskii (Invent./Ann. 2015–2017) [mem] and Meyer (PNAS 2016) [mem] on Fourier quasicrystals.
- None of these, to my recollection, states Theorem R's combination: continuous frequencies allowed, positivity only off ℕ, a gap above 1, no discreteness assumption.

**Radchenko–Viazovska** (Publ. IHÉS 2019) [mem] is not a competitor. Their theorem is uniqueness and interpolation for *even Schwartz functions* from f(±√n) and f̂(±√n). Its dual content concerns linear relations among the point evaluations δ_{√n} and their Fourier transforms (weight-3/2 modular objects). It says nothing about a tempered measure η = η̂ that vanishes on a window and whose support is unrestricted. Such signed η ≠ 0 exist: the G of R163_901 Lemma 2.1 and R164_402 Rem T. So R–V cannot remove the positivity hypothesis, and positivity is genuinely needed in Theorem R. The two settings differ in three ways: test functions versus measures, the √n-lattice versus arbitrary support, and evaluation data versus vanishing on a window.

**Novelty assessment.** Theorem R is a clean and correct rigidity statement. Its ingredients are all classical:
- the Bochner–Hecke dictionary (Lemma 1);
- the Beurling–Selberg / Cohn–Elkies device of a positive band-limited square vanishing on a lattice (Lemma 2);
- periodicity of self-dual lattice measures (Lemma 3, i.e. Hamburger).

I know no reference that states exactly "positivity off ℕ + gap + Γ_ℝ-FE + ζ's residues ⇒ ζ" for arbitrary real (even continuous) frequencies. Proximity to Córdoba's positive-comb theorem and to Kahane–Mandelbrojt makes it plausible that it is folklore or a short exercise for experts. It should be presented as "PROVED; we have not found it stated in this form" and not as a new theorem. Its consequence for RH is nil: Cor R.2's identification wall is correct and honestly stated.

### Thm SA

The cited statement is correct. Akhiezer (*Lectures on Approximation Theory*) and Krein, as presented in Levin's *Lectures on Entire Functions*, show that an entire function of exponential type τ₀ that is ≥ 0 on ℝ and satisfies ∫log⁺Ψ/(1+t²) < ∞ equals SS^#, with S of type τ₀/2 and all zeros in a closed half-plane. [mem for the exact lecture numbers.]

- Ψ is a finite sum of products of PW_T functions, so it has type ≤ 2T and is Cartwright. |S|² = Ψ ∈ L¹, and the Paley–Wiener theorem gives S = Ĥ with H ∈ L²(−T,T).
- The domain is 𝒟_T = {F: ∫log(2+|τ|)|F̂|² < ∞} (R163_401 §1.1). This is exactly ∫log(2+|τ|)Ψ < ∞, which follows from |Ψ| ≤ ½Σ(|Φ̂_i|² + |K̂_i|²). So H ∈ 𝒟_T. ✓
- Step 3: the zero sum depends only on the function Ψ, not on its decomposition. ✓
- Step 4: Cauchy–Schwarz for a semidefinite Hermitian form. ✓

**PROVED.**

### Cor SA.1

**F5 (FIX NEEDED).** Thm SA gives *some* H ∈ E_c with |Ĥ|² = τ²|Φ̂|². Spectral factorisation is not unique (zeros can be flipped), so it does not give zΦ̂ ∈ Ê_c. Use the direct route, which the text mentions only parenthetically:
- W(zΦ̂) = Σ_ρ t_ρ²(Φ̂Φ̂^#)(t_ρ) = W(Φ, z²Φ) = 0, and zΦ̂ ∈ 𝒟̂_T because z²Φ̂ ∈ 𝒟̂_T;
- hence zΦ̂ ∈ Ê_c by step 4.

For the ladder: 𝒟_T is monotone under lower polynomial weights, so z^{2m}Φ̂ ∈ 𝒟 implies z^kΦ̂ ∈ 𝒟 for all k ≤ 2m, and in particular for k ≤ m+1. The functions Φ̂, zΦ̂, …, z^mΦ̂ are linearly independent, which contradicts dim Ê_c = m. ✓ After F5: **PROVED.**

### Prop 4

**Residue.** Write Ψ̌(u) = (1/2π)∫Ψe^{−izu}. For u>2T, close the contour in Im z<0. There |G(z)²e^{−izu}| ≤ Ce^{(2T−u)|Im z|}, and the factor y/(z²+y²) = O(|z|^{−2}) kills the arcs. Then:
- (1/2π)(−2πi) · G(−iy)² · y/(−2iy) · e^{−yu} = ½G(iy)²e^{−yu}, using (−i)(i/2) = ½ and G(−iy)² = G(iy)² by parity. ✓

**Admissibility.** Weil–Barner requires Ψ holomorphic in |Im z| ≤ ½+ε with O(|x|^{−1−ε}) decay uniformly there. The poles of Ψ_y are at ±iy, with y > ½. For ε < y − ½, G is bounded in the strip (Phragmén–Lindelöf; it is in fact rapidly decaying, since it is the transform of a compactly supported function), so Ψ_y = O(|z|^{−2}). ✓ The prime side converges for y > ½. ✓

**𝔄_y.** σ_T contains the window primes (R163_401: σ_T = m − Σ_{𝒩_T}v_ncos(τlog n)). So 𝔄_y does use only window data. ✓

**Sign.** If G is real on ℝ with parity m, then G(iy)² = (−1)^m|G(iy)|². ✓

**PROVED.**
