Referee: analytic number theory (Beurling primes, character sums, mean values). Object: R164_201 §§2–4.

A useful normal form, used throughout: h_n = Σ_{dm=n} d^a g_m = n^a (1 ∗ γ)(n). So h = (d ↦ d^a) ∗ g with g_m = γ_m m^a, and h is multiplicative.

## Item 1: §3.1 integration by parts and boundary terms. FIX NEEDED (R1)

**Checked, correct.**
- B(u) = ∫_0^u(t − ½)dt = (u² − u)/2 on [0,1). ψ has mean 0, so pB({X/p}) is a periodic antiderivative of ψ(X/p). Hence Ψ_p(X) = p(B({X/p}) − B({Y/p})), Ψ_p(Y) = 0, |Ψ_p| ≤ p/4.
- ∫Eφ_p = [EΨ_p]_Y^{2Y} − ∫Ψ_p dE. Ψ_p is continuous, so the Stieltjes integral against the step function A is Σ_{Y<n≤2Y} h_nΨ_p(n). The B({Y/p}) piece gives −pB({Y/p})(ΔA − ΔM) = −pB({Y/p})(E(2Y) − E(Y)). Together with E(2Y)Ψ_p(2Y) this is O(p·max(|E(Y)|, |E(2Y)|)). The sign of the bracket, −p[Σh_nB(r_n/p) − ∫M′B], is correct.

**Logical gap.** The theorem is stated in mean square. The reduction "if sup|E| ≥ Y^{a+κ(½−a)} there is nothing to prove" proves only the Ω-statement (N − ρx ≠ O(x^{θ+δ})). It does not prove the mean-square statement. A large sup does not force a large mean square here. Jumps are ≥ 0, so a large positive value of E propagates only over a length ≍ |E|·Y^{−a}. That gives mean square ≫ |E|³Y^{−1−a}, which is far below the target. "Equivalently" in the statement is also wrong: mean square ⇒ Ω, and the converse does not hold.

**Repair R1 (the boundary only needs |E| at the two endpoints).** Suppose that (1/Y)∫_Y^{2Y}|E|² = R². By Chebyshev, the set where |E| > 4R has measure ≤ Y/16. So there are Y₁ ∈ [Y, 5Y/4] and Y₂ ∈ [7Y/4, 2Y] with |E(Y_i)| ≤ 4R. Run §§3.1–3.4 on [Y₁, Y₂] with Ψ_p based at Y₁. The boundary term becomes O(pR). ΔM over [Y₁,Y₂] is still ≍ Y^{1+a}, and the Gram estimates are unchanged.

Now argue by contradiction with R ≤ Y^{a+κ(½−a)}. The condition pR = o(Y^{1+a}p^{−a}) holds when p^{1+a}Y^{κ(½−a)} = o(Y). Since p ≤ Y^κ, this follows from κ(3/2) < 1, which holds. So the mean-square statement is PROVED as stated, on [Y,2Y]. Delete "Equivalently" and write "In particular".

## Item 2: §3.2 residue distribution. CORRECT (with a sharper bound available, R3)

**Class 0.** h is multiplicative, and Σh_n n^{−u} = ζ(u−a)H(u−a). The p-Euler factor is (1 − p^{a−u})^{−1}H_p(u−a). Removing it gives the relative density of {p ∤ n}:

  (1 − 1/p)/H_p(1),  with  H_p(1) = 1 + ε_p p^{−1−a} + Σ_{j≥2}γ_{p^j}p^{−j} = 1 + ε_p p^{−1−a} + O(p^{−2−2a}),

by Lemma W(ii). So f_0 = 1 − (1 − 1/p)(1 − ε_p p^{−1−a} + O(p^{−2−2a})) = 1/p + ε_p p^{−1−a}(1 − 1/p) + O(p^{−2−2a}). **Verified, including the sign.**

**The error, done exactly.** The p∤n mass up to Z is Σ_{m≤Z, p∤m} g_m S_a^{(p)}(Z/m), where S_a^{(p)}(T) = S_a(T) − p^aS_a(T/p) = (1−1/p)T^{1+a}/(1+a) + O(T^a + p^a) by (2.2). The error is therefore ≪ Σ_m |g_m|(Z/m)^a + p^aΣ_{m≤Z}|g_m| ≪ Z^aΣ_{m≤Z}|γ_m| + p^aZ^{a}Σ|γ_m| ≪ p^aZ^{1+ε}, by Lemma W(iv). The tail m > Z of the main term is ≪ Z^{1+ε} by the same lemma. The cited ≪ pY^{1+ε} is a valid (weaker) bound. The main term is expressed with ΔM directly, so no use of E is hidden here.

**Nonzero classes.** For a character χ mod p, h_nχ(n) = Σ_{dm=n}(d^aχ(d))(g_mχ(m)), because χ is completely multiplicative. g is exactly γ_m m^a, the coefficients of F·G in the variable w + a (R163_803 §2). Pólya–Vinogradov gives Σ_{d≤T}χ(d) ≪ √p log p. Partial summation gives Σ_{d≤T}d^aχ(d) ≪ T^a√p log p. Hence

  A_χ(Y) ≪ √p log p · Σ_{m≤2Y}|g_m|(Y/m)^a = √p log p · Y^aΣ_{m≤2Y}|γ_m| ≪ p^{1/2+ε}Y^{1+ε}. **Verified.**

**Is class uniformity enough? Required error.** The main term of ⟨E,φ_p⟩ is (ΔM/12)ε_pp^{−a} ≍ Y^{1+a}p^{−a}. The proof needs Σ_r(mass_r − f_rΔM)B(r/p) = o(Y^{1+a}p^{−1−a}), because of the outer factor p.
- Each class deviation is bounded by max_χ|ΔA_χ| and sums p classes. This gives an error p·p·p^{1/2+ε}Y^{1+ε} = p^{5/2+ε}Y^{1+ε} in ⟨E,φ_p⟩.
- That is o(Y^{1+a}p^{−a}) iff p^{5/2+a} ≪ Y^{a−ε}, i.e. κ < a/(5/2+a). **Verified.** So "uniform up to PV" is exactly what the stated range needs. No finer uniformity is required inside that range. The finer uniformity is precisely the missing input of L\*, as §3.5 says.
- Class 0 adds p·p^aY^{1+ε}, which is dominated.

**Sharper bound (R3, optional).** Expand by characters. The contribution of the non-principal characters is (1/(p−1))Σ_{χ≠χ₀}ΔA_χ·B̂(χ̄), where B̂(χ) = Σ_rχ(r)B(r/p).
- B(1−t) = B(t), so B̂(χ) = 0 for odd χ.
- For even χ, B = ½B₂ − 1/12 and B₂(t) = Σ_{k≥1}cos(2πkt)/(π²k²). Hence B̂(χ) = (τ(χ)/(2π²))Σ_kχ̄(k)k^{−2}, so |B̂(χ)| ≤ √p/12.

The error in ⟨E,φ_p⟩ is then p^{2+ε}Y^{1+ε}, and the range improves to κ < a/(2+a). This is not needed for the theorem.

## Item 3: §3.3 the main term. CORRECT

- (1/p)Σ_{r=0}^{p−1}B(r/p) = (1/(2p))[(p−1)(2p−1)/(6p) − (p−1)/2] = −(p²−1)/(12p²) = −1/12 + 1/(12p²). ∫_0^1B = −1/12.
- With f_0 = 1/p + η and f_r = 1/p − η/(p−1) for r ≠ 0, and B(0) = 0:
  Σf_rB(r/p) = (−1/12 + 1/(12p²)) − (η/(p−1))·p·(−(p²−1)/(12p²)) = −1/12 + 1/(12p²) + η(p+1)/(12p).
  **Sign verified.** The excess in class 0, where B = 0, removes mass from classes where B < 0, so the sum goes up.
- ∫_Y^{2Y}M′B({X/p}) = −ΔM/12 + O(pY^a). Multiplying by −p gives ⟨E,φ_p⟩ = −(ΔM/12)[1/p + η(p+1)] + O(p²Y^a) + …, and η(p+1) = ε_pp^{−a}(1 − p^{−2}) + O(p^{−1−2a}). **Verified.**
- Sanity check against Franel: E ≈ −X^aΣγ_mψ(X/m) gives ⟨E,φ_p⟩ ≈ −Y^{1+a}(2^{1+a}−1)γ_p/(12(1+a)). This has the same sign and size as above, with H(1) ≈ 1.

## Item 4: §3.4 Bessel and the exponents. CORRECT

- For primes p ≠ q, ψ(X/p)ψ(X/q) has period pq and mean gcd(p,q)²/(12pq) = 1/(12pq) (Franel). An interval of length Y contains complete periods plus a remainder of length < pq, and |ψψ| ≤ ¼. So the entry is Y/(12pq) + O(pq), and the diagonal is Y/12 + O(p).
- G = (Y/12)[I − diag(v²) + vvᵀ] + R with v_p = 1/p, and ‖R‖ ≤ ‖R‖_F ≪ Σ_{p≤P}p² ≪ P³. So λ_max ≤ (Y/12)(1 + Σp^{−2}) + O(P³) < Y/4 once P³ = o(Y). This needs κ < 1/3, and that is implied by κ < a/(5/2+a) < 1/6.
- Bessel: Σ|⟨E,φ_p⟩|² ≤ λ_max‖E‖².
- Primes with ‖p^a‖ ≥ ¼ and p ≥ p₀(a) satisfy |ε_p|p^{−a} ≥ p^{−a}/4 > 2/p, so no cancellation with the 1/p term. Then ‖E‖²/Y ≫ Y^{−2}·Y^{2+2a}Σp^{−2a} ≫ Y^{2a}P^{1−2a}/log P.
- So E_rms ≫ Y^{a+κ(½−a)}(log Y)^{−½}. Since Y^a = x^θ and Y = x^{1−θ}, we get N − ρx ≠ O(x^{θ+δ}) for δ < (1−θ)κ(½−a).

**Explicit δ(θ)** (absent from R164_201):
- With κ ↑ a/(5/2+a), δ(θ) = θ(1−3θ)/(5−3θ).
- With R3, δ(θ) = θ(1−3θ)/(2(2−θ)).
- In both cases δ(θ) → 0 as θ → 1/3 and as θ → 0.

## Item 5: Lemma W and the equidistribution citation. W(i)–(iv) CORRECT; citation FIX NEEDED

**W(i).** c_1(q) = q, and ζ_𝒫/ζ(w) = Π(1−z^k)^{−(b_{p,k}−c_{p,k})}. So the p^{−w} coefficient is (b_{p,1} − p^a)p^{−a}. Correct for any integer b.

**W(ii)–(iii).** |binom(ε+i−1,i)| ≤ binom(C+i−1,i) for |ε| ≤ C, so the majorant is Π_k(1−z^k)^{−C} times the finite F-factor. It is analytic in |z| < 1 and has subexponential coefficients. Correct, with constants depending on C.

**W(iv).** Rankin with σ = 1−a+ε gives Σ|γ_m|m^{−σ} ≤ Π_p(1 + Cp^{−1−ε} + O(p^{−2a−2σ}(1+η)²)) < ∞. Correct. The truth is X^{1−a}(log X)^{O(C)}.

**The positive proportion of p with ‖p^a‖ ≥ ¼.**
- The short-interval route as written is defective. The bad set is a specific union of intervals of length ≍ P^{1−a}. "PNT in almost all intervals of length P^{1/6+ε}" (Huxley 1972; Zaccagnini) is a measure statement, and it does not apply to a prescribed family without an extra argument.
- A correct elementary route exists for part of the range. Baker–Harman–Pintz (2001) give π(x+y) − π(x) ≫ y/log x for all y ≥ x^{0.525}. This covers a ≤ 0.475, i.e. θ ≤ 0.322.
- For the full range 0 < a < ½, cite uniform distribution of p^c mod 1 for non-integer c > 0. **From memory:** I. M. Vinogradov for 0 < c < 1, in his trigonometric-sum work of the 1940s (book: *The Method of Trigonometrical Sums in the Theory of Numbers*). Stux (1975) and Leitmann (1977) treat the general non-integer c > 1. The exact original references are **not verified** here.
- Label: **PROVED-CITED (citation from memory)**. Equidistribution gives the proportion ½, which is more than enough.

## Item 6: Theorem L\* and Lemma D. L\* ARGUED confirmed; Lemma D FIX NEEDED (R2)

**L\*.** The missing input is the residue equidistribution of h_n mod p with error o(Y^{1+a}p^{−1−a}) for p up to Y^{1−ε}. That is square-root cancellation in Σh_nχ(n) for large conductor, roughly the statement itself. The large-sieve claim (reaching p ≈ Y^{1/2}) is not written out. **ARGUED** confirmed. The "sharpness" remark (it matches Theorem C's upper bound max(θ,(1−θ)/2)) is also ARGUED.

**Lemma D as written is false term by term.** If {p^a} ≈ p^{a−1} and one rounds down, then ε_pp^{−a} ≈ −1/p, and the bracket ε_pp^{−a}(1−p^{−2}) + 1/p can vanish. The proof only gives |u+v|² ≥ u²/2 − v².

**Repaired statement (PROVED in 𝒦_θ(C)).** For Y → ∞ and P ≤ Y^κ with κ < a/(5/2+a):

  (1/Y)∫_Y^{2Y}|E|²  ≫  Y^{2a}[ Σ_{p≤P}‖p^a‖²p^{−2a} − K ],

with K = O(Σ_p p^{−2}) absolute. The implied constants depend on θ and C, and P must be in the stated range.

**The tests.**
- "Passes ζ_θ" is only a consistency check. ζ_θ has non-integer masses, so it is outside 𝒦_θ. Setting ε = 0 makes the right side ≤ 0, so the test cannot fail. It does not discriminate anything.
- The θ > 1/3 test is likewise only consistency.
- The conclusion that Lemma D is zero-blind and gives no RH step is **confirmed**.

## Item 7: scope and the "threshold" claim. FIX NEEDED (R4)

**What 𝒦_θ(C) covers.** All systems on the lattice {p^{k/(1−θ)}} with base ζ(w) and |b_{p,k} − c_{p,k}| ≤ C.
- 𝒦_θ(1) already contains every rounding (floor, ceiling, random, dependent, greedy).
- Finitely many large deviations are covered by enlarging C.
- **Not covered:**
  - (a) unbounded deviations on a sparse set of (p,k), e.g. |ε_{p,k}| ≍ p^{η} or ≍ log p. W(iv) and the O(p^{−2−2a}) in W(iii) then fail as stated. The proof survives deviations ≪ p^{η} for small η, with a loss in κ, but this is not written.
  - (b) off-lattice points (O164.201a).
  - (c) the same points with a different base Dirichlet series.
- It is **not proved** that a lattice system with error O(x^{θ+δ}) must have bounded deviations. So "every system on the Witt lattice" would overstate the result. "Every bounded-deviation rounding of the Witt counts" is accurate. The definition in §2 states this correctly, and the scope statement O164.201a is accurate in that sense.

**What Theorem L proves about 1/3.** For θ < 1/3, no system in 𝒦_θ reaches error exponent θ + δ(θ). For θ > 1/3, Theorem C reaches θ + ε. So 1/3 is a genuine **qualitative** threshold: below it the construction cannot attain its natural exponent θ. That is PROVED.

**What Theorem L does not prove.** It does not prove that the error is ≥ x^{1/3}. θ + δ(θ) < 1/3 throughout (0, 1/3); for example, at θ = 0.3 the bound is x^{0.3+0.0028}. So:
- Row 9 of R164_201, the grid cell 5G phrase "counterexample must be off-lattice", and "By Theorem L/L\*" in O164.201a all rest on **L\*** and are **ARGUED**, not PROVED.
- Theorem L alone leaves open a 𝒦_θ system with error x^{θ′}, θ + δ(θ) ≤ θ′ ≤ 1/3.
- Whether such a system could have an off-line zero is a separate question. The zeros of ζ(w) sit at Re s = (1+θ)/2 < (1+θ′)/2, so they are harmless. Zeros of H are not controlled by anything in R164_201.

**Required rewording of row 6, row 9 and cell 5G:** "1/3 is a threshold for attaining error exponent θ within 𝒦_θ (PROVED); 1/3 is a floor x^{1/3} for the error within 𝒦_θ (ARGUED, = L\*); Problem 6 counterexamples must be off-lattice (ARGUED, via L\*)."
