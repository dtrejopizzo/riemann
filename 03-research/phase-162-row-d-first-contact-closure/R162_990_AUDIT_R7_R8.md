## R162_703

**Lemma 2.1: CORRECT.**
- Extension by zero preserves ℓ_par, because φ_par restricted to I_T is the same function.
- It preserves the norm and A, B.
- It preserves a_T. For G, F supported in I_T, the cross-correlation vanishes on |u| ≥ 2T, and the new
  contacts have log n ≥ 2T (lem:monoT). This includes log n = 2T, where c_F(2T) = 0 by continuity.
- thm:parityschur(a3) needs λ_par > 0 at both T and T′. The hypothesis "on an interval" supplies this.
- Remark: Thm 2.2(1)–(2) do not actually need Lemma 2.1. Monotonicity of λ_W (lem:monoT) together with
  thm:parityschur(c) at T₁ already suffices.

**Thm 2.2: CORRECT WITH FIXES.**
- (1) and (2) are correct.
- Resolvent form: h = A⁻¹φ/f(0) needs f(0) ≠ 0. This must be stated. It follows from λ_par > 0: if
  f(0) = 0, then A⁻¹φ ∈ Q and a(A⁻¹φ, G) = ⟨φ, G⟩ = 0 on Q, which is a kernel vector of a|Q.
- a(h) = ⟨φ, A⁻¹φ⟩/f² = 1/f. Checked.
- (ev): if μ₁ < 0, then f(0) < 0. This needs ⟨ψ₁, φ⟩ ≠ 0, which holds: otherwise ψ₁ ∈ Q with a < 0,
  contradicting λ_ev > 0. With that, f increases from −∞ at μ₁⁺ to its zero λ_ev > 0, so f(0) < 0.
  Then g_ev = 1/f + 2 ≥ 0 ⟺ f ≤ −½. Checked.
- (odd): g ≥ 0 ⟹ W_odd ≥ 0 ⟹ A ≥ 2φφ* ≥ 0 ⟹ f > 0 (using 0 ∉ spec) ⟹ 1/f ≥ 2 ⟺ f ≤ ½. Checked.
- Compact resolvent of A^par is used implicitly, for discrete μ_k. Cite the logarithmic growth of m for this.

**Prop 4.1: WRONG as an "iff".**
- Type I ⟹ 0 ∈ spec A^par: correct.
- The converse direction is false for individual vectors. The proof's own computation shows this:
  - if E ∈ ker A^par and F is Type II, then E ⊥ φ;
  - so E is a *further* element of 𝒩 with α(E) = 0;
  - the kernel 𝒩 can therefore contain a Type II vector F and a Type I vector E at the same time.
  The proof then retreats to "the clean statement".
- Correct replacement:
  - (i) α ≡ 0 on 𝒩 ⟺ 𝒩 ⊂ ker A^par. This is immediate: α(F₀) = 0 ⟺ a(F₀, ·) ≡ 0.
  - (ii) 0 ∉ spec A^par ⟹ 𝒩 = ℝA⁻¹φ and every first-contact vector is Type II.
  - (iii) A Type I vector ⟹ 0 ∈ spec.
- The even reading should say: μ₂^ev = 0 = λ_ev ⟹ a Type I vector *exists*. The reason is that the
  eigenvector E of μ₂ must satisfy E ⊥ φ, since otherwise the zero of f in (μ₁, μ₂) would be < 0. It does
  not follow that every contact vector is Type I.
- Theorem 4.2 and §4 do not use the false direction.

**Thm 4.2: CORRECT WITH FIXES.**
- (1): {λ_A < 0} ⊂ {λ_W < 0}. Correct. T_* < ∞ under ¬RH by Weil's criterion with primitive tests.
- (2): correct.
  - R162_504 Thm 3 gives α ≠ 0, so λ_W(T_*) < 0.
  - lem:contT then gives T_W < T_*.
  - lem:monoT gives λ_W < 0 on (T_W, T_*].
  - The appeal to "λ_W > 0 on (0, ½log5]" is irrelevant here. It only gives T_W > ½log5.
- (3): **gap.** "λ_A(T_W) > 0" does not follow from T_W < T_* := inf{λ_A < 0}. Only λ_A(T_W) ≥ 0
  follows, since a nonincreasing λ_A can touch 0 and stay there. Two fixes are possible:
  - (a) state λ_A(T_W) ≥ 0, and treat λ_A(T_W) = 0 by thm:parityschur(b) with the range condition;
  - (b) redefine T_* := inf{λ_A ≤ 0}.
  The rest of (3) is correct: λ_W(T_W) = 0 by continuity, 𝔊 ⪰ 0 but not ≻ 0, and the radical is
  span{h_par : g_par = 0}, which has dimension n₀(𝔊) and lies outside P since ℓ(h) = 1.
- (4): correct.
  - λ_W(T_*) ≥ 0 by left continuity.
  - λ_W(T_*) ≤ λ_A(T_*) = 0 by lem:contA.
  - thm:parityschur(c) then gives the range condition.
  - "Type I" follows directly from the range condition (α ≡ 0 ⟹ r = 0). It does not need Prop 4.1.
- Side remark on Paper 47 thm:parityschur(b): "W_T unbounded below on D^par" cannot be literal, since W is
  a_T plus a rank-one term and is bounded below. It should read "unbounded below on {ℓ_par = 1}", or
  simply "λ_W < 0". This should be fixed in the paper.

## R162_802

**Thm 2.1: CORRECT.**
- r|_{I_T} = 0 by extension compatibility.
- r(ũ) = a_T(u,u) − ⟨φ,u⟩ = 0.
- ũ − u′ = A_{T′}⁻¹r.
- f(T′) − f(T) = −r(u′) = ⟨A_{T′}⁻¹r, r⟩.
- r lies in the dual of the form domain, and A_{T′}⁻¹ extends to that dual. Every step is exact.

**Cor 2.2: not proved as written.**
- The Schur identity (A_{T′}⁻¹)_CC = S_C⁻¹ is correct, since A_II = A_T is invertible.
- But "S_C > 0 for small δ" ignores the coupling term A_CI A_T⁻¹ A_IC. The collar is adjacent to I_T and
  the kernel is singular on the diagonal, so this term is not controlled by the log(1/δ) bottom.
- The monotonicity itself is nonetheless rigorous by a different route, on intervals where A_T is
  invertible and λ_par > 0:
  - 703 Lemma 2.1 gives 1/f + 2ε nonincreasing;
  - f cannot vanish there (see above), so f is nondecreasing.
- Replace the S_C argument by this one.

**§3.1: CORRECT WITH FIXES.**
- Monotonicity of f is established only while λ_par > 0. After a contact, nothing is known.
- The pole behaviour needs a transversal simple crossing with ⟨ψ_k, φ⟩ ≠ 0.
- "f passes through 0 exactly at Type II contacts" holds for the *first* zero only. Later zeros are
  interior compression eigenvalues crossing 0.

**§3.2: CORRECT WITH FIXES.**
- The bordered-matrix count is In([[A,φ],[φ*,0]]) = In(A) + In(−f) = In(A|Q) + (1,1,0). This gives
  ι = N₋ − 𝟙[f<0] whenever A is invertible and f ≠ 0. Checked.
- Conservation across a crossing needs ⟨ψ_k, φ⟩ ≠ 0. A crossing with ψ_k ∈ Q is a Type I event: ι jumps
  while f stays finite.
- "λ_par > 0 ⟺ ι = 0" needs f ≠ 0 and 0 ∉ spec A, both of which are among the standing hypotheses.

**§3.3: CORRECT WITH FIXES.**
- The even-branch argument is valid for Type II contacts. f < 0 increases after T_P and must hit −½
  before 0. It also cannot reach a μ₂ pole before hitting 0.
- It does not see Type I contacts.
- T_W ≤ T_* holds in general by λ_W ≤ λ_A in one line, so the "recovery" is a consistency check, not a proof.
- The odd-branch statement is correct and new: T_W^odd ≤ the first odd crossing with nonzero overlap.

**§3.4: WRONG as stated.**
- (⇐) The proof invokes ι ≡ 0, which is not among (i), (ii). ι ≡ 0 for all T means a_T ≥ 0 on P_T for
  all T, which *is* RH by Weil's criterion. So with ι ≡ 0 assumed, the direction is circular.
- With only (i) and (ii), the monotonicity of f is unavailable after a possible contact, since it was
  established only for λ_par > 0. A Type I contact is invisible to f altogether. A condition on the
  limit alone therefore does not exclude a contact followed by a return.
- "Both limits exist by monotonicity" also presupposes (i) together with ι ≡ 0.
- (⇒) is conditional on R162_504 Cor 2.1. It also needs μ₂ > 0 strictly (for no poles) and a strictly
  decreasing μ₁ (for a unique T_P).
- Correct salvage: replace the limit condition (ii) by the pointwise condition "f_ev(T) ≤ −½ for all
  T > T_P and 0 < f_odd(T) ≤ ½ for all T". But that is g_par ≥ 0 for all T, which is Thm 2.2 of 703
  restated.
- Recommendation: downgrade §3.4 to a heuristic reformulation and remove the label PROVED.

**Theorem G: CORRECT WITH FIXES.**
- Translation integral, checked by hand. Substitute t = x − L/2, which gives
  max(|t+L|, |t|) = |x| + |L|/2. Then

  ∫ e^{αt} e^{−2s max} dt = e^{−αL/2 − s|L|} · 4s/(4s² − α²),   |Re α| < 2s.

  With the factor e^{zL}, the exponent is e^{βL − s|L|}. So L > 0 gives H(s−β) and L < 0 gives H(s+β).
  The prefactor becomes (1/s)·4s/(4s² − α²) = 4/(4s² − α²). Checked.
- Normalisation of H, using Paper 47's kernel k_W (whose Fourier transform is 𝔰_T plus the polar term):
  - arch: 2Re H_∞(−iτ) = m(τ), which gives H_∞(u) = ½ψ(¼ + u/2) − ½log π;
  - comb: −Σ w_n n^{−u} = +ζ′/ζ(½+u);
  - polar: ∫_0^∞ 2cosh(L/2) e^{−uL} dL = 1/(u−½) + 1/(u+½).
  So H(u) = ξ′/ξ(½+u) **exactly**, with ξ(s) = ½s(s−1)π^{−s/2}Γ(s/2)ζ(s). No normalisation is needed.
- Sign typo: the text says "the comb gives ΣΛ n^{−½−u} = −ζ′/ζ". The comb enters with a minus sign and
  contributes +ζ′/ζ(½+u).
- **The constant c.** In the pairing ⟨Φ(s)e_{iτ′}, e_{iτ}⟩, c = 1, and P_s(x) = 4/(4s² + x²). The
  written P_s = 4s/(4s²+x²)·(1/s) is the same thing. In the Fourier kernel of Φ[F] with Paper 47's
  convention F̂(τ) = ∫F e^{iτt}, one has Φ[F] = (2π)^{−2} ∫∫ K F̂(τ′) conj(F̂(τ)), so c = (2π)^{−2}. The
  sign flip e_{−iτ} is harmless because Re ξ′/ξ(½+s+iσ) is even in σ.
- Region: s > ½ for both the comb and the polar Laplace integral. Correct.

**Theorem H: CORRECT WITH FIXES.**
- (i) is correct: a positive mixture of W_T(1_{I_T}F) ≥ 0 under RH, via lem:roughEF.
- (ii) The wave-packet limit is unnecessary. For tests in t > 0, K_s = e^{−s|t−t′|}, and W∘K_s is
  translation-invariant. So positivity on C_c(0,∞) is positivity on C_c(ℝ), and hence the continuous
  symbol 2Re ξ′/ξ(½+s+iσ) is ≥ 0 pointwise.
- The objection: for s > ½, i.e. Re u > 1, the conclusion Re ξ′/ξ(u) = Σ_ρ Re 1/(u−ρ) > 0 holds
  **unconditionally**, because Re ρ < 1. So the PROVED range carries no information.
- The equivalence "Φ(s) ≥ 0 ∀s ⟺ RH" needs 0 < s ≤ ½. There it is PARTIAL.
- Suggested repair route: Bochner–Schwartz. A PD distribution k_W e^{−s|u|} is tempered, and its
  transform is a positive measure. This measure would then need to be identified with the continuation
  of 2Re ξ′/ξ.
- Relabel "Hence ⟺ RH" as EQUIV-conditional.
