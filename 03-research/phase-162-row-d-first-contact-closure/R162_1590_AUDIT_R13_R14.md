### Script `scripts/c3/q1402_float_Q.py`: a gross error

The Legendre Fourier transforms, the prefactor 2T/π·√(2a+1)√(2b+1)·(−1)^{(b−a)/2}, V_n, m(τ) and the Tate constraint are all correct. The contacts n ∈ {2,3,4} are right for T ≤ 0.8047 < ½log5, although Lam() only knows primes ≤ 7, which is fine here.

**Tail bug.** For large x, j_a j_b(x) ≈ ½(−1)^{(a−b)/2}/x². So the tail must be added as `sign*tail`, and the prefactor's `sign` then squares to +1. The script adds `abs(sign)*tail`. As a result, the tail enters A with the wrong sign on every pair with (b−a)/2 odd. This makes the high-frequency tail form indefinite, at size ~10^{−3}–10^{−2}, which is far above the reported λ.

I re-ran scratch copies with the fix (and also with no tail at all; both agree to about 1%):

| T, sector | λ as published | λ, tail fixed | λ, no tail |
|---|---|---|---|
| 0.50 ev | 2.5e−2 | 1.19e−2 | 1.18e−2 |
| 0.65 ev | 1.5e−2 | 2.40e−6 | — |
| 0.70 ev | 1.3e−3 | 5.94e−8 | — |
| 0.78 ev | 3.2e−6 | 6.14e−11 | 6.08e−11 |
| 0.8047 ev | 4.4e−7 | **6.65e−12** | 6.59e−12 |
| 0.8047 odd | 2.5e−5 | 1.05e−9 | 1.03e−9 |

What this does to the file:
- The fixed λ at ½log5 (6.6e−12) is the same order as the certified ≈2.5e−12 (R162_303). The file's explanation of the discrepancy as "not converged" is wrong: it is the bug.
- Q_m is 10^4–10^5 larger than the table. The fixed values at 0.8047 ev are Q₁ = 1.1e10, Q₂ = 2.1e11.
- **The gs dips at 0.65 (even) and 0.70 (odd) disappear** (gs = 1.000 with the fix). The F1 observation "x_m(ψ_T) ≈ 0 does occur for λ > 0" is an artefact and must be deleted.
- Monotonicity of Q in T still holds.

**"ψ_T carries O(1) Gamma data."** With the fix, |x_m(ψ_T)|²/‖e_m‖² = gs·λ·Q/‖e_m‖² ≈ 0.08 (m=1) and 0.04 (m=2) at 0.8047 ev, 0.09 at 0.8047 odd, and 0.09 at 0.78 ev. So the claim is **qualitatively supported** (stable and non-vanishing, of order 10^{−1}). The stated range "0.2–1" is not supported. The float run is still uncertified, and a finite T-range cannot say anything about the rate as T ↑ T_*. Replace the table with the fixed run and state the ratio as ≈ 0.04–0.09.
