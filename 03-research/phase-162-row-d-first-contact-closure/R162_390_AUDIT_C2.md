# R162_390 — audit report on R162_302 (C2 coefficient law)

Scope: R162_302 §1, §4, §5 (and the parts of §2–§3, §6 they use). Checked against
Paper 47: eq:symbol, eq:form, eq:Aform, lem:degen, lem:contA, lem:firstcontact, sec:firstcontact
(R, K_F(a), a_m = 2m+1/2, b_m = sqrt(a_m) e^{-a_m(T+δ)}, eq:Gammaenergy).

**Verdict: CORRECT WITH FIXES.** Lemma 4.1 is correct: the sign and the parity factor ε are right.
Lemma 1.1 is correct as a Danskin/Kato statement. One sentence about the tangent cone needs a
Slater hypothesis. Proposition 5.1 is valid and holds for EVERY kernel vector of parity ε. It
actually needs less than (A): the weaker (5.1) suffices. Four statements in §5–§6 are wrong as
written: "(5.1) ⇔ (A)", "(B) contains no Λ", the ε in the α = 0 remark, and the DH argument
built on "(B) is common to both". None of them breaks the implication.

## Checks passed

1. **Lemma 4.1 (sign and ε).** ∫c_F(s)cosh(as)ds = ½[K_F(-a)K_F(a) + K_F(a)K_F(-a)] = K_F(a)K_F(-a).
   K_F(-a) = ∫e^{at}F(t)dt = ∫e^{-at}F(-t)dt = εK_F(a). So K_F(a)^2 = ε∫c_F cosh(a·).
   Weighting by b_m^2 = a_m e^{-2a_m(T+δ)} gives ||R_L F||^2 = ε⟨c_F, κ_L⟩, with κ_L exactly as
   stated. The window is T = T_*. supp c_F ⊂ [-2T, 2T], and κ_L is smooth, so the pairing is an
   ordinary integral. The identity holds for every real G of parity ε, not only for kernel vectors.
   Consequently ε⟨c_G, κ_L⟩ ≥ 0 on the ε-class and ≤ 0 on the (-ε)-class. There is no sign error.

2. **Lemma 1.1.** B_w is bounded with ||B_w|| ≤ Σ|w_n|, because |⟨V_bF, F⟩| ≤ ||F||^2 under
   compression. 0 = min spec H_{T_*} is isolated with finite multiplicity (compact resolvent).
   Analytic perturbation, or directly Danskin for the concave infimum of affine functions in
   lem:degen, gives V'(v^0; w) = min_{F ∈ K_*, unit, real} (-Σ w_n c_F(log n)). The quadratic form
   is real and J-commuting, so the real minimum equals the complex one.

3. **Prop 5.1: "for some" versus "for every".** The step
   0 ≤ V(v^0 + tα) ≤ -tΣα_n c_F(log n) uses lem:degen's inequality V(v) ≤ a^{(v)}(F_★). That
   inequality holds for every real unit F in the form domain of P_T with a^{(v^0)}(F) = V(v^0).
   It is simply V(v) ≤ (the affine function of F). Every F ∈ K_* is such a minimizer, since
   V(v^0) = 0 and K_* ⊂ P_{T_*} lies in the form domain. So (A) gives Σα_n c_F(log n) ≤ 0 for
   EVERY F ∈ K_*, not merely for the minimizing F of Lemma 1.1. The min in Lemma 1.1 says the same
   thing: V'(v^0; α) ≥ 0 ⇔ min_F(-Σα c_F) ≥ 0 ⇔ Σα c_F ≤ 0 for all F. The logic is valid.

4. **The final line of the proof.** ||R_L F||^2 = ⟨c_F, εκ_L⟩ = 2Σα_n c_F(log n) - β a_T(F) - ⟨c_F, p⟩.
   The atom convention is correct: ⟨c_F, δ_b + δ_{-b}⟩ = 2c_F(b), because c_F is even and
   continuous. a_T(F) = 0 on the radical, so β drops out and ||R_L F||^2 ≤ 0.

5. **Lemma 2.1** is correct: c_F(±2T) is an integral over a null overlap. Lemma 3.1 is correct
   (Möbius inversion).

## Issues

**I1 (MAJOR, statement): "(5.1) is equivalent to (A)" is false. (A) is also stronger than needed.**
(A) ⇒ V'(v^0; α) ≥ 0 ⇔ (5.1). The converse fails when V'(v^0; α) = 0, because the second-order
term can be negative; this is exactly the degenerate direction. The proof of Prop 5.1 only uses
(5.1).
*Fix:* replace (A) by (A′): V'(v^0; α) ≥ 0, i.e. Σα_n c_F(log n) ≤ 0 for all F ∈ K_*. Record
(A) ⇒ (A′) and not the converse. §6 "F2/F4: (A) is a superlevel condition" should then refer to
(A′), which is the closed dual cone of the superdifferential.

**I2 (MAJOR, claim): "(B) contains no Λ" / "(B) is archimedean and common to all systems" is false
as written.**
σ̌_{T_*} is the kernel of the full symbol:
σ̌ = C_0 δ_0 + (Lévy finite part) - Σ_n (v^0_n/2)(δ_{log n} + δ_{-log n}).
It therefore contains the Λ comb whenever β ≠ 0. Two equivalent corrections are possible:
- Reparametrize with α′ = α + (β/2)v^0. Then (B) becomes Λ-free:
  εκ_L = Σα′_n(δ_{log n} + δ_{-log n}) - β(C_0δ_0 + Lév) - p.
  The Λ-dependence moves into (A′), which now reads: α′ - (β/2)v^0 ∈ Tan(v^0).
- Alternatively, keep (B) as stated and say it depends on v^0 through β.

The §6 F3/Davenport–Heilbronn paragraph ("(B) is common to both, so the failure must sit in (A)")
must be redone on the reparametrized pair. The split of responsibility is not by (A)/(B) but by
(α′, β) jointly.

**I3 (MODERATE, precision): the meaning of the positivity of p.**
(B) is used only through ⟨c_F, p⟩ ≥ 0 for F ∈ K_* of parity ε. The needed and correct hypothesis
is: ⟨c_G, p⟩ ≥ 0 for every real G ∈ P_{T_*} in the FORM DOMAIN with JG = εG. "Parity class of
P_T" must mean the J = ε eigenspace of P_T, not the even functions c_G (every c_G is even).
Complex G only enter through Re c_G. Using (B) as an identity of functionals, it is equivalent to
the operator inequality on P_{T_*}^ε:

    2 Σ_n α_n Re V_{log n} - β H_{T_*} - R_L^* R_L ≥ 0 (as forms).                (B′)

Prefer (B′). It has two advantages:
- it removes all distributional bookkeeping;
- it can be restricted to K_*, or to any subspace containing it.

**I4 (MODERATE, distributional pairing).** "p an even distribution on [-2T, 2T]" is not literally
right, for two reasons:
- The Lévy part of σ̌ is a finite-part functional on all of R (kernel K(u) near 0, and not
  compactly supported).
- c_G is only continuous with log-finite energy, not smooth, so ⟨c_G, σ̌⟩ is defined only as
  C_0 c_G(0) + Lev(c_G) - Σ v_n c_G(log n), per eq:Aform.
*Fix:* define all pairings on the cone {c_G : G in the form domain of P_T} via eq:Aform, and read
(B) modulo functionals that vanish on functions supported in [-2T, 2T]. With that reading,
⟨c_F, σ̌_T⟩ = a_T(F) holds exactly (eq:Aform with ||F|| = 1, C_0 c_F(0) = C_0||F||^2). The atoms
at ±log n are fine because c_F is continuous. The atom at n = e^{2T} is excluded (N_T is strict),
and in any case c_F(2T) = 0.

**I5 (MINOR): the α = 0 remark has a spurious ε and a circular "false".**
With α = 0, (B′) reads |β|·a_T ≥ ||R_L·||^2 on P^ε, and this forces β < 0. No ε appears, because
ε is already absorbed in Lemma 4.1. "That spectral gap is false at a contact" is tautological: it
fails iff a contact vector with R_L F ≠ 0 exists, which is the conclusion. The motivation for atoms
should instead be stated as "α = 0 makes (B) equivalent to Gate 1".

**I6 (MINOR): the tangent cone in Lemma 1.1.** {w : V'(v^0; w) ≥ 0} equals the closure of the
tangent cone of 𝒱 = {V ≥ 0} at v^0 only under a Slater point, i.e. some v with V(v) > 0. Such a
point exists iff v^0 is not a global maximizer of V with value 0; compare the degenerate case of
lem:degen. Without it, only Tan ⊆ {V' ≥ 0} is guaranteed. Add the hypothesis, or state the cone
as {V'(v^0; ·) ≥ 0}. That set is all Prop 5.1 needs.

**I7 (MINOR): Lemma 4.1 → (4.1) "by faithfulness of R".** R_L (m ≤ L) is not faithful; only the
full R is. (4.1) ⇔ R_L F = 0 is trivial, since the left side is ||R_L F||^2 ≥ 0. Getting F = 0
needs either L = ∞ or the stated injectivity on K_*. Because dim K_* < ∞, some finite L suffices,
but L is not explicit. Say so.

## Is (B) trivially impossible? No.

- **Sign of β.** Test (B′) on G ∈ P^ε built from functions of support width < log 2. For these,
  c_G(log n) = 0 for all n, and the Tate constraints leave an infinite-dimensional space. (B′)
  then gives -β a_T(G) ≥ ||R_L G||^2. Such G can be highly oscillating with a_T(G) → +∞, so
  **β ≤ 0 is forced**, and β < 0 unless R_L vanishes on them, which does not happen. State this.
- **Finite dimensionality.** With β < 0, |β|H is unbounded positive with compact resolvent, while
  B_α and R_L^*R_L are bounded (the second is finite-rank). So (B′) holds automatically on a
  high spectral subspace for large |β|. It is a genuine finite-dimensional condition on the
  low-lying part of H_{T_*}^ε, and it is not obstructed by smoothness.
- **Smooth κ_L versus atoms.** No obstruction. p absorbs the difference, and positivity is tested
  only on c_G.
- **κ̂_L is not positive definite** (cosh growth). This is consistent with ε⟨c_G, κ_L⟩ changing
  sign with parity, and it is harmless because (B′) is posed on one parity class.
- **Support [-2T, 2T].** Harmless (see I4).

(B′) can therefore hold. Its conjunction with (A′) forces 2Σα c_F = ||R_L F||^2 + ⟨c_F, p⟩ ≥ 0
and ≤ 0 on K_*. That is the real content, and the reduction is non-vacuous.
