## R162_2501

### Prop 1, lower bound: CORRECT
Put ∫_{−T}^{T} e^{2βt}dt = sinh(2βT)/β. By Cauchy–Schwarz, |Φ_F(½±z)| ≤ ‖F‖(sinh(2βT)/β)^{1/2}. For real F, Φ_F(½+z̄) is the conjugate of Φ_F(½+z), so the four members of a quartet contribute AB + BA + conj + conj = 4Re(AB). This is ≥ −4‖F‖² sinh(2βT)/β. On-line zeros contribute |F̂(γ)|² ≥ 0. lem:roughEF gives the zero-side expression on P_T for smooth F. Density of the core and closedness of 𝔞_T then give the bound for λ_A. Multiplicity is counted in the sum. Nothing is missing.

### Prop 1, upper bound (flagged as a sketch): CORRECT WITH FIXES
The conclusion −λ_A ≥ c e^{2β*T} − C is true, but three steps are misstated.
- **F1 (expansion of A is wrong).** On the right bump, e^{zt}cos(γ_j t+θ) = ½e^{β*t}[e^{−iθ} + e^{i(2γ_j t+θ)}]. So
  A = ½e^{β*(T−1)}[e^{−iθ}Φ_φ(β*) + e^{iθ}e^{2iγ_j(T−1)}Φ_φ(β*+2iγ_j)] + O(e^{−β*T}).
  The second term is of the same order as the first and rotates with T. It is not O(e^{−2β*T}). The fix: as θ varies, the bracket traces an ellipse centred at 0. Unless the ellipse is degenerate, it meets the imaginary axis, so a θ = θ(T) with arg A = π/2 exists. The degenerate case |Φ_φ(β*)| = |Φ_φ(β*+2iγ_j)| must be excluded by choosing φ; this is an open condition. Then |A|² ≥ c₀e^{2β*T} uniformly, because the minor semi-axis ||u|−|v|| is T-independent. Evenness of F gives B = A, so 4Re(AB) = −4|A|².
- **F2 (primitivity).** Φ_F(0) = Φ_F(1) = 0 is one condition by evenness. As written it depends on T and θ(T), so "finitely many linear conditions on φ" is not T-uniform. The fix is to impose the T- and θ-independent conditions ∫φ(u)e^{u/2}e^{±iγ_j u}du = 0. These kill Φ_F(1) for every θ and T. Do the same for the moments at β*+i(γ_i±γ_j) of the other quartets with β_i = β*. Choose φ in a fixed finite-dimensional space where these vanish and the non-degeneracy of F1 holds. Linear independence of exponentials makes this possible.
- **F3.** The on-line tail is Σ_γ|φ̂(γ∓γ_j)|²: the translation by T only contributes a phase, and φ̂ decays rapidly. It is bounded independently of T, as claimed. The O(e^{(β*+β_i)T}) cross terms and the left-bump O(1) terms are fine.

With F1–F2, the limit lim (1/T) log(−λ_A) = 2β* holds.

### Prop 2 (floor): CORRECT
2Σ_{n<e^{2T}}Λ(n)/√n ~ 4e^T follows from Chebyshev/PNT. The archimedean symbol grows like log|τ| and is bounded below, so the archimedean part is ≥ −O(‖F‖²). The polar term vanishes on P_T.
Notation fix: "Θ ≤ 1" in the parenthesis is the exponent e of §5.3, not sup Re ρ. Under H(m), e = 2Θ_ρ − 1. Use a different letter.

### Model M_m: CORRECT WITH FIXES
- Entire: yes, provided each removed factor (s−½∓iγ_k^0) is a zero of ξ with at least the removed multiplicity. Order 1: the rational factor has degree 0 (4m/4m) if k runs over 2m conjugate pairs, i.e. 4m zeros removed, and it is 1+O(1/|s|) at ∞. **Fix:** say "2m conjugate pairs (4m on-line zeros) traded for m quartets (4m zeros)". "2m on-line zeros" is ambiguous and, read literally, gives degree mismatch 4m/2m. Order stays 1 either way, but the zero counting N(T) is then shifted by m.
- Real: yes. Functional equation: the quartet product is invariant under s ↦ 1−s (four sign flips), and each pair (s−½)²+γ² is invariant. So ξ_m(1−s) = ξ_m(s). ✓
- Counting: "κ(ζ)+4m" (zeros) and "exactly m" (quartets) mix units. Fix to one unit.

### Thm 3 (class obstruction): CORRECT WITH FIXES
- The logic is correct. 𝒫 holds for M_m and κ(M_m) ≥ m ≥ 1, so the argument would force κ(M_m) = ∞, hence κ(ζ) = ∞, hence ¬RH.
- Δ_T is a sum of at most 4m+2m bounded rank-≤2 forms, each continuous in T. So closedness, semiboundedness, compact resolvent and lem:contA continuity transfer. ✓
- **Fix (small-T positivity).** "unaffected at heights > H_PT up to O(T·e^{−…})" is wrong. Cauchy–Schwarz gives |Δ_T| ≤ (4Σ sinh(2β_jT)/β_j + 8mT)‖F‖² = O(mT)‖F‖², and this is height-independent. It is still enough for small T, because λ_A^ζ(T) stays bounded away from 0 there. Height > H_PT matters only for Theorem M.
- **Fix (Theorem M).** thm:margin (Σ_p(21) + e^TΣ_p(H_PT)) uses zeros ≤ H_PT. For M_m it holds anyway, trivially once λ_A < 0. Say "trivially satisfied" rather than "its proof transfers".
- The one missing property (atomicity of the arithmetic side) is correctly identified.

### Prop 3 (restatement): CORRECT WITH FIXES
Both directions hold, provided "E" is restricted to quartet-type densities E(u) = Σ_j (exponential terms e^{(ρ_j−½)u} over the quartet) and "real zero measure" means a zero measure satisfying the explicit formula for datum Λ-comb − E. That measure is unique on test functions, so ζ's zeros are that measure plus the quartets. State this restriction explicitly. As written, "any finite exponential density" is too broad. The von Koch formula and the derivative O(x^{β*−½}) are correct.

### §5 claims: CORRECT (fix one redundancy)
- RH ⟺ C_B ∧ κ<∞: trivially true.
- κ<∞ ⟹ quasi-RH: sup Re ρ = ½+β* < 1, trivial.
- κ<∞ ⟹ LH: true independently of P33, by Backlund's criterion (N(σ,T+1)−N(σ,T) = o(log T) for σ > ½). That count is eventually 0 here.
- "At least quasi-RH ∧ Lindelöf strength" is fair.
- §5.3: "RH ⟺ e=0 and λ_A ≥ 0 ∀T". λ_A ≥ 0 ∀T already gives e = 0, so the clause "e=0" is redundant. State instead "RH ⟺ λ_A ≥ 0 ∀T", which is Paper 46's criterion on P_T.
- "Under κ<∞, e = 2β*" needs κ ≥ 1 (or the convention β* = 0).
