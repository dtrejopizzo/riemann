## 1. Minorant

- Paper 47 defines N_T = {n ≥ 2 : log n < 2T}. At 2T = log5 this gives {2,3,4}, so n = 5 is excluded,
  and that is correct: the autocorrelation vanishes at the endpoint u = ±2T. In the code,
  v_4 = 2·log2/√4 = log 2, and A_T = 0.98026 + 1.26851 + 0.69315 = 2.94186. ✓
- lem:mbounds(i) says m is increasing, and (iii) says the comb is ≥ −A_T. Hence s_T ≥ m(τ_N) − A_T ≥ s_∞
  for |τ| > τ_N. s_∞ is taken to be an exact dyadic strictly below the lower endpoint of the ball.
  Hand check: m(240) ≈ log(120/π) = 3.6428 ✓, and s_∞ = 0.70079 ✓.
- ω₊ = s_∞ − C₀ + A_T with C₀ = ψ(¼) − log π = −5.3721, which gives 9.0149 ✓. ω₋ = m(τ_N) + A_T − s_∞ is
  valid on |τ| ≤ τ_N because m is monotone ✓.
- The matrix entry G_il = (2T/π)√((2i+1)(2l+1))(−1)^{(l−i)/2}∫₀^{τ_N} g j_i j_l, re-derived from
  ê_l = 2T√((2l+1)/2T)(−i)^l j_l(τT) and the evenness of g ✓.

## 3. Primitive constraint

- A = ∫F e^{t/2} and B = ∫F e^{−t/2}. For even F, A = B = ∫F cosh(t/2). For odd F, A = −B = ∫F sinh(t/2).
  The symbol is even, so a_T commutes with R, and λ_A = min(λ_even, λ_odd) ✓.
- ‖χ₀‖² = sinh T + T and ‖χ₁‖² = sinh T − T ✓. χ_l = 2T√((2l+1)/2T) i_l(T/2) ✓.
- The congruence diag(H,1) uses an exact binary64 matrix H, and ‖HᵀH − I‖_∞ < 1 is checked in balls,
  so H is invertible and Sylvester's law applies. det B < 0 is certified, so B has inertia (1,1).
  Haynsworth then gives n₋(𝖱′) = 1 + n₋(S) = 1. The code keeps the small residual components
  rp[1:] (H is not exact) inside the Schur correction ✓.
- lem:border gives n₋(b) = n₋(b_μ|ker χ) + 1. So n₋(b) ≤ 1 implies b_μ ≥ 0 on ker χ, and
  therefore a_T ≥ μ on P_T ∩ L²_par ✓.

## 4. Numeric rigor

- **Quadrature: ✓.** The ellipse has semi-axis 0.439 < ½, and the poles of Re ψ(¼ ± iτ/2) are at
  τ = ±i(2k+½). The ψ box covers the ellipse, and its real part stays ≥ 0.03 > 0 (asserted).
- **Binet bound: ✓.** It uses DLMF 5.9.13 with |g(t)| ≤ t/12 and |arg u| ≤ π/2, and the recurrence is
  applied with the correct sign.
- **Other bounds: ✓.** |j_n(z)| ≤ e^{|Im z|} and |cos| ≤ cosh(η log n) are both correct. The error is
  added as a ball to every accumulated entry. The error summed over panels is 1.5·10⁻⁴³.
- **Special functions: ✓.** Legendre roots and weights come from Arb's rigorous `legendre_p_root`.
  Bessel balls are asserted to have radius < 10⁻⁶⁰. The only floating-point objects are H (handled by
  the exact congruence) and the pivot *reporting* (`float(mid)` inside `min`), which is not part of
  the certificate.
- **Cholesky: ✓.** The interval Cholesky uses Arb `>` comparisons and the standard update.
- **Cancellation in 𝖱_ξξ: ✓.** 𝖱_ξξ ≈ 10⁻¹⁹⁰ is computed as ‖χ‖² − Σχ_l² at 640 bits. The radius is
  4.5·10⁻²⁰⁰, it is tracked, and only its upper end is used.
