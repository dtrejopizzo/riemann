# Non-abelian moment-map audit

## 1. Two type corrections

The common causal field is `Z_F(t,zeta)`.  The variable `t` is real and
`zeta` is complex, so its natural carrier has three real dimensions.  A Higgs
bundle on a complex curve cannot contain this field without treating `t` as
an external parameter and losing the mixed transport equation.  The closest
geometric type is a Bogomolny system (or a Hilbert quiver gauge system) on

```
(-T,T) x (slit disk).
```

There is a second mismatch.  A nonzero nilpotent residue has zero eigenvalues;
its scalar amplitude is changed by complex gauge and is not a parabolic
weight.  Hence `(log p) p^(-j/2)` cannot be encoded as the parabolic degree of
that residue.  The coefficient must instead enter as a fixed real moment-map
level or as the norm of a source-defined port.

## 2. The correctly typed port representation

On the primitive source `P_T`, phase 120 has independently constructed
operators

```
X_T F = (W_Gamma F, sqrt(theta_T) F, E_+ z(F)),
Y_T F = (sqrt(m_0) F, E_- z(F), deg z(F))
```

with the exact identity

```
X_T^* X_T - Y_T^* Y_T = -B_nuc,T.                 (2.1)
```

These maps define the minimal Hilbert-quiver representation carrying all
Gamma, Frobenius, degree and Tate ports.  Its real moment map at the source
vertex is

```
mu_T = X_T^* X_T - Y_T^* Y_T.                     (2.2)
```

The zero-residual Green identity fixes the corresponding complex/boundary
data, but it does not fix the sign of (2.2).

## 3. Mixed-subobject theorem

### Theorem

Any stability criterion for the port quiver which tests all closed analytic
source subobjects tests, in particular, the one-dimensional subobject
generated by every nonzero `F in P_T`.  The numerical moment weight of that
subobject is

```
w_T(F) = ||X_T F||^2 - ||Y_T F||^2
       = -B_nuc,T(F,F).                            (3.1)
```

Consequently

```
all mixed analytic subobjects have nonnegative weight
       iff  -B_nuc,T >= 0 on P_T.                  (3.2)
```

### Proof

Restrict the source vertex to the line `C F` and restrict every outgoing
arrow to its image.  This is the subrepresentation generated by `F`; closing
the images does not alter its source weight.  The positive and negative arrow
contributions to the real moment character are respectively the two squared
norms in (3.1).  Equation (2.1) gives the second equality.  Quantifying over
all nonzero source lines is exactly positivity of the Hermitian form (2.2).
QED.

## 4. Consequence for the proposed stability lemma

The coordinate subobjects supported on individual place legs are only a
small subset of the subobject lattice.  Unique factorization and separation
of the Bohr frequency lattices classify those coordinate objects, but do not
classify the mixed source lines `C F`.  A negative primitive test, if one
exists, is itself a destabilizing mixed subobject.

Therefore the following argument is circular:

```
rank one per place + two Tate flags
    => stability
    => harmonic metric
    => row (d).
```

Its first implication is already row (d) unless an independent theorem
reduces every mixed analytic subobject to a coordinate arithmetic subobject
without assuming the sign.

## 5. The only surviving non-abelian target

A non-abelian successor must prove a new **arithmetic degeneration theorem**:

> Every destabilizing mixed source subobject admits a degeneration, defined
> solely from Frobenius composition and the two Tate flags, to a coordinate
> place subobject whose moment weight is no larger.

If such a theorem existed, coordinate stability could imply full stability
and the Bogomolny moment equation would supply the square.  Ordinary torus or
Groebner degeneration cannot be assumed: making all prime colours torus
eigencharacters also diagonalizes the cross-place Green coupling and falls
under the placewise obstruction.

Thus the harmonic-metric machinery is not itself the new sign principle.
The arithmetic degeneration theorem would be that principle.

## 7. Tate rigidity of arithmetic one-parameter degenerations

The natural attempt to prove the arithmetic degeneration theorem is to use a
real one-parameter character of the multiplicative translation semigroup.
On the physical source this is rigid.

### Theorem (two-Tate one-parameter rigidity)

Let `I` be a nonempty open interval and

```
P(I)={F in C_c^infinity(I):
      integral F(t)e^(t/2)dt=integral F(t)e^(-t/2)dt=0}.
```

Suppose multiplication by `e^(ct)` maps `P(I)` into itself.  Then `c=0`.

### Proof

The annihilator of `P(I)` in distributions represented by smooth functions
is exactly

```
span{e^(t/2),e^(-t/2)}.
```

Invariance under multiplication by `e^(ct)` therefore implies that both

```
e^((c+1/2)t),   e^((c-1/2)t)
```

belong to that two-dimensional span on `I`.  Distinct real exponentials are
linearly independent on every open interval.  Hence the unordered exponent
pair `{c+1/2,c-1/2}` must be contained in `{1/2,-1/2}`.  Its difference is
one with the fixed orientation, so the only possibility is `c=0`.  QED.

### Corollary

A physical one-parameter degeneration satisfying

```
D_c S_(log n) D_c^(-1)=n^c S_(log n)
```

cannot preserve the primitive source unless it is trivial.  Independent
prime-colour torus weights exist only after enlarging to an auxiliary colour
space.  Such an action moves the common-source diagonal out of the physical
subspace; averaging it kills the cross-place coupling and returns the
placewise obstruction.

Thus ordinary torus/Groebner/Harder--Narasimhan degeneration cannot prove the
missing mixed-to-coordinate reduction while retaining both Tate conditions.

## 8. Final status of this candidate

The proposed non-abelian route does not currently furnish an independent
sign principle:

1. full moment-map stability is row (d) by the mixed-subobject theorem;
2. coordinate stability is weaker and misses arbitrary primitive tests;
3. the canonical arithmetic one-parameter degeneration needed to bridge
   them is trivial by two-Tate rigidity.

Accordingly the present Higgs/Bogomolny/quiver candidate is **closed
negatively in its canonical form**.  A successor would need a nonlinear,
non-character degeneration which preserves the common-source diagonal and
both Tate moments; no such operation is constructed here.

## 9. The compressed-character repair and its exact defect

There is one canonical way to evade the rigidity theorem while remaining on
the primitive source.  Let `P=P_T`, `N=1-P`, let `M` be multiplication by
`t`, and set

```
K=PMP : P H_T -> P H_T,
T_a=P S_a P.
```

The flow `exp(cK)` is nontrivial and preserves `P H_T` by construction.  It
does not, however, retain the character law for the Frobenius translations.

### Theorem (compressed-character defect)

On the common smooth core,

```
[K,T_a] = -a T_a - P M N S_a P + P S_a N M P.     (9.1)
```

In particular the infinitesimal character identity `[K,T_a]=-aT_a` holds
if and only if the two-Tate normal defect

```
Delta_a = -P M N S_a P + P S_a N M P             (9.2)
```

vanishes.  Since `N` is the projection onto the two Tate directions,
`Delta_a` has finite rank, but it has no fixed sign and couples all place
translations through the same two-dimensional normal space.

### Proof

Insert `P=1-N` on the two inner sides:

```
PMPPS_aP - PS_aPPMP
 = P M(1-N)S_aP - P S_a(1-N)MP
 = P[M,S_a]P - PMNS_aP + PS_aNMP.
```

For the convention `S_aF(t)=F(t+a)`, one has `[M,S_a]=-aS_a`, which gives
(9.1).  QED.

The defect is not an inessential boundary remainder.  It is exactly the
failure of geometric dilation to be tangent to the two moment constraints.
Removing it by a second projection simply returns the nonlocal projected
dilation already audited in phase 106.124.

## 10. Why neither real nor unitary compressed flow supplies the sign

Write the source moment operator as

```
A_T=X_T^*X_T-Y_T^*Y_T=-B_nuc,T.
```

Along the real compressed flow `F_c=exp(cK)F`, its weight satisfies

```
d/dc <A_T F_c,F_c>
 = <(K A_T+A_T K)F_c,F_c>.                         (10.1)
```

The anticommutator in (10.1) is not positive: (9.1) decomposes it into the
signed prime-dilation contribution and the unsigned two-Tate defect.  No
term in the already proved zero-residual Green identity gives either piece
a sign.

Replacing the real flow by the unitary flow `exp(icK)` changes (10.1) into

```
d/dc <A_T exp(icK)F,exp(icK)F>
 = <i[A_T,K]exp(icK)F,exp(icK)F>.                  (10.2)
```

For every eigenvector of `A_T`, the right side at `c=0` is zero.  Hence a
strict positive-commutator estimate would already exclude the negative
spectral subspace whose absence it is meant to prove.  This is the finite
primitive version of the projected Mourre equivalence in phase 106.124.

### Corollary

The canonical nonlinear-looking repair `exp(cP_TtP_T)` does not prove the
arithmetic degeneration theorem.  It gives the following exhaustive
dichotomy:

* retain the exact arithmetic character law and leave the primitive space;
* remain primitive and acquire the sign-indefinite two-Tate defect (9.2).

Thus the requested non-abelian harmonic construction has now been carried
through its source object, moment map, mixed-subobject classification,
arithmetic-character degeneration and compressed-character repair.  It does
not close the global square.  The obstruction is not PDE existence: it is
the absence of an independent sign for mixed source lines.
