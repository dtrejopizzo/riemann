# Modular-Hessian polarization audit

## 1. Purpose and novelty boundary

This note tests a different type of positive construction.  Instead of
factoring the signed Weil form directly, it asks whether that form is the
Hessian of relative entropy at a source-defined faithful state.  Positivity
would then be inherited from the state manifold, while the comparison with
`B_nuc` would occur only after the state and its tangent map had been fixed.

Scalar relative entropy of zero measures was studied in phases 33 and 104.
The construction below is different: it uses the noncommutative modular
Hessian of unitary orbits, and it first derives the literal von Mangoldt
weight from a geometric local density matrix.  No BKM/Petz/modular-Hessian
construction occurs elsewhere in phases 1--120.

The local construction succeeds exactly.  The proposed global entangling
step does not follow from the already constructed Green unitary; its missing
lift is shown below to be another form of the global-square problem.

## 2. Relative entropy on a unitary orbit

Let `rho` be an invertible density matrix and let `A=A*`.  Put

```
rho_epsilon=exp(i epsilon A) rho exp(-i epsilon A).
```

Since `log rho_epsilon` is the same unitary conjugate of `log rho`, direct
differentiation gives

```
d^2/d epsilon^2 D(rho_epsilon || rho)|_(epsilon=0)
 =Tr([A,[A,rho]] log rho)                            (2.1)
 =sum_(j,k) (lambda_j-lambda_k)
              (log lambda_j-log lambda_k)|A_jk|^2,  (2.2)
```

where `rho=diag(lambda_j)`.  Formula (2.2) counts ordered pairs.  It is
nonnegative because the logarithm is increasing.

This is the Bogoliubov--Kubo--Mori metric on the unitary orbit, written in
a form which exposes the modular energy gaps.

## 3. Exact modular origin of the von Mangoldt tower

Fix a prime `p` and put

```
r=p^(-1/2),
rho_p=(1-r) sum_(j>=0) r^j |j><j|.                  (3.1)
```

This is a faithful trace-one density matrix.  Its adjacent modular gaps are
constant:

```
log lambda_j-log lambda_(j+1)=-log r=(1/2)log p.    (3.2)
```

For a finitely supported sequence `b=(b_j)`, define the self-adjoint
adjacent-transition generator

```
A_p(b)=1/(1-r) sum_(j>=0)
 [b_j |j><j+1|+conjugate(b_j)|j+1><j|].             (3.3)
```

### Theorem 3.1 -- von Mangoldt modular Hessian

The unitary orbit of (3.1) generated by (3.3) satisfies

```
d^2/d epsilon^2
 D(exp(i epsilon A_p(b))rho_p exp(-i epsilon A_p(b)) || rho_p)|_0
   =sum_(j>=0) (log p)p^(-j/2)|b_j|^2.              (3.4)
```

### Proof

For the unordered adjacent pair `{j,j+1}`, (2.2) gives

```
2(lambda_j-lambda_(j+1))
  (log lambda_j-log lambda_(j+1)) |A_(j,j+1)|^2.
```

Now

```
lambda_j-lambda_(j+1)=(1-r)^2 r^j,
log lambda_j-log lambda_(j+1)=(1/2)log p,
|A_(j,j+1)|^2=|b_j|^2/(1-r)^2.
```

Multiplication gives `(log p)r^j|b_j|^2`, and summation proves (3.4).
QED.

Thus both factors in

```
Lambda(p^j)/sqrt(p^j)=(log p)p^(-j/2)               (3.5)
```

come from one positive state: `log p` is a modular level spacing and
`p^(-j/2)` is its Gibbs population.  The cancellation which removes a
spurious factor `j` is built into adjacent modular transitions.

## 4. Relation to the physical prime port

The physical local load in phase 120 is

```
prime_load_p(F)=(log p)||O_p E_TF||^2,
O_p=sqrt(1-p^(-1))(1-p^(-1/2)V_(log p))^(-1).       (4.1)
```

It has an immediate modular realization: use only the first transition in
(3.3) and set

```
b_0(F)=O_pE_TF,  b_j(F)=0 for j>=1.                 (4.2)
```

Then (3.4) is exactly (4.1).  Equivalently, one may expand `O_p` first; in
that reading the full prime-power tower is the coherent amplitude in one
modular transition rather than an orthogonal sum over powers.  Keeping it
coherent is necessary because the Poisson norm contains the cross terms
between different returns of the same prime.

This distinction corrects the naive claim that independent level
transitions alone reproduce the place-Poisson port.  They reproduce the
individual weights (3.5), but the physical port requires the coherent
resolvent (4.1).

## 5. Gamma modes do not obstruct a modular realization

For an arbitrary prescribed positive coefficient `c>0`, a faithful
two-level state `sigma=diag(mu_0,mu_1)` with `mu_0>mu_1>0` and a normalized
off-diagonal generator gives

```
d^2 D(exp(i epsilon A)sigma exp(-i epsilon A)||sigma)|_0
 =c|u|^2.                                             (5.1)
```

Indeed the unnormalized coefficient is

```
2(mu_0-mu_1)(log mu_0-log mu_1)>0,
```

and the generator can be scaled by its positive square root.  Taking
`c=alpha_n^(-1)`, `alpha_n=n+1/4`, realizes each already-positive Gamma
mode.  This is compatible with the literal oscillator construction, but
it adds no new information: every positive diagonal bank has such a
two-level modular realization.

The force-bearing question is therefore not the prime or Gamma local
Hessian.  It is whether one positive global modular metric produces their
oriented difference on the primitive common source.

## 6. The proposed global state and the type mismatch

The initial proposal was to form a positive product state

```
rho_prod=rho_Gamma tensor (tensor_p rho_p)            (6.1)
```

and entangle it by the zero-residual Green unitary.  Phase 120, however,
constructs the bilateral profile multiplier

```
K_T=M_(Theta_T) on L^2(R_tau),                        (6.2)
```

with

```
K_T^*QK_T-Q=M_(A_T).                                 (6.3)
```

It does **not** construct a unitary on the tensor product reservoir (6.1).
The prime density matrices live on occupation towers, the Gamma density
matrices live on oscillator cells, and `K_T` lives on their common external
profile.  Calling (6.2) an entangler of (6.1) is therefore a type error.

A second-quantized lift is not automatic.  The free/symmetric Fock lift is
precisely the construction rejected in D.142 by the factorial monoidal
descent obstruction.  A reservoir lift which is not second quantization
would be a new operator and must itself be constructed.

There is also no ordinary Gibbs density with modular Hamiltonian `Q` in
(6.3).  The bilateral generator `Q=-i d/dtau` has spectrum `R`, so
`exp(-beta Q)` is neither bounded nor trace class.  Replacing `Q` by a
positive function such as `Q^2` changes the connection to

```
K_T^*Q^2K_T-Q^2=Q A_T+A_T Q+A_T^2,                  (6.4)
```

which is not the Weil multiplier.  A type-III modular realization could
have a bilateral modular spectrum, but no such algebra, faithful weight or
source tangent map is supplied by (6.2)--(6.3).

## 7. Unitary conjugation does not manufacture the missing sign

For every faithful state `rho` and unitary `U`, the modular Hessian is
unitarily covariant:

```
g_(U rho U^*)(U A U^*,U A U^*)=g_rho(A,A).          (7.1)
```

Thus conjugating both the product state and its natural tangent generators
does not introduce any cross-place curvature; it only changes coordinates.
To obtain mixed terms one must keep a separately chosen physical tangent
`A_F` while conjugating the state.  In the product coordinates this means
constructing

```
J_TF=U^* A_F U                                      (7.2)
```

with exactly the required correlated Gamma--prime matrix elements.
Equation (7.2), not the local state (3.1), is the new datum.

## 8. Mixed-graph theorem

Let the exact four-port reduction be written

```
q_T(F)=-B_nuc,T(F,F)=||X_TF||^2-||Y_TF||^2.         (8.1)
```

Suppose a positive modular Hessian `g_rho` and a linear tangent map `J_T`
obey

```
g_rho(J_TF,J_TF)=q_T(F)                              (8.2)
```

for every primitive `F`.  Then `q_T>=0`.  Conversely, after completion of
the quotient by the null space, every positive `q_T` has a Hilbert
realization of the form (8.2).  Hence abstract existence of (8.2) is
equivalent to the global sign.

More specifically, if `J_T` is constructed from the known ports by a
positive ambient unitary or isometry, its image must be a positive graph in
`K_X plus K_Y`.  Therefore there is a contraction `Theta_T` on the physical
range with

```
Y_T=Theta_T X_T.                                     (8.3)
```

This is the Schur--Douglas condition already isolated in phase 118.  A
modular state changes the positive metric on the target, but it does not
remove the graph condition.

### Consequence

The modular proposal is non-circular only if it explicitly constructs a
reservoir algebra, a faithful global state and a tangent map `J_T` before
comparison, and then proves (8.2) by a direct Hessian calculation.  The
local states (3.1) and the profile scattering (6.2) do not provide that
tangent map.  Declaring the missing lift to be the Green entangler merely
renames (8.3).

## 9. Verdict

Proved:

* the exact von Mangoldt modular-Hessian identity (3.4);
* the coherent realization of the physical place-Poisson load (4.1)--(4.2);
* compatibility of the positive Gamma bank with modular Hessians;
* unitary covariance (7.1) and the mixed-graph obstruction;
* the type mismatch between the constructed profile unitary `K_T` and a
  reservoir entangler.

Not constructed:

* a faithful global Euler--Gamma state carrying the profile scattering;
* a source-defined mixed tangent `J_T` whose Hessian is `-B_nuc,T`;
* the two-Tate kernel as the exact modular centralizer;
* the global square.

The local theorem is a genuine new structural realization of the
von Mangoldt coefficient, but the proposed global modular-Hessian
polarization does not presently close row (d).  Its missing global tangent
is equivalent in force to the positive mixed graph, and the already proved
Green unitary is not an operator of the required type.

## 10. Maximal type-III repair: the canonical standard real subspace

The absence of a trace-class density with Hamiltonian `Q` is not by itself
terminal.  A bilateral operator can be a Tomita modular Hamiltonian.  On
`H_tau=L^2(R_tau)` let `J` be complex conjugation.  Since

```
J Q J=-Q,
```

the positive nonsingular operator

```
Delta=exp(-Q)                                         (10.1)
```

satisfies `J Delta J=Delta^(-1)`.  Hence

```
S=J Delta^(1/2),   V=ker(S-1)                        (10.2)
```

is the canonical standard real subspace associated with `(J,Delta)`.
This constructs a legitimate bilateral modular object without a Gibbs
trace and without using `B_nuc`.

For the global scattering unitary `K_T`, put

```
V_T=K_T^* V.
```

Its modular operator is `Delta_T=K_T^*Delta K_T`, and therefore its modular
Hamiltonian differs from that of `V` by

```
-log Delta_T-(-log Delta)
  =K_T^*QK_T-Q
  =M_(A_T).                                           (10.3)
```

Thus the zero-residual Green identity has an exact modular interpretation:
the localized Weil form is the difference of the modular Hamiltonians of
two explicitly constructed standard real subspaces.

This is stronger typing than the density-matrix proposal, but it is still
a **difference** of modular energies, not one relative-entropy Hessian.
Monotonicity would give a sign only from an inclusion or a modular order,
for example

```
V_T subset V                                           (10.4)
```

with the compatible orientation.  For multiplication scattering, (10.4)
is a one-sided Hardy/innerness condition on `Theta_T`.  The relative prime
factors `c_p` were introduced precisely because they are bilateral
unitaries; they are not one-sided Schur transfers.  Consequently (10.4)
does not follow from the Euler product or from unitarity on the boundary.

After compression to the primitive source, modular order in (10.3) is

```
P_T E_T^*(K_T^*QK_T-Q)E_TP_T >=0,                    (10.5)
```

which is the global square itself.  Therefore the type-III repair proves a
new exact identification -- `A_T` is a relative modular Hamiltonian -- but
does not supply the missing inclusion.  Assuming half-sided modularity at
this point would be the same innerness/positive-Hamiltonian wall already
encountered by the colligation route.

## 11. Final classification after the type-III repair

The modular programme yields two exact new identities:

1. von Mangoldt weights are local Gibbs modular Hessians, (3.4);
2. the full Green multiplier is a relative Tomita modular Hamiltonian,
   (10.3).

What fails is their proposed fusion.  Local modular Hessians are positive
but assemble the prime load with the positive orientation.  The global
Tomita object has the correct oriented Euler--Gamma difference but only as
the difference of two modular Hamiltonians.  Passing from that difference
to a single positive relative entropy requires the unproved modular
inclusion (10.4), whose primitive compression is (10.5).

Accordingly the modular-Hessian candidate is **closed negatively as a
global sign mechanism**, while retaining Theorem 3.1 and identity (10.3)
as exact structural results.  The global square remains open.
