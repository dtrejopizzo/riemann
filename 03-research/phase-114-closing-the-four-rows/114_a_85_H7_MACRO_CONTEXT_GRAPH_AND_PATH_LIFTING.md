# 114.a.85 — H7: the full macro congruence is a sandwich-context graph

```
+-------------------------------------------------------------------------+
| SOURCE      Every generated-equivalence step is one sandwich             |
|             c o (x_epsilon plus id_V) o d versus c o id_V o d.           |
| GRAPH       Vertices are signed bilateral data; these sandwiches are edges.|
| QUOTIENT    E_cancel classes are exactly connected components.            |
| COLON       (E_cancel:p) pulls back component connectivity along F->pF.   |
| ESCAPE      Paths with p-divisible endpoints may pass through vertices     |
|             outside the p-image.                                          |
| DIVIDE      A path confined to the p-image must descend after canceling p. |
| EXACT GATE  p-convexity of the image plus divided path lifting.            |
+-------------------------------------------------------------------------+
```

## 1. The source already gives the macro presentation

Let `P=Upsilon tensor_F F{+-1}` and let `x_0,x_1` be the two cancellation
generators.  Haran's general formula for an equivalence ideal generated by
pairs `(a_i,a_i')` says that `b~b'` precisely when there is a finite path
whose elementary unordered pairs have the form

\[
 \left\{
 c\circ(a_i\oplus id_V)\circ d,
 c\circ(a_i'\oplus id_V)\circ d
 \right\},                                                          \tag{1.1}
\]

and, with involution, the transposed form as well.  For `E_cancel`, take
`(a_i,a_i')=(x_epsilon,0)`.

Thus no guessed list of macro grids is needed.  For each arity `(Y,X)`
define the undirected **macro-context graph** `C_{Y,X}`:

- vertices are elements of `P_{Y,X}`;
- an edge is any pair (1.1) obtained from `x_0` or `x_1`, arbitrary finite
  auxiliary identity block `V`, and all typed outer contexts `c,d`, including
  transpose.

### Proposition 1.1

Two vertices are `E_cancel`-equivalent if and only if they lie in the same
connected component of `C_{Y,X}`.

This is exactly the generator-path theorem quoted above.  It closes
H7-MACRO-PRESENT at the set-theoretic level.  The remaining problem is not
which rows/edges exist, but connectivity after multiplication by a prime.

## 2. Prime saturation as component injectivity

Let `mu_p:P_{Y,X}->P_{Y,X}` be multiplication by a first-ruling prime `p`.
Compatibility of the congruence makes it induce

\[
 \bar\mu_p:\pi_0(C_{Y,X})\longrightarrow\pi_0(C_{Y,X}).             \tag{2.1}
\]

### Proposition 2.1 (component criterion)

The cancellation congruence is `p`-root-closed in this arity if and only if
the component map (2.1) is injective.

### Proof

The images of `F,G` have the same component exactly when `pF E_cancel pG`.
Injectivity of (2.1) says this implies `F E_cancel G`, which is the colon
criterion of `a_76`.  QED.

## 3. The two independent path problems

Write `pP=mu_p(P)` for the subset of `p`-divisible vertices.

> **H7-p-CONVEX.** Whenever two vertices of `pP` are connected in the full
> macro graph, they can be connected by a path all of whose vertices lie in
> `pP`.

This forbids an equality between `pF,pG` which is proved only by passing
through nondivisible intermediate presentations.

> **H7-p-DIVPATH.** If
> `pF=H_0--H_1--...--H_m=pG` is a macro path entirely in `pP`, choose
> `H_j=pK_j`; then the choices can be made so that `K_0=F`, `K_m=G` and
> consecutive `K_j` lie in the same macro component.

The divided step need not itself be one edge; a finite macro subpath is
enough.

### Theorem 3.1 (path-lifting criterion)

H7-p-CONVEX plus H7-p-DIVPATH implies `p`-root-closure of `E_cancel`.

### Proof

Given a path from `pF` to `pG`, p-convexity replaces it by one inside `pP`.
Divided path lifting supplies a chain connecting `F` to `G` in macro
components.  Hence they have the same component, and Proposition 2.1 gives
root closure.  QED.

Conversely, root closure is strictly weaker than these two separate
conditions; they are a structured sufficient factorization of the exact
component criterion, not a claimed equivalence term by term.

## 4. Relation to the completed sectors

The rectangular macro contexts of `a_82` satisfy both conditions: incidence
paths remain in the divisible lattice and divide coordinatewise.  The cycle
Laplacian warning of `a_83` models a possible failure of DIVPATH when only
aggregated rows survive.  The fold-fiber theorem `a_71` constrains the
endpoints of a collision but does not constrain intermediate macro-path
vertices, so it does not prove p-CONVEX.

The exact next questions are therefore:

1. prove p-CONVEX from the sandwich form (1.1), perhaps using a valuation or
   filtration preserved at every elementary edge; and
2. prove DIVPATH by extracting `p` from `c,d` or by a saturated scalar
   invariant.

Neither statement is established for the full plane.  H7-PRIME-REG and row
A remain open.

## 5. Verification scope

`114_a_85_h7_macro_context_graph_verify.py` exhausts finite graphs and
endomorphisms, checks Proposition 2.1, the two-condition implication, and
explicit escape-path countermodels showing why endpoint divisibility alone
does not give a divisible path.
