## 1. Frobenius fixes coprime cyclotomic classes

Let `C_n=[Phi_n]` in the free cyclotomic subgroup of `W_rat(Z)`.  Frobenius
`F_N` raises every inverse root to its `N`-th power.

### Lemma 1.1

If `gcd(N,n)=1`, then

```
F_N(C_n)=C_n.                                                (1.1)
```

*Proof.* Exponentiation by `N` permutes `(Z/nZ)^x`, hence permutes the primitive
`n`-th roots of unity.  Their characteristic polynomial remains `Phi_n`. `[]`

Recall from `114_a_05` that

```
E_n=C_n-phi(n)C_1,       n>=2,                               (1.2)
```

and that the `E_n` form a free abelian group of countably infinite rank inside
`ker(r,m)`.  Since `F_N(C_1)=C_1`, Lemma 1.1 gives:

### Corollary 1.2

For every `n>=2` and every `N>=2` coprime with `n`,

```
F_N(E_n)=E_n.                                                (1.3)
```

## 2. Weight-one gauges cannot see the kernel

### Theorem 2.1 (Frobenius fixed-point obstruction)

Let `A` be an abelian group with an endomorphism `F_N`, and let
`g:A->R` satisfy

```
g(F_N x)=N g(x),       N>=2.                                 (2.1)
```

Then `g(x)=0` at every fixed point of `F_N`.

*Proof.* If `F_Nx=x`, then `g(x)=Ng(x)`, so `(N-1)g(x)=0`. `[]`

### Corollary 2.2 (no positive weight-one norm on the I7 lattice)

Every function satisfying (2.1) for the Witt Frobenius vanishes on every
`E_n`.  In particular no positive definite norm, length, or proper gauge on
the free lattice generated by the `E_n` can satisfy weight-one Frobenius
equivariance.

This is not peculiar to Mahler measure.  It proves that the entire class of
gauges to which the Tate telescoping argument of `114_a_04` applies is forced
to be blind on the cyclotomic kernel.

Therefore the old design requirement

```
kernel norm + m(F_N x)=N m(x)
```

is inconsistent.  A kernel gauge would have to transform with weight zero,
be indexed place-by-place, or abandon scalar Frobenius equivariance.

## 3. The same kernel is principal after compactification

On `P^1_Z`, homogenising `Phi_n` and `1-T` gives

```
div(Phi_n(z)) = Z_n - phi(n) D_infinity,
div(1-z)      = Z_1 - D_infinity.                             (3.1)
```

Consequently

```
E_n=Z_n-phi(n)Z_1=div(Phi_n(z)/(1-z)^phi(n))                  (3.2)
```

is principal.  No identification of `Z_1` with infinity is being made.

### Theorem 3.1 (principal-invariance obstruction)

Let `B` be a bilinear intersection pairing on divisors which descends to the
Picard/divisor-class group.  Then

```
B(E_n,D)=0                                                    (3.3)
```

for every divisor `D` and every `n`.

*Proof.* A pairing descending to divisor classes annihilates principal
divisors in either argument.  Apply (3.2). `[]`

But the finite local intersection with the diagonal/reference divisor is

```
I_fin(Z_n,Delta)=log|Res(Phi_n,T-1)|=Lambda(n).               (3.4)
```

There is no contradiction: (3.4) is one finite-place contribution.  A global
arithmetic intersection of a principal arithmetic divisor includes the
remaining finite and archimedean/Green contributions, and the product formula
forces their total to vanish as in (3.2).

### Corollary 3.2 (the resultant is local data, not the missing global form)

The map `n |-> Lambda(n)` cannot be both

1. the intersection `B(Z_n,Delta)` in a pairing descending to Picard, and
2. the raw finite resultant contribution.

Indeed `Z_3-Z_6=div(Phi_3/Phi_6)` is principal because both degrees are two,
so principal invariance forces `B(Z_3,Delta)=B(Z_6,Delta)`, whereas the raw
finite values are `log 3` and `0`.

This is the structural reason behind row-(a) item a2 (“principal invariance
fails”) and I7.  Adding the canonical toric Green metric of `114_a_07` restores
global principal invariance by completing/cancelling the local resultant; it
does not turn the finite contribution into a nonzero global class pairing.

## 4. Exact trilemma for the W_rat/P1 route

The following three requirements cannot hold simultaneously on the
cyclotomic kernel:

```
(P) principal divisors vanish in the global class group;
(L) B(Z_n,Delta)=Lambda(n) as a global intersection;
(F) the kernel gauge has Frobenius weight one.
```

- `(P)+(L)` contradict Theorem 3.1 already for `n=3,6`.
- `(F)` contradicts positivity/properness of the kernel gauge by Corollary 2.2.

Hence the W_rat/P1 candidate is closed negatively as a route to **a4-strong
with the row-(c) local numbers unchanged**.  This does not refute Haran's
literal square or another category in which the Frobenius cycles are not
principal.
