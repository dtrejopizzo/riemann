## 0. Framework

𝔉 ⊂ 𝒦 an arbitrary set of admissible tests (family P of R166_501: K ≥ 0 continuous, type ≤ Δ_max), G fixed. For each K, the exact identity (1.1): Z_K(Σ) = 𝔄_K − Tail_K(λ). t(λ) := (Tail_K(λ))_{K∈𝔉} ∈ ℝ^𝔉. Shadow Sh(B) := {t(λ) : B(λ)}; t_ζ := t(Λ_ζ) ∈ Sh(B).

**Why exclusion must be read as a statement about proofs.** If 𝔉 is rich (all K of all Δ ≤ Δ_max), the map Σ ↦ (Z_K(Σ))_K is injective on zero measures (the Z_K determine the transforms of G²·Σ in a frequency band, and G ≢ 0 is entire; see Paper 47, Theorem Z, for the same reading). Then "the witness is compatible with Λ_ζ" ⟺ "Σ_ζ has that quadruple", and "exclusion by Λ_ζ" is literally the absence of the quadruple: trivial E1. The content of circularity is what a proof may *use*. As in R185_002 Thm F, it is formalized thus: a proof that uses only (a) B(λ), (b) the identities (1.1) for K ∈ 𝔉, (c) O_K ≥ 0 and the information about R (bounds R_K ≥ −S_K in (M1); R ∈ 𝓡 in (M2)), holds for every λ′ satisfying B. It then excludes the witness only if Sh(B) ∩ W = ∅, with
- (M1) W = O_U, U_K := 𝔄_K − Q^{hyp}_K + S_K;
- (M2) W = w₀ − 𝓡 − C̄, w₀ := 𝔄 − Q^{hyp}, C̄ ⊂ ℝ^𝔉 the closed convex cone (product topology) generated by v(γ) := (G(γ)²K(γ))_{K∈𝔉}.

## 1. Model (M1): arbitrary families

**Lemma 2∞. PROVED.** For arbitrary 𝔉, U ∈ ℝ^𝔉, A ⊂ ℝ^𝔉: A ∩ O_U = ∅ ⟺ A ⊂ ⋃_{K∈𝔉}{t : t_K > U_K}.
*Proof.* Pointwise: t ∉ O_U ⟺ ¬(∀K: t_K ≤ U_K) ⟺ ∃K: t_K > U_K. Neither finiteness nor topology is used. ∎

**Thm 1 (circularity in M1, arbitrary families). PROVED.** If a proof of type (a)–(c) excludes the witness with arbitrary 𝔉 (infinite, non-power-type, of any scales ≤ Δ_max), then:
- (i) B ⟹ ⋁_{K∈𝔉}[Tail_K > U_K] (possibly infinite disjunction, each disjunct a 𝔅₀ statement);
- (ii) there exists K* ∈ 𝔉 with Tail_{K*}(Λ_ζ) > U_{K*} (strict, attained violation);
- (iii) by true (1.1): Z_{K*}(Σ_ζ) < Q^{hyp}_{K*} − S_{K*}, the zero-side inequality of R166_802 Thm 2 at a single test, false if the quadruple is present and R_{K*} ≥ −S_{K*} is true.
*Proof.* (i) Lemma 2∞ applied to A = Sh(B). (ii) t_ζ ∈ Sh(B). (iii) substitution t_ζ = 𝔄 − Z(Σ_ζ). ∎

**Obs 1.2 (non-uniformity of S).** The bounds S_K need not be uniform in K: Thm 1 only uses the bound at the produced K*. If S_K = +∞ for some K (uncontrolled), those K have U_K = +∞ and are never K*: the effective family is 𝔉_fin := {K : S_K < ∞}. PROVED.

**Obs 1.3 (unattained infima). PROVED.** If inf_K (U_K − Tail_K(λ′)) = 0 without being attained, then t(λ′) ∈ O_U: λ′ is compatible with the witness in (M1). Exclusion requires a K with strict inequality. There is no gain from accumulating near-violations.

**Consequence.** In (M1), (ρ1) is **closed** for every family within 𝒦. The "strength" needed at K* is that of R166_802: U_{K*} has the size of the quadruple term (Prop 2.1, ≍ e^{2δ_qT_c}|G(t_q)|²-scale in the test localized at γ_q), so the zero-free tail bound must have exponent strength δ_q = Θ − ½ at that test (Thm 3 for power-type families). The infinite union does not allow this strength to be spread out: a single K pays for it.

## 2. Model (M2): joint convex restriction

**Lemma 5. CITED (standard, e.g. Schaefer, TVS, ch. II/IV).** The topological dual of ℝ^𝔉 with the product topology is ⊕_{𝔉}ℝ: every continuous functional is ℓ(t) = Σ_{i≤m} a_i t_{K_i} with finite support. ℝ^𝔉 is locally convex and Hausdorff, and strict separation of a point from a closed convex set holds.

**Lemma 6. PROVED.** If 𝓡 ⊂ ℝ^𝔉 is convex and compact (product topology), W = w₀ − 𝓡 − C̄ is convex and closed.
*Proof.* The sum of a compact set and a closed set in a topological group is closed; translating and reflecting preserves closedness and convexity. ∎

**Lemma 7 (the cone contains the real zeros). PROVED.** For every real-zero configuration with Σ_γ G(γ)²K(γ) convergent for each K ∈ 𝔉, o := (O_K)_K ∈ C̄. *Proof.* The partial sums lie in the cone and converge coordinate-wise, i.e. in the product topology; C̄ is closed. ∎

**Thm 2 (circularity in M2, arbitrary families, 𝓡 compact). PROVED.** Suppose 𝓡 is convex compact in ℝ^𝔉 (typical case 𝓡 = {0}: a single quadruple) and Sh(B) ∩ W = ∅. Then there exist K₁,…,K_m ∈ 𝔉 and a ∈ ℝ^m with K* := Σ a_iK_i ≥ 0 on ℝ (hence K* ∈ 𝒦) such that
  Tail_{K*}(Λ_ζ) > 𝔄_{K*} − Q^{hyp}_{K*} + S_𝓡(a), S_𝓡(a) := max_{r∈𝓡}(−a·r) < ∞,
equivalently Z_{K*}(Σ_ζ) < Q^{hyp}_{K*} − S_𝓡(a).
*Proof.* t_ζ ∈ Sh(B) ∖ W, W convex closed (Lemma 6). By Lemma 5 there exists ℓ = a of finite support {K₁,…,K_m} with a·t_ζ > sup_W a·w = a·w₀ + S_𝓡(a) + sup_{o∈C̄}(−a·o). The last term is finite only if a·o ≥ 0 ∀o ∈ C̄, in particular a·v(γ) = G(γ)²K_a(γ) ≥ 0 ∀γ; by continuity and isolation of the zeros of G, K_a ≥ 0 on ℝ, and then it equals 0. Type of K_a ≤ max type K_i ≤ Δ_max. Linearity of K ↦ Tail_K, 𝔄_K, Q_K concludes. ∎

That is: **with the natural (product) topology, infinite-dimensional separation never produces a non-admissible functional**; it produces a finite, nonnegative-on-ℝ combination, i.e. the case already closed in R185_001 Thm 5(b).

**Prop 3 (mixtures in normed topologies). PROVED.** If one works in a finer space (e.g. t bounded in a weighted norm over 𝔉 ⊂ 𝒦 compact, with functionals ℓ_μ(t) = ∫ t_K dμ(K), μ a finite signed Radon measure):
- (a) in (M1), if ℓ_μ is bounded above on O_U then μ ≥ 0 (take t = U − s·1_E, E Borel with μ(E) < 0, s → ∞: ℓ_μ → +∞);
- (b) in (M2), ℓ_μ bounded above on −C̄ forces ∫ G(γ)²K(γ)dμ(K) ≥ 0 ∀γ, i.e. K_μ := ∫K dμ ≥ 0 on ℝ;
- (c) if every K ∈ supp μ has type ≤ Δ_max and sup ‖K‖_{L¹∩L^∞} < ∞ on supp μ, then K_μ is continuous, of type ≤ Δ_max (Paley–Wiener is closed under Bochner integrals), hence K_μ ∈ 𝒦; and Tail_{K_μ} = ∫Tail_K dμ (the tail is a finite sum over n ∈ [X, Xe^{Δ_max}]), Z_{K_μ} = ∫Z_K dμ (Fubini: Σ_ρ |G(ρ)|²·sup|K| converges), 𝔄_{K_μ} = ∫𝔄_K dμ (linearity of the polar/archimedean term, to be checked against def:W/eq:nuw, R185_001 audit item 6).
Hence the mixture is a single test K_μ ∈ 𝒦 and R166_802 Thm 1–2 applies. ∎

## 3. The exact residual

**(ρ1′) Exclusion not detectable in finite dimension. OPEN.** If 𝓡 is closed convex but not compact, w₀ − 𝓡 − C̄ may not be closed. If t_ζ ∈ cl(W) ∖ W, no finite projection separates and Thm 2 gives no K*. Characterization: t_ζ ∈ cl(W) ⟺ for every finite F ⊂ 𝔉, π_F(t_ζ) ∈ cl π_F(W). Thus (ρ1′) = "every finite shadow is compatible, but the full family is not": a compactness phenomenon on 𝓡 (other quadruples), not on B. Even so, by Thm 6 of R185_001 in ℝ^𝔉 (substitution t_ζ = 𝔄 − Z(Σ_ζ), topology-free), exclusion is equivalent to the zero-side statement Z(Σ_ζ) ∉ Q^{hyp} + 𝓡 + C̄: it remains circular in the sense of R166_802 (false if the quadruple is present and the information about R is true). What fails is only the factorization through **one** test.

**(ρ1″) Unbounded type. Outside the framework.** If K of type Δ → ∞ are admitted (tails over all of [X, ∞)), the K are not in 𝒦 and the mixture K_μ = Σ μ_nK_n has no finite type. A statement Σ μ_n Tail_{K_n}(λ) > Σ μ_n U_{K_n} is a single inequality over the full infinite tail. With power-type weights this is R166_802 Thm 3 (𝔅₁, PROVED: requires strength δ = Θ − ½). In general this is the territory of (TC) from phase 164: "C_{T_c} − iG²𝒯_X with no poles for Im x ∈ (−½, 0)", with 𝒯_X the full tail; (TC) on the witness is RH (R164 README, Rem 4.8a) and phase 164 does not prove it. **It is not asserted** that (ρ1″) implies or is implied by (TC); only that this is the single place where a family escapes reduction to a test in 𝒦, and that there the statement is already, by true (1.1), a statement about the full tail of the type phase 164 identified as equivalent to the conclusion.

## 4. (ρ3) Uniformity

K* = K*(π) depends on π = (t_q, G). Uniformity is not required for the logical reduction: exclusion is only asked for the true witness data, and Thm 1–2 apply at fixed π. But a **proof** of exclusion for every π must produce K*(π) without knowing t_q; Thm 1–2 only give existence (disjunction, not disjunct). Producing the selector π ↦ K*(π) from Λ-data is the selector problem of R184_016, labeled E1. Moreover thm:finZ (Paper 47) prevents a finite number of zeros from sustaining a flat-top certificate for all π at once, and R184_094 (A1) recalls that "absence of zeros at selected heights" is not a zero-free region. Recorded; no label change.

## Final theorem (for Paper 47)

**Theorem (circularity for arbitrary families).** Let G be fixed, 𝔉 ⊂ 𝒦 an arbitrary set of admissible tests of type ≤ Δ_max, π hypothetical parameters, and B a statement about λ true for Λ_ζ. Suppose a proof that uses only B, the identities (1.1) for K ∈ 𝔉, the positivity of the contribution of real zeros, and the information about the other quadruples excludes the witness.
1. (M1, bounds R_K ≥ −S_K test by test.) There exists K* ∈ 𝔉 with Tail_{K*}(Λ_ζ) > 𝔄_{K*} − Q^{hyp}_{K*} + S_{K*}, equivalently Z_{K*}(Σ_ζ) < Q^{hyp}_{K*} − S_{K*}.
2. (M2, R ∈ 𝓡 convex compact in the product topology.) There exists K* = Σ_{i≤m} a_iK_i, K_i ∈ 𝔉, K* ≥ 0 on ℝ, with Tail_{K*}(Λ_ζ) > 𝔄_{K*} − Q^{hyp}_{K*} + S_𝓡(a), equivalently Z_{K*}(Σ_ζ) < Q^{hyp}_{K*} − S_𝓡(a).
In both cases the zero-side inequality is false if the hypothetical quadruple is present. Continuous mixtures of bounded-type tests are tests in 𝒦 and give nothing new.
**Remark (residual).** Factorization through a single test can fail only at (ρ1′) if 𝓡 is not compact and w₀ − 𝓡 − C̄ is not closed, a case in which exclusion remains a zero-side statement about the whole family; or at (ρ1″) if tests of unbounded type are admitted, which exits the cone 𝒦 and is the domain of full-tail statements (R166_802 Thm 3; (TC) from phase 164).

## For the audit

1. **Lemma 2∞ is trivial and that is the point.** The infinite disjunction requires no compactness; the strict violation is pointwise at t_ζ.
2. **Topology matters in (M2).** With the product topology the dual has finite support (Lemma 5) and the reduction is that of R185_001. Anyone proposing a "non-admissible mixing" functional must use a finer topology; Prop 3 shows that with bounded types the mixture stays in 𝒦. The only thing a finer topology could separate that the product one cannot is t_ζ ∈ cl_prod(W) ∖ cl_fine(W): exactly (ρ1′).
3. **K-∞ correction.** In (M2) the forced sign is K_a ≥ 0 on ℝ, not a ≥ 0 (the task stated it as a ≥ 0).
4. **Injectivity.** The §0 argument (the Z_K determine Σ for rich 𝔉) only motivates reading exclusion as a statement about proofs; it is not used in the theorems.
5. **Linearity of 𝔄_K in K** must be checked against def:W/eq:nuw of Paper 47 before integration, also for integrals ∫𝔄_K dμ (Prop 3(c)).
6. **(ρ1″) and (TC).** No implication is asserted; only the location of the residual.
7. RH is not asserted; nothing excludes a quadruple. The form of every possible exclusion is classified.

## Honest assessment

(ρ1) is **closed** in (M1) for every family within 𝒦, and in (M2) whenever 𝓡 is compact (including the single-quadruple case, 𝓡 = {0}). The residuals are (ρ1′), a compactness problem about the information on the other quadruples that remains circular even though it does not factor through a test, and (ρ1″), which exits the bounded-type framework toward the full tail of phase 164.
