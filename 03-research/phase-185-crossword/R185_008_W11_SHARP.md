## 1. Reformulation of W11

### 1.1 Why the literal statement is false

True, zero-free, joint (primes + Γ) counterexamples that are not RH:
- Paper 46 thm:C: primitive form ≥ 0 at T = ½log3 (primes 2 and 3 + Γ), explicit certificate.
- Paper 46 thm:log5A: same at T = ½log5 (primes 2, 3, 5 + Γ).
- CC (cc_2006.13771 Thm 6.11): positivity on |I| = log 2 via the archimedean route plus Tate's restriction
  ĝ(0) (formally archimedean, but the primitivity restriction is the fingerprint of the pole, not of the primes).

None implies RH: they are statements about a fixed window. So W11 is false as «every coupling is RH».
What the source (phase 136 §2) actually proves is a statement about **all** windows.

### 1.2 (W11-∞) — PROVED-CITED

**Theorem W11-∞.** Let 𝒮 be any sentence (zero-free or not) such that 𝒮 ⟹ W_T ≥ 0 on P_T for all T.
Then 𝒮 ⟹ RH. Conversely RH ⟹ W_T ≥ 0 ∀T. Moreover (cor:RH) RH ⟺ for every T ≥ ½log2 there exists w ∈ 𝒲^reg with
f_w ≥ 0 on ℝ.

*Proof.* Every compactly supported test function lives in some I_T; W ≥ 0 on all of them is the Weil criterion
(cor:RH (c)⟹(a); cor:margin2(iii): RH ⟺ L^A ≥ 0). ∎

So **E1 is the quantifier ∀T, not the coupling**.

### 1.3 (W11-fin) — PROVED-CITED, with the correct caveat

**Theorem W11-fin.** Let T₀ ≥ ½log2.
(i) If λ^P_{T₀} > 0 (resp. λ^W_{T₀} > 0) there exists w ∈ 𝒲^reg and β ∈ ℝ² with inf_τ[f_w + …] > 0: a **zero-free**
certificate (elementary function eq:fw, data: primes < e^{2T₀}, Γ, pole). *Proof:* thm:Zexh (sup = λ). ∎
(ii) For T₀ ∈ {½log2, ½log3, ½log5} the margin is > 0 and the certificate is written out (Paper 46). PROVED.
(iii) For T₀ > ½log5 it is **not known** that λ_{T₀} > 0: that is OPEN, and by W11-∞ knowing it for every T₀ is RH.

Caveat with respect to the target: «W_{T₀} ≥ 0 is probably zero-free for each T₀» **is not a theorem**: it is
true only if λ_{T₀} > 0, and the truth of that for each concrete T₀ is OPEN. What is PROVED is implication (i).

### 1.4 The honest form

> **W11 (honest).** The primes–Γ coupling is not an obstacle: it certifies finite windows (PROVED up to ½log5).
> The obstacle is uniformity in T: λ^A_T ≤ exp(−e^{(2−ε)T}) (Theorem M, R162_2101; cor:margin2(i) gives the
> explicit bound 4·10⁹ T e^{−15.449T} for T ≥ 1), so no mechanism with margin propagates, and certificates
> are not inductive (R169_101, NO-GO W2).

## 2. What a mechanism would need for all T

### 2.1 No margin

By cor:margin2(i), λ_T → 0 (under RH; if RH fails, λ_T < 0 eventually). A mechanism valid ∀T is therefore an
identity or inequality **with no slack** (S12): W_T = P_T + R_T with P_T ≥ 0 structural and R_T controlled with no margin.

### 2.2 Is this literally Theorem Z? Not entirely.

- thm:Z + thm:Zexh: **within the class of dual-LP certificates** (flat-top w, plus β ∈ ℝ² for the primitive),
  every certificate at T is, up to uniform ε, the explicit formula on a flat test: f_w(τ) = Σ_ρ ŵ(τ − γ_ρ).
- thm:finZ: no finite set of zeros sustains a flat-top certificate; the certificate sees every zero.
- What Theorem Z does **not** cover: decompositions W_T = P_T + R_T with P_T ≥ 0 an arbitrary multiplier and R_T
  of bounded inertia (not necessarily ≥ 0). The CC mechanism lives there: R183_019 §5 describes it as an
  extended-class certificate (atom at γ = 0, β ∈ ℝ³), and the Sonin part is not a flat test.

So W11-sharp = thm:Z (certificate class) **+** R183_031 Theorem 1 (multiplier class + bounded inertia).

### 2.3 (W11-sharp) — PROVED

**Class 𝔐_mult.** Families (P_T, R_T)_{T>0} with W|_{prim ∩ C_c^∞(I_T)} = P_T + R_T,
P_T(h) = (1/2π)∫ρ_T|ĥ|² with ρ_T ≥ 0 locally integrable, and sup_T n₋(R_T) ≤ N₀ < ∞.

**Theorem W11-sharp.**
(a) (W11-fin) For each T₀ with λ_{T₀} > 0 there exists a zero-free certificate (thm:Zexh). PROVED-CITED.
(b) If a dual-LP certificate exists for every T, it is at each T the explicit formula on a flat test (thm:Z,
    thm:Zexh) and it is not truncated to finitely many zeros (thm:finZ). PROVED-CITED.
(c) For every family in 𝔐_mult: ζ has at most finitely many zeros off the line (§3), and on every compact K at
    distance d > 0 from the real ordinates of zeros, |{s ∈ K : ρ_T(s) ≥ τ}| ≤ πN₀'/T + o(1),
    N₀' = N₀ + 2·#(off-line zeros) < ∞. If moreover ∫_K ρ_T is bounded, every vague limit of ρ_T ds is
    supported on the ordinates of zeros (Cor 1.2). PROVED (R183_031 Thm 1 + §3 here).
(d) Consequence: an ∀T mechanism of certificate class or of class 𝔐_mult **contains the explicit formula**: its
    positive part knows the zeros at every height. In the grid's language: E1.

### 2.4 Residue (OPEN)

Mechanisms outside both classes:
- (ρ-a) P_T ≥ 0 not diagonal in frequency (not a multiplier), e.g. non-self-adjoint semilocal prolate
  projections (R183_031 §3.1, "semilocal": no defined spectrum in the source).
- (ρ-b) n₋(R_T) unbounded in T but with controlled growth (R185_007 treats the unbounded type).
- (ρ-c) exact non-quadratic identities (factorizations W_T = A_T^*B_T A_T with B_T ≥ 0 with no density form).
For (ρ-a) the argument of §R183_031 Thm 1 step 2 only uses P_T(h) ≥ τ‖h‖² on Gabor wave packets localized in A; it
extends to every P_T with "symbol" ≥ τ on A in the Gabor sense (lower bound on packets). What remains outside is
P_T with no lower bound on any packet — which contributes no local positivity in frequency. Not closed here.

## 3. Lemma 1.1(b) — PROVED

**Lemma 1.1(b′).** If n₋(W | prim ∩ C_c^∞(ℝ)) ≤ N₀ < ∞ (equivalently, by Lemma 1.1(a), sup_T N(T) ≤ N₀), then ζ
has only finitely many zeros off the critical line.

Notation: zeros ρ = ½ + iγ_ρ, γ_ρ ∈ ℂ, |Im γ_ρ| < ½; the set {γ_ρ} is invariant under γ ↦ γ̄ and γ ↦ −γ.
W(h) = Σ_ρ ĥ(γ_ρ)·conj ĥ(conj γ_ρ) (R183_031 (1.1)), a Hermitian form on complex h.

**Step 0 (reductions).**
(i) n₋ of a real symmetric form coincides with n₋ of its Hermitian extension to the complexification; the
    primitive conditions ĥ(±i/2) = 0 are ℂ-linear. We work with complex h.
(ii) Gaussian class 𝒳 = {h : e^{|t|}h^{(j)}(t) bounded and rapidly decreasing, ∀j}. Weil's explicit formula holds
    on 𝒳 with absolute convergence on both sides (CITED: Weil 1952; Bombieri 2000; it is the standard class,
    ĥ holomorphic on |Im s| < 1 with decay). Both sides are continuous in the topology of 𝒳.
(iii) C_c^∞ ∩ prim is dense in 𝒳 ∩ prim: truncate with χ(t/R) and correct ĥ(±i/2) by subtracting small multiples
    of two fixed functions in C_c^∞. If W were < 0 on an r-dimensional subspace of 𝒳 ∩ prim, by continuity and
    finite dimensionality it would be so on an r-dimensional one of C_c^∞ ∩ prim (approximate a basis; the Gram
    determinant and negative definiteness are open conditions). So it suffices to prove n₋(W|𝒳∩prim) = ∞ if there
    are infinitely many off-line zeros.

**Step 1 (dominant Gaussian block).** Fix c ∈ ℝ and, for each zero, v_ρ(c) := β_ρ² − x_ρ², with
x_ρ = Re γ_ρ − c, β_ρ = Im γ_ρ. Let M_c := sup_ρ v_ρ(c). If there is an off-line zero with Re γ_ρ = c,
M_c ≥ β_ρ² > 0. Only zeros with |x_ρ| < ½ have v > 0, and they are finitely many; so M_c is attained on a finite
set F_c, made of off-line zeros, closed under γ ↦ γ̄. Also δ_c := M_c − sup_{ρ∉F_c} v_ρ(c) > 0 (finitely many
candidates with v > −1, the rest with v ≤ −1 < M_c).

Take ĥ_{a,p}(s) := e^{−aM_c} e^{−a(s−c)²} p(s), p a polynomial with p(±i/2) = 0. It lies in 𝒳 ∩ prim. For a zero,
|ĥ(γ_ρ) ĥ(conj γ_ρ)| = e^{2a(v_ρ − M_c)} |p(γ_ρ) p(conj γ_ρ)|.

Split W(h) = Q_a(p) + E_a(p), Q_a = sum over F_c. For γ_ρ = x + c + iβ ∈ F_c, the pair {γ_ρ, γ̄_ρ} contributes
    e^{−4iaxβ}·p(γ_ρ) conj p(γ̄_ρ) + c.c. = 2 Re(e^{−4iaxβ} u conj w),  u = p(γ_ρ), w = p(γ̄_ρ),
of weight modulus exactly 1 (v = M_c). 2Re(e^{iθ} u w̄) has signature (1,1) in (u, w) for every θ.

**Step 2 (negative subspace).** Let r = #pairs in F_c ≥ 1 and z_1, …, z_{2r} be the points of F_c; they are
distinct from one another and from ±i/2. By Lagrange interpolation (degree ≤ 2r+1), for each pair j and each a
there exists p_j^{(a)} with p(γ_j) = 1, p(γ̄_j) = −e^{−4iax_jβ_j}… (chosen so the pair's term equals −2), p = 0 at
the other points of F_c and at ±i/2. The coefficients of p_j^{(a)} are uniformly bounded in a (data of modulus 1
at fixed nodes). On V_a = span{p_j^{(a)}}: Q_a = −2·Id in the basis (disjoint pairs). For the rest, with a ≥ 1,
    |E_a(p)| ≤ e^{−2(a−1)δ_c} Σ_{ρ∉F_c} e^{2(v_ρ−M_c)} |p(γ_ρ)p(conj γ_ρ)| ≤ C e^{−2(a−1)δ_c}‖p‖²,
because the sum converges (Gaussian factor e^{−2x²} against a zero density ≍ log) and the coefficients are
bounded. For a large, W < 0 on V_a: n₋ ≥ r ≥ 1 in a block localized at c.

**Step 3 (many blocks).** If there are infinitely many off-line zeros, their real parts Re γ_ρ are unbounded
(finitely many zeros in each bounded strip). Choose c_1, …, c_k ordinates of off-line zeros with
|c_i − c_j| > 2. The functions of blocks i ≠ j have cross terms bounded by
    e^{−a[(M_{c_i} − v_ρ(c_i)) + (M_{c_j} − v_ρ(c_j))]}·(…),
and the bracket is ≥ ½(c_i − c_j)² − 1 > 0 for every ρ (since M ≤ ¼, β² ≤ ¼, x_i² + x_j² ≥ ½(c_i−c_j)²); summable
as above. So the matrix of W on ⊕_i V_a^{(i)} is diag(−2 Id) + O(e^{−κa}): n₋ ≥ k. Since k is arbitrary,
n₋(W|𝒳∩prim) = ∞, and by Step 0(iii) n₋(W|C_c^∞∩prim) = ∞. Contrapositive: finite index ⟹ finitely many
off-line zeros. ∎

**Consequences.**
- R183_031 Lemma 1.1(b): PROVED (no longer dependent on an unverified citation to Yoshida). Theorem 1 and Cor 1.2
  without RH: PROVED.
- R184_004 Prop 2(iv): PROVED; together with (ii)–(iii): **m < ∞ ⟺ sup_T N(T) < ∞, and then sup N = 2m** (iii
  remains CITED R162_2602 Thm 6). The "⟺" of line C_B in R184_004 §1.3 is no longer CONDITIONAL.
- Free quantitative variant: Step 3 gives n₋ ≥ #{groups of off-line ordinates separated by > 2}.

**Scope correction.** The argument uses all windows (the Gaussian has no compact support; the approximation lives
in I_T with T large). It gives nothing at a fixed window; it is consistent with W11-∞.

## 5. Conclusion for the program

1. The non-E1 content in the joint direction is **finite windows**: extending an analytic proof (not a numerical
   certificate) from ½log2 (CC) to ½log3 and beyond (R185_006, in parallel). It is a real, finite gain.
2. By Theorem M, that gain cannot be bootstrapped: each window is a new problem with margin
   exp(−e^{(2−ε)T}).
3. Every mechanism for all T in the certificate class or in 𝔐_mult is the explicit formula (W11-sharp (b)–(d)).
   The only genuine residue is mechanisms outside those classes (§2.4).
