## FATAL

**F1 (R185_002 Thm D).** The reduction "a lower bound on the count ψ(Xe^Δ) − ψ(X) ≥ (1−η)(e^Δ−1)X gives Tail_K ≥ (1−η′)𝒫_K − O(1)" is false.
- Ψ̌_K is continuous with support in [−2T_c−Δ, 2T_c+Δ], so it vanishes at u = 2T_c+Δ.
- A single counting bound over the whole [X, Xe^Δ] allows the primes to concentrate where Ψ̌_K is small, for example near the right endpoint. Then Tail_K can end up close to 0, not to (1−η′)𝒫_K.
- The claim η′ ≍ η·(oscillation) + η has no proof and is false in general. For something like this to hold, counting information at the resolution scale is needed, i.e. on every subinterval of [X, Xe^Δ]. That is a different hypothesis.
- For the family P (Ψ̌ with variable sign) the memo already admits there is not even a lower bound.

Second defect, independent of the previous one: "η ≲ X^{δ_q−½} at a single scale X ⟺ Θ ≤ ½+δ′" is not a well-formed statement. The Ingham/Landau equivalence (R166_802 Thm 3) is asymptotic as X → ∞, and a single fixed scale does not determine Θ. What is correct: a family of such bounds as X → ∞ implies Θ ≤ ½ + δ′.

**Downgrade.** Thm D moves to ARGUED. Possible reformulation: "if for every subinterval J ⊂ [X, Xe^Δ] we have |ψ(J) − |J|| ≤ η|J|X/…, then …", with "uniformly in X" for the E1 part.

## MAJOR

**M1 (R185_001 Thm 5(b), closure).** "In general replace W₂ by its closure, which only strengthens the exclusion hypothesis" is not a proof step. The theorem's hypothesis is Sh∩W₂ = ∅. If t_ζ ∈ cl(W₂)∖W₂, there is no strict separation and the conclusion can fail.

One must add the hypothesis "t_ζ ∉ cl(W₂)", or else guarantee that 𝓡 + C̄ is closed. Sufficient criterion: C̄ ⊂ ℝ^m_{≥0} is closed and pointed, so 𝓡 + C̄ is closed if 𝓡 is compact or, more generally, if rec(𝓡) ∩ (−C̄) = {0}. One also needs W₂ ≠ ∅, which is trivial since 𝓡 ≠ ∅.

**M2 (R185_001 Thm 5(b) / Cor 7, scope).** W₂ is a **relaxation**: the cone C̄ forgets the integrality of multiplicities and the Riemann–von Mangoldt density, and includes o = 0. Hence the theorem classifies sentences that exclude the relaxed set, not the actual witness set. The memo states this in (ρ2), but the table, Cor 7, and the "For Paper 47" text ("every sentence … that excludes the witness") state it without the restriction. In (M1) there is no problem, because O_U is the definition from R166_802. It should read "excludes the witness set W (= O_U or W₂)".

**M3 (R185_002 Prop A and §0, normalization).** U_K = 𝒫_K − Q + O(1) + S treats "(archimedean + window)" as O(1). But the window part of 𝔄_K is the sum of primes in the window plus the window's pole. Both are ≍ e^{T_c} and their difference is a PNT error at scale X, which unconditionally is only O(X^{1/2}·exp(−c√log X)) after the n^{−1/2} normalization, not O(1). The exponent comparison "e^{T_c} versus e^{2δ_q T_c}" in Prop A and Thm D is not justified without controlling that term. Moreover, dyadic Chebyshev says nothing if Δ < log 2. Downgrade Prop A to ARGUED. Its NO-GO conclusion is plausible, but the one-line proof ("partial sum") is not enough.

**M4 (R185_002 Thm F, conclusion).** The core is correct (see the verification). But "this is R166_802 Thm 1 and, by Thm 2, E1" is an illegitimate step. Thm 2 transfers via the explicit formula **of ζ**, and the deleted system Λ_∅ satisfies (1.1) with no set of zeros. What is PROVED: exclusion via B_int + window ⟺ ∃K: E_K > U_K, in (M1), with E_K the contribution of prime powers, which does not change. Reading that condition as E1 requires a separate argument. Via the true identity, U_K < E_K ⟺ Z_K(Σ_ζ) + (Tail_K(Λ_ζ) − E_K) + S < Q^{hyp}_K, an inequality on the zero side with the explicit tail prime term. Label for "⇒ E1": ARGUED. The last bullet ("add counting ⇒ Thm D ⇒ E1") inherits F1.

## MINOR

- **m1 (Cor 2.1).** Empty boxes appear in the DNF, which trivially avoid O_U. (a) requires I_i ≠ ∅, so they must be explicitly discarded.
- **m2 (Lemma 4, requested key point).** C̄ is generated by evaluations at **every γ ∈ ℝ**, not at the actual real zeros of ζ. That is correct: the witness set quantifies over hypothetical configurations of real zeros, and the memo nowhere uses the actual zeros of ζ. If the actual zeros were used, C̄* would be larger (non-negativity only on that set) and K_a could fall outside 𝒦. This does not happen, but it should be stated explicitly in the statement.
  - C̄ is closed by definition (closure), and the dual of the closure coincides with the dual of the generators.
  - The step through the zeros of G is correct: G is entire, nonzero, with isolated zeros, and K_a is continuous.
  - The series o = Σ v(γ) has terms ≥ 0 and converges, so the limit of the partial sums lies in C̄.
  - It must be added that K_a inherits the type ≤ max Δ_i and the integrability or decay required by 𝒦.
- **m3 (Thm 5(b), extreme ray).** The function a ↦ σ(a) − a·t_ζ is convex (supremum of linear functions), not "concave". The minimum over a compact base exists, but it is extreme only for 𝓡 = {0}, as stated. C̄* has a compact base only if it is pointed, i.e. if C̄ has nonempty interior. With repeated or linearly dependent tests in ℝ, C̄* contains a line. This hypothesis must be added or the sentence removed.
- **m4 (Thm 6).** The identity t_ζ = 𝔄 − Z(Σ_ζ) is the **true** explicit formula, not a hypothesis: correct. But the admissibility of Ψ = G²K for Weil (decay/integrability of K on ℝ, absolute convergence of Σ_ρ) is tacitly inherited from R166_802 §1 and must be cited. The "equivalently" of (ii) is correct in both directions with S(K*) = S_𝓡(a), and in (M1) with S = Σ a_iS_i.
- **m5 (linearity of 𝔄_K, flagged risk).** Verified. For fixed G, Ψ = G²K is linear in K, and so is Ψ̌. The polar term is a linear evaluation or integral of Ψ (Ψ at ±i/2, or ∫Ψ̌·2cosh(u/2)). The archimedean and window-prime parts are linear functionals. In eq:nuw of Paper 47 the polar term 2w(u)cosh(u/2) is linear in the weight and does not depend on K nonlinearly. **No obstruction.** But note: the w of def:W is the certificate's weight, not K. The identification of 𝔄_K with the terms of Paper 47 must be written out before integrating.
- **m6 (Thm C).** (i) is simply conv{0,1}^P = [0,1]^P; Krein–Milman is unnecessary. (ii) is correct: b_θ/Λ = ½(1+cos(γ log n+θ)) ∈ [0,1] on the **same** support. In ℝ^P only the primes are seen, and the prime powers p^k (E_K) are modified the same way, which should be mentioned. (iii) is correct for C closed and solid inside the orthant. The conclusion should not cite Thm 1 (bounds on a Tail_K), but rather: solid C ∋ 0 ⇒ Tail = E_K is compatible ⇒ it excludes only if U_K < E_K. It is the same mechanism as Thm F.
- **m7 (Prop E, line by line).**
  - ζ: correct (c_n = 1).
  - b_θ: c_p = ½(1+cos(γ log p+θ)). A single p with value ∉ {0,1} suffices, which is immediate for γ ≠ 0. Correct.
  - Λ̃ (R162_2601: Λ̃(n) = 1 − Σ2Re n^{ρ_j−1}, except for finitely many n): for p a large prime, c_p = Λ̃(p)/log p ∈ (0,1). (II) is false, and the separation is **legitimate** and provable. It is exactly the content "it is not the logarithmic derivative of an integral Euler product", which is what B_int asserts. Write this line instead of "it is precisely the property that separates it".
  - DMV: according to R162_2601 it has atoms at logs of g-integers, not at logs of ℕ, so (I) fails. Correct for non-integer g-primes. If a variant had integer g-primes with non-integer multiplicity, it would separate (II). Mention it.
  - DH and L(u,χ): "(III) fails" or "c_n ∉ ℤ_{≥0}" requires exhibiting a concrete n and specifying which Λ is used (−f′/f of DH has complex coefficients). ARGUED until written out.
  - f_t, M_m "undefined": acceptable, but an undefined statement must count as false, and this must be stated.
- **m8 (Thm F, requested verifications).**
  - Window: Λ_{P′} = Λ for n < X, and the segment > Xe^Δ is irrelevant due to the support of Ψ̌. Correct.
  - E_K: if p ≥ X, then p² ≥ X² > Xe^Δ when Δ < log X, and the powers of p < X are untouched. E_K does not change. Correct.
  - Functional equation: B_int does not encode it and the deletion destroys it. That is irrelevant **because the argument is a proof-transfer one (W3 type)**: every proof that uses only B_int + window data applies literally to Λ_{P′}. It is not claimed that the deleted system has the same zeros. The memo must say so, because now "preserves the window" reads as if Λ_{P′} were a candidate for (1.1).
