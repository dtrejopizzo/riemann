# Simultaneous detection on a family of steps

Fix a≥1/2, an undamped parity of 088 and an increasing sequence r_n→∞ such that r_(n+1)/r_n→1. Let F(T) be the normalized energy of that parity, continuous by local uniform convergence of the series of 088. If the set of h>0 such that F(r_n h)≥0 eventually is non-meager in (0,∞), the global sign holds. The threshold in n may depend on h. Conversely, under the sign all steps work. For example, r_n=n^k is allowed for any fixed integer k≥1.

Indeed the set of good steps is the countable union of the closed sets E_N=∩_{n≥N}{h:F(r_n h)≥0}. If all of them had empty interior, the union would be meager by definition. Hence some E_N contains [u,v] with 0<u<v. For n large, r_(n+1)u≤r_n v, so the intervals [r_n u,r_n v] cover a half-line. On it F≥0 and 088 applies. In particular if the sign fails, for a residual set of steps there are infinitely many strictly negative samples. The same residual set can serve simultaneously for both parities and for a prescribed countable list of values of a and admissible sequences, by taking the intersection.

**Scope.** This is a topological lemma on continuous functions applied to the spectral equivalence of 088. A countable list of prescribed steps is still meager, even if dense. The selection quartet 089 explains the risk of a single grid. To use the criterion in the proof direction, an arithmetic reason is missing to obtain a non-meager set of good steps.
