## 1. The site LP and its dual
Fix finite X ⊂ L, n = |X|, write E_X = {(x,y) : x ≠ y}. Since the log p are ℚ-linearly independent (unique factorisation — the · input),
the map ι: X → ℤ^X, x ↦ e_x, and the differences e_x − e_y ((x,y) ∈ E_X) are pairwise distinct non-zero characters of the torus 𝕋^X.
**Definition 1.1 (torus certificate).** A positive Borel measure η on 𝕋^X, invariant under z ↦ z̄, with η̂(e_x − e_y) = ∫ z_x z̄_y dη = 𝖡(x − y) for all
(x,y) ∈ E_X. Its value is 𝖡(0) − η(𝕋^X). λ_𝕋(X) := sup of values (−∞ if none).
**Proposition 1.2 (weak duality, attainment; PROVED).** (a) For every torus certificate and unit s ∈ ℝ^X:
s^T M_X s = (𝖡(0) − η(𝕋^X)) + ∫ |P_s(z)|² dη(z),  P_s(z) := Σ_x s_x z_x.
Hence λ_min(M_X) ≥ λ_𝕋(X). (b) If certificates exist, λ_𝕋(X) is attained (compactness of 𝕋^X, weak-* closedness of the moment constraints).
*Proof.* (a) Expand |P_s|²: diagonal terms give η(𝕋^X)|s|², off-diagonal ones give s_xs_y𝖡(x − y). (b) Minimizing sequence has bounded mass
(≤ 𝖡(0) − λ + const); Banach–Alaoglu; moments are continuous functionals. ∎
**Proposition 1.3 (Kronecker realisation; PROVED, Kronecker CITED).** The closure of {ψ|_{X−X} : ψ = μ̂, μ ≥ 0 finite symmetric on ℝ} coincides with
the set of edge-moment vectors of positive symmetric measures on 𝕋^X. So torus certificates are exactly the limits of *PD-extension certificates*:
PD functions ψ on ℝ with ψ = 𝖡 on the finite set (X − X)∖{0} and ψ(0) ≤ 𝖡(0) — the CE/RV interpolation shape (values prescribed on a discrete set).
*Proof.* t ↦ (e^{itx})_x has dense image in 𝕋^X (Kronecker; ℚ-independence) and is equidistributed for Haar (Weyl); pushforwards of measures on ℝ
are weak-* dense in the positive measures on 𝕋^X (approximate η by atomic measures, each atom by an orbit point). ∎
Difference with P47's dual: there ψ must equal the window symbol on all of [−2T, 2T] and the free part lives on |u| ≥ 2T; here ψ is free
everywhere except on the finite set X − X. This is the restoration of (V1): **discrete primal, attained dual.**

## 2. Slackness: the magic vanishing condition
**Theorem 2.1 (exactness and slackness; PROVED).** λ_𝕋(X) = λ_min(M_X) iff there is a torus certificate η with η(𝕋^X) = 𝖡(0) − λ_min(M_X), and then
supp η ⊂ Z_s := {z ∈ 𝕋^X : P_s(z) = 0} for **every** bottom eigenvector s of M_X. Equivalently: M_X − λ_min I ∈ 𝒰_X := {∫ Re(zz*) dη : η ≥ 0},
the cone generated by the rank-≤2 real correlation matrices [cos(θ_x − θ_y)].
*Proof.* From Prop 1.2(a) with s a bottom eigenvector: equality forces ∫|P_s|²dη = 0. Conversely a certificate of that mass gives equality. The
real part arises from z ↦ z̄ invariance; Re(zz*) = [cos(θ_x − θ_y)]. ∎
This is the exact analogue of Viazovska's double zeros at √(2n): the certificate lives on the vanishing locus of the "Fourier transform" of
the primal optimum (P_s restricted to the Kronecker line is ŝ(t) = Σ s_x e^{itx}).
**Theorem 2.2 (where the gap sits; PROVED + CITED).** (a) If n ≤ 5, every n×n real correlation matrix is a convex combination of rank-≤2 ones
(extreme points of the elliptope have rank r with r(r+1)/2 ≤ n; CITED: Grone–Pierce–Watkins 1990, Li–Tam 1994), so for |X| ≤ 5 and
λ_min(M_X) < 𝖡(0), λ_𝕋(X) = λ_min(M_X): the torus certificate is **exact**. (b) For n ≥ 6 there are rank-3 extreme correlation matrices
(Laurent–Poljak 1995/96, CITED); for such configurations λ_𝕋 < λ_min strictly is possible: single-X torus certificates are lossy in value.
*Proof.* (a) Normalise M_X − λ_min I by its diagonal 𝖡(0) − λ_min to a correlation matrix and decompose. (b) Cited. ∎
**Theorem 2.3 (no loss at the level of the sign; PROVED).** (eq:target) ⟺ λ_𝕋(X) ≥ 0 for every finite X ⊂ L.
*Proof.* ⇐: Prop 1.2(a) and K-S. ⇒: (eq:target) ⟺ 𝖡 PD on ℝ (thm:oneprofile); Bochner gives μ_𝖡 ≥ 0 with μ̂_𝖡 = 𝖡; its pushforward under
t ↦ (e^{itx}) is a torus certificate of mass 𝖡(0), value 0. ∎
So the site LP is an **exact restatement** (REF-D) with attained duals; Grothendieck-type losses affect the value, never the sign.
**Corollary 2.4 (conic dual, Grothendieck form; PROVED by finite-dimensional conic duality on C(𝕋^X)).** With c*(X) := min{η(𝕋^X) : η torus
certificate}: c*(X) = sup{ −Σ_{x≠y} A_xy 𝖡(x − y) : A real symmetric, zero diagonal, min_{z∈𝕋^X} z*Az ≥ −1 }. Hence (eq:target) ⟺ for every finite
X ⊂ L and every zero-diagonal A with unimodular minimum ≥ −1: Σ_{x≠y}A_xy𝖡(x − y) ≥ −𝖡(0). Witnesses A are "Grothendieck witnesses":
quadratic forms bounded below only on unimodular vectors, i.e. on Ĝ-twisted Dirichlet polynomials (CA_K Prop 2.1 class). (Slater point: A = 0.)

## 3. What survives of (V2), (V3); the +/· reading
**+ and ·.** · enters exactly once: ℚ-independence of log p makes 𝕋^X the full torus (a finite quotient of the solenoid Ĝ) and the edge
characters distinct. + enters through the values 𝖡(log p − log q) at the edges (additive kernel, near-coincidence ratios p/q — Div ≡ 0 on
primes, K-S). ℤ enters only through which p are prime; the FE only inside 𝖡 (through α and c₀). A magic η must therefore be a measure on the
solenoid quotient with prescribed edge moments (·) equal to values of an additive kernel (+), supported on Z_s.
**Proposition 3.1 (B″ and FE-class; PROVED).** Thms 2.1–2.3 and Cor 2.4 hold verbatim for every even continuous 𝖡 and every ℚ-independent site set
(Beurling primes with ℚ-independent logs included, O11); for integer sites (Epstein, O10) the torus is replaced by 𝕋^{π(M)} via exponent vectors
and the same statements hold with the edge relation m/k. So the construction is comb-generic and FE-generic: it separates nothing; Epstein
simply has some X with λ_𝕋(X) < 0 (no certificate), consistent and uninformative.
**Proposition 3.2 (the magic set is the minimizer; REF-D).** Exact certificates (Thm 2.1) require Z_s, s the bottom eigenvector of M_X: the
vanishing set is unknown in exactly the way {γ} is unknown in CA_L_001 §2. A *canonical* s-independent η (the analogue of Viazovska's explicit
modular form) would have to have value ≥ 0 for all X; the only canonical one available is the Bochner pushforward of Thm 2.3, which exists
iff 𝖡 is PD — the target. Haar (η = 𝖡(0)·m) has zero edge moments (fails unless 𝖡 vanishes on edges); the Kronecker line ν₀ is CA_H_002.
**Remark 3.3 ([crit], ARGUED).** Realising η on ℝ (Prop 1.3) needs Kronecker approximations of η's support points; quantitative Kronecker for
log p, p ≤ e^{2T}, uses linear forms in logarithms (Baker), with times exponential in n. A certificate must also resolve λ_min(M_X), which is of
size λ_A (tiny, P47 [crit]). Neither obstructs the restatement; both obstruct an explicit construction.
**Modular construction of η?** Modular/Eisenstein objects produce measures on ℝ (Laplace/Mellin transforms in y), i.e. points of the Kronecker
line closure; an exact η on Z_s ⊂ 𝕋^X is generically not on the line (Z_s ∩ line = zeros of ŝ, a discrete set of t). By Prop 1.3 line measures
only approximate; exactness (V3) fails for the same reason as CA_L_001 Thm 1.1, now one level up: exact = on the torus, constructive = on the line.
