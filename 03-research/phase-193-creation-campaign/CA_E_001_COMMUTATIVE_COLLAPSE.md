## 1. Lemma 0 (target as a PD-function problem on the abelian group G; PROVED)

## 2. Lemma 1 (the Bochner measure of φ is carried by the Kronecker line; PROVED)
If φ is PD on G, then 𝖡 is PD on ℝ, 𝖡 = ν̂ with ν a finite positive measure on ℝ, and the Bochner measure μ_φ on Ĝ equals ι_*ν. In
particular μ_φ(Ĝ ∖ ι(ℝ)) = 0 and μ_φ(ι(ℝ)) = 𝖡(0).
*Proof.* PD on G gives Σ s_j s̄_l 𝖡(d_j − d_l) ≥ 0 for d_j ∈ log G, a dense subgroup of ℝ; continuity of 𝖡 extends this to all d_j ∈ ℝ
(as in the proof of prop:AM(i)). Bochner on ℝ gives ν. ι(ℝ) is σ-compact, hence Borel. ι_*ν is a finite positive Radon measure on Ĝ with
Fourier transform ∫χ(q) d(ι_*ν)(χ) = ∫ q^{iτ} dν(τ) = 𝖡(log q) = φ(q); uniqueness of Fourier–Stieltjes transforms on the compact group Ĝ
gives μ_φ = ι_*ν. ∎

## 3. Theorem 1 (separability: product test vectors suffice; PROVED)
For a finite set S of primes, a **product test vector** is s = ⊗_{p∈S} c_p, i.e. s_m = Π_{p∈S} c_p(v_p(m)) for S-smooth m, with each c_p a
finitely supported complex sequence on ℕ₀; its Dirichlet polynomial is the Euler-product polynomial Π_{p∈S} P_p(p^{−iτ}). Then
**(eq:target) ⟺ Σ_{m,k} s_m s̄_k 𝖡(log m − log k) ≥ 0 for every finite S and every product test vector s.**
*Proof.* (⇒) Lemma 0. (⇐) By translation invariance it suffices to show: if f: ℤ^S → ℂ is a function with
Σ_{x,y} c(x)c̄(y) f(x − y) ≥ 0 for all product c = ⊗c_p (finite support), then f is PD on ℤ^S. Induction on |S|. |S| = 1: every c is a
product. Step S = S′ ⊔ {p}, write x = (u, w) ∈ ℤ^{S′} × ℤ. For fixed finitely supported b on ℤ put g_b(u) := Σ_{k,l} b_k b̄_l f(u, k − l). Product
vectors a ⊗ b (a a product over S′) give Σ a a̅ g_b ≥ 0, so g_b is PD on ℤ^{S′} by induction; let ρ_b ≥ 0 be its Bochner measure on 𝕋^{S′}.
b ↦ ρ_b is a Hermitian quadratic form with values in measures; by polarization there are complex measures ρ_w (w ∈ ℤ) with
ρ_b = Σ_{k,l} b_k b̄_l ρ_{k−l} and ρ̂_w(u) = f(u, w). For each Borel E ⊂ 𝕋^{S′}, b ↦ ρ_b(E) ≥ 0, so w ↦ ρ_w(E) is PD on ℤ; hence
|ρ_w(E)| ≤ ρ₀(E), so ρ_w ≪ ρ₀, ρ_w = h_w ρ₀. For ρ₀-a.e. θ, w ↦ h_w(θ) is PD on ℤ (countably many rational coefficient vectors suffice;
continuity in the coefficients), so h_w(θ) = ∫ e^{iwη} dκ_θ(η) with κ_θ ≥ 0 on 𝕋, measurable in θ (its Fourier coefficients are). Then
κ(dθ, dη) := κ_θ(dη) ρ₀(dθ) ≥ 0 on 𝕋^{S′} × 𝕋 and κ̂(u, w) = ∫ e^{iuθ} h_w(θ) dρ₀(θ) = ρ̂_w(u) = f(u, w). So f is PD on ℤ^S. Finally the
measures μ_S on 𝕋^S are consistent under projection, so they define a positive Radon measure μ on Ĝ = lim 𝕋^S with μ̂ = φ; φ is PD on G,
and Lemma 0 concludes. No growth bound on φ is assumed (boundedness is an output: |φ| ≤ φ(1)). ∎

## 4. Theorem 2 (no Schur factorization through a product kernel; PROVED)
Let g, b be PD functions on G with φ = g·b on G. Suppose
(A′) μ_g(x + ι(ℝ)) = 0 for every x ∈ Ĝ.
Then a contradiction follows. So **no such factorization exists**. (A′) holds in each of these cases:
(a) g(q) = g_p(v_p(q))·g′(q p^{−v_p(q)}) for one prime p, with g_p PD on ℤ whose Bochner measure on S¹ has no atoms (Wiener:
    (2N+1)^{−1}Σ_{|k|≤N}|g_p(k)|² → 0), and g′ PD;
(b) μ_g absolutely continuous with respect to Haar measure on Ĝ (e.g. g ∈ ℓ²(G) PD).
Covered kernels: the GCD (Smith) kernels (gcd(m,k)²/mk)^β, β > 0 (local Poisson kernels); Haagerup kernels e^{−tℓ}, ℓ(q) = Σ w_p|v_p(q)|
with some w_p > 0; Gaussian kernels e^{−tΣw_pv_p(q)²}; two-point functions of ITPFI product states with one non-degenerate atomless
local factor (the prime-gas / primon states of seed E7).
*Proof.* φ = gb is PD (Schur), so Lemma 1 applies: μ_φ = ι_*ν, μ_φ(ι(ℝ)) = 𝖡(0) > 0. Also μ_φ = μ_g * μ_b (Fourier transform of a
product). Then μ_φ(ι(ℝ)) = ∫ μ_g(ι(ℝ) − y) dμ_b(y) = 0 by (A′), a contradiction.
(a) ⇒ (A′): write Ĝ = S¹_p × Ĝ′ (coordinate p and the rest); μ_g = μ_{g,p} ⊗ μ′. For fixed θ′ ∈ Ĝ′ the fiber
{θ_p : (θ_p, θ′) ∈ x + ι(ℝ)} has at most one point, because τ ↦ (q^{iτ})_{q prime, q≠p} is injective (two primes q₁, q₂ ≠ p already
determine τ, log q₁/log q₂ ∉ ℚ). Fubini and atomlessness give μ_g(x + ι(ℝ)) = 0. (b) ⇒ (A′): ι(ℝ) is a σ-compact subgroup ≠ Ĝ; if it had
positive Haar measure, Steinhaus would make it open, hence closed and equal to the connected group Ĝ. So every translate is Haar-null. ∎

**Remark (scope).** Theorem 2 concerns M-uniform ratio kernels (functions on G). For one fixed M, 𝔸_M = 𝔾_M ∘ 𝔹_M with an M-dependent

theorem. What survives: g whose Bochner measure charges a translate of the line, e.g. g = 𝖡₁∘log with 𝖡₁ PD on ℝ. Then φ = gb means
𝖡 = 𝖡₁𝖡₂ on ℝ, i.e. ν = ν₁ * ν₂: a convolution factorization of the profile measure ν, which the explicit formula identifies with a
zero-side measure (thm:Z type); so it is (R)(4), or a square with Cauchy–Schwarz ((R)(3), N_018). Label of this last reading: ARGUED.
