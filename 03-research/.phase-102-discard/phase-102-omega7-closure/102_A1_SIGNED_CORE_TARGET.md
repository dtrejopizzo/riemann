# 102 A1 signed core target

## Target

After A0, prove the finite-core inequality

[
  -n+
  \int_1^{e^{T(n)}}(\psi(y)-y)f'_{n,0}(y)\,dy
  \ge
  -{3\over4}\lambda_n^{arch}
  \qquad(n\ge8).
]

This is the force-RH core isolated by the direct Li route.

## Constraint

The proof must not use absolute values before the signed cancellation has
occurred. It must not reduce to a positive factorization that assumes the
Li positivity conclusion.

## Required output

Either prove the target, or replace it by a sharper equivalent theorem whose
proof would imply

[
  \lambda_n^{prime}\ge-\lambda_n^{arch}\qquad(n\ge8).
]

Any failed candidate must specify the no-go class it actually eliminates.
