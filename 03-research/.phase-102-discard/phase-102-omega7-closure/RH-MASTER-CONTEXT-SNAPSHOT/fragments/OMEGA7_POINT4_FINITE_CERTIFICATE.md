# Omega7 point 4 finite certificate

## Statement

For the Li--Keiper coefficients attached to

[
  xi(s)=1/2 s(s-1) pi^{-s/2} Gamma(s/2) zeta(s),
]

the seven exceptional archimedean indices satisfy

[
  lambda_n>0, \qquad 1 <= n <= 7,
]

by a finite Euler--Gamma/Stieltjes computation. No zero of zeta enters the
calculation.

This closes the finite part of point 4 in the restart list, modulo the
standard enclosure of the finitely many constants displayed below by
Euler--Maclaurin interval arithmetic.

## Exact finite formula

Put `z=s-1` and write

[
  zeta(1+z)=z^{-1}+\sum_{j>=0} (-1)^j gamma_j z^j/j!,
]

so that

[
  z zeta(1+z)
  =
  1+\sum_{j>=0} (-1)^j gamma_j z^{j+1}/j!.
]

Let

[
  log(z zeta(1+z))=\sum_{k>=1} p_k z^k.
]

Equivalently, setting

[
  q_r={(-1)^{r-1}gamma_{r-1}\over (r-1)!},
]

the coefficients are computed by the finite recurrence

[
  p_1=q_1,\qquad
  p_r=q_r-{1\over r}\sum_{k=1}^{r-1} k p_k q_{r-k}.
]

For each fixed `n`, the coefficient `p_k`, `k<=n`, is therefore a rational
polynomial in `gamma_0,...,gamma_{k-1}`. The prime-side contribution is

[
  lambda_n^{prime}
  =
  n\sum_{k=1}^n {n-1 \choose k-1}p_k.
]

The archimedean contribution is

[
  lambda_n^{arch}
  =
  1-{n\over 2}(gamma+\log(4pi))
  +\sum_{k=2}^n (-1)^k {n\choose k}(1-2^{-k}) zeta(k).
]

Therefore

[
  lambda_n
  =
  lambda_n^{arch}+lambda_n^{prime}
]

is a rational expression in the finite list

[
  gamma_0,\ldots,gamma_6,\quad \log(4pi),\quad zeta(2),\ldots,zeta(7).
]

This is the promised zero-free finite certificate.

Each inclusion is a one-dimensional constant enclosure; it can be certified
without zeros by the Euler--Maclaurin summation formula for `zeta(s)` and for
the Laurent coefficients at `s=1`, with the usual Bernoulli remainder bound.
The finite calculation below only needs these enclosures as input.

A completely rational certification route is as follows. For `0 <= j <= 6`,
put

[
  f_j(x)={\log^j x\over x},\qquad
  A_j(N)=\sum_{k=1}^N f_j(k)-{\log^{j+1}N\over j+1}.
]

Euler--Maclaurin gives, for `N=256`,

[
  gamma_j
  =
  A_j(N)-{1\over2}f_j(N)
  -\sum_{r=1}^{8}{B_{2r}\over(2r)!}f_j^{(2r-1)}(N)+R_{j,N}.
]

Writing

[
  f_j^{(q)}(x)=x^{-q-1}P_{j,q}(\log x),
]

the integer polynomials are generated by

[
  P_{j,0}(t)=t^j,\qquad
  P_{j,q+1}(t)=P'_{j,q}(t)-(q+1)P_{j,q}(t).
]

If `P_{j,16}(t)=sum_l c_l t^l`, then the remainder is bounded by

[
 |R_{j,N}|
 \le
 {4\over 6^{16}}
 \sum_l |c_l|N^{-16}
 \sum_{a=0}^{l}
 {l!\over(l-a)!\,16^{a+1}}(\log N)^{l-a}.
]

The logarithms are enclosed by the rational `artanh` series after reducing
`x=2^e u`, `1 <= u < 2`:

[
  \log u
  =
  2\sum_{r=0}^{K-1}{y^{2r+1}\over2r+1}+E_K,
  \qquad y={u-1\over u+1},
]

[
  0\le E_K\le {2y^{2K+1}\over(2K+1)(1-y^2)}.
]

The value of `pi` is enclosed by Machin's identity

[
  pi=16\arctan(1/5)-4\arctan(1/239),
]

with alternating-series remainders. The odd zeta-values use positive partial
sums plus the integral tail:

[
  \sum_{m=1}^{M}{1\over m^s}+{1\over(s-1)(M+1)^{s-1}}
  \le zeta(s)\le
  \sum_{m=1}^{M}{1\over m^s}+{1\over(s-1)M^{s-1}}
]

for `s=3,5,7`. The even zeta-values are then obtained from `pi`.
