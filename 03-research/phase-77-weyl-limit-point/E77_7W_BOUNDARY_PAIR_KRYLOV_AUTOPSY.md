# E77.7w - Boundary-pair Krylov autopsy

**Run:** 2026-07-18.

## 1. Purpose

E77.7v refuted source-only nonspectral blocks and left the next admissible
target:

```text
BOUNDARY-PAIR-KRYLOV-BLOCK:
build the resonant package from both sides of the boundary relation.
```

This note audits the smallest concrete version of that idea.

## 2. Probe

Companion:

```text
E77_7w_boundary_pair_krylov_probe.py
E77_7w_boundary_pair_krylov_results.json
```

Command:

```bash
python3 E77_7w_boundary_pair_krylov_probe.py \
  --lambda 6 --max-modes 18 --dps 60 --depth 2
```

The block is the orthonormalized finite space generated by

```text
b_N,
A_N(mu_ref)b_N,
c_{z0},
A_N(mu_ref)c_{z0},
```

where `c_{z0}` is the inner Cauchy-anchor vector with entries

```text
1 / (i sigma_0 - d_j).
```

This is a genuinely coupled source-plus-row block.

## 3. Result

### Zeta

The boundary-pair block has a visible effect, stronger than the source-only
Krylov block, but it is not uniformly stabilizing:

```text
N=11: raw 0.0831 -> reg 0.0311
N=15: raw 0.1065 -> reg 0.0713
N=17: raw 0.0804 -> reg 0.0533
```

Yet many rows worsen:

```text
N=7:  raw 0.1697 -> reg 0.2894
N=10: raw 0.0766 -> reg 0.1455
N=18: raw 0.0527 -> reg 0.0744.
```

So the coupled boundary-pair block captures some real geometry, but still not
the full singular object.

### Planted build

The same block is very effective in the earliest planted rows:

```text
N=6: raw 8.5e-9 -> reg 1.3e-13
N=7: raw 2.2e-8 -> reg 7.9e-12
N=8: raw 2.5e-8 -> reg 1.4e-8.
```

But from `N=10` onward it is consistently worse:

```text
N=10: raw 1.8e-7 -> reg 5.9e-7
N=12: raw 6.3e-7 -> reg 5.0e-6
N=18: raw 1.9e-6 -> reg 4.2e-6.
```

So even the coupled source-plus-anchor Krylov block is not a stable theorem
target.

## 4. Reading

This sharpens the front once more.

```text
1. adding the Cauchy side does reveal more of the right geometry;
2. but a hand-built finite Krylov block is still too rigid;
3. the remaining object must be intrinsic to the Schur/Feshbach reduction
   itself, not just to a chosen generating set.
```

Compared with E77.7v:

```text
source-only Krylov block: some effect, mostly on planted early rows;
boundary-pair Krylov block: stronger effect, including some late zeta rows.
```

That is real progress in localization, even though it does not close.

## 5. What is refuted

The following target is refuted:

```text
BOUNDARY-PAIR-KRYLOV-BLOCK
```

as a sufficient singular-section regularizer.  It is informative, but not
coherent enough to serve as the closure object.

## 6. Smaller live object

The next admissible reduction is:

```text
INTRINSIC-SCHUR-FESHBACH-BLOCK:
construct the resonant package directly from the finite Schur/Feshbach data
(for example the coupled (tau, kappa, Sigma) geometry or a self-energy block
defined before quotienting), rather than from an external trial subspace.
```

This is strictly smaller and more faithful than every refuted construction:

```text
spectral cutoffs,
scalar self-energy rankings,
source-only Krylov blocks,
boundary-pair Krylov blocks.
```
