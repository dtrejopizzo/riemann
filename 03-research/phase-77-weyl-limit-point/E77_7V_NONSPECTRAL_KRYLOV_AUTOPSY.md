# E77.7v - Nonspectral Krylov autopsy

**Run:** 2026-07-18.

## 1. Purpose

E77.7u showed that every spectral Feshbach block is already covered by the
mode-subtraction autopsies.  The next admissible front was therefore a
genuinely **nonspectral** boundary-generated block.

This note audits the smallest such candidate:

```text
Krylov block generated by the boundary source b_N.
```

## 2. Probe

Companion:

```text
E77_7v_nonspectral_krylov_probe.py
E77_7v_nonspectral_krylov_results.json
```

Command:

```bash
python3 E77_7v_nonspectral_krylov_probe.py \
  --lambda 6 --max-modes 18 --dps 60 --block-size 3
```

The block is the orthonormalized Krylov space

```text
span{ b_N, A_N(mu_ref)b_N, A_N(mu_ref)^2 b_N }.
```

This is genuinely nonspectral: it is built from the boundary source, not from
any eigencut.

## 3. Result

### Zeta

The size-3 Krylov block gives only mixed improvement:

```text
N=16: raw 0.0610 -> reg 0.0444
N=18: raw 0.0527 -> reg 0.0453
```

but many rows are worse, sometimes substantially:

```text
N=10: raw 0.0766 -> reg 0.1834
N=12: raw 0.0665 -> reg 0.1119.
```

So the zeta singular profile is not stably regularized by a source-only
Krylov block.

### Planted build

The same block is very effective in the early planted regime:

```text
N=6: raw 8.5e-9 -> reg 3.0e-15
N=7: raw 2.2e-8 -> reg 2.8e-13
N=8: raw 2.5e-8 -> reg 5.0e-10.
```

But the effect is not uniform.  From `N=10` onward it often worsens the
already small regularized steps:

```text
N=10: raw 1.8e-7 -> reg 3.8e-7
N=15: raw 1.1e-6 -> reg 3.7e-6
N=18: raw 1.9e-6 -> reg 2.2e-6.
```

So a source-only Krylov block is not a stable theorem target either.

## 4. Reading

This sharpens the singular front one more time.

```text
1. a genuinely nonspectral block can matter;
2. source-only information is still insufficient;
3. the missing structure is the coupled source-plus-row geometry.
```

The contrast with the spectral autopsies is useful:

```text
spectral blocks: no new geometry at all;
source-only Krylov block: some genuine effect, but not enough.
```

So the next object must include both halves of the boundary relation, not
just the source.

## 5. What is refuted

The following target is refuted:

```text
SOURCE-KRYLOV-FESHBACH-BLOCK:
build the resonant package from the Krylov space of b_N alone.
```

It is too weak for zeta and not uniformly coherent for the plant.

## 6. Smaller live object

The next admissible reduction is:

```text
BOUNDARY-PAIR-KRYLOV-BLOCK:
build the resonant package from both sides of the boundary relation,
for example from a coupled finite space generated by

  b_N,
  A_N b_N,
  Cauchy-row adjoint vectors tied to r_{z0},
  and the Schur source/response pair (kappa, tau).
```

This is the smallest object suggested by all current autopsies:

```text
not spectral only,
not source only,
but a coupled boundary pair.
```
