### H1 — `C_Pó` (and `C_Pó^{sm}`) is called a *detecting cone*, which is a type error and, for `C_Pó`, contradicts R138_001's own theorem. **MAJOR**

*Location:* Theorem D.17.2 ("Hence `C_Pó` is a **detecting cone**"); Corollary D.17.2d ("and so is
`C_Pó^{sm}`"); §5 item 4; `README.md` round-1 answer and the label tables (twice).

*Exact claim:* "the triangle family (hence `C_Pó`, `E`, `C_c^∞`) is **detecting**", `PROVED`.

*Why wrong.* Definition 0.1 defines *detecting* for a convex cone `C ⊆ D^W` of **classes `F`**, by
failure of `I_∞(F,F) ≤ ½(deg F)²` at some `F ∈ C`. `C_Pó` (Definition D.17.1a) is a cone of
**kernels `h`**, i.e. of objects in the `h = F⋆F^∨` variable, and by R138_001's own Theorem D.17.1b
`C_Pó ∩ D^W = {0}` — so under Definition 0.1, `C_Pó` is the zero cone and is **not** detecting. Two
further defects of the same statement: (α) the set of square roots `{F : F⋆F^∨ ∈ C_Pó}` is not known to
be convex (square roots of a convex cone of positive-definite kernels need not form a cone), so "the
Pólya cone, viewed through its square roots, is a detecting cone" is not even well posed; (β)
`C_Pó^{sm}` is likewise a cone of kernels, not of classes, so D.17.2d inherits the same type error.

*Minimal repair.* Delete "hence `C_Pó`" and "and so is `C_Pó^{sm}`" from the headline. What is proved,
and is enough for everything downstream, is: (1) the one-parameter *family* `{h_T}` detects
(Theorem D.17.2, which needs no membership in `D^W` — the zero sum converges on its own); (2) by
Lemma D.17.2c the classes `F_T^{(δ)} = F_T⋆ψ_δ` are effective, even, smooth, compactly supported and
witness the failure; hence (3) **`E` and `C_c^∞` are detecting cones** in the sense of Definition 0.1.
§5 item 4, the record line of D.17.3 and the answer to **Q** survive verbatim with "`E` and `C_c^∞`"
in place of "the Pólya/triangle cone". If the phase wants a statement about `C_Pó`, it must first
define "detecting" in the `h`-variable (`W(h) < 0` for some `h ∈ C`), which is a different definition
and should be numbered separately.

### H2 — "`E` has empty interior in **every** topology in which `I_∞(·,F)` is continuous" is unproved, and the reason offered is a non-sequitur. **MAJOR** (claim of record; conclusion unaffected)

*Location:* the `REFUTED` box after Theorem D.15.2b; the "Topology, stated precisely" paragraph;
blueprint correction **B-3**.

*Exact claim:* "…`E` has empty interior in every topology in which `I_∞(·,F)` is continuous
(Theorem D.15.2b); no topology repairs it: (i) uses only that `‖·‖₁` dominates pointwise decay against
`2cosh(t/2)`, which any topology making `I_∞(·,F)` continuous must do (Thm 11.14(ii) is sharp)."

*Why wrong.* Continuity of the family of linear functionals `{I_∞(·,F)}` is a *lower* bound on the
topology; it does not force the topology to be *coarser* than `‖·‖₁`, and a finer topology can give
`E` interior. Concretely, on the step `D^W_ε := {E : E^{(j)} = O(e^{−(1+ε)|t|}), j ≤ 2}` with the
weighted sup-norm `‖E‖_ε := sup_t |E(t)|e^{(1+ε)|t|}`, each `I_∞(·,F)` is continuous (by Thm 11.14(i)
and `|I_∞(E,F)| ≤ C_F∫|E|2cosh(t/2)dt ≤ C_F‖E‖_ε∫e^{−(1+ε)|t|}2cosh(t/2)dt`), and `E ∩ D^W_ε` has
nonempty `‖·‖_ε`-interior: any `F` with `F(t) ≥ 2δe^{−(1+ε)|t|}` has the `δ`-ball inside `E`. So the
quoted implication is false as an implication; whether the conclusion holds on all of `D^W` with, say,
the inductive-limit topology is a separate question that round 1 does not address. The sharpness of
(11.17)'s coefficients (Thm 11.14(ii)) is about a constant in a bound, and carries no information
about which topologies make the functionals continuous.

*Minimal repair.* State D.15.2b(i) for `‖·‖₁` only, and let the refutation of the blueprint rest on
**D.15.2b(ii)**, which is purely algebraic and topology-free: `K` decays super-exponentially while
`D^W` only demands `e^{−(1+ε)|t|}`, so for every `ε > 0` there is `t` with `(K+εF)(t) < 0` — `E` is
**not absorbing at `K`**, and by Theorem D.15.2(c) that alone kills the route, in any topology. The
downstream use (the Khovanskii–Teissier shape is unavailable on `E`; use the ample cone) is unaffected.

### H4 — D.16.1(d) is stated for a **fixed** convolution kernel; with a fixed kernel it is not proved, and cannot be, for every off-line zero. **MAJOR**

*Location:* Definition D.16.1 ("`⋆k` (`k` a fixed even kernel in `C_c^∞`)") and Theorem D.16.1(d),(e).

*Exact claim:* "`⟨C_W⟩_{{p(∂),⋆}}` is **detecting**, with no translation and no dilation", `PROVED`.
