## 2. The coupled generator package

At fixed `mu`, write

```text
A=A_N(mu),                                                  (D-2)
u=A^(-1)s,
v=A^(-1)1.                                                  (D-3)
```

With the notation of P76.041, let

```text
g = R_b(s-S_b 1),                                           (D-4)
p = v^T g,
q = u^T g,                                                  (D-5)

a_b = 2/L + 4p/L^2,
b_b = -2S_b/L - 4q/L^2.                                     (D-6)
```

Then P76.042 gives the one-generator package

```text
h_b = a_b u + b_b v,
f_b = a_b s + b_b 1,
A h_b = f_b,                                                (D-7)
```

and the exact boundary numerator

```text
F_b(z) = 1 + H_b(z) + H_b^bd,                              (D-8)
```

with

```text
H_b(z)=sum_n h_b(n)/(z-d_n),  H_b^bd=sum_n h_b(n)/(d_n-d_b). (D-9)
```

## 3. Exact `mu` derivative of the coupled package

Differentiate `(D-3)`:

```text
partial_mu u = A^(-1)u,
partial_mu v = A^(-1)v.                                     (D-10)
```

Let

```text
c_b := A^(-1) g.                                            (D-11)
```

Since `g` is `mu`-independent, `(D-10)` yields

```text
partial_mu p = v^T c_b,
partial_mu q = u^T c_b.                                     (D-12)
```

Hence

```text
alpha_b := partial_mu a_b = 4 v^T c_b / L^2,
beta_b  := partial_mu b_b = -4 u^T c_b / L^2.              (D-13)
```

Differentiate `(D-7)`:

```text
partial_mu h_b
 = alpha_b u + a_b partial_mu u + beta_b v + b_b partial_mu v
 = A^(-1)( h_b + alpha_b s + beta_b 1 ).                   (D-14)
```

Define the fourth coupled solution

```text
y_b := partial_mu h_b,                                      (D-15)
```

which solves exactly

```text
A y_b = h_b + alpha_b s + beta_b 1.                         (D-16)
```

This is the key reduction: `partial_mu` adds only two auxiliary scalar
coefficients `alpha_b,beta_b` and one further inhomogeneous solve `y_b`.

## 4. Exact derivative formula for `F_b` and `F_b'/F_b`

Let

```text
Y_b(z)=sum_n y_b(n)/(z-d_n),
Y_b^bd=sum_n y_b(n)/(d_n-d_b).                              (D-17)
```

Differentiating `(D-8)` gives

```text
partial_mu F_b(z)=Y_b(z)+Y_b^bd,                            (D-18)
partial_mu F_b'(z)=Y_b'(z).                                 (D-19)
```

Therefore

```text
partial_mu (F_b'/F_b)
 = Y_b'/F_b - F_b' (Y_b+Y_b^bd)/F_b^2.                     (D-20)
```

Using P76.041 `(TG-6)`, the dangerous term in `partial_mu J_{L,N}` is now
entirely contained in the finite package

```text
(u,v,c_b,y_b ; a_b,b_b,alpha_b,beta_b ; F_b,F_b',Y_b,Y_b'). (D-21)
```

No spectral sum appears.
