# 114.a.54 — H7 no-go: unfiltered finite moments saturate the target

```
+--------------------------------------------------------------------------+
| MAP         E:A_12 -> F_p^m is a product of multiplicative moments.     |
| WITNESS     If one scalar x has m distinct moment values, E(x) has       |
|             distinct coordinates.                                       |
| INTERPOLATE Polynomials in E(x) produce every coordinate idempotent.     |
| RESULT      E(A_12)=F_p^m: the unfiltered Laurent ring saturates target. |
| CONSEQUENCE Target cardinality cannot prove the sharp RR coefficient.    |
| REQUIRED    Degree-bounded tree complexity/sheaf filtration is essential.|
+--------------------------------------------------------------------------+
```

## 1. A finite product-algebra lemma

Let `k` be a field and let `B` be a `k`-subalgebra of `k^m` containing the
diagonal copy of `k`.

### Lemma 1.1

If `v=(v_1,...,v_m) in B` has pairwise distinct coordinates, then

\[
 B=k^m.                                                                  \tag{1.1}
\]

### Proof

For each `j`, the Lagrange polynomial

\[
 L_j(T)=\prod_{i\ne j}\frac{T-v_i}{v_j-v_i}\in k[T]                     \tag{1.2}

satisfies `L_j(v)=e_j`, the `j`-th coordinate idempotent. Hence every `e_j`
belongs to `B`; diagonal scalars times these idempotents span `k^m`. QED.

## 2. Application to moment evaluations

Let

\[
 \mathcal E=(\chi_{s_1},\ldots,\chi_{s_m}):
 A_{12}\longrightarrow\mathbb F_p^m                                  \tag{2.1}

be any of the moment maps used in `a_33` or `a_51`, and assume the first
ruling coefficients reduce onto the diagonal `F_p`.

### Theorem 2.1 (saturation criterion)

If there is a Laurent label `x` such that

\[
 x^{s_1},\ldots,x^{s_m}\pmod p                                          \tag{2.2}

are pairwise distinct, then

\[
 \boxed{\mathcal E(A_{12})=\mathbb F_p^m.}                               \tag{2.3}

\]

### Proof

The image is an `F_p`-subalgebra containing the diagonal coefficients. The
element `E([x])` has the coordinates (2.2), so Lemma 1.1 applies. QED.

For the odd exponents `s_j=2j+1`, it is enough that the multiplicative order
of `x` modulo `p` exceed `2m`: then the exponents are distinct modulo that
order. In particular, if

\[
 p>2^{2m},                                                               \tag{2.4}

the values of `x=2` are distinct as ordinary integers modulo `p`. The
controlled-prime construction may include (2.4) without changing
`log p=O(m+log Q)`, since it only enlarges the initial exponential height by
`2m log2`.

## 3. Exact consequence for the RR gate

Theorem 2.1 concerns the **unfiltered** Laurent ring. It does not say that
the bounded section set in a divisor of degree `O(t)` realizes the Lagrange
idempotents (1.2). It proves that the finite target itself supplies no sharp
upper coefficient:

\[
 \log\#\mathcal E(A_{12})=m\log p.                                      \tag{3.1}

This may be strictly larger at quadratic order than the optimal balanced
code entropy. Therefore the former H7-RR0/EXACT gate cannot follow from target cardinality,
full-tree descent or principal invariance alone.

The exact surviving statement is:

> **H7-RR-FILT.** Put a geometric degree/complexity filtration on the scalar
> section bio and prove that, inside degree `tD`, the extra moment classes
> beyond the balanced code contribute only `o(t^2)` to logarithmic image
> size. This filtration must be compatible with restrictions and exact
> sequences.

H7-RR-FILT is equivalent to the sharp comparison demanded in `a_53`, once
the already constructed lower code and Picard-normalized quotient are fixed.
It is not settled by the unfiltered algebra.

**Later strengthening (`a_55`).** Centered Vandermonde coefficients and a
single typed cross-contraction realize the entire block inside a genuinely
bounded line bundle of linear bidegree. Hence the proposed sharp comparison
for the complete-bounded `h_FM` is actually false. The surviving replacement
is H7-SEL-RR/EXACT, which must change the measured object and canonically
exclude that bounded interpolation family.

## 4. Verification scope

`114_a_54_h7_moment_saturation_verify.py` constructs Lagrange coordinate
idempotents over finite fields and checks that the algebra generated by one
separating moment vector is the full product. It does not assert that those
idempotents lie in a fixed bounded divisor filtration.
