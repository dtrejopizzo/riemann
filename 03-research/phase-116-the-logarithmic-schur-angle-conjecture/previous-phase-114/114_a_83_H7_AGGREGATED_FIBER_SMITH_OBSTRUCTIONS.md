# 114.a.83 — H7: aggregated fibers can create exact Smith torsion

```
+-------------------------------------------------------------------------+
| EDGE ROWS   Individual fiber differences form saturated incidence groups.|
| AGGREGATE   Keeping only sums of incident fibers gives graph Laplacians.  |
| TRIANGLE    Smith(L_C3)=diag(1,3,0): explicit odd 3-torsion.              |
| EVEN CYCLE  Smith(L_Cn) has terminal factor n: bipartiteness is not enough.|
| EXACT NEED  Show that Haran contexts retain/generate every individual     |
|             fiber row before aggregation, or compute the actual Smith map.|
+-------------------------------------------------------------------------+
```

## 1. Incidence versus aggregated relations

Let `B` be an oriented vertex-edge incidence matrix.  The rectangular sector
of `a_82` uses the individual columns/rows `e_v-e_u`; its image is saturated.

Suppose instead that a nonseparable contraction retains only the sum of the
edge differences incident at each vertex.  The resulting relation matrix is
the graph Laplacian

\[
 L=BB^t.                                                             \tag{1.1}
\]

Every row of `L` is primitive for a simple connected graph, but the row
lattice need not be saturated.

### Theorem 1.1 (cycle obstruction)

For the cycle graph `C_n`,

\[
 \operatorname{coker}(L_{C_n})\cong \mathbb Z\oplus\mathbb Z/n\mathbb Z.
                                                                         \tag{1.2}
\]

Equivalently its Smith normal form is

\[
 \operatorname{diag}(1,\ldots,1,n,0).                               \tag{1.3}
\]

### Proof

The free factor is generated by the total coordinate sum.  Delete one row
and column.  The determinant of the reduced Laplacian equals the number of
spanning trees by the matrix-tree theorem; `C_n` has exactly `n` spanning
trees.  The minors of lower rank contain unit triangular minors, so all
earlier invariant factors are one.  This gives (1.3).  QED.

In particular `C_3` produces `3`-torsion.  Even if Haran's tree incidence
forces bipartite macro graphs, `C_6` produces `6`-torsion, including an odd
factor.  Thus bipartiteness and primitive rows do not prove saturation.

## 2. Exact fiber-retention condition

For a macro context graph `G`, write `R_macro(G)` for the relation subgroup
actually generated after all contractions.  The safe incidence subgroup is

\[
 I(G)=\langle e_v-e_u:(u,v)\in E(G)\rangle.                           \tag{2.1}
\]

The needed statement is

> **H7-FIBER-RETENTION.** Whenever an aggregated macro relation supported on
> `G` occurs, the full contextual equivalence ideal also contains the
> individual fiber differences generating `I(G)` in the same component
> coordinates.

If this holds, `I(G) subseteq R_macro(G)`.  Every aggregate row already lies
in `I(G)`, so equality follows and `a_82` gives saturation.  Conversely, a
cycle Laplacian retained without its edge rows gives the explicit torsion in
Theorem 1.1.

The natural proposed proof uses the pointed-set selectors and zero law in
the initial generalized ring: set every unwanted branch of a context to
zero before performing the contraction, leaving one fiber.  The unresolved
point is whether the selected relation lands in the **same normalized
first-additive component coordinates** as the corresponding summand of the
aggregate.  This compatibility must be shown, not inferred from the
existence of set maps.

## 3. Sharpened decision problem

H7-MACRO-OVERLAP is now reduced to a concrete alternative.

1. Prove H7-FIBER-RETENTION by structural induction on multiplication and
   contraction contexts; then every macro graph relation is incidence-like
   and prime-saturated.
2. Or exhibit a context for which selector rows fail to land in the same
   coordinates and whose Smith form has a factor greater than one.

`a_82` completes the first branch for independent rectangular contexts and
ordinary vertex identifications.  The first unproved case is an overlapping
contraction in which two context fibers share internal component data.

No Haran cycle-Laplacian context is asserted to exist here.  The matrices
are exact obstruction models and acceptance tests for any proposed macro
presentation.  H7-PRIME-REG and row A remain open.

## 4. Verification scope

`114_a_83_h7_aggregated_fiber_smith_verify.py` computes exact Smith forms for
cycle incidence and Laplacian matrices, verifies saturation of the former,
the `Z/n` obstruction of the latter, and the odd factor in the bipartite
cycle `C_6`.
