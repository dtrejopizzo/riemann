# 114.a.135 — H7: the mixed boundary is rational-spherical base change


## 1. The real point in Haran's pro-curve

At level `N`, Haran (9.4) glues the real chart

\[
 A_N=\mathbb Z[1/N]\cap\mathbb Z_{\mathbb R}
\]

to `Spec Z[1/N]`.  The real point is the maximal ideal `eta_N` of `A_N`.
The transition maps are the identity on points and Haran states
`O_(X_N) ~= (f_N^M)_*O_(X_M)`.  Equation (9.7) identifies the limit local
valuation object as

\[
 O_{X,\infty}=\mathbb Q\cap\mathbb Z_{\mathbb R}.                    \tag{1.1}
\]

Thus the phrase "the point has local object `Z_R`" is too large.  The
reduced point is obtained levelwise by quotienting the local object by its
unique maximal equivalence ideal.  Denote its compatible residue pro-object
by

\[
 \kappa_\infty=(\mathbb Q\cap\mathbb Z_{\mathbb R})/\mathfrak m_\infty,
 \qquad x_\infty=\operatorname{Spec}\kappa_\infty.                  \tag{1.2}
\]

This is a definition from the local object and its maximal ideal; Haran
does not name `kappa_infty` in the cited text.

## 2. It is a rational sphere object

Haran (4.6) gives the quotient `Z_R -> F_R`: strict-interior vectors go to
zero and unit-sphere vectors survive.  Restricting it to (1.1) shows that
`kappa_infty` consists of rational unit-sphere operations, augmented by
zero.

It is neither endpoint that a shorthand might suggest:

- it is not `Z_R`, because all strict-interior elements vanish in the
  residue;
- it is not the full `F_R`, because irrational unit vectors such as
  `(1/sqrt(2),1/sqrt(2))` are absent;
- it is larger than `F{+-1}` in higher arity, since the rational unit vector
  `(3/5,4/5)` survives while it is not a signed coordinate vector.

The unary unit group is still `{+-1}`.  Higher-arity residue operations are
the reason that conservativity cannot be inferred from unary units alone.

## 3. Correct mixed boundary construction

Let `S=Spec F{+-1}`.  At compatible levels define

\[
 \widetilde B_{1,N}=x_{\infty,N}\times_S X_N,
 \qquad
 \widetilde B_{2,N}=X_N\times_Sx_{\infty,N}.                         \tag{3.1}
\]

Haran (8.12) constructs these fiber products by tensor products on affine
charts.  On the cofinal levels `(T,N)` of `a_132`, define the repaired mixed
boundaries by inverse image in `Y^locreg_(T,N)`.  This is the typed meaning
of the boundaries used in `a_130`; no uniform `Y^reg` is used.

For the arithmetic projection, pullback is therefore the composite

\[
 P_{pr}\longrightarrow
 Pic_{tor}(X\times_Sx_\infty)
 \longrightarrow Pic_{cmp}(B_i^{locreg}),                            \tag{3.2}
\]

whenever the completed comparison exists.  The first arrow is base change
along `F{+-1}->kappa_infty`; the second is supportwise inverse image.

## 4. Exact live theorem

The boundary strategy now has a precise, correctly typed gate:

> **H7-RSPH-CONS.** Base change by `kappa_infty`, followed by the
> supportwise reflection inverse image, is conservative on the subgroup of
> `Pic_tor(X)` generated by the prime lattices `L_p`, and the torsor result
> compares faithfully with `Pic_cmp`.

H7-RSPH-CONS implies H7-MIXED-BDRY-PIC of `a_130`, hence
H7-ARCH-BDRY.  The converse is not asserted.

The audited source supplies finite limits and the real residue object, but
no faithfully-flat descent theorem, norm, retraction, or conservative
base-change theorem for (3.2).  In particular, the fact that
`GL_1(kappa_infty)={+-1}` does not prove H7-RSPH-CONS: a trivialization can
use higher-arity transition operations, and Haran explicitly warns that
coefficient maps for `F_R` need not be injective.

`a_136` proves more: an `S`-algebra retraction
`kappa_infty->F{+-1}` is impossible, using the rational unit vector
`(3/5,4/5)`. Thus only a genuine descent or Picard-norm proof remains.

## 5. Status

This closes the typing of the mixed boundary and replaces an ambiguous
"real-point pullback" by one algebraic map.  It does not prove its
conservativity.  H7-RSPH-CONS, H7-ARCH-BDRY, row A and RH remain open.
