## 1. RECURSIVE_TRANSFER_001

### 1.1 Lemma 1 (the exact transfer identity): PROVED, re-derived

Definitions from the short preprint, §3 and (2.2): A_u(D) = Σ_{(n,S)=1} μ(n)ν(n)χ_n(u)W(N(n)/D),
n over ideals prime to S represented by primary generators, χ_n(u) = (u/n)_6 extended by zero
when (u, n) ≠ 1, ν extended by zero on ideals not prime to its conductor, S containing the
primes above 2, 3 and the conductor. For a primary prime p ∉ S, (p⁶/n)_6 = ((p/n)_6)⁶ = 1 if
p ∤ n and 0 if p | n, so χ_n(p⁶) = 1_{p∤n} (used by the preprint in the proof of Theorem 1.1).
Hence A_{p⁶}(D) = Σ_{p∤n} μ(n)ν(n)W(N(n)/D) and A_1(D) − A_{p⁶}(D) = Σ_{p|n} μ(n)ν(n)W(N(n)/D).
With μ(n) ≠ 0 the ideal n is squarefree, n = pm with p ∤ m, m squarefree and prime to S (p ∉ S);
μ(pm) = −μ(m), ν(pm) = ν(p)ν(m) (p is prime to the conductor), N(n) = qN(m) with q = N(p).
So the difference is −ν(p) Σ_{(m,S)=1, p∤m} μ(m)ν(m)W(N(m)/(D/q)) = −ν(p)A_{p⁶}(D/q), i.e.
A_{p⁶}(D) = A_1(D) + ν(p)A_{p⁶}(D/q). Iterating, A_{p⁶}(D) = Σ_{j≥0} ν(p)^j A_1(D/q^j); the
series terminates because A_1(D′) = 0 when bD′ < 1 (every nonzero ideal has norm ≥ 1 and
supp W ⊂ [a, b]). Correct; the same W and S appear on both sides. The phase 209 note
QRH_REPLICA_COHERENCE (lines 132–138) has the first-order form B_p(D) = −ν(p)A_1(D/N(p)) + O(1)
for Y = √D; Lemma 1 is its exact iterate and is new in that form. The routes index (L74 and the
phase 209 section) records no recursive transfer.

### 1.2 Theorem R: the induction

Step 2 is checked line by line. Rows p⁶ for p ∈ P are distinct elements of O with
0 < N(p⁶) ≤ Y⁶ = D^α (unique factorization), so (MS) at scale D applies to them; J ≥ c_2 Y/log Y
by (F2) once Y ≥ Y_0(S); the average gives (2C_ε/c_2)D^{1+α+2ε}Y^{−1}, and
1 + α − α/6 = 1 + 5α/6 = 2θ. Correct.

Step 3: for D ∈ [D_0 2^k, D_0 2^{k+1}) and q > Y/2 ≥ 16 every scale D/q^j (j ≥ 1) is below
D/16 < D_0 2^{k−3}, so the induction hypothesis is invoked only at strictly smaller dyadic
blocks. The geometric tail Σ_{j≥1} q^{−j(θ+ε)} ≤ (4/3)q^{−θ} ≤ (4/3)(2/Y)^θ uses q^{−θ} ≤ 1/4
(q ≥ 16, θ ≥ 1/2). The absorption 2|R_p|² ≤ (K²/2)D^{2θ+2ε} needs (32/9)4^θ Y^{−2θ} ≤ 1/2; with
Y ≥ 32 and 1/2 ≤ θ ≤ 11/12 the left side is ≤ 0.023 (the memo's cruder bound 4/9 also
suffices). K² = max(K_0², 4C_ε/c_2) makes the two halves add to K²D^{2θ+2ε}. Correct.

Uniformity, as asked: (i) the constants c_1, c_2, Y_0(S) are field constants and S-constants,
independent of p and of the step; (ii) MS(α) is invoked once per scale, always at the scale
being treated, always with the fixed W and S; it is never invoked at a scale D/q^j; (iii) the
induction hypothesis at D/q^j is the conclusion, not the hypothesis, so there is no change of
the W-dependence of C_ε along the recursion and no circularity of that kind; (iv) no ε
accumulates: the tail carries the power saving Y^{−2θ} = D^{−αθ/3}; (v) Y_0(S) enters only through
D_0, i.e. the base case; (vi) the dyadic blocks are used only to order the induction and play no
quantitative role. All checked.

### 1.5 The adversarial finding: the used hypothesis is equivalent to the conclusion

Let MS_P(α) be the restriction of MS(α) to the rows u = p⁶, p ∈ P (the only rows Theorem R
uses). Then

    MS_P(α) for all D ⟺ A_1(D) ≪ D^{θ+ε} for all D          (PROVED, both directions).

(⟹) is Theorem R. (⟸): by Lemma 1, |A_{p⁶}(D)| ≤ Σ_{j≥0} |A_1(D/q^j)| ≤ K D^{θ+ε}(1 + (4/3)(2/Y)^θ),
so Σ_{p∈P}|A_{p⁶}(D)|² ≪ J D^{2θ+2ε} ≪ Y D^{1+5α/6+2ε} = D^{1+α+2ε}, which is MS_P(α). Hence,
on the rows it consumes, Theorem R is an exact restatement; this is the same phenomenon that
QRH_REPLICA_COHERENCE records for Y = √D ("the selective target is an exact formulation of
the problem"), now valid for every α. The memo acknowledges it only in the limit α → 0 (§3,
"Remark on the factor 5/6"). The content of MS(α) beyond the p⁶ rows is what would have to
carry a proof, and §4–5 of the memo show that the preprint's method does not supply it.

A second, simpler observation in the same direction: MS(α) contains the row u = 1 (χ_n(1) = 1),
hence implies |A_1(D)|² ≤ C_ε D^{1+α+ε} directly, i.e. a zero-free half-plane Re s > (1 + α)/2.
For α = 18/25 that is Re s > 43/50 = 0.86 < 11/12. So MS(α) for any α < 5/6 is, before any
transfer, an unconditional improvement of the short preprint's theorem, and §5(c) of the memo
("MS(α), α < 1, cannot be obtained by citation") holds already for this trivial reason when
α < 5/6; the memo's threshold 9/10 (via Theorem R and 7/8) is the finer one.

Consequence for the labels: "Theorem R, PROVED" stands. "4/5 is reduced, within this
architecture, to MS(18/25)" is a true implication; "it is now equivalent, within this
architecture, to MS(18/25)" (result paragraph) is not proved: the direction
A_1(D) ≪ D^{4/5+ε} ⟹ MS(18/25) on all rows 0 < N(u) ≤ D^{18/25} is not shown and is not
expected. Replace "equivalent" by "implied by".
