## 2. MAJOR

**MAJOR-1. "W is a bounded form" is false.** The symbol m(s) grows like log|s|, so W is not bounded on L². The Schur complement remains valid, but it must be formulated on the form domain 𝒟 (of H^{log} type):
- (L1) must hold as W(v, v) ≥ c‖v‖² on 𝒱 ∩ 𝒟. Then G_𝒱𝒱 is closed, semi-bounded and coercive, and G_𝒱𝒱^{−1} is defined by Lax–Milgram on the form completion.
- e_B^± ∈ 𝒟 despite the jumps: ê ~ 1/s, and ∫log|s|·s^{−2} < ∞.
- v ↦ W(v, e) is an L²-bounded functional, because ‖θ ê‖_{L²}² ~ ∫log²|s|·s^{−2} < ∞. This makes "‖G_𝒱E‖" well defined.

Its slow growth with N (0.885 → 0.914) is slow convergence, not divergence. The proof needs to be rewritten in this framework. With it, the equivalence W ≥ 0 on 𝒫_T ⟺ S ⪰ 0 is **PROVED**. Without it, the proof invokes a false hypothesis.

**MAJOR-2. ±–M couplings (§"For the audit").** The text leaves them as "expected to be bounded". This can be closed with known results. The archimedean kernel has a principal-value-type singularity ~ 1/|x−y| on the diagonal. Between adjacent intervals what remains is a Hilbert kernel 1/(x+y) on half-lines, bounded by π (Hilbert's inequality: **CITED**, Hardy–Littlewood–Pólya). This argument should be added. Without it, the sentence "W|_𝒱 ≥ c" mixes an unbounded operator (the diagonal) with couplings whose boundedness has not been shown.

## 3. MINOR

2. "λ_min(W|𝒫_T) ≥ min(c, λ_S)·(angle constant)": 𝒱 and E are L²-orthogonal, so there is no angle. The correct bound is as follows. Let K = G_𝒱𝒱^{−1}G_𝒱E and x = v + e. Then
 W(x) = W|_𝒱(v + Ke) + ⟨Se, e⟩ ≥ min(c, λ_S)·‖x‖² / (1 + ‖K‖)².
 In the other direction, with x = e − Ke, one gets λ_min(W) ≤ λ_S·(1 + ‖Ke‖²)^{−1} ≤ λ_S. This explains 9.4·10⁻⁴ < 1.17·10⁻³ via ‖K‖, not via an angle. The text of §3 must be corrected.

## 4. Is the 4×4 route a genuine simplification?

**Yes, partially.**
- Positive: all the fine cancellation is confined to a 4×4 matrix.
- G_EE is computed in closed form: these are integrals of θ against transforms of truncated exponentials, with elementary formulas plus the digamma part.
- G_𝒱𝒱 has a gap of 0.57, so its resolvent is well conditioned. With Galerkin using N ≈ 12 per block plus a tail bound (R185_093), errors of 10⁻⁴ can be achieved with interval arithmetic, which is 10 times smaller than the 1% required. **Feasible route, OPEN.**
- Negative: S is not explicit. It is a resolvent over three intervals coupled by Hilbert kernels.
- A closed form via block Wiener–Hopf factorization is not realistic. The symbol θ·2cos² (or θ) on a finite interval is a truncated Wiener–Hopf problem with no explicit factorization, of the same type as the original. Moreover the couplings prevent treating the blocks separately.
- Hence the correct description is "dimension-4 certificate with a well-conditioned resolvent". The adjective "analytic" does not apply. The memo's phrase "a disguised certificate, but of minimal size" is **fair**.
