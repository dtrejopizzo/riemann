Verdict: the geometry of 𝒱_T is now described (polar of the joint numerical range, convexified by
density matrices). The Gram tool is correct but **it is Bochner**: it encodes the multiplicative
structure of ℕ in the ratios m/n, but all of that information is already in the spectral measure
|F̂|²ds, and the only thing separating E4 from falsehood is the constraint of **support in the window**
(exponential type 2T) plus Tate. Next tool: the cone 𝒦_T (§4). No closure of row D is claimed.

## 1. Exact definition and duality

Paper 46 notation: I_T = (−T,T), 𝒫_T ⊂ L²(I_T) the subspace of primitives (A(F) = B(F) = 0,
Tate constraints, functionals bounded on L²(I_T): integrals against e^{±u/2}), 𝒩_T = {2 ≤ n < e^{2T}},
N_T = |𝒩_T|, c_F(u) = ∫F(x)F(x−u)dx (F extended by 0), and for F real unitary in the form domain
(eq:Aform)

 𝔞^{(v)}_T(F) = a(F) − Σ_{n∈𝒩_T} v_n c_F(log n), a(F) := C_0 + Lev(c_F) (archimedean energy).

The prime powers k ≥ 2 enter as their own coordinates (v_4 = 2log2/2, v_8, v_9, …); the vector
v_T(Λ) is zero at the n that are not prime powers, but 𝒱_T lives in all of ℝ^{N_T}. Parity: the
form is even in frequency, c_F is even, and the reduction to real tests is that of prop:finite(ii)
(F = F_1 + iF_2 splits). Also F ↦ F(−·) preserves 𝒫_T (swaps A and B) and c_F, so the form
decomposes into even/odd sectors and 𝒱_T = 𝒱_T^{even} ∩ 𝒱_T^{odd}.

**Def.** 𝒱_T := {v ∈ ℝ^{N_T} : 𝔞^{(v)}_T ≥ 0 on 𝒫_T ∩ form domain}.

**Prop. 1 (PROVED).** 𝒱_T = ⋂_F {v : ⟨c(F), v⟩ ≤ a(F)}, F real unitary in 𝒫_T ∩ dom, c(F) := (c_F(log n))_n.
It is closed, convex, and bounded (Prop. 3bis). Support function: h_{𝒱_T}(u) = inf{ t·a : (a, c) ∈ cone 𝒞_T, t c = u } by
standard Fenchel duality (𝒱_T is the shifted polar of the conic hull generated by 𝒞_T := {(a(F),c(F))}).

*Proof.* This is prop:finite(ii). The support-function formula is cone–half-space duality:
𝒱_T = {v : ⟨(1,−v),(a,c)⟩ ≥ 0 ∀(a,c) ∈ 𝒞_T}, so (1,−v) ∈ (cone 𝒞_T)^*, and the support function of a
section of the dual cone is the gauge function of the primal cone (Rockafellar, Thm 14.1, CITED). ∎

**Prop. 3bis (PROVED).** 𝒱_T is bounded. *Proof.* For each n₀ ∈ 𝒩_T and each sign, the construction of
lem:cpos with u₀ = log n₀ and ℓ < min_{n≠n'}|log n − log n'|, ℓ < log 2 so that J + log n (n ∈ 𝒩_T ∪{1})
… gives F^±_φ = φ ± φ(·−u₀) with c_{F}(u₀) = ±‖φ‖² and c_F(log n) = 0 for log n ∉ {u₀, 2u₀} ∪ {|log n −... |}:
the only translations with nonzero overlap are 0, ±u₀, ±2u₀; if 2u₀ = log n₀² < 2T, c_F(2u₀) appears
— in the + case it equals +‖φ‖²·0 (the three pieces φ, φ_{u₀}, φ_{2u₀}: c_F(2u₀) = ⟨φ, φ_{2u₀}⟩·0
because F only has φ and φ_{u₀}; c_F(2u₀) = ⟨φ_{2u₀}… ⟩ = 0 since J+2u₀ is disjoint from J). Hence
c(F^±) = ±‖φ‖² e_{n₀} and ⟨c,v⟩ ≤ a gives ±v_{n₀} ≤ a(F^±)/‖φ‖² < ∞. ∎

## 2. Density matrices and joint numerical range

Let S_n := the form on 𝒫_T, S_n(F) = Re c_F(log n) = ⟨F, ½(τ_{log n}+τ_{−log n})F⟩, compressed to 𝒫_T;
A_∞ the archimedean form (unbounded, closed, bounded below on 𝒫_T).

**Prop. 2 (PROVED).** v ∈ 𝒱_T ⟺ for every finite-rank ρ ≥ 0, Tr ρ = 1, Ran ρ ⊂ 𝒫_T ∩ dom,
Tr(ρA_∞) ≥ Σ_n v_n Tr(ρ S_n). Equivalently conv 𝒞_T = {(Tr ρA_∞, (Tr ρS_n)_n)} over that set.

*Proof.* (⇐) ρ = FF^*. (⇒) ρ = Σ p_i F_iF_i^* (spectral, finite rank), and the expression is linear in ρ;
convex sums of inequalities. The identity with conv: "⊂" via ρ = Σ p_i F_iF_i^* with p_i from the
convex combination (not orthogonal: ρ remains ≥ 0 of trace 1); "⊃" via the spectral decomposition.
Complex F reduce to real ones by prop:finite(ii). ∎

*Remark.* For a tuple of ≥ 3 forms the joint numerical range 𝒞_T is not convex in general
(Toeplitz–Hausdorff only gives 2 forms); 𝒱_T only sees conv 𝒞_T, so the non-convexity is invisible
to E4. Formulation: **E4_T ⟺ the joint numerical range of (A_∞; S_n)_{n∈𝒩_T} on 𝒫_T lies in the
half-space {a ≥ ⟨v_T(Λ), c⟩}.**

**Prop. 3 (PROVED): non-commutation.** Let 0 < a < b < 2T with b − a < 2T and Σ_u := P(τ_u+τ_{−u})P on L²(I_T).
For φ supported on J = (−T, −T+ε), ε small: Σ_bφ = φ_b (φ_{−b} falls outside), Σ_aΣ_bφ = φ_{a+b}1_I + φ_{b−a},
Σ_bΣ_aφ = φ_{a+b}1_I + φ_{a−b}1_I = φ_{a+b}1_I (since J + a − b lies outside I). Hence
[Σ_a,Σ_b]φ = φ_{b−a}, an isometry on the infinite-dimensional space {φ : supp φ ⊂ J}; the commutator has
infinite rank. With Q the projection onto 𝒫_T (codim 2),
Q[Σ_a,Σ_b]Q − [QΣ_aQ, QΣ_bQ] = QΣ_a(1−Q)Σ_bQ − QΣ_b(1−Q)Σ_aQ has rank ≤ 4, and Q[Σ_a,Σ_b]Q remains
of infinite rank; hence [QΣ_aQ, QΣ_bQ] ≠ 0. In particular S_{log 2}, S_{log 3} do not commute on 𝒫_T
for T > ½log3. ∎ Consequence: there is no simultaneous diagonalization; E4 is not a condition on a
joint spectrum, but on a genuinely non-commutative numerical range — **except** in the spectral
representation of §3, where all the S_n are multipliers cos(s log n) on L²(ℝ, ds),
and the non-commutativity is exactly the Paley–Wiener projection.

**Prop. 4 (PROVED): geometric margin.** Let λ_T := inf_{F ∈ 𝒫_T, ‖F‖=1} 𝔞^{(v_T)}_T(F). If λ_T > 0 then
the Euclidean ball B(v_T, λ_T/√N_T) ⊂ 𝒱_T. *Proof.* |c_F(u)| ≤ ‖F‖² (Cauchy–Schwarz), so
‖c(F)‖₂ ≤ √N_T and 𝔞^{(v_T+δ)}(F) ≥ λ_T − ‖δ‖₂√N_T. ∎ Better: |c_F(u)| ≤ ‖F1_{(−T,T−u)}‖‖F1_{(−T+u,T)}‖.
At T = ½log3 (N_T = 1, only n = 2): radius ≥ 9.7·10⁻⁴ in the v_2 coordinate (NUMERICAL via R185_006,
consistent in order of magnitude with the margins of R184_007 at T = log2, which are 7·10⁻⁶ and up).
The minimizers F* (first-contact witnesses) are the active normals c(F*); v_T ∈ ∂𝒱_T ⟺ λ_T = 0.

## 3. The Gram tool

**Def.** For F ∈ L²(I_T) real, 𝒢_F := [c_F(log m − log n)]_{m,n ∈ {1}∪𝒩_T}.

**Theorem G (PROVED).** (i) 𝒢_F = Gram matrix of the translates {F(· − log n)}, so 𝒢_F ⪰ 0.
(ii) The prime term is ⟨v_T, 𝒢_F e_1⟩ (first row, n = 1 ↔ translation 0).
(iii) For every x ∈ ℂ^{N_T+1}: x^*𝒢_F x = (1/2π)∫|F̂(s)|² |D_x(s)|² ds, D_x(s) = Σ_n x_n n^{−is}.
(iv) Hence the family {𝒢_F ⪰ 0} is exactly the Bochner positivity of c_F restricted to the
differences log(m/n); the entries c_F(log(m/n)) with m/n ∉ ℕ are values of c_F at shifts that
are not log k: that is where the multiplicative structure enters (ℚ-independence of the log p, Kronecker).

*Proof.* (i) G_{mn} = ⟨F_{log m}, F_{log n}⟩. (iii) c_F(u) = (1/2π)∫|F̂|² e^{isu} ds (Plancherel), and
Σ x_m x̄_n e^{is log(m/n)} = |Σ x_n n^{is}|². (ii) definition. ∎

Choices of x (all PROVED as identities): x_n = n^{−σ−it₀} gives ∫|F̂|²|ζ_N(σ + i(s+t₀))|² ≥ 0
(truncated Dirichlet polynomial). Mellin–Parseval does not reproduce the archimedean energy: a(F) =
(1/2π)∫m|F̂|², and m(s) ~ log|s| is not a positive combination of |D_x|² with frequencies in log(ℚ_{>0})
of bounded support (|D_x|² is bounded almost periodic, m is unbounded); at best
m ≥ inf … — see Theorem NG.

**Theorem NG (PROVED, NO-GO).** Let 𝓘 be any inequality of the form
"a(F) − ⟨v, c(F)⟩ ≥ 0" derived only from (a) x^*𝒢_F x ≥ 0 for all x, and (b) a(F) = (1/2π)∫ m|F̂|²,
valid for every finite positive measure μ in place of |F̂|²ds/2π. Then 𝓘 is false for v = v_T(Λ)
at every T > ½log2.
*Proof.* Hypotheses (a), (b) are satisfied by μ = δ_{s₀} + δ_{−s₀} (and by its Gaussian
approximations): x^*𝒢x = 2|D_x(s₀)|² ≥ 0, a = 2m(s₀), ⟨v,c⟩ = 2Σ v_n cos(s₀ log n). Taking s₀ = 0, a − ⟨v,c⟩ =
2σ_T(0) = 2(C_0 − Σ v_n) < 0 (prop:band(ii)). ∎
Reading: Gram positivity is a test-side constraint, valid on L²(ℝ); E4 is only true because of the
constraint of **support in I_T** (Paley–Wiener of type T) and Tate. Every useful inequality must use
the support. The best possible "pure" Gram bound is 𝔞 ≥ (inf_s σ_T)‖F‖², which at T = ½log3 gives
θ(0) = −6.352 against the real gap +9.7·10⁻⁴ (NUMERICAL, R185_006): **uninformative**, as NG predicts.

**Barrier (R185_005).** 𝒢_F ⪰ 0 is a statement about the test F, not a sentence in Λ; the relative
barrier does not apply to it. What NG shows is something else: that this tool, alone, cannot reach the
goal. Once coupled to v_T(Λ), any inference becomes a sentence in Λ again and the barrier applies once more.

## 4. Reformulation and the next tool

By the symbol identity (R185_006 §1, generalized: on 𝒫_T the polar terms vanish),
𝔞^{(v)}_T(F) = (1/2π)∫|F̂|²σ_v, σ_v(s) = m(s) − Σ v_n cos(s log n). Let
𝒦_T := closed conv {|F̂|² : F ∈ 𝒫_T} ⊂ L¹(ℝ). Then (PROVED)

 v ∈ 𝒱_T ⟺ ∫ σ_v Φ ≥ 0 ∀Φ ∈ 𝒦_T, E4 ⟺ ∀T: σ_{v_T(Λ)} ∈ 𝒦_T^*.

𝒦_T ⊂ {Φ ≥ 0 on ℝ, entire of type ≤ 2T, Φ ∈ L¹, Φ(±i/2) = 0}; by Kreĭn–Akhiezer (factorization of
non-negative entire functions of exponential type, CITED) every such Φ is E E^# with E ∈ PW_T, and
equality with 𝒦_T depends on being able to distribute the zeros ±i/2 over E (OPEN: distribution lemma;
if Φ has double zeros at ±i/2 it is immediate). This is the Paley–Wiener–Tate cone: the next tool is its
geometry (extremals = Φ with double real zeros, de Branges type), and the position of σ_{v_T} in
its dual, with the alignment arcs of prop:align as the region where σ < 0 must be compensated.
