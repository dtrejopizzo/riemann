## 4. The quartet as a rank-(2,2) form; the blind regime

**4.1 Lemma Q (PROVED).** For F ∈ L²(I_T) real and ρ = ½ + δ + iγ: the quartet {½ ± δ ± iγ} contributes to Σ_ρ Φ_F(ρ)Φ_F(1−ρ) exactly Q_δ(F) = 4Re[Φ_F(½+z)Φ_F(½−z)], z = δ + iγ (R186_114 §1.1). With Φ_F(½±z) = ∫F e^{±δt}e^{±iγt} = P_± ± iR_± (P_± = ∫F e^{±δt}cos γt, R_± = ∫F e^{±δt}sin γt): Re[Φ(½+z)Φ(½−z)] = P₊P₋ + R₊R₋ = ¼[(P₊+P₋)² − (P₊−P₋)² + (R₊+R₋)² − (R₊−R₋)²]. Since P₊ + P₋ = 2∫F cosh(δt)cos γt, P₊ − P₋ = 2∫F sinh(δt)cos γt (and likewise R with sin):
