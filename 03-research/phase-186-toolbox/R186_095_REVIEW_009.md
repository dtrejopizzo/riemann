# R186.095 — Audit of R186.009 (semilocal Sonin intersection, Halmos, (84)_S)

File reviewed without modification. Sources checked against: R186.006–008, R186.093/094, CC 2006.13771 §4 ((74)–(90), phase-137 local text), R183.031, Halmos's two-projections theorem.

## Summary

No FATAL. The operator core (L0, H, G, D) is **correct**: F_S is a self-adjoint unitary involution, cos²θ_n = λ_n(A_S)² (not 1 − λ_n²), and the gap (1 isolated in spec Q₁Q₂Q₁, rate ‖(Q₁Q₂Q₁)^n − Π_S‖ = λ₁^{2n}) is **PROVED** given two inputs already audited in 094 (A_S compact; ±1 is not an eigenvalue). There are three MAJOR issues: (M1) the reduction of (TC_S) to H_g(μ) = o(μ) is insufficient and its expansion is not justified; (M2) Δ/"exact absorption of the comb" is a definition by difference, not a theorem, and the formula for κ_S is vacuous; (M3) the identification with the "gap condition of R183.031" is false (they are different objects). MINOR: claim "nor HS" false/unproved, label of Prop. C, δ_S not defined as a function, CV_S not optimal.

## Verifications

**(L0) — CORRECT, and simpler than stated.** F_S = EF_∞E⁻¹ is a similarity conjugate of an involution, so F_S² = 1 trivially, with no need for F_∞UF_∞ = U*. The alternative route also checks out: with U = E*E⁻¹ = e^{iφ(D)}, F_∞e(D)F_∞ = e(−D) (since F_∞ϑ(ρ)F_∞ = ϑ(ρ⁻¹)); in the Mellin variable D ↦ −D is s ↦ 1−s = s̄ on Re s = ½, and e(s) = (1−2^{−s})⁻¹ satisfies e(s̄) = conj e(s); thus e(−D) = e(D)* and φ is **exactly** odd: φ(0) = −2 arg e(½) = 0 because e(½) = (1−2^{−1/2})⁻¹ > 0. There is no constant. F_S = F_∞U unitary (U unitary since E is normal, bounded and invertible: |1−2^{−s}| ≥ 1−2^{−1/2}). Unitary + involution ⟹ self-adjoint; A_S = PF_SP self-adjoint. F_Sϑ(ρ)F_S = ϑ(ρ⁻¹): correct. PROVED stands.

**(H) — CORRECT: cos²θ_n = λ_n², not 1 − λ_n².** On the generic part, Q₁ = [[1,0],[0,0]], Q₂ = [[c²,cs],[cs,s²]] ⟹ P = 1−Q₁ = [[0,0],[0,1]], P̂ = [[s²,−cs],[−cs,c²]]; Q₁Q₂Q₁ = c²⊕0 and PP̂P = 0⊕c². Since PP̂^SP = PF_SPF_SP = A_S², the spectrum of c² is {λ_n² : 0 < |λ_n| < 1}. The operator P − A_S² = P(1−P̂)P has eigenvalues 1 − λ_n² = s²: it is the **sine**, the operator of the angle between Q₁ and (1−Q₂), irrelevant to Π_S. Independent check via D: Q₁P̂Q₁ζ_n = (1−λ_n²)ζ_n ⟹ Q₁Q₂Q₁ζ_n = λ_n²ζ_n. On ran Q₁: eigenvalue 1 on son = ran Q₁∩ran Q₂, eigenvalue 0 on ran Q₁∩ker Q₂ = F_S(ker A_S) (verified), λ_n² on the generic part. Correct.

**(G) — PROVED.** sup{λ_n²} = ‖A_S‖² and, A_S being compact self-adjoint, ‖A_S‖ = max|λ_n| is attained; ‖A_S‖ ≤ 1 and ±1 is not an eigenvalue (R186.007, accepted in 094) ⟹ λ₁² < 1. The λ_n² only accumulate at 0. Hence spec(Q₁Q₂Q₁) ⊂ [0,λ₁²] ∪ {1}: 1 isolated, Π_S a Riesz projection with r < 1−λ₁², and (Q₁Q₂Q₁)^n − Π_S = Σλ_n^{2n}|ζ_n⟩⟨ζ_n| has norm exactly λ₁^{2n} (if the generic part is nonzero). For the actual alternation, ‖(Q₁Q₂)^n − Π_S‖ = |λ₁|^{2n−1}. If cos² = 1−λ² held, the sup would be 1 and there would be no gap; that is not the case. Dependencies: compactness of A_S and absence of ±1, both from 007/094; dim son = ∞ is not needed for G (if son = 0, Π_S = 0 and G still holds).

**(D) — CORRECT.** ‖(1−P)F_Sξ_n‖² = 1 − λ_n², ⟨(1−P)F_Sξ_n,(1−P)F_Sξ_m⟩ = δ_{nm} − λ_nλ_m⟨ξ_n,ξ_m⟩ = δ_{nm}(1−λ_n²). {ζ_n} orthonormal and spans cl((1−P)F_S ran P) = cl(Q₁ ran(1−Q₂)) = ran Q₁ ⊖ son. Q₁ = Π_S + Σ|ζ_n⟩⟨ζ_n|, Q₁Q₂Q₁ = Π_S + Σλ_n²|ζ_n⟩⟨ζ_n|. Matches CC (76)/(81).

**Weight of (84).** Confirmed in the CC text: ε(ρ) = Σ λ(n)(1−λ(n)²)^{−1/2}⟨ξ_n|ϑ(ρ⁻¹)ζ_n⟩ (τ(n) of (77)). The weight λ²/(1−λ²) is incorrect; 009 is right. The support (82)_S: ϑ(ρ⁻¹)ξ_n ⊂ [0,λ/ρ] ⊥ ζ_n ⊂ (λ,∞) for ρ ≥ 1: correct.

**(d) — CORRECT given TC_S.** Fatou with ϑ(g_k) → 1 strongly, ‖g_k*g_k^*‖₁ ≤ 1 and supports contracting to {1}: valid argument.

## FATAL

None.

## MAJOR

**M1 (§4, reduction of TC_S).** (a) The sufficient condition is Σ_n |u_n| H_g(λ2^{|n|/2}) < ∞ with |u_n| ≍ 2^{−|n|/2} = λ/μ_n, i.e. Σ_n H_g(μ_n)/μ_n < ∞ at μ_n = λ2^{|n|/2} → ∞. **H_g(μ) = o(μ) is NOT enough** (e.g. H_g = μ/log μ gives Σ 1/|n| = ∞). Something like H_g(μ) = O(μ^{1−δ}) or Σ_k H_g(λ2^{k/2})2^{−k/2} < ∞ is needed. The direction (μ → ∞) is correct. (b) The expansion is not justified: Q₂ = 1 − F_∞UPU*F_∞ and ϑ(g)Q₁·1 is not HS, so one cannot expand term by term as "1 − Σu_nū_m(...)"; it must be regrouped as (1−UPU*) = Σ u_nū_m(…) with terms of the type (1−P_a)F_∞(1−P_b), which requires Σu_nū_m T_{(n−m)c} = 1 in the correct sense, not proved here. (c) The level index must depend on (n,m) (a = λ, b depending on n and the shift n−m); writing H_g(λ2^{|n|/2}) is imprecise. The scale covariance ‖ϑ(g)(1−P_a)F_∞(1−P_b)‖_HS = H_g(√(ab)) is indeed correct (ϑ abelian, ϑ(r) is absorbed). **Downgrade:** "reduced to H_g = o(μ)" → "reduction ARGUED to Σ_k H_g(λ2^{k/2})2^{−k/2} < ∞, pending justification of the regrouping".

**M2 (§5, Δ and "exact absorption of the comb").** The formula for κ_S contains "−(d_S−d_∞) + (d_S−d_∞)", which sums to zero, and ends in "≡ ε_S − ε_∞ + comb density": κ_S is **defined** so that the identity holds. Hence "E_S = Son_S − ∫c_h(ε_∞+κ_S)" is a tautology except for the content of C/C′ (008, accepted), which identifies the prime term of E_S with Tr ϑ(f)X. Moreover it has not been shown that Tr ϑ(f)PX, Tr ϑ(f)XP, Tr ϑ(f)PXP are individually trace class (X is not so locally without ϑ(f) on both sides; P is not compact). And (86)_S requires δ_S(ρ) = density of Tr ϑ(ρ⁻¹)P̂^SP = Σλ_n⟨ξ_n|ϑ(ρ⁻¹)F_Sξ_n⟩, a series with weights |λ_n| ≍ n^{−1/2} (ARGUED) with no absolute convergence and with P̂^SP not HS: δ_S is not defined as a function. **Downgrade:** Δ from "PROVED given TC_S" to "DEFINITION of κ_S + identity CONDITIONAL on TC_S, on the trace-class property of PX, XP, PXP against ϑ(f), and on the existence of δ_S"; the phrase "comb absorbed exactly with no remainder" is only legitimate as a restatement.

**M3 (§2 end, §7.3).** "operator version of the gap condition of R183.031, here unconditional" is **false as an identification**: R183.031 deals with a gap in the height variable (−γ₁,γ₁) for the density of a positive part P_T (and concludes it is not separable from D); G is a spectral gap of the operator Q₁Q₂Q₁ at 1. No implication in either direction has been proved. Withdraw the sentence; in §7.3(b) the approximation (Q₁Q₂Q₁)^N with error λ₁^{2N} in norm contributes nothing to the requirement of R183.031 (which is in trace/density), as the text itself half-admits.

## MINOR

- m1 (§3) "f(Q₁Q₂Q₁) is neither trace class **nor HS**": not trace class (Σλ_n² = ∞) correct; HS ⟺ Σλ_n⁴ < ∞, unproved and, with the ARGUED law λ_n² ≍ 1/n (094 m11), **it is true that it is HS**. Withdraw "nor HS".
- m2 Table: Prop. C "PROVED (algebraic)" → CONDITIONAL (TC_S, existence of δ_S); the cancellation of d_S requires both sides to be finite.
- m3 L0: the argument F_∞UF_∞ = U* is correct but unnecessary for F_S² = 1 (similarity). Keep both.
- m4 §6 (CV_S): the valid bound is |c_n(ρ)| ≤ ‖1_{(λ/ρ,λ]}ξ_n‖·‖1_{(λ,λρ]}ζ_n‖; the second factor is discarded unnecessarily; the wording "after inversion" is confusing. The criterion (with weight λ_n/√(1−λ_n²) ≍ |λ_n| by G) is sufficient and correct; OPEN correctly labeled.
- m5 "dim son = ∞ (CITED CCM)": the citation is for the CCM case; for F_S = EF_∞E⁻¹ with fixed λ one must check that the object coincides. Does not affect G.
- m6 "λ_1" denotes the one of maximum |λ|; fix the ordering by decreasing |λ_n|.
