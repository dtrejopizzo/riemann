**R1 (resolvent form). Correct; label to be refined.** With ζ_n = (1−P)F_Sξ_n/(1−λ_n²)^{1/2} (‖(1−P)F_Sξ_n‖² = 1−λ_n² by Halmos), λ_n(1−λ_n²)^{−1/2}|ζ_n⟩⟨ξ_n| = (1−P)F_S·λ_n(1−λ_n²)^{−1}|ξ_n⟩⟨ξ_n|; the sum = (1−P)F_S A_S(1−A_S²)^{−1}P, convergent in norm (‖A_S‖ = λ₁ < 1). Weights λ(1−λ²)^{−1/2} of CC (84) respected (not λ²/(1−λ²)). ϑ(ρ⁻¹)g(x) = ρ^{1/2}g(ρx) and the supports give ∫_{λ/ρ}^{λ}. G = G₀(1+R) correct.
- What is PROVED: the distribution ρ ↦ Σ_n(...) (paired with f ∈ C_c^∞) coincides with d_S, because the pairing is Tr(K_f G) with K_f a smooth, compactly supported kernel on (0,∞)² (x ≥ λ/R) — trace class, and continuous in operator norm. Moreover d_S is well defined a.e. as L¹_loc by Fubini (change (u,x) ↦ (u/x,x)); there is NO need to define the trace of an L² kernel on a measure-zero line. This should be stated explicitly (MINOR).
- The pointwise agreement outside {2^j} (ARGUED) is **unnecessary** for the L² conclusion: distributional equality + d_S ∈ L²_loc suffices. Correct as is.
- Not proved: that "partial sums in n converge in L²_loc" (what R186.096 asked for). With the resolvent form this is no longer needed: the distributional limit is d_S ∈ L²_loc. Acceptable.

**R2 (kernel of G₀). PROVED.** ∫_0^λ cos(2παy)cos(2πβy)dy = ½[S(α−β)+S(α+β)].
