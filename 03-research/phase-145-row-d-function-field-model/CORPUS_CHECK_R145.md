## 3. Phase-41 Doc 125 (tropical toy Hodge index) and other toy models

**Status: TRIED–NO-GO for direct transport (obstruction identified and named).**

Searched `03-research/phase-41*` and neighboring phases; no file literally named "Doc 125" with a tropical
toy model was found under that exact numbering in the current tree (phase-41 in the corpus concerns a
different topic — the numbering cited may refer to material later renumbered or absorbed). The
corpus's actual toy-model/sign-definite-Hodge-index material that plays this role is:

* **The Connes–Deninger "geometric" foliated space over `E/F_q`** (phase 43), which *is* a literal
  toy model with a sign-definite Kähler metric, and whose non-transport obstruction is recorded precisely:
  - `03-research/phase-43-hodge-foliated-specZ/130-circularity-to-destruction-test-of-deninger-s.md:22,66,82`:
    *"En el único caso aritmético realizado (math/0204194, curva elíptica), la métrica que hace al espacio
    Kähler–Riemann USA el teorema de Hasse |ξ|²=q como INPUT."* Verbatim source quote: *"According to a
    theorem of Hasse — the Riemann conjecture for elliptic curves over function fields — we have |ξ|²=q."*
    And: *"Hasse is used as input to construct X and its metric ... The RH follows from the index
    computation on this pre-constructed space, not from positivity alone."*
  - Carrier: Deninger's 3-dim laminated space `X = X̃/H`, `X̃ = C × V_ξΓ × R`, for `E₀/F_q`. Cone: none
    stated independent of Hasse. `h⁰`: none — the metric itself is Hasse-dependent.
  - **Exact obstruction recorded:** the toy model's sign-definiteness is *derived from* the already-known
    function-field RH (Hasse), not from an independent geometric structure — so it cannot be transported to
    supply an independent positivity for the arithmetic case; it would be circular. This is the same
    obstruction class as NG-style circularity entries.

* **Phase 63's F_q control** (see item 1) is the corpus's actual "toy model with a literal sign-definite
  Hodge index" in the row-D programme's own vocabulary (PD gapped polarization, `|eig|=√q`), and its
  non-transport obstruction is likewise named precisely: `03-research/phase-63-lefschetz-realization/E99_RESULTS.md:31-40`:
  *"This is why no finite-window / F_q-style argument can cross: the one ingredient the curve proof
  [uses]... A spectral gap requires finitely many eigenvalues. A curve over F_q has genus g — H¹ is
  finite-dimensional; the ζ window is not."*

**Recommendation:** treat both as **TRIED–NO-GO for direct transport**, with the obstruction already named
(Hasse-as-input circularity for the Deninger model; finite-genus/finite-eigenvalue mismatch for the phase-63
model). Phase 145's job is different in kind — not to transport a sign-definite structure, but to *compare
cones* to identify a missing geometric ingredient — so it is not blocked by either no-go; but do not attempt
to reuse Deninger's metric as an independent input, and do not expect the F_q Frobenius/Lefschetz operator
itself to transport (already proved impossible, NG-63, `NO-GO-LIST.md:377-391`).
