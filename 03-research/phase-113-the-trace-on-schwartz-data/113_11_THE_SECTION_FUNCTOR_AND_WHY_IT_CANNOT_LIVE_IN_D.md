## 0. The question, and why the obvious answer is wrong

Row (d) is now one statement, `(E^o)`: *if `s(f,f) > 0` for real `f` in `D^o`,
then `f` or `-f` is effective* (113_10 Thm 4.2, and Thm 4.3 for the candid
converse `(E^o) <==> RH`). On an algebraic surface the corresponding statement
is a theorem, and its proof is Riemann–Roch. So d3 asks for a section functor
`h^0`.

113_10 already blocked the naive answer. Obstruction **O1**: `D / rad` is a
complex vector space, the effective cone is stable under positive scaling, so
`h^0(nD) = h^0(D)` and the growth argument that drives the classical proof has
nothing to grow. This file finds the *cause* of O1, shows the cause is not
removable inside `D`, and identifies where the missing structure actually lives.

The cause, stated in one line and proved in section 3:

> In 113_08–113_10, divisors and sections are the same kind of object — both
> are elements of `D`, related by addition. In a genuine divisor theory they are
> different kinds of object, related by a map `div` that is **invariant under
> scaling the section**. Our `f -> [f]` is not.

That single defect produces O1 exactly. And repairing it costs the intersection
form.

## 1. What `D / rad` actually is: a ring, and the rulings are its idempotents

This section replaces the "quadric surface with two rulings" picture by an exact
algebraic statement. The picture was a useful metaphor; the statement is a
theorem, and it is sharper.

Under the Mellin transform, `*`-convolution on `D` becomes pointwise
multiplication of the transforms (113_05). Write

```
        A := { f^ : f in D },
```

a commutative ring of holomorphic functions on the strip, and recall from
113_09 Thm 2.2 that

```
        rad I_d  =  (chi),      chi(s) := s(s-1) xi(s),
```

the **principal ideal** generated by `chi`. So `D / rad I_d = A / (chi)` is a
*quotient ring*, not merely a quotient vector space.

**Theorem 1.1 (the coordinate ring).** Evaluation at the zero set of `chi`,

```
        ev : A / (chi)  -->  C^{ {0,1} }  x  C^Z ,
             [f]  |-->  ( f^(0), f^(1) ; ( f^(rho) )_rho ),
```

is a homomorphism of `C`-algebras, and it is the coordinate model of 107_241 /
113_08. In particular the `s`-form of 113_08 is a Hermitian form on the
*underlying vector space* of a ring.

*Proof.* Each `ev_{s_0}` is a ring homomorphism because transforms multiply.
The kernel is `{ f : f^ vanishes on the zero set of chi }`, which by 113_09
Thm 2.2 (in the multiplicity-respecting form) is `(chi)`. `[]`

Two caveats, recorded rather than hidden: at a zero `rho` of multiplicity
`m_rho > 1` the candid target is the truncated ring `C[t]/t^{m_rho}`, not `C`,
and the corpus's coordinate model uses `C` with a multiplicity weight in the
form. Nothing below depends on the difference; where it could, it is flagged.
Also, `ev` is injective by construction and its image is a proper subalgebra of
the full product (a transform cannot have arbitrary prescribed values at
infinitely many points), so "`=`" above should be read as "embeds onto its
image".

**Theorem 1.2 (the rulings are the minimal idempotents).** In `D / rad I_d`:

```
        [f_v]^2 = [f_v],     [f_h]^2 = [f_h],     [f_v][f_h] = 0,
        [H] = [f_v] + [f_h],     [H]^2 = [H].
```

`[f_v]` and `[f_h]` are the two minimal idempotents of the polar factor
`C^{ {0,1} }`, and `[H]` is that factor's unit element (it annihilates the zero
block).

*Proof.* Compute with transforms. `f^_v = -2(s-1)xi`, so

```
        (f^_v)^2 - f^_v = 2(s-1) xi * [ 2(s-1) xi + 1 ].
```

The first factor supplies `(s-1)xi`; the bracket vanishes at `s = 0` because
`xi(0) = 1/2` gives `2(-1)(1/2) + 1 = 0`, so the bracket supplies the remaining
`s`. Hence `(f^_v)^2 - f^_v` is divisible by `s(s-1)xi(s) = chi(s)`, i.e.
`[f_v]^2 = [f_v]`. Symmetrically for `f_h`, using `xi(1) = 1/2`. Next
`f^_v f^_h = -4 s(s-1) xi^2 = chi * (-4 xi)`, so `[f_v][f_h] = 0`. Finally
`H^ = 2xi` gives `H^2 - H^ = 2xi(2xi - 1)`, and `2xi(s) - 1` vanishes at `s = 0`
and `s = 1` (again `xi(0) = xi(1) = 1/2`), hence is divisible by `s(s-1)`; so
`[H]^2 = [H]`. Minimality and the coordinate description follow from
Theorem 1.1: the coordinate vectors are `(1,0;0)`, `(0,1;0)`, `(1,1;0)`. `[]`

**Remark 1.3 (what makes this work).** Every step used `xi(0) = xi(1) = 1/2` —
that is, the *normalisation* of `xi`, the factor `1/2` in
`xi(s) = (1/2)s(s-1)pi^{-s/2}Gamma(s/2)zeta(s)`. Change the normalisation and
the rulings stop being idempotent. So the "two rulings of a quadric" are not an
analogy imposed from outside; they are the two minimal idempotents that the
completed zeta function's own normalisation produces. Correspondingly

```
        H^2 = s(H,H) = 2  =  the number of minimal idempotents in the polar factor,
```

which is a rank statement, not a curvature statement.

**Corollary 1.4.** `D / rad I_d = [f_v] . (D/rad) (+) [f_h] . (D/rad) (+) J`,
where `J` is the ideal of classes vanishing at `0` and `1` — that is,
`J = D^o / rad`. This is 113_09 Cor 3.2 upgraded from a vector-space splitting
to a **ring** splitting by orthogonal idempotents.

## 2. The order map: the first discrete structure

**Definition 2.1.** Let `S := {0, 1} union { rho : xi(rho) = 0 }` be the zero set
of `chi`, and let `Div_S := (+)_{s_0 in S} Z . [s_0]` (finitely supported
integer combinations). For `f` in `D` with `f^` not identically zero, set

```
        div_S(f) := sum_{s_0 in S} ord_{s_0}(f^) . [s_0] .
```

**Proposition 2.2.** `div_S` has all three properties that `[f] -> V` lacks:

1. **`Z`-valued and lattice-valued**: `div_S(f)` lies in the free abelian group
   `Div_S`. (Well-defined: `f^` is holomorphic and not identically zero, so each
   order is a finite nonnegative integer, and only finitely many are nonzero for
   the elements we use.)
2. **`*`-additive**: `div_S(f * g) = div_S(f) + div_S(g)`, because transforms
   multiply and orders of a product add.
3. **`C^x`-invariant**: `div_S(lambda f) = div_S(f)` for every `lambda != 0`.

*Proof.* Immediate from `ord_{s_0}` being a valuation on the ring of germs at
`s_0`. `[]`

Property 3 is the one O1 was missing, and property 2 is the one the additive
class map was missing. Values on the five standard classes:

| class | `f^` | value coords at `(0,1)` | `div_S` |
|---|---|---|---|
| `H` | `2 xi` | `(1, 1)` | `sum_rho m_rho [rho]` |
| `f_v` | `-2(s-1) xi` | `(1, 0)` | `[1] + sum_rho m_rho [rho]` |
| `f_h` | `2 s xi` | `(0, 1)` | `[0] + sum_rho m_rho [rho]` |
| `w` | `s(s-1) xi` | `(0, 0)` | `[0] + [1] + sum_rho m_rho [rho]` |
| `f_v * f_v` | `4(s-1)^2 xi^2` | `(1, 0)` | `2[1] + 2 sum_rho m_rho [rho]` |

Note the pattern: **the support of `div_S(f)` is exactly the vanishing set of
the value vector.** The two objects have complementary supports. Section 3 turns
that observation into an obstruction.

**Definition 2.3.** `deg_ord(f) := sum_{s_0 in {0,1}} ord_{s_0}(f^)`, the polar
part of the order divisor. From the table, `deg_ord + deg = 2` on all five
classes, where `deg` is 113_10's degree. This is a genuine `Z`-valued degree —
but it is the *complement* of the one the intersection form uses, which is the
first sign of trouble.

## 3. The double dissociation, and the true cause of O1

**Theorem 3.1 (double dissociation).** Neither of the two structures determines
the other. Explicitly:

- **(a) Same divisor, different values.** `div_S(2 f_v) = div_S(f_v)` while the
  value vectors are `(2,0)` and `(1,0)`, so `s(2f_v, 2f_v) = 4 s(f_v,f_v)`'s
  polar part differs: `s(2f_v, F_h) = 2` but `s(f_v, F_h) = 1`.
- **(b) Same values, different divisor.** `f_v * f_v` and `f_v` have the *same*
  value vector `(1,0;0)` — indeed `[f_v]^2 = [f_v]` by Theorem 1.2, so they are
  the same class in `D / rad` — while
  `div_S(f_v * f_v) = 2 div_S(f_v) != div_S(f_v)`.

*Proof.* (a) `ord` ignores nonzero scalars (Prop 2.2(3)) while `ev` does not.
(b) Theorem 1.2 gives `[f_v]^2 = [f_v]`; Prop 2.2(2) gives
`div_S(f_v * f_v) = 2 div_S(f_v)`, and `div_S(f_v) != 0` because `f^_v(1) = 0`.
`[]`

**Corollary 3.2 (the cause of O1).** A divisor map deserving the name must be
invariant under scaling the section, so that `H^0(D)` is a module and grows with
`D`. The map `f -> [f] in V` used in 113_08–113_10 is *linear*, hence maximally
non-invariant: scaling the section scales the divisor. That is precisely why
`h^0(nD) = h^0(D)` there. Conversely `div_S` is scaling-invariant, hence
escapes O1 — but by Theorem 3.1(b) it does not see the values, and the
intersection form `s` is a function of the values alone.

**Theorem 3.3 (the fork).** No `h^0` defined on `V = D / rad I_d` can satisfy a
Riemann–Roch identity with a nonconstant degree term, and no `h^0` defined on
`Div_S` can be coupled to `s`.

*Proof.* First half: define, for a class `c` with representative `f`,
`H^0(c) := { g in rad I_d : f + g >= 0 }` — the section set forced by 113_10
Def 2.1, since `h^0(c) > 0` must mean exactly that `c` is effective (acceptance
tests R7, R8 of 113_10 both refer to this notion). Changing the representative
translates the set, so its affine-hull dimension `d(c)` is well defined
(`d(c) := -1` when empty). For `n > 0`, `g |-> ng` is a bijection
`H^0(c) -> H^0(nc)`, so `H^0(nc) = n . H^0(c)` and `d(nc) = d(c)`. Any RR of the
form `h^0(D) - h^1(D) = deg D + chi` applied along `D, 2D, 3D, ...` with
`deg D > 0` forces `h^0(nD) -> infinity` unless `h^1` absorbs it, and `h^1`
built from the same affine sets is scale-invariant by the identical argument.
Second half: by Theorem 3.1(a), `div_S` does not separate `f_v` from `2 f_v`,
while `s` does; so `s` does not factor through `div_S`. `[]`

**Theorem 3.4 (effectivity is not a function of degree).** There are classes of
equal degree, one effective and one provably not. Take `c_1 = [H]` (degree `2`,
effective by 113_10 Thm 3.2) and `c_2 = [3 f_v - f_h]` (degree `3 - 1 = 2`).
Then `c_2` is not effective.

*Proof.* Every `g` in `rad I_d` has `g^(1) = 0` (113_10 Thm 1.3), so every
representative of `c_2` has `f^(1) = -1 < 0`. But `f^(1) = int f(u) du`, which is
strictly positive for a nonnegative nonzero `f` (113_10 Thm 2.2). `[]`

Corollary: **a Riemann–Roch of the shape `h^0 - h^1 = deg + chi` cannot by itself
deliver (E^o)**; the whole burden falls on `h^1`, which must be exactly the
functional that separates `[H]` from `[3f_v - f_h]`. This is a sharp, cheap
acceptance test for any future `h^1`, and it is new:

- **R9.** A candidate `h^1` must satisfy `h^1([3f_v - f_h]) > h^1([H])`, since the
  two classes have equal degree and only the first fails to be effective.

## 4. Why an imported `h^0` will not close row (d) either

If `h^0` cannot be built inside `D`, the natural move is to import one. The
corpus already contains a careful, source-verified inventory of every
Riemann–Roch theorem in the Connes–Consani programme
(`03-research/phase-39-G1G2-interface/120-inventario-CC-fuente.md`). Read against
the requirements of row (d), all four are insufficient, and for the same reason.

| source | dimension theory | RR formula | pairing |
|---|---|---|---|
| `1603.03191`, scaling site `C_p` | real-valued, von Neumann type II | `Dim_R H^0(D) - Dim_R H^0(-D) = deg D` | **none** |
| `2205.01391`, `Spec Z-bar` over `S[±1]` | integer, min. generators | `dim H^0 - dim H^1 = ceil'(deg' D + log' 2) - 1_L` | Pontryagin `H^1(D) x H^0(K-D) -> U(1)` |
| `2306.00456`, `Z` over `S` | integer | `dim H^0 - dim H^1 = ceil'(deg_2 D) + 1` (**genus 0**) | as above |
| `1805.10501`, the RR strategy | — | — | declares RR on the *square* open |

Three facts from that inventory decide the matter, all marked `[VERIFICADO]`
there against the source text:

1. **The pairing has no signature.** Of `2205.01391` Thm 1.2 the inventory
   records: it is *"un apareamiento de dualidad perfecto entre espacios distintos
   (`H^1` contra `H^0` del divisor dual), **no** una forma bilineal simétrica
   sobre un mismo espacio, y **no** trae asociada noción alguna de
   signatura/índice."* Row (d) needs a symmetric form on one space with
   signature `(1, n-1)`. A perfect duality between two different spaces is a
   different object and does not degenerate into one.
2. **It is all dimension 1, and genus 0.** `2306.00456` states the analogy
   itself: *"(1.1) displays a perfect analogy with the Riemann-Roch formula
   holding for curves of genus 0."* On a genus-0 curve the intersection theory is
   rank one — the degree — with signature `(1,0)`. There are no negative
   directions, so no index theorem. Our `s` already has a negative direction:
   `(F_v - F_h)^2 = -2` (113_09 Thm 4.1, measured from primes). Rank-one RR
   cannot produce it.
3. **The square is open, and CC say so.** The inventory records for
   `1805.10501`: *"to prove a Riemann-Roch theorem on the square of the Scaling
   Site one faces a substantial difficulty"*, and its own summary line: *"Nadie ha
   cruzado todavía 'RR absoluto' con 'cuadrado'."* Also listed under what is
   absent from `1603.03191`: *"Teoría de intersección sobre `C_p x C_p`."*

**Conclusion 4.1.** Importing `h^0` from the CC corpus can supply a section
functor in dimension one. It cannot supply the signature form row (d) requires,
because no such form exists anywhere in that corpus. This is not a gap in our
reading; it is the declared open problem of the source programme.

This also settles 113_12's realistic ceiling in advance, and 113_12 should be
written to that ceiling rather than to the hope: Serre duality from
`2205.01391` Thm 1.2 can be transported as a *duality*, and the involution
`s -> 1 - conj(s)` (which 113_09 showed swaps `f_v` and `f_h`) is the natural
candidate to carry it. What it will not produce is `H^2`, a trace map, or a
self-intersection.

## 5. Where the missing `Z`-structure actually is

O1(i) asked for a genuine discrete component. Theorem 3.1 says it is not in the
values. Section 4 says importing it in dimension one does not help. But it is
already present in the phase, in plain sight, on the *arithmetic* side of the
identity that defines everything here.

113_06 Thm 2.2 / 113_08 Thm 1.2 give the Weil functional as

```
        T(h)  =  sum_n Lambda(n) [ h(n) + h(1/n)/n ]  -  A(h),
```

and `A(h)` is a single archimedean integral. That is exactly the shape of an
Arakelov intersection number: a **`Z`-indexed sum over the finite places**
(the index set is the free commutative monoid on the primes — a lattice) plus one
archimedean term. The pairing of a test function against the finite part is

```
        < n , f >  :=  Lambda(n) [ f(n) + f(1/n)/n ] ,
```

and `s(f,g) = < D_arith , f * g~ >` with `D_arith` the fixed arithmetic divisor
`sum_n Lambda(n).{n}` completed at infinity.

Compare CC's `H^0` for `Spec Z-bar`, as the inventory records it: the
`S[±1]`-module of **`Z`-valued divisors `sum_i n_i x_i` with `sum_i |n_i| <=
e^a`**, whose dimension is the minimum number of generators with coefficients in
`{-1, 0, 1}`. Its finiteness is lattice-points-in-a-ball: integrality of the
`n_i` plus an archimedean bound. Our finite-place index set is the same kind of
object.

**So the correct target for a section functor in this programme is a module of
integral divisors on prime powers, not a subspace of `D`.** `D` is the space of
*test functions* that such divisors are paired against; asking it to also be the
space of sections was the category error that produced O1. Stated as the
deliverable for whoever attacks this next:

> **Target T1.** Construct a `Z`-module `M` of integral divisors on the prime
> powers, with an archimedean bound making `H^0` finite, together with a
> symmetric `M x M -> R` pairing that (i) restricts to `s` on the image of
> `D`, (ii) has a positive direction realised by `H` with `H.H = 2`, and (iii)
> has a negative direction realised by `F_v - F_h` with `(F_v-F_h)^2 = -2`.
>
> Requirement (iii) is what makes T1 "RR on the square" rather than RR on
> `Spec Z`, and it is why CC's declared open problem and ours are the same
> problem.

That is an candid statement of the remaining distance. It is also the first time
in the phase that the missing object has been specified tightly enough to be
attacked or refuted.

## 6. Verdict on d3

**d3 is not closed, and this file argues it cannot be closed as posed.**

- Inside `D`: blocked by Theorem 3.3. The intersection form lives on the values;
  the only scaling-invariant divisor map lives on the orders; the two are

- By import: blocked by Conclusion 4.1. The available Riemann–Roch theorems are
  one-dimensional and carry no signature, which the source programme itself
  identifies as the open problem.

What this file does deliver is (i) an exact algebraic description of
`D / rad` and of the rulings, replacing a metaphor with a theorem; (ii) the first
`Z`-valued, `*`-additive, scale-invariant structure in the phase; (iii) the
diagnosis of O1 as a divisor/section category error; (iv) two new acceptance
tests, R9 and Target T1; and (v) a defensible reason to stop looking for `h^0`
inside `D`.

Pre-registered refutation conditions for this file's own claims:

- **R10.** If someone exhibits an `h^0` on `V` that is *not* determined by the
  section sets `{ g in rad : f + g >= 0 }`, Theorem 3.3's first half does not
  apply to it, and this file's verdict must be revisited. The theorem constrains
  `h^0` compatible with 113_10 Def 2.1, which is what R7/R8 demand — not every
  conceivable `h^0`.
- **R11.** If a symmetric form with a negative direction is ever produced from
  CC-type duality in dimension one, Conclusion 4.1 is refuted. The test is
  concrete: it must reproduce `(F_v - F_h)^2 = -2`.

  to matter — i.e. if some zero has `m_rho > 1` and the truncated ring
  `C[t]/t^{m_rho}` changes the idempotent structure — Theorem 1.2 needs
  restating. It does not affect `f_v, f_h, H`, whose classes are supported at

The divisibility test is a real test, not a tautology: the negative control
`(f^_v + 1)/chi` blows up like `1/eps` across exactly the same probe points
where the four genuine quotients stay flat to 4 significant figures. The
`t_max` ratios are the numerical face of obstruction O1 — the admissible set of
sections is a *scaled copy*, exactly, at `n = 2, 5, 100`, and the ratio is `n`
to 20 digits. And the interval is genuinely bounded (`W` ranges over
`[-16.95, 8.67]`), so the ratio test has content rather than measuring
`infinity / infinity`.
