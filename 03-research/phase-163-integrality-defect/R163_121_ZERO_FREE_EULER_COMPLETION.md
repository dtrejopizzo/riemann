# R163_121 — Positive, zero-free Euler completion of each ordinary prefix

**Status:** construction and error `O_{X,ε}(x^ε)` proved; **uniform bound critical in `X` open**. A candidate quantitative mechanism for closing D, not a proof of RH. Does not modify paper 48.

## 1. The explicit object

Fix `X≥2`, `A=log X`, and the finite ordinary Euler product

```
P_X(s)=∏_{p≤X}(1−p^{-s})^{-1}.
```

Define a continuous **prime-power measure** for the tail by

```
dΠ_X^{tail}(t)=1_{t>X} dt/log t.                       (1)
```

Its formal zeta for `Re s>1` is

```
T_X(s)=exp(∫_X^∞ t^{-s}dt/log t)
      =exp(E₁(A(s−1))),
Z_X(s)=P_X(s)T_X(s).                                   (2)
```

The difficulty with (1) is that `dΠ` is not automatically a measure of **genuine primes**: the sum over powers must be inverted. Here that inversion preserves the sign.

## 2. Witt–Möbius inversion: positive continuous primes

Let `pow_m(t)=t^m`. Define

```
dπ_X^{tail}=Σ_{m≥1} [μ(m)/m](pow_m)_* dΠ_X^{tail}.   (3)
```

The sum is locally finite, since the `m`-th term starts at `X^m`. Applying the prime-power operator gives exactly

```
Σ_{k≥1}(1/k)(pow_k)_*dπ_X^{tail}
 =Σ_{n≥1}(1/n)(Σ_{m|n}μ(m))(pow_n)_*dΠ_X^{tail}
 =dΠ_X^{tail}.                                        (4)
```

For `t>X`, with `M=⌊log t/log X⌋`, the measure in (3) has density

```
dπ_X^{tail}(t)
 = [dt/log t] · [1+Σ_{m=2}^M μ(m)m^{-1}t^{1/m−1}]. (5)
```

If `M=1`, the bracket equals 1. If `M≥2`, since `t≥X^M≥2^M`,

```
1+Σ_{m=2}^M μ(m)m^{-1}t^{1/m−1}
 ≥1−t^{-1/2}(H_M−1)
 ≥1−2^{-M/2}(M−1)>0.                            (6)
```

The last inequality holds for every integer `M≥2` (check `M=2,3,4` and then increase `M` two at a time). So `dπ_X^{tail}` is a positive, locally finite measure of continuous primes. Together with the ordinary atoms `p≤X`, it defines a genuine Beurling system **in the sense of positive measures**, though not a discrete one.

Since the tail starts strictly after `X`, its generalized integers of size `≤X` are only the unit. The atomic primes `p≤X` generate exactly the ordinary integers `n≤X`, each once. So

```
N_X(x)=⌊x⌋,  π_X|[1,X]=π_ζ|[1,X],
Λ_X(p^k)=log p for p^k≤X.                         (7)
```

The complete prime-power measure equality (4) simultaneously guarantees that no spurious squared terms of the continuous primes appear: this is the construction's sum×product step.

## 3. Zero-free continuation and bound for fixed `X`

The classical expansion of the exponential integral (see [NIST DLMF §§6.6, 6.12](https://dlmf.nist.gov/6.12)) has the form

```
E₁(z)=−γ_E−log z+h(z),   h an entire function,
T_X(s)=e^{−γ_E}[A(s−1)]^{-1} exp(h(A(s−1))).      (8)
```

So `T_X` is meromorphic on all of `ℂ`, has only a simple pole at `s=1`, and **has no zeros**. `P_X` is holomorphic and non-zero for `Re s>0`, so `Z_X` is likewise zero-free there except for its pole at 1. Its residue is

```
ρ_X=e^{−γ_E}P_X(1)/log X>0.                         (9)
```

For each fixed `ε>0` and each `X`,

```
N_X(x)=ρ_X x+O_{X,ε}(x^ε).                         (10)
```

**Justification of (10).** On any closed vertical strip `ε≤Re s≤c` with `c>1`, the asymptotic expansion of `E₁` from [DLMF §6.12](https://dlmf.nist.gov/6.12) gives `T_X(s)−1=O_{X,ε,c}(1/|Im s|)` as `|Im s|→∞`. For the integer measure of the tail alone, `T_X−1` is the transform of its part on `(1,∞)`, which is continuous. Its Mellin–Perron formula has integrand `(T_X(s)−1)x^s/s=O_{X,ε,c}(x^{Re s}/|Im s|²)` and converges absolutely. Moving the line from `c` to `ε` only crosses the pole at `s=1`, with residue `e^{−γ_E}/A`. The horizontals tend to zero; what remains is `N_X^{tail}(x)=1+(e^{−γ_E}/A)x+O_{X,ε}(x^ε)` for `x>1`.

**Audit of the inversion step.** Continuity of the part `t>1` is not assumed: `dπ_X^{tail}` has a locally integrable density, each push-forward by `pow_k` does too, and `dN_X^{tail}=\exp_*(dΠ_X^{tail})` is a locally **finite** sum of convolutions of those densities because all their supports start after `X>1`. So there are no atoms for `t>1`, and Mellin inversion gives the count's value on all of `x>1`. On the initial line `c>1` this is applied to `T_X−1`, whose transform divided by `s` is integrable at infinity; shifting to `ε` does not cross `s=0`. This argument verifies the bound for each fixed `X`, but the symbols `O_{X,ε,c}` may grow without control as `X→∞`.

Convolving with the integers `d` generated by the finite set of primes `p≤X` gives `N_X(x)=Σ_{d≤x}N_X^{tail}(x/d)`. The constant term `1` sums to `#\{d∈S_X:d≤x\}=O_{X,ε}(x^ε)`. Both the sum of the other errors and extending the main sum to `d>x` likewise cost `O_{X,ε}(x^ε)`, because `Σ_{d∈S_X}d^{-ε}=∏_{p≤X}(1−p^{-ε})^{-1}<∞`. This proves (10).

## 4. A single uniform bound would suffice for RH — and it is not proved

Fix any `0<θ<1/2` and define the best counting constant of the constructed system,

```
C_{X,θ}=sup_{x≥1} x^{-θ}|N_X(x)−ρ_X x|<∞.         (11)
```

Finiteness for each `X` follows from (10), taking `ε<θ`. The **new target** is the uniform estimate

```
C_{X,θ}=O_η(X^{1/2−θ+η}) for every η>0.          (UC_θ)
```

If `(UC_θ)` holds for some `θ<1/2`, then RH follows rigorously: `N_X=⌊x⌋` on `[1,X]`, `Z_X` is zero-free on `Re s>0`, and `R163_120 (5)`'s Mellin stability bound gives `Z_X→ζ` uniformly on every compact subset of `Re s>1/2` (excluding the pole at 1). Indeed, for a compact set with `Re s≥β>1/2`, choose `0<η<β−1/2` and the error is `O(X^{1/2+η−β})→0`. By Hurwitz, ζ cannot have zeros for `Re s>1/2`; its functional equation reflects the result to the other side. **`(UC_θ)` has not been proved.** The fact that (10) holds for each `X` gives no control at all over how its constant depends on `X`.

In the first band `X<x<2X` there is an exact identity showing where the hard arithmetic enters:

```
N_X(x)=⌊x⌋−[π(x)−π(X)]+[Li(x)−Li(X)].          (12)
```

Indeed, the integers generated by `p≤X` that are missing below `2X` are exactly the ordinary primes in `(X,x]`, and the continuous tail contributes a single prime with density `dt/log t`; products of two tails or of one tail with `p≥2` are `≥2X`. So `(UC_θ)` is not a routine consequence of `Z_X`'s zero-free continuation: already in (12) it demands uniform control of the ordinary-prime discrepancy and the residue adjustment `ρ_X`.

In fact, (12) gives a second, direct audit of `(UC_θ)`'s strength. Equality at `x=X` and `(UC_θ)` would imply `|ρ_X−1|X=O_η(X^{1/2+η})`; substituting this and the bound on `N_X−ρ_Xx` into (12) gives, uniformly for `X<x<2X`,

```
|[π(x)−π(X)]−[Li(x)−Li(X)]|=O_η(X^{1/2+η}).    (13)
```

Summing (13) over dyadic intervals produces `π(x)−Li(x)=O_η(x^{1/2+η})` for every `η>0`, a bound of RH strength. So the uniform gate **is not a simple technical improvement** on (10): it already contains the central arithmetic problem in the first band. It is not claimed here that RH implies `(UC_θ)` for this particular family.

## 5. Audit against falsifiers and scope

- The construction uses the **exact values** of the ordinary primes up to `X`, the prime-power identity (4), and the exact integer lattice up to `X`, but the tail `dπ_X^{tail}` is continuous. So it does not contradict the Epstein, DH or Beurling–DMV barriers: it does not claim that positive Euler and **finite** integrality suffice. The needed global law is precisely `(UC_θ)`.
- If Witt–Möbius inversion is dropped and `dt/log t` is taken simply as a prime measure, the powers of the continuous primes add a quadratic term with a singularity at `s=1/2`; inversion (3) exactly cancels those terms while keeping positivity. This joint control of sum and product is the note's constructive contribution.
- `(UC_θ)` is a concrete sufficient criterion for RH, not a proved theorem nor a strategy declared successful. It must be subjected to direct estimates on `N_X` and to the test of (12); if it fails, this explicit family does not close D.
