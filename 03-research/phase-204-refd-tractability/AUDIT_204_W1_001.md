## 1. Lemma W1

### 1(a) The variational identity

prop:WT's convention (l.4358): 𝔄 = 𝔞_T|𝒟^par_T (archimedean + comb, without the Tate condition), χ_par ∈ L²_par(I_T) with
⟨F, χ_par⟩ = ℓ_par(F); in the odd sector ℓ_odd(F) = S(F) = ∫_{I_T} F(t) sinh(t/2) dt (thm:parityschur(o): 𝔞_T(F_o) −
2ℓ_odd(F_o)², and Rel(A B̄) = |C|² − |S|²). Then q := ⟨𝔄⁻¹χ, χ⟩, g := 𝔄⁻¹χ ∈ 𝒟^par_T (Lax–Milgram in prop:WT's proof)
and q = ℓ(g) = 𝔞_T(g).

If 𝔄 ≻ 0 (positive floor; compact resolvent ⇒ coercive on the form domain), 𝔞_T is an inner product on the form
domain and ℓ(F) = 𝔞_T(g, F). Cauchy–Schwarz in 𝔞_T: ℓ(F)² ≤ 𝔞_T(g)𝔞_T(F) = q·𝔞_T(F), with equality at F = g. Hence
q = sup_{F≠0} ℓ(F)²/𝔞_T(F) and the sup is attained. **✓ PROVED.** Without 𝔄 ≻ 0 the identity is false (with
n_−(𝔄) ≥ 1 the sup is +∞ if ℓ does not vanish in the negative direction): this is why W1 does not extend to the even
sector, as WEAKEN acknowledges in Lemma W2. Equivalently: 1/q = min{𝔞_T(F) : ℓ(F) = 1} = 𝔞_T(h_odd), which is
thm:parityschur(a3) with the full form.

### 1(b) Monotonicity in T and χ's T-dependence

Initial objection: χ_T = sinh(t/2)·1_{I_T} changes with T, so "sup over a larger space" is not enough a priori.
Resolution with the exact convention:

1. **χ is not normalized.** In prop:WT, q is not divided by ‖χ_T‖² or by anything T-dependent; χ is the representative of
   the functional ℓ_par, whose formula ∫F sinh(t/2) does not depend on T. (Had χ_T/‖χ_T‖ been normalized, q would be
   divided by ‖χ_T‖² = sinh T − T, which is increasing, and monotonicity would break; this is not the paper's
   convention.)
2. **The functional agrees on E's image.** For F ∈ 𝒟^odd_T and E F its extension by zero, ⟨χ_{T′}, E F⟩ =
   ∫_{I_{T′}} (EF) sinh(t/2) = ∫_{I_T} F sinh(t/2) = ⟨χ_T, F⟩. (This is exactly lem:gmono's remark: "χ_par on
   I_{T′} restricts to χ_par on I_T".)
3. **The form agrees on E's image.** By lem:monoT's proof: the archimedean symbol m(s) of eq:form is
   **independent of T** (confirmed by lem:contT's proof, where the T-dependence enters only through the test's
   dilation); c_{EF} = c_F vanishes for |u| ≥ 2T, and every new contact n ∈ 𝒩_{T′}∖𝒩_T has log n ≥ 2T. Hence
   𝔞_{T′}(EF) = 𝔞_T(F). On the question "is there a T-dependent archimedean term beyond the support
   (C₀, killing term, κ(y) ~ ½log 1/(y−T))?": in P46's form 𝔞_T (eq:Aform/eq:form) **no**; those objects belong to
   other normalizations (bordered window form) and are not prop:WT's 𝔄. ✓
4. **Domain.** The form domain is {F : ∫log(2+|s|)|F̂(s)|² < ∞}, a condition on F̂, which E does not alter. ✓

Then q_odd(T′) = sup_{𝒟^odd_{T′}} ℓ²/𝔞_{T′} ≥ sup_{E𝒟^odd_T} ℓ²/𝔞_{T′} = sup_{𝒟^odd_T} ℓ²/𝔞_T = q_odd(T),
provided 𝔄_odd ≻ 0 at T and at T′. **Lemma W1: PROVED.**

Interval hypothesis: the condition "𝔄_odd(T) ≻ 0" is itself monotone (𝔄_odd's floor is non-increasing by the same
E argument), so the set of T where it holds is an initial interval (0, T_𝔄); WEAKEN's "interval J" is
consistent.

### 1(c) Novelty: none

prop:WT gives 𝔤_odd = 1/q_odd − 2. lem:gmono (P46 l.4760) proves 𝔤_par(T′) ≤ 𝔤_par(T) under λ^par_A > 0 at T and T′, which
is implied by 𝔄_odd ≻ 0 (restriction to 𝒬^odd). Since x ↦ 1/(x+2) is decreasing for x > −2, **Lemma W1 ⟺ lem:gmono in
the odd sector** (over the interval where both hypotheses hold). The proof is the same, word for word (extension by
zero + (a3)). POLAR_CAP_001 §2.2 already recorded this and its index entry says "d𝔤/dT ≤ 0 (lem:gmono) and the
derivative is a functional of the resolvent". **Label: PROVED (reformulation of lem:gmono; no new content).** WEAKEN
l.66's phrase "new PROVED content" must be corrected.

## 2. Cor W1′

Statement: for T ≤ T₀ = ½log15, 𝔄_odd(T) ≻ 0 and q_odd(T) < ½.

D0 in WEAKEN l.32 is stated as "W_T ⪰ 0, λ_A(T) > 0". With only W_odd ⪰ 0:
- 𝔄_odd = W_odd + 2ℓ_odd² ⪰ W_odd ⪰ 0 gives 𝔄_odd ⪰ 0, **not** ≻ 0: an F with 𝔞_T(F) = 0 requires W(F) = 0 and ℓ(F) = 0,
  which ⪰ 0 does not exclude.
- prop:WT requires 0 ∉ spec(𝔄) and q ≠ 0; without strictness it cannot be invoked, and in degenerate case (iii),
  q = −ε/2 = ½ is possible with W_odd ⪰ 0 and a one-dimensional radical. So the written proof ("q_odd ≤ ½
  (non-degenerate ⇒ <)") **assumes** the non-degeneracy it was meant to prove.

Repair (available, CITED): Mori VIII certifies λ^W(½log15) ≥ 2^{−2904} > 0, and lem:monoT gives λ^W(T) ≥ λ^W(T₀) > 0 for
T ≤ T₀. Then 𝔄_odd ⪰ W_odd ⪰ λ^W > 0 (strict, by forms), q_odd = ⟨𝔄⁻¹χ,χ⟩ > 0 (χ ≠ 0), and prop:WT(ii) with
n_−(W_odd) = 0 = n_−(𝔄_odd) and null radical excludes q ≥ ½. Moreover prop:WT's "only if" gives directly: W_odd with
positive floor ⟺ 𝔄_odd ≻ 0 ∧ q_odd < ½. **Cor W1′: PROVED given λ^W(T₀) > 0 (CITED Mori) + prop:WT; with D0 in the
form "⪰" it only gives 𝔄_odd ⪰ 0 and q_odd ≤ ½.** Correct D0 to "λ^W(T₀) > 0" in WEAKEN.

Observation: the corollary has no content beyond its hypothesis. "𝔄_odd ≻ 0 ∧ q_odd < ½ on (0,T₀]" is, by prop:WT,
identical to "W_odd ≻ 0 on (0,T₀]", which is part of D0. It is exactly an instance of WEAKEN's own Lemma W0
(equivalent to the datum).

## 3. Is there "amplification"? No.

### 3.1 The T discrepancy: resolved

- prop:WT (P46, paragraph after the proof): "at T = ½log3: … n_−(𝔄_odd) = 0 with q_odd ≈ ½ − 2.5·10⁻⁴ (numerical)".
- POLAR_CAP_001 l.152–153: Galerkin at T₀ = ½log3 (16/24/32 modes): 𝔤_odd ≲ 1·10⁻³.
- INTEGRATION_204_001 l.26 cites the number **without T**; the attributed "½log15" appears in no memo.

Conclusion: **the measurement is at ½log3**. No measurement of q_odd exists in the corpus at ½log5 or ½log15.

### 3.2 It is an upper bound on the margin, not a lower bound

½ − q_odd = ½ − 1/(𝔤_odd + 2) = 𝔤_odd/(2(𝔤_odd + 2)) ≈ 𝔤_odd/4. The value 𝔤_odd ≲ 10⁻³ is a Galerkin minimum of
W over {ℓ = 1} (thm:parityschur(a3)), hence an **upper bound** on 𝔤_odd (POLAR_CAP says so: "legitimately an upper
bound"). So "½ − q_odd ≈ 2.5·10⁻⁴" correctly reads as **½ − q_odd ≲ 2.5·10⁻⁴** at ½log3. WEAKEN uses it as
*available margin* (L-b's budget), which requires a **lower** bound: none is proved or measured.

### 3.3 Exact relation between ½ − q_odd and λ^W_odd (computation in thm:parityschur's block)

Odd sector, ε = −1. Decomposition (a1): 𝒟^odd_T = 𝒬^odd_T ⊕ ℝh, W_T(G + xh) = 𝔞_T(G) + 𝔤x², with h = h_odd = 𝔄⁻¹χ/q
(prop:WT), ℓ(h) = 1, 𝔞_T(h) = 1/q, 𝔤 = 1/q − 2.

(a) **Upper bound on 𝔤 via the floor.** Let e be the unit floor vector of W_odd (W(e) = λ^W_odd). If ℓ(e) ≠ 0, e/ℓ(e)
is feasible in (a3): 𝔤_odd ≤ λ^W_odd/ℓ(e)². Hence
  ½ − q_odd ≤ λ^W_odd / (4ℓ(e)²)·(1 + O(𝔤)).
(b) **Two-sided bound from (a4).** λ^W_odd ≤ 𝔤/‖h‖², and if 2λ^W_odd < λ^odd_A: 𝔤/‖h‖² ≤ 2λ^W_odd. Hence
  λ^W_odd·‖h‖²/4 ≲ ½ − q_odd ≲ λ^W_odd·‖h‖²/2.
(c) Limit: λ^W_odd → 0⁺ with λ_A^odd bounded below ⟹ 𝔤 → 0 ⟹ q_odd → ½ (degeneracy (iii) of prop:WT); the converse
likewise. That is, "½ − q_odd" and "λ^W_odd" vanish together and their ratio is **exactly ‖h_odd‖²/4 up to a factor of 2**.

Can ‖h_odd‖² be ~10⁶²? ‖h‖ ≥ 1/‖χ‖ (a4) and ‖χ_T‖² = sinh T − T (≈ 0.028 at ½log3, ≈ 0.46 at ½log15): the lower bound is
O(1)–O(10²). An amplification of 10⁶² would require, by (a), ℓ(e) ≲ 10⁻³¹: the odd floor vector almost orthogonal to
sinh(t/2) in L². Nothing in the corpus suggests this: MORI15_EXTREMAL l.57 gives the Galerkin odd floor 6.109·10⁻⁶⁶
(certified margin 3.95·10⁻⁶⁶) with the comb as the positive carrier; ℓ(e) has not been measured. **Falsifiable
prediction (NUMERICAL pending, not run):** at ½log15, ½ − q_odd ≤ 1.5·10⁻⁶⁶/ℓ(e)²; with ℓ(e) ≥ 10⁻³ this is ≤ 10⁻⁶⁰.

### 3.4 Reading with the odd-sector data

- At ½log3 the odd floor is large (pre-first-contact of 3; AA_001: the odd margin is "first-contact scale", a constant
  gain of 10²–10³ over the even sector, not a regime change). A ½ − q_odd ~ 10⁻⁴ there is compatible with
  λ^W_odd ~ 10⁻⁵–10⁻⁶ and ‖h‖² ~ 10–10²: **no amplification**, just a change of units.
- WEAKEN's comparison "2.5·10⁻⁴ versus 10⁻⁷⁰" mixes **different T** (½log3 vs ½log15) and **different sectors**
  (odd vs even: 10⁻⁷⁰ is Mori's even floor; the odd one is 3.95·10⁻⁶⁶).
- By W1 (= lem:gmono), μ_odd(T) = ½ − q_odd is non-increasing: the "budget" 2.5·10⁻⁴ from ½log3 is consumed between
  ½log3 and ½log15, and by 3.3(a) it ends up ≲ λ^W_odd(½log15)/ℓ(e)². The L-b scalar that was supposed to "stay below
  2.5·10⁻⁴" already sits, at T₀, at distance ~10⁻⁶⁵ (barring anomalous ℓ(e)) from ½.

Moreover the odd sector is the easy one: the minimizer and the 10⁻⁷⁰ scale live in the even sector, where
𝔤_ev = q-reformulation of a −2 + 2 cancellation (POLAR_CAP §4.3), with no sup variational formula (WEAKEN Lemma W2,
OPEN). Even if there were odd amplification, row D would remain pending on the even channel.

**§3 verdict: no amplification is proved or measured; structure (a3)–(a4) indicates there is none
(½ − q_odd ≍ ‖h_odd‖²·λ^W_odd).** The phrase "first sign-bearing quantity at non-double-exponential scale" is an
artifact of comparing ½log3 with ½log15.

## 4. (L-b): consumption rate, Theorem X, and restriction 11

### 4.1 The formula

With 𝒟_{T′} = 𝒟_T ⊕ 𝒟_ring (L²-orthogonal; 𝔄 is not diagonal in this decomposition: archimedean and comb couple window
and ring), block [[𝔄₁₁, 𝔄₁₂], [𝔄₂₁, 𝔄₂₂]] and χ = (χ₁, χ₂): Schur–Banachiewicz formula,
q(T′) = ⟨𝔄₁₁⁻¹χ₁, χ₁⟩ + ⟨S⁻¹r, r⟩, S = 𝔄₂₂ − 𝔄₂₁𝔄₁₁⁻¹𝔄₁₂, r = χ₂ − 𝔄₂₁𝔄₁₁⁻¹χ₁. Correct (and S ≻ 0 if 𝔄 ≻ 0), and
⟨S⁻¹r, r⟩ ≥ 0 reproduces W1. Note: 𝔄₁₁⁻¹χ₁ = q(T)·h_odd(T), hence r = χ₂ − q(T)𝔄₂₁h_odd(T).

### 4.2 Does Theorem X apply?

Theorem X (R186_045 §2.2) is a statement about the negative subspace E₋ of W_T(σ_{T₀}) (prolate packets in U₀) and the
condition Δ_{T₀,T} (new primes) must satisfy there; the derived rule "every first-order discriminant is a functional of
h*" refers to the minimizer. h_odd **is not** h* (it is the minimizer over {ℓ = 1}, not over the sphere), so Theorem X
**does not apply literally**. But the objection resurfaces through another, more direct route:
1. r and S depend on 𝔄₁₁⁻¹ (the window's resolvent) and on h_odd(T): this is exactly the 𝒦_H pattern already recorded
   in POLAR_CAP for d𝔤/dT ("the derivative is a functional of the resolvent"). Since q = 1/(𝔤+2), Δq = −Δ𝔤/((𝔤+2)(𝔤′+2)):
   **L-b is POLAR_CAP's route R6/T6.2 (NO-GO TRANSFER) in the variable q.**
2. Restriction 11 (SYNTHESIS_MECHANISM_001): no flow/continuation argument without an independent virial bound at
   relative precision 1/c. Summing increments Δq from T₀ is continuation; the actual budget at T₀ is, by §3.3,
   ≍ ‖h‖²λ^W_odd(T₀), not 2.5·10⁻⁴. The precision required of the bound on ⟨S⁻¹r, r⟩ is thus of the order of the odd
   floor (≈10⁻⁶⁶ at ½log15), not 10⁻⁴: no scale is gained.
3. The working conjecture W1-c ("increments ~ e^{−δT} from the sinh(t/2) weight") runs against the sign of the weight:
   sinh(t/2) **grows** on the ring, ‖χ₂‖² ~ (sinh T′ − sinh T); the decay would have to come entirely from the
   cancellation χ₂ − 𝔄₂₁𝔄₁₁⁻¹χ₁, i.e. from the exact strength of positivity on the ring (TRANSFER).

**§4 verdict: L-b does not dodge restriction 11; it is a renamed retry of POLAR_CAP R6/T6.2 (index: "Do not retry
without an object that does not go through (𝔞_T|𝒬)⁻¹"; 𝔄₁₁⁻¹ is that same type of resolvent). NO-GO (TRANSFER).**
(L-a) remains a legitimate measurement, but its decisive question is now different: measure ℓ(e_odd) and ‖h_odd‖ at
½log15 (prediction §3.3: ½ − q_odd(½log15) ≲ 10⁻⁶⁵·ℓ(e)⁻²).
