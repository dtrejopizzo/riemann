# Balance Laplace jet form

## Purpose

`146_RAISED_LAGUERRE_DUAL_HIERARCHY.md` rewrites A1 using the \(r\)-fold
cumulative balances \(B_r\).  This note records the Laplace-transform form
of those balances.

The point is that each raised A1 inequality is a finite jet at \(s=1\) of a
truncated Laplace transform, plus explicit endpoint terms.  This gives a
coefficient-level target for the signed balance theorem.

## Infinite Laplace transform

Let
\[
  H(s)={1\over s-1}+{\zeta'\over\zeta}(s).
\tag{1}
\]

From the prime-pole integral generator,
\[
  H(s)
  =
  -1
  -
  s\int_0^\infty E(e^u)e^{-su}\,du
  \qquad(\Re s>1).
\tag{2}
\]

Therefore, with \(B_0(u)=E(e^u)\),
\[
  \mathcal B_0(s)
  :=
  \int_0^\infty B_0(u)e^{-su}\,du
  =
  -{H(s)+1\over s}.
\tag{3}
\]

Since \(B_r\) is the \(r\)-fold integral of \(B_0\) from the origin and
\(B_j(0)=0\), the Laplace transform divides by \(s\) at each integration:
\[
  \boxed{
  \mathcal B_r(s)
  :=
  \int_0^\infty B_r(u)e^{-su}\,du
  =
  -{H(s)+1\over s^{r+1}}
  \qquad(\Re s>1).
  }
\tag{4}
\]

Thus all raised balances are generated by the same pole-paired logarithmic
derivative \(H\).

## Truncated transform

For the compact core put
\[
  X=e^T
\]
and define
\[
  \mathcal B_{r,T}(s)
  =
  \int_0^T B_r(u)e^{-su}\,du.
\tag{5}
\]

Using the exact arithmetic formula
\[
  B_r(U)
  =
  {1\over r!}\sum_{m\le e^U}\Lambda(m)(U-\log m)^r
  -
  e^U
  +
  \sum_{j=0}^{r-1}{U^j\over j!},
\]
finite Fubini gives, for \(r\ge1\),
\[
\boxed{
\begin{aligned}
  \mathcal B_{r,T}(s)
  &=
  {1\over r!}
  \sum_{m\le X}\Lambda(m)m^{-s}
  \int_0^{T-\log m} e^{-st}t^r\,dt \\
  &\quad
  -\int_0^T e^{(1-s)u}\,du
  +
  \sum_{j=0}^{r-1}{1\over j!}\int_0^T e^{-su}u^j\,du .
\end{aligned}
}
\tag{6}
\]

All terms are finite.  At \(s=1\), the middle term is interpreted by its
limit:
\[
  \int_0^T e^{(1-s)u}\,du\bigg|_{s=1}=T.
\]

The same formula with \(r=0\) is obtained directly from \(B_0=E(e^u)\):
\[
  \mathcal B_{0,T}(s)
  =
  \int_0^T\psi(e^u)e^{-su}\,du
  -
  \int_0^T e^{(1-s)u}\,du.
\tag{7}
\]

## Laguerre jets at \(s=1\)

Write
\[
  L_{n-1}^{(2+r)}(u)
  =
  \sum_{k=0}^{n-1} c_{n,r,k}u^k .
\tag{8}
\]

Then
\[
  \int_0^T B_r(u)e^{-u}L_{n-1}^{(2+r)}(u)\,du
  =
  \sum_{k=0}^{n-1}
  c_{n,r,k}(-1)^k
  \left.
  {d^k\over ds^k}\mathcal B_{r,T}(s)
  \right|_{s=1}.
\tag{9}
\]

This is just differentiation under the finite integral:
\[
  (-1)^k\mathcal B_{r,T}^{(k)}(1)
  =
  \int_0^T B_r(u)e^{-u}u^k\,du.
\]

Combining (9) with the raised hierarchy gives the exact A1 jet form:
\[
\boxed{
\begin{aligned}
  &\sum_{j=1}^{r} B_j(T_n)e^{-T_n}L_{n-1}^{(1+j)}(T_n) \\
  &\quad+
  \sum_{k=0}^{n-1}
  c_{n,r,k}(-1)^k
  \left.
  {d^k\over ds^k}\mathcal B_{r,T_n}(s)
  \right|_{s=1}
  \le
  {3\over4}\lambda_n^{\rm arch}-n.
\end{aligned}
}
\tag{10}
\]

For each fixed \(n,r,T_n\), every object in (10) is finite and explicitly
arithmetical.

## Infinite-tail comparison

If \(T=\infty\) is used formally, (9) and (4) give
\[
  \int_0^\infty B_r(u)e^{-u}L_{n-1}^{(2+r)}(u)\,du
  =
  \sum_{k=0}^{n-1}c_{n,r,k}(-1)^k
  \left.
  {d^k\over ds^k}
  \left[-{H(s)+1\over s^{r+1}}\right]
  \right|_{s=1}.
\tag{11}
\]

This recovers the same pole-paired Li coefficient data as the prime-pole
generator.  However A1 is compact and uses \(T_n<\infty\), so the useful
object is the truncated jet (10), not the formal infinite transform alone.

## Minimal jet theorem

A coefficient-level route to A1 is:

prove that for some fixed \(r\), or some explicit \(r=r(n)\), the finite jet
inequality (10) holds for all \(n\ge8\), with \(\mathcal B_{r,T_n}\) given by
the finite arithmetic formula (6).

The theorem must use the signed structure of the finite jets.  Bounding
each derivative of \(\mathcal B_{r,T_n}\) in absolute value returns to the
discarded absolute-estimate class.

## Status

Closed as an exact Laplace-jet normal form.  A1 remains open.

The new live target is the finite signed jet inequality (10), equivalently
the raised-balance theorem of `146` written in Laplace coordinates.
