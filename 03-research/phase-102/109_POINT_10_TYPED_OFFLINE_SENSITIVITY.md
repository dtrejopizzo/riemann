# Point 10 - Typed off-line sensitivity

## Purpose

This point is a validity control for any proposed proof of A1. It is not an
extra hypothesis in Li's criterion.

## Required typed test

A proposed A1 mechanism must be tested in a class \({\cal C}_{\rm EG}\) that
contains:

- the zeta data;
- on-line controls compatible with the functional equation;
- an off-line member with a quartet of zeros producing
  \[
    |w_\rho|=\left|1-{1\over\rho}\right|>1 .
  \]

For such a member, the Li term contains an exponentially growing component
\[
  -2\Re(w_\rho^n),
\]
along a subsequence of \(n\), while the archimedean contribution grows only
like \(n\log n\). Thus the Li coefficients eventually become negative.

## Consequence for the proof search

Any proof of A1 that is also valid for the off-line member is false as a
proof of \(\Omega_7\). The proof must use a zeta-specific arithmetic input
that fails for the off-line member before Li positivity is invoked.

## Status

Open as an implemented test class. The mathematical obstruction is clear:
the test must be attached to the exact A1 core, not only to a detached zero
sum.
