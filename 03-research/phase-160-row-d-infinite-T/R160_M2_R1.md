## §1 Definitions

All from P47 (brief §1). `T > 0`, `I_T = (−T, T)`, `N_T = {n ≥ 2: log n < 2T}`, `N_max := max N_T`,
`δ_T := 2T − log N_max > 0`. For real `F ∈ L²(I_T)`, `c_F(u) = ∫F(t)F(t−u)dt` (even, `c_F(0) = ‖F‖²`, `|c_F| ≤ ‖F‖²`,
support in `[−2T, 2T]`). Tate moments `A(F) = ∫Fe^{t/2}`, `B(F) = ∫Fe^{−t/2}`; `P_T = {A = B = 0}`; form domain
`𝒟_T = {F ∈ L²(I_T): ∫log(2+|τ|)|F̂|² < ∞}`. Real tests suffice (P47 `prop:finite`(ii)), so throughout `P_T` denotes the
real Hilbert space of real functions in `P_T`, and `𝒫_T` its real unit vectors in `C_c^∞(I_T)`.

**D1 (weighted forms, eq:Aform).** For `v ∈ ℝ^{N_T}` and `F ∈ 𝒟_T`:
`𝔞^{(v)}_T(F) = C_0‖F‖² + 𝔈(c_F) − Σ_{n∈N_T} v_n c_F(log n)`, `𝔈(Φ) = ∫_0^∞(Φ(0) − Φ(u))K(u)du ≥ 0`. The true comb is
`v^0 := v_T(Λ)`, `v^0_n = 2Λ(n)/√n` (zero at non-prime-powers).

**D2 (contact map).** `κ_T: 𝒟_T → ℝ^{N_T}`, `κ_T(F) := (c_F(log n))_{n∈N_T}`. For `F` unit, `|κ_T(F)|_∞ ≤ 1`. In
operator terms `c_F(log n) = ⟨F, T_n F⟩` with `T_n := ½(S_{log n} + S_{−log n})` compressed to `L²(I_T)` (`S_u` = translation),
bounded self-adjoint, `‖T_n‖ ≤ 1`; for `d ∈ ℝ^{N_T}` put `B_d := −Σ_n d_n T_n`, `‖B_d‖ ≤ |d|_1`.

**D3 (bottom function, container, optimal combs).** `V_T(v) := inf{𝔞^{(v)}_T(F): F ∈ P_T ∩ 𝒟_T, ‖F‖ = 1}` (`lem:degen`);
`V_T(v^0) = λ^A_T`. `𝒱_T := {v: V_T(v) ≥ 0}` (`prop:finite`). `V*_T := sup V_T`, `𝒪_T := {v: V_T(v) = V*_T}`.
`M_T(v)` := the set of real unit minimisers of `𝔞^{(v)}_T` on `P_T` (nonempty: `thm:O`'s proof), `M_T := M_T(v^0)`.

**D4 (relaxed problem).** `𝒦^prim_T` := the feasible set of def:PD (P) read as functions `Φ = μ̌`: even continuous
positive-definite `Φ` with `Φ(0) = 1`, `supp Φ ⊂ [−2T, 2T]`, `∫Φ cosh(u/2) = ∫Φ u sinh(u/2) = 0` (P47 eq:Kprim;
`prop:weak` identifies it with the (P)-feasible set via Boas–Kac). It is **convex** (the constraints are linear in `μ`).
`V^prim_T(v) := inf_{Φ∈𝒦^prim_T}[C_0 + 𝔈(Φ) − Σ_n v_nΦ(log n)] = λ^prim_T(v)` (def:PD (P), `thm:A`). Since
`{c_F: F ∈ P_T unit} ⊂ 𝒦^prim_T` (`thm:A`), `V^prim_T ≤ V_T`. `𝒱^prim_T := {V^prim_T ≥ 0} ⊂ 𝒱_T`, `𝒪^prim_T := argmax V^prim_T`.

**D5 (prime-blind bottoms).** A test is *prime-blind at `T`* if `κ_T(F) = 0` (resp. `Φ(log n) = 0 ∀ n ∈ N_T`). Put
`Z^A_T := inf{C_0 + 𝔈(c_F): F ∈ P_T ∩ 𝒟_T real unit, κ_T(F) = 0}` and
`Z^prim_T := inf{C_0 + 𝔈(Φ): Φ ∈ 𝒦^prim_T, Φ(log n) = 0 ∀ n ∈ N_T}`. Both feasible sets are nonempty (any primitive `F`
supported in an interval of length `< log 2` inside `I_T` is prime-blind at every `T`), and `Z^prim_T ≤ Z^A_T`.
**Neither number involves any value `Λ(n)`**: they depend on `m` (i.e. `C_0`, `K`) and on the set `{log n: n ∈ N_T}`.

**D6 (contact marginal).** `g_T: ℝ^{N_T} → (−∞, +∞]`, `g_T(x) := inf{C_0 + 𝔈(Φ): Φ ∈ 𝒦^prim_T, κ_T(Φ) = x}`
(`κ_T(Φ) := (Φ(log n))_n`), `+∞` if no such `Φ`. So `Z^prim_T = g_T(0)` and `V^prim_T(v) = inf_x[g_T(x) − ⟨v, x⟩] = −g_T^*(v)`.

## §2 The contact cone; compactness of the container

**Lemma 2.1 (contact cone; PROVED).** Let `d ∈ ℝ^{N_T}`, `d ≠ 0`. There is `F ∈ 𝒫_T` with `⟨d, κ_T(F)⟩ > 0`.

*Proof.* Put `𝒩 := {1} ∪ N_T` and fix a real `φ ∈ C_c^∞([0, ℓ))`, `φ ≠ 0`, with `ℓ > 0` to be chosen. For
`a ∈ ℝ^{𝒩}`, offsets `s_1, s_2, s_3 ∈ [−T, −T + δ_T − ℓ)` and `t ∈ ℝ³` put
```
F := Σ_{i=1}^3 t_i Σ_{k∈𝒩} a_k φ(· − s_i − log k).
```
Every bump `[s_i + log k, s_i + log k + ℓ)` lies in `I_T` because `log k ≤ 2T − δ_T`. Compute `c_F(log n)`, `n ∈ N_T`:
by bilinearity it is a sum over pairs of bumps, and the pair `(i, j; i′, k)` contributes
`t_i t_{i′} a_j a_k ∫φ(x)φ(x + log j − log n − log k + s_i − s_{i′})dx = t_it_{i′}a_ja_k c_φ(s_{i′} − s_i + log(nk/j))`,
which vanishes unless `|s_{i′} − s_i + log(nk/j)| < ℓ`.
*Within a copy* (`i = i′`): the finite set `Λ_T := {|log(nk/j)|: n ∈ N_T, j, k ∈ 𝒩, nk ≠ j}` has a positive minimum
`ℓ_T`; choose `ℓ < ℓ_T`. Then only `j = nk` survives and the copy contributes `t_i² ‖φ‖² Σ_{k: k, nk ∈ 𝒩} a_k a_{nk}`.
*Across copies* (`i ≠ i′`): the forbidden set for `s_{i′} − s_i` is the finite union `⋃_{n,j,k}(−log(nk/j) − ℓ, −log(nk/j) + ℓ)`,
of measure `≤ 2ℓ·|N_T||𝒩|²`; choosing `ℓ` small enough there are `s_1, s_2, s_3` in the allowed interval with all three
pairwise differences outside it. Then cross-copy terms vanish at every `log n`, and
```
⟨d, κ_T(F)⟩ = ‖φ‖² (Σ_i t_i²) · q_d(a),   q_d(a) := Σ_{n∈N_T} d_n Σ_{k∈𝒩: nk∈𝒩} a_k a_{nk}.
```
`q_d` is the quadratic form of the symmetric matrix `Q_d` on `ℝ^{𝒩}` with `(Q_d)_{k,nk} = (Q_d)_{nk,k} = d_n/2` (the pair
`(k, nk)` determines `n = nk/k`, so entries do not collide) and all other entries `0`. Its diagonal vanishes (`nk ≠ k`),
so `tr Q_d = 0`; and `Q_d ≠ 0` since `d_n ≠ 0` for some `n` and `(1, n)` is an admissible pair. A nonzero symmetric matrix
of trace zero has a positive eigenvalue: pick `a` with `q_d(a) > 0`.
*Primitivity.* `A(φ(· − s)) = e^{s/2}A(φ)`, `B(φ(· − s)) = e^{−s/2}B(φ)`, so
`A(F) = A(φ)(Σ_k a_k√k)·Σ_i t_i e^{s_i/2}` and `B(F) = B(φ)(Σ_k a_k/√k)·Σ_i t_i e^{−s_i/2}`: two homogeneous linear
conditions on `t ∈ ℝ³`, which have a nonzero solution. For it, `⟨d, κ_T(F)⟩ > 0`, so `F ≠ 0`; `F ∈ P_T ∩ C_c^∞(I_T)` is real;
normalise. ∎

**Corollary 2.2 (the contact image surrounds the origin; PROVED).** `conv κ_T(𝒫_T)` contains `0` in its interior;
`cone(κ_T(𝒫_T)) = ℝ^{N_T}`; the same holds for `κ_T(𝒦^prim_T) ⊇ κ_T(𝒫_T)`.

*Proof.* By Lemma 2.1 applied to `±e_n` there are `F_n^± ∈ 𝒫_T` with `κ_T(F_n^±) = ±t_n^± e_n + (rest)`, more precisely
`⟨±e_n, κ_T(F_n^±)⟩ > 0`. A compact convex set meeting every open half-space `{⟨d, ·⟩ > 0}`, `d ≠ 0`, contains `0` in its
interior (else a supporting hyperplane at `0`, or separating `0` from the set, gives a `d` with `⟨d, ·⟩ ≤ 0` on the set).
Here `conv κ_T(𝒫_T)` is bounded (`|κ_T| ≤ 1`) and its closure meets every such half-space; a bounded convex set whose
closure contains `0` in its interior itself contains `0` in its interior (Rockafellar Thm 6.3). ∎

**Theorem 2.3 (coercivity; the container is compact; PROVED).** There are `c_T > 0`, `C_T < ∞` with
`V_T(v) ≤ C_T − c_T|v|_2` for all `v ∈ ℝ^{N_T}`. Consequently: `𝒱_T` is compact; every superlevel set `{V_T ≥ c}` is compact;
`V*_T < ∞` and `𝒪_T` is nonempty, compact and convex. The same holds for `V^prim_T`, `𝒱^prim_T`, `𝒪^prim_T`.

*Proof.* For each unit `d` pick `F_d ∈ 𝒫_T` with `⟨d, κ_T(F_d)⟩ > 0` (Lemma 2.1). The condition is open in `d`, so by
compactness of the sphere finitely many `F_1, …, F_m` satisfy `max_j ⟨d, κ_T(F_j)⟩ ≥ 2c_T > 0` for every unit `d`. For
`v ≠ 0`, `V_T(v) ≤ min_j[C_0 + 𝔈(c_{F_j}) − ⟨v, κ_T(F_j)⟩] ≤ max_j(C_0 + 𝔈(c_{F_j})) − |v|_2·max_j⟨v/|v|_2, κ_T(F_j)⟩ ≤ C_T − 2c_T|v|_2`
(`𝔈(c_{F_j}) < ∞` since `F_j ∈ C_c^∞`). `V_T` is finite, concave and continuous (`lem:degen`; G2_B8_R1 Thm B), so its
superlevel sets are closed, convex and, by coercivity, bounded. A continuous function with compact nonempty
superlevel sets attains its supremum. `V^prim_T ≤ V_T` is concave (an infimum of affine functions) and finite
(`≥ C_0 − |v|_1`), so the same argument applies. ∎

**Proposition 2.4 (monotonicity in `T`; PROVED).** Let `T < T′` and `π = π^{T′}_T: ℝ^{N_{T′}} → ℝ^{N_T}` the restriction.
(i) `V_{T′}(v′) ≤ V_T(πv′)` for all `v′`; hence `π(𝒱_{T′}) ⊂ 𝒱_T`, `π(𝒱^prim_{T′}) ⊂ 𝒱^prim_T`, and within one regime
(`N_T = N_{T′}`) `𝒱_{T′} ⊂ 𝒱_T`. (ii) `V*_T`, `Z^A_T`, `Z^prim_T` are nonincreasing in `T`.

*Proof.* Extend `F ∈ P_T` by zero: `c_F` vanishes on `|u| ≥ 2T`, so the contacts of `N_{T′}∖N_T` contribute `0` and
`𝔞^{(v′)}_{T′}(F) = 𝔞^{(πv′)}_T(F)` (the computation of `lem:monoT`). Taking the infimum over the smaller class gives (i).
For (ii): `V*_{T′} = V_{T′}(v′) ≤ V_T(πv′) ≤ V*_T`; a prime-blind test at `T` is prime-blind at `T′` with the same value. ∎

## §3 The derivative of the bottom and the first-order criterion

**Lemma 3.1 (Danskin–Kato formula; PROVED).** Fix `v`. Let `𝐀_v` be the self-adjoint operator on `P_T` associated with
the closed semibounded form `𝔞^{(v)}_T` (Kato's representation theorem; the form is bounded below by `C_0 − |v|_1`).
Then `𝐀_v` has compact resolvent; `λ_0 := V_T(v)` is its lowest eigenvalue, of finite multiplicity, with eigenspace
`E_0` and spectral gap `g := λ_1 − λ_0 > 0`; `M_T(v)` is the unit sphere of `E_0`. For every `d ∈ ℝ^{N_T}` and
`0 < t ≤ g/(2(|d|_1 + ‖B_d‖))`:
```
λ_0 + t β_min(d) − 2t²|d|_1²/g ≤ V_T(v + td) ≤ λ_0 + t β_min(d),   β_min(d) := min_{F∈M_T(v)} ⟨F, B_d F⟩ = −max_{F∈M_T(v)} ⟨d, κ_T(F)⟩.
```
Hence `V_T′(v; d) := lim_{t↓0}(V_T(v+td) − V_T(v))/t = −max_{F∈M_T(v)}⟨d, κ_T(F)⟩`, and the superdifferential of the
concave function `V_T` at `v` is `∂V_T(v) = −conv κ_T(M_T(v))`.

*Proof.* Compact resolvent: the sublevel sets of `𝔞^{(v)}_T` on the unit sphere of `P_T` are compact (proof of `thm:O`,
main.tex:673–678, valid for every weight vector), which is equivalent to the compactness of the embedding of the form
domain (form norm) into `L²`; so the spectrum is discrete with finite multiplicities and `λ_0 = min spec` is attained on
`E_0`. `𝔞^{(v+td)}_T = 𝔞^{(v)}_T + t⟨·, B_d ·⟩` with `B_d` bounded (D2). Upper bound: test on `F ∈ M_T(v)`. Lower bound: for a
unit `G` in the form domain write `G = F + H`, `F = P_{E_0}G`, `H ⊥ E_0`; then `𝔞^{(v)}_T(G) = 𝔞^{(v)}_T(F) + 𝔞^{(v)}_T(H) ≥ λ_0‖F‖² + λ_1‖H‖²`
(`E_0` reduces `𝐀_v`), and `t⟨G, B_dG⟩ ≥ t⟨F, B_dF⟩ − 2t‖B_d‖‖F‖‖H‖ − t‖B_d‖‖H‖² ≥ tβ_min‖F‖² − 2t‖B_d‖‖H‖ − t‖B_d‖‖H‖²`
(`F/‖F‖ ∈ M_T(v)` when `F ≠ 0`). With `‖F‖² = 1 − ‖H‖²` and `x := ‖H‖`,
`𝔞^{(v+td)}_T(G) ≥ λ_0 + tβ_min + [λ_1 − λ_0 − t(β_min + ‖B_d‖)]x² − 2t‖B_d‖x ≥ λ_0 + tβ_min + (g/2)x² − 2t‖B_d‖x ≥ λ_0 + tβ_min − 2t²‖B_d‖²/g`
for `t` in the stated range (`|β_min| ≤ ‖B_d‖ ≤ |d|_1`). Taking the infimum over `G` gives the display. The derivative
formula follows; `d ↦ −max_{M_T(v)}⟨d, κ_T⟩ = min{⟨d, s⟩: s ∈ −conv κ_T(M_T(v))}` is the support function (in the concave
convention) of the compact convex set `−conv κ_T(M_T(v))` (`M_T(v)` compact, `κ_T` continuous), and a finite concave
function on `ℝ^N` has `V′(v; d) = min_{s∈∂V(v)}⟨s, d⟩` with `∂V(v)` the unique compact convex set with this support
function (Rockafellar Thm 23.2, 23.4). ∎

**Theorem 3.2 (first-order criterion for the optimal comb; PROVED).** `v ∈ 𝒪_T` if and only if `0 ∈ conv κ_T(M_T(v))`,
i.e. iff some convex combination of ground-state contact vectors vanishes. In particular:
(a) if the bottom at `v` is simple (`dim E_0 = 1`, ground state `F*` unique up to sign), `v ∈ 𝒪_T ⟺ κ_T(F*) = 0`, i.e. iff
the ground state is prime-blind;
(b) for `v = v^0 = v_T(Λ)`: **the comb of ζ is optimal at window `T` iff `0 ∈ conv κ_T(M_T)`**; the sufficient condition
of `lem:degen` (some minimiser with `κ_T(F*) = 0`) is also necessary whenever the bottom `λ^A_T` is simple;
(c) at every `v ∈ 𝒪_T` with a simple bottom, `V*_T = C_0 + 𝔈(c_{F*})` with `F*` prime-blind, so `V*_T ≥ Z^A_T`.

*Proof.* A concave function on `ℝ^N` is globally maximised at `v` iff `0 ∈ ∂V(v)` (Rockafellar Thm 27.1), and
`∂V_T(v) = −conv κ_T(M_T(v))` (Lemma 3.1). Directly: if `0 ∉ conv κ_T(M_T(v))`, separate: some `d` has `⟨d, c⟩ < 0` on
the compact convex set, so `V_T′(v; d) > 0` and `v` is not a maximiser; if `0 ∈ conv κ_T(M_T(v))` then
`max_{M_T(v)}⟨d, κ_T⟩ ≥ 0` for every `d`, so `V_T′(v; d) ≤ 0`, and by concavity `V_T(v + d) ≤ V_T(v) + V_T′(v; d) ≤ V_T(v)`.
(a): `M_T(v) = {±F*}` and `κ_T(−F*) = κ_T(F*)`. (b), (c): specialisations. ∎

**Corollary 3.3 (the true comb's derivative in its own direction; PROVED).** `V_T′(v^0; v^0) = min_{F∈M_T}[λ^A_T − 𝔞^{(0)}_T(F)]`
and `V_T′(v^0; −v^0) = max_{F∈M_T}[𝔞^{(0)}_T(F) − λ^A_T]`, where `𝔞^{(0)}_T(F) = C_0 + 𝔈(c_F)` is the prime-free value of the
ground state. Thus scaling the comb up raises the bottom (to first order) iff every ground state has prime-free value
below `λ^A_T`; in the degenerate case both derivatives vanish.

*Proof.* `⟨v^0, κ_T(F)⟩ = 𝔞^{(0)}_T(F) − 𝔞_T(F) = 𝔞^{(0)}_T(F) − λ^A_T` for `F ∈ M_T`; insert in Lemma 3.1. ∎

## §4 The value of the maximum: strong duality and the prime-blind bottom

**Theorem 4.1 (strong duality; the optimal relaxed comb is a Lagrange multiplier; PROVED).**
`max_v V^prim_T(v) = Z^prim_T = g_T(0)`, the maximum is attained, and `𝒪^prim_T = ∂g_T(0)` (subdifferential of the convex
function `g_T` at `0`), a nonempty compact convex set.

*Proof.* (1) `g_T` is convex: for `x, x′ ∈ dom g_T`, `θ ∈ (0,1)`, `ε > 0`, pick `Φ, Φ′ ∈ 𝒦^prim_T` with `κ_T(Φ) = x`,
`κ_T(Φ′) = x′` and values within `ε` of `g_T(x), g_T(x′)`; then `θΦ + (1−θ)Φ′ ∈ 𝒦^prim_T` (convex), `κ_T` and `𝔈` are
linear, so `g_T(θx + (1−θ)x′) ≤ θg_T(x) + (1−θ)g_T(x′) + ε`. `g_T ≥ C_0 > −∞` since `𝔈 ≥ 0`; `g_T ≢ +∞`. So `g_T` is a proper
convex function. (2) `0 ∈ int dom g_T`: `dom g_T = κ_T(𝒦^prim_T) ⊇ κ_T(𝒫_T)` (`thm:A`: primitive pure autocorrelations lie in
`𝒦^prim_T`, with `𝔈 < ∞` for `C_c^∞` tests), and `dom g_T` is convex, so it contains `conv κ_T(𝒫_T)`, which contains `0` in
its interior (Corollary 2.2). (3) `V^prim_T(v) = inf_Φ[C_0 + 𝔈(Φ) − ⟨v, κ_T(Φ)⟩] = inf_x[g_T(x) − ⟨v, x⟩] = −g_T^*(v)`. Hence
`sup_v V^prim_T(v) = −inf_v g_T^*(v) = g_T^{**}(0)`. A proper convex function on `ℝ^N` is continuous on the interior of its
domain (Rockafellar Thm 10.1), so `g_T` is lower semicontinuous at `0`, and `g_T^{**} = cl g_T` (Thm 12.2) agrees with `g_T`
at `0` (Thm 7.4: `cl g_T = g_T` on `int dom g_T`). So `sup_v V^prim_T = g_T(0) = Z^prim_T`. (4) Attainment and the
multiplier description: `v` maximises `⟨v, 0⟩ − g_T^*(v)` iff `v ∈ ∂g_T(0)` (Thm 23.5), and `∂g_T(0) ≠ ∅`, compact, convex
because `0 ∈ int dom g_T` (Thm 23.4). ∎

**Reading.** `Z^prim_T` is the value of the constrained problem "minimise the prime-free energy `C_0 + 𝔈(Φ)` over the
relaxed primitive class subject to the `|N_T|` linear constraints `Φ(log n) = 0`"; `v` is the multiplier vector of
these constraints; `V^prim_T(v)` is the Lagrangian dual function; Theorem 4.1 is zero duality gap plus dual
attainment. **The best possible comb at window `T` is the Lagrange multiplier of a problem in which the primes enter
only through their positions.**

**Theorem 4.2 (sandwich; PROVED).** `Z^prim_T ≤ V*_T ≤ Z^A_T`. Moreover:
(i) if the degenerate case of `lem:degen` occurs at `T` (some `F* ∈ M_T` with `κ_T(F*) = 0`), then `λ^A_T = V*_T = Z^A_T`;
(ii) if `v ∈ 𝒪_T` has a simple bottom then `V*_T = Z^A_T` (so then `Z^A_T = V*_T ≥ Z^prim_T`, and the pure and relaxed optimal
values coincide iff `Z^A_T = Z^prim_T`).

*Proof.* `V^prim_T ≤ V_T` gives `Z^prim_T = max V^prim_T ≤ max V_T = V*_T`. For any `v` and any prime-blind `F`,
`V_T(v) ≤ 𝔞^{(v)}_T(F) = C_0 + 𝔈(c_F)`; take the infimum over `F` and the supremum over `v`: `V*_T ≤ Z^A_T`. (i) By `lem:degen`
`v^0 ∈ 𝒪_T`, so `λ^A_T = V*_T ≤ Z^A_T ≤ C_0 + 𝔈(c_{F*}) = 𝔞_T(F*) = λ^A_T`. (ii) Theorem 3.2(c) with `V*_T ≤ Z^A_T`. ∎

**Theorem 4.3 (prime-blind necessary condition; PROVED).**
(a) `𝒱_T ≠ ∅ ⟺ V*_T ≥ 0`; `𝒱^prim_T ≠ ∅ ⟺ Z^prim_T ≥ 0`. (b) `Z^A_T < 0 ⟹ 𝒱_T = ∅ ⟹ RD_T fails ⟹ ¬RH`; explicitly, a real

(c) Under RH: `Z^A_T ≥ V*_T ≥ λ^A_T > 0` and `Z^prim_T ≥ λ^prim_T ≥ λ^W_T > 0` for every `T`. (d) Unconditionally:

*Proof.* (a) `𝒱_T ≠ ∅ ⟺ ∃v: V_T(v) ≥ 0 ⟺ V*_T ≥ 0` (max attained, Thm 2.3); same for the relaxed container with Thm 4.1.

`𝔞^{(v)}_T(F) = C_0 + 𝔈(c_F) = (1/2π)∫m|F̂|²` for every `v`. (c) `V*_T ≥ V_T(v^0) = λ^A_T ≥ λ^W_T > 0` under RH (O4 of

(d) as (c) with the cited windows. (e) D5, and `V*_T = max` of a function defined by `m` and the contact positions. ∎

## §5 Faces of `𝒱_T` and the position of the true comb as `T` grows

**Theorem 5.1 (Lipschitz, interior, inradius; PROVED).**
(a) `|V_T(v) − V_T(v′)| ≤ |v − v′|_1`. Hence, whenever `λ^A_T > 0`, the `ℓ¹`-ball `{v: |v − v^0|_1 < λ^A_T}` lies in `𝒱_T`, and
`v^0` is an interior point of `𝒱_T`. Under RH this holds at every `T`: **the true comb touches no face of `𝒱_T`, ever.**
(b) The `ℓ¹`-inradius `r_1(v^0) := sup{r: B_1(v^0, r) ⊂ 𝒱_T}` satisfies `λ^A_T ≤ r_1(v^0) ≤ λ^A_T / ‖κ_T‖_{M_T,∞}`, where
`‖κ_T‖_{M_T,∞} := max_{F∈M_T} max_n |c_F(log n)|` (right side `+∞` iff every ground state is prime-blind). Under RH both
bounds tend to `0` doubly exponentially (Theorem M).
(c) If `λ^A_T < 0` (which happens for all large `T` under ¬RH, `prop:uniform` + `lem:monoT`), then `dist_1(v^0, 𝒱_T) ≥ −λ^A_T`.

*Proof.* (a) Each affine function `v ↦ C_0 + 𝔈(c_F) − ⟨v, κ_T(F)⟩` is `1`-Lipschitz in `|·|_1` (`|κ_T(F)|_∞ ≤ 1`), and an
infimum of `1`-Lipschitz functions is `1`-Lipschitz; `V_T(v) ≥ V_T(v^0) − |v − v^0|_1 > 0` on the ball. (b) Lower bound: (a).
Upper bound: `lem:degen`'s inequality with `v = v^0 + s·sgn(c_{F}(log n_0))e_{n_0}` for `F ∈ M_T` gives
`V_T(v) ≤ λ^A_T − s|c_F(log n_0)|`, which is `≤ 0` at `s = λ^A_T/|c_F(log n_0)|`; so a point at `ℓ¹`-distance
`λ^A_T/|c_F(log n_0)|` is not in the interior of `𝒱_T`. (This is `rem:resweights` read as geometry.) (c) `V_T ≥ 0` on `𝒱_T`
and `V_T(v^0) = λ^A_T < 0`, so (a) forces `|v − v^0|_1 ≥ −λ^A_T` for `v ∈ 𝒱_T`. ∎

**Theorem 5.2 (faces are indexed by ground states; PROVED).** Assume `V*_T > 0` (true for `T ≤ log 2`; under RH for all
`T`). Let `v ∈ ∂𝒱_T`, i.e. `V_T(v) = 0`. Then the normal cone of `𝒱_T` at `v` is
`N_{𝒱_T}(v) = cone(conv κ_T(M_T(v))) = {Σ_i θ_i κ_T(F_i): θ_i ≥ 0, F_i ∈ M_T(v)}`,
and the exposed face of `𝒱_T` in the direction `−κ_T(F)`, `F ∈ M_T(v)`, contains `v`. Thus every face of `𝒱_T` is cut out by
the ground states of the forms on its boundary; the direction in which the container is thin at `v` is the direction
of the contact vectors of the ground states at `v`.

*Proof.* `𝒱_T = {V_T ≥ 0}` is the superlevel set of a concave function with a Slater point (`V*_T > 0`). For such sets
`N_{𝒱_T}(v) = ℝ_{≥0}·(−∂V_T(v))` at boundary points (Rockafellar Cor 23.7.1 applied to the convex function `−V_T`), and
`−∂V_T(v) = conv κ_T(M_T(v))` (Lemma 3.1). The exposed-face statement is the definition of the normal cone. ∎

**Theorem 5.3 (the tower and the regimes; PROVED).** (a) The family `(𝒱_T)_T` with the restrictions `π^{T′}_T` is a
projective system of compact convex sets: `π^{T′}_T(𝒱_{T′}) ⊂ 𝒱_T`, `π^{T″}_T = π^{T′}_T ∘ π^{T″}_{T′}`. (b) The true comb lies in the
coordinate subspace `S_T := {v: v_n = 0 for n not a prime power}` at every `T`. (c) At a regime boundary `T = ½log n_{k+1}`
a coordinate is added; the true comb enters it at `2Λ(n_{k+1})/√n_{k+1}`, which is `0` when `n_{k+1}` is composite.
(d) `RH ⟺ ∀T: v_T(Λ) ∈ ∩_{T′≥T} π^{T′}_T(𝒱_{T′})` — this is E4 (`prop:uniform`), **EQUIV**, recorded only to fix the frame.
(e) Under RH, `π^{T′}_T(𝒱_{T′}) ⊃ B_1(v_T(Λ), λ^A_{T′})`, so the projected containers shrink onto a set containing `v_T(Λ)` no
faster than the margin allows, and under Theorem M the guaranteed ball shrinks doubly exponentially in `T′`.

*Proof.* (a) Prop 2.4 and compactness (Thm 2.3). (b), (c) definition of `v_T(Λ)`. (d) `prop:uniform` with (a). (e) Thm 5.1(a)
at `T′` and `π^{T′}_T(B_1(v_{T′}(Λ), r)) ⊃ B_1(v_T(Λ), r)` (drop coordinates). ∎

## §6 An audacious shape, and why it is not a mechanism

**Proposition 6.1 (the optimal-comb tower; PROVED as an implication).** Suppose
(i) `Z^prim_T ≥ 0` for every `T` (prime-blind positivity, Remark 4.4);
(ii) there is a selection `T ↦ v*_T ∈ 𝒪^prim_T` and a comb `a* = (a*_n)_{n≥2}` with `v*_{T,n} → 2a*_n/√n` for every `n`;
(iii) `b := a* − Λ ∈ 𝒯`, i.e. `Σ_n b_n n^{−1/2}(δ_{log n} + δ_{−log n})` is a tempered distribution (G2_B9_R3 §3).
Then RH. If moreover `b ∈ 𝒯_meas`, then `a* = Λ`.

*Proof.* By (i), Theorem 4.3(a) and Theorem 4.1, `v*_{T′} ∈ 𝒱^prim_{T′} ⊂ 𝒱_{T′}`; by Prop 2.4, `π^{T′}_T(v*_{T′}) ∈ 𝒱_T` for
every `T ≤ T′`; `𝒱_T` is closed and `π^{T′}_T(v*_{T′}) → v_T(a*)` coordinatewise as `T′ → ∞` (ii), so `v_T(a*) ∈ 𝒱_T`, i.e.
`λ^A_T(a*) ≥ 0` for all `T`. With (iii), G2_B9_R3 Theorem N(i) gives RH; Theorem N(ii) gives `a* = Λ` when `b ∈ 𝒯_meas`. ∎

**Why this is a shape and not a mechanism.** (i) is prime-blind and is *not* RH-strength on its face (H1), but it is
unproved for `T > log 2`. (ii) is a compactness statement about multipliers of a problem whose constraint count `|N_T|`
grows like `e^{2T}`; no a-priori bound on `|v*_T|` is available beyond Theorem 2.3's window-dependent `C_T/c_T`. (iii) is
where the whole of the arithmetic sits: `Λ ∉ 𝒯` itself (its comb has mass `Σ_{n≤X}Λ(n)/√n ≍ √X`, exponential in `u = log X`),
so (iii) demands that the prime-blind multipliers reproduce `Λ` to within a log-polynomially small comb — that is a
statement of the strength of `ψ(x) − x ≪ x^{½+ε}` (P46 §28.2, brief §1.16), i.e. RH. The proposition therefore relocates
the sign into (iii) without weakening it; its only value is that (i) and (ii) are new, prime-blind sub-problems whose
solution would isolate (iii) as *the* arithmetic step. Target EQUIV-shaped (Thm N(iii)); flagged per R-1.

**H1 (heuristic on the size of `Z^prim_T`; HEURISTIC, no numerics).** A prime-blind test must have `c_F` vanishing at all
`log n`, `n < e^{2T}`; near the top of the window these points have spacing `≍ e^{−2T}`. If `|F̂|²` carried its mass at
frequencies `|τ| ≤ Ω`, then `|c_F′| ≤ Ω`, so `|c_F| ≤ Ω e^{−u}` on `[log 2, 2T]` between consecutive contacts; vanishing at
dense contacts with a slowly varying `c_F` forces `c_F ≈ 0` on `[log Ω, 2T]`, and then `𝔈(c_F) ≥ ∫_{log Ω}^∞ K + …`, which is
`≈ 1.5` for `Ω ≈ 7` — not enough against `−C_0 = 5.37` by crude bounds, but the low-frequency prime-blind tests are exactly
those supported in one gap of length `≤ log 2`, where the primitive archimedean form is positive (`T*_{∞,P} ≥ 0.58 > ½log 2`).
Tests that resolve the top-of-window contacts must carry frequencies `≍ e^{2T}`, where `m ≍ 2T`. The two regimes are
coupled by the primitivity constraint (a low-frequency negative piece at the left edge cannot be made `B`-primitive by
a small right-edge piece: the correction costs `≍ e^{T}` in norm and `≍ 2T` per unit mass). A prime-blind "generic
lattice" test `F = Σ_k w_k e^{−iγ_0 s_k}φ(· − s_k)` aimed at an off-line zero `β_0 + iγ_0` has, by the explicit formula
without prime terms, off-line contribution `≍ M^{3/2}e^{(β_0−½)L}` (one coherent, one incoherent factor) against an
on-line noise floor `≍ M L e^{L}` with `M ≤ L e^{L}` bumps, ratio `≤ L^{−1/2}e^{(β_0−1)L} → 0`: such tests do not detect an
off-line zero. Expectation: `Z^prim_T > 0` for all `T`, strictly weaker than RH, and not doubly exponentially small — which
by Theorem 4.5 would make the true comb non-optimal at every large window and settle O3's non-degeneracy there.
None of this is proved.

## §7 Open steps (exact statements)

1. **(PBP_T) Prime-blind positivity.** Prove `Z^prim_T ≥ 0` (or `V*_T ≥ 0`, or `Z^A_T ≥ 0`) for every `T > log 2`. Equivalent
   (Thm 4.3) to `𝒱^prim_T ≠ ∅` (resp. `𝒱_T ≠ ∅`). Implied by RH; expected strictly weaker (H1). Unknown for every `T > log 2`
   in the pure form and for every `T > 0.8` in the relaxed form. What it would take: a lower bound for
   `(1/2π)∫m|F̂|²` over primitive `F` with `c_F(log n) = 0`, `n < e^{2T}`, i.e. a joint use of the primitivity constraint and
   the quadratic contact constraints; the archimedean thresholds (`thm:index`) are the `|N_T| ≤ 2` case.
2. **Size of the prime-blind bottom.** Prove `Z^prim_T ≥ z(T)` with `z(T) > exp(−e^{(2−ε)T})` for large `T` (e.g. `z(T) ≥ c/T`).
   By Theorem 4.5 this gives `v_T(Λ) ∉ 𝒪_T` for all large `T` and, where `λ^A_T` is simple, O3's non-degeneracy. Nothing
   below `+∞` and above `λ^prim_T` is known about `Z^prim_T` for `T > 0.8`.
3. **Simplicity of the bottom.** Is `λ^A_T` a simple eigenvalue of `𝐀_{v^0}` on `P_T`? Even/odd parity splits `P_T` (P47
   §parity), so simplicity is at best within a parity; Theorem 3.2(b) needs `0 ∈ conv κ_T(M_T)` in general. OPEN.
4. **Support of the optimal comb.** Does `𝒪_T` (or `𝒪^prim_T = ∂g_T(0)`) meet the prime-power subspace `S_T`? If not at some
   `T`, then `v_T(Λ) ∉ 𝒪_T` there for a `Λ`-blind reason (Remark 5.4). OPEN.
5. **Optimality at small `T`.** For `T ∈ (½log 2, log 2]`, decide `0 ∈ conv κ_T(M_T)` from the ground state(s) of `𝔞_T` on
   `P_T`. A finite computation (one or two contacts), uncertified unless interval-arithmetic; not performed.
6. **Compactness of multipliers (Prop 6.1 (ii)).** A bound `sup_T |v*_T|_∞ < ∞` for some selection `v*_T ∈ 𝒪^prim_T`, or a
   proof that none exists. OPEN; Theorem 2.3's constants `C_T/c_T` are window-dependent.
7. **The arithmetic step (Prop 6.1 (iii)).** Whether any prime-blind construction can produce a comb in `Λ + 𝒯`. This is
   the sign; recorded as the exact location of the wall on this route.

**Summary for the panel.** Everything from the definitions to Theorem 5.3 is proved; no statement is a sign. The route
question "can `V_T(v_T(Λ)) = max V_T` hold?" is answered structurally (Theorem 3.2: iff a convex combination of
ground-state contact vectors vanishes) and conditionally at large `T` (Theorem 4.5: not unless the prime-blind bottom
is doubly exponentially small). The route question "which faces does the true comb touch?" is answered: under RH none,
at any `T` (Theorem 5.1), the faces being indexed by ground-state contact vectors (Theorem 5.2), with the guaranteed
`ℓ¹`-ball around the comb shrinking doubly exponentially. The new object is the prime-blind bottom `Z^prim_T` and the
identification of the optimal comb as its Lagrange multiplier (Theorem 4.1). Claim level: PARTIAL_NEW.
