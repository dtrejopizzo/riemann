## §1 Definitions

**1.1 Borger's square** (CITED, R1 §1.1–1.3). `W^*(Spec Z) = Spec W(Z)`, `gh_n : W(Z) → Z` the ghost components,
`Γ_n := Spec Z ↪ Spec W(Z)` via `gh_n`, `Γ_n = (F_n)_*Γ_1`, `F_kΓ_n = Γ_{kn}`. Structure map `π : Spec W(Z) → Spec Z`
(from `Z → W(Z)`); every `Γ_n` is a section of `π`. Vertical fibres `Φ_p = Spec W(Z)/p`, `Γ_n·Φ_p = log p` (R2 §1.2).

**1.2 The Witt row and the two pairings of record.** Scheme-theoretic lengths (R1 Thm B): for `m ≠ n`,

(P46 Def 22.1, un-normalised bidegree `(n,1)`): `L(m,n) := min(m,n)·Λ(max/min)`, `= min·log p` if `max/min = p^k`,
else `0`; `L(n,n) := δ_n` a free counterterm.

**1.3 The Witt–Rosati form** (R1 Thm A). On `ℓ²(N, 1/m)` the unique form with `F_n^† = V_n`; on its hull
`H_W = L²((0,∞), x^{−2}dx)`, `⟨F_qg, F_qh⟩ = q⟨g,h⟩`: conformal factor `q`. In unitary coordinates
`G(u) = e^{−u/2}g(e^u)` the flow is translation.

**1.4 The Weil form** (P47 main.tex:115–147, quoted in brief §1.1–1.4). `K(u) = ½/sinh(u/2) + ½/cosh(u/2)
= 2e^{3u/2}/(e^{2u}−1) = 2Σ_{k≥0}e^{−(2k+½)u}` (`lem:K`, main.tex:363); `m(τ) = C_0 + ∫_0^∞(1−cos τu)K(u)du`;

## §2 Theorem A: the archimedean place is a Frobenius fixed point of Λ-geometry

**Theorem A** (PROVED).
(i) The only ring endomorphism of `R` is the identity. Hence `R` carries exactly one Λ-ring structure, `ψ_n = id`
for all `n`.
(ii) The continuous ring endomorphisms of `C` are `id` and complex conjugation `c`. Hence the continuous Λ-ring
structures on `C` are exactly `ψ_n = c^{ε(n)}` with `ε : N → Z/2` completely multiplicative (`ε(mn) = ε(m)+ε(n)`),
i.e. one structure for each set `P_c` of primes (`ψ_p = c` for `p ∈ P_c`). The trivial one is `P_c = ∅`; `P_c` = all
primes gives `ψ_n = c^{Ω(n)}`, the Liouville-twisted structure.
(iii) Let `X` be a Λ-scheme with Frobenii `ψ_n`. Every Λ-morphism `x : Spec R → X` has image in the joint fixed
locus `{ψ_n = id ∀n}`; the same holds for `Spec C` with its trivial structure, and for the Liouville-twisted structure
the image is fixed by `ψ_n` for `ε(n) = 0` and by `ψ_n∘c` for `ε(n) = 1`.

*Proof.* (i) A unital ring endomorphism `φ` fixes `Z`, hence `Q`. If `x ≥ 0` then `x = y²` and `φ(x) = φ(y)² ≥ 0`, so
`φ` is order-preserving. For real `x` and rationals `q < x < q′`, `q ≤ φ(x) ≤ q′`; letting `q, q′ → x` gives
`φ(x) = x`. Over a `Q`-algebra a Λ-structure is a commuting family of ring endomorphisms `ψ_n` with `ψ_1 = id`,
`ψ_{mn} = ψ_mψ_n` (Wilkerson, CITED), so the only one is trivial.
(ii) `φ` continuous, `φ|_Q = id` ⟹ `φ|_R = id`; `φ(i)² = −1` ⟹ `φ(i) = ±i`. Multiplicativity in `n` of `ψ_n ∈ {id, c}`
(an abelian group of order 2) is exactly `ε(mn) = ε(m) + ε(n)`; `ε` is determined by its values on primes, which are
free.
(iii) A Λ-morphism satisfies `x^♯∘ψ_n^X = ψ_n^R∘x^♯ = x^♯` on functions, so the point `x` and `Spec(ψ_n)(x)` have the
same residue map `O_X → R`, i.e. `Spec(ψ_n)(x) = x`. The twisted case is the same computation with `ψ_n^C = c^{ε(n)}`. ∎

**Corollary A.1** (PROVED as algebra; the dictionary is HEURISTIC). In Borger's dictionary (`Λ`-structure = the
Frobenius flow at all primes at once), the real place has *trivial* Frobenius. On any Λ-scheme its real Λ-points are
joint fixed points of all `ψ_n`. In Deninger's picture (R158_001 C5, C6; G1_B2_R4 Prop F; G1_B1_R5) the archimedean
place is a fixed point of the flow *by axiom*. Here it is a theorem: the only Λ-structure `R` can carry forces it.
The vertical fibres `Φ_p` are `F_k`-stable cycles (`F_kΦ_p = Φ_p`, R2 §1.2), the closed-orbit avatars; the ghost
sections `Γ_n` are the orbit `F_kΓ_1 = Γ_k` of the diagonal. Nothing here produces the Γ-factor (OT-12 needs a
linearisation at the fixed point, which Λ-geometry does not supply); §3 produces it from the other side.

**Remark A.2** (OPEN, not needed below). Whether `Hom_{Λ-ring}(W(Z), R)` is non-empty, i.e. whether Borger's square
has Frobenius-fixed real points at all. A Λ-map `φ` satisfies `φ(F_nx) = φ(x)`, `φ(V_nx) = nφ(x)` (from `F_nV_n = n`)
and `φ([a]) = φ([a])^n` for all `n`, so `φ([a]) ∈ {0,1}`; on the `V`-adically convergent expansion `x = Σ_nV_n[x_n]`
this reads `φ(x) = Σ_n n·1_{x_n≠0}`, divergent for `x = (1,1,1,…)`. So no `V`-adically continuous fixed point exists;
discontinuous ones are not excluded.

## §3 Theorem B: the archimedean Lévy density is the Coulomb kernel of the ghost line

**Theorem B** (PROVED).
(i) *(Coulomb identity)* For `x, y > 0`,
`K(|log(y/x)|) = √(xy)·( 1/|x−y| + 1/(x+y) )`.
(ii) *(bilinear form)* For real `F, G ∈ C_c(R)` put `f(x) := x^{−1/2}F(log x)`, `g(y) := y^{−1/2}G(log y)` on `(0,∞)`
(so `‖f‖_{L²(dx)} = ‖F‖_{L²(dt)}`). Whenever one side converges absolutely (e.g. `supp F ∩ supp G = ∅`),
`∬_{R²} F(t)G(s)K(|t−s|) dt ds = ∬_{(0,∞)²} f(x)g(y)[1/|x−y| + 1/(x+y)] dx dy = ½∬_{R²} f̃(x)g̃(y)/|x−y| dx dy`,
with `f̃, g̃` the even extensions to `R∖{0}`.
(iii) *(the Lévy energy)* For real `F ∈ C_c^∞(R)`, `𝔈(c_F) = ¼∬_{R²}(F(t)−F(s))²K(|t−s|) dt ds ≥ 0`: the
Hadamard-subtracted Coulomb energy of `f̃`.
(iv) *(degree normalisation)* `g_∞(x,y) := √(xy)·K(|log(y/x)|) = xy(1/|x−y| + 1/(x+y)) = 2·min·max²/(max²−min²)
= 2Σ_{j≥0} min(x,y)^{2j+1}/max(x,y)^{2j}`. It is symmetric, positive, homogeneous of degree `1`:
`g_∞(kx,ky) = k·g_∞(x,y)`; each summand `2·min^{2j+1}max^{−2j}` is the contribution of the trivial zero `−2j`.
(v) *(positivity structure)* `1/(x+y)` is a positive-definite kernel on `(0,∞)`; hence `u ↦ ½/cosh(u/2)` is a
positive-definite function on `R`. `1/|x−y|` is not, and only the subtracted energy (iii) is positive.

*Proof.* (i) Let `0 < x ≤ y`, `u = log(y/x) ≥ 0`. Then `sinh(u/2) = ½(√(y/x) − √(x/y)) = (y−x)/(2√(xy))` and
`cosh(u/2) = (y+x)/(2√(xy))`, so `½/sinh(u/2) = √(xy)/(y−x)` and `½/cosh(u/2) = √(xy)/(y+x)`. Sum. (The `x = y` case
is `K(0) = +∞` on both sides.)

## §4 Theorem C: degree versus length — the two transports of the Witt row

**Theorem C** (PROVED). Let `⟨·,·⟩` be a symmetric `R`-bilinear form on the free module `Z[Γ_n : n ≥ 1]`, considered
off the diagonal only. Suppose
(R) `⟨Γ_1,Γ_n⟩ = Λ(n)` for `n ≥ 2` (the Witt row, R1 Thm B);
(Z) `⟨Γ_m,Γ_n⟩ = 0` when `m ∤ n` and `n ∤ m` (Witt disjointness, R1 Thm B);
(D) `⟨F_kx, F_ky⟩ = k⟨x,y⟩` for all `k ≥ 1` (degree-conformality: the law `⟨F_qg,F_qh⟩ = q⟨g,h⟩` of the Witt–Rosati
form, R1 Thm A(iii)).
Then `⟨Γ_m,Γ_n⟩ = L(m,n) = min(m,n)·Λ(max/min)` for all `m ≠ n`, and `L` satisfies (R), (Z), (D). Its unitary kernel
is Toeplitz: `(mn)^{−1/2}L(m,n) = ½v_{max/min}` (`= 0` off integer ratios).

*Proof.* If `m | n`, `n = mr`, `r ≥ 2`: by (D) with `k = m`, `⟨Γ_m,Γ_{mr}⟩ = m⟨Γ_1,Γ_r⟩ = mΛ(r)` by (R). By symmetry the
same for `n | m`. Otherwise (Z). Conversely `L(km,kn) = k·min(m,n)Λ(max/min) = kL(m,n)`, `L(1,n) = Λ(n)`, and `L = 0`
off comparable pairs. Unitary kernel: `(mn)^{−1/2}·mΛ(r) = (m/n)^{1/2}Λ(r) = Λ(r)/√r = ½v_r`. ∎

**Corollary C.1** (PROVED; comparison of the two transports). The scheme-theoretic pairing of the Witt square (R1
Thm B) satisfies (R) and (Z) and, instead of (D), the **length law** (R2 Prop K): `⟨Γ_{pm},Γ_{pn}⟩ = ⟨Γ_m,Γ_n⟩ +
log p·1_{m′=n′}` (one Brownian increment per `p`-class), and `⟨Γ_{km},Γ_{kn}⟩ = ⟨Γ_m,Γ_n⟩` for `k` prime to the
linking prime. So the same Lefschetz row has exactly two transports along the Frobenii: the **degree transport**
(multiplicative in `k`; it is P46 Def 22.1, Thm 22.3, and by Thm D below the prime part of Weil's form) and the
**length transport** (additive increments; it is the scheme-theoretic intersection theory of Borger's square, R2
Thm E). In Weil's `C×C` the two coincide because `q^{min(a,b)}` is both a degree and a length (R2 Prop K reading);
over `Spec Z` they split. This is the exact content of "the Witt Frobenius has log-degree".

**Corollary C.2** (PROVED; Dirichlet Grams). For `Re s, Re w > 1` with `Re(s+w) > 2`,
`Σ_{m≠n} m^{−s}n^{−w}L(m,n) = ζ(s+w−1)·[−ζ′/ζ(s) − ζ′/ζ(w)]`,
versus R2 Thm F for the length transport, `ζ(s+w)·[−ζ′/ζ(s) − ζ′/ζ(w) + R(s,w)]`. The degree transport shifts the
polar hyperplane from `s+w = 1` to `s+w = 2` (the `H²` weight `n`) and removes the cross term `R`.
*Proof.* Pairs `(m, mr)`, `r ≥ 2`: `Σ_m m^{−s}(mr)^{−w}·mΛ(r) = Σ_m m^{1−s−w}·Σ_rΛ(r)r^{−w} = ζ(s+w−1)(−ζ′/ζ(w))`;
the mirror pairs give the other term; absolute convergence in the stated region. ∎

**Corollary C.3** (PROVED; the same for the archimedean term). `g_∞` of Thm B(iv) satisfies (D). It does not satisfy
(Z) (it is nonzero on every pair), and its "row" is `g_∞(1,n) = n(1/(n−1) + 1/(n+1)) = 2n²/(n²−1)`, the
degree-normalised archimedean contact `√n·K(log n)`. So `L + ½g_∞` is degree-conformal.

**Proposition C.4** (PROVED; why no archimedean term repairs the length transport). Let `Q_W` be the scheme-theoretic
Witt pairing and `a(m,n)` any symmetric function. If `Q_W + a` satisfies (D) with some `λ(k)` in place of `k`, then
on `p`-linked pairs `a(k,kp) − λ(k)a(1,p) = (λ(k) − 1 − v_p(k))log p` for every prime `p` and every `k`. In particular
`a` is **not** a function of the norm ratio `n/m`. *Proof of the last claim.* For Toeplitz `a`, `a(k,kp) = a(1,p)
=: a_p`, and the relation reads `(1−λ(k))a_p = (λ(k)−1−v_p(k))log p`. At `k = p`: `(1−λ(p))a_p = (λ(p)−2)log p`.
At `k = q` a prime `≠ p`: `(1−λ(q))a_p = (λ(q)−1)log p`. If `λ(q) ≠ 1` for some prime `q`, the second relation gives
`a_p = −log p` for every `p ≠ q`, and then the first at such a `p` reads `(1−λ(p))(−log p) = (λ(p)−2)log p`, i.e.
`λ(p)−1 = λ(p)−2`, absurd. If `λ(q) = 1` for every prime `q`, the first relation at `k = p` reads `0 = −log p`, absurd.
The required correction `−v_p(k)log p` on `p`-linked pairs is `p`-adic valuation data: local, and unchanged by
`ξ → Ξ_a` (C16, P46 Prop 22.5). ∎
*Reading.* The length transport cannot be completed to a degree-conformal form by any archimedean term; the two
transports differ by a purely local defect. Thm B's `g_∞` is the archimedean completion of the *degree* transport.

## §5 Theorem D: the Arakelov–Witt form is Paper 46's intersection form, with the archimedean part explicit
