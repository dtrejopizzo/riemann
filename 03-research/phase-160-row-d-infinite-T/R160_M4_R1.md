## §0 Verdict

### 0.1 In one paragraph

Riemann's function `K_Pó` (Pólya's normalisation, `Φ_{K_Pó} = ξ`, P46 Def–Thm 11.7) and its derivative are
the **exact `T = ∞` Schur vectors** of Paper 47's parity–Schur theorem. They solve the whole-line
Euler–Lagrange equations `𝔞_*(N_par, ·) = −2ε_par ℓ_par` with multiplier `−2ε_par`. So the `T = ∞` Schur block
is **exactly `−J`**, and the `T = ∞` polar capacity is exactly `0` (Theorem A). This is the structural reason
for the DIAGNOSTIC near-degeneracy `S^Sch ≈ −J` of `rem:polarcapdiag`. The same identity carries every window
test to the `T = ∞` primitive form with no loss: `W_T(F) = 𝔞_*(F − ℓ_ev(F)N_ev − ℓ_odd(F)N_odd)`. The polar
capacity is then an **exterior capacity**: the least primitive energy of a function that equals `−N_par`
outside the window.

Quantitatively (Theorem B), unconditionally and for every large `T`:
* `𝔤̃_par(T) ≤ e^{cT}e^{−2πe^{2T}}` and `λ^W ≤ λ^prim ≤ λ^A ≤ Ce^{cT}e^{−2πe^{2T}}`;
* conversely, **`λ^W_T ≥ −Ce^{cT}max(0,−λ^A_T) − Ce^{cT}e^{−πe^{2T}}`**. So for ζ the per-window converse
  `RD_T ⟹ λ^W_T ≥ 0` holds up to a doubly exponentially small error, at the same window. For the comb models of
  `cor:convfail` it fails by `O(1)`. The line that separates them is the radical, which finite comb
  modifications do not have (Proposition E).

Every positive extension `ν ∈ 𝔖(T)` puts mass at most `Ce^{cT}e^{−2πe^{2T}}/min_S|Ξ|²` on any compact `S` that
avoids the real zeros of `Ξ`. So the Kreĭn sets collapse onto the zero set at a doubly exponential rate,
uniformly over the whole set (Theorem D). No nonzero ξ-divisible radical element decays faster than
`exp(−πe^{2|t|})` (Theorem C), so `2π` is the natural constant of the method.

**No sign is proved at any window.** The route's decision-relevant output is negative for the route itself.
The polar block carries no independent obstruction for ζ, and the whole `∀T` content of row D sits in the
primitive form [prim] (§8).

## §2 Three lemmas

**Lemma 1 (sign criterion without hypotheses; PROVED, elementary) [compl].**
(a) `λ^W_{T,par} ≥ 0 ⟺ 𝔤̃_par(T) ≥ 0`. Hence `λ^W_T ≥ 0 ⟺ 𝔤̃_ev(T) ≥ 0 ∧ 𝔤̃_odd(T) ≥ 0`.
(b) If `λ_min(A_T|P^par_T) ≥ 0` and `h_par` is defined (`thm:parityschur` (a), or (b) with the range
condition), then `𝔤̃_par(T) = 𝔤_par(T)`. If `λ_min(A_T|P^par_T) < 0`, then `𝔤̃_par(T) = −∞`.
(c) `T ↦ 𝔤̃_par(T)` is nonincreasing.

*Proof.* (a) "⟹" is trivial. "⟸": if `ℓ(F) ≠ 0`, then `W_T(F) = ℓ(F)²W_T(F/ℓ(F)) ≥ 0`. If `ℓ(F) = 0`, pick
`h ∈ 𝒟^par_T` with `ℓ(h) = 1`. The polynomial `x ↦ W_T(F + xh)` is `≥ 0` for `x ≠ 0` by the first case, so
it is `≥ 0` at `x = 0`. Parity splitting (`thm:parityschur` (o)) gives the second sentence.
(b) By `thm:parityschur` (a1), each `F` with `ℓ(F) = 1` is `G + h`, `G ∈ Q`, and `W_T(F) = 𝔞_T(G) + 𝔤 ≥ 𝔤`,

## §3 Theorem A: Riemann's Φ is the exact polar vector at `T = ∞`

**Theorem A (PROVED).** Let `T > 0`.
(i) *(transport)* For every `F ∈ 𝒟_T`, with `Π_ξF := F − ℓ_ev(F)N_ev − ℓ_odd(F)N_odd ∈ 𝒱_T`:

*Proof.* (i) `Φ_{N_ev}(ρ) = 2ξ(ρ) = 0` and `Φ_{N_odd}(ρ) = 4(ρ−½)ξ(ρ) = 0`, so by Lemma 2(c),

## §5 Theorem C: no radical element decays faster than Riemann's Φ

**Theorem C (PROVED; uses CITED classical complex analysis).** Let `N` be measurable with
`|N(t)| ≤ C_N exp(−ae^{2|t|})` for all `t`, for some `a > π`. Suppose `E := Φ_N/ξ` extends to an entire
function. Then `N = 0`.

*Proof.* `Φ_N` is entire. For `x := σ − ½ ≥ 1`, substituting `y = e^{2t}` gives
`|Φ_N(σ+iτ)| ≤ C_N(½Γ(x/2)a^{−x/2} + 1)`. The symmetric bound holds for `σ ≤ −1`, using `t → −∞`. For
`σ ≥ 2`: `|ζ(s)| ≥ 1/ζ(2)`, and by the product formula,
`log(Γ(x′)/|Γ(x′+iy)|) ≤ ½log(1+y²/x′²) + ½∫_0^∞log(1+y²/u²)du = ½log(1+y²/x′²) + π|y|/2`. So
`|ξ(s)| ≥ c|s|²π^{−σ/2}Γ(σ/2)e^{−π|τ|/4}(1+τ²/σ²)^{−1/2}`, and therefore
`|E(σ+iτ)| ≤ Ce^{π|τ|/4}(1+|τ|)(π/a)^{σ/2}` for `σ ≥ 2`. The same holds for `σ ≤ −1` with `(π/a)^{(1−σ)/2}`,
using `ξ(s) = ξ(1−s)`.

`E` is entire of order `≤ 1`, as an entire quotient of order-1 functions (CITED). On the half-strips
`{−1 ≤ σ ≤ 2, ±τ ≥ 0}`, `Ee^{±i(π/4+1)s}` is bounded on the boundary and of order 1 inside, hence bounded
(Phragmén–Lindelöf). So `E` has exponential type. Its indicator satisfies `h_E(0) ≤ −½log(a/π) < 0` and
`h_E(π) ≤ −½log(a/π) < 0`. That contradicts `h(0) + h(π) ≥ 0` for nonzero functions of exponential type

## §7 Proposition E: the line that fails for the falsifiers

**Proposition E (i) (PROVED) [meth].** Let `a` differ from `Λ` in finitely many weights: `v_n(a) = v_n − δ_n`,
with `δ = (δ_n)_{n∈S} ≠ 0` and `S` finite. This covers `Λ1_{n≥N}`, `Λ + c1_{n=n₀}` and `a_θ`. Let
`W^{(a)}_*(X,Y) := W_*(X,Y) + Σ_{n∈S}(δ_n/2)[c_{X,Y}(log n) + c_{X,Y}(−log n)]` on `D^W`. If `N ∈ D^W`
satisfies `W^{(a)}_*(N,G) = 0` for all `G ∈ C_c^∞(R)`, then `N = 0`.

*Proof.* By Lemma 2(a), `W_*(N,G) = ∫G(s)𝒮(s)ds` with `𝒮(s) := Σ_ρΦ_N(1−ρ)e^{(ρ−½)s}`, after re-indexing
`ρ ↦ 1−ρ`. Also `Σ_{n∈S}(δ_n/2)[c_{N,G}(log n) + c_{N,G}(−log n)] = ∫G(s)P(s)ds`, with
`P(s) := Σ_{n∈S}(δ_n/2)[N(s+log n) + N(s−log n)]`. Both functions are continuous, so `𝒮 + P ≡ 0` on `R`.
`|P(s)| ≤ C_Se^{−(1+ε)|s|}`, so `∫_0^∞P(s)e^{−zs}ds` is holomorphic for `Re z > −1−ε`. The Laplace transform
of `𝒮` over `[0,∞)` is `Σ_ρΦ_N(1−ρ)/(s−ρ)` with `s = z+½` (P46 Lemma 11.9, proof). It is meromorphic with
residue `m_ρΦ_N(1−ρ)` at `ρ`. All `ρ` satisfy `0 < Re ρ < 1`, which lies inside `Re s > −½−ε`, where the
other side is holomorphic. So `Φ_N(1−ρ) = 0` for every `ρ`, hence `𝒮 ≡ 0`, hence `P ≡ 0`. Fourier: `P̂ = N̂c_S`
with `c_S(τ) = Σ_{n∈S}δ_n cos(τ log n)`, a nonzero real-analytic function (distinct frequencies), so its zeros
are isolated. So `N̂ ≡ 0`. ∎

**8.2 Two attempted closings, and where each stops.**
(a) *Exterior maximum principle.* In the form of Remark 3.3, one would like to show that the minimiser of the
