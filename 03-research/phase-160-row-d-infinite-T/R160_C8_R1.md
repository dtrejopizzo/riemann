## §1 Definitions

All notation is P46's (`main.tex`:115–145). F̂(τ) = ∫F(t)e^{iτt}dt, c_F is the autocorrelation, and v_n = 2Λ(n)/√n,
N_T = {n ≥ 2 : log n < 2T}. The form is 𝔞_T(F) = (1/2π)∫σ_T|F̂|², with σ_T = m − Σ_{n∈N_T}v_n cos(τ log n) and
m(τ) = Re ψ(¼+iτ/2) − log π = C₀ + ∫_0^∞(1 − cos τu)K(u)du, C₀ = ψ(¼) − log π (`lem:K`). The Tate moments are
A(F) = ∫F e^{t/2}, B(F) = ∫F e^{−t/2}, the primitive space is P_T, and W_T = 𝔞_T + 2Re(A B̄). Test functions are real
unless stated otherwise.

**1.1 Operators on L²(R).** ⟨G,H⟩ = ∫ Ḡ H. Put S_a G(t) = G(t − a), so that (S_aG)^ = e^{iτa}Ĝ, and JG(t) = G(−t),
E_aG = e^{at}G, and X = multiplication by t. For a measurable g, g(D) is the Fourier multiplier (g(D)G)^ = gĜ. Put
M₁(G) := ⟨G, XG⟩ = ∫t|G(t)|²dt, the log-scale centre of mass (t = log x).

**1.2 Local factors and Tate multipliers.** Put L_∞(s) = π^{−s/2}Γ(s/2) and L_p(s) = (1 − p^{−s})^{−1}. The **Tate multiplier**
of v, with ψ standard (ψ_∞(x) = e^{−2πix}, ψ_p trivial on Z_p), is

  u_v(z) := ε_v(½ − iz, ψ_v) · L_v(½ + iz)/L_v(½ − iz),  ε_v ≡ 1 for ζ.            (1.1)

Tate's local FE (CITED) says that this is the multiplier of the local Fourier transform in Mellin coordinates. For even
f ∈ S(R), and for Z_p^×-invariant f ∈ S(Q_p), with Mf(s) = ∫f|x|^s d^×x, one has Mf̂(½+iτ) = u_v(τ)Mf(½−iτ). For real
τ, |u_v(τ)| = 1 and u_v(−τ) = \overline{u_v(τ)}. Write u_v(τ) = e^{iθ_v(τ)} with θ_v continuous, odd, and θ_v(0) = 0.

**1.3 Semilocal operators.** S_T := {p : log p < 2T}. For a finite set S of primes put U_S := u_∞(D)∏_{p∈S}u_p(D),
Θ_S := θ_∞ + Σ_{p∈S}θ_p, **𝔉_S := U_S J**, and θ(S) := Σ_{p∈S}log p. For S = ∅, 𝔉_∅ = 𝔉_∞ is the log-scale Fourier
transform: if F(t) = e^{t/2}f(e^t) with f even, then 𝔉_∞F(t) = e^{t/2}f̂(e^t). This follows from 1.2, since
F̂(τ) = ½Mf(½+iτ).

**1.4 Gauge.** For b = (b_v) a finite idèle (b_v ∈ Q_v^×, a unit for almost all p), ψ^{[b]}_v(x) := ψ_v(b_v x), with its
self-dual measure. u_v^{[b]} is (1.1) computed with ψ^{[b]}, and |b|_A = ∏_v|b_v|_v.

**1.5 Falsifier data.** Ξ_a (0 < a < ½) has local factors L_v(s+a)L_v(s−a), hence u_v^{(a)}(z) = u_v(z−ia)u_v(z+ia).
Λχ₂ has χ₂(2) = −1 and χ₂(p) = 1 otherwise (G2_B3_R1:170), local factor (1 + 2^{−s})^{−1} at 2, and ζ's Γ-factor.

**1.6 Pitt family.** For F ∈ C_c^∞(I_T), finite S and real α: N₂(α) := ‖E_{−α}F‖², N₁(α) := ‖E_α𝔉_SF‖²,
B_F(α) := N₁(α) − N₂(α), and φ_j := log N_j.

## §2 The Tate–Beckner identity

**Lemma 2.1 (time delay). PROVED.** Let θ ∈ C^∞(R) be real with |θ′(τ)| + |θ″(τ)| ≤ C(1+|τ|)^N, let U = e^{iθ}(D), and let
G ∈ C_c^∞(R). Then UG, XUG ∈ L²(R) and M₁(UG) = M₁(G) + (1/2π)∫θ′(τ)|Ĝ(τ)|²dτ.

*Proof.* Ĝ is a Schwartz function, and (XH)^ = −i∂_τĤ. Hence (XUG)^ = −i(iθ′e^{iθ}Ĝ + e^{iθ}Ĝ′), which lies in L².
By Parseval, ⟨UG, XUG⟩ = (1/2π)∫\overline{e^{iθ}Ĝ}(−i)(iθ′e^{iθ}Ĝ + e^{iθ}Ĝ′) = (1/2π)∫θ′|Ĝ|² + (1/2π)∫\overline{Ĝ}(−i)Ĝ′,
and the last term is ⟨G, XG⟩. ∎

**Lemma 2.2 (phase slopes). PROVED** (given Tate's FE for (1.1)). (i) θ_∞(τ) = 2 arg Γ(¼+iτ/2) − τ log π, so θ_∞′ = m.
(ii) θ_p(τ) = 2 arg(1 − p^{−½}e^{iτ log p}) = −2Σ_{k≥1}p^{−k/2}sin(kτ log p)/k, so
θ_p′(τ) = −Σ_{k≥1} v_{p^k} cos(kτ log p), absolutely convergent and bounded by 2log p/(√p − 1).
(iii) Θ_S′ = m − Σ_{p∈S}Σ_k v_{p^k}cos(kτ log p) is even, smooth and O(log(2+|τ|)).

*Proof.* (i) u_∞(τ) = π^{−iτ}Γ(¼+iτ/2)/Γ(¼−iτ/2) and Γ(z̄) = \overline{Γ(z)}. Differentiating,
d/dτ[2 arg Γ(¼+iτ/2)] = 2 Im[(i/2)ψ(¼+iτ/2)] = Re ψ(¼+iτ/2). (ii) With w = p^{−½}e^{iτ log p},
u_p = (1 − w)/(1 − w̄) = e^{2i arg(1−w)}, and arg(1 − w) = −Σ_k Im(w^k)/k. Differentiate termwise (uniform convergence)
and use v_{p^k} = 2 log p·p^{−k/2}. (iii) follows. ∎

**Theorem 1 (Tate–Beckner identity). PROVED; [prim] on P_T, [compl] with the polar term.** For every T > 0, every finite
S ⊇ S_T and every real F ∈ C_c^∞(I_T):

  𝔞_T(F) = M₁(F) + M₁(𝔉_S F) = (1/2π)∫Θ_S′|F̂|²,   W_T(F) = M₁(F) + M₁(𝔉_S F) + 2A(F)B(F).       (2.1)

In particular M₁(𝔉_SF) does not depend on S ⊇ S_T. In adelic language (reading 𝔉_S as the semilocal Fourier transform on
the unramified sector of C_S, CCM 2024, CITED), 𝔞_T = ½[∫log|x|_S|f|² + ∫log|ξ|_S|f̂_S|²].

*Proof.* JF ∈ C_c^∞(I_T), (JF)^(τ) = F̂(−τ) and JXJ = −X. By Lemma 2.1 with θ = Θ_S (Lemma 2.2(iii)),
M₁(𝔉_SF) = M₁(U_S JF) = M₁(JF) + (1/2π)∫Θ_S′(τ)|F̂(−τ)|²dτ = −M₁(F) + (1/2π)∫Θ_S′|F̂|², using evenness of Θ_S′.
Next, |F̂|² = ĉ_F ∈ L¹ and Σ_k v_{p^k} < ∞, so Fubini and (1/2π)∫cos(τu)|F̂(τ)|²dτ = c_F(u) give
(1/2π)∫Θ_S′|F̂|² = (1/2π)∫m|F̂|² − Σ_{p∈S}Σ_k v_{p^k}c_F(k log p). Since supp c_F ⊂ [−2T,2T] and c_F(±2T) = 0, a term
survives iff p^k ∈ N_T. Every n ∈ N_T is a power of a prime in S_T ⊆ S. So the sum is Σ_{n∈N_T}v_nc_F(log n), and the
right side is 𝔞_T(F) (`eq:form`). Add 2AB for W_T (`eq:W`). ∎

*Scope.* The identity is stated on C_c^∞(I_T). Both sides extend to the form domain of 𝔞_T by closure, since |M₁(F)| ≤
T‖F‖². The proof never uses the global functional equation: (2.1) holds for **any** unimodular local data with ζ's
Γ-factor, and in particular for Λχ₂ and for Ξ_a (with u^{(a)}). The FE enters only through `eq:W` = zero sum (P45 Thm 9.4).

**Corollary 2.3 (involution and parity forms). PROVED.** (a) 𝔉_S is a self-adjoint unitary involution of L²(R), and
𝔉_S S_a = S_{−a}𝔉_S. (b) With P_± := ½(1 ± 𝔉_S) (the self-dual and anti-self-dual parts),
𝔞_T(F) = 2M₁(P₊F) + 2M₁(P₋F). (c) If JF = ±F, then M₁(F) = 0 and 𝔞_T(F) = M₁(𝔉_SF) = M₁(U_SF): the window form of a
parity-definite test is the log-scale centre of mass of its Tate transform. For general real F,
𝔞_T(F) = M₁(U_SF_ev) + M₁(U_SF_odd).

*Proof.* (a) u_S(−τ) = \overline{u_S(τ)} gives JU_SJ = U_S^*. Hence 𝔉_S² = U_SJU_SJ = U_SU_S^* = 1 and
𝔉_S^* = JU_S^* = U_SJ = 𝔉_S. Moreover S_a commutes with U_S and JS_a = S_{−a}J. (b) M₁(F) + M₁(𝔉F) = ⟨F, YF⟩ with
Y = X + 𝔉X𝔉. Y commutes with 𝔉, so it preserves the orthogonal eigenspaces H_± and the cross terms vanish. On H_±,
⟨G, YG⟩ = ⟨G,XG⟩ + ⟨±G, X(±G)⟩ = 2M₁(G). The domains are fine: P_±F ∈ dom X by Lemma 2.1. (c) If |F|² is even,

## §3 The ε-gauge: what the product formula fixes

**Theorem 2 (gauge covariance). PROVED** (Tate's formula CITED). For every finite idèle b and every v,
u_v^{[b]}(τ) = |b_v|_v^{−iτ}u_v(τ), i.e. U_v^{[b]} = S_{−log|b_v|_v}U_v and θ_v^{[b]′} = θ_v′ − log|b_v|_v. Hence, for
S ⊇ S_T containing every p with |b_p|_p ≠ 1 and real F ∈ C_c^∞(I_T),

  M₁(F) + M₁(𝔉^{[b]}_S F) = 𝔞_T(F) − (log|b|_A)‖F‖².                                          (3.1)

For b ∈ Q^×, |b|_A = 1 (product formula) and (3.1) is 𝔞_T(F): the window forms are gauge-invariant.

*Proof.* The self-dual measure of ψ_v(b_v·) is |b_v|^{½}dx, so f̂^{[b]}(ξ) = |b_v|^{½}f̂(b_vξ). Then
Mf̂^{[b]}(s) = |b_v|^{½−s}Mf̂(s), which is Tate's ε(s,ψ_b) = |b|^{s−½}ε(s,ψ) seen through (1.1). At s = ½ + iτ the extra
factor is |b_v|^{−iτ}, i.e. a translation. The phase slope drops by log|b_v|_v. Summing, via Lemma 2.1 and as in Thm 1,
gives (3.1). ∎

For ζ with the standard ψ all ε_v are 1. The GL(1) phase datum of ζ is therefore **exactly** this gauge family: unimodular
phases |b_v|^{iτ} on the line, whose product is 1 on principal idèles.

**Corollary 3.1 (Schur gauge; the free delays are gauge). PROVED** (Stirling CITED). Put r = p^{−½}, w = p^{−iτ}, and
b_r(w) = (w − r)/(1 − rw).
(a) u_p(τ) = b_r(w)/w. This is D.252's relative factor c_r, with its pole at w = 0: the free delay.
(b) In the gauge b_S := ∏_{p∈S}p^{−1} ∈ Q^× one has u_p^{[b_S]}(τ) = b_r(p^{−iτ}) for p ∈ S. This is inner in Im τ < 0,
since |p^{−iτ}| = p^{Im τ} < 1 there, and the finite cascade ∏_{p∈S}b_{p^{−½}}(p^{−iτ}) is a Schur function of τ with
**no** negative squares. Also u_∞^{[b_S]}(τ) = e^{iτθ(S)}u_∞(τ).
(c) The phase slopes in this gauge are −log p·P_{p^{−½}}(τ log p) ≤ 0 at p ∈ S and m(τ) + θ(S) at ∞.
(d) Every non-Schur feature is at ∞: for 0 < η < ½, |u_∞^{[b_S]}(τ − iη)| = e^{ηθ(S)}π^{−η}|Γ(¼+η/2+iτ/2)/Γ(¼−η/2−iτ/2)|,
which grows like e^{ηθ(S)}(|τ|/2π)^{η} → ∞.
So the pole obstruction of D.252 and the |S| negative squares of D.255 are ε-gauge artefacts: a principal gauge carries
them to the archimedean place, where they total θ(S), Chebyshev's function.

*Proof.* (a) u_p = (1 − p^{−½+iτ})/(1 − p^{−½−iτ}) = (1 − r/w)/(1 − rw) = (w − r)/(w(1 − rw)). (b) |b_p|_p = p gives
u_p^{[b_S]} = p^{−iτ}u_p = w·b_r(w)/w, and at ∞, |b_S|_∞^{−iτ} = e^{iτθ(S)}. |b_r(w)| ≤ 1 for |w| ≤ 1, and a product of
bounded analytic functions of modulus 1 on R is inner. (c) Thm 2 and D.248 (1.3): −i∂_φ log b_r(e^{iφ}) = P_r, with
φ = −τ log p. (d) Stirling. ∎

**Corollary 3.2 (Euler–Gram form). Identity PROVED; target EQUIV (E1).** For real F ∈ C_c^∞(I_T),

  W_T(F) = 2A(F)B(F) + (1/2π)∫(m(τ) + θ(S_T))|F̂(τ)|²dτ − Σ_{p∈S_T}(log p)(1 − p^{−1})‖L_p(½+iD)F‖²,            (3.2)

*Proof.* Thm 1 in the gauge b_{S_T}, with Cor 3.1(c), and

## §4 The Pitt family and the tempered strip

**Theorem 4. PROVED; [prim].** Let F ∈ C_c^∞(I_T) be real, F ≠ 0, and S ⊇ S_T finite.
(i) N₂ is finite and real-analytic on R. N₁(α) < ∞ for α > −½. Both are log-convex (Hölder).
(ii) B_F(0) = 0, because 𝔉_S is unitary (the phase datum as Plancherel), and B_F′(0) = 2𝔞_T(F).
(iii) For α > −½: N₁(α) = (1/2π)∫|u_S(τ − iα)|²|F̂(τ + iα)|²dτ, hence
  B_F(α) = (1/2π)∫(|L_S(½+α+iτ)|²/|L_S(½−α+iτ)|² − 1)|F̂(τ+iα)|²dτ.
(iv) **Tempered strip.** u_S is holomorphic and zero-free exactly on |Im z| < ½. Its poles lie on Im z = ½ (at
z = i/2 + 2πk/log p and z = i/2) and its zeros on Im z = −½. For F ≥ 0, N₁(α) → ∞ as α ↓ −½, so the abscissa of the
Pitt family is −½. For Ξ_a-data, u_S^{(a)}(z) = u_S(z−ia)u_S(z+ia) is holomorphic and zero-free exactly on
|Im z| < ½ − a, and N₁^{(a)}(α) → ∞ as α ↓ −(½−a) whenever ∫F e^{(½−a)t}dt ≠ 0 (in particular for F ≥ 0 and for
generic F ∈ P_T).
(v) **Factorization.** On C_c^∞, V_a := E_aU_SE_{−a} is the multiplier u_S(τ − ia) and V_{−a} = (V_a^*)^{−1}, so
U_S^{(a)} = V_a(V_a^*)^{−1}. For a = 0, V₀ = U_S is unitary. For a > 0, |u_S(−ia)| = L_S(½+a)/L_S(½−a) < 1, so V_a is not
unitary. Consequently the Ξ_a window form is 2⟨E_{−a}F, σ_T(D)E_aF⟩ (bilinear, real F): this is phase-153 Theorem A,
re-derived.

*Proof.* (i) For N₂ this is clear. By Lemma 2.1's argument, Ĝ(z) := u_S(z)F̂(−z) is the Fourier transform of G = 𝔉_SF.
It is holomorphic on Im z < ½ by (iv), rapidly decreasing on horizontal lines (F̂ decays rapidly on horizontal lines;
|u_p| is bounded on Im z ≤ ½ − δ; |u_∞| grows polynomially). The Paley–Wiener shift lemma then gives E_αG ∈ L² with
(E_αG)^ = Ĝ(· − iα) for α > −½, and this is (iii) for N₁. For N₂, (E_{−α}F)^ = F̂(· + iα). Moreover
|F̂(−τ+iα)| = |F̂(τ+iα)| for real F. Log-convexity: N(α) = ∫e^{2αt}dμ with μ ≥ 0. (ii) N₁(0) = N₂(0) = ‖F‖² by
unitarity. Differentiating under the integral (justified by the decay just used): N₁′(0) = 2M₁(𝔉_SF) and
N₂′(0) = −2M₁(F); apply Thm 1. (iii) Insert u(z) = L(½+iz)/L(½−iz) at z = τ − iα and use |L(½−α−iτ)| = |L(½−α+iτ)|.
(iv) The p-adic factor (1 − p^{−½+iz})/(1 − p^{−½−iz}) has poles where p^{−½−iz} = 1, i.e. Im z = ½, and zeros at
Im z = −½. Γ(¼+iz/2) has poles at z = i(½+2k), and 1/Γ(¼−iz/2) has zeros at z = −i(½+2k). For Ξ_a, shift by ±ia. At
the edge α₀ = −½ (resp. −(½−a)), u(τ − iα) → u(τ + i|α₀|) has a pole at τ = 0, of order ≥ 1 from Γ(0), while
|F̂(τ + iα)|² → |F̂(iα₀)|² = (∫F e^{|α₀|t})² > 0 in the stated cases. For ζ with F ∈ P_T, the archimedean zero of F̂ at
τ = 0 is simple generically, while the pole there has order 1 + |S| ≥ 2. Fatou's lemma then gives divergence.
(v) (E_{−a}G)^(τ) = Ĝ(τ+ia) and (E_aH)^(τ) = Ĥ(τ−ia), so E_aU_SE_{−a} is the multiplier u_S(τ−ia). On R,

## §5 A phase-reading sufficient criterion

**Theorem 5 (Pitt-secant criterion). PROVED; [prim].** Let F ∈ C_c^∞(I_T) be real and nonzero, S ⊇ S_T, and β ∈ (0,½). Put
R_β(F) := ∫_{−β}^0(s+β)φ₁″(s)ds + ∫_0^β(β−s)φ₂″(s)ds. Then R_β(F) > 0 and

  ‖E_{−β}F‖ · ‖E_{−β}𝔉_S F‖ ≤ ‖F‖²  ⟺  𝔞_T(F) ≥ ‖F‖² R_β(F)/(2β).                       (5.1)

In particular the left side implies 𝔞_T(F) > 0. In x-variables (S = ∅) the left side reads
(∫|x|^{−2β}|f|²)(∫|ξ|^{−2β}|f̂_S|²) ≤ (∫|f|²)², a negative-moment uncertainty inequality. For Ξ_a-data and β ≥ ½ − a,
‖E_{−β}𝔉_S^{(a)}F‖ = ∞ (Thm 4(iv)), so the criterion exists only for β < ½ − a. **For β > ½ − a it reads the phase
datum.**

*Proof.* The φ_j are smooth on [−β, β] ⊂ (−½, ∞) (Thm 4(i)). Taylor with integral remainder gives
φ₁(−β) = φ₁(0) − βφ₁′(0) + ∫_{−β}^0(s+β)φ₁″ and φ₂(β) = φ₂(0) + βφ₂′(0) + ∫_0^β(β−s)φ₂″. Here φ₁(0) = φ₂(0) = log‖F‖²
and φ₁′(0) − φ₂′(0) = B′(0)/‖F‖² = 2𝔞_T(F)/‖F‖² (Thm 4(ii)). So the left side of (5.1), i.e. φ₁(−β) + φ₂(β) ≤ 2log‖F‖²,
is equivalent to R_β ≤ 2β𝔞_T(F)/‖F‖². Finally φ″ = 4Var_{ν_s}(t) with ν_s ∝ e^{2st}|G|²dt, which is strictly positive
because ν_s is not a point mass. ∎

**Remark 5.2 (tension with U-1). HEURISTIC.** As β → 0, R_β/β ≈ (β/2)(φ₁″(0) + φ₂″(0)) = 2β[Var_{|F|²}(t) +
Var_{|𝔉_SF|²}(t)]. By Theorem M, inf_{P_T} 𝔞_T/‖F‖² → 0 super-exponentially. So (5.1) with a fixed β can hold on all of
P_T for all T only if the log-variance sum of near-minimisers tends to 0. That is implausible, since 𝔉_S spreads
log-concentrated tests: the multiplier phase grows like τ log τ. If a uniform lower bound Var + Var ≥ c₀ > 0 were
proved, Thm 5 with fixed β would fail on P_T for all large T. "Reading the strip at depth β" costs a margin of order β.
The only margin-free limit is β → 0, which is O-1 itself.

## §7 Open steps (exact statements)

**O-1 (window Beckner inequality; OPEN; EQUIV to RH).** For every T > 0 and every real F ∈ P_T,
M₁(F) + M₁(𝔉_{S_T}F) ≥ 0 [prim]; equivalently, for every real F ∈ L²(I_T), M₁(F) + M₁(𝔉_{S_T}F) + 2A(F)B(F) ≥ 0 [compl].

every L²(R)-valid argument stops at κ_{S_T} → −∞ (Cor 2.5). In P46's language this is an out-of-window measure ν, i.e. a
flat-top certificate (`thm:Zexh`). (b) The full strip width ½ must be read, because unitarity is shared by Ξ_a
(Prop 4.2(a)). (c) The FE/product formula must be used beyond the single constant it fixes, because strip width is shared
