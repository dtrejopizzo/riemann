## §1 Definitions (P46 normalisation)

For real `F ∈ C_c^∞(R)` put `Φ_F(s) = ∫F(t)e^{(s−½)t}dt` (entire), `F̂(τ) = Φ_F(½+iτ)`, `c_F = F⋆F̃`,
`A(F) = Φ_F(1)`, `B(F) = Φ_F(0)`, `v_n = 2Λ(n)/√n`, `m(τ) = Re ψ(¼+iτ/2) − log π`, `C_0 = ψ(¼)−log π`,
`𝔈(Φ) = ∫_0^∞(Φ(0)−Re Φ(u))K(u)du` (`thm:A`). For a real even test `g` with `|g(u)| ≤ Ce^{−(½+δ)|u|}`, `δ > 0`,
continuous and of bounded variation, the **Weil functional** is
```
𝒲(g) := Φ_g(0) + Φ_g(1) + (1/2π)∫_R m(τ)ĝ(τ)dτ − Σ_{n≥2} v_n g(log n),         Φ_g(s) = ∫g(u)e^{(s−½)u}du,
```
and Weil's explicit formula (CITED) is `𝒲(g) = Σ_ρ Φ_g(ρ)`, the sum over the non-trivial zeros in symmetric pairing.
For `g = c_F`: `Φ_{c_F}(s) = Φ_F(s)Φ_F(1−s)`, so `𝒲(c_F) = Σ_ρ Φ_F(ρ)Φ_F(1−ρ) =: W(F)`, and `W(F) = W_T(F)` of P46
`eq:W` for `F ∈ L²(I_T)` (`= C_0‖F‖² + 𝔈(c_F) − Σ v_n c_F(log n) + 2A(F)B(F)`, `thm:A`). `W` is translation
invariant on `C_c^∞(R)` (G2_B10_R3 §1). `P_T = {A = B = 0}`.

**Combs and data.** A *comb* is `a: N → R` with `a(1) = 0`. Dirichlet convolution `(a∗b)(k) = Σ_{dm=k}a(d)b(m)`;
`1_N ≡ 1`; `log(k) = log k`; `μ` Möbius. The falsifiers are those of R160_001 §1.17: `Λ1_{n≥N}`, `Λ+c1_{n₀}`

## §2 The ring datum

**Definition 2.0 (ring datum `𝒵`).** A triple (comb `a`; archimedean symbol; polar pair) satisfies `𝒵` if
* **(Z1)** `a ≥ 0` (P47 A8, non-negative atoms);
* **(Z2)** `a ∗ 1_N = log`, i.e. `Σ_{d|k}a(d) = log k` for every `k ≥ 1`, where `1_N` is the indicator of the
  **additive semigroup** `N = {1,2,3,…}` (equivalently: the Dirichlet series with logarithmic derivative `−Σ a(n)n^{−s}`
  has all coefficients equal to `1`);
* **(Z3)** the Mellin transform of `1_N`, `ζ(s) = Σ_n n^{−s}`, continues meromorphically with the single polar pair
  `P = {0,1}` (`|p−½| = ½` for both: P47 A3, `θ_P = ½`), and satisfies `ξ(s) = ξ(1−s)` with `ξ = ½s(s−1)Γ_R(s)ζ(s)`,
  `Γ_R(s) = π^{−s/2}Γ(s/2)` — which is the statement that the declared archimedean symbol is `m(τ)` and the declared
  Tate moments are `A, B` with exponents `±½` (A3 + A7: the zero strip is the polar strip `|Re ρ − ½| ≤ ½`).

**Theorem 2.1 (`(Z2)` is the exact comb). PROVED.** If `a ∗ 1_N = log` then `a = μ ∗ log = Λ`. Consequently `(Z1)`
follows from `(Z2)`, and any argument whose load-bearing line is `(Z2)` uses the exact value of every `Λ(n)` and no
finite initial segment of it.

*Proof.* `1_N` is invertible in the Dirichlet ring with inverse `μ`; convolve both sides with `μ`. `Λ ≥ 0` is
classical. The last clause: `(Z2)` is the infinite family of linear conditions `Σ_{d|k}a(d) = log k`, `k ≥ 1`, and its
solution set is the single point `Λ`; a finite subfamily has an infinite-dimensional affine solution set. ∎

**Theorem 2.2 (the falsifier table). PROVED; the Beurling clause CITED.** Define the *defect* of a comb `a` by
`δ_a(k) := (a∗1_N)(k) − log k`. Then:
| datum | (Z1) | (Z2): `δ_a` | (Z3) | first non-zero defect |
|---|---|---|---|---|
| (i) `Λ1_{n≥N}`, `N ≥ 3` | ✓ | `δ(k) = −Σ_{d|k, d<N}Λ(d)` | ✓ (ζ's data kept) | `δ(2) = −log 2` |

## §3 The dilation calculus and the Chebyshev completion identity

**Definition 3.0.** For a finitely supported `b: N → R` and real `F ∈ C_c^∞(R)` put
```
(S_bF)(t) := Σ_{m≥1} b_m m^{−1/2} F(t + log m),          D_b(s) := Σ_m b_m m^{−s},
```
and write `S_X := S_{1_{≤X}}`, `ζ_X := D_{1_{≤X}}`. If `supp F ⊂ I_T` then `supp S_bF ⊂ (−T−log X_b, T)`,
`X_b = max supp b`.

**Lemma 3.1. PROVED.** (a) `Φ_{S_bF}(s) = D_b(s)Φ_F(s)`. (b) `c_{S_bF}(u) = Σ_{m,m'} b_mb_{m'}(mm')^{−1/2}
c_F(u + log(m/m'))`. (c) `A(S_bF) = D_b(1)A(F)`, `B(S_bF) = D_b(0)B(F)`, `‖S_bF‖² = Σ_{m,m'}b_mb_{m'}(mm')^{−1/2}
c_F(log(m/m'))`.

*Proof.* (a) `∫F(t+log m)e^{(s−½)t}dt = m^{−(s−½)}Φ_F(s)`; multiply by `m^{−1/2}`. (b) `∫F(t+log m)F(t−u+log m')dt
= c_F(u + log m − log m')`. (c) Specialise (a) at `s = 1, 0` and (b) at `u = 0`. ∎

**Theorem 3.2 (zero side). PROVED (Weil's formula CITED).** For real `F ∈ C_c^∞(R)` and finitely supported real `b`,
```
W(S_bF) = Σ_ρ D_b(ρ)D_b(1−ρ)Φ_F(ρ)Φ_F(1−ρ),
```
absolutely convergent. If every zero is on the line, each term is `|D_b(ρ)|²|Φ_F(ρ)|² ≥ 0`.

*Proof.* `S_bF` is real and compactly supported, so `W(S_bF) = Σ_ρΦ_{S_bF}(ρ)Φ_{S_bF}(1−ρ)`; insert Lemma 3.1(a).
Absolute convergence: `|D_b(s)| ≤ Σ|b_m|m^{−Re s}` is bounded on the strip and `|Φ_F(s)| ≤ C_N e^{T|Re s−½|}(1+|s|)^{−N}`.
On the line `1−ρ = \bar ρ` and `D_b(\bar s) = \overline{D_b(s)}`, `Φ_F(\bar s) = \overline{Φ_F(s)}`. ∎

**Theorem 3.3 (prime side). PROVED.** With the notation of Lemma 3.1,
```
comb(S_bF) := Σ_{n≥2} v_n c_{S_bF}(log n) = 2 Σ_{k≥1} Σ_{m'≥1} (km')^{−1/2} b_{m'} (Λ∗b)(k) c_F(log k − log m'),
```
a finite sum, and `W(S_bF) = C_0‖S_bF‖² + 𝔈(c_{S_bF}) − comb(S_bF) + 2D_b(1)D_b(0)A(F)B(F)`.

*Proof.* By Lemma 3.1(b), `Σ_n v_n c_{S_bF}(log n) = Σ_{n,m,m'} 2Λ(n)n^{−1/2}b_mb_{m'}(mm')^{−1/2}c_F(log(nm/m'))`.

## §4 The limit `X → ∞`, the polar boundary, and the kernel identity

**Theorem 4.1 (the Li-weighted form as the limit). PROVED; the zero-free region CITED.** For real `F ∈ C_c^∞(R)`,
```
lim_{X→∞} X^{−1} W(S_XF) = W^{Li}(F) := Σ_ρ Φ_F(ρ)Φ_F(1−ρ) / (ρ(1−ρ)),
```
the series converging absolutely, and `X^{−1}W(S_XF) − W^{Li}(F) = O_F(X^{−1})`.

*Proof.* For `Re s = σ > 0` and `X ≥ 1`, partial summation gives
`ζ_X(s) = ζ(s) + X^{1−s}/(1−s) + R_X(s)`, `R_X(s) = −{X}X^{−s} + s∫_X^∞{u}u^{−s−1}du`, so `|R_X(s)| ≤ (1+|s|/σ)X^{−σ}`.
At a zero `ρ = β+iγ`, `ζ(ρ) = 0 = ζ(1−ρ)`, hence
```
X^{−1}ζ_X(ρ)ζ_X(1−ρ) = 1/(ρ(1−ρ)) + X^{−1}[X^{1−ρ}R_X(1−ρ)/(1−ρ) + X^{ρ}R_X(ρ)/ρ + R_X(ρ)R_X(1−ρ)],
```
and the bracket is bounded by `C(1 + |ρ|²/(β(1−β)))`. By de la Vallée Poussin (CITED), `min(β,1−β) ≥ c/log(|γ|+3)`,
so the bracket is `≤ C|ρ|²log²(|γ|+3)`. Since `Σ_ρ(1+|ρ|)^{−2} < ∞` and `|Φ_F(ρ)Φ_F(1−ρ)| ≤ C_N(1+|ρ|)^{−2N}`, the
error sum is `O(X^{−1})` and the main sum converges absolutely. Insert into Theorem 3.2 with `b = 1_{≤X}`. ∎

*Remark 4.1a (where A3 is load-bearing).* For `Ξ_a` the same computation with `D = ` truncation of
`ζ(s+a)ζ(s−a)` gives at the zero `ρ+a` (where `ζ(s−a)` vanishes) the leading weight
`ζ(ρ+2a)·X^{1−ρ}/(1−ρ)` and at `1−ρ−a` the weight `ζ(1−ρ−2a)X^{ρ}/ρ`, so the limit weight is
`ζ(ρ+2a)ζ(1−ρ−2a)/(ρ(1−ρ))`: on the line `ζ(½+2a+iγ)ζ(½−2a−iγ)` is not `|·|²`. The equimodular polar block of
`(Z3)` is exactly what makes ζ's limit weight `1/|ρ|² > 0` on the line. (This is a zero-side statement, recorded to
name the line; it carries no sign for ζ.)

**Theorem 4.2 (the polar boundary). (i) PROVED. (ii) EQUIV (converse CITED).**
(i) Let `H(u) := e^{−|u|/2}`. Then `Φ_H(s) = 1/(s(1−s))` on `0 < Re s < 1`, and `W^{Li}(F) = Σ_ρ Φ_{c_F⋆H}(ρ)` is the
zero-sum half of the Weil functional on the test `g_F := c_F ⋆ H`. This test has `g_F(u) = κ_F e^{−|u|/2}(1+o(1))`,
`κ_F = ∫c_F(v)e^{v/2}dv = A(F)B(F)`, when `A(F)B(F) ≠ 0`, and `g_F(u) = O(|u|e^{−|u|/2})` in general: its decay rate is
exactly `δ = 0` in `def:W`, and its prime sum `Σ_n v_n g_F(log n)` diverges like `Σ_n Λ(n)/n` unless `κ_F = 0`. So
`g_F ∉ 𝒲_T` for every `T`, and `W^{Li}` is not a Weil-functional evaluation in the sense of `thm:Z` (the mechanism
behind P46 `cor:Li`).
(ii) `RH ⟺ W^{Li}(F) ≥ 0` for all real `F ∈ C_c^∞(R)`. (⟹: on the line each term is `|Φ_F(ρ)|²/|ρ|²`. ⟸: the weights
`1/(ρ(1−ρ))` are positive on the line and bounded by `1/|ρ|²`, so Bombieri's proof of Weil's converse [Bombieri 2000,
Thm 1] applies verbatim with the weights; this is the weighted criterion of Bombieri–Lagarias 1999, Thm 1. CITED.)

*Proof of (i).* `∫_0^∞e^{−u/2}e^{(s−½)u}du = 1/(1−s)`, `∫_{−∞}^0 e^{u/2}e^{(s−½)u}du = 1/s`. Mellin transforms multiply
under convolution: `Φ_{c_F⋆H} = Φ_{c_F}Φ_H`. Decay: `g_F(u) = ∫c_F(v)e^{−|u−v|/2}dv = e^{−u/2}∫c_F(v)e^{v/2}dv` for
`u > 2T`, and symmetrically. Divergence: `v_n g_F(log n) = 2Λ(n)n^{−1/2}·κ_F n^{−1/2}(1+o(1))`. ∎

**Theorem 4.3 (polar-boundary theorem for the integer-comb convolution; the kernel identity). PROVED (Poisson
summation classical; Weil's formula CITED).** Let `h` be real, even, `C_c^∞`, `supp h ⊂ [−2T', 2T']`, and
```
G := S_ζ h,   G(t) := Σ_{m≥1} m^{−1/2} h(t + log m)     (finitely many terms for each t).
```
(a) `G(t) = 0` for `t > 2T'`, and for `t < −2T'`, for every `N`,
`G(t) = Φ_h(1)e^{−t/2} + O_{N,h}(e^{Nt})`. Hence `G` is an admissible Weil test (exponential decay of rate `> ½` on
both sides) **iff `Φ_h(1) = ∫h(u)e^{u/2}du = 0`**; otherwise it grows exactly at the polar rate `e^{|t|/2}`.
(b) If `Φ_h(1) = 0`, then `Φ_G(s) = ζ(s)Φ_h(s)` is entire, `Σ_ρ Φ_G(ρ) = 0`, and the Weil functional vanishes on the
even part `G_ev := ½(G + G̃)`: `𝒲(G_ev) = 0`. Written out, with `𝔥(n) := Σ_{m≥1}m^{−1/2}h(log(m/n)) = O_N(n^{−N})`,
```
(C′)   Σ_{k≥1} k^{−1/2} log k · h(log k)  +  Σ_{n≥2} Λ(n) n^{−1/2} 𝔥(n)
       =  Φ_h'(1) − ½Φ_h(0) + (1/2π) ∫_R m(τ) ĥ(τ) Re ζ(½+iτ) dτ .
```
(c) In particular, for `F ∈ P_T ∩ C_c^∞` real and `h = c_F` (so `Φ_h(0) = Φ_h(1) = 0` and `Φ_h'(1) = 0`),
```
(C′′)  Σ_{k<e^{2T}} k^{−1/2} log k · c_F(log k)  +  Σ_{n≥2} Λ(n)n^{−1/2} 𝔠_F(n)  =  (1/2π)∫ m(τ)|F̂(τ)|² Re ζ(½+iτ) dτ,
```
`𝔠_F(n) := Σ_m m^{−1/2}c_F(log(m/n))`.

*Proof.* (a) For `t < −2T'` every term has `m > 1`, so `Σ_{m≥1}f_t(m) = Σ_{m∈Z}f_t(m)` with
`f_t(x) := x^{−1/2}h(t+log x) = e^{t/2}φ(xe^t)`, `φ(y) := y^{−1/2}h(log y) ∈ C_c^∞(0,∞)`. Poisson:
`Σ_m f_t(m) = ∫f_t + Σ_{j≠0}f̂_t(j)`, `∫f_t = e^{−t/2}∫h(u)e^{u/2}du = e^{−t/2}Φ_h(1)`, and
`f̂_t(j) = e^{−t/2}φ̂(je^{−t})` with `|φ̂(ξ)| ≤ C_N|ξ|^{−N}`, so `Σ_{j≠0}|f̂_t(j)| ≤ C_N e^{(N−½)t}`.
(b) For `Re s > 1`, `Φ_G(s) = Σ_m m^{−s}Φ_h(s) = ζ(s)Φ_h(s)` by Lemma 3.1(a) (the sum converges absolutely); by (a) the
left side is entire when `Φ_h(1) = 0`, and so is the right side (the pole of `ζ` is cancelled). Each `Φ_G(ρ) = 0`. `G_ev`
is `C^∞`, even, with super-exponential decay, so Weil's formula applies: `𝒲(G_ev) = ½Σ_ρ[Φ_G(ρ)+Φ_G(1−ρ)] = 0`.
Terms of `𝒲(G_ev)`: polar `Φ_{G_ev}(0)+Φ_{G_ev}(1) = Φ_G(0)+Φ_G(1) = ζ(0)Φ_h(0) + lim_{s→1}ζ(s)Φ_h(s) = −½Φ_h(0) +
Φ_h'(1)`; archimedean: `Ĝ_ev(τ) = Re[ζ(½+iτ)ĥ(τ)] = ĥ(τ)Re ζ(½+iτ)` (`ĥ` real even); comb: `Σ_n v_n G_ev(log n) =
Σ_nΛ(n)n^{−1/2}[G(log n)+G(−log n)]`, with `Σ_nΛ(n)n^{−1/2}G(log n) = Σ_{n,m}Λ(n)(nm)^{−1/2}h(log nm) =
Σ_k k^{−1/2}(Λ∗1_N)(k)h(log k) = Σ_k k^{−1/2}log k·h(log k)` (a finite sum; the line `(Z2)`), and
`G(−log n) = 𝔥(n) = O_N(n^{−N})` by (a) with `t = −log n`, so `Σ_nΛ(n)n^{−1/2}𝔥(n)` converges absolutely (the double
series `Σ_{n,m}` does **not** converge absolutely — its diagonal is `h(0)ΣΛ(n)/n` — and must be read with the inner
sum first). Assemble. (c) `Φ_{c_F}(s) = Φ_F(s)Φ_F(1−s)` vanishes to second order at `s = 0, 1` when `A = B = 0`, so
`Φ_h(0) = Φ_h(1) = Φ_h'(1) = 0`; `ĉ_F = |F̂|²`; `c_F(log k) = 0` for `k ≥ e^{2T}`. ∎

*Remark 4.4 (what (C′) is and is not).* (C′) is an exact identity relating a *finite* log comb, an *infinite* prime
sum of Poisson-dual corrections `𝔥(n)` (super-polynomially small, and vanishing identically if `N` were replaced by a
continuum), and the archimedean symbol twisted by `Re ζ(½+iτ)`. It uses `(Z1)`, `(Z2)` (the log comb), `(Z3)` (Weil's
formula and the polar terms) and nothing else; it is in the **kernel** of the Weil functional, so it carries no sign,
and Theorem 3.5's defect shows it is false for every falsifier comb. By the contour route it is the residue theorem for
`−ζ'(s)Φ_h(s)`, which has no poles in the strip; it is thus the Weil-form incarnation of Chebyshev's
`Σ_{n≤x}Λ(n)⌊x/n⌋ = log⌊x⌋!`. It appears not to be in the corpus (§0.3), and I do not claim it is new to the
literature.

## §5 The closure theorem

**Theorem 5.1 (ring-datum closure). PROVED (Thm M1 of G2_B10_R3 for (i); Theorem 4.1 for (ii)).**
Let `T > ½log 2`, `X ≥ 1`, and let `𝔅_X` be the set of finitely supported real `b` with `supp b ⊂ [1,X]`.
(i) *Per window.* The statement `P_X(T)`: "`W(S_bF) ≥ 0` for all `b ∈ 𝔅_X` and all real `F ∈ C_c^∞(I_T)`" is
equivalent to `λ^W_{T+½log X} ≥ 0`. In particular `P_X(T)` for all `X` is E1, and `P_X(T)` for one `X` is a
single-window statement at the window `T + ½log X` that contains no information beyond that window.
(ii) *In the limit.* The statement "`W^{Li}(F) ≥ 0` for all real `F ∈ C_c^∞`" is EQUIV (Theorem 4.2(ii)).
(iii) *Hence:* every positivity statement whose comb input enters through a Dirichlet-convolution identity applied to
the tests — in particular every statement in which the separating line `(Z2)` is used as in Theorems 3.4, 3.5, 4.3 —
is, per window, a plain window statement at a shifted `T`, and, uniformly in `X`, E1. **The separating line is never
the sign-bearing line.**

*Proof.* (i) `span{S_bF: b ∈ 𝔅_X, F ∈ C_c^∞(I_T)} = span{τ_{log m}F: m ≤ X, F ∈ C_c^∞(I_T)} = C_c^∞((−T−log X, T))`
by Thm M1(i)–(ii) (the interval is connected because `T > ½log 2`), and `W` is translation invariant, so the infimum
of `W/‖·‖²` over that span is `λ^W_{T+½log X}`. Positivity of a quadratic form on a span is positivity on the span.
(ii) Theorem 4.2(ii). (iii) Any such statement is, for each fixed length `X`, a statement about `W` on a subset of
the span in (i), hence implied by `λ^W_{T+½log X} ≥ 0`; and any family of them indexed by `X → ∞` at fixed `T` that
is strong enough to give the sign at `T + ½log X` for all `X` is E1. ∎

**Corollary 5.2 (finitely many exact linear data are void; extends `cor:void`). PROVED (Thm R′ of G2_B9_R3,
record U-11, unconditional).** Let `ℓ_1, …, ℓ_J` be finitely many linear functionals on combs, continuous for the
norm `‖b‖ = Σ_n|b_n|n^{−1/2}` (for instance evaluations `a ↦ a(n_j)`, or `a ↦ Σ_{d|k_j}a(d)`, or moments
`a ↦ Σ_n a(n)n^{−1/2}φ_j(log n)`). Then there is a comb `a = Λ + b`, `b ≠ 0`, `‖b‖ < ∞`, with `ℓ_j(a) = ℓ_j(Λ)` for
all `j` and `λ^W_T(a) < 0` for some `T` (indeed for all large `T`). Consequently no argument whose only comb input is
`ℓ_1(Λ), …, ℓ_J(Λ)` — in particular the exact value `Λ(2)` alone, or any finite set of exact values, or any finite
set of instances of `(Z2)` — can prove `∀T λ^W_T ≥ 0`; the comb input must be an infinite independent family such as
`(Z2)` itself.

*Proof.* `{b: ‖b‖ < ∞, ℓ_j(b) = 0 ∀j}` has finite codimension in an infinite-dimensional space, so it contains `b ≠ 0`.
By Thm R′(i), `Λ + b ∉ 𝒮^W`, i.e. `λ^W_T(Λ+b) < 0` for some `T`; by R′(ii), for all `T ≥ T_b`. ∎

*Remark 5.3 (reading of Theorems 5.1–5.2 against the brief).* They sharpen the round-1 structural lesson into a
statement about *how* the separating datum may enter: (a) not through finitely many exact values (Cor 5.2); (b) not
through an identity on the tests in `Z[Q_{>0}]`, however the tests are chosen (Thm 5.1); (c) G2_B3_R5 Cor S2 already
excluded identities on the *form* (separated squares) beyond `0.74921`. What is left is the use of `(Z3)` as an
*operator* — the Fourier involution `𝔉` on `L²(R)`, which does not commute with the dilations `τ_{log m}` but
intertwines them with the adjoint dilations up to the local Tate multipliers (C8 Thm 1, Lemma 2.2) — jointly with
`(Z2)`. No identity of §3–§4 uses `𝔉`; they use only the *values* of `ζ` on the line (Thm 4.3) or at the zeros (Thm
3.2). This is the precise sense in which the algebraic use of the ring datum is closed.
