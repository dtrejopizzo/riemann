# 107.93 -- Real elliptic bad-fiber intersection witness

## 1. Purpose

Phase 107 has accumulated many exact finite audit artifacts, but almost
all of them still live at the level of symbolic shadows.  This note
does something narrower and more concrete:
it checks actual bad fibers of actual elliptic curves over
\(\mathbf Q\), using real local data from LMFDB and exact intersection
matrices built from Kodaira fiber types.

The goal is not yet a full Phase 107 realization theorem.  The goal is
to anchor one local finite-place piece of the target geometry on genuine
arithmetic objects.

## 2. Real objects used here

The verifier `107_93_real_elliptic_bad_fiber_intersection_witness.py`
uses an explicit snapshot of the local bad-reduction data visible on the
LMFDB pages for the following curves:

1. `14.a1`, with bad fibers of Kodaira types \(I_9\) at \(p=2\) and
   \(I_2\) at \(p=7\);
2. `20.a1`, with bad fibers of Kodaira types \(IV\) at \(p=2\) and
   \(I_3\) at \(p=5\).

These are genuine elliptic curves over \(\mathbf Q\), not symbolic
Phase 107 candidate objects.

## 3. Exact checks performed

For each supported bad fiber, the verifier:

1. reads the prime \(p\), Tamagawa number, Kodaira symbol, reduction
   type, and valuations from a pinned snapshot of the LMFDB local-data
   tables;
2. constructs the finite component-intersection matrix from the
   corresponding affine Dynkin diagram:
   \(I_n\) as affine \(A_{n-1}\), and \(IV\) as affine \(A_2\);
3. checks exactly, with symbolic linear algebra, that the matrix is
   negative semidefinite with one-dimensional kernel generated by the
   total fiber vector;
4. forms the target-side weighted matrix
   \((\log p)\,M_p\), making explicit that the finite-place Arakelov
   weight is attached at the target level as standard local
   normalization;
5. records the local witness that the geometric intersection pattern and
   the \(\log p\) weight are different layers of the same real target
   datum.

So this artifact is not another purely symbolic governance audit.  It
is a reproducible local witness on real bad fibers over
\(\operatorname{Spec}\mathbf Z\), with the network-dependent lookup
replaced by a pinned page snapshot so the check remains stable.

## 4. Outcome

Running the verifier on Saturday, August 1, 2026 produced:

```text
All real elliptic bad-fiber intersection checks passed.
```

So the workspace now contains a first exact Phase 107 artifact that
touches genuine arithmetic fibers rather than only symbolic finite
shadows.

## 5. What this proves and what it does not

This witness proves a narrow but useful point:

1. actual bad fibers of actual elliptic curves realize the expected
   affine-Dynkin intersection matrices exactly;
2. the finite-place \(\log p\) factor on the Arakelov side is visible as
   standard target-side weighting of those real local intersection
   matrices;
3. any future Phase 107 source package that claims to reproduce local
   finite-place geometry can now be compared against a real target-side
   normalization, not only against a symbolic audit layer.

It does **not** prove:

1. that the current Phase 107 source package reproduces these local
   matrices;
2. any global Phase 107 realization theorem;
3. the terminal identity or RH.

So the correct reading is:

\[
 \text{real local bad-fiber witness exact-checked},
 \qquad
 \text{full Phase 107 geometric realization still open}.
 \]
