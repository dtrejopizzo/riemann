## 2. Lattice dichotomy (no order constraint)

(b) if ε < 1/(2√N), every admitted window change sits on the top layer 𝒬 = {q=p^k : √N ≤ q < N}, equals

## 3. Kronecker parity: no FE defect is one-sided on odd levels (NO-GO)

**Theorem X2 (PROVED).** Let σ_P (P a finite set of primes) act by R_p(x) ↦ R_p(−x) for p∈P, i.e. on the comb
d := a − Λ by d(p^j) ↦ (−1)^j d(p^j). Every ratio defect is σ_P-invariant: D(a) = D(σ_P a).
*Proof.* Only finitely many R_p ≠ 1, so ρ_a on each line is a continuous function of u = (p^{-it})_{p∈P'} on a finite torus;
R_p(p^{-σ}(−u_p)) and R_p(p^{-(1−σ)}(−ū_p)) are the σ_P-images (−1 is real, so the rotation acts compatibly on s and 1−s).
By Kronecker (log p ℚ-independent) the Bohr distribution, and the closure of the value set, are Haar-pushforwards / images of
the torus; u_p ↦ −u_p is a Haar-preserving homeomorphism. ∎
**Corollary X2′ (PROVED).** Write d = d_e + d_o (even/odd levels). A σ-closed admissible set satisfies S ⊆ H_T only if
⟨d_e,w⟩ + |⟨d_o,w⟩| ≤ λ_A(T;Λ) for all d ∈ S: on odd-level coordinates (all primes p ≥ √N, all p^{odd}) any FE ratio
defect, *smooth or non-smooth, sup/max/Chebyshev included*, is **antipodal**. One-sidedness from FE alone can live only on
even-level coordinates p^{2j} < N. **NO-GO class 𝒦_X^dist** (ratio defects on σ-closed classes, e.g. 𝓘, real Euler
families E_N): covers ideas (2) (min/max, equioscillation) and (4) (lattice). Not covered: defects not functions of ρ_a's

## 4. The integrality vertex: order breaks the parity — central question of AUDIT_197_2

Class 𝓘_{01} := 𝓘 ∩ {b_n ∈ {0,1}} (= ζ majorizes termwise, b ≤ b(ζ); idea (3)); ζ is its top vertex b ≡ 1.
**Theorem X3 (PROVED).** (a) Moves at Λ: r_{p,k}=−1 at the first changed level (b drops 1→0); σ_P is broken (σ maps
1−x^k, k odd, to 1+x^k, b=2 ∉ 𝓘_{01}). With ε<1/(2√N): π_N S_ε = {Λ − Σ_{q∈Q} k_q log p_q e_q : Q ⊆ 𝒬, Δ_Q ≤ ε},
a **finite, one-sided** set (every coordinate change ≤ 0); non-pinning iff ε ≥ 1/(2q) for some q∈𝒬 (cheapest: q = max𝒬).
(b) **Tangent cone is a sup of linear forms of the comb.** At first order δb_n = Σ_{m|n, m prime power} δa(m)/log m; the
cone of {b ≤ 1} at Λ is the polyhedral divisor cone C_div = {δ : Σ_{m|n} δa(m)/log m ≤ 0 ∀n}, and the integral set above is
contained in it and generates its top-layer face exactly (on 𝒬 the rows reduce to δa(q) ≤ 0). So the integrality vertex
cone **coincides with the tangent cone of its LP relaxation 0 ≤ b ≤ 1** — it is a cone premise (A2/A3), a sup of linear
forms *of the comb*. It is **not** a dual certificate of the window form (def:PD): its compatibility with H_T is
C_div ⊆ {⟨δ,w_T⟩ ≤ 0} ⟺ w_T(m)log m ∈ cone{rows of the divisor matrix} (Farkas) — a sign condition on the minimizer's
autocorrelation; necessary: c_{F⋆}(log q) ≥ −λ_A√q/(2k_q log p_q) for every admitted q.
(c) Falsifiers (ε < ¼): a_P/0 (O_6) cost ≥ ½(1+½−1)=¼ ⇒ excluded; O_4 (cΛ, c∉{0,1}) and O_2 (generic c) violate

(d) Decision: π_N S_ε is finite, so the method decides T iff WP_T(Λ_Q) for the finitely many deleted combs Λ_Q ∋ Λ:
**REF-D⁺ (finite family), not pinning** for ε ≥ 1/(2N).

constraint b ≤ 1; that cone equals a polyhedral cone of linear forms in the comb (no information beyond its LP relaxation),
is not a window-form certificate, is non-pinning, and reduces deciding to a finite family of WP statements. Without the
order constraint, integrality is antipodal (X1) and FE defects cannot break it (X2).
