## §1 Lemma S closed

**Lemma S. PROVED (from BRS's proof, re-read in the primary text).** `U_n|_ℝ, V_{ρ,j}|_ℝ ∈ 𝒮(ℝ)`, and for every `Y > 0`
and `l`: `sup_{|y|≤Y}|h(x+iy)| ≪_{l,Y}(1+|x|)^{−l}`.

*Proof.* Write `s = ½ + iz`, so that `z = x + iy` corresponds to `σ = ½ − y`, `t = x`. A horizontal strip `|y| ≤ Y` is the
vertical strip `|σ − ½| ≤ Y`.

1. *`U_n`.* By BRS (4.9), `U_n^±(z) = h^∓_n(½+iz)`. By (4.7), `h^±_n(s) = ½ζ*(s)Σ_{d²|n}μ(d)α^±_{n/d²,1/2}(s/2)`, a
  finite sum.
  * By (3.15), each `α_{m,k}(s)` is the Fourier–Laplace transform of a `C^∞` function supported in `[−¼,¼]`. So
  `|α_{m,1/2}((σ+it)/2)| ≪_{k,Y} e^{π|t|/4}(1+|t|)^{−k}`, uniformly for `σ` in a compact set. This is the standard
  Paley–Wiener bound: integrate by parts `k` times, and the factor `e^{c|σ|}` is bounded on compacts.
  * `|ζ*(σ+it)| ≪_Y (1+|t|)^{A}e^{−π|t|/4}` uniformly for `σ` in a compact set, by Stirling for `Γ(s/2)` (uniform
  on compact `σ`-ranges away from the poles) and the convexity bound for `ζ`. Near `s = 0, 1`, the product
  `h_n^±` is entire (BRS, after (4.7)), so bounded `|t|` costs nothing.
  * The product is `≪_{k,Y}(1+|t|)^{A−k}` uniformly in the strip.
2. *`V_{ρ,j}`.* By (4.10), `V^±_{ρ,j}(z) = (2πi)^{−1}∮_{|w−ρ|=r} i^{−j}(w−ρ)^j H^∓(w, ½+iz)dw`. The circle is chosen
  to meet no other zero, and by (4.6) `H^±(w,s) = ζ*(s)A^±_{1/2}(w/2,s/2)/(2ζ*(w))`, minus a term independent of `w`.
  That term integrates to 0 on the circle, since `j ≥ 0`.
  * On the circle, `1/ζ*(w)` is bounded.
  * By (4.3), `A^±_{1/2}(w/2, s/2)` is a sum of three parts:
  * `−α^±_{0,1/2}(s/2)(…)`, which is rational in `w`, bounded on the circle, and handled as in step 1;
  * `(w/2 − s/2)^{−1} ± (½ − w/2 − s/2)^{−1}`, which is `O(1/|t|)` once `|t| > |Im w| + 1`;
  * the integral `∫_1^∞(F^±(it,s/2) − α^±_0(s/2))(t^{w/2−1} ± t^{½−w/2−1})dt`. By Prop 3.4 it is
  `≪ e^{π|Im s|/4 − c√(|Im s|/2)}`, uniformly in `s`, since Prop 3.4 depends only on `|Im s|`, and uniformly for
  `w` on the circle.
  * Multiplied by `ζ*(s) ≪_Y(1+|t|)^Ae^{−π|t|/4}`, each part is `≪_{l,Y}(1+|t|)^{−l}`, uniformly for `σ` in compact
  sets and `w` on the circle.
  * Integrating over the circle preserves the bound. For bounded `|t|`, `V` is entire, so it is bounded on compacts.

  This is exactly BRS's sentence "s ↦ ζ*(s)A^±(w,s) is rapidly decaying in vertical strips (uniformly for w in compact
  sets)", with "in vertical strips" in its standard, uniform sense.
3. *Schwartz on `ℝ`.* Cauchy's estimate on the circle of radius 1 about `x ∈ ℝ` gives
  `|h^{(k)}(x)| ≤ k!·sup_{|ζ−x|=1}|h(ζ)| ≪_{k,l}(1+|x|)^{−l}`, by the `Y = 1` case. ∎

**Consequence.** Theorem P of R4 (no nonzero even tempered comb on `±½log ℕ` has Fourier transform carried by `Z_on`
with order `< m`) is PROVED from CITED BRS Thm 1.1 together with the §4.3 construction, with no gap. So are Cor P1, P2
and P3 (A)–(C). Cor P2 still uses B9's Lemma L with its panel patch, as before.

## §2 The fibre over Λ is pointed at Λ

Conventions are those of R4 §1 and G2_B9_R2:
* `β_b = Σ_{n≥2}b_n n^{−1/2}(δ_{log n}+δ_{−log n})`, `D_b = β̂_b`, `𝒯 = {b : β_b ∈ 𝒮′}`;
* `u_a = k_∞ + 2cosh(u/2) − β_a`;
* `𝒮^W = {a : u_a positive definite} = {a : λ^W_T(a) ≥ 0 ∀T}`;
* `μ_Λ = Σ_{γ∈Z_on}m_γδ_γ`.

Three facts are used throughout:
* (N) B9 R3 Thm N(i): `𝒮^W ∩ (Λ+𝒯) ≠ ∅ ⟹ RH`;
* (R) B9 R2 Thm R(iv): under RH, `Λ + b ∈ 𝒮^W ⟺ D_b ≤ 2πμ_Λ` (as distributions; then `D_b` is a real measure);
* (Pos) a positive tempered distribution is a measure with `∫(1+|x|)^{−N}d|·| < ∞`.

**Theorem X (Λ is an extreme point). PROVED, unconditional, complete form.** Let `b ∈ 𝒯` and `t > 0`. If
`Λ + b ∈ 𝒮^W` and `Λ − tb ∈ 𝒮^W`, then `b = 0`.

*Proof.* By (N), RH holds. By (R), `D_b ≤ 2πμ_Λ` and `−tD_b ≤ 2πμ_Λ`, so `D_b` is a real measure.
* On the open set `ℝ∖Z_on` (open because `Z_on` is closed), `μ_Λ` vanishes. So `D_b ≤ 0` and `D_b ≥ 0` there, and
  `D_b|_{ℝ∖Z_on} = 0`.
* Hence `D_b` is an atomic measure carried by `Z_on`, of order `0 < m`. Theorem P with `σ = β_b` gives `β_b = 0`.
* So `b = 0`. ∎

*Reading.* `𝒮^W ∩ (Λ + 𝒯)` is convex, because `a ↦ u_a` is affine. It is empty if RH fails. If RH holds, it contains
`Λ`, and Theorem X says no open segment through `Λ` lies in it. So `Λ` is an extreme point. Any other point `a` would
make `[Λ, a]` a segment with `Λ` as an *endpoint*. Positivity near `Λ` is therefore a strictly one-sided phenomenon.

**Proposition C (the rigidity question as an RH-free cone). PROVED, complete form.** Define
```
𝒞 := { b ∈ 𝒯 : D_b is a real measure, D_b|_{ℝ∖Z_on} ≤ 0, and D_b^+ ≤ C·μ_Λ for some C < ∞ }.
```
Then:
* (i) `𝒞` is a convex cone. Its definition uses only the set `Z_on` and multiplicities, not RH.
* (ii) `𝒞 ∩ (−𝒞) = {0}`.
* (iii) Under RH, `𝒮^W ∩ (Λ + 𝒯) = Λ + 𝒞_{2π}`, where `𝒞_{2π} := {b ∈ 𝒞 : D_b^+ ≤ 2πμ_Λ}`. Also
  `⋃_{s>0}s·𝒞_{2π} = 𝒞`.
* (iv) Hence, under RH: `𝒮^W ∩ (Λ + 𝒯) = {Λ}` if and only if `𝒞 = {0}`.

*Proof.*
* (i) Closure under sums and positive multiples is clear, since `(D_{b+b'})^+ ≤ D_b^+ + D_{b'}^+`.
* (ii) If `±b ∈ 𝒞`, then `D_b = 0` off `Z_on`, and Theorem P applies as in Theorem X.
* (iii) "⊆": by (R), `D_b ≤ 2πμ_Λ`, so `D_b ≤ 0` off `Z_on` and `D_b^+ ≤ 2πμ_Λ`. "⊇": if `b ∈ 𝒞_{2π}`, then
  `D_b = D_b^+ − D_b^−` with `D_b^+ ≤ 2πμ_Λ`, so `D_b ≤ 2πμ_Λ`, and (R) gives `Λ + b ∈ 𝒮^W`. For the union: if
  `D_b^+ ≤ Cμ_Λ`, then `(2π/C)b ∈ 𝒞_{2π}`.
* (iv) follows from (iii). ∎

*Reading.* The OPEN residual of R4 §4 asks for a nonzero tempered comb on `±log ℕ_{≥2}` whose Fourier transform is
nonpositive off the on-line ordinates, with positive atoms at the ordinates bounded by a multiple of the
multiplicities. Weil positivity and RH have left the question. It is a pure one-sided Fourier-pair problem for the pair
`(log ℕ, Z_on)`. The cone is pointed (ii), and three sub-cones are known to be `{0}`:
* R4 Cor P3(A), where `D_b ≤ 0`;
* Theorem P, where `D_b` is carried by `Z_on`;
* Theorem F below, where the deficit set is sparse.

**Primitive form.** The same statements hold for `𝒮^A` if the primitive analogue of (R), with weight `(τ²+¼)²` (B9 N(i)
with `k = 2`), is granted. The weight is positive and does not change supports, so the proofs go through verbatim.

## §3 The probe on the rigid side: removing zeros

Let `a = Λ + b ∈ 𝒮^W`, `b ∈ 𝒯`. By (N) RH holds, and `ν_a := û_a ≥ 0` is the spectral measure of the law `a`. Its
relation to the zeros is `ν_a = 2πμ_Λ − D_b`. Define the **deficit set** (the zeros that `a` removes or thins)
```
E(b) := { γ ∈ Z_on : D_b({γ}) > 0 } = { γ : ν_a({γ}) < 2πm_γ }.
```
Write `D_b = P − N`, with `P := D_b|_{E(b)}` and `N := −D_b|_{ℝ∖E(b)}`. By (R), `P` is atomic and satisfies
`0 ≤ P ≤ 2πμ_Λ`, and `N ≥ 0`. Both are tempered measures, since `|D_b| ≤ 2πμ_Λ + ν_a` and (Pos) applies. In the
 language: `ν_a = 2π·(zeros, with those in `E` partly or wholly removed) + N`, where `N` is compensating spectral
mass anywhere.

**Theorem F. PROVED, complete form.** Suppose there is a nonzero entire function `S`, of exponential type `σ < ½log 2`,
bounded on `ℝ`, with `S|_{E(b)} = 0`. Then `b = 0`.

*Proof.*
1. *Tests.* Fix `ε > 0` with `σ + ε < ½log 2`, and take `φ ∈ C_c^∞(−ε, ε)`. Put `φ̌(τ) := ∫φ(u)e^{−iτu}du`,
  `F := S·φ̌` and `g := |F|²` on `ℝ`.
  * By Bernstein's inequality every derivative of `S` is bounded on `ℝ`, and `φ̌ ∈ 𝒮`. So `F|_ℝ ∈ 𝒮` and `g ∈ 𝒮`.
  * `F` is entire of exponential type `≤ σ + ε`. By Paley–Wiener–Schwartz, `F̂` is supported in
  `[−σ−ε, σ+ε]`, and `F̂ ∈ 𝒮`, so `F̂ ∈ C_c^∞`.
  * `ĝ = (2π)^{−1}F̂ ⋆ (F̄)^` is in `C_c^∞` with support in `[−2σ−2ε, 2σ+2ε]`, a compact subset of
  `(−log 2, log 2)`.
2. *The pairing vanishes.* `β_b` has no mass in `(−log 2, log 2)`, because its nodes satisfy `|±log n| ≥ log 2`. So
  `∫g dD_b = ⟨D_b, g⟩ = ⟨β_b, ĝ⟩ = 0`. The first equality holds because `|D_b|` is tempered and `g ∈ 𝒮`.
3. *Sign.* `g = 0` on `E(b)`, so `∫g dP = 0`. Hence `∫g dN = 0`. Since `g ≥ 0` is continuous, `N({g > 0}) = 0`.
4. *`N` lives on `Z_ℝ(S)`.* Let `x_0 ∈ ℝ` with `S(x_0) ≠ 0`. Take `φ = φ_0e^{ix_0u}` with `0 ≤ φ_0 ∈ C_c^∞(−ε,ε)`,
  `φ_0 ≠ 0`. Then `φ̌(x_0) = ∫φ_0 > 0`, so `g(x_0) > 0` and `N` vanishes near `x_0`. Thus `N` is carried by the
  discrete closed set `Z_ℝ(S)` of real zeros of `S`.
5. *Remove the extra zeros.* Let `x_2 ∈ Z_ℝ(S)∖E(b)` have order `k`. Put `S_2(z) := S(z)·((z − x_2 − 1)/(z − x_2))^k`.
  * `S_2` is entire, of the same exponential type, and bounded on `ℝ`: the rational factor is bounded off a
  neighbourhood of `x_2`, and `S_2` is continuous there.
  * `S_2` still vanishes on `E(b)`, since `x_2 ∉ E(b)`, and `S_2(x_2) ≠ 0`.
  * Steps 1–4 with `S_2` show that `N` vanishes near `x_2`.

  Hence `N` is carried by `E(b) ⊆ Z_on`.
6. *Conclusion.* `D_b = P − N` is an atomic measure carried by `Z_on`. By Theorem P (with Lemma S, §1), `β_b = 0`, so
  `b = 0`. ∎

**Corollary F1 (finitely many removed zeros; the "100 random zeros", rigid form). PROVED.** If `E(b)` is finite,
then `b = 0`. So no ∀T Weil-positive law in `Λ + 𝒯` has spectrum equal to the zeros with finitely many of them (chosen
at random or not) wholly or partly removed, whatever compensating mass `N` is added elsewhere.
*Proof.* With `k = #E(b)`, take `S(z) = Π_{γ∈E(b)} sin(σ′(z − γ))`, where `kσ′ < ½log 2`. It is bounded on `ℝ`, of
type `kσ′`, and vanishes on `E(b)`. Apply Theorem F. ∎

**Corollary F2 (BM-sparse deficit). PROVED from CITED Beurling–Malliavin.** If `E(b)` has Beurling–Malliavin exterior
density `D*(E(b)) < log 2/(2π)`, then `b = 0`.
*Proof.* By the Beurling–Malliavin radius-of-completeness theorem, `{e^{iγt}}_{γ∈E}` is incomplete in
`L²(−σ, σ)` for `π D*(E) < σ < ½log 2` (CITED: Beurling–Malliavin 1967; Koosis, *The Logarithmic Integral* II;
Havin–Jöricke). So a nonzero `f ∈ L²(−σ,σ)` annihilates all of them. Its Fourier transform `S` is entire of type
`≤ σ`, bounded on `ℝ` (it is in `L²` with compact spectrum), and vanishes on `E`. Apply Theorem F. ∎

**What is left (OPEN).** A nonzero element of `𝒞` must have a deficit set `E(b)` with:
* BM exterior density `≥ log 2/(2π)` (Cor F2);
* lower density `≥ log 2/(2π)` (Eremenko–Novikov, CITED in R4 Rem 4.6; this bound is stronger than Cor F2 but was
  not re-read in the measure version);
* positive upper mean *mass* density `d⁺(b) ≥ sup_n |b_n|/(2√n)` (G2_B7_R5 Thm M, concurrent, not checked by me).

The random universes sit exactly here. A Bernoulli(`p`) thinning of the zeros (`0 < p < 1`) gives
`E = Z_on∖M` of density `(1−p)(2π)^{−1}log t → ∞`, which none of these bounds excludes. **The probe, run on the
rigid side, lands precisely on the OPEN residual:** "can a positive law remove a positive-density random set of zeros
and compensate with mass off the zeros?" Theorem F excludes finite and BM-sparse removals.

## §4 Literature check of the residual (the panel's request)

* **Olevskii–Ulanovskii**, *Fourier quasicrystals with unit masses*, C. R. Math. 358 (2020) 1207–1211,
  arXiv:2009.12810. CITED from the abstract: "every set `Λ ⊂ ℝ` such that the sum of δ-measures at the points of `Λ` is
  a Fourier quasicrystal is the zero set of an exponential polynomial with imaginary frequencies".
* **Gonçalves**, *A classification of Fourier summation formulas and crystalline measures*, arXiv:2312.11185. CITED
  from the abstract: it extends Kurasov–Sarnak and Olevskii–Ulanovskii, and classifies nonnegative measures with
  **uniformly discrete** support bounded away from zero on the support, under quadratic decay.
* **Application.** These theorems need measures on *both* sides with locally finite, typically uniformly discrete
  support and translation-bounded variation, or positivity.
  * (a) `μ_Λ` is not a Fourier quasicrystal: its transform `u_Λ` has the non-atomic part `k_∞ + 2cosh(u/2)`. Also,
  zero sets of exponential polynomials have bounded density, while `#(Z_on ∩ [t, t+1]) ≍ log t`.
  * (b) In the residual pair, `supp β_b ⊆ ±log ℕ` is not uniformly discrete (gaps `≍ 1/n`), and `D_b = P − N` is
  signed. Its positive part is not bounded away from zero, and nothing forces `N` to be atomic.
  * So the FQ classifications do not apply, and no reduction to them is visible: a change of variable `u ↦ e^u`
  destroys the Fourier structure.
* **The relevant uniqueness literature for a sign-constrained, spectrally gapped measure** is the Beurling–Malliavin /
  Eremenko–Novikov line, which Theorem F and Rem 4.6 use. It gives density thresholds of order `log 2/(2π)`. These do
  not reach the zero density `(2π)^{−1}log t`.
* Label: CITED at the abstract level; it bears no load.

(H_Q) of R4 is unchanged (OPEN). Theorem F is its "localised" replacement: (H_Q) asked for positive prime-blind tests
vanishing on all of `Z_on`. Theorem F needs them only on `E(b)`, and for sparse `E(b)` the Paley–Wiener tests of
type `< ½log 2` suffice.

side (rounds 1–3), needs infinite density plus reality, and reality is RH (R3 Prop D). Run on the rigid side (rounds
4–5), it shows three things:
* the explicit formula is the **unique** law of its shape (R4 Cor P2);
* the law is an **extreme point** of the positive laws (Thm X);
* no positive law can drop a finite or sparse set of zeros (Thm F).

No law "other than the explicit formula" exists in the tempered class, and none of this yields its sign.

## §7 Weakest steps

1. **Lemma S, step 2.** I use "rapidly decaying in vertical strips" in its standard uniform sense, and I re-derived the
  uniformity from (4.3), Prop 3.4 and Stirling. The Stirling and convexity bound for `ζ*` near `σ ∈ [½ − Y, ½ + Y]`
  is uniform only away from the poles at `s = 0, 1`, which occur at bounded `|t|`, where entireness covers it. A
  referee should check the `w`-uniformity of Prop 3.4 on the circle `|w − ρ| = r`. Prop 3.4 is stated for all `s` with
  a bound depending only on `|Im s|`, and `t^{w/2−1}` is uniformly bounded times `t^{C}` on the circle, so the
  `t`-integral converges uniformly.
2. **Theorem F, step 5** assumes `Z_ℝ(S)` is discrete (true for `S ≢ 0`) and moves one zero at a time. Handling all
  extra zeros needs only the local statement at each `x_2`, and that is what is proved.
3. **Cor F2** rests on the Beurling–Malliavin theorem for general real sequences (not necessarily separated). I cite it
  in the form of the radius of completeness. If a referee prefers the separated version, Cor F2 holds for separated
  `E(b)`. Cor F1 needs no citation.
4. **Novelty.** Theorem X is a two-line corollary of Theorem P, and Theorem F combines Paley–Wiener tests with Theorem
  P. Their value is structural: rigidity at `Λ` is one-sided, and the zero-removal probe is excluded exactly
  up to the density threshold. None of it bears on the sign of `λ_T(Λ)`. **Nothing here is a step toward
  `∀T λ_T(Λ) ≥ 0`.**
