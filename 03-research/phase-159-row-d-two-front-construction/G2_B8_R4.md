## §1 Definitions

All definitions are from Paper 47, checked against the source lines cited above.
`I_T = (−T,T)`. For real `F ∈ L²(I_T)` extended by zero: `c_F(u) = ∫F(t)F(t−u)dt`,
`F̂(τ) = ∫F e^{iτt}`, and `\widehat{c_F} = |F̂|²`. Contacts are `𝒩_T = {n ≥ 2 : log n < 2T}`, with
`v_n = 2Λ(n)/√n`. Then `m(τ) = Re ψ(¼ + iτ/2) − log π = C_0 + ∫_0^∞(1 − cos τu)K(u)du`, where
`C_0 = ψ(¼) − log π = −5.37218…` and `K(u) = 2e^{3u/2}/(e^{2u} − 1) = 1/(2 sinh(u/2)) + 1/(2 cosh(u/2))`
(lem:K). On the form domain (thm:A):

  `𝔞_T(F) = C_0‖F‖² + ∫_0^∞ ε_F(u)K(u)du − Σ_{n∈𝒩_T} v_n c_F(log n)`, `ε_F(u) := c_F(0) − c_F(u) = ½‖F − F_u‖² ≥ 0`.

Here `P_T = {A(F) = B(F) = 0}`, with `A(F) = ∫F e^{t/2}` and `B(F) = ∫F e^{−t/2}`. The complete form is
`W_T = 𝔞_T + 2Re(A\bar B)`, and `W_T = 𝔞_T` on `P_T`. For a prime `p < e^{2T}`, the local prime form is
`Q_p(F) = −Σ_{k≥1, k log p<2T} v_{p^k} c_F(k log p)` (cor:Qp).

**Definition 1 (Lévy–Khintchine splitting).** Fix `T`. Let `Π` be a finite index set consisting of the primes
`p < e^{2T}` and finitely many extra labels `∞_1, …, ∞_r`, for which we set `Q_{∞_i} := 0`. An **LK splitting** is a
family `(C_π, ψ_π)_{π∈Π}` with the following properties:
* `C_π ∈ ℝ` and `Σ_π C_π = C_0`;
* each `ψ_π : ℝ → [0,∞)` is even, continuous, conditionally negative definite, with `ψ_π(0) = 0`;
* `Σ_π ψ_π = m − C_0 = φ(τ²)`.

The **local forms** are `q_π(F) := C_π‖F‖² + (2π)^{−1}∫ψ_π|F̂|² + Q_π(F)`, so that `Σ_π q_π = 𝔞_T` on the form
domain. The splitting **certifies** `RD_T` locally if `q_π ≥ 0` on `P_T ∩ H¹_0(I_T)` for every `π`.

*Why this is the stability class (CITED + PROVED reduction).*
* By Schoenberg's theorem (Berg–Forst, *Potential Theory on LCA Groups*, Thm 7.8; Sato, *Lévy Processes and Infinitely Divisible
  Distributions*, Thm 8.1 and its symmetric case), `ψ_π` is conditionally negative definite with `ψ_π(0) = 0` exactly when
  `e^{−tψ_π}` is the Fourier transform of a probability measure for every `t > 0`. That is, each piece is the exponent
  of a convolution semigroup: an infinitely divisible, "stable under convolution powers" object. The Euler factor's
  own symbol sits on the other side (round 3, Remark B).
* By Lévy–Khintchine for real even `ψ` (CITED, Sato Thm 8.1), `ψ_π(τ) = b_πτ² + ∫_ℝ(1 − cos τu)ν_π(du)`, with
  `b_π ≥ 0` and `ν_π` a symmetric Lévy measure. The triple is unique, so triples add, and
  `Σ b_π τ² + ∫(1 − cos τu)Σν_π = φ(τ²)`.
* By thm:S(ii), `φ(τ²)` has Gaussian part `0` and Lévy measure `½K(|u|)du`. Uniqueness then gives `Σ b_π = 0`, hence
  every `b_π = 0`, and `Σ ν_π = ½K(|u|)du`. Hence `0 ≤ ν_π ≤ ½K(|u|)du`, so `ν_π = ½K_π(|u|)du` with measurable
  `0 ≤ K_π ≤ K` and `Σ_π K_π = K` a.e.
* Therefore, by Tonelli and Plancherel exactly as in the proof of thm:A,

  `q_π(F) = C_π‖F‖² + ∫_0^∞ ε_F(u)K_π(u)du + Q_π(F)`. (1.1)

  The scalar shares of round 3 are the case `K_π = α_πK`, `C_π = α_πC_0`.
* Without the conditional negative definiteness constraint, the splitting would be vacuous. One could take
  `ψ_p := σ_p` (the `p`-symbol) and give the rest to `∞`, which is just `𝔞_T` itself. The constraint is exactly what
  "stability-preserving" adds.

**Definition 2 (complete form).** For `W_T`, each `q_π` may also carry a polar piece `h_π(A(F), B(F))`, where `h_π`
is a Hermitian form on `ℂ²` and `Σ h_π = 2Re(A\bar B)`. These pieces vanish on `P_T`. Arbitrary polar pieces not
factoring through `(A, B)` would again make the splitting vacuous.

## §2 Theorem L′ and its proof

**Constants.** `S_0 = {2, 3, 5, 7, 11, 13, 17, 19}`, `ℓ = 1/20`, `u_1 = 2ℓ/(3π) = 0.0106103…`, and
`G(u) = log tanh(u/4) + 2 arctan e^{u/2}`, an antiderivative of `K` (thm:S(iii)), with `G(∞) = π`. Define

  `E := 2 + ⅔u_1 + 4[G(ℓ) − G(u_1)] + 2[π − G(ℓ)] + Σ_{p∈S_0}[G(log p + ℓ) − G(log p − ℓ)]`.

Numerically (§6): `2 + ⅔u_1 = 2.007074`, `4[G(ℓ) − G(u_1)] = 6.279350`, `2[π − G(ℓ)] = 11.855755`, and the
neighbourhood sum is `0.700459`. So `E = 20.842638`, and

  **(L′)** `Σ_{p∈S_0} v_p = 10.753396 > 2C_0 + E = 10.098271` (margin `0.6551`).

**Theorem L′. PROVED, unconditional.** Let `T ≥ 1.50`. No LK splitting (Definition 1) certifies `RD_T` locally. More
precisely, for every LK splitting there is a label `π ∈ Π` and a real `F ∈ P_T ∩ H¹_0(I_T)` with `‖F‖² = 2` and
`q_π(F) < 0`. The same holds for the complete form with polar pieces as in Definition 2.

*Proof.*

*Step 1 (one test per prime of `S_0`).* Fix `p ∈ S_0` and put `u_0 = log p`, `J = (−T, −T + ℓ)`. Let
`ψ_j(x) = √2 sin(jπx)` on `(0,1)` for `j = 1, 2, 3`, and `φ_j(t) = ℓ^{−1/2}ψ_j((t + T)/ℓ)`. These are orthonormal in
`L²(J)`, lie in `H¹_0(J)`, and satisfy `‖φ_j′‖² = j²π²/ℓ²` with the `φ_j′` mutually orthogonal. For `c ∈ ℝ³` with
`|c| = 1`, put `φ_c = Σ c_jφ_j` and `F_c = φ_c + φ_c(· − u_0)`.

Conditions:
* `ℓ < u_0`, since `ℓ = 0.05 < log 2`.
* `J + u_0 ⊂ I_T`, since `−T + u_0 + ℓ ≤ T` is equivalent to `log p + ℓ ≤ 2T`. This holds because
  `log 19 + 0.05 = 2.99444 ≤ 3.00 ≤ 2T`.

`A` and `B` are real linear functionals on the 3-dimensional real space `{F_c}`. The map `c ↦ F_c` is injective,
since `J` and `J + u_0` are disjoint. So there is a unit `c` with `F_c ∈ P_T`. Call this test `F^{(p)}` and write
`φ = φ_c`. Then `‖φ‖ = 1`, `‖F^{(p)}‖² = 2` and `‖φ′‖² ≤ 9π²/ℓ²`. Since `F^{(p)} ∈ H¹_0(I_T)`, it lies in the form
domain.

*Step 2 (the autocorrelation).* `supp c_φ ⊂ [−ℓ, ℓ]`, `c_φ(0) = 1` and `|c_φ| ≤ 1`. As in round 3 (and `lem:cpos`),

  `c_F(u) = 2c_φ(u) + c_φ(u + u_0) + c_φ(u − u_0)`, `F = F^{(p)}`.

Since `u_0 > 2ℓ`:
* `c_F(0) = 2`.
* For `0 ≤ u ≤ ℓ`: `c_F(u) = 2c_φ(u)`, so `ε_F(u) = ‖φ − φ_u‖² ≤ min(4, u²‖φ′‖²) ≤ min(4, 9π²u²/ℓ²)`. The middle
  inequality uses `‖φ − φ_u‖ ≤ |u|‖φ′‖` for `φ ∈ H¹(ℝ)`.
* For `u > ℓ`: `c_F(u) = c_φ(u − u_0)`, so `ε_F(u) = 2 − c_φ(u − u_0) ≤ 2 + 𝟙_{|u−u_0|<ℓ}`.

*Contact isolation.* The support of `c_F` on `(0,∞)` is `(0, ℓ] ∪ [u_0 − ℓ, u_0 + ℓ]`.
* `(0, ℓ]` contains no `log n` with `n ≥ 2`.
* If `n ≠ p` and `|log n − log p| ≤ ℓ`, then `|log(n/p)| ≥ log(1 + 1/p) ≥ log(20/19) = 0.05129 > ℓ`, a contradiction.
* For `k ≥ 2`, `k log p − log p ≥ log 2 > ℓ`.

Hence `c_F(log n) = 0` for every `n ∈ 𝒩_T∖{p}`, `c_F(log p) = c_φ(0) = 1`, and so `Q_p(F^{(p)}) = −v_p`.
Also `Q_{π}(F^{(p)}) = 0` for every label `π ≠ p`.

*Step 3 (tests for the other labels).* For `π ∈ Π ∖ S_0` (the primes `19 < π < e^{2T}` and the labels `∞_i`), use
`F_π := F^{(2)}`. Then `Q_π(F_π) = 0` by Step 2. For `π = p ∈ S_0`, use `F_p := F^{(p)}`.

*Step 4 (summation; this is where the archimedean place enters).* Suppose `q_π(F_π) ≥ 0` for every `π`. Summing (1.1):

  `0 ≤ Σ_π q_π(F_π) = 2Σ_πC_π + ∫_0^∞ Σ_π K_π(u)ε_{F_π}(u) du − Σ_{p∈S_0} v_p`.

By Step 2, every test satisfies `ε_{F_π}(u) ≤ M(u)`, where
* `M(u) := min(4, 9π²u²/ℓ²)` for `u ≤ ℓ`, and
* `M(u) := 2 + 𝟙_U(u)` for `u > ℓ`, with `U = ∪_{p∈S_0}(log p − ℓ, log p + ℓ)`.

Since `K_π ≥ 0` and `Σ K_π = K`,

  `∫ Σ_π K_π ε_{F_π} ≤ ∫_0^∞ K M du ≤ E`. (2.1)

The last inequality is evaluated piece by piece:
* `9π²u²/ℓ² ≤ 4` exactly when `u ≤ u_1`.
* On `[0, u_1]`, use `K(u) ≤ 1/u + ½` (from `sinh x ≥ x` and `cosh ≥ 1`). This gives
  `∫_0^{u_1} (9π²u²/ℓ²)K ≤ (9π²/ℓ²)(u_1²/2 + u_1³/6) = 2 + ⅔u_1`.
* On `[u_1, ℓ]`, the contribution is `4∫K = 4[G(ℓ) − G(u_1)]`.
* On `(ℓ, ∞)`, the contribution is `2[π − G(ℓ)] + Σ_{p∈S_0}∫_{log p−ℓ}^{log p+ℓ}K`. The intervals are disjoint and
  lie in `(ℓ, ∞)`.

With `Σ C_π = C_0`, this gives `0 ≤ 2C_0 + E − Σ_{S_0}v_p = −0.6551 < 0`, a contradiction.

For Definition 2, add `Σ_π h_π(A(F_π), B(F_π)) = 0`: every test lies in `P_T`. ∎

**Corollary L′.1 (supersedes round-3 Theorem L). PROVED.** Scalar-share decompositions (`K_π = α_πK`) never certify
`RD_T` for `T ≥ 1.50`. Round 3 needed `T ≥ 4.70`.

**Corollary L′.2 (growth of the local defect). PROVED.** For `T ≥ 1.50`, let
`δ_loc(T) := sup_{S,ℓ}[Σ_{p∈S}v_p − 2C_0 − E(S, ℓ)]`, over admissible `(S, ℓ)`. Admissible means
`ℓ < log(1 + 1/max S)` and `log max S + ℓ ≤ 2T`, with `E(S, ℓ)` defined as `E` above. Then `δ_loc(T) ≫ e^T`.

*Proof.* Take `S` = the primes `≤ P := ⌊e^{2T−1}⌋` and `ℓ = ½log(1 + 1/P) ≍ 1/P`. Then:
* `E(S, ℓ) ≤ 2 + ⅔u_1 + 4 log(3π/2) + O(1) + 2log(1/ℓ) + O(1) + 2ℓΣ_{p≤P}K(log p − ℓ) = 2 log P + O(1)`. Here
  `K(log p − ℓ) ≪ p^{−1/2}` and `ℓΣ_{p≤P}p^{−1/2} ≪ P^{−1/2}`.
* By Chebyshev, `Σ_{p≤P} 2log p/√p ≥ c√P`.
* Hence `δ_loc(T) ≥ c√P − 2log P − O(1) ≫ e^T`. ∎

So local certification is not missed by a little. The prime demands exceed any stability-type archimedean supply by a
factor that grows like `e^T/T`.

**Remark L′.3 (blocks). PROVED as stated.** Suppose the primes are grouped into blocks `B_1, …, B_N`, each with one LK
piece. Evaluating block `B_j` at `F^{(p_j)}` for one chosen `p_j ∈ B_j ∩ S_0`, and every other label at `F^{(2)}`,
gives the same contradiction whenever `Σ_j v_{p_j} > 2C_0 + E`, with `E` computed over the representatives. The
single block containing every prime is `𝔞_T` itself, and on it the method says nothing, as it must. The theorem
therefore measures how global a certificate has to be.

## §3 Proposition M: where the archimedean factor enters; the upgraded Theorem NM(d)

**Proposition M. PROVED.** Let `(C_π, K_π)` be any LK splitting and `(F_π)_{π∈Π}` any family of real tests in
`P_T ∩ H¹_0(I_T)`, all with `‖F_π‖ = 1`. Then

  `Σ_π q_π(F_π) ≤ C_0 + ∫_0^∞ K(u) max_π ε_{F_π}(u) du + Σ_π Q_π(F_π)`,

and equality holds in the archimedean term when all the `F_π` are equal. That equal case is `𝔞_T(F)`.

*Proof.* This is (1.1) summed, followed by `Σ_π K_πε_π ≤ (Σ_π K_π) max_π ε_π`. ∎

*Reading.*
* The functional `(F_π) ↦ ∫K max_π ε_{F_π}` is monotone and sublinear, and stays bounded as the number of places grows (by Step 2 it is at most `∫K M` for the tests of §2). The
  prime functional `Σ_π Q_π(F_π)` is additive over places.
* Local certification would need the additive prime demand to be covered by the max functional. Theorem L′ shows it
  never is.
* The archimedean factor of `Λ(s) = Γ_ℝ(s)ζ(s)` is therefore spent **once**, on the joint behaviour of one test
  across all contacts. It cannot be allocated to Euler factors.
* Any proof of `λ^A_T ≥ 0` must use a constraint linking the values `c_F(log p)` for different `p` *within a single
  `F`*. Such constraints exist: `c_F` is positive definite with compact support, and `c_F(u) = c_F(0)` for `u ≠ 0` is
  impossible. **HEURISTIC:** the quantitative form of this joint constraint, uniform in `T` and exact in `Λ`, is the
  content of the zero side of the explicit formula (thm:Z, cor:RH). **EQUIV.**

**Theorem NM, clause (d′) (upgrade of round 3). PROVED.** A derivation of `RD_T(Λ)` that certifies each local form
`q_π` separately, under any LK splitting of the archimedean place, proves a false statement at every `T ≥ 1.50`. It
does not even need a varying comb: it asserts `q_π ≥ 0` for some `π` where Theorem L′ exhibits `q_π(F_π) < 0`.
Clauses (a)–(c) are unchanged from round 3.

**OPEN (P159.B8.4).** Two questions remain.
* Is Theorem L′ true on `(0.8, 1.50)`? The only obstruction to lowering the threshold is the crude bound `9π²/ℓ²` on
  the energy of a 3-mode test. A sharper `P_T`-compatible profile with an explicit energy would lower it. I claim
  nothing below `1.50`.
* Does the converse of Proposition M hold? That is: does an LK certificate exist exactly when
  `C_0 + ∫K max_π ε_{σ_π} + Σ tr(σ_pQ_p) ≥ 0` for all families of density operators? That would be a minimax duality
  in infinite dimension. It is not needed here.
