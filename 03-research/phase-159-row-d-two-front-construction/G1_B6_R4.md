## §1 Flow functionals

**Definition 1.1 (flow datum, flow functional, flow measure).** A *flow datum* is `𝔇 = (H, U, (ξ_k)_{k∈K})`. Here `U`
is a strongly continuous unitary representation of `ℝ` on a Hilbert space `H`, and `(ξ_k)` is a family of vectors
indexed by an arbitrary set. Put `U(f) := ∫f(t)U_t dt` for `f ∈ L¹`. Let `ν_ξ` be the spectral measure of `ξ`, i.e.
`⟨U_tξ, ξ⟩ = ∫e^{iτt}dν_ξ(τ)`, so that `‖U(f)ξ‖² = ∫|f̂|²dν_ξ`. The *flow functional* and the *flow measure* are

  `φ_𝔇(f) := Σ_k ‖U(f)ξ_k‖² = ∫|f̂|² dν_𝔇`, `ν_𝔇 := Σ_k ν_{ξ_k}` (a positive Borel measure, possibly infinite).

`𝔇` is **flow-finite** if `φ_𝔇(f) < ∞` for every `f ∈ C_c^∞(ℝ)`.

**Remark 1.1a (scope; `PROVED`/`CITED`).** Every positive object of the brief is a flow functional:
* A vector state is one with a single vector.
* A positive functional `ψ` on a C\*-algebra `A` with a unitary group `u_t ∈ M(A)` is one through its GNS
  representation: `ψ(u(f)^*u(f)) = ‖π_ψ(u(f))Ω_ψ‖²`.
* A positive functional on a C\*-crossed product `A ⋊_α ℝ` comes from a covariant representation `(π, U)`, and then
  `u(f) ↦ U(f)`. That correspondence is CITED, standard: Pedersen, *C\*-algebras and their automorphism groups*, 7.6;
  Williams, *Crossed products of C\*-algebras*, 2.40.
* A normal weight on a von Neumann algebra `M ∋ U_t` is a sum of normal positive functionals (Haagerup, J. Funct. Anal.
  19 (1975); CITED), and each of these is a countable sum of vector functionals in any faithful normal representation
  (Dixmier; CITED standard). This covers traces, dual weights and KMS weights.
So "a trace/state/weight on a crossed product, evaluated on the flow" is exactly a flow functional.

**Lemma 1.2 (flow-finite ⟹ tempered; `PROVED`).** If `𝔇` is flow-finite, then `ν_𝔇` is a tempered Radon measure:
there are `C, N` with `ν_𝔇([σ−1, σ+1]) ≤ C(1+|σ|)^{2N}` for all `σ ∈ ℝ`.

*Proof.*
* **Continuity.** Let `E = C_c^∞([−1,1])`, a Fréchet space with seminorms `p_j(f) = max_{i≤j}sup|f^{(i)}|`. The map
  `J : E → ⊕_k H`, `f ↦ (U(f)ξ_k)_k`, is well defined by flow-finiteness and is linear. Its graph is closed: if
  `f_n → f` in `E` and `Jf_n → y`, then `‖U(f_n − f)ξ_k‖ ≤ ‖f_n − f‖_{L¹}‖ξ_k‖ → 0`, so `y_k = U(f)ξ_k`. By the closed
  graph theorem (Fréchet → Hilbert), `‖Jf‖ ≤ C p_N(f)` for some `C, N`.
* **A test function.** Fix `f₀ ∈ C_c^∞([−½,½])`, real, even, `≥ 0`, with `∫f₀ = 1`. Then
  `f̂₀(τ) = ∫f₀(t)cos(τt)dt ≥ cos ½ > ½` for `|τ| ≤ 1`.
* **Modulation.** Put `f_σ(t) := e^{−iσt}f₀(t) ∈ E`. Then `f̂_σ(τ) = f̂₀(τ − σ)`, and by Leibniz
  `p_N(f_σ) ≤ 2^N(1+|σ|)^N p_N(f₀)`. Hence
  `ν_𝔇([σ−1,σ+1]) ≤ 4∫|f̂_σ|²dν_𝔇 = 4‖Jf_σ‖² ≤ 4C²4^N(1+|σ|)^{2N}p_N(f₀)²`. ∎

So the flow distribution `D_𝔇(h) := ∫ĥ dν_𝔇` (`h ∈ 𝒮`) is a tempered positive-definite distribution, and
`D_𝔇(c_f) = φ_𝔇(f)`. This is the Bochner–Schwartz theorem in the case needed here, proved without citation.

**Lemma 1.3 (the primitive annihilator; `PROVED`).** Let `ℐ := {F ∈ C_c^∞(ℝ) : A(F) = B(F) = 0}` (complex). If
`S ∈ 𝒟′(ℝ)` satisfies `⟨S, c_F⟩ = 0` for all `F ∈ ℐ`, then `P²S = 0`, i.e.
`S ∈ 𝒩 := span{e^{t/2}, te^{t/2}, e^{−t/2}, te^{−t/2}}`. Conversely, every element of `𝒩` annihilates `c_F` for
`F ∈ ℐ`. The only tempered element of `𝒩` is `0`.

*Proof.*
* **Polarisation.** `(F, G) ↦ ⟨S, F ⋆ G̃⟩` is sesquilinear, so it vanishes on `ℐ × ℐ`.
* **`Pk ∈ ℐ` for every `k ∈ C_c^∞`.** Integration by parts gives `A(Pk) = ∫k(−¼ + ¼)e^{t/2} = 0`, and likewise
  `B(Pk) = 0`.
* **The annihilator.** `(Pl)~ = P l̃` because `P` has real, even-order coefficients. Hence
  `Pk ⋆ (Pl)~ = P²(k ⋆ l̃)`, and `⟨P²S, k ⋆ l̃⟩ = 0` for all `k, l`. Fix `l`: then `(P²S) ⋆ l^∨` (a smooth function) is
  `0`. Letting `l` run through an approximate identity gives `P²S = 0`.
* **Solving.** The distributional solutions of the constant-coefficient equation `P²S = 0` are classical, and form
  `𝒩` (standard: a distributional solution of a constant-coefficient ODE is classical; Schwartz, *Théorie des
  distributions*, Ch. II; elementary).
* **Converse.** For `S = te^{t/2}`: `⟨te^{t/2}, F ⋆ G̃⟩ = ∫∫F(x)\overline{G(y)}(x−y)e^{(x−y)/2}`, which is a combination
  of `A(F)`, `\overline{B(G)}` and similar moments, hence `0` on `ℐ × ℐ`. The same holds for the other three.
* **Tempered elements.** Let `S = (a+ct)e^{t/2} + (b+dt)e^{−t/2} ∈ 𝒮′`. With `θ, χ` as in Lemma 2.1, `ℒ(θS)` is
  holomorphic on `Re s > 0`. But `ℒ(θS)(s) = e^{−(s−½)/2}[a/(s−½) + c(½/(s−½) + (s−½)^{−2})] + (holomorphic on
  Re s > −½)`, so `a = c = 0`. Reflection `t ↦ −t` preserves `𝒮′` and gives `b = d = 0`. ∎

## §2 Theorem Δ — the relative-trace law

**Definition 2.0 (finite split).** A *finite split* of `𝒲`, complete form, is a pair of flow-finite data `𝔇₁, 𝔇₂`
(over possibly different Hilbert spaces and flows) with

  `(RL)` `φ_{𝔇₁}(f) − φ_{𝔇₂}(f) = ⟨𝒲, c_f⟩` for all `f ∈ C_c^∞(ℝ)`.

The *primitive form* asks `(RL)` only for `f ∈ ℐ`. `𝔇₁` is the **dominant term**.

### Lemma 2.1 (Laplace criterion with explicit polar slack) — `PROVED`; content von Koch–Landau; priority G2_B9_R3 Lemma L

If `𝒲 − S ∈ 𝒮′(ℝ)` for some `S ∈ 𝒩`, then RH.

*Proof.*
* **The Laplace transform.** Let `β := 𝒲 − S`. Fix `θ ∈ C^∞`, `θ = 0` on `(−∞, 0.1]`, `θ = 1` on `[0.5, ∞)`. Fix
  `χ ∈ C^∞`, `χ = 0` on `(−∞, 0.02]`, `χ = 1` on `[0.05, ∞)`. Since `θ ∈ 𝒪_M`, `θβ ∈ 𝒮′` with support in `[0.1, ∞)`.
  For `Re s > 0`, `χe^{−s·} ∈ 𝒮`, and `s ↦ χe^{−s·}` is holomorphic into `𝒮`: its difference quotients converge in
  every seminorm, by the mean value theorem applied to `ue^{−su}`. Hence `ℒ(θβ)(s) := ⟨θβ, χe^{−s·}⟩` is holomorphic
  on `Re s > 0`.
* **The measure pairing.** On `(0.1, ∞)`, `θβ` is the locally finite measure
  `μ := θ(u)[2cosh(u/2) − ½K(u) − S(u)]du − Σ_{n≥2}(Λ(n)/√n)δ_{log n}`. Note that `θ(log n) = 1` for `n ≥ 2`, since
  `log 2 > 0.5`, and that the `δ_{−log n}`, `δ₀` and `Pf K` parts are killed by `θ`. For `σ > ½` we have
  `∫e^{−σu}d|μ| < ∞`, because `K = O(e^{−u/2})` and `ΣΛ(n)n^{−½−σ} < ∞`. For `Re s > ½`, truncating `χe^{−s·}` by
  `ϱ(u/R)` (`ϱ ∈ C_c^∞`, `0 ≤ ϱ ≤ 1`, `ϱ = 1` near `0`) gives convergence in `𝒮`, and dominated convergence gives
  `ℒ(θβ)(s) = ∫e^{−su}dμ(u)`.
* **Evaluation.** Summing,
  `ℒ(θβ)(s) = C(s) + A(s) − ℒ_S(s) + (ζ′/ζ)(½+s)` for `Re s > ½`, where:
  * `C(s) := ∫θ(u)2cosh(u/2)e^{−su}du` is meromorphic on `ℂ` with simple poles at `±½` only;
  * `A(s) := −½∫θKe^{−su}` is holomorphic on `Re s > −½`;
  * `ℒ_S(s) := ∫θSe^{−su}du` is meromorphic on `ℂ` with poles at `±½` only;
  * `−ΣΛ(n)n^{−½−s} = (ζ′/ζ)(½+s)`.
* **Continuation.** Hence `(ζ′/ζ)(½+s) = ℒ(θβ)(s) − C(s) − A(s) + ℒ_S(s)` on `Re s > ½`. The right side is
  meromorphic on `Re s > 0`, with poles at most at `s = ½`. A zero `ρ` with `Re ρ > ½` gives a pole of the left side at
  `s = ρ − ½ ≠ ½` (because `ρ ≠ 1`), which is impossible. So ζ has no zero in `Re ρ > ½`, and by the functional
  equation none in `Re ρ < ½`. ∎

(G2_B9_R3 Lemma L proves the general case `P^k(𝒲 − β) ∈ 𝒮′`. Taking `S ∈ 𝒩` explicitly avoids the commutator step
that P3 flagged there.)

### Theorem Δ — `PROVED`

Let `(𝔇₁, 𝔇₂)` be a finite split of `𝒲`, complete or primitive. Then:

*(i)* **RH holds.**

*(ii)* `ν₁ − ν₂ = μ_Z` as signed Radon measures, and `(RL)` holds for all `f ∈ C_c^∞`, even if only the primitive form
was assumed.

*(iii)* For every ordinate `γ`, `ν₁({γ}) = m_γ + ν₂({γ}) ≥ m_γ`. Equivalently,
`Σ_k‖E₁({γ})ξ_k^{(1)}‖² ≥ m_γ`, where `E₁` is the spectral measure of `U^{(1)}`. The dominant term's space contains
eigenvectors `U^{(1)}_tη = e^{iγt}η` for every ordinate.

*(iv)* `ν₁(ℝ) = ∞`. In particular `𝔇₁` is not a state, not a finite trace, and not a finite sum of vector
functionals.

*(v) (converse; EQUIV).* Under RH, a finite split exists: take `𝔇₁ = (L²(μ_Z), e^{iτt}, (1_{[j,j+1)})_{j∈ℤ})` and
`𝔇₂ = 0`.

*Proof.*
* **(i), complete form.** By Lemma 1.2, `D_i(h) := ∫ĥ dν_i` are tempered distributions. Put `β := D₁ − D₂ ∈ 𝒮′`.
  `(RL)` says `⟨β − 𝒲, c_f⟩ = 0` for all `f ∈ C_c^∞`. Polarisation gives `⟨β − 𝒲, f ⋆ g̃⟩ = 0` for all `f, g`, and the
  approximate-identity argument of Lemma 1.3 gives `β = 𝒲`. So `𝒲 ∈ 𝒮′`, and Lemma 2.1 with `S = 0` gives RH.
* **(i), primitive form.** Lemma 1.3 gives `S := 𝒲 − β ∈ 𝒩`. Then `𝒲 − S = β ∈ 𝒮′`, and Lemma 2.1 gives RH.
* **(ii).** Under RH, `𝒲 ∈ 𝒮′`, since `μ_Z` is tempered by `N(T) ≪ T log T` and `⟨𝒲, h⟩ = ∫ĥdμ_Z` (P46 `thm:Z`(ii);
  G2_B9_R3 Lemma L, converse). In the primitive case `S = 𝒲 − β` is then tempered and lies in `𝒩`, so `S = 0` by
  Lemma 1.3. In both cases `∫ĥ d(ν₁ − ν₂ − μ_Z) = 0` for all `h ∈ C_c^∞`. The set `{ĥ : h ∈ C_c^∞}` is dense in `𝒮`,
  so `ν₁ − ν₂ = μ_Z` as tempered distributions, hence as signed Radon measures (Riesz uniqueness).
* **(iii).** Evaluate (ii) at `{γ}`, and use `ν_ξ({γ}) = ‖E({γ})ξ‖²`.
* **(iv).** There are infinitely many zeros (Hadamard–de la Vallée Poussin; `N(T) → ∞`, CITED), so
  `ν₁(ℝ) ≥ Σ_γ m_γ = ∞`. A finite family of vectors has `ν(ℝ) = Σ‖ξ_k‖² < ∞`.
* **(v).** `ν_{1_{[j,j+1)}} = μ_Z|_{[j,j+1)}`, the sum is `μ_Z`, and `(RL)` is the explicit formula under RH. ∎

**Remark 2.1 (what is and is not new).** The analytic core, (i) for `𝔇₂ = 0` or for `𝔇₂` a multiple of the
Plancherel functional, is classical: Weil's criterion together with von Koch–Landau. It is on the record as G2_B9_R3
Lemma L and Thm N(i). New here:
* the arbitrary subtracted positive term;
* the conclusion (iii), that the zeros are located in the dominant term's point spectrum;
* the exclusions of §3;
* the locality law of §4.
(v) shows that the existence of a finite split is `EQUIV`, and that its construction under RH installs the zeros
(Lemma T; OT-3).

**Remark 2.2 (domination is automatic: correction of G1_B6_R1 Rem 2.3; `PROVED`).** R1 Rem 2.3 read
`φ₁∘u − φ₂∘u = W` as "RH ⟺ `φ₂ ≤ φ₁` on squares ⟺ a Radon–Nikodym contraction `h`". The equivalence is correct, but the
reading is wrong. For flow-finite terms, Theorem Δ(i) derives RH from the identity alone, and (ii) then gives
`ν₂ ≤ ν₁` on atoms and `ν₁ − ν₂ = μ_Z ≥ 0`. So the contraction `h` exists automatically. The positivity content of a
finite relative trace is zero; its content is **finiteness of both terms on the flow**. Mechanisms that produce
domination for structural reasons are therefore beside the point. The main example is the **Pimsner–Popa inequality**
`E_N(x) ≥ [M:N]^{−1}x` (Pimsner–Popa, Ann. Sci. ENS 19 (1986); CITED), which gives `τ∘E − λτ ≥ 0`. For finite
factors it is excluded by (iv), since finite traces have finite flow measure. In the semifinite case it still needs
(iii) for `τ∘E`, i.e. a Hilbert–Pólya flow.

## §3 Corollary Δ3 — unconditional exclusions of the dominant term

**Corollary Δ3 (`PROVED`, modulo the `CITED` standard theorems named in each item).** Let `(𝔇₁, 𝔇₂)` be a pair of
flow-finite data satisfying `(RL)` for ζ, complete or primitive. By Theorem Δ(i) RH holds, so by (iii) `ν₁` has an
atom of mass `≥ m_γ` at every ordinate. In particular it has atoms at `±γ₁ = ±14.134…` (P47 (X19) certifies `γ₁`; any
zero suffices). Each item exhibits a class in which `ν₁` cannot have these atoms. All conclusions are unconditional.

*(a) Atomless or mixing dominant terms, and every normal weight on a von Neumann crossed product.*
* **(a0)** If `ν₁` has no atoms, `(RL)` is impossible. This covers every `U^{(1)}` with continuous spectrum on the
  closed span of the `U(f)ξ_k`. It covers every mixing flow, since mixing matrix coefficients have atomless spectral
  measures by Wiener's lemma (CITED standard).
* **(a1)** `U^{(1)} = λ ⊗ 1` on `L²(ℝ) ⊗ 𝒦` (the regular representation with any multiplicity), for instance
  `L²(C_Q) = L²(ℝ^×_+) ⊗ L²(Ẑ^×)` with scaling. Every `ν_ξ` is `(2π)^{−1}‖ξ̂(τ)‖²_𝒦dτ` by Plancherel, which is
  absolutely continuous. Sums of such measures are absolutely continuous as long as they are locally finite.
* **(a2)** Let `M = N ⋊_σ ℝ` be any von Neumann crossed product. It acts on `L²(ℝ, H_N)`, generated by `π_σ(N)` and
  `λ_t ⊗ 1`. Take `U_t = λ_t` and any **normal** weight `ψ` on `M`. Amplify to `L²(ℝ, H_N) ⊗ ℓ²`: every normal
  positive functional is a countable sum of vector functionals there (CITED standard), and `ψ` is a sum of such
  functionals (Haagerup 1975). In that representation `λ_t` acts as `λ_t ⊗ 1 ⊗ 1`, so by (a1) the flow measure of `ψ`
  is absolutely continuous. This includes:
  * the **Takesaki core** of a III_1 factor and its **dual trace**. `τ = ω̃(h^{−1}·)` gives flow measure
  `ω(1)e^{−x}dx`, which is not even tempered, so by Lemma 1.2 `τ` is not flow-finite;
  * **Connes' foliation II_∞ factor**;
  * the core of **BC at `β ≤ 1`**;
  * **every dual weight** `ω̃`. It restricts to `2πω(1)g(0)` on `λ(g)`, i.e. to `ω(1)·Lebesgue`, which is infinite
  unless `ω` is finite.

  This is R1 Cor 5 upgraded from "no `L^p` eigenvector of the dual trace" to "no normal weight on the crossed product
  can be the dominant term of any relative Lefschetz identity".

*(b) The imprimitivity law, at the C\*-level.* Let `Y` be a locally compact space with a continuous flow `y ↦ y·t`.
Suppose `Y₀ ⊂ Y` is an open invariant subset with a continuous equivariant log-coordinate `ℓ : Y₀ → ℝ`,
`ℓ(y·t) = ℓ(y) + t`. Let `(π, U)` be any covariant representation of `(C_0(Y), ℝ)`, and put
`H₀ := [π(C_0(Y₀))H]`. This covers every positive functional on `C_0(Y) ⋊ ℝ`, normal or not, through its GNS
covariant representation. Then:
* `U|_{H₀}` is a multiple of the regular representation;
* every vector of `H₀` has an absolutely continuous spectral measure;
* atoms of the flow can live only on `H₀^⊥`, the part carried by `Y ∖ Y₀`.

*Proof.* `C_0(Y₀)` is an invariant ideal of `C_0(Y)`, and `π|_{C_0(Y₀)}` is nondegenerate on `H₀`, so it extends to
the multiplier algebra `C_b(Y₀)` (CITED standard). For `g ∈ C_0(ℝ)`, `g∘ℓ ∈ C_b(Y₀)`, and `g ↦ π̄(g∘ℓ)` is a
representation of `C_0(ℝ)` on `H₀`. It is nondegenerate: for `f ∈ C_c(Y₀)` the set `ℓ(supp f)` is compact, and
`g = 1` there gives `(g∘ℓ)f = f`, so `π̄(g∘ℓ)π(f)ξ = π(f)ξ`, and these vectors are dense in `H₀`. Its covariance under
`U` is translation, since `ℓ` is equivariant. By the spectral theorem this gives a unitary group `V_s` on `H₀` with
`U_tV_sU_t^* = e^{−ist}V_s`. By the Stone–von Neumann theorem (CITED standard; Mackey imprimitivity for `ℝ`), the pair
is a multiple of the Schrödinger pair, in which `U` is translation. Then apply (a1). ∎

*Application.* `Y = C_Q` with `ℓ = log|·|`, which is continuous on the idele class group in its own topology. So
every covariant representation of `C_0(C_Q) ⋊ ℝ^×_+` has Lebesgue flow spectrum. This covers CC's `Tr_Y`, `L²(C_Q)`,
and Connes' `δ = 0` Hilbert space `L²(X)`, which is realised on `C_Q` through `f ↦ Σ_q f(qx)` (R158_002 §2.3). None of
these can be the dominant term. (Connes' `L²_δ`, `δ > 1`, has a non-unitary, polynomially bounded flow. It is outside
Def 1.1: it is a Banach translation carrier of R3's class, excluded there by Cor D1.) In CC's picture, therefore, the zeros can be atoms only of a representation carried by the
**complement** of the idele class group in the adèle class space. This matches Connes' cokernel picture, and it is
now a theorem about positive functionals. *Caveat (`PROVED` negative):* the idele norm is not continuous on any
nonempty open subset of `A_Q` (a neighbourhood of any adèle contains adèles with `x_p ∈ pZ_p` for some large `p`),
so (b) does **not** apply to `C_0(A_Q) ⋊ (Q^× × ℝ^×_+)`. That algebra is where the only escape at the C\*-level lies
(§5.3).

*(c) Bost–Connes Hamiltonian at every `β`, and Proposition K.*

**Proposition K (the zeros live at `β = 0`; `PROVED`).** Let `H` be self-adjoint on `ℋ`, `U_t = e^{itH}`, and let
`N_H(B) := Tr(1_B(H)) ∈ [0,∞]` be the spectral multiplicity measure. Let `𝔇₁` be the KMS_β weight `Tr(e^{−βH}·)` of
`Ad U` on `B(ℋ)`. Every normal KMS_β weight of an inner flow on a type I factor has this form (CITED standard). Its
flow measure is `ν₁ = e^{−βλ}dN_H(λ)`. If `(𝔇₁, 𝔇₂)` satisfies `(RL)` for ζ, complete or primitive, then `β = 0` and
`N_H({γ}) ≥ m_γ` for all ordinates. So `H` is a Hilbert–Pólya operator and `𝔇₁` is its trace.

*Proof.* By Theorem Δ, RH holds and `ν₁({γ}) ≥ m_γ ≥ 1` for every ordinate. Since `ν₁` is a multiple of `N_H` on
atoms, `N_H({γ}) ≥ 1`, and `N_H` takes integer values on atoms. The ordinates are symmetric, `γ ↦ −γ`, and unbounded.
If `β > 0`, then `ν₁({−γ}) ≥ e^{βγ}` for every positive ordinate `γ`. So `ν₁([−γ−1, −γ+1]) ≥ e^{βγ}` along an unbounded
sequence, which contradicts Lemma 1.2 (`ν₁` tempered). The case `β < 0` is symmetric. Hence `β = 0`, and
`N_H({γ}) = ν₁({γ}) ≥ m_γ`. ∎

*BC.* The BC Hamiltonian is `H ε_n = (log n)ε_n` on `ℓ²(ℕ)`. For `β > 1` the Gibbs states `Tr(e^{−βH}π_u(·))/ζ(β)`
(CITED, Bost–Connes 1995) have flow measure supported in `log ℕ ⊂ [0, ∞)`, and so do the KMS weights at any `β`
(Prop K). There is no atom at `−γ₁ < 0`, so they are excluded, in every representation `π_u` and with every subtracted
term. At `β ≤ 1`, the only implementation of the flow is the core, which is excluded by (a2). This extends R1 Prop 6,
which had `𝔇₂ = 0`.

*(d) States and finite traces.* These are excluded by Theorem Δ(iv). This covers II_1 factors, finite-index
Pimsner–Popa pairs with finite trace, BC Gibbs states, and every KMS state. It also re-proves R1 Thm 1(a) with an
arbitrary subtracted term.

*(e) CC's relative trace.* If `Tr_X` and `Tr_Y` are traces of representations whose flow measures are absolutely
continuous, then they cannot both be flow-finite with `Tr_X − Tr_Y = 𝒲`, because by (ii) `ν_X − ν_Y = μ_Z` would have
atoms. More generally the dominant one must have pure point flow spectrum `⊇` the zeros. Consequently:
* in every Lebesgue-class realisation, the identity CC state "(after a cut-off)" is necessarily **∞ − ∞**, unconditionally;
* the divergent `log Λ·f(1)` term (their [17] Thm 2.36) cannot be eliminated by any choice of finite positive traces
  that are both absolutely continuous on the flow;
* eliminating it with finite positive traces is equivalent to RH together with a Hilbert–Pólya dominant trace.

CC's step 2 intends an intersection-theoretic regularisation, and that is not a positive functional. It is not
refuted here. What is shown is that "remove the divergence" and "give the dominant trace pure point spectrum on the
zeros" are the same task in any positive-trace formulation.

## §4 Theorem Λ — the locality law: the relative-trace shape is void at every finite level

Call `𝒱 ∈ 𝒟′(ℝ)` *hermitian* if `⟨𝒱, h̃⟩ = \overline{⟨𝒱, h⟩}`.

**Theorem Λ (`PROVED`).** Let `𝒱` be any hermitian distribution. This includes `𝒲`, and also the Weil distributions of
`Ξ_a`, `Ξ_Q`, of an Epstein ζ with off-line zeros, and of a Beurling system with an off-line zero, which are false
data.

*(1) Windowed splits always exist.* For every `T > 0` there are flow-finite data `𝔇₁^T, 𝔇₂^T` such that `φ_{𝔇₁^T}(f) − φ_{𝔇₂^T}(f) = ⟨𝒱, c_f⟩` for all `f ∈ C_c^∞(I_T)`.

*(2) Regularised splits always exist.* There are finite-mass flow data `𝔇_i^Λ`, `Λ → ∞`, with
`φ_{𝔇₁^Λ} − φ_{𝔇₂^Λ} → 𝒱` in the sense `⟨·, c_f⟩ → ⟨𝒱, c_f⟩` for every `f ∈ C_c^∞`. A counterterm `c(Λ)δ₀`, as in
Connes' `2 log Λ f(1)`, may be added at no cost.

*(3) Stagewise positivity is RH.* For `𝒱 = 𝒲`, a regularisation as in (2) with `φ_{𝔇₁^Λ} − φ_{𝔇₂^Λ}` positive-definite
for every `Λ` exists iff RH. This is `EQUIV`, and it is E1 (Weil's criterion window by window) in operator form.

*Proof.*
* **(1).** Pick `ϱ ∈ C_c^∞`, real and even, with `ϱ = 1` on `[−2T, 2T]`. Then `E := ϱ𝒱 ∈ ℰ′` is hermitian.
  * By Paley–Wiener–Schwartz (CITED standard), `Ê` is smooth and `|Ê(τ)| ≤ C(1+|τ|)^M`. Hermitian symmetry makes it
  real.
  * Put `ν_± := (2π)^{−1}(Ê(−τ))_±dτ`. These are positive tempered measures, and by Fourier inversion on `ℰ′`,
  `∫ĥ d(ν₊ − ν₋) = ⟨E, h⟩` for `h ∈ C_c^∞`.
  * Realise `ν_±` as the data `(L²(ν_±), e^{iτt}·, (1_{[j,j+1)})_{j∈ℤ})`. They are flow-finite because the measures
  are tempered.
  * For `f ∈ C_c^∞(I_T)` we have `supp c_f ⊂ (−2T, 2T)`, so `⟨E, c_f⟩ = ⟨𝒱, c_f⟩`.

  Finite total mass is not claimed in (1). In general `Ê` is not integrable.
* **(2).** Put `𝒱_Λ := (ϱ(·/Λ)𝒱) ⋆ η_{1/Λ} ∈ C_c^∞`, with `ϱ, η ∈ C_c^∞` real and even, `ϱ(0) = 1`, `∫η = 1`. Then
  `𝒱_Λ` is hermitian and `𝒱_Λ → 𝒱` in `𝒟′` (CITED standard). `\widehat{𝒱_Λ}` is real and Schwartz, so
  `ν_±^Λ := (2π)^{−1}(\widehat{𝒱_Λ}(−τ))_±dτ` are **finite** positive measures, and `𝒱_Λ = D_{ν₊^Λ} − D_{ν₋^Λ}`. Realise
  them as single-vector data `(L²(ν_±^Λ), e^{iτt}, 1)`: vector states, up to scale. Adding `c(Λ)δ₀` means adding
  `c(Λ)(2π)^{−1}dτ`, a Plancherel functional, to the appropriate side.
* **(3).** (⟸) Under RH take `ϱ = σ ⋆ σ̃` (so `ϱ̂ = |σ̂|² ≥ 0`) and `η = κ ⋆ κ̃`, normalised. Then
  `\widehat{𝒱_Λ} = (μ_Z ∗ ϱ̂_Λ)·η̂_{1/Λ}/(2π)`, a product of nonnegative factors, so `ν₋^Λ = 0` for every `Λ`.
  (⟹) Stagewise positive-definiteness passes to the limit: `⟨𝒲, c_f⟩ = lim⟨𝒱_Λ, c_f⟩ ≥ 0` for all `f`, which is
  Weil's criterion (P46 l.140–146), hence RH. ∎

*Reading (`PROVED` + `HEURISTIC`).* (1) and (2) hold for false data, so they contain no information. (3) holds only
for true data, and it is Weil's criterion. So the relative-trace shape converts exactly into the reduced statement:
decidable and void at each finite level (`prop:finite`, `thm:margin`), and RH at the global level. Theorem Δ says what
the global level costs in operator algebra: finite positive terms, with the dominant one Hilbert–Pólya.

### 5.2 The BC modular flow (`OPEN`; the one BC structure not excluded)

For `β > 1` the GNS space of the Gibbs state `ω_β` sits inside the Hilbert–Schmidt operators on `ℓ²(ℕ)`. The modular

Cor Δ3(a2) needs normality. On `C*(λ) ≅ C_0(ℝ̂) ⊂ N ⋊ ℝ`, a non-normal state can restrict to any finite measure, for

is exactly the non-commutative part of the adèle class space, and it is where CC and Connes place the zeros. **This
is the precise location of the only escape, and I have no candidate there.**

## §7 What is genuinely new

1. **Theorem Δ(iii) and (iv).** In any relative Lefschetz identity for ζ with finite positive terms, whatever the
  subtracted term, the dominant term's flow has point spectrum containing every zero with multiplicity, and infinite
  mass. The analytic core, (i), is von Koch–Landau via G2_B9_R3 Lemma L. That priority is acknowledged, and Lemma 2.1
  gives a self-contained proof with explicit polar slack.
2. **Rem 2.2.** Domination of the subtracted term is automatic. This corrects the reading of G1_B6_R1 Rem 2.3, and
  makes the Pimsner–Popa / Radon–Nikodym mechanisms superfluous.
3. **Cor Δ3.** These are unconditional exclusions of the dominant term:
  * every normal weight on every von Neumann crossed product by `ℝ`, on the canonical unitaries;
  * every covariant representation over a space with an equivariant log-coordinate (Stone–von Neumann), in
  particular everything over `C_Q`;
  * the BC Hamiltonian at every `β`, and every type I KMS weight at `β ≠ 0` (Prop K, "the zeros live at `β = 0`");
  * every state.

  Together these upgrade R158_004 row 17(iii) from RESTATEMENT to a proved exclusion for finite realisations. They
  also show that CC's `log Λ` divergence is necessary in every Lebesgue-class realisation.
4. **Theorem Λ.** The relative-trace shape is void at every finite window and after every regularisation, and it is
  E1 under stagewise positivity.
5. **Localisation of the only escapes.** One is the non-normal part of `N ⋊ ℝ`, whose C\*-analogue is
  `C_0(A_Q) ⋊ (Q^× × ℝ^×_+)`, where the idele norm is nowhere continuous. The other is the BC modular flow, which
  needs `(BC-mod)`, a transcendence condition. Both are `OPEN`, and neither has a candidate that does not install the
  zeros.

Not new: Weil's criterion; von Koch–Landau; Bochner–Schwartz (re-proved in the needed case); Stone–von Neumann;
Haagerup's sum theorem; Pimsner–Popa; Lemma T.

## §8 The weakest step

* **The mass distinction in Theorem Λ.** Windowed splits are by **flow-finite** data (exact on the window) and
  regularised splits by **finite-mass** data (in the limit). A compactly supported distribution has, in general, a
  polynomially bounded Fourier transform that is not integrable, so finite mass is not available exactly on a window.
  §5–§6 use only "void", so the distinction is not load-bearing.
* **Scope of "flow functional".** Everything that is a positive functional or normal weight is covered (Rem 1.1a).
  Objects that are **not positive**, such as `Tr(R_Λ U(f))` with `R_Λ = P̂_ΛP_Λ` non-positive, or CC's intended
  intersection-theoretic regularisation, are outside Theorem Δ. They are covered only by Theorem Λ(2), as regularised
  shapes. So CC's programme is not refuted. What is shown is that its positive-trace version is either Hilbert–Pólya
  or void.
