## §0 How the lens was applied

For a candidate *mechanism* (a proof of `∀T λ ≥ 0`), the test asks at which line the argument uses an input that
`Ξ_a` / `Ξ_Q` / DMV / `ζ·E` lacks. If there is no such line, the argument proves a false statement, so it is refuted.

For a candidate *obstruction* (a no-go theorem), the lens is used in reverse. Two checks:
- (a) The obstruction must not exclude a true derivation. For example, it must not "exclude" Weil's own implication
  RH ⟹ `W_T ≥ 0` for `ζ`, since that would show the obstruction is over-stated.
- (b) Every negativity it claims for a falsifier must be really proved.

Check (a) was a real risk for B3 (Cor D lists "every statement about the zeros in the strip") and for B7 (Thm C,
"RH-type bounds for ζ_θ"). Both pass (§3, §7).

## §7 G2_B7_R1 — Bohr–Jessen / Kronecker twist torus

**Checks.**
- **Thm A.** Jensen for the concave `V_T` (`lem:degen`), with `∫v^θ dμ = 0`. VERIFIED. It strengthens B3's Thm A from
  an infimum to a mean.
- **Thm B.** Audited step by step, as the memo asked.
  - *Step 0.* `c_{F_T}(u)/‖F_T‖² = r_T(u/T)`, after the substitution `s = Tτ`. Correct.
  - *Step 1.* `1 − r_T(x) ≤ x²M/2` and `K ≤ 1/u + ½` on `(0, 1]`. Correct.
  - *Step 4, lower bound.* With `y = e^{x_0T_j/2}`, primes in `(y, y²]` have `log p/T_j ∈ (x_0/2, x_0]`, so
  `r ≥ ½`. Then `s_j² ≥ ½ log y·(log y + O(1)) ≍ T_j²`. This needs `T_j/T_{j−1} = 2^{2j−1} ≥ 4/x_0`, which holds
  for large `j`.
  - *Step 4, upper bound.* Orthogonality of the distinct `(p, k)` gives `E R_j² ≤ C T²_{j−1} + C′`. Note that `R_j`
  contains prime powers of primes in `B_j`, so it is *not* independent of `Y_j`. The proof never needs that: it
  handles `D_j` by a union bound. Correct.
  - *Step 5.* The events `A_j` are independent, since they depend on disjoint coordinates. Berry–Esseen for
  non-identical bounded summands gives `C·1.48/s_j`, and `Φ(1) ≈ 0.841 < 0.85`. Chebyshev gives
  `T²_{j−1}/T_j² = 4^{−(2j−1)}`, which is summable. Correct.
  - *Step 6.* Borel–Cantelli II on the independent `Y_j`, then Borel–Cantelli I on `R_j`. Correct.
  - **VERIFIED:** `liminf λ^θ_T/T ≤ −c` a.s.
- **Thm C** (Wintner–Kolmogorov). VERIFIED. It is classical in substance and correctly applied.

**Falsifier run, reverse check (a).** Thm C says a.e. `ζ_θ` is zero-free in `Re s > ½`, and Thm B says its twisted form
with `ζ`'s `m` is negative. Is this a contradiction with Weil? No:

**Verdict: EXCLUDED** (the mechanism class is closed by Thms A and B). The results are PROVED and audited.
