## 2. The falsifier runs (Lens 5)

The question is whether the argument, run on a falsifier, would prove a positivity that is false there.

**(a) `ζ·E`, the modified combs of `thm:finmod` / `𝒞_zeros`.** These are the falsifiers that decide the verdict.
* Deletion `a = Λ1_{n≥N}`. The Schur entries are nonnegative and pointwise `≤` those of Λ, so Lemma S and Prop. P hold
  verbatim. By `thm:finmod`(i), `RD_T(a)` fails for `0.60 ≤ T ≤ ½log N`. So the argument proves positivity on `ℛ_M`
  for a comb that is negative on those windows (PROVED).
* Amplification `a = Λ + c1_{n=n_0}`. Each Schur row sum grows by at most `c(1 + 1/n_0)` (entries at `m/k = n_0` give
  `c`, entries at `k/m = n_0` give `c/n_0`). Prop. P therefore holds with `K ≥ K_0e^{O(c)}`, while by `thm:finmod`(ii)
  `RD_T(a)` fails for `c > c_*(T, n_0)` (PROVED).
* Consequence. Positivity on `∪_M ℛ_M` is a property of the whole class `𝒞_zeros`, which is closed under both
  operations. By `cor:void`, a derivation whose load-bearing prime input is only what Prop. P uses cannot yield
  `RD_T` at any `T > ½log 2`. This is not a refutation, because Prop. P asserts nothing outside `ℛ_M`. It is the
  exclusion: **the falsifier `ζ·E` passes every step of the argument and is still negative on a window, so the
  argument cannot be the "∀T" arrow.**

**(b) Dedekind `ζ_K` and Beurling/DMV–Zhang systems (T1, F4).** The input the memo calls "F1, exact values", namely
`Λ∗1 = log`, is **not specific to ζ**. It is the identity `Λ_𝒫 ∗ 1 = log` that holds for *every* Euler product: every
Dedekind zeta with `log N𝔞`, and every Beurling system with `log n_𝒫`. The memo concedes the field-uniform case in
§5.
* Beurling case (HEURISTIC; the transposition is not written out in full). The Beurling integers up to `M` form a
  finite set, so they have a positive minimal log-gap `δ_M`. Choose `ε < δ_M/4` in place of `1/(8M)` and weight the
  Schur test by `n_𝒫^{−½}`. Lemma S then reads `Σ_{d|m}Λ_𝒫(d) = log m`, together with the Beurling Mertens bound. That
  bound holds for DMV/Zhang systems, which satisfy `N(x) = ax + O(x^θ)` with `θ < 1`. Shrinking `ε` only enlarges the
  archimedean budget `log(1/ε)`. So the Beurling analogue of Prop. P holds for DMV/Zhang systems, which have zeros off
  the line.
* The consequence is the same as in (a): the argument is β-blind (O2/F4). It gives no false *window* sign, but it
  cannot separate ζ from DMV.

**(c) `Ξ_a = ξ(s+a)ξ(s−a)`, `0 < a < ½` real.** The comb is `Λ(n)(n^a + n^{−a})` (with the matching normalisation of
`v_n`). The archimedean symbol is a shifted digamma, still `~ log|τ|`.
* Lemma S fails. The divisor row sum is `Σ_{d|m}Λ(d)(d^a + d^{−a}) ≍ m^a log m`, which is far above the budget
  `log(1/ε) ≈ log M + log log M`. Prop. P therefore does **not** transfer, and the argument asserts no positivity for
  `Ξ_a`.
* On the destructive side, Theorem D (with the shifted `m`, same proof) gives
  `G_M ≥ (2/H(M))Σ_{n≤√M}Λ(n)n^{a−1}·½log M ≫ M^{a/2}`, which exceeds `log 8M + C`. So `Ξ_a` is **not ∀T-positive**. This
  is correct, since `Ξ_a` has zeros at `ρ ± a` off the line (HEURISTIC in the constant for the shifted `m`; the
  structure is PROVED).
* The negative half of the memo detects this falsifier correctly. That is a point in its favour, but it is a
  necessary-condition result, not a mechanism.

**(d) Epstein `Ξ_Q`, class number `> 1` (T2).** Epstein zeta has no Euler product, so there is no `Λ_Q ∗ 1 = log`
identity. The coefficients of `−Z_Q′/Z_Q` have no sign and no support on prime powers. Lemma S does not apply, and the
memo asserts nothing for `Ξ_Q`. Whether `Ξ_Q` is negative on some `ℛ_M` is OPEN, and it is not load-bearing. No false
positivity arises.

**Falsifier summary.** No falsifier receives a false positivity from the argument, so the candidate is not refuted.
But `ζ·E` (and, heuristically, DMV) satisfies every hypothesis Prop. P uses while failing `RD_T` on some window.
That is precisely the signature `cor:void` excludes. **Fatal for the mechanism: the positivity is inherited by the
falsifier `ζ·E` of `thm:finmod`, so it separates nothing.**

## 3. Other filters

* **O3 (`rem:resweights`).** The gap in Prop. P is `log(8K(2+log M)) − O(1)`, which is insensitive to `O(1)` changes in
  a single weight, let alone changes of size `e^{−14.4T}`. That is an estimate with slack, not an exact identity at
  resolution `e^{−14.4T}`, so O3 is failed as a mechanism (PROVED by the same computation as (a)).
* **thm:arena / thm:finZ.** `ℛ_M` is a finite-dimensional compression of `P_T`, and it does not contain the
  near-minimisers (consistent with `thm:margin`). No zero set is used. Nothing is violated, and nothing is gained.
* **Premise 3 (prime side).** Satisfied.

## 4. Salvageable ideas

1. **Lemma R** (PROVED) is a clean exact transfer. On the resonators, the window form becomes the multiplicative
  Toeplitz matrix `(log(1/ε)+O(1))I − (𝕄_a+𝕄_a^⊤)`. It makes GCD-sum and resonance technology available as a
  *falsifier generator*. Theorem R and Cor. R1 give an unconditional spread-mass analogue of `rem:resweights` that needs
  neither `thm:margin` nor the OPEN non-degeneracy hypothesis. This is worth recording.
2. **Thm D / Cor. D1** is a necessary condition. It correctly rejects `Ξ_a` (§2(c)) and all dense or Cramér models. It
  is a useful test to run first on any future candidate comb.
3. **Thm T** (the T-free symbol `S_s` for analytically structured combs) generalises `prop:finsupp`. It is a correct
  and quick way to dispose of any "structured part carries the positivity" proposal. By Cor. T2 every such proposal is
  EQUIVALENT to RH.
