  Bochner–Schwartz).

BRS conventions: `f̂_B(ξ) = ∫f(x)e^{−2πixξ}dx`. For an even `V`, `V̂(u) = f̂_B(u/2π)` with `f = V`. Hence
`V̂(±½log m) = V̂_B(log m/4π)`, and in particular `V̂(±log n) = V̂_B(log n²/4π)`. **The Weil nodes `±log n` are the BRS

`Z_on := {γ ∈ ℝ : ζ(½+iγ) = 0}`, with `m(γ)` the multiplicity. This set is closed, discrete and symmetric, and
`0 ∉ Z_on` because `ζ(½) ≠ 0`. It is defined without RH.

**BRS Theorem 1.1 (CITED, unconditional; statement re-read from the PDF).** There are even entire functions `U_n`
(`n ≥ 1`) and `V_{ρ,j}` (`ρ` a nontrivial zero with `γ > 0`, `0 ≤ j < m(ρ)`). They are *rapidly decaying*:
`h(x+iy) ≪_{y,l}(1+|x|)^{−l}` for every real `y` and every `l`. They satisfy
```
U_n^{(j)}((ρ′−½)/i) = 0, Û_{n,B}(log n′/4π) = δ_{n,n′},
V_{ρ,j}^{(j′)}((ρ′−½)/i) = δ_{(ρ,j),(ρ′,j′)}, V̂_{ρ,j,B}(log n/4π) = 0 for all n ≥ 1,
```

together with the expansion (1.2) for even `f ∈ H_1`. For `ρ = ½+iγ` on the line, the node `(ρ−½)/i` is the real point

**Lemma S (the BRS functions are Schwartz on ℝ). CITED + PROVED.** `V_{ρ,j}|_ℝ ∈ 𝒮(ℝ)` and `U_n|_ℝ ∈ 𝒮(ℝ)`.

The uniformity in `y` is read off BRS's construction and is not stated in their definition. This is the one point where

## §2 Theorem P: no pure prime–zero Fourier pair

**Theorem P. PROVED (from CITED BRS Thm 1.1 and Lemma S); unconditional.** Let
```
σ = Σ_{m≥1} s_m (δ_{½log m} + δ_{−½log m}), s_m ∈ ℂ,
```
be a tempered distribution. It is automatically an even measure of order 0, because the points `±½log m` are locally
finite. Suppose `σ̂` is supported in `Z_on` and, near each `γ ∈ Z_on`, has the form `Σ_{j<m(γ)} A_{γ,j} δ^{(j)}_γ`. For
simple zeros this means `σ̂ = Σ_γ A_γ δ_γ`, an atomic measure with arbitrary complex weights. Then `σ = 0`.

*Proof.*
1. *Local form.* A distribution supported on a closed discrete set is, near each point, a finite combination of
  derivatives of `δ`. The hypothesis fixes the order to be `< m(γ)`. Hence for `ψ ∈ C_c^∞`,
  `⟨σ̂, ψ⟩ = Σ_{γ∈Z_on∩supp ψ} Σ_{j<m(γ)} A_{γ,j}(−1)^jψ^{(j)}(γ)`, a finite sum.
2. *Evenness.* Reflection sends `δ^{(j)}_γ` to `(−1)^jδ^{(j)}_{−γ}`. Since `σ` is even, `σ̂` is even, so
  `A_{−γ,j} = (−1)^jA_{γ,j}`.
3. *Pairing with `V := V_{ρ,j}`, `ρ = ½+iγ_0`, `γ_0 > 0`.* By Lemma S, `V ∈ 𝒮`, so `⟨σ̂, V⟩ = ⟨σ, V̂⟩`.
  * *Comb side.* Let `χ_R := χ(·/R)` with `χ ∈ C_c^∞`, `χ = 1` on `[−1,1]`. Then `V̂χ_R → V̂` in `𝒮`, and
  `⟨σ, V̂χ_R⟩ = Σ_m s_m[(V̂χ_R)(½log m) + (V̂χ_R)(−½log m)]`, a finite sum. Every term vanishes, because
  `V̂(±½log m) = V̂_B(log m/4π) = 0` for all `m ≥ 1` (evenness of `V̂` handles the minus sign). So `⟨σ, V̂⟩ = 0`.
  * *Zero side.* `⟨σ̂, V⟩ = lim_R ⟨σ̂, Vχ_R⟩`. At any `γ ∈ Z_on` with `γ ≠ ±γ_0`, Leibniz gives
  `(Vχ_R)^{(i)}(γ) = Σ_{k≤i} C(i,k) V^{(k)}(γ)χ_R^{(i−k)}(γ)`. For `i < m(γ)`, every `V^{(k)}(γ)` with `k ≤ i` vanishes
  by the interpolation property (for `γ < 0`, by evenness of `V`). So these points contribute `0` for every `R`.
  For `R > |γ_0|`, `χ_R ≡ 1` near `±γ_0`, and `V^{(i)}(γ_0) = δ_{ij}` for `i < m(γ_0)`. With step 2 and
  `V^{(i)}(−γ_0) = (−1)^iV^{(i)}(γ_0)`, the contribution is
  `(−1)^j A_{γ_0,j} + (−1)^j A_{−γ_0,j}(−1)^j = (−1)^j(A_{γ_0,j} + A_{γ_0,j}) = 2(−1)^jA_{γ_0,j}`.
  * Hence `A_{γ_0,j} = 0`.
4. Step 3 covers all `γ_0 > 0` in `Z_on` and all `j < m(γ_0)`. Step 2 then covers `γ_0 < 0`, and `0 ∉ Z_on`. So all
  `A_{γ,j} = 0`, which gives `σ̂ = 0` and `σ = 0`. ∎

Remark 2.2 (the proof uses only the `V`'s). The functions `U_n` were not needed. Only the biorthogonality of
`{V_{ρ,j}}` against *all* frequency nodes and *all* zero nodes other than their own was used. The zeros *off* the line
(if any) do not enter: their nodes are not real, and `σ̂` lives on `ℝ`. This is why the theorem is unconditional.

**2.3 Consistency checks (PROVED).**
* *BRS §2.5.* The crystalline measures `μ_x := δ_x − Σ_{ρ,j}(…)V_{ρ,j}(x)δ^{(j)}_{γ}` have Fourier transform carried by
  the frequency nodes. Their `r`-side support is `Z_on ∪ {x}`, which is not inside `Z_on`, so Theorem P does not apply.
  For `x = γ_0 ∈ Z_on` the interpolation properties make `μ_{γ_0} = 0`, exactly as Theorem P demands. This is BRS's
  sharpness ("breaks down if one removes any single point") read on the measure side: `Z_on` carries no pair, and
  `Z_on ∪ {x}` does.
* *Weil's formula, BRS §4.4.* The Weil functional `W` has BRS coordinates `W U_{n²} = π^{−1}Λ(n)/n^{1/2}`, `W U_m = 0`
  for non-square `m`, and `W V_{ρ,0} = 2`. So `W` equals (zero sum) + (comb at the squares), and it is not zero. In
  distributional terms, `û_Λ − 2πμ_Λ = 0` holds under RH only because `u_Λ` contains `k_∞ + 2cosh(u/2)`, which is not a
  comb. Theorem P says this is no accident: without the archimedean term, the pair is zero.
* *Poisson on `ℤ log 2`.* `σ = Σ_{k∈ℤ}δ_{k log 2}` is carried by `±log ℕ ∪ {0}`. Its transform
  `(2π/log 2)Σ_mδ_{2πm/log 2}` charges `0 ∉ Z_on`, so the hypothesis of Theorem P fails, as it must.

**2.4 Extensions (PROVED as stated).** (i) `σ` may be complex-weighted. (ii) An atom at `0` is allowed (`m = 1`).
(iii) The odd case follows in the same way from the odd BRS formula. BRS §5.1 says it "extends painlessly"; this is
CITED and not re-derived, and it is not needed, because every comb in row D is even. (iv) The same proof, with
BRS §5.1–5.3 in place of Thm 1.1, gives the analogue for even primitive Dirichlet `L`-functions and for the Dirichlet
series with functional equation covered in BRS §5.3 (CITED). **That class contains functions with zeros off the line**
(Doc 101 §5.3). This is the β-blindness recorded in §5.

## §3 Corollaries for the question

**Corollary P1 (zero universes, rigid side). PROVED.** Let `M ⊆ Z_on` be any sub-multiset: finite, obtained by
random thinning (e.g. the "100 random zeros", or a Bernoulli thinning as in G2_B6_R2 Prop T), or all of `Z_on`.
No nonzero even tempered comb `σ` on `±log ℕ` (or on `±½log ℕ`) has `σ̂` an atomic measure carried by `M`.
*Proof.* Such a `σ̂` is carried by `Z_on` with order `0 < m(γ)`, so Theorem P applies. (For finite `M` there is also
the elementary reason that `σ` would be a nonzero trigonometric polynomial, whose support is all of `ℝ`.) ∎

*Reading.* In rounds 1–3 the probe asked which infinite structure repairs a finite universe *on the positivity side*,
and the answer was density plus reality (Prop D). On the rigid side the answer is sharper: **no universe, finite or
infinite, is dual to the primes alone.** The Fourier partner of the zeros is always `k_∞ + 2cosh(u/2) − β_Λ`, and the
archimedean and polar term cannot be removed or replaced by a comb.

**Corollary P2 (uniqueness of the explicit formula). PROVED, unconditional (uses B9's Lemma L with the panel's
step-2 patch).** Let `a` be a real comb with `β_a − β_Λ ∈ 𝒮′`. Suppose `u_a ∈ 𝒮′` and `û_a = Σ_{γ∈Z_on} c_γδ_γ` with
arbitrary real weights `c_γ`, with no assumption on sign, integrality or growth beyond temperedness. Then RH holds,
`a = Λ`, and `c_γ = 2πm_γ`.
*Proof.* `u_Λ = u_a + (β_a − β_Λ)` is tempered, so RH holds by Lemma L (`k = 0`). Under RH, `û_Λ = 2πμ_Λ`. The
difference `σ := β_a − β_Λ = u_Λ − u_a` is an even tempered comb on `±log ℕ`, and its transform
`σ̂ = 2πμ_Λ − û_a = Σ_γ(2πm_γ − c_γ)δ_γ` is an atomic measure carried by `Z_on`. Theorem P gives `σ = 0`. ∎

*Reading (the answer to the task's last question).* The explicit formula has three parts: the archimedean term, the
polar term `2cosh(u/2)`, and a comb, with its spectrum on the ordinates. Once the first two are fixed, the ordinates
alone, with *any* weights, determine the prime weights `Λ(n)` uniquely and force the weights to be the multiplicities.
**The "sequence equation" is the explicit formula and nothing else.** This is not Hadamard's theorem: Hadamard needs
integer multiplicities (a divisor) and a growth class, and Hamburger needs a functional equation. Corollary P2 needs
neither, and uses the additive structure of `ℕ` through BRS.

## §4 B9's Theorem R(iv) and Remark 3.4: what is now closed and what is open

Setting: `a = Λ + b` with `β_b ∈ 𝒮′`. If `a ∈ 𝒮^W`, then RH holds (B9 Theorem N(i), complete form), so we may assume RH.
Then `u_a` is positive definite, `ν_a := û_a ≥ 0` is a tempered measure (Bochner–Schwartz), and
```
D_b = 2πμ_Λ − ν_a (a real, even, locally finite measure). (4.1)
```
B9 R2 Thm R(iv): `a ∈ 𝒮^W ⟺ D_b ≤ 2πμ_Λ`.

**Lemma G (one-signed spectral gap; classical, PROVED).** Let `D` be a real tempered measure whose inverse transform
vanishes on `(−c, c)`, `c > 0`. If `D ≥ 0` or `D ≤ 0`, then `D = 0`.
*Proof.* Take `ψ ∈ C_c^∞(−c/2, c/2)`. Then `ψ⋆ψ̃` is supported in `(−c,c)`, so `0 = ⟨D, 𝓕^{−1}(ψ⋆ψ̃)⟩ = κ∫|ψ̌|²dD`,
with `κ > 0` a normalisation constant. So `|D|` is carried by the discrete zero set of the entire function `ψ̌`. For any
`r_0`, the choice `ψ = ψ_0e^{−ir_0u}` with `ψ_0 ≥ 0` gives `ψ̌(r_0) = ∫ψ_0 ≠ 0`, so `|D|` vanishes near `r_0`. ∎

**Corollary P3 (three cases closed). PROVED (complete form).** Under the setting above, `b = 0` in each case:
* **(A) `ν_a ≥ 2πμ_Λ`.** Then `D_b ≤ 0`, and `β_b = 𝓕^{−1}D_b` vanishes on `(−log 2, log 2)`. Lemma G applies.
* **(B) `ν_a(ℝ∖Z_on) = 0`.** Then `ν_a` is atomic on `Z_on` (a positive measure carried by a countable set), so
  `D_b = Σ_γ(2πm_γ − ν_a{γ})δ_γ` is atomic on `Z_on`. Theorem P applies with `σ = β_b`. This includes every
  `ν_a ≤ C·2πμ_Λ` and every "zero re-weighting" `ν_a = Σ c_γδ_γ`, `c_γ ≥ 0`.
* **(C) `ν_a{γ} = 2πm_γ` for all `γ`.** Then `|D_b|(Z_on) = 0`, so `b ∈ 𝒯_meas`, and B9's Theorem R′(i) applies
  (verified 5/5).

Since (C) ⊂ (A), the **residual case** is: there is an ordinate `γ_1` with `ν_a{γ_1} < 2πm_{γ_1}` (a deficit) **and**
`ν_a(ℝ∖Z_on) > 0`. **OPEN.**

**4.4 Two PROVED constraints on the residual.**

**Proposition LM (the spectral measure has the local mass of the zeros). PROVED.** For `a ∈ 𝒮^W ∩ (Λ + 𝒯)` and every
Schwartz `g` with `ĝ` supported in `(−log 2, log 2)`: `∫g(r−t)dν_a(r) = 2πΣ_γ m_γ g(γ−t)` for all `t`. Consequently
`ν_a([t−h, t+h]) ≪_h log(2+|t|)`.
*Proof.* The Fourier transform of `g(·−t)` is `e^{itu}ĝ(u)`, supported in `(−log 2, log 2)`, where `β_b` vanishes.
So `⟨D_b, g(·−t)⟩ = ⟨β_b, e^{it·}ĝ⟩ = 0`, and (4.1) gives the identity. For the bound:
* take `φ ≥ 0` in `C_c^∞(−¼log 2, ¼log 2)`, `φ ≠ 0`, and set `q := |φ̌|²`. This is Schwartz and nonnegative, with
  `q̂ = κφ⋆φ̃` supported in `(−½log 2, ½log 2)`, and `q ≥ q_0 > 0` on some `[−δ,δ]`;
* put `g_0 := q_0^{−1}Σ_{|k|≤K} q(· − kδ)` with `Kδ ≥ h`, so that `g_0 ≥ 1` on `[−h,h]`;
* then `ν_a([t−h,t+h]) ≤ ∫g_0(r−t)dν_a = 2πΣm_γg_0(γ−t)`, and this is `≪ log(2+|t|)` by Riemann–von Mangoldt (a unit
  interval at height `x` holds `O(log(2+|x|))` zeros) and the rapid decay of `g_0`. ∎

In words: `ν_a` and `2πμ_Λ` solve the *same* Kreĭn extension problem on `(−log 2, log 2)`, and also on every gap
`(log n, log(n+1))`. They differ only by the transform of a comb.

**Proposition Q (reduction of the residual to a cone of prime-blind tests). PROVED as an implication; its hypothesis
(H_Q) is OPEN.** Let
```
𝒢⁺_Z := {g ∈ 𝒮(ℝ) : g ≥ 0, g|_{Z_on} = 0, ĝ(±log n) = 0 for all n ≥ 2}.
```
For `a ∈ 𝒮^W ∩ (Λ + 𝒯)`, `ν_a` is carried by the common zero set `Z(𝒢⁺_Z) := ∩_{g∈𝒢⁺_Z} g^{−1}(0)`. Hence:

> (H_Q) `Z(𝒢⁺_Z) = Z_on` ⟹ `𝒮^W ∩ (Λ + 𝒯) ⊆ {Λ}`.

*Proof.* For `g ∈ 𝒢⁺_Z`, the same finite-sum truncation as in Theorem P, step 3, gives `⟨D_b, g⟩ = ⟨β_b, ĝ⟩ = 0`.
So `∫g dν_a = 2πΣm_γg(γ) = 0`. Since `g ≥ 0` is continuous, `ν_a({g > 0}) = 0`. Under (H_Q), `ν_a` is carried by
`Z_on`, and case (B) applies. ∎

What is known about (H_Q), all PROVED:
* (i) `𝒢⁺_Z` has no nonzero element with `ĝ` compactly supported in `[−log 2, log 2]`. Such a `g` is entire of
  exponential type `≤ log 2` and has `O(r)` zeros in `[−r,r]`, while `#(Z_on ∩ [−r,r])` is not `O(r)` (Hardy–Littlewood /
  Selberg: a positive proportion of `N(r) ≍ r log r`; CITED). Elements of `𝒢⁺_Z`, if any, have `ĝ` vanishing at every
  `±log n` without a spectral gap.
* (ii) Necessary condition, from the explicit formula: for `g ∈ 𝒢⁺_Z` the prime terms vanish, so
  `W(g) = Σ_{ρ off the line} g((ρ−½)/i)`. Under RH, `W(g) = (2π)^{−1}∫g·m + 2g(i/2) = 0`. This is not
  contradictory, since `m(0) < 0`.
* (iii) The non-emptiness of `𝒢⁺_Z ∖ {0}` is itself OPEN.

**Remark 4.6 (Eremenko–Novikov). CITED; the growth-class match is checked, but the measure version was not re-read
in the primary text.** `D_b` has spectral gap `(−log 2, log 2)`, and by Prop LM it is a real measure of polynomial
growth. Eremenko–Novikov (PNAS 101 (2004) 5872; arXiv:math/0301060 for the locally integrable, Beurling-temperate
version) give its sign changes lower density `≥ log 2/π`. By (4.1), `D_b` is positive only at deficit ordinates. So in
the residual case the deficit ordinates in `[0,r)` number `≥ (log 2/2π)·r·(1 − o(1))`: *a positive-density set of zeros
must be "partly removed"*. This is a vanishing proportion of `N(r)`, so it is no contradiction.

**4.5 The proportional case (B9 Remark 3.4), corrected.** Suppose `D_b^+ = ε·2πμ_Λ`, i.e. `D_b = ε2πμ_Λ − ν_0` with
`ν_0 ≥ 0` and `ν_0(Z_on) = 0`.
* If `ν_0 = 0`, then case (B) (equivalently Lemma G) gives `b = 0`. **PROVED.** This is the correct version of the part
  of B9's Remark 3.4 that was withdrawn.
* If `ν_0 ≠ 0`, the case is in the residual. Theorem P's pairings give `∫V_{ρ,0}dν_0 = 4πε` for every simple on-line
  `ρ`, and `∫U_m dν_0 = 0` for `m = 1` and every non-square `m`. By BRS §4.4 these are the BRS coordinates of
  `2πε·W`, so the case rescales to `Λ + b/ε ∈ 𝒮^W`, as P2 noted. **OPEN.** "The pole forbids proportionality" is
  **withdrawn** in general and holds only for `ν_0 = 0`.

## §7 Weakest steps

1. **Lemma S (the Schwartz property of `V_{ρ,j}`).** BRS define "rapidly decaying" pointwise in `y`. Theorem P needs
  `V_{ρ,j}|_ℝ ∈ 𝒮`, which I derive from the uniformity for `|y| ≤ 1` that their §4.3 construction provides (Mellin
  transforms decaying rapidly in vertical strips, "uniformly for `w` in compact sets"). Every alternative route I
  found (a contour shift to get decay of `V̂`, Phragmén–Lindelöf) needs the same uniformity in `y` on compact sets,
  so I do not claim it can be avoided. It is a point of bookkeeping in BRS's construction, not a gap in Theorem P's
  logic, but it is the place where the citation is used beyond the letter of their Theorem 1.1.
2. **The order hypothesis in Theorem P** (order `< m(γ)` at each ordinate) is essential. A `δ′_γ` at a simple zero
  is not killed by the `V`'s. For Cor P2 and P3 only measures occur, so nothing is lost.
3. **Cor P2** inherits Lemma L (B9 R3), including the panel's step-2 truncation patch, which I did not re-derive. Only
  the implication "u_Λ tempered ⟹ RH" is used.
4. **Remark 4.6** is CITED from the PNAS abstract and the arXiv version (which is for locally integrable functions).
  The measure version and its exact growth class were not re-read. It is not load-bearing.
5. **Nothing here is a step toward a sign.** Theorem P is the measure-side dual of BRS Cor 1.1(i). Its novelty is the
  application: the answer to the logged Remark 3.4 question and the uniqueness of the explicit formula (Cor P2). It is
  not new analysis, and it falls in the β-blind branch of Dichotomy 101.C. The genuinely OPEN residual of Theorem R(iv)
  is isolated in §4, with (H_Q) as a sufficient condition; any answer to it would concern uniqueness near `Λ`, not RH.
