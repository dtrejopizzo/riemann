## 2. Verification of the PROVED claims (audit re-derivation)

**2.1 Lemma R: VERIFIED.**
* `A(ψ) = ∫χ_ε(−∂²+¼)e^{t/2} = 0`, and likewise `B(ψ) = 0`.
* `ψ̂(τ) = (τ²+¼)εχ̂(ετ)` with P47's convention `e^{iτt}`. Substituting `x = ετ` gives (1.1) with the factor `ε^{−3}`.
* Separation: `|log(nk/m)| ≥ log(1+1/M) ≥ 1/(2M) ≥ 4ε` for `nk ≠ m`, using `m, k ≤ M`. In the case `nk < m` one also has
  `nk < M`.
* All `n ≤ M` are contacts, since `2T ≥ log M + 2ε`. For `n > M`, `log n − log M ≥ 4ε > 2ε`, so `c_{F_b}(log n) = 0`.
* `b^⊤(𝕄+𝕄^⊤)b = 2Σ_n a_n n^{−½}Σ_k b_{nk}b_k` matches `Σ v_n c_F(log n)` with `v_n = 2a_n/√n`.
* (d): for `|τ| ≥ 1`, `m(τ) ≤ log|τ| − 1.84 + 1 + 0.11 < log(1+|τ|)`; for `|τ| < 1`, `m(τ) ≤ m(1) < 0`. Also
  `log(1+y) ≤ ℓ(y) + ½log 2`, because `(1+y)² ≤ 2(1+y²)`.
* Off-diagonal: two integrations by parts give `|J(u)| ≤ (2π)^{−1}ε^{−3}M_2(ε/u)²`. Then `log(m/k) ≥ (m−k)/M`, and
  Schur/Young with `Σ1/h² = ζ(2)` gives the bound.

**2.2 Lemma S: VERIFIED.** Schur test with weights `w_k = k^{−½}`.
* Divisor side: `m^{½}Σ_{d|m}Λ(d)d^{−½}(m/d)^{−½} = Σ_{d|m}Λ(d) = log m`. This is exact.
* Multiple side: `Σ_{j≤M/m}Λ(j)/j ≤ log(M/m) + E`, with Mertens CITED.

**2.3 Proposition P: VERIFIED** (constants not optimised, and no constant is load-bearing for a sign).
* Diagonal lower bound: `m(τ) ≥ log(|τ|/2π) − 4`. For `|τ| < 1` this uses `log(1/2π) − 4 = −5.84 < C_0 = −5.372 = m(0) ≤ m(τ)`.

* Time-domain off-diagonal: polarising `eq:A` gives `−½∫_0^∞[c_ψ(u+u_0)+c_ψ(u−u_0)]K`. The `C_0` and `⟨·,·⟩K`

* `K(u) ≤ 1/u + ½`, `‖ψ‖_1 ≤ ε^{−1}‖χ''‖_1 + ε‖χ‖_1/4` and `‖ψ‖² ≥ ε^{−3}D_χ` give the ratio `C(ε/u_0 + ε)`.

**2.4 Theorem D / Corollary D1: VERIFIED.**

**2.6 Theorem R: VERIFIED given CITED input.** I extracted Soundararajan, arXiv:0708.3990, Theorem 2.1 and its

## 3. Defects found (none fatal to the side results; all confirm the exclusion)

(a) **"Uniform in T / every T" is empty content in Prop. P.** `F ∈ ℛ_M(ε_M)` is supported in `I_{½log M+ε}`, so
`𝔞_T(F)` is the same for all larger `T` (`lem:monoT`, proof). The ∀T phrasing should read "for every `M`, on
`ℛ_M ⊂ P_T` for `T ≥ ½log M + ε_M`". It must not be listed under F2 as uniformity in `T` in the G2 sense.

(b) **The cleanest exclusion is the empty comb, not deletion/amplification.** Prop. P holds for `a = 0` with a
*larger* gap, and `RD_T(0)` fails for `T ≥ 0.60`. The memo should cite `thm:finmod`(i) with `N > e^{2T}` explicitly.
It shows that on `ℛ_M` the prime comb is a perturbation dominated by the archimedean part: Λ is not *needed* for
positivity there, only *tolerated*. "Positivity of Λ on structured tests" is therefore not a positivity carried by
Λ. §6 ("the first unconditional ∀T positivity statement for the prime comb ... proved from `Λ∗1 = log`") overstates
this and should be reworded: `Λ∗1 = log` shows that Λ does not *destroy* the archimedean positivity on `ℛ_M`.

(c) **Wording in Theorem R's preamble.** "Every Cramér/Green–Tao W-trick model is of this kind" is correct for the
deterministic W-trick model `s^W` (Cor. R1). It is false for the *random* Cramér model (a sparse random set with
weights `log n`), which is not `≥ c` on all large-prime squarefrees. Restrict the wording to `s^W` and to dense models.

(d) **Remark R.1.** Its band claim ("spectrum inside `[2πe^{2T}, 2πe^{A_T}]`") holds only at `T ≈ ½log M`. For
larger `T`, `1/ε_M ≍ KM log M` can lie below `2πe^{2T}`. It is HEURISTIC and not load-bearing, and should be labelled
so. The claim "trivial bound fails by `e^T/T`" is also unlabelled heuristic.

(e) **Cor. T2(iii)** is correctly labelled EQUIVALENT. It is a tautological reformulation (Λ = s + r moves every zero
into `r`). It is not a candidate.

## 4. Salvageable ideas

* **Lemma R (multiplicative-Toeplitz transfer)** is a clean new *diagnostic* tool: on the lattice `log ℕ`, at high
  frequency, it turns the Weil form into GCD-sum matrices. Its value is **destructive** (Theorem R, Cor. R1): it gives
  an unconditional spread-mass flip of the sign that needs neither `thm:margin` nor the OPEN non-degeneracy
  hypothesis of `rem:resweights`. I recommend recording it next to `thm:finmod`/`rem:resweights` as a companion
  obstruction: **any G2 mechanism must fail for `Λ + c·1_{ℛ∩[1,e^{2T}]}`**, and so must use that Λ vanishes on
  squarefree numbers with two or more prime factors. This support property is exact arithmetic of Λ, of F1 type.
* **Theorem T** is a useful general tool: analytically structured combs are T-free Toeplitz forms. It reduces the
  "structured" side of any split to one inequality `S_s ≥ 0`, and it shows that a split carries no mechanism.
* **Cor. D1** (the residue cap at 1 for ∀T-positive nonnegative combs) is a sharp necessary condition, and it is
  class-level.
* **Not salvageable as G2:** Proposition P, for the reasons in §1 and §3(b).
