## §1 Setting (recalled from R3, with one lemma)

An HWD is a Hilbert space `H` with a representation `n ↦ S_n` of `N^×` by **doubly commuting isometries**
(`S_a^†S_b = S_bS_a^†` for `(a,b) = 1`). Put `F_n := S_n^†` (the Frobenius) and `V_n := nS_n` (the Verschiebung). This
is R3 Def. 1.1 and Lemma 1.2: the Witt relations plus the Rosati compatibility `V_p = pF_p^†`. The positive form is the
inner product. It is given before any spectrum and uses no zeros. A **character** is a completely multiplicative
`χ : N → C`. `E_χ := {y : F_ny = χ(n)y ∀n}`. Since `‖F_p‖ ≤ 1`, `E_χ ≠ 0` forces `|χ(p)| ≤ 1` for all `p`.

**Lemma 1.1 (Nica spanning; `PROVED`).** `𝔗 := C*(S_n : n ∈ N)` is the closed linear span of `{S_aS_b^† : a, b ∈ N}`.

*Proof.* The span is closed under adjoints, since `(S_aS_b^†)^† = S_bS_a^†`. For products, let `g = (b, c)`. Then
`S_b^†S_c = S_{b/g}^†S_g^†S_gS_{c/g} = S_{b/g}^†S_{c/g} = S_{c/g}S_{b/g}^†`, using double commutation for the coprime
pair `(b/g, c/g)`. So `(S_aS_b^†)(S_cS_d^†) = S_{ac/g}S_{db/g}^†`. The span is therefore a *-algebra containing the
generators. ∎

**Local model (`PROVED`, elementary).** On `ℓ²(Z_{≥0})`, let `S` be the shift. For `|z| < 1` put
`v(z) := (1−|z|²)^{1/2}Σ_k z^kδ_k`. Then:
* `ker(S^† − z) = C·v(z)`, and `S^†` has no eigenvalue with `|z| ≥ 1`;
* `|⟨v(z), v(w)⟩|² = (1−|z|²)(1−|w|²)/|1−z̄w|²`, hence `1 − |⟨v(z),v(w)⟩|² = |z−w|²/|1−z̄w|² =: ϱ(z,w)²` (the
  pseudo-hyperbolic distance);
* `S^k(1−SS^†)S^{†l} = |δ_k⟩⟨δ_l|`, so `C*(S)` contains all finite-rank operators.

*Proof.* `(S^†x)_k = x_{k+1}`, so `S^†x = zx` gives `x_k = z^kx_0`, which is in `ℓ²` iff `|z| < 1`. The distance
identity is `|1−z̄w|² − (1−|z|²)(1−|w|²) = |z−w|²`. The last item holds because `1−SS^† = |δ_0⟩⟨δ_0|`. ∎

**Tensor lemma (`PROVED`).** Let `A` be bounded on `K_1` and `R` a Hilbert space. Then
`ker(A⊗1 − z) = ker(A − z) ⊗ R`.

*Proof.* Expand `x = Σ_jx_j⊗r_j` in an orthonormal basis `(r_j)` of `R`. Then `(A⊗1−z)x = Σ(A−z)x_j⊗r_j = 0` iff every
`x_j ∈ ker(A−z)`. ∎

## §2 Lemma E and the eigen-sector theorem

**Lemma E (`PROVED`).** Let `y ∈ E_χ` with `‖y‖ = 1`. Then `⟨S_aS_b^†y, y⟩ = ⟨F_by, F_ay⟩ = χ(b)\overline{χ(a)}`. By
Lemma 1.1 this determines the vector state `ω_χ` of `y` on `𝔗`. By GNS uniqueness, `([𝔗y], 𝔗)` is unitarily equivalent
to the GNS representation of `ω_χ`, which depends only on `χ`. More generally, for `y, y′ ∈ E_χ`:
`⟨Ay, y′⟩ = ω_χ(A)⟨y, y′⟩` for all `A ∈ 𝔗`. ∎

No factorisation, type assumption or tail condition is used. Every HWD in which `χ` occurs contains the **same**
cyclic representation.

**Definition 2.1 (coherent sector).** Let `P_χ := {p : |χ(p)| < 1}`. Define
`H_χ := ⊗_{p∈P_χ}(ℓ²(Z_{≥0}), v_p)`, with `v_p := v(χ(p))`. This is von Neumann's incomplete tensor product with
reference vector `ξ := ⊗v_p`: the closed span of the finite modifications `x_P ⊗ ξ^{P^c}` (`P` finite). On it:
* `S_p` is the shift in factor `p` for `p ∈ P_χ`;
* `S_p = \overline{χ(p)}·1` for `p ∉ P_χ` (unimodular).

Operators acting in finitely many factors extend to the ITP (CITED: von Neumann, Compositio Math. 6 (1939)). The
`S_p` are doubly commuting isometries, so `H_χ` is an HWD, and `F_pξ = χ(p)ξ`.

**Prop 2.2 (`PROVED`).**
(i) `ξ` is cyclic for `𝔗`.
(ii) The `χ`-eigenspace of `H_χ` is `C·ξ`.
(iii) `H_χ` is irreducible.
(iv) Let `χ′` be a character with `∏_{p∈P_χ}|⟨v_p, v′_p⟩| = 0`, where `v′_p := v(χ′(p))`, or with `|χ′(p)| = 1` for
some `p ∈ P_χ`. Then for any Hilbert space `E`, `H_χ ⊗ E` contains no nonzero joint eigenvector of character `χ′`.

*Proof.*
(i) For finite `P ⊂ P_χ`, `C*(S_p : p ∈ P)` contains every finite-rank operator on `K_P := ⊗_{p∈P}ℓ²`, by the local
model. Applied to `ξ = ξ_P ⊗ ξ^{P^c}` (with `ξ_P ≠ 0`), it produces every `x_P ⊗ ξ^{P^c}`. These are dense.
(ii) Let `η` be a `χ`-eigenvector. For finite `Q`, the tensor lemma applied factor by factor in
`H_χ = K_Q ⊗ H_χ^{Q^c}` gives `η = ξ_Q ⊗ η_Q`, with `η_Q ∈ H_χ^{Q^c}`. Put `η′ := η − ⟨η,ξ⟩ξ`, again a `χ`-eigenvector,
with `η′ ⊥ ξ`. For a finite modification `x = x_P ⊗ ξ^{P^c}`:
`⟨η′, x⟩ = ⟨ξ_P, x_P⟩⟨η′_P, ξ^{P^c}⟩`, and `⟨η′_P, ξ^{P^c}⟩ = ⟨η′, ξ⟩ = 0`. Such `x` are dense, so `η′ = 0`.
(iii) An operator `C` in the commutant commutes with every `F_n`, so it preserves the `χ`-eigenspace: `Cξ = cξ`. Then
`C(Aξ) = cAξ` for `A ∈ 𝔗`, and (i) gives `C = c`.
(iv) If `|χ′(p)| = 1` for some `p ∈ P_χ`, then `F_p` acts as `S^†⊗1` on `ℓ²⊗(rest)`, which has no unimodular
eigenvalue (local model plus tensor lemma). Otherwise, suppose `η ≠ 0` is such an eigenvector. As in (ii),
`η = v′_Q ⊗ η_Q` for every finite `Q ⊂ P_χ`.
* Pick a finite modification `x = X_P ⊗ ξ^{P^c}` (`X_P ∈ K_P ⊗ E`) with `‖x − η‖ < ‖η‖/2`. Then
  `|⟨x, η⟩| > ‖η‖²/2` and `‖x‖ < 2‖η‖`.
* For finite `R ⊂ P_χ ∖ P` and `Q = P ⊔ R`:
  `⟨x, η⟩ = ⟨X_P ⊗ ξ_R ⊗ ξ^{Q^c}, v′_P ⊗ v′_R ⊗ η_Q⟩`. Hence
  `|⟨x,η⟩| ≤ ‖x‖·∏_{p∈R}|⟨v_p, v′_p⟩|·‖η‖`.
* The factors are non-zero, and the full product is `0`, so `∏_{p∈R} → 0` as `R ↑ P_χ ∖ P`. This contradicts the
  first bullet. ∎

**Theorem E (eigen-sector theorem; `PROVED`).** Let `H` be any HWD.
(i) For each character `χ` with `E_χ ≠ 0`, the map `Aξ ⊗ y ↦ Ay` (`A ∈ 𝔗`, `y ∈ E_χ`) extends to a unitary
`H_χ ⊗ E_χ → [𝔗E_χ]` that intertwines `𝔗`.
(ii) Call `χ, χ′` *tail-equivalent* (`χ ~ χ′`) if `P_χ = P_{χ′}`, `χ = χ′` off `P_χ`, and
`Σ_{p∈P_χ}ϱ(χ(p), χ′(p))² < ∞`. If `χ ≁ χ′`, then `[𝔗E_χ] ⊥ [𝔗E_{χ′}]`.
(iii) Hence `H ⊇ ⊕_{[χ]}[𝔗E_{[χ]}]`, an orthogonal sum over tail classes. Within a class, all eigenvectors lie in one
common sector type, since `H_χ ≅ H_{χ′}` for `χ ~ χ′` (CITED, von Neumann's equivalence of ITPs up to phases).

*Proof.*
(i) By Lemma E, `⟨Ay, A′y′⟩ = ω_χ(A′^†A)⟨y,y′⟩ = ⟨Aξ, A′ξ⟩⟨y,y′⟩`. So the map is isometric on the algebraic span.
Its domain is dense by Prop 2.2(i), and its range is dense in `[𝔗E_χ]` by definition.
(ii) First, `ϱ² = 1 − |⟨v,v′⟩|²` and `1 − |c| ≥ (1 − |c|²)/2`, so `Σϱ² = ∞` implies `∏|⟨v_p,v′_p⟩| = 0`. The other
cases of `χ ≁ χ′` (where `P_χ ≠ P_{χ′}`, or `χ ≠ χ′` on a unimodular prime) give different eigenvalues at a single
prime, or the unimodular case of Prop 2.2(iv). Now let `Π` be the orthogonal projection onto `[𝔗E_χ]`. It lies in
`𝔗′`, so it commutes with every `F_n`. For `y′ ∈ E_{χ′}`, `Πy′ ∈ [𝔗E_χ] ≅ H_χ ⊗ E_χ` is a `χ′`-eigenvector, so it is
`0` by Prop 2.2(iv) (applied symmetrically if needed). So `E_{χ′} ⊥ [𝔗E_χ]`. Since `[𝔗E_χ]` is reducing, this gives
`[𝔗E_{χ′}] ⊥ [𝔗E_χ]`.
(iii) follows from (ii). ∎

**Reading** (`HEURISTIC` interpretation of `PROVED` statements). The Rosati compatibility, i.e. isometric
Verschiebung for a *positive* form, makes every Frobenius eigenvector a **coherent vector**. Its sector is a product
sector, whatever the global type of the representation (type I, II or III, ITPFI or not). This is the precise sense in
which entanglement is invisible to point spectrum in the Witt class.

## §3 Prop C: tail classes of `χ_s(n) = n^{−s}`

**Prop C (`PROVED`; PNT CITED).** Let `Re s, Re s′ > 0`. Then:
(a) if `Re s, Re s′ > ½`, then `χ_s ~ χ_{s′} ~ χ_∞`, where `χ_∞ := 1_{n=1}` (so `v(0) = δ_0`, and `H_{χ_∞} = ℓ²(N)` is
the ghost model `(G)`);
(b) if `min(Re s, Re s′) ≤ ½` and `s ≠ s′`, then `χ_s ≁ χ_{s′}`.

*Proof.* For `z = p^{−s}`, `w = p^{−s′}` we have `|z̄w| ≤ 2^{−Re(s+s′)} < 1`, so `|1 − z̄w| ∈ [1−2^{−Re(s+s′)}, 2]` and
`ϱ(z,w)² ≍ |p^{−s} − p^{−s′}|²` uniformly in `p`.
(a) `|p^{−s} − p^{−s′}|² ≤ 2p^{−2Re s} + 2p^{−2Re s′}`, which is summable over `p`. For `χ_∞`, `ϱ(p^{−s},0) = p^{−Re s}`.
(b) Put `σ = Re s`, `σ′ = Re s′`, `m = min(σ, σ′) ≤ ½`.
* If `σ ≠ σ′`: `|p^{−s} − p^{−s′}| ≥ |p^{−σ} − p^{−σ′}| ≥ p^{−m}(1 − 2^{−|σ−σ′|})`, and `Σ_pp^{−2m} ≥ Σ_pp^{−1} = ∞`
  (Mertens, CITED).
* If `σ = σ′ ≤ ½` and `τ := Im(s′−s) ≠ 0`: `|p^{−s}−p^{−s′}|² = p^{−2σ}|1 − p^{−iτ}|² ≥ p^{−1}|1−p^{iτ}|²`. On a
  dyadic block, PNT with de la Vallée Poussin error (CITED) and partial summation give
  `Σ_{x<p≤2x}p^{iτ} = (x^{1+iτ}/log x)∫_1^2v^{iτ}dv·(1+o(1))` and `π(2x) − π(x) = (x/log x)(1+o(1))`. Put
  `r(τ) := |∫_1^2v^{iτ}dv|`. Since `v^{iτ}` is continuous and non-constant on `[1,2]`, `r(τ) < 1`. Hence
  `Σ_{x<p≤2x}|1−p^{iτ}|² = 2(π(2x)−π(x)) − 2Re Σ p^{iτ} ≥ 2(1 − r(τ) − o(1))x/log x`, and
  `Σ_{x<p≤2x}p^{−1}|1−p^{iτ}|² ≥ (1 − r(τ) − o(1))/log x`. Summing over `x = 2^k` gives `Σ_k 1/(k log 2) = ∞`. ∎

(The dyadic PNT computation is the same as in B3_R4 Lemma PW and B4_R4 Lemma D. The σ ≠ σ′ case and the use for sector
disjointness at fixed `σ ≤ ½` are what is added here; 106.164 Thm 6.1 had only the limit `σ ↓ ½`.)

## §4 Cor E2: `F`-invariant carriers (O-B5.4) and entanglement (E1)

with `T(log n) = F_n|Y`, with generator `B`.
* If `By = −sy` with `y ≠ 0`, then `T(t)y = e^{−st}y`, so `y ∈ E_{χ_s}`.
* Conversely, joint eigenvectors in `Y` exist without any semigroup.

In either case `y` is a joint eigenvector of the **ambient** `H`, and:
(i) `Re s ≥ 0`; if `Re s = 0` then `y ∈ H_u` (R3 Prop D). There `[𝔗y] = Cy`, and every unimodular configuration is
installable (G1_B2_R2 Prop R, Lemma T(⇐)).
(ii) If `0 < Re s ≤ ½`, then `y` lies in the `H_{χ_s}`-isotypic part of `H`, and distinct such `s` lie in mutually
orthogonal, pairwise disjoint irreducible sectors (Theorem E + Prop C(b)). So `σ_p(B) ∩ {0 < Re s ≤ ½}` is contained in
the set `𝔖(H) := {s : H_{χ_s} occurs in H}`, which is an invariant of the ambient representation. No choice of `Y` or
`T` creates a strip point that the ambient Witt representation does not already contain as a coherent sector.
(iii) If `Re s > ½`, then `y` lies in the ghost-isotypic part `≅ ℓ²(N) ⊗ E_{χ_∞}`, whose `χ_s`-eigenspace is
`e_s ⊗ E_{χ_∞}` (Prop D of R3, tensored). An `F`-invariant `Y` selects from it through orthocomplements of `S`-invariant
subspaces, i.e. common zero sets of `𝓗²`-Dirichlet series (R3 Prop N, extended verbatim to several generators).

*Proof.* The first two bullets are the semigroup law. (i)–(iii) are Prop D, Theorem E, Prop C, and Prop N. ∎

**Consequences for ζ** (implications `PROVED`; the identification with the record's families is record-based). Use

* Other normalisations `s = ρ − c` only move the three regimes. For `c ≤ 0` every zero is in the ghost region, where

`x ≥ x_0`. If `G(s) := D(s+a)` has coefficients in `ℓ²` (i.e. `G ∈ 𝓗²`), then `a > ½`, and every zero `ρ` of `D` with
`Re ρ ≤ 1` gives `G(ρ − a) = 0` at `Re(ρ − a) < ½`. That lies outside `{Re s > ½}`, the region where R3 Prop N detects
zeros as eigenvalues on `Y_g`. So `Y_g` with `g` the coefficients of `D(·+a)` has no point spectrum coming from the
zeros of `D` in the strip.

*Proof.* Partial summation: `Σ_{n≤N}|d_n|²n^{−2a} ≥ 2a∫_{x_0}^NA(x)x^{−2a−1}dx ≥ 2ac∫_{x_0}^Nx^{−2a}dx`, which diverges
if `a ≤ ½`. ∎

(`HEURISTIC`) This is why Nyman–Beurling must use a constructed generator, the fractional-part functions, and it is
consistent with its EQUIV status (R157_002 row 43).

## §5 Theorem G: the Gibbs–Witt (Bost–Connes KMS) data

**Definition 5.1.** For `β > 0` and each `p`:
* the geometric density `ρ_p := (1−p^{−β})Σ_kp^{−kβ}|δ_k⟩⟨δ_k|` on `ℓ²(Z_{≥0})` (106.192 §2 at `β = 1`), with
  `‖ρ_p‖ = 1 − p^{−β}`;
* its purification `Ω_p := ρ_p^{1/2}` in the Hilbert–Schmidt space `HS_p := HS(ℓ²(Z_{≥0}))`, with `S_p` acting by left
  multiplication, `X ↦ SX`, which is an isometry.

Put `K_β := ⊗_p(HS_p, Ω_p)` (ITP), `Ω := ⊗Ω_p`, and `W_β := [𝔗Ω] ⊂ K_β`. Then `K_β` is an HWD (left multiplications
in different factors doubly commute), and
`⟨S_aS_b^†Ω, Ω⟩ = ∏_pTr(ρ_pS^{a_p}S^{†b_p}) = δ_{ab}a^{−β}`,
using `Tr(ρ_pS^kS^{†l}) = δ_{kl}Σ_{j≥k}(1−p^{−β})p^{−jβ} = δ_{kl}p^{−kβ}`.

**Remark 5.2 (`PROVED` from the KMS condition, BC presentation CITED).** Every KMS_β state `φ` of the Bost–Connes system
`(C*_BC, σ_t)`, with `σ_t(μ_n) = n^{it}μ_n`, satisfies `φ(μ_aμ_b^*) = δ_{ab}a^{−β}`:
* invariance under `σ` kills `a ≠ b`;
* the KMS condition with `x = μ_a^*`, `y = μ_a` gives `φ(μ_aμ_a^*) = a^{−β}φ(μ_a^*μ_a) = a^{−β}`.

So `W_β` is the GNS representation of the restriction to `𝔗` of every BC KMS_β state. It is canonical, zero-free and
defined before any spectrum. Its positive form is a Gibbs state, so OT-5′ holds **as a form**.

**Theorem G (`PROVED`).** `K_β` contains a nonzero joint Frobenius eigenvector of character `χ` iff
`β > 1` and `Σ_p|χ(p)|² < ∞` (in particular `|χ(p)| < 1` for all `p`).

*Proof.*
* On `HS_p`, `F_p` is left multiplication by `S^†`. Its eigenvectors with eigenvalue `z` are the `X` all of whose
  columns lie in `ker(S^†−z)`: `X = |v(z)⟩⟨w|` if `|z| < 1`, and none if `|z| ≥ 1`. Let `E_p` be the projection
  `X ↦ |v_p⟩⟨v_p|X` onto them, with `v_p = v(χ(p))`.
* One computes `‖E_pΩ_p‖²_HS = ⟨v_p, ρ_pv_p⟩ = (1−p^{−β})(1−|z|²)/(1−p^{−β}|z|²)`, with `z = χ(p)`. Put
  `a := p^{−β} ≤ ½` and `b := |z|²`. Then `1 − ‖E_pΩ_p‖² = (a + b − 2ab)/(1−ab) ≥ max(b(1−a), a(1−b)) ≥ max(b/2, a(1−b))`.

(⇒) Suppose `η ≠ 0` is a `χ`-eigenvector. By the tensor lemma, `(⊗_{p∈Q}E_p ⊗ 1)η = η` for every finite `Q`.
* Choose a finite modification `x = x_P ⊗ Ω^{P^c}` with `‖x−η‖ < ‖η‖/2`. For finite `R` disjoint from `P`:
  `|⟨x,η⟩| = |⟨E_Rx, η⟩| ≤ ‖x‖·∏_{p∈R}‖E_pΩ_p‖·‖η‖`.
* If `Σb_p = ∞`, then `Σ(1 − ‖E_pΩ_p‖²) ≥ Σb_p/2 = ∞`.
* If `Σb_p < ∞` but `Σa_p = ∞` (i.e. `β ≤ 1`), then `b_p → 0` and `Σa_p(1−b_p) = ∞`.
* In both cases `∏_{p∉P}‖E_pΩ_p‖ = 0`, which contradicts `|⟨x,η⟩| > ‖η‖²/2`.

(⇐) Take `η := ⊗_p|v_p⟩⟨δ_0|`. Then
`⟨|v_p⟩⟨δ_0|, Ω_p⟩_HS = ⟨v_p, ρ_p^{1/2}δ_0⟩ = (1−p^{−β})^{1/2}(1−|z|²)^{1/2} ∈ (0,1]`, and
`1 − ⟨·,·⟩ ≤ 1 − (1−a)(1−b) ≤ a + b`, which is summable. By von Neumann's criterion (CITED), `η ∈ K_β`. It is a
product of local eigenvectors, so it is a `χ`-eigenvector. ∎

**Scope of Theorem G.**
* For the cyclic subspace `W_β ⊂ K_β`, direction (⇒) holds verbatim, since `W_β ⊂ K_β`. So: no eigenvector in `W_β`
  for `β ≤ 1`, and none with `Σ|χ(p)|² = ∞`. This is the only direction used for exclusions.
* Direction (⇐) for `W_β` at `β > 1` (that the GNS space itself, and not only its purification, contains the ghost
  eigenvectors) would follow from the quasi-equivalence of `⊗ψ_p` with the ghost product state when
  `Σ(1−‖ρ_p‖) < ∞`. That is `CITED`-level (von Neumann / Araki–Woods) and not written out here. It plays no role.

**Reading.**
* (`PROVED`) At and below the critical temperature, `β ≤ 1`, the canonical Gibbs form carries no Frobenius eigenvector
  whatever: `Σ_pp^{−β} = ∞` is the same divergence as the pole of `ζ(β)`.
* (`PROVED`) Above it, the form carries exactly the ghost characters, and among the `χ_s` only `Re s > ½`: the polar,
  Euler-product side, dual to Theorem K′.
* (`HEURISTIC`, the Witt form of B2's type-III question) The divergence `Σ_p(1 − ‖ρ_p‖) = ∞` is Araki–Woods' non-type-I
  condition for product states (CITED: Araki–Woods, Publ. RIMS 4 (1968)). BC proved the KMS_β factor is of type III_1
  for `β ≤ 1` (CITED). So "type III kills point spectrum" is here an elementary theorem that needs no type theory. In a
  prime-built positive object with modulus-`p^{−1}` germs at every `p` at once, the zeros cannot be point spectrum. They
  can enter only as absorption/cokernel data: Connes' adèle class space and Meyer's virtual representation, EQUIV (A17).

**Falsifier check.** Theorem G and Theorem E are uniform in any Beurling monoid with divergent `Σ_pp^{−1}`. They are
non-existence statements and assert no positivity, so `Ξ_a`, Epstein, DMV and admissible combs are untouched. On
`Ξ_a` (off-line zeros with `a < ½`), Cor E2(ii) says an HWD carries them only through installed coherent sectors, and
never their partners. ✓

**Inverse check.** Weil's `H¹` of a curve over `F_q` is finite-dimensional with unitary Frobenius after normalisation.
It is the `Re s = 0` regime (i), where Theorem E says nothing restrictive (`[𝔗y] = Cy`). So the theorems exclude no
true object. ✓

## §8 New, open, weakest step

**New** (`PROVED`; credit as in §C):
1. Lemma E: every Frobenius eigenvector of every Rosati-compatible Witt datum is a coherent vector, and its sector is
  canonical.
2. Prop 2.2 and Theorem E: the coherent sectors are irreducible with one-dimensional eigenspace. Tail-inequivalent
  characters lie in orthogonal, disjoint sectors.
3. Prop C at fixed `σ ≤ ½`: every strip point has its own sector class. All of `Re s > ½` is one class, the ghost class.
