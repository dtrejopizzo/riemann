## §1 Definitions (from P47, checked against the source)

* **Window, tests, forms.** `I_T = (−T,T)`. `D_T := P_T ∩ H¹_0(I_T)`, real-valued. `P_T = {A = B = 0}`, with
  `A(F) = ∫Fe^{t/2}` and `B(F) = ∫Fe^{−t/2}`. `c_F(u) = ∫F(t)F(t−u)dt` and
  `ε_F(u) = c_F(0) − c_F(u) = ½‖F − F_u‖² ≥ 0`.
* **Archimedean data.** `K(u) = 1/(2sinh(u/2)) + 1/(2cosh(u/2))` (lem:K), and `C_0 = ψ(¼) − log π = −5.37218…`.
* **Contacts.** `𝒩_T = {n ≥ 2 : log n < 2T}`, with `v_n = 2Λ(n)/√n`.
* **Local prime form.** For a prime `p < e^{2T}`, `Q_p(F) = −Σ_{k≥1, k log p<2T} v_{p^k} c_F(k log p)` (cor:Qp).
* **The primitive form (eq:Aform).** `𝔞_T(F) = C_0‖F‖² + ∫_0^∞ ε_F K du + Σ_p Q_p(F)`.
* **The complete form.** `W_T = 𝔞_T + 2Re(A\bar B)`, so `W_T = 𝔞_T` on `P_T`.

**Definition 1 (LK splitting, local certificate; as round 4).** Let `Π_T` be the set of primes `p < e^{2T}`.
* An **LK splitting** is a family `(C_p, K_p)_{p∈Π_T}` with `C_p ∈ ℝ`, `Σ C_p = C_0`, `K_p` measurable, `0 ≤ K_p`,
  and `Σ K_p = K` a.e.
* It **certifies** `RD_T` locally if `q_p(F) := C_p‖F‖² + ∫_0^∞ ε_F K_p du + Q_p(F) ≥ 0` for all `F ∈ D_T` and all
  `p`.
* `T` is **locally certifiable** if some LK splitting certifies it.
* For `T ≤ ½log 2` (no contacts), locally certifiable means `𝔞_T ≥ 0` on `D_T`.

*Why this is exactly the stability class (PROVED reduction, round 4 §1, CITED Schoenberg/Lévy–Khintchine).*
* Let `ψ_p` be an even, continuous, conditionally negative definite piece with `ψ_p(0) = 0` and `Σψ_p = φ(τ²)`.
  Then `e^{−tψ_p}` is positive definite for all `t > 0` (Schoenberg), so each piece is the exponent of a
  convolution semigroup.
* By Lévy–Khintchine uniqueness and thm:S(ii) (the Lévy measure is `½K(|u|)du`, with no Gaussian part), such a
  splitting is exactly `ψ_p(τ) = ∫(1 − cos τu)K_p(u)du` with `0 ≤ K_p ≤ K` and `ΣK_p = K`.
* Extra purely archimedean labels `∞_i` (with `Q_{∞_i} = 0`) can be merged into any prime label, because a sum of
  nonnegative LK local forms is an LK local form. So they neither help nor hurt.
* A **block** version (primes grouped, one piece per block) is covered by Remark 4.3.
* **Complete form.** Polar pieces `h_p(A(F), B(F))` with `Σh_p = 2Re(A\bar B)` vanish on `P_T`. Every statement
  below that is proved on `D_T` holds verbatim for the complete-form variant.

**Notation.** Let `𝒮` be the set of finite-rank positive operators `σ` on `L²(I_T)` with `tr σ = 1` and range
in `D_T`. Writing `σ = Σ_i w_i |F_i⟩⟨F_i|` with `F_i ∈ D_T` orthonormal and `w_i ≥ 0`, `Σw_i = 1`, put
`ε_σ := Σw_iε_{F_i}` and `Q_p(σ) := Σw_iQ_p(F_i)`. These are affine in `σ`.

## §2 Theorem D: the exact local-certification problem

**Lemma 2.1 (upper bound; round-4 Prop M restated). PROVED.** Let `(C_p, K_p)` be an LK splitting and let
`(σ_p)_{p∈Π_T} ∈ 𝒮^{Π_T}`. Then

  `Σ_p [C_p + ∫ε_{σ_p}K_p + Q_p(σ_p)] ≤ Φ_T[(σ_p)] := C_0 + ∫_0^∞ K(u) max_p ε_{σ_p}(u) du + Σ_p Q_p(σ_p)`.

*Proof.* `ΣC_p = C_0`, and `Σ_p K_pε_p ≤ (Σ_p K_p) max_p ε_p = K max_p ε_p` pointwise, since `K_p ≥ 0` and
`ε_p ≥ 0`. ∎

If the splitting certifies `RD_T`, the left side is `≥ 0`: it is a convex combination of values `q_p(F_i) ≥ 0`.
Hence:

**Corollary 2.2 (elementary obstruction). PROVED.** If some family has `Φ_T[(σ_p)] < 0`, then `T` is not locally
certifiable. Pure states (`σ_p = |F_p⟩⟨F_p|`) suffice for every use below.

**Theorem D (duality). PROVED.** Put `Φ_T := inf_{(σ_p)∈𝒮^{Π_T}} Φ_T[(σ_p)]`. Then `T` is locally certifiable if
and only if `Φ_T ≥ 0`. Moreover `Φ_T ≤ λ^A_T(D_T) := inf_{F∈D_T, ‖F‖=1} 𝔞_T(F)`.

*Proof.*
1. *Primal reformulation.* Put `X := {θ = (θ_p) ∈ L^∞(0,∞)^{Π_T} : θ_p ≥ 0, Σ_pθ_p = 1 a.e.}`. Each LK splitting
  gives `θ_p := K_p/K ∈ X`, and conversely. For `θ ∈ X` define
  `μ_p(θ_p) := inf_{F∈D_T, ‖F‖=1}[∫ε_F θ_pK du + Q_p(F)]`. Then `μ_p ≥ −Σ_n v_n > −∞`, since `|c_F| ≤ ‖F‖²`.
  * *Certificate implies `g ≥ 0`.* If `(C_p, K_p)` certifies, then `C_p ≥ −μ_p(θ_p)` for each `p`, so
  `g(θ) := C_0 + Σ_pμ_p(θ_p) ≥ 0`.
  * *`g ≥ 0` implies a certificate.* If `g(θ) ≥ 0`, set `C_p := −μ_p(θ_p) + g(θ)/|Π_T|`. Then
  `q_p(F) ≥ (C_p + μ_p)‖F‖² ≥ 0`.
  * So `T` is locally certifiable if and only if `sup_X g ≥ 0`, provided the supremum is attained, which step 4
  shows.
2. *The saddle function.* Let `f(θ, σ) := C_0 + Σ_p[∫_0^∞ θ_p K ε_{σ_p} du + Q_p(σ_p)]` on `X × 𝒮^{Π_T}`.
  * For fixed `σ`, `Kε_{σ_p} ∈ L¹(0,∞)`: `0 ≤ ε_σ ≤ 2`, `ε_σ = 1` for `u ≥ 2T`, `K ∈ L¹(1,∞)`, and
  `ε_σ(u) ≤ ½u²Σw_i‖F_i′‖²` near 0, while `K ≤ 1/u + ½`.
  * So `θ ↦ f(θ, σ)` is affine and continuous for the weak-* topology `σ(L^∞, L¹)`.
  * `X` is convex, bounded and weak-* closed, hence weak-* compact (Banach–Alaoglu).
  * For fixed `θ`, `σ ↦ f(θ, σ)` is the restriction to the convex set `𝒮^{Π_T}` of a linear functional on the
  real vector space spanned by finite-rank self-adjoint operators with range in `D_T`.
  * Give that space its finest locally convex topology (Schaefer, *Topological Vector Spaces* II.6). Every linear
  functional is then continuous.
3. *Sion.* Apply Sion's minimax theorem (Sion, Pacific J. Math. 8 (1958) 171–176; the form in Komiya, Kodai
  Math. J. 11 (1988)) to `−f`, with `X` compact convex, `𝒮^{Π_T}` convex, and `−f` affine and continuous in each
  variable. This gives `min_θ sup_σ(−f) = sup_σ min_θ(−f)`, that is,
  `max_θ inf_σ f = inf_σ max_θ f`. (CITED theorem, verified hypotheses.)
4. *Identify both sides.*
  * *The inner infimum.* `inf_σ f(θ, σ)` splits over `p`. The infimum of an affine functional over finite mixtures
  equals its infimum over pure states, so `inf_σ f(θ, ·) = g(θ)`.
  * *Attainment.* `g` is an infimum of weak-* continuous functions, hence weak-* upper semicontinuous, so it
  attains its maximum on the compact `X`.
  * *The inner maximum.* `max_θ f(θ, σ) = C_0 + ∫K max_pε_{σ_p} + Σ_pQ_p(σ_p)`. It is attained at
  `θ_p = 𝟙{p = the least index achieving max_q ε_{σ_q}(u)}`, which is measurable.
  * Hence `max_X g = Φ_T`, and step 1 gives the equivalence.
5. *Comparison with the bottom.* The equal family `σ_p = |F⟩⟨F|` for all `p` has `Φ_T[(σ_p)] = 𝔞_T(F)`. ∎

**Reading of Theorem D (where the archimedean factor enters). PROVED.**
* Local certification is a *resource-allocation* problem. Each Euler factor `p` receives the share `θ_p(u)` of the
  archimedean jump density at jump size `u`.
* Its dual is a *multi-test* problem in which the archimedean place charges the pointwise **maximum** of the
  deficits `ε_{σ_p}` over the factors. It charges neither their sum nor any factor separately.
* The archimedean factor is thus the unique place that couples the Euler factors in the local problem, and it
  couples them through a sublinear functional.
* The gap `λ^A_T − Φ_T ≥ 0` measures exactly how much of the proved positivity is *cross-prime*, meaning carried by
  one test across several primes.

## §3 Monotonicity and the lower bound

**Lemma Mon. PROVED.** If `T′ > T` is locally certifiable, so is `T`. Hence the locally certifiable set is an
interval `(0, T_loc)` or `(0, T_loc]`.

*Proof.* Extension by zero maps `D_T` into `D_{T′}` isometrically. `A` and `B` are unchanged (the integrals see
only the support), and `H¹_0(I_T) ⊂ H¹_0(I_{T′})`. For `F ∈ D_T`, `c_F` vanishes off `[−2T, 2T]`. Consequently:
* `C_0‖F‖²` and `∫ε_FK_p` are the same numbers in both windows;
* `Q^{T′}_p(F) = Q^T_p(F)` for `p < e^{2T}`;
* `Q^{T′}_p(F) = 0` for `e^{2T} ≤ p < e^{2T′}`.

Merge every such `p`'s piece `(C_p, K_p)` into the label 2. The merged local form is the sum of two local forms,
each `≥ 0` on `D_T`. This gives an LK splitting on `Π_T` that certifies `RD_T`. ∎

**Proposition 3.1 (lower bound). PROVED.** `T_loc ≥ ½log3`.

*Proof.* For `½log2 < T ≤ ½log3`, `𝒩_T = {2}` and `Π_T = {2}`. The only LK splitting is `(C_0, K)` on the label
2, so local certifiability is `𝔞_T ≥ 0` on `D_T`. That holds by Paper 42, primitive form for `T ≤ log 2` (CITED;
at `T = ½log3` also P47 thm:C, `λ^A ≥ 8.86·10⁻⁵`). For `T ≤ ½log2` the same holds with `Π_T = ∅`. ∎
