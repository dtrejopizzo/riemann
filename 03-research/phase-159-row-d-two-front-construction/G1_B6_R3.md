## §1 Translation carriers

**Definition 1.1 (translation carrier).** A translation carrier is `(H, U, V, H_0, Ψ, Z)` where:
* **(T1)** `H` is a Banach space with a group `(U_s)_{s∈ℝ}` of bounded operators, `sup_{|s|≤1}‖U_s‖ < ∞`;
  `V ⊂ H` is a `U`-invariant linear subspace ("coboundaries"), `V̄` its closure, `H¹ := H/V̄` with the induced group,
  and `M := sup_s‖U_s|_{H¹}‖ ≤ ∞`. As in R2, `(H¹)^* = V̄^⊥ ⊂ H^*` isometrically and `‖U_s|_{H¹}‖ = ‖U_s^*|_{V̄^⊥}‖`
  (Hahn–Banach).
* **(T2)** `H_0 ⊂ H` is a dense subspace of "test elements", and `Z ⊂ ℂ` is a set with `Ψ : Z → H^*` such that
  `U_s^*Ψ(z) = e^{zs}Ψ(z)` for all `s`, `z ∈ Z`, and for every `F ∈ H_0` the function `z ↦ ⟨F, Ψ(z)⟩` is the
  restriction to `Z` of an entire function. (`Z` is the **visible set**; `Ψ(z)` is the adjoint eigenvector "`e^{zt}⊗h_0`",
  see Example 1.2.)
* **(T3) Tate coboundaries.** `V` is spanned by `U_sv`, `v` in a generating set `𝒢`, and for each `v ∈ 𝒢` there is a
  function `A_v`, entire, with `⟨v, Ψ(z)⟩ = ζ(½+z)·A_v(z)` for `z ∈ Z`.
* **(T4) local boundedness.** `z ↦ ‖Ψ(z)‖_{H^*}` is bounded on compact subsets of `Z`.

**Strip visibility (V_a).** For some `a > 0` and `λ_0 ≥ 0`: `Z ⊇ S_a^{λ_0} := {z : |Re z| < a, |Im z| > λ_0}`.

**Example 1.2 (concrete carriers; `PROVED` that they satisfy (T1)–(T4)).** Let `F` be a Banach space (the fibre:
`ℂ`; `L²(Ẑ^*)`; a noncommutative `L^p(N)`), `H` a Banach space of `F`-valued functions or distributions on the log
line `ℝ` with `U_sF = F(·−s)`, continuously embedded in `𝒟′(ℝ; F)`, containing `C_c^∞(ℝ)⊗F` (or a dense part of it)
as `H_0`. Fix `h_0 ∈ F^*` (the **ζ-fibre vector**: `h_0 = 1` for scalar carriers, `h_0 = 1_{Ẑ^*}` for `C_Q`, i.e. the
trivial-character component of R2 Rem 1.4). Put `Ψ(z) := e^{zt}⊗h_0`, i.e. `⟨F, Ψ(z)⟩ = ∫⟨F(t), h_0⟩e^{zt}dt` on
`H_0`, and `Z := {z : Ψ(z) extends to a bounded functional on H}`. Then (T2) holds (the integral is entire in `z` for
compactly supported `F`), and (T3) holds for the Tate coboundaries `v = Eg`, `g ∈ 𝒮_0`, by R2 Lemma 1.2:
`⟨Eg, Ψ(z)⟩ = Φ_{Eg}(½+z) = ζ(½+z)Mg(½+z)` with `A_v = Mg(½+·)` holomorphic on `Re z > −5/2` (entire after the
obvious modification of `𝒮_0`; only `|Re z| < ½` is used below, so "entire" in (T2)–(T3) may be read "holomorphic on
`|Re z| < ½`" throughout). Instances:
* Construction 9′ (`H = L²(w)`, `H^* = L²(w^{−1})`): `Z ⊇ S_{a}` for all `a < ½` by the last condition of R2 Def 1.1;
  `(V_a)` holds; `‖Ψ(β+iλ)‖ = (∫e^{2βt}w^{−1})^{1/2}` is independent of `λ` and continuous in `β`, so (T4) holds.
* Construction 9 over `C_Q`, fibre `L²(Ẑ^*)`, `h_0 = 1`: same.
* Cor B2 carriers (`‖F‖² = ∫|F|²w + (2π)^{−1}∫μ|F̂|²`): `‖·‖_{H^*} ≤ ‖·‖_{L²(w^{−1})}`, so `Z ⊇ S_a` and (T4) hold.
* The `L¹` carrier: `H = L¹(ℝ)`, `H^* = L^∞`, `Z = iℝ` (Prop E).
* `L^p(M, τ)` of the II_∞ core with the normalised dual action (R1 Cor 5): `Z = ∅` (R1 Thm 4: no eigenvectors at all).

**Lemma 1.3 (eigenvectors of concrete carriers are exponentials; `PROVED`).** In Example 1.2, every `h ∈ H^* ⊂
𝒟′(ℝ;F^*)` (the dual embedding induced by `H_0`) with `U_s^*h = e^{zs}h` for all `s` is of the form `e^{zt}⊗k` with
`k ∈ F^*` a constant. *Proof.* `e^{−zt}h` is a translation-invariant `F^*`-valued distribution: pairing with each `φ ∈ F`
gives a translation-invariant scalar distribution, hence a constant `c(φ)`, linear and continuous in `φ`, so `k := c`. ∎

Hence in a concrete carrier the zero-eigenvectors are **necessarily** members of exponential families `e^{zt}⊗k`, and
the only way for the ζ-eigenvectors not to belong to one fixed family `Ψ = e^{zt}⊗h_0` is for the fibre vector `k = k(γ)`
to depend on the zero. In the trivial-character sector `k` is constant (R2 Rem 1.4: annihilation of the Tate
coboundaries by `e^{iγt}⊗k` for all `g` forces `k ⊥` every nontrivial character). A zero-dependent `k(γ)` in a general
fibre is the residual escape; it is recorded as `OPEN` in §9, with the remark that a fibre whose admissible vector
depends on the zero encodes the zeros in the fibre structure (OT-3 exposure, `HEURISTIC`).

## §2 Lemma S′ (separation, modulus form) — `PROVED`

Let `X` be a Banach space, `(U_s)` a group on `X` with `M := sup_s‖U_s‖ < ∞`. R2 Lemma S(c): if `U_se = e^{iγs}e`,
`U_se′ = e^{iγ′s}e′`, `γ ≠ γ′`, then `‖e − e′‖ ≥ 2max(‖e‖,‖e′‖)/(M+1)`.

**Lemma S′.** Let `λ ↦ h_λ ∈ X` be any map (no regularity) with `U_sh_λ = e^{iλs}h_λ`, `h_λ ≠ 0`, defined on a set
`Λ ⊂ ℝ`, and let `ω_λ(δ) := sup\{‖h_μ − h_λ‖/‖h_λ‖ : μ ∈ Λ, |μ−λ| ≤ δ\}` be its relative modulus. If `M < ∞`, then
`ω_γ(γ′−γ) ≥ 2/(M+1)` for all `γ ≠ γ′` in `Λ`. In particular, if `Λ ⊇` the ordinates of a zero set with `N(X)/X → ∞`,
then for every `X` large there is `γ ∈ (X, 2X]` with `ω_γ(2π(1+o(1))/log X) ≥ 2/(M+1)`.

*Proof.* Lemma S(c) with `e = h_γ`, `e′ = h_{γ′}`, and the Riemann–von Mangoldt gap argument of R2 Thm A, Case 3. ∎

*Reading.* No continuity is needed: the law is a statement about the modulus at the zero spacing. Def B.1's `C¹`
hypothesis was only used to bound `ω_γ(δ) ≤ δR(γ)`. Theorem C shows that the hypothesis is not an assumption but a
consequence of visibility.

## §3 Theorem C — visibility forces holomorphy and bounds resolution — `PROVED`

### Lemma 3.1 (locally bounded weak\*-holomorphic maps into a dual are norm-holomorphic) — `PROVED` (standard)

Let `X` be a Banach space, `Ω ⊂ ℂ` open, `f : Ω → X^*` with `sup_K‖f‖ < ∞` on compacts `K ⊂ Ω`, and suppose
`z ↦ ⟨x, f(z)⟩` is holomorphic for every `x` in a dense subspace `X_0 ⊂ X`. Then:
* (i) `z ↦ ⟨x, f(z)⟩` is holomorphic for every `x ∈ X`;
* (ii) `f` is norm-differentiable on `Ω`, with derivative `f′(z) ∈ X^*` given by
  `⟨x, f′(z)⟩ = (2πi)^{−1}∮_{|ζ−z|=r}⟨x, f(ζ)⟩(ζ−z)^{−2}dζ` for any `r` with `D̄(z,r) ⊂ Ω`;
* (iii) **Cauchy estimate:** `‖f′(z)‖ ≤ r^{−1}max_{|ζ−z|=r}‖f(ζ)‖`.

*Proof.* (i) For `x ∈ X` pick `x_n ∈ X_0`, `x_n → x`. On a compact `K`, `|⟨x − x_n, f(z)⟩| ≤ ‖x−x_n‖sup_K‖f‖`, so
`⟨x, f(·)⟩` is a locally uniform limit of holomorphic functions, hence holomorphic.
(ii) Fix `z_0`, `r` with `D̄(z_0, 2r) ⊂ Ω`, `C := max_{|ζ−z_0|=2r}‖f(ζ)‖`. For `z ∈ D(z_0, r)` define `g(z) ∈ X^*` by the
displayed formula with the circle `|ζ−z_0| = 2r` (a bounded functional: `|⟨x,g(z)⟩| ≤ 2C‖x‖/r`). By the scalar Cauchy
formula applied to the holomorphic functions `⟨x, f(·)⟩` of (i), for `|h| < r/2`:
`⟨x, f(z+h) − f(z) − hg(z)⟩ = (2πi)^{−1}∮_{|ζ−z_0|=2r}⟨x,f(ζ)⟩·h²/((ζ−z−h)(ζ−z)²)dζ`,
and with `|ζ−z| ≥ r`, `|ζ−z−h| ≥ r/2` this is bounded by `(2π)^{−1}(4πr)·C‖x‖·|h|²/((r/2)r²) = 4C‖x‖|h|²/r²`. Taking
the sup over `‖x‖ ≤ 1`: `‖f(z+h) − f(z) − hg(z)‖ ≤ 4C|h|²/r²`, so `f` is norm-differentiable with `f′ = g`. The
formula in (ii) with any admissible `r` follows from the scalar Cauchy formula for `⟨x,f(·)⟩` and (i).
(iii) From (ii): `|⟨x, f′(z)⟩| ≤ (2π)^{−1}(2πr)·‖x‖max_{|ζ−z|=r}‖f(ζ)‖·r^{−2}`. ∎

(The general theorem, with `X^*` replaced by any Banach space and `X_0` by a separating set of functionals, is
Arendt–Nikolski, Math. Z. 234 (2000), Thm 3.1, `CITED`, not needed.)

### Definition 3.3 (strip magnification)

For a translation carrier with `(V_a)`, `0 < r < a`, and `|λ| > λ_0 + 1 + r`:
`𝔪(λ, r) := sup_{|μ−λ|≤1} max_{|z − iμ| = r} ‖Ψ(z)‖_{H^*} / ‖Ψ(iλ)‖_{H^*}`.
By the maximum principle for the subharmonic function `‖Ψ(·)‖` (the norm of a holomorphic map is subharmonic) and
(T4), `𝔪(λ,r) ≥ ‖Ψ(iλ)‖/‖Ψ(iλ)‖ = 1`, and `𝔪` is finite.

### Theorem C

Let `(H, U, V, H_0, Ψ, Z)` be a translation carrier (Def 1.1) with strip visibility `(V_a)`. Then:

*(i) Holomorphy.* `Ψ` is norm-holomorphic on `S_a^{λ_0}`. In particular `λ ↦ h_λ := Ψ(iλ)` is norm-`C^∞` on
`|λ| > λ_0`, and `∂_λh_λ = iΨ′(iλ)`.

*(ii) Visibility conditions.* (Z1) `h_γ ∈ V̄^⊥` for every on-line ordinate `γ` with `|γ| > λ_0`; (Z2) `∂_λh_λ|_γ ∈ V̄^⊥`
at every multiple on-line zero (indeed `∂^j_λh_λ|_γ ∈ V̄^⊥` for `j < m`); (Z3) for every off-line zero `ρ = ½+z` with
`z ∈ S_a^{λ_0}`, `Ψ(z) ∈ V̄^⊥` is a nonzero `U^*`-eigenvector with character `e^{zs}`. So Def B.1 of R2 holds on
`|λ| > λ_0`, and Theorem B applies verbatim (its proof only uses large heights).

*(iii) Resolution bound.* For `0 < r < a` and `|λ| > λ_0 + 1 + r`: `R(λ) ≤ 𝔪(λ, r)/r`, where
`R(λ) = sup_{|μ−λ|≤1}‖∂_μh_μ‖/‖h_λ‖` is R2's resolution function.

*(iv) Consequences (R2 Thm B).* If `M = sup_s‖U_s|_{H¹}‖ < ∞`, then RH holds, all zeros are simple, and
`liminf_{X→∞}(log X)^{−1}max_{γ∈(X,2X]}𝔪(γ, r)/r ≥ 1/(π(M+1))` for every fixed `r < a`. Hence:
* `𝔪(λ, r) = o(log λ)` for some fixed `r < a` ⟹ `M = ∞` (**unconditional**);
* `𝔪(λ, r) = O(log λ)` for some fixed `r` and (SG) ⟹ `M = ∞`.

*Proof.* (i) Apply Lemma 3.1 with `X = H`, `X_0 = H_0`, `Ω = S_a^{λ_0}`, `f = Ψ`: (T2) gives weak\*-holomorphy on
`H_0`, (T4) gives local boundedness. (ii) For `v ∈ 𝒢` and `s ∈ ℝ`, `⟨U_sv, Ψ(z)⟩ = ⟨v, U_s^*Ψ(z)⟩ = e^{zs}ζ(½+z)A_v(z)`,
a holomorphic function of `z ∈ S_a^{λ_0}` vanishing to order `≥ m` at `z_0 = ρ − ½` whenever `ζ` vanishes to order `m`
at `ρ`. For `v ∈ V̄`, `⟨v, Ψ(·)⟩` is a locally uniform limit (by (T4)) of finite linear combinations of such functions,
hence holomorphic and, by the Cauchy estimates for the derivatives, still vanishing to order `≥ m` at `z_0`. Thus
`⟨v, Ψ^{(j)}(z_0)⟩ = 0` for `j < m`, `v ∈ V̄`, which is (Z1)–(Z3). `Ψ(z) ≠ 0` because `⟨F, Ψ(z)⟩ = ∫⟨F,h_0⟩e^{zt} ≠ 0` for
suitable `F ∈ H_0` (in Example 1.2; in the abstract setting this is part of (T2) by convention). (iii) Lemma 3.1(iii)
at the points `iμ`, `|μ−λ| ≤ 1`, divided by `‖Ψ(iλ)‖`. (iv) R2 Theorem B(i), (iii) with `R(γ) ≤ 𝔪(γ, r)/r`. ∎

**Remark 3.4 (what the theorem does to the panel's escape; `PROVED` by (i)).** "A zero-free carrier that avoids a
norm-`C¹` eigenfamily" cannot see any two-sided strip around the line at large heights. Conversely every carrier that
can host an off-line zero and its mirror `1−ρ̄` at distance `r` from the line, for one `r > 0`, at all large heights,
has a `C^∞` eigenfamily. Regularity of the eigenfamily is not an extra hypothesis: it is the analytic content of
visibility.

## §4 Theorem D (blind or resolved) and Corollary D1 — `PROVED`

**Theorem D.** Let `(H,U,V,H_0,Ψ,Z)` be a translation carrier (Def 1.1; in the concrete case, Example 1.2 with a
fixed ζ-fibre vector `h_0`). Exactly one of the following holds.

*(a) Blind near the line.* For every `a > 0` and every `λ_0`, `Z ⊉ S_a^{λ_0}`: there are hypothetical zero positions
`ρ = ½ + z` with `|Re z|` arbitrarily small and `|Im z|` arbitrarily large for which `Ψ(z) ∉ H^*`. Then:
* the counterfactual clause NC4 of OT-5′ (R158_001 l.307: "Would `𝒪` still exist, with the form still defined, if a
  zero were off the line?") fails for those positions — the carrier has no functional that could register such a zero,
  and (Z3) is unavailable there;
* in particular the on-line eigenvectors `Ψ(iγ)` are not restrictions of any locally bounded holomorphic family, so
  Theorem B does not apply, and `M < ∞` has no RH consequence (Prop E shows this can happen with `M = 1`);
* no proof of OT-2 (the Lefschetz identity with the **full** zero sum) can be carried out on the carrier without a
  zero-location input finer than the known ones: a zero-free proof must be valid for every configuration compatible
  with the Hadamard strip `0 < Re ρ < 1` and the classical zero-free region, and such configurations include zeros at
  the invisible positions (`PROVED` as a logical statement about proofs that do not use the position of the zeros).

*(b) Resolved.* `(V_a)` holds for some `a > 0`. Then Theorem C applies: the eigenfamily is holomorphic, (Z1)–(Z3) hold,
and `M < ∞` forces RH ∧ SZ and `𝔪(λ, r)/r ≠ o(log λ)` for every fixed `r < a` (unbounded over `log λ` under (SG)).

*Proof.* (a) and (b) are complementary by definition of `(V_a)`. The three bullets of (a): the first is the definition of
NC4 read on the dual (an off-line zero at `ρ` is registered by the carrier if and only if `V̄^⊥` contains an eigenvector
with character `e^{(ρ−½)s}`; by Lemma 1.3 that eigenvector is `e^{(ρ−½)t}⊗k`, and in the trivial-character sector
`k ∝ h_0`, so it is `Ψ(ρ−½)`, which is not in `H^*`). The second is the contrapositive of Theorem C(i) together with
the observation that Lemma S′ needs the eigenvectors of the off-line zeros only through (Z3). The third: the
zero sum on the spectral side of OT-2 must contain the term of every zero; on the carrier the only functionals with the
right character are the `Ψ(z)`; if `Ψ(z) ∉ H^*` for an admissible hypothetical position `z`, then an argument that does
not use the actual position of the zeros cannot exclude that a zero sits at `z`, and then the identity is unprovable
by that argument. (b) is Theorem C. ∎

**Remark 4.1 (two-sidedness is forced; `PROVED`, classical).** Zeros of `ζ` come in pairs `ρ, 1−ρ̄`, i.e. `z, −z̄`. So
the strip must be visible on both sides of the line. A one-sided carrier (dual containing `e^{βt}h_0` only for `β ≥ 0`)
is in case (a).

**Corollary D1 (modulation-invariant carriers; `PROVED`).** Suppose in addition to `(V_a)` that the dual norm is
modulation-invariant on the eigenfamily: `‖e^{iλt}Ψ(β)‖_{H^*} = ‖Ψ(β)‖_{H^*}` for all real `λ, β` with `|β| < a`
(i.e. `‖Ψ(β+iλ)‖` does not depend on `λ`). Then `𝔪(λ, r) ≤ c(r) := max_{|β|≤r}‖Ψ(β)‖/‖Ψ(0)‖ < ∞` for all `λ`, so by
Theorem C(iv)

  `sup_s‖U_s|_{H¹}‖ = ∞` **unconditionally**, whatever RH says.

This covers: every time-weighted `L^p` carrier `L^p(ℝ, w; F)`, `1 < p < ∞`, with any fibre `F` (commutative or a
noncommutative `L^p(N)`), any ζ-fibre vector, and any weight admitting a two-sided exponential moment `∫e^{2a|t|}w^{−p′/p}
< ∞`; Construction 9 (over `C_Q`), 9′, and their `L^p` and fibred versions. It **does not** cover carriers with a
frequency-dependent norm (Cor B2's archimedean energy `μ`, phase-space weights), where `𝔪` can grow: there Theorem C(iv)
gives the requirement `𝔪(λ, r) ≫ log λ`.

*Proof.* `max_{|z−iμ|=r}‖Ψ(z)‖ = max_{|z−iμ|=r}‖Ψ(Re z)‖ ≤ max_{|β|≤r}‖Ψ(β)‖` by modulation invariance, and
`‖Ψ(iλ)‖ = ‖Ψ(0)‖`. Then `𝔪(λ,r)/r ≤ c(r)/r = O(1) = o(log λ)`. Apply Theorem C(iv). For the weighted-`L^p` class the
dual norm is `L^{p′}(w^{−p′/p})`, `‖e^{(β+iλ)t}⊗h_0‖ = ‖h_0‖·(∫e^{p′βt}w^{−p′/p})^{1/p′}`, independent of `λ`, finite
for `|β| ≤ a` by the moment condition, continuous in `β` (dominated convergence), so (T4) and `(V_a)` hold. ∎

**Remark 4.2 (what Cor D1 adds to R2 Theorem A; `PROVED` by comparison).** Theorem A needed: `p = 2`, scalar or `C_Q`
fibre, the explicit moments `n_w, K_w`, and the `C¹` family through `t·e^{iγt} ∈ L²(w^{−1})`. Cor D1 needs none of
these: the derivative is never computed; it is bounded by the off-line eigenvectors through the Cauchy estimate. The
constant is worse (no explicit `2n_w/πK_w`), the scope is the whole modulation-invariant class.

## §5 The magnification form of N-e — `PROVED` (in the class of Def 1.1 with `(V_a)`), `HEURISTIC` beyond

R2 stated N-e as: a P-HS object on a zero-free quotient carrier must have `R(λ)/log λ ↛ 0` (unbounded under (SG)).
Theorem C(iii) rewrites it in terms of the carrier's geometry alone:

**N-e (magnification form).** A translation carrier with strip visibility `(V_a)` and `sup_s‖U_s|_{H¹}‖ < ∞` must
satisfy, for every fixed `r < a`,
  `liminf_{X→∞}(log X)^{−1}max_{γ∈(X,2X]}𝔪(γ, r) ≥ r/(π(M+1)) > 0`,
i.e. **at height `λ` the dual norm must weigh an eigenvector `r` off the line at least `≍ log λ` times more than the
on-line eigenvector**, along a positive proportion of dyadic blocks; under (SG), the ratio `𝔪(γ,r)/log γ` must be
unbounded. Equivalently, taking `r = r(λ) ↓ 0`: `𝔪(λ, r(λ)) ≳ r(λ)log λ`, so with `r(λ) = 1/log λ` (the zero
spacing) `𝔪(λ, 1/log λ) ≳ 1/(π(M+1))`, which is no constraint (since `𝔪 ≥ 1`) unconditionally, and must be
**unbounded** under (SG). The carrier has to resolve the strip at the scale of the zero spacing, anisotropically: fine in
the imaginary direction (to separate the zeros), amplified in the real direction (to see off-line positions), with the
ratio growing like the Riemann–von Mangoldt density.

*Reading (`HEURISTIC`).* Weil's `H¹(C×C)` is finite-dimensional and `𝔪` is irrelevant there. Over `Spec Z` the
analogue of the "topology of the surface" must encode the log-density of the zeros as an anisotropy of the dual norm
around the critical line, **before** the spectrum. Cor B2 of R2 (archimedean energy `μ`) is the only zero-free device
of record that produces `λ`-dependence of the dual norm, and it needs `μ* ≳ log²` to pass N-e while `μ* ≳ log`
already makes Weil's form small relative to the norm (R2 Prop C, Rem B.4). Whether any zero-free device gives
`𝔪(λ, r) ≫ log λ` **and** keeps the Lefschetz identity (OT-2) is `OPEN`; I know none.

## §6 The flat escape (Prop E), and the operator-algebraic rows

### Proposition E (the `L¹` carrier) — `PROVED`

Let `H = L¹(ℝ)`, `U_sF = F(·−s)`, `V = span\{U_sEg : s ∈ ℝ, g ∈ 𝒮_0\}` with `Eg` as in R2 Def 1.1 (Schwartz on the log
line by R2 Lemma 1.2, so `V ⊂ L¹`), `H¹ = L¹/V̄`, `H_0 = C_c^∞`. Then:

*(i)* `(U_s)` is isometric on `L¹` and on `H¹`: `M = 1`, unconditionally. The carrier is zero-free (OT-3 ✓ in the
definition).

*(ii)* `V̄^⊥ = \{h ∈ L^∞ : supp ĥ ⊂ Z_crit\}` where `Z_crit` is the set of ordinates of the **on-line** zeros. Its
`U^*`-eigenvectors are exactly the `e^{iγt}`, `γ ∈ Z_crit`, and `‖e^{iγt} − e^{iγ′t}‖_∞ = 2` for `γ ≠ γ′`: Lemma S′
is satisfied with `ω_γ(δ) = 2` for all `δ > 0`: infinite resolution, no continuity.

*(iii)* The visible set is `Z = iℝ`: `e^{zt} ∉ L^∞` for `Re z ≠ 0`. The carrier is in case (a) of Theorem D. Off-line
zeros and Jordan chains (`t e^{iγt} ∉ L^∞`) are invisible; (Z2), (Z3) fail.

*(iv)* No positive form of Weil type is continuous on it: for `F ∈ C_c^∞`, `W(F*F̃) ≤ C‖F‖²_{L¹}` is false (R1 Thm 1(b)).

*Proof.* (i) `‖F(·−s)‖_1 = ‖F‖_1`; a quotient of an isometry by an invariant closed subspace is isometric on the
quotient (`inf_v‖U_sF − v‖ = inf_v‖F − U_{−s}v‖`). (ii) `h ∈ L^∞` annihilates `V` iff `(h * (Eg)^∨)(s) = 0` for all `s`
and `g`, iff (Fourier transform in `𝒮′`, using `\widehat{Eg} ∈ 𝒮`) `ĥ·\widehat{Eg} = 0` for all `g`, iff `supp ĥ ⊂
∩_g\{λ : Φ_{Eg}(½+iλ) = 0\}` (where `\widehat{Eg}(λ_0) ≠ 0`, `ĥ = \widehat{Eg}^{−1}(ĥ\widehat{Eg}) = 0` near `λ_0`).
By R2 Lemma 1.2, `Φ_{Eg}(½+iλ) = ζ(½+iλ)Mg(½+iλ)`. For each `λ_0` some `g ∈ 𝒮_0` has `Mg(½+iλ_0) ≠ 0`: otherwise the
functional `g ↦ ∫_0^∞g(x)x^{iλ_0−½}dx` on even Schwartz functions would vanish on the common kernel of `g ↦ g(0)` and
`g ↦ ∫g`, hence be a linear combination `c_1δ_0 + c_2·1` as a distribution on even test functions, which the locally
integrable non-constant function `|x|^{iλ_0−½}` is not. So the intersection is `Z_crit`. Eigenvectors: `U_s^*h =
e^{iγs}h` gives `supp ĥ ⊂ \{γ\}`, so `h = P(t)e^{iγt}` with `P` a polynomial, and `h ∈ L^∞` forces `P` constant.
(iii) `|e^{zt}| = e^{(Re z)t}` is unbounded for `Re z ≠ 0`. (iv) is R1 Thm 1(b): `W_ε(F_ε) ≍ ε^{−1}log(1/ε)` while
`‖F_ε‖_1 = 1`. ∎

**Remarks (`PROVED` unless marked).**
* (E1) Prop E is the **sharpness** of Theorem B and of Theorem C: a zero-free carrier with `M = 1 < ∞` exists, it has no
  `C¹` (not even `C⁰`) eigenfamily, and the reason is exactly blindness (`Z = iℝ`). Theorem B(i) ("`M < ∞ ⟹ RH`") fails
  to apply because (Z3) fails, and indeed `M = 1` is consistent with any zero configuration.
* (E2) By the classical synthesis theorem for closed countable sets (`CITED`, standard: Rudin, *Fourier Analysis on
  Groups*, 7.2.5; not load-bearing), `V̄ = \{F ∈ L¹ : F̂ = 0 on Z_crit\}`, so `H¹ ≅ L¹/I(Z_crit)` and `V̄^⊥` is the
  weak\*-closed span of `\{e^{iγt}\}_{γ∈Z_crit}`: the carrier is the `L¹` version of the Bohr / Kronecker-line
  structure of B2 Theorem S (`HEURISTIC` link; different proofs).
* (E3) OT status of the `L¹` carrier: OT-1 (an `H¹` with the on-line zeros as adjoint eigenvalues) ✓ for on-line zeros
  only; OT-2 ✗ (blind: no off-line term can appear, and no form is continuous, (iv)); OT-3 ✓; OT-5′ (P-HS) requires a
  Hilbert norm and Weil's form; the isometric flow is there but no Hilbert structure compatible with Weil is (by (iv),
  Weil's form is not even continuous); (D3) holds trivially and proves nothing. It is a **decoy**: everything that
  looks like OT-5′ is satisfied and nothing about the zeros follows. This is the cleanest illustration in the record
  that "a flow-compatible positive/isometric structure defined before the spectrum" is worthless without full
  visibility (R1 Thm 7, Theorem D).

### The operator-algebraic rows (brief: II_∞ dual trace, Bost–Connes; R158_004 A23 rows 17(ii)–(iii))

* **Crossed-product traces/states as OA-carriers (the brief's object).** R1 Theorem 2 / Cor 2.1 (`PROVED`, content
  classical): any positive functional on a crossed product whose restriction to the flow satisfies the Lefschetz
  identity has a GNS space equal to `L²(μ_Z)` — a Hilbert–Pólya realisation — so proving OT-2 for it is RH-strength
  (Lemma T). R1 Thm 1 (`PROVED`): the functional cannot be a state (the archimedean term diverges like `log(1/ε)`), so
  it must be an unbounded weight. **Unchanged in round 3; this closes the brief's object.**
* **II_∞ core of a III_1 factor with the normalised dual action** (R1 Cor 5): `L^p(M,τ)` has no eigenvectors for any
  character (R1 Thm 4), i.e. as a translation carrier its visible set is `Z = ∅`: the extreme case (a) of Theorem D.
  Every quotient `L^p(M,τ)/V̄` inherits a null form on eigenclasses (R1 Thm 3). Nothing to add; the dichotomy places it
  in the blind branch.
* **Bost–Connes at `β > 1`** (R1 Prop 6): the Gibbs carriers `ℓ²(ℕ)` have one-sided spectrum `log ℕ` and are not
  translation carriers over the log line in the sense of Def 1.1 (the flow is `e^{itH}`, `H = log n`, and the weights
  pull back to positive measures on `log ℕ`); excluded by the symmetry of `μ_Z`. At `β ≤ 1` the only implementation is
  the core, previous row. Unchanged.
* **Connes' `L²(C_Q)` with the scaling flow** (R1 Cor 5(c)): Lebesgue spectrum, no eigenvectors, `Z = ∅` in `L²`;
  the absorption spectrum is a cokernel phenomenon. In the Meyer–CCM nuclear realisation (not Banach) Theorem C does
  not apply as stated; R158_004 rows 11, 15 govern it (Lemma U: any definite compatible form ⟹ RH ∧ SZ; OT-5′ = Weil's
  criterion there).

**Verdict on the angle (`PROVED` by the above).** Within operator algebras, a positive functional on a crossed product
is a Hilbert–Pólya model as soon as it satisfies OT-2 (Lemma T); the concrete Hilbertian/Banach carriers with a flow
either are blind (`Z = ∅` or `Z = iℝ`: cores, `L²(C_Q)`, `L¹`) or, if they see a strip, fall under the resolution law,
which excludes every modulation-invariant one unconditionally (Cor D1) and leaves for the rest the requirement
`𝔪(λ, r) ≫ log λ` with OT-2 intact, of which no zero-free instance is known. **The object of the brief is not
constructed and this angle cannot construct it.**

## §8 What is genuinely new

1. **Theorem C.** On a translation carrier, strip visibility (the ability to register a hypothetical off-line zero and
  its mirror at large heights) forces the eigenfamily to be norm-holomorphic, and bounds the resolution function by
  the strip magnification: `R(λ) ≤ 𝔪(λ,r)/r`. The `C¹` hypothesis of R2 Def B.1 is removed: it is a consequence of
  the object test's own clause NC4.
2. **Theorem D.** Zero-free translation carriers are blind near the line (and then fail NC4 and cannot carry an
  unconditional OT-2) or resolved (and then obey the resolution law). The named escape of the panel lies entirely in
  the blind branch.
3. **Corollary D1.** All modulation-invariant carriers (time-weighted `L^p`, any fibre, any `p ∈ (1,∞)`, commutative
  or von Neumann) with strip visibility fail P-HS unconditionally, without computing a derivative. Theorem A of R2 is
  the `L²`, scalar, explicit-constant case.
4. **Proposition E.** The `L¹` carrier: zero-free, isometric flow (`M = 1`), eigenfamily nowhere continuous, blind,
  Weil form discontinuous — the sharpness example for Theorem B and the cleanest decoy in the record.
5. **N-e in magnification form**: the object must weigh off-line positions `≫ log λ` times more than on-line ones at
  height `λ`, i.e. the zero density must be built into the anisotropy of the dual norm around the critical line,
  before the spectrum.

Not new: Lemma 3.1 (standard vector-valued holomorphy); Lemma S′ (trivial); Serre's argument; Riemann–von Mangoldt;
synthesis for countable sets; the GNS collapse (Lemma T).

## §9 The weakest step

* **Scope: translation carriers with a fixed ζ-fibre vector `h_0`.** Lemma 1.3 shows eigenvectors of concrete carriers
  are `e^{zt}⊗k`; the reduction to one family `Ψ = e^{zt}⊗h_0` uses that in the trivial-character sector the fibre
  vector annihilating the Tate coboundaries is constant. A carrier whose fibre admits a **zero-dependent** `k(γ)`
  (e.g. a norm on `ℝ × Y` that couples the frequency `λ` to the fibre coordinate in a way that is not the tensor
  structure of Example 1.2) is outside Theorem C as stated: `OPEN`. My reading is that such a coupling is where the
  zeros would be encoded in the fibre (OT-3 exposure), `HEURISTIC`. This is where a reader should push now.
* **Hypothesis (T4)** (local boundedness of `‖Ψ(z)‖` on the visible strip) is assumed. It holds for every carrier of
  record (weighted `L^p` norms are continuous in `β` and constant in `λ`; energy norms are dominated by them). A
  carrier with `(V_a)` but with `‖Ψ(z)‖` unbounded on compacts of the strip would escape Lemma 3.1; I know no natural
  example (the norm of a weakly holomorphic map is lower semicontinuous, and a Baire argument gives local boundedness
  on a dense open subset of the strip, which would suffice to run the Cauchy estimate on that subset — not written
  out, `OPEN` as a refinement).
* **Theorem D(a), third bullet** is a statement about proofs (an unconditional Lefschetz identity cannot omit an
  admissible zero position); it is logically clear but not a theorem inside a fixed formal system, and it is labelled
  accordingly. The first two bullets are ordinary theorems.
* **Nuclear / non-Banach carriers** (Meyer's `H¹`, CCM) are outside Def 1.1; Lemma 3.1 has Fréchet analogues but I
  have not written them. Those carriers are governed by R158_004 rows 11, 15 (Lemma U; OT-5′ = Weil's criterion).
* **(SG)** is unproved; only the "unbounded" clauses depend on it, as in R2.
* **Citations.** Riemann–von Mangoldt and R2 Lemma 1.2 (Poisson / Tate) are `CITED` standard; Arendt–Nikolski is
  mentioned for context only; Rudin 7.2.5 is non-load-bearing.
