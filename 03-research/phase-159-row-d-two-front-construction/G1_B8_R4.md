## §2 Canonical systems: the facts used (all CITED)

A canonical system is `J Y′(x, z) = z H(x) Y(x, z)` on `[0, L]`, with:
* `J = [[0, −1], [1, 0]]`;
* `H ≥ 0` real symmetric and locally integrable;
* transfer matrix `M(x, z)` with `M(0, z) = I`;
* `E_x = Θ⁺(x,·) + iΘ⁻(x,·)`, the Hermite–Biehler function built from the first column;
* the de Branges space `H_x = B(E_x)`, with norm `‖F‖² = ∫|F/E_x|² dt` up to a constant.

The normalisation (compatibility condition (L)) is that of Romanov, *Canonical systems and de Branges spaces*,
arXiv:1408.6022 (read). Write `τ(x) := ∫_0^x √det H`.

* **(F1) Krein–de Branges formula.** `E_x` and all entries of `M(x,·)` are entire of the same exponential type, equal to
  `τ(x)` (Romanov Thm 11, Lemma 17). `E_x` is a regular HB function without real zeros, hence of bounded type in `C₊`.
  Since `E_x^# = Θ_x E_x` with `|Θ_x| ≤ 1` in `C₊`, `E_x` is of bounded type in both half-planes, hence of Cartwright
  class (Krein's theorem).
* **(F2) Chain.** For `x ≤ x′` outside the interiors of singular intervals, `H_x ⊂ H_{x′}` isometrically. `H_x` depends
  only on `H|[0,x]` (Romanov proof of Thm 13, and Thm 5).
* **(F3) Ordering.** Let two de Branges spaces be contained isometrically in a third, with HB functions without real zeros.
  Then one of them contains the other (Romanov Thm 12 / Cor 19; de Branges 1968, Thm 35).
* **(F4) Subspaces are chain members.** Let `X` be a de Branges space, with HB function without real zeros, contained
  isometrically in `H_L`. Then `X = H_y` for some `y ≤ L` outside the interiors of singular intervals. This is the argument
  of Romanov, proof of Thm 13, step II, with `H¹_t` replaced by `X`; that argument uses only (F2), (F3) and the
  singular-interval analysis. See also de Branges 1968, Thm 40.
* **(F5) Axiomatic characterisation (de Branges Thm 23 / Romanov Thm 19).** A nonzero Hilbert space of entire functions
  is a de Branges space if it satisfies three axioms:
  * (H1) point evaluations are continuous;
  * (H2) if `F(w) = 0`, then `F(z)(z − w̄)/(z − w)` lies in the space with the same norm;
  * (H3) `F^#` lies in the space with the same norm.
* **(F6) Mean type.** Mean type is additive on functions of bounded type in `C₊`. For `G ∈ H²(C₊)` and `a > 0`,
  `mt₊(G) ≤ −a ⟺ G ∈ e^{iaz}H²`, by inner–outer factorisation (Garnett, *Bounded Analytic Functions*, Ch. II). For a
  Cartwright function, `mt₊(F) = h_F(π/2)` and the exponential type is `max(h_F(π/2), h_F(−π/2))`.

## §3 Definitions

**Def 3.1 (the family and its forms).**
* 𝔉 is the set of even primitive Dirichlet characters `χ` of prime conductor `N`. The completed L-function is
  `(N/π)^{s/2}Γ(s/2)L(s,χ)`, which is entire.
* For `f ∈ C_c^∞(R)` put `g = f * f̃` with `f̃(x) = \overline{f(−x)}`, and `F(t) = ∫ f(x)e^{ixt}dx`.
* The Weil form of `χ` is defined **from the prime side**:
  ```
  Q_χ(f) := g(0) log(N/π) + (1/2π)∫|F(t)|² Re(Γ′/Γ)(¼ + it/2) dt
  − Σ_{n≥2} Λ(n) n^{−½} [χ(n) g(log n) + \bar χ(n) g(−log n)].
  ```
* By Weil's explicit formula this equals `Σ_ρ |F(γ_ρ)|²` in the usual sense (CITED: Iwaniec–Kowalski, Thm 5.12). The
  identity is **not used** anywhere. For `supp f ⊂ (−r, r)` the sum is finite: `n < e^{2r}`.
* Its distribution is `D_χ := log(N/π)δ₀ + (arch) − Σ_n Λ(n)n^{−½}(χ(n)δ_{log n} + \barχ(n)δ_{−log n})`, so that
  `Q_χ(f) = D_χ(g)`.

**Def 3.2 (window realisation).** Let `𝒟_r := {\hat f : f ∈ C_c^∞(−r, r)}` (Fourier transforms `F`). A canonical system
*realises the window `r` of `χ`* if there is an `x` such that `𝒟_r ⊂ H_x` and `‖F‖²_{H_x} = Q_χ(f)` for all
`f ∈ C_c^∞(−r, r)`. This is OT-2 restricted to one window, in the de Branges carrier. It forces `Q_χ` to be positive
definite on that window.

**Def 3.3 (sequential data-local rule, SDL).** Fix:
* an index set `I = I_∞ ⊔ {primes} ⊔ {glob}`;
* a well-order `≺` on `I` (the layout), independent of the L-function.

The rule assigns to each index a finite-length Hamiltonian block:
* an **archimedean block** `B_i`, `i ∈ I_∞`, depending only on the gamma factor `Γ(s/2)` (the same for all of 𝔉);
* a **global block** `B_glob`, depending only on (gamma factor, pole order). It is the same for all of 𝔉, since there
  are no poles;
* a **prime block** `B_{p,b}`, depending only on `p` and the local datum `b` at `p`.
  * For `p ∤ N` the local datum is `b = (χ(p)^k log p)_k`.
  * For `p = N` it is the ramified local datum, meaning the local character `χ_N` together with the conductor exponent.

The Hamiltonian of `χ` is the concatenation of the blocks in the order `≺`. The block of index `i` starts at
`x_i = Σ_{j≺i} ℓ_j`, and `s_i := τ(x_i)` is its **start type**.

* **Condition (F):** for every `r`, only finitely many prime blocks start at type `≤ r` in the reference chain below.
* **The reference chain `R`** is the chain with trivial local data `b = (log p)_k` at every prime. These are ζ's local
  data. The archimedean and global blocks are those of 𝔉. Put `Q_r := {p : s_p ≤ r in R}`.
* **Conductor convention.** Convention **(T)** (Tate) counts `log N · g(0)` as part of the ramified datum at `N`.
  Convention **(G)** lets the global block also depend on `N`, and then assumes that `Q_r` does not depend on `N`. The
  theorem below holds under either convention; Cor K.3 needs (T).

**Def 3.4 (Frobenius-local).** An SDL rule is *Frobenius-local* if, for every `p` and every local datum `b` in its
domain, the block transfer matrix is `M_{p,b}(z) = Φ_{p,b}(p^{iz})`, non-constant, with `Φ_{p,b}` holomorphic on `C*`.
* The variable `p^{iz}` is the Frobenius shift `u ↦ u + log p` on the line: see R3 §2.
* The constant-coefficient block with `ℓ√det H = log p`, whose transfer matrix is `cos(z log p) I + sin(z log p) JH/√det H`,
  is the basic example.
* Phase-61 O8 (`respuestas-matematicos.md`, §O8: `T_S = T_∞ Π_p T_p`, local Hamiltonian `H_p` on an interval
  `ℓ_p ∝ log p`, concatenated) is of this shape. Its `T_p` as written is not entire, since the Euler-factor Cayley
  transform has poles, so it needs an entire repair to be a canonical system at all. Cor K.1 applies to every repair of
  this shape.

## §4 Lemmas

**Lemma P (non-vacuity: the targets are positive; PROVED modulo the CITED formula, used only as a definition).** For every
`r > 0` put `C(r) := log π − ψ(¼) + 2Σ_{n<e^{2r}} Λ(n)n^{−½}`, where `ψ(¼) = −γ − π/2 − 3log 2 ≈ −4.2274`. If
`log N > C(r) + 1`, then `Q_χ(f) ≥ g(0) = ‖f‖²₂` for all `f ∈ C_c^∞(−r, r)` and all `χ ∈ 𝔉` of conductor `N`.

*Proof.*
1. `g` is positive definite, so `|g(x)| ≤ g(0) = ‖f‖²`, and `(1/2π)∫|F|² = ‖f‖²` by Plancherel.
2. `Re ψ(σ + iu) = ψ(σ) + Σ_{k≥0} u²/((k+σ)((k+σ)² + u²)) ≥ ψ(σ)` for `σ > 0`.
3. Hence the archimedean part is `≥ ψ(¼)‖f‖²`, and the prime part has modulus `≤ 2Σ_{n<e^{2r}} Λ(n)n^{−½}‖f‖²`. ∎

**Lemma A (the window space is a de Branges space; PROVED).** Suppose `𝒟_r ⊂ H_x` isometrically for the form `Q_χ`. Let
`𝒫_r` be the closure of `𝒟_r` in `H_x`. Then `𝒫_r` is a de Branges space whose HB function has no real zeros.

*Proof.*
1. **Stability of `𝒟_r`.** `F^# = \widehat{\bar f(−·)} ∈ 𝒟_r`. If `F(w) = 0`, then `F(z)/(z − w) = \hat h` with
  `h(x) = −ie^{−iwx}∫_{−∞}^x f(s)e^{iws}ds`. This `h` is smooth and vanishes for `x < −r′` and for `x > r′` (the latter
  because `F(w) = 0`), where `supp f ⊂ [−r′, r′] ⊂ (−r, r)`. So `F(z)(z − w̄)/(z − w) = F + (w − w̄)\hat h ∈ 𝒟_r`.
2. **Passage to the closure.**
  * `#` is an isometry of `H_x`, so the closure is `#`-stable.
  * Let `F ∈ 𝒫_r` with `F(w) = 0`, and let `F_n → F` with `F_n ∈ 𝒟_r`. Pick `G ∈ 𝒟_r` with `G(w) ≠ 0` and put
  `F′_n := F_n − (F_n(w)/G(w))G`. Then `F′_n ∈ 𝒟_r`, `F′_n(w) = 0` and `F′_n → F`, by continuity of evaluation.
  * The division map is isometric on `{F ∈ H_x : F(w) = 0}`, so the images of `F′_n` converge to that of `F`, which
  therefore lies in `𝒫_r`.
  * (H1) is inherited. By (F5), `𝒫_r` is a de Branges space.
3. **No real zeros.** A real zero `t` of its HB function would force every element to vanish at `t`. But `\hat f(t) ≠ 0`
  for a suitable bump `f`. ∎

**Lemma B (type lemma; PROVED modulo (F1), (F6)).** If `𝒫_r = H_y` isometrically, as in (F4), then `τ(y) ≤ r`.

*Proof.*
1. Let `τ := τ(y)` and `E := E_y`, which is Cartwright of type `τ` by (F1). In `C₊` we have `|E^#| ≤ |E|`, so
  `h_E(−π/2) ≤ h_E(π/2)` and `mt₊(E) = τ` by (F6).
2. Suppose `τ > r` and put `a := τ − r > 0`. For `F_n ∈ 𝒟_r` we have `|F_n(z)| ≤ ‖f_n‖₁e^{r|Im z|}`, so
  `mt₊(F_n) ≤ r`, and `G_n := F_n/E ∈ H²` has `mt₊(G_n) ≤ r − τ = −a` (additivity).
3. So `G_n ∈ e^{iaz}H²`. That space is closed, and `F ↦ F/E` is an isometry of `H_y` onto a subspace of `H²`. Hence
  `F/E ∈ e^{iaz}H²` for **every** `F ∈ 𝒫_r = H_y`.
4. Now take the reproducing kernel `K(w, ·) ∈ H_y`. It satisfies
  `K(w,z)/E(z) = \overline{E(w)}(1 − Θ(z)\overline{Θ(w)})/(2πi(w̄ − z))`, with `Θ = E^#/E`.
  * `|1 − Θ(z)\overline{Θ(w)}| ≥ 1 − |Θ(w)| > 0`, since `E` is strictly HB, so this factor has mean type 0.
  * `1/(w̄ − z)` has mean type 0.
  * So `mt₊(K(w,·)/E) = 0 > −a`. This is a contradiction. ∎

**Lemma C (polarisation; PROVED).** Let `D` be a distribution on `(−2r, 2r)` with `D(f * f̃) = 0` for all
`f ∈ C_c^∞(−r, r)`. Then `D = 0` on `(−2r, 2r)`.

*Proof.*
1. Polarisation gives `D(f * h̃) = 0` for all `f, h ∈ C_c^∞(−r, r)`.
2. So the distribution `(x, y) ↦ D(x − y)` vanishes on `(−r, r)²` against all product tests, hence on all of `(−r, r)²`,
  since products are total.
3. Every point of `(−2r, 2r)` is of the form `x − y` there, so the pull-back determines `D` on `(−2r, 2r)`. ∎

**Echo Lemma E (PROVED modulo (F2)–(F4)).** Let two canonical systems `H¹`, `H²` coincide on `[0, x*]`, and let
`τ(x*) > r`. Suppose `Hⁱ` realises the window `r` of a form `Qᵢ` (`i = 1, 2`). Then `Q₁ = Q₂` on `C_c^∞(−r, r)`. If
`Qᵢ = Dᵢ(f * f̃)`, then `D₁ = D₂` on `(−2r, 2r)`.

*Proof.*
1. By Lemma A and (F4), `𝒫ⁱ_r = Hⁱ_{y_i}`, and by Lemma B `τ_i(y_i) ≤ r < τ(x*)`. Since `τ_i = τ` on `[0, x*]` and is
  non-decreasing, `y_i < x*`.
2. By (F2), `H¹_{y_i} = H²_{y_i} =: H_{y_i}` depends only on the common prefix. Say `y₁ ≤ y₂`. Then
  `H_{y₁} ⊂ H_{y₂}` isometrically, and both contain `𝒟_r`.
3. `𝒟_r` is dense in `H_{y₂} = 𝒫²_r`, and `H_{y₁}` is closed in it. So they are equal, with equal norms, and
  `Q₁(f) = ‖\hat f‖² = Q₂(f)`.
4. Lemma C finishes the proof. ∎

*Meaning.* A de Branges carrier of a Weil window of radius `r` "reads" the window within type `r`, and it reads nothing
of the window after type `r`. The inequality `τ ≤ r` is Krein's continuation duality (`H|[0,r] ↔` the distribution on
`(−2r, 2r)`) in the direction that needs no positivity hypothesis beyond the realisation itself. In scattering language,
an atom at `x` is an echo from depth `|x|/2`.

## §5 Theorem K and corollaries

**Theorem K (position law; PROVED modulo CITED Chebotarev and (F1)–(F6); unconditional).** Let an SDL rule satisfy
condition (F), under convention (T) or (G). Suppose it realises the window `r` for every `χ ∈ 𝔉` with conductor
`N ≥ N₀(r)`; by Lemma P these targets are positive definite. Then `Q_r ⊇ {q prime : q < e^{2r}}`: every prime below
`e^{2r}` has its block start at type `≤ r` in the reference chain.

*Proof.*
1. **Setting up.** Suppose `q < e^{2r}` is prime with `s_q > r`. By (F), `Q_r` is finite, and `q ∉ Q_r`.
2. **Choosing the conductor.** Let `K := Q(ζ₃, p^{1/3} (p ∈ Q_r), q^{1/3})`.
  * The primes in `Q_r ∪ {q}` are independent modulo cubes in `Q(ζ₃)^×`. For `p ≠ 3`, valuations at a prime above `p`
  are `e_p`; for `3`, `v_{1−ζ₃}(3) = 2`, so `2e₃ ≡ 0 mod 3` forces `e₃ ≡ 0`.
  * By Kummer theory `Gal(K/Q(ζ₃)) ≅ (Z/3)^{|Q_r|+1}`, with coordinates the actions on the cube roots.
  * By Chebotarev (CITED) there are infinitely many rational primes `N ≡ 1 mod 3`, split in `Q(ζ₃)`, whose Frobenius
  fixes every `p^{1/3}` (`p ∈ Q_r`) and moves `q^{1/3}`. Take one with `N ≥ N₀(r)` and `N ∉ Q_r ∪ {q}`, unramified
  in `K`.
  * Then every `p ∈ Q_r` is a cube mod `N` and `q` is not.
3. **The two characters.** Let `χ` be a character of order 3 mod `N`. It is even, since `χ(−1)² = 1 = χ(−1)³`, and
  primitive, since `N` is prime. So `χ, \barχ ∈ 𝔉` with the **same conductor, gamma factor and global datum**. Moreover
  `χ(p) = \barχ(p) = 1` for `p ∈ Q_r`, and `χ(q) = ω ≠ ω² = \barχ(q)`.
4. **The two chains share a prefix.**
  * Archimedean and global blocks are equal for `χ` and `\barχ`. Under (G), `Q_r` is unaffected by the choice of `N`.
  * Local data at `p ∈ Q_r` are equal to the reference data.
  * The first `≺`-index `i*` at which the data of `χ` or `\barχ` differ from the reference is a prime block outside
  `Q_r`. It is either a prime `p` with `χ(p) ≠ 1`, or `N` itself.
  * The prefix before `i*` is the reference prefix, so `i*` starts at `x*` with `τ(x*) = s_{i*} > r`, in both chains.
  * So the chains of `χ` and `\barχ` coincide on `[0, x*]`.
5. **Contradiction.** Echo Lemma E gives `D_χ = D_{\barχ}` on `(−2r, 2r)`. But the coefficient of `δ_{log q}` in
  `D_χ − D_{\barχ}` is `−Λ(q)q^{−½}(ω − ω²) = −i√3 log q/√q ≠ 0`, and `0 < log q < 2r`. ∎

**Cor K.1 (Frobenius-local chains; PROVED).** No Frobenius-local SDL rule satisfies the hypothesis of Theorem K for any
single window `r ∈ (½ log 3, log 2)`. In particular, phase-61 O8 in any entire repair cannot satisfy the Lefschetz
identity (OT-2) on the family, whatever the sign of its blocks.

*Proof.*
1. A block `Φ(p^{iz})` that is entire of finite exponential type (F1) is a Laurent polynomial in `p^{iz}`. If it is
  non-constant, its type is `≥ log p`. By (F1) this type equals `∫_{block}√det H`.
2. Condition (F) holds, since `|Q_r| ≤ r/log 2 + 1`.
3. By Theorem K both 2 and 3 lie in `Q_r`, because `e^{2r} > 3`. The `x`-earlier of their two blocks ends before the
  later one starts, so its type is `≤ r < log 2`. But its type is `≥ log 2`. ∎

**Cor K.2 (density law; PROVED).** Under the hypothesis of Theorem K for all `r`, and with `t_q := type(block_q)` in `R`,
every prime satisfies `s_q ≤ ½ log q`. Hence `Σ_{q≤X} t_q − max_{q≤X} t_q ≤ ½ log X`.

*Proof.* Let `r ↓ ½ log q`. The blocks of the primes `≤ X` all start by type `½ log X`, and all but the last lie inside
that region. ∎

**Cor K.3 (Tate-local conductor; PROVED).** Under (T) with condition (F), no SDL rule realises any window `r > 0` for the
family.

*Proof.* Choose, as in the proof of Theorem K, cubic characters `χ₁`, `χ₂` of two distinct prime conductors
`N₁, N₂ ∉ Q_r`, both trivial on `Q_r`. The chains coincide up to type `> r`. But `D_{χ₁} − D_{χ₂}` has `δ₀`-coefficient
`log(N₁/N₂) ≠ 0`. This contradicts Echo Lemma E and Lemma C. ∎

*Reading.* Under (T), every ramified block would have to start at type 0, and there are infinitely many of them. So a
data-local rule must treat the conductor as global. This is why (G) is the fair convention, and Theorem K holds under
it.

**Remark K.4 (link to ζ and OT-10; HEURISTIC).** For the cyclic cubic field `K_N` of conductor `N`,
`ζ_{K_N} = ζ · L(χ) · L(\barχ)`. An OT-10 object `𝒪_{K_N}` with Galois-isotypic decomposition of `H¹` under `Z/3`
(Artin formalism) yields window realisations for `χ` and `\barχ`. Theorem K therefore excludes every **ζ-construction**
of SDL (in particular Frobenius-local) shape that is field-uniform in this Artin-compatible sense. For ζ alone, with no
family, no comparison is available, and the statement reduces to installation (OT-3), as for any single datum.

## §7 What is genuinely new, and the remaining escapes

**New (checked against the corpus by grep for "concatenation", "Krein–de Branges", "√det H" and "transfer matrix"; the only
hit is phase-61 O8, which has no theorem):**
1. **Echo Lemma E.** A window realisation localises in type `≤ r`. Lemma B, the mean-type argument, closes the escape of
  realising a small window inside a long chain.
2. **Theorem K, the position law `s_q ≤ ½ log q`.** It is proved by comparing Galois-conjugate cubic twists. The
  comparison is legitimate (both targets are positive), and it needs no falsifier.
3. **Cor K.1.** Frobenius-local concatenated Hamiltonians, i.e. the natural "Euler product as a chain" and phase-61 O8,
  are excluded at the single window `r ∈ (½ log 3, log 2)`. The mechanism is an exponential mismatch: the type budget is
  additive (`Σ log p`), while the Weil window is multiplicative (`e^{2r}` primes).
4. **The dichotomy for this angle is complete.** Local cascade (L), local chain (K) and global (EQUIV).

**Escapes (for the map).**
* **(E4) Echo chain (OPEN).** Type-zero blocks: singular intervals, i.e. rank-one "point interactions" whose strength is
  set by `(q, b)` and which sit at type positions `≤ ½ log q` inside an archimedean background.
  * They satisfy the position and density laws and condition (F), so Theorem K does not exclude them.
  * **Multiple-echo obstruction (HEURISTIC).** Compare `χ` and `\barχ` differing, among the primes `< e^{2r′}`, only at
  `q`. By Echo Lemma E, the `q`-block alone must produce a difference of distributions on `(−2r′, 2r′)` supported on
  `{±k log q}`.
  * But a path `0 → q → p → q → 0` with `p < q` contributes an echo at `log(q²/p)`, with coefficient proportional to
  `(r_q^{χ2} − r_q^{\barχ 2})r_p ≠ 0`. It can be cancelled only by paths with the same integer combination of prime
  logarithms (independence of `log p`).
  * Turning this into a theorem needs convergence of the Born series on an archimedean background. That is **OPEN**.
* **(E5) Non-sequential coupling (OPEN, RH-strength by record).** This means genuine Redheffer / Potapov coupling through
  more than the two chain ports, or vector-valued (`2n×2n`) systems. It is phase 114 D.252–254 → phase 120 P3, whose
  missing "positive bulk identity" is RH-strength (P3_GLOBAL_FOUR_PORT_REDUCTION §1).
* **(E6) Global-block dependence on `N` violating (G) (OPEN, routine-looking).** Theorem K is proved under (T) or (G).
  With a global block whose layout influence depends on `N`, the choice of `N` becomes circular. I did not resolve this.
