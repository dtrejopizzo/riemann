## §2 Rigidity of the structured part

Write the window comb as the arithmetic function `a` with `a_1 = α ∈ ℝ`, `a_n = Λ(n)` for `2 ≤ n < X`, where
`X := e^{2T}` (Def. 1(b) of R1). A **structured completion of ζ-type** is a zero-free completion of the form
`D = ζ·P`, `P(s) = Σ_{d≥1} b_d d^{-s}` a Dirichlet series absolutely convergent for `Re s > 1` (the Selberg
completion `ζM_R`, `R ≥ X`, is one; every "ζ × mollifier" is one). Its coefficient sequence is `a = 1 * b`.

**Lemma R0 (PROVED; elementary).** `μ * Λ = −μ · log` as arithmetic functions.

*Proof.* `log` is completely additive, so for any `g, h`: `(g*h)·log = (g·log)*h + g*(h·log)`. Apply this to
`ε = μ*1` (`ε = 1_{n=1}`, `ε·log = 0`): `0 = (μ·log)*1 + μ*(1·log) = (μ·log)*1 + μ*log`. Since `Λ = μ*log`,
`μ*Λ = μ*μ*log = μ*(−(μ·log)*1) = −(μ·log)*(μ*1) = −μ·log`. ∎
(Checked numerically for `d ≤ 400`; not load-bearing.)

**Theorem R (rigidity of ζ-type structured completions; PROVED; form-independent).** Let `D = ζ·P` reproduce the
window comb, i.e. `(1*b)_1 = α` and `(1*b)_n = Λ(n)` for `2 ≤ n < X`. Then
```
b_d = μ(d)(α − log d) for every d < X.
```
The coefficients `b_d`, `d ≥ X`, are unconstrained by the window. In particular, for `X ≤ R`, the only ζ-type
structured completions supported on `d ≤ R` with `b_d = 0` for `X ≤ d ≤ R` are the Selberg completions
`ζ·M_R` with `R = X` if and only if `α = log X`; for `α ≠ log X` the family is
`P^{(α)}_X(s) = Σ_{d<X} μ(d)(α − log d) d^{-s}`, a one-parameter perturbation of Selberg's mollifier.

*Proof.* Möbius inversion: `b = μ * a`. For `d < X`, every divisor `e` of `d` is `< X`, so
`b_d = Σ_{e|d} μ(d/e) a_e = μ(d)α + Σ_{e|d, e ≥ 2} μ(d/e)Λ(e) = μ(d)α + (μ*Λ)(d) = μ(d)α − μ(d)log d` by Lemma R0
(the `e = 1` term of `μ*Λ` is `μ(d)Λ(1) = 0`). For `d ≥ X` the value `b_d` involves `a_d`, which is free. ∎

**Reading (the Tao decomposition has no freedom below the window).** In the structure/randomness picture the
structured part is "`Λ` as seen through the pole", i.e. a multiple of `ζ`. Theorem R says that inside the window
this multiple is *forced* to be the Selberg mollifier up to the additive constant `α` in the coefficients. Every
other choice (Levinson-type `μ(d)(1 − log d/log R)`, smoothed weights, W-tricks) changes `b_d` for `d < X` and
therefore fails to reproduce some `Λ(n)`, `n < X`: it is not a completion but a *different comb* on the window.
Theorem R therefore reduces the whole ζ-type branch of the angle to the two parameters `(α, tail)`; the tail is
invisible to the window form on `P_T` only through the symbol `σ_D` (Prop 1 of R1), and `α` is analysed next.

## §3 The rigid family fails at every `α` (unconditional)

For `α ∈ ℝ` and `X = e^y` put
```
g_α(y) := σ_{ζP^{(α)}_X}(0) = C_0 + 2α − 2ζ(½)·[α M_{e^y}(½) − N_{e^y}(½)],
M_X(s) := Σ_{d<X} μ(d) d^{-s}, N_X(s) := Σ_{d<X} μ(d) log d · d^{-s}.
```
This is the centre value of the structured symbol of the comb `a^{(α)}_X := 1 * b^{(α)}_X` (the coefficients of
`ζP^{(α)}_X`), restricted to `n ≥ 2`. For `α = y` it is the Selberg centre `g(y)` of R1 Thm 3.

**Theorem S (PROVED; unconditional; primitive form).**
(a) For every `α, X` and every `T > 0`, real `F ∈ C_c^∞(I_T)`:
`𝔞^{(a^{(α)}_X)}_T(F) = (2π)^{-1}∫σ_{ζP^{(α)}_X}|F̂|² − 2P^{(α)}_X(1)A(F)B(F)`. The explicit formula of the
structured comb has an empty zero side.
(b) `limsup_{T→∞} λ_min(A_T(a^{(α)}_X)|P_T) ≤ g_α(log X)`.
(c) The Laplace transform of `g_α` is, for `Re s > ½`,
```
G_α(s) = (C_0 + 2α)/s − 2ζ(½)·[ α/(s ζ(s+½)) − ζ′(s+½)/(s ζ(s+½)²) ].
```
It is regular at `s = 0`, analytic on the real interval `(−5/2, ∞)`, and has a pole at `s = ρ − ½` for every
non-trivial zero `ρ`.
(d) `g_α` takes negative and positive values on unbounded sets of `y`. Consequently, for every `α` there are
arbitrarily large `X` such that the primitive form of the rigid structured comb `a^{(α)}_X` is negative on `P_T`
for all `T > T_{α,X}`.

*Proof.* (a) is Prop 1 of R1 for `D = ζP^{(α)}_X` without window condition (`D` is `ζ` times a Dirichlet
polynomial: (a), (c), (d) of Def. 1 hold with a simple pole of residue `P^{(α)}_X(1)`). (b) is the `prop:finsupp`
argument with the `T`-independent symbol `σ_{ζP^{(α)}_X}`, exactly as in R1 Thm 3(b); the domination
`|σ(s/T)| ≪_{α,X} (1+|s|)^{1/4+ε}` is unchanged.
(c) `g_α` is piecewise constant in `y`, with jumps `−2ζ(½)μ(d)(α − log d)d^{-½}` at `y = log d` (unlike the
Selberg centre, which is continuous). It is locally bounded and `≪ e^{(½+ε)y}`, so the Laplace transform exists
for `Re s > ½`; Landau's theorem in (d) needs measurability and one-signedness only, not continuity. Fubini: `∫_0^∞ e^{-sy} Σ_{d<e^y} μ(d)d^{-½} dy = Σ_d μ(d) d^{-½} ∫_{log d}^∞ e^{-sy}dy
= Σ_d μ(d)d^{-½-s}/s = 1/(sζ(s+½))`, and likewise
`∫_0^∞ e^{-sy}N_{e^y}(½)dy = Σ_d μ(d)log d · d^{-½-s}/s = −(1/ζ)′(s+½)/s = ζ′(s+½)/(sζ(s+½)²)`. This gives the
formula. Near `s = 0`: `1/ζ(s+½) = 1/ζ(½) − sζ′(½)/ζ(½)² + O(s²)` and `ζ′(s+½)/ζ(s+½)² = ζ′(½)/ζ(½)² + O(s)`, so
```
G_α(s) = (C_0 + 2α)/s − 2α/s + 2αζ′(½)/ζ(½) + 2ζ′(½)/(ζ(½)s) + O(1) = (C_0 + 2ζ′/ζ(½))/s + O(1) = O(1)
```
by Lemma 2 of R1 (`C_0 = −2ζ′/ζ(½)`). The pole at `0` cancels **for every `α`**. On the real axis, `ζ(s+½)` has
no zero for `s+½ ∈ (−2, 1)` and `ζ(0) = −½`, so `G_α` is analytic on `(−5/2, ∞)` (the point `s = ½`, where
`1/ζ(1) = 0`, is regular). At `s = ρ − ½`, `1/ζ(s+½)²` has a pole of order `2m_ρ` and `1/ζ(s+½)` one of order
`m_ρ`; the combination `α/ζ − ζ′/ζ²` has a pole of order exactly `2m_ρ` unless the leading coefficients cancel,
which would require `ζ′(s+½) ≈ αζ(s+½)` near a zero, impossible since `ζ′/ζ` has a pole there. So `G_α` has a pole
of order `2m_ρ` at every `ρ − ½`.
(d) Landau's theorem for Laplace transforms of eventually one-signed functions (Widder, *The Laplace Transform*,
Ch. II, Thm 5b; Ingham, *Distribution of Prime Numbers*, Ch. V): if `g_α` were eventually one-signed, the real
point of the abscissa of convergence would be a singularity of `G_α`. By (c) there is none on `(−5/2, ∞)`, so
`G_α` would be analytic on `Re s > −5/2`, contradicting the pole at `ρ_1 − ½ = 14.1347…i`. Hence `g_α` changes
sign on unbounded sets. The consequence follows from (b). ∎

**Proposition S2 (the Selberg normalisation is the unique member with simple zero-poles; PROVED).** The Laplace
transform of the Selberg centre `g(y) = g_{y}(y)` is `G(s) = C_0/s + 2/s² − 2ζ(½)/(s²ζ(s+½))` (R1 Thm 3(c)); its
pole at `ρ − ½` has order `m_ρ`. For every constant `α`, the pole of `G_α` at `ρ − ½` has order `2m_ρ`.
*Proof.* Read off from (c) above and R1 Thm 3(c). ∎

**Reading (HEURISTIC, stated as such).** Under RH with simple zeros and `Σ_ρ 1/(|γ|²|ζ′(ρ)|) < ∞`, a simple pole
at `iγ` contributes a bounded almost-periodic term `e^{iγy}` and a double pole a term `y·e^{iγy}`. So the Selberg
centre is `O(1)` in `y` while every other rigid centre oscillates with amplitude growing like `log X`. The
non-certified illustration below is consistent with this (`g_α(log X)` for `X = 10, 10², 10³, 3·10³, 10⁴`):
`α = 0`: −2.10, −4.08, −2.65, +1.87, +5.64; `α = 5`: +2.27, +0.39, −0.70, +0.67, +2.58; `α = 20`: +15.4, +13.8,
+5.13, −2.93, −6.59. Selberg's `α = log X` (R1 table) stays within `±0.05` from `X = 30` on. **In words:** the
Selberg mollifier is the unique ζ-type structured part whose centre is renormalised to the critical level with
bounded fluctuation; all others drift with `log X`; and *none* stays on one side. The structured centre never
carries a sign.

## §4 Where the functional equation enters, and what it does

The panel's round-2 requirement (G2_P5_R1 §9, G2_P4_R1 §8) is that a mechanism must have a load-bearing line using
the functional equation at `θ = 0`, and must fail on the falsifier battery. This angle has exactly one line that
uses the functional equation: Lemma 2 of R1 (`ξ′/ξ` imaginary on the critical line, hence `C_0 = −2ζ′/ζ(½)`),
which cancels the pole of `G_α` at `s = 0` in Theorem S(c). The following proposition shows what that line does
and does not do, by running it on the deleted comb of `thm:finmod(i)`.

**Proposition F (structured centre of the deleted comb drifts positive; PROVED; primitive form).** Let `N ≥ 5`,
`a := Λ·1_{n ≥ N}`, `ζ_a = ζ·E` with `E(s) = exp(−Σ_{n<N}Λ(n)n^{-s}/log n)` (entire, zero-free; `thm:finmod(iii)`).
Let `μ_a` be the coefficients of `1/ζ_a`, so `a = μ_a * log`, and let `a_R := Σ_{d|n, d≤R} μ_a(d) log(R/d)` be the
Selberg completion of `a` (coefficients of `ζ_a M_{a,R}`, `M_{a,R} = Σ_{d≤R}μ_a(d)log(R/d)d^{-s}`). Its centre
value is `g_a(y) := C_0 + 2y − 2ζ_a(½)M_{a,e^y}(½)`, with Laplace transform
`G_a(s) = C_0/s + 2/s² − 2ζ_a(½)/(s²ζ_a(s+½))`, and
```
Res_{s=0} G_a = C_0 + 2ζ_a′/ζ_a(½) = 2E′/E(½) = 2 Σ_{n<N} Λ(n)/√n =: 2A_N > 0.
```
Consequently `g_a(y) − 2A_N` changes sign on unbounded sets: the structured centre of the deleted comb oscillates
around the **positive** level `2A_N`, while the primitive form of `a` itself is negative on `P_T` for every
`0.60 ≤ T ≤ ½log N` (`thm:finmod(i)`, `cor:Tarch`). Whether `g_a` itself ever goes below `0` (which by the
`prop:finsupp` argument would make the structured comb `a_R` fail for large `T` at those `R`) is not decided by
Landau's theorem, which only gives oscillation around the level `2A_N`.

*Proof.* `ζ_a = ζE` has the pole of `ζ` with residue `E(1)` and no zeros other than ζ's, and `E` is entire of
finite order, bounded in vertical strips of `Re s ≥ ½` (a Dirichlet polynomial in the exponent), so Def. 1(a),(c),(d)
hold for `ζ_aM_{a,R}` and Prop 1 of R1 and the Laplace computation of R1 Thm 3(c) go through with `ζ` replaced by
`ζ_a`. At `s = 0`: `−2ζ_a(½)/(s²ζ_a(s+½)) = −2/s² + 2(ζ_a′/ζ_a)(½)/s + O(1)`, so the residue of `G_a` at `0` is
`C_0 + 2ζ_a′/ζ_a(½) = [C_0 + 2ζ′/ζ(½)] + 2E′/E(½) = 0 + 2E′/E(½)` by Lemma 2 of R1, and `E′/E(s) = Σ_{n<N}Λ(n)n^{-s}`.
Subtract the constant: `L[g_a − 2A_N](s) = G_a(s) − 2A_N/s` is regular at `0`, analytic on `(−5/2, ∞)` (the real
zeros of `ζ_a(s+½)` are those of `ζ`, since `E` has none), and has a pole at `ρ_1 − ½`. Landau's theorem as in
Theorem S(d) gives the sign changes of `g_a − 2A_N`. The statements about the form of `a` are `thm:finmod(i)`. ∎

**What Prop. F shows (PROVED as a comparison, not as a sign).**
1. The functional equation, through Lemma 2, sets the *level* of the structured centre: exactly `0` for ζ (Theorem
  S), `2A_N > 0` for the deleted comb `ζ·E` (Prop. F), and `−2c n_0^{-½} < 0` for the amplified comb
  `Λ + c·1_{n=n_0}` (same computation with `E′/E(½) = −c n_0^{-½}`). In all three cases the comb's own form
  fails past `0.60` (resp. past `½log2` for amplification, `thm:finmod(ii)`), and ζ's form is the open case.
2. Hence "structured centre `≥ 0`" is neither necessary nor sufficient for the sign of the form: the deleted comb
  has a positive structured level and a negative form. This is the falsifier run for item 4 of the battery, and
  it goes in the right direction: the angle claims nothing positive, and the one quantity it computes exactly
  does not separate ζ from `ζ·E`.
3. The functional equation is load-bearing in this angle only for the *level*. A mechanism would have to use it
  for the *sign*, i.e. at the level of the symbol `σ_D(τ)` for all `τ`, which is the pointwise bound
  `Re D(½+iτ) ≤ ½m(τ) + α` (Q1 of R1: EQUIVALENT if attained; OPEN).

## §5 Higher-order poles: the corrected Heath-Brown formulation

**Definition 1′ (completion with a pole of order `k+1`).** As Def. 1 of R1, with (c) replaced by: `D` continues
meromorphically to `Re s > ½ − η` with a single pole at `s = 1`, of order `≤ k+1`, principal part
`Σ_{j=0}^{k} r_j/(s−1)^{j+1}`.

**Proposition 1′ (exact representation with Tate moments; PROVED; both forms).** For such `D` and real
`F ∈ C_c^∞(I_T)`, with `C(z) = ∫c_F(u)e^{zu}du` (so `C(½) = A(F)B(F)` and `C^{(j)}(½) = ∫c_F(u)u^j e^{u/2}du`),
```
𝔞_T(F) = (2π)^{-1}∫σ_D|F̂|² − 2 Σ_{j=0}^{k} r_j C^{(j)}(½)/j!,
W_T(F) = (2π)^{-1}∫σ_D|F̂|² + 2(1 − r_0)A(F)B(F) − 2 Σ_{j=1}^{k} r_j C^{(j)}(½)/j!.
```
*Proof.* Identical to Prop 1 of R1; the residue of `C(z)D(z+½)` at `z = ½` is now `Σ_j r_j C^{(j)}(½)/j!`. ∎

The Heath-Brown completions `D_{k,z}` satisfy Def. 1′ (their poles at `1` have order `≤ k+1`; the coefficients of
`(ζ′/ζ)(1−ζM_z)^k` vanish for `n ≤ z^k`, so `D_{k,z}` reproduces the window comb for `z^k ≥ e^{2T}`). On the
linear subspace `P^{(k)}_T := {F ∈ P_T : ∫F(t)t^i e^{t/2}dt = ∫F(t)t^i e^{−t/2}dt = 0, 1 ≤ i ≤ k}` (codimension
`≤ 2k` in `P_T`), one has `C^{(j)}(½) = 0` for `1 ≤ j ≤ k`: indeed `C(z) = Φ(z)Φ(−z)` with `Φ(z) = ∫F(t)e^{zt}dt`,
so `C^{(j)}(½)` is a sum of products `Φ^{(i)}(½)Φ^{(j−i)}(−½)`, and every factor is a Tate moment of order `≤ k`
(the order-`0` moments vanish on `P_T`). Hence `𝔞_T = (2π)^{-1}∫σ_{D_{k,z}}|F̂|²` on `P^{(k)}_T`, and by min–max
`n_-(A_T|P_T) ≤ n_-(A_T|P^{(k)}_T) + 2k`. **This is
not a mechanism:** `σ_{D_{k,z}} ≥ 0` is again a pointwise bound of Q1 type (OPEN/EQUIVALENT), and the codimension
`k` grows with `T` if `z` is to stay fixed (`z^k ≥ e^{2T}`). It is recorded because R157_002 row 30 said the
identity-level use of Heath-Brown "has no formulation"; Prop. 1′ is that formulation, and it lands in the same
place as Prop 1.

## §6 The remaining regimes

* **Q2 (moving cutoff `R = e^{2θT}`, `0 < θ < 1`): OPEN, and not a mechanism route.** The probe of Theorem S(b)
  reads the symbol at scale `|τ| ≲ 1/T`, on which `σ_{ζM_R}` varies (scale `1/log R = 1/(2θT)`), so no limit value
  is read off. Unconditionally, even the centre value `g(2θT)` is not controlled: it needs
  `Σ_{d≤R}μ(d)d^{-½}` to `o(1)`, i.e. information at the edge `Θ ≥ ½` of the Möbius sum. Whatever its answer, Q2
  concerns a modified comb (`Λ_R ≠ Λ` on `(R, e^{2T})`) and by R1 Prop 4 any split inherits the margin.
* **Q3 (`inf_τ σ_{ζM_R} = −∞` for fixed `R`): HEURISTIC.** A proof would go through the joint distribution of
  `(log|ζ(½+it)|, arg ζ(½+it))` (Selberg's central limit theorem, CITED: Selberg 1946/1992; Tsang 1984) together
  with Kronecker alignment of `d^{-it}`, `d ≤ R`; the small primes contribute `O_R(1)` to `log ζ`, so the
  conditioning should not disturb the CLT. Not attempted; it would only strengthen a falsifier.
* **Q1 (strong duality in the zero-free class): OPEN; EQUIVALENT if true.** No progress.
