  `supp μ`. This turns round 3's Remark 4.2 from `HEURISTIC` into `PROVED`, with no "diagonal" restriction. A
  non-diagonal Dirichlet kernel that is flow-invariant is automatically diagonal (Cor S.1).
3. **Consequence (the angle's trichotomy, `PROVED` as stated in §4).** A commutative probabilistic carrier puts its

  * a multiplicative (factor) subspace: excluded by Theorem K;
  * a Gaussian or linear first chaos: the covariance must be the Weil distribution, i.e. Lemma T (EQUIV);
  * a holomorphic RKHS: Theorem S plus round-3 Theorems 1–3 (Landau cap), or a damped Weil sum (EQUIV).

  The one structural escape left is **non-commutative with nilpotent eigen-operators** (fermionic / CAR). Its

## §1 Definitions

* **Critical ordinates.** `Γ := {γ ∈ ℝ : ζ(½ + iγ) = 0}`. It is closed, discrete and symmetric, and `0 ∉ Γ` because
  `ζ(½) ≈ −1.4604 ≠ 0` (classical, `CITED` (std.)).
* **Probabilistic (commutative) carrier.**
  * Data: a σ-finite measure space `(Ω, 𝔅, m)` and a measurable flow `θ : ℝ × Ω → Ω`, with each `θ_τ` an invertible
  measure-preserving map and `θ_{τ+τ′} = θ_τθ_{τ′}` a.e.
  * Koopman group: `U_τ f := f∘θ_τ`, unitary on `L²(m)`.
  * Point spectrum: `σ_p(U) := {λ ∈ ℝ : ∃ f ∈ L²(m), f ≠ 0, U_τ f = e^{iλτ}f a.e. for every τ}`.
  * This covers every "random object built from the primes whose law is invariant under the flow". The positive form
  is `‖·‖_{L²(m)}`, defined before any spectrum, and `U` is unitary for it. So OT-5′'s *form* clause holds
  automatically, and the whole question is where the spectrum sits.
* **Factor subspace.** For a `θ`-invariant sub-σ-algebra `𝔉 ⊂ 𝔅`, set `L²_0(𝔉) := L²(Ω, 𝔉, m) ⊖ {θ-invariant
  functions}`. The **full carrier** is `𝔉 = 𝔅`.
* **Power maps.** For `f` measurable and `n ∈ ℤ∖{0}`: `f^{[n]} := f^n |f|^{1−n}` on `{f ≠ 0}` for `n ≥ 1`, and
  `f^{[n]} := \bar f^{|n|}|f|^{1−|n|}` for `n ≤ −1`, with `f^{[n]} := 0` on `{f = 0}`.
* **Lefschetz spectrum (OT-2, Lemma T form (D2)).** A closed invariant subspace `H¹` "carries the zeros" if `U|_{H¹}`
  has pure point spectrum and its eigenvalues, with multiplicity, are the ordinates of the nontrivial zeros. By
  unitarity these zeros are then critical (Lemma T(⇒)). The weaker demand used below is only
  **`∅ ≠ σ_p(U|_{H¹}) ⊆ Γ`**.

## §2 Theorem K (the Koopman power law)

### Theorem K — `PROVED` ((i), (ii) elementary; (iii) with `CITED` [LR])

Let `(Ω, m, θ)` be a probabilistic carrier as in §1.

(i) **Power law.** If `f` is an eigenfunction with eigenvalue `λ`, then `|f|` is `θ`-invariant, and for every
`n ∈ ℤ∖{0}` the function `f^{[n]}` is an eigenfunction with eigenvalue `nλ` and `|f^{[n]}| = |f|`. In particular
`λ ∈ σ_p(U) ⟹ λℤ ⊆ σ_p(U)`. The same holds inside `L²(𝔉)` for any invariant sub-σ-algebra `𝔉` containing `f`'s
σ-algebra.

(ii) **Ergodic case.** If `θ` is ergodic, then:
* `σ_p(U)` is an additive subgroup of `ℝ` and every eigenvalue is simple;
* if `m(Ω) = ∞`, then `σ_p(U) = ∅`.

(iii) **Exclusion.** Fix constants `κ ≠ 0` and `β ∈ ℝ`, where `κ = 1, β = 0` is the normalisation of Lemma T. No
probabilistic carrier and no invariant sub-σ-algebra `𝔉` satisfy
`∅ ≠ {κλ + β : λ ∈ σ_p(U|_{L²_0(𝔉)})} ⊆ Γ`.
In words: **a measure-preserving flow cannot have a nonempty nontrivial point spectrum made only of critical
ordinates**, on the full carrier or on any factor.

*Proof.*
(i) Fix `τ`. From `f∘θ_τ = e^{iλτ}f` a.e. we get `|f|∘θ_τ = |f|` a.e., so `|f|` is invariant and `{f ≠ 0}` is an
invariant set mod null. For `n ≥ 1`, a.e. on `{f ≠ 0}`:
`f^{[n]}∘θ_τ = (f∘θ_τ)^n |f∘θ_τ|^{1−n} = e^{inλτ} f^n |f|^{1−n} = e^{inλτ} f^{[n]}`.
Both sides vanish on `{f = 0}` (invariant). For `n ≤ −1`, replace `f` by `\bar f`, which has eigenvalue `−λ`.
`|f^{[n]}| = |f|` gives `f^{[n]} ∈ L²`, `f^{[n]} ≠ 0`, and measurability with respect to any `𝔉` that makes `f`
measurable. ∎(i)

(ii) Let `f, g` be eigenfunctions with eigenvalues `λ, μ`. By ergodicity `|f|` and `|g|` are nonzero constants a.e.
Then `fg` is a nonzero eigenfunction with eigenvalue `λ + μ`, and `\bar f` has eigenvalue `−λ`. So `σ_p` is a group.
If `λ = μ`, then `f/g` is invariant, hence constant, so the eigenvalue is simple. If `m(Ω) = ∞`, a nonzero constant
is not in `L²`, so there is no eigenfunction. ∎(ii)

(iii) Suppose the inclusion holds and pick `λ` in the nontrivial point spectrum of `U|_{L²_0(𝔉)}`. Then `λ ≠ 0`,
since eigenvalue-`0` vectors are invariant functions, which `L²_0` removes. Let `f ∈ L²_0(𝔉)` be an eigenfunction.
By (i), `f^{[n]} ∈ L²(𝔉)` is an eigenfunction with eigenvalue `nλ ≠ 0` for every `n ≥ 1`. It is orthogonal to the
invariant functions, because eigenspaces of a unitary group for distinct eigenvalues are orthogonal. So
`f^{[n]} ∈ L²_0(𝔉)`, and `nλ ∈ σ_p(U|_{L²_0(𝔉)})`. Hence `κnλ + β ∈ Γ` for all `n ≥ 1`, i.e.
`ζ(½ + i(αn + β)) = 0` for all `n ≥ 1`, where `α := κλ`.
* If `α < 0`, replace `n` by `−n`, using `f^{[−n]}` (eigenvalue `−nλ`), so `κ(−n)λ + β = |α|n + β ∈ Γ` for all
  `n ≥ 1`.
* So in all cases `{|α|n + β : n ≥ 1} ⊆ Γ` with `|α| > 0`.

This contradicts [LR, Theorem 4]: for `α > 0` and `β ∈ ℝ`, `#{T ≤ ℓ ≤ 2T : ζ(½ + i(αℓ + β)) ≠ 0} ≥ (⅓ + o(1))T`.
The statement is unconditional, and it was read this phase in the arXiv text of 1208.2684, §1.2. ∎

### Remarks on Theorem K

**Remark K.1 (what is and is not used).**
* Nothing about the zeros is used except [LR]. In the ergodic case with two eigenvalues of irrational ratio, (ii) makes
  `σ_p` dense, which contradicts the discreteness of `Γ` with no citation at all. [LR] is needed only for eigenvalue
  groups of the form `cℤ`.
* The hypotheses are exactly: **commutativity** (`f^n` exists and is again in the carrier), **an invariant measure**
  (`U` preserves `|·|`), and **automorphic action** (`U(fg) = UfUg`).
* No product structure, no tail factorisation, no Frobenius and no contractivity beyond unitarity is used. That is why
  Theorem K covers globally entangled carriers, which the tail wall (B4 Thm W) cannot reach.

**Remark K.2 (affine renormalisation).** The pair `(κ, β)` covers every convention linking flow frequencies to
ordinates: Lemma T's `U_t = e^{−t/2}φ^t`, the time rescaling `t ↦ t·2π`, and a twist by a character `e^{iβt}`. Li–Radziwiłł's theorem
holds for every offset `β`. Putnam 1954 (`CITED` via [LR] §1.2 and G2_B7_R4) covers only `β = 0`, which is why [LR]
is used.

### Corollaries

**Corollary K.1 (the full carrier is excluded; `PROVED`).** For every probabilistic carrier, `H¹ := L²(m) ⊖
{invariant functions}` does not carry the zeros in the sense of §1. For the Lefschetz spectrum to be the zeros one
needs `σ_p(U|_{H¹}) = Γ ≠ ∅`, which Theorem K(iii) excludes. The same holds for `L²_0(𝔉)` of every factor, i.e. for
every "random object built from primes" taken with **all** its square-integrable functionals.

**Corollary K.2 (the named models; `PROVED` from K).** Each of these carries no zero on any factor:
* the Bohr–Bagchi random Euler product (`T^∞` with Haar measure and the Kronecker flow `ω_p ↦ p^{−iτ}ω_p`); its
  spectrum is `log ℚ_{>0}`, a group, and B2_R1/R2 computed it;
* Steinhaus random multiplicative functions (the same flow);
* every stationary point process built from primes, taken with its full `L²` of the law;
* the Gaussian GAF `Y` of round 3, with the full `L²` of its law;
* any Poisson or Cox process on `ℝ` driven by a prime intensity;
* a Markov-local product (this recovers B7 Cor C3 as a special case, now without its tail hypotheses).

**Corollary K.3 (where zeros *can* sit: a non-multiplicative subspace; `PROVED`).**
* Let `X` be a real stationary Gaussian process (generalised, i.e. indexed by `C_c^∞(ℝ)`) with tempered spectral
  measure `μ`, and let `𝒢_1` be its first Wiener chaos (the closed linear span of `X(F)`). Then `U|_{𝒢_1} ≅`
  multiplication by `e^{iτλ}` on `L²(μ)`, so `σ_p(U|_{𝒢_1}) = {atoms of μ}`.
* `L²(law) = ⊕_k 𝒢_k` (bosonic Fock space), and on `𝒢_k` the spectrum is `k`-fold sums of `supp μ`, consistent with
  Theorem K.
* Hence a Gaussian carrier can hold the zeros on `𝒢_1` exactly when `μ ⊇ Σ_γ m_γδ_γ` on its atomic part. Its
  covariance `E[X(F)X(G)^−] = ∫F̂\bar Ĝ dμ` restricted to the atomic part is `Σ_ρ Φ_F(ρ)\overline{Φ_G(ρ)}` (in
  Lemma T's normalisation). For that to be definable **without the zeros**, the covariance must be given by its prime
  side, which is the Weil distribution `g` of P47 `eq:gdatum`. By Bochner–Schwartz (`CITED` (std.)), a generalised
  stationary Gaussian process with covariance `g` exists iff `g` is positive-definite, iff RH (Weil).

  *Proof.* The chaos decomposition and the second-quantisation form of `U` are standard (`CITED` (std.): Janson,
  *Gaussian Hilbert Spaces*, Ch. 2–4). The rest is Bochner–Schwartz plus Weil's criterion (P47 `thm:Z`, round-1
  Prop C). ∎

  **This is Lemma T (EQUIV), not a new route.** The first chaos is precisely the linear subspace that Theorem K cannot
  touch, and it is exactly Weil's covariance. The multiplicative structure of `L²` is what Theorem K kills; the linear
  structure that survives is Weil's criterion.

**Reading (`HEURISTIC`).** In Weil's proof the cohomology of a curve's Jacobian is `Λ^•H¹`. It is an **exterior**
algebra: the product of two `H¹` classes lands in `H²`, and `α∧α = 0`. Eigenvalues multiply only across degrees, and
the square of a Frobenius eigenvector is zero. A commutative probabilistic carrier is the **symmetric** (bosonic)
algebra instead. There the square of an eigenvector is a nonzero eigenvector in the same space, and Theorem K shows
that this alone is incompatible with the zeros. So the right algebraic shape for an `H¹` carrying zeros is fermionic,
not probabilistic. This is the precise sense in which "positivity by construction as a probability measure" is the
wrong kind of positivity for G1.

## §3 Theorem S (stationary holomorphic kernels are Laplace kernels)

### Theorem S — `PROVED` (with `CITED` (std.): Widder, *The Laplace Transform*, Ch. VI Thm 21; Hartogs)

Let `S := {a < Re s < b}` with `−∞ ≤ a < b ≤ ∞`, and let `K : S × S → ℂ` satisfy all of the following:
* `K` is positive-definite: `Σc_i\bar c_jK(s_i,s_j) ≥ 0`;
* `K` is holomorphic in `s` and antiholomorphic in `w`;
* `K` is flow-invariant: `K(s+iτ, w+iτ) = K(s,w)` for all real `τ`.

Then there is a positive Borel measure `μ` on `ℝ` with `∫e^{−xλ}dμ(λ) < ∞` for all `x ∈ (2a, 2b)`, such that
`K(s, w) = ∫e^{−(s+w̄)λ}dμ(λ)`. The RKHS `H_K` is unitarily equivalent to `L²(μ)`, with the flow `(V_τf)(s) = f(s+iτ)`
acting as multiplication by `e^{−iτλ}`. So the flow generator has spectrum `supp μ` (with the sign fixed by this
convention).

*Proof.*
1. **Reduction to one variable.** Put `G(s, u) := K(s, ū)` on `S × S`. Note that `w ∈ S ⟺ w̄ ∈ S`. `G` is separately
  holomorphic, hence jointly holomorphic (Hartogs). Invariance reads `G(s+iτ, u−iτ) = G(s,u)` for real `τ`.
2. **Complex invariance.** Fix `(s,u)`. The set `D := {τ ∈ ℂ : s+iτ ∈ S, u−iτ ∈ S}` is convex and contains `ℝ`. On
  `D`, `τ ↦ G(s+iτ, u−iτ)` is holomorphic and constant on `ℝ`, hence constant on `D`.
3. **Take `iτ := (u−s)/2`.** Then `s+iτ = u−iτ = (s+u)/2 ∈ S` because `S` is convex. Moreover `τ ∈ D`: along the
  segment from `0` to this `τ`, `Re(s+iτ)` and `Re(u−iτ)` move linearly between `Re s`, `Re u` and their midpoint.
  So `G(s,u) = g(s+u)` with `g(z) := G(z/2, z/2)` holomorphic on `2S`. Hence `K(s,w) = g(s + w̄)`.
4. **Exponential convexity.** For `x, y ∈ (a,b)`, `g(x+y) = K(x,y) = \overline{K(y,x)} = \overline{g(x+y)}`, so `g` is
  real on `(2a, 2b)`. For `x_i ∈ (a,b)`: `Σc_i\bar c_j g(x_i+x_j) = Σc_i\bar c_jK(x_i,x_j) ≥ 0`. So `g` is
  exponentially convex on `(2a,2b)`, in the convention recorded in G1_B10_R3 §1.
5. **Widder.** `g(x) = ∫e^{−xλ}dμ(λ)` with `μ ≥ 0`, convergent on `(2a,2b)`. Both sides are holomorphic on `2S`: a
  Laplace integral of a positive measure converging at real `x` converges absolutely on `Re z = x`. They agree on the
  real segment, hence on `2S`.
6. **RKHS.** `k_w ↦ e^{−w̄λ}` is isometric, since `⟨e^{−w̄λ}, e^{−z̄λ}⟩_{L²(μ)} = ∫e^{−(z+w̄)λ}dμ = K(z,w)`. It is onto
  `L²(μ)`: if `c ⊥ e^{−w̄λ}` for all `w ∈ S`, then the finite measure `\bar c e^{−x_0λ}dμ` (`x_0 ∈ S` real) has vanishing
  Fourier transform, so `c = 0` μ-a.e. Finally `V_τk_w = k_{w−iτ} ↦ e^{−iτλ}e^{−w̄λ}`. ∎

### Corollaries of Theorem S

**Corollary S.1 (flow-invariant Dirichlet kernels are diagonal; `PROVED`).** Let
`K(s,w) = Σ_{m,n} a_{mn} m^{−s}n^{−w̄}` converge absolutely on `S` and be flow-invariant. Then `a_{mn} = 0` for `m ≠ n`.

*Proof.* Invariance gives `Σ a_{mn}(n/m)^{iτ}m^{−s}n^{−w̄} = Σ a_{mn}m^{−s}n^{−w̄}` for all `τ`. For fixed real
`s = x`, `w = y`, the left side is an absolutely convergent almost-periodic function of `τ` with frequencies
`log(n/m)`. Its mean coefficient at frequency `ω ≠ 0` is `Σ_{n/m = e^ω} a_{mn}m^{−x}n^{−y}`, and this must vanish
(`CITED` (std.): uniqueness of Bohr–Fourier coefficients). Fix a ratio `r = n/m ≠ 1` in lowest terms `p/q`, so
`(m,n) = (qk, pk)`. Then `Σ_k a_{qk,pk}(qk)^{−x}(pk)^{−y} = 0` for all `(x,y)` in an open set. This is a Dirichlet
series `Σ_k a_{qk,pk}q^{−x}p^{−y}k^{−(x+y)}` in the single variable `x + y`, identically zero. Hence all
`a_{qk,pk} = 0`. ∎

So round 3's §6.1 caveat ("closed on the diagonal class") is removed: **flow invariance forces the diagonal.** The
correspondence-valued (non-diagonal) kernels of B4/B7 are exactly the non-flow-invariant ones.

**Corollary S.2 (the zeros in a stationary holomorphic carrier; `PROVED`).** Suppose the flow generator on `H_K` has
pure point spectrum `Γ` (the zero ordinates). Then:
1. `μ = Σ_{γ∈Γ}c_γδ_γ` with every `c_γ > 0`.
2. `Σ_γ c_γe^{−xγ} < ∞` on an interval of `x`. Since `Γ` is symmetric and unbounded in both directions, `c_γ` must
  decay exponentially in `|γ|` on at least one side.
3. The Lefschetz trace (`Tr` of multiplication by `ĥ` on `L²(μ)`) is `Σ_γĥ(γ)`, independent of the `c_γ`. So OT-2 in
  trace form is compatible with Theorem S.
4. However, the kernel is then `k(z) = Σ_γc_γe^{−zγ}`, a damped zero sum.
  * If `k` is **defined by** its prime side (explicit formula applied to the test functions `e^{−zγ}w(γ)`), its
  positive-definiteness is a damped Weil criterion. That is the round-2 Gaussian ladder class, judged RESTATEMENT
  5/5, i.e. Lemma T.
  * If it is defined from the zeros, OT-3 fails (installation).
  * If `μ` is built from `Λ ≥ 0` directly, `supp μ = {log n}` and round-3 Theorems 1–3 apply (Landau cap at `Re z = 1`;
  no strip-size correction restores positivity).

*Proof.* Items 1–2 are Theorem S. Item 3 holds because a multiplication operator on `L²(Σc_γδ_γ)` is diagonal in the
basis `(c_γ^{−1/2}1_{γ})`. Item 4 is the dichotomy of the definitions. ∎

## §4 The trichotomy of the angle — `PROVED` as a classification, with the scope stated

Let a G1 candidate from this angle be a commutative carrier whose positive form is (a) the `L²` norm of an invariant
measure, or (b) a stationary covariance. Its zero-carrying `H¹` is then one of the following.

| place of `H¹` | status | proof |
|---|---|---|
| a factor `L²_0(𝔉)` (closed under power maps), including the full carrier | **EXCLUDED, unconditional** | Theorem K(iii), Cor K.1–K.2 |
| a linear, non-multiplicative subspace of a Gaussian (or Gaussian-like) model: the first chaos | **EQUIV** (covariance = Weil distribution) | Cor K.3, Lemma T, Bochner–Schwartz |
| a holomorphic RKHS on a strip, stationary | **EXCLUDED** (Λ-built: Landau cap) **or EQUIV** (damped Weil sum) | Theorem S, Cor S.1–S.2, R3 Thms 1–3 |
| any other invariant subspace, **selected by a spectral projection** | installation, OT-3 fails | Lemma T(⇐); selecting `E(Γ)` reads the zeros |

**Scope (the honest limit).** The table exhausts subspaces that are either closed under the multiplicative structure,
or linear spans of the "first-order" observables, or spectral projections. An invariant subspace that is none of these,
defined without the zeros and carrying exactly `Γ`, is not excluded by anything above. By Theorem K it must fail to be
closed under the power maps. I know of no such subspace in any probabilistic model. Its existence is `OPEN`; it is the
commutative form of the non-multiplicative residual.

## §5 The non-commutative (fermionic) residual — named, not built

Theorem K(i) uses that `f^n` is again an eigenvector. In a C*-dynamical system `(𝒜, σ_t, φ)` with an invariant state:
* an eigen-operator `a` (`σ_t(a) = e^{iλt}a`) gives `a^n`, an eigen-operator with eigenvalue `nλ`;
* but `a^n` may be `0`, and in the GNS space `a^nΩ_φ` may vanish.

**Proposition F (quasi-free reduction; `PROVED` modulo `CITED` (std.): Bratteli–Robinson II, §5.2.2–5.2.3, quasi-free
states of the CAR algebra).** Let `φ_A` be a gauge-invariant quasi-free state on `CAR(𝔥)` that is invariant under the
Bogoliubov flow `σ_t(a(f)) = a(e^{itH}f)`, with `0 ≤ A ≤ 1` its two-point operator. Suppose `A` is a projection, or
more generally that the GNS representation is the Fock–anti-Fock representation over `𝔥_A`. Then the GNS space is the
fermionic Fock space `Λ(𝔥_A)`, and the flow is the second quantisation `Γ(e^{itH})`. Its point spectrum on `Λ^k` is the
set of sums of `k` distinct one-particle eigenvalues (counted by eigenvector). Hence:
* `σ_p` on the one-particle space `Λ^1` is `σ_p(H|_{𝔥_A})`;
* the higher sectors hold the sums;
* **a fermionic quasi-free carrier holds the zeros exactly when its one-particle space does.**

This reduces the question to one-particle data `(𝔥, H)`, i.e. Lemma T again.

*Proof.* Standard Fock-space structure (cited). The spectral statement: on `Λ^k` with an eigenbasis `e_j` of `H`,
`Γ(e^{itH})e_{j_1}∧…∧e_{j_k} = e^{it(λ_{j_1}+…+λ_{j_k})}e_{j_1}∧…∧e_{j_k}`, and `e_j∧e_j = 0`. ∎

**Reading (`HEURISTIC`).**
* The Pauli rule `e∧e = 0` is exactly the escape from Theorem K. It is the analogue of `α∧α = 0` in `H^•(Jac)`.
* Supertraces on `Λ(𝔥)` are Fredholm determinants, `Str Γ(U) = det(1 − U)`. This is where the "determinantal" half of
  the angle naturally lives.
* Julia's primon gas (bosonic one-particle spectrum `{log p}` gives `ζ`; fermionic gives `ζ(s)/ζ(2s)`) shows that the
  one-particle spectrum of the prime-built second quantisations is `{log p}`, not `Γ`.
* The residual **(F-nqf): a non-quasi-free, flow-invariant state on a CAR-type algebra built from the primes, whose
  GNS flow has point spectrum `Γ` on a canonically defined sector** is `OPEN`. There is no candidate in the record or
  in the literature I know. By P1_R3 §7.2's Lens-1 warning, the moment it carries a zero-carrying `H¹` with a positive
  pairing it lies in the Lemma T family unless its positivity is proved from the algebra. That positivity is automatic
  (it is a state), so everything would rest on proving the spectrum, which is OT-2.

## §7 What is genuinely new, and what is not

**New at record level (literature novelty `HEURISTIC`):**
1. **Theorem K**: the Koopman power law, combined with Li–Radziwiłł, gives an **unconditional exclusion** of every
  commutative measure-preserving carrier (any factor, any entanglement, any affine normalisation) from holding critical
  zeros as flow eigenvalues. Before this round the record's walls needed tail factorisation (W, I, C) or a local Markov
  structure (C3). K needs neither. It closes the commutative part of residual (E1) ("globally entangled") of P1_R3
  §7.2.
2. **Cor K.3 + Reading**: the multiplicative structure of a probability space is what kills the zeros, and the linear
  structure that survives (the first chaos) is exactly Weil's covariance. The algebraic shape required is exterior
  (fermionic), matching `Λ^•H¹` in Weil's case (`HEURISTIC` reading, `PROVED` quasi-free reduction, Prop F).
3. **Theorem S + Cor S.1**: every stationary holomorphic positive kernel on a strip is a Laplace kernel, and
  flow-invariance forces Dirichlet kernels to be diagonal. This removes round 3's only `HEURISTIC` load-bearing step.

**Not new:**
* The power trick and the group structure of eigenvalues of ergodic systems (Halmos–von Neumann theory).
* [LR] itself, and Putnam's `β = 0` case.
* Widder's theorem.
* Cor K.3 is Lemma T / Weil in Gaussian dress (EQUIV).
* Prop F is standard CAR theory.

**Status for R159_000's success criterion.** No object passes OT-1 ∧ OT-2 ∧ OT-5′ for ζ. The angle is shown incapable
of producing one in every commutative form. The only named residual is the non-quasi-free fermionic one (F-nqf, `OPEN`,
no candidate).

**Recommendation.** File a necessary condition **N-i (non-multiplicativity)**:
*a zero-carrying `H¹` realised inside a commutative algebra of functions with an invariant measure must not be closed
under `f ↦ f^{[n]}`; in particular it is never the `L²_0` of a factor (Theorem K).* This joins N-h (round 3,
horizontal blindness), and together they close the probabilistic angle.

## §8 Weakest step

1. **[LR] is a `CITED` load-bearing input.** I read the theorem's statement (Theorem 4, `α > 0`, `β` real,
  unconditional) in the arXiv text this phase. I did not re-derive its mollified discrete moment proof. If [LR]
  failed, Theorem K(iii) would still hold in the ergodic case whenever two eigenvalues have irrational ratio
  (elementary, Remark K.1). The remaining case `σ_p = cℤ` would then rest on Putnam 1954 for `β = 0` (cited only via
  secondary sources) and would be open for `β ≠ 0`.
2. **Scope of "probabilistic".** Theorem K needs `U` to act by automorphisms of a commutative algebra, preserving a
  measure. A "random operator" angle in which the positive form is a covariance but the carrier is a **linear**
  subspace (Cor K.3) or a **non-commutative** algebra (§5) is outside K. Those are treated by reduction (EQUIV / Prop
  F), not by exclusion. The §4 table's last row and (F-nqf) are the honest gaps.
3. **Measurability conventions** in Theorem K(i) (a jointly measurable flow; "a.e. for each `τ`") are standard. The
  argument only ever uses one `τ` at a time.
4. Nothing in this memo is a positivity statement for ζ's Weil form. There is no sign to be wrong about.
