## §1 The arithmetic resonator (Lemma R)

**Construction.** Fix a real `χ ∈ C_c^∞((−1,1))`, `χ ≢ 0`. For `0 < ε ≤ 1` put `χ_ε(t) = χ(t/ε)` and
`ψ := (−∂² + ¼)χ_ε ∈ C_c^∞((−ε,ε))`. Two integrations by parts give `A(ψ) = ∫χ_ε(−∂²+¼)e^{t/2} = 0`, and likewise
`B(ψ) = 0`. Also `ψ̂(τ) = (τ²+¼)ε χ̂(ετ)`, hence
```
‖ψ‖² = (2π)^{−1}ε^{−3} ∫ (x² + ε²/4)² |χ̂(x)|² dx. (1.1)
```
For `M ≥ 1` and `b ∈ ℝ^M` put `x_m := log m − ½log M` and
```
F_b(t) := Σ_{m≤M} b_m ψ(t − x_m).
```
The resonator subspace is `ℛ_M(ε) := {F_b : b ∈ ℝ^M}`.

**Lemma R (PROVED; primitive form).** Let `ε ≤ 1/(8M)` and `T ≥ ½log M + ε`. Then:
(a) `F_b ∈ P_T ∩ C_c^∞(I_T)`.
(b) `‖F_b‖² = ‖ψ‖²‖b‖²`.
(c) For every real comb `a` and every contact `n ≥ 2`,
`c_{F_b}(log n) = ‖ψ‖² Σ_{k ≤ M/n} b_{nk}b_k` (the sum is empty for `n > M`). Hence
```
Σ_{n∈N_T} v_n(a) c_{F_b}(log n) = ‖ψ‖² · Q_a(b), Q_a(b) := 2 Σ_{n≥2} a_n n^{−½} Σ_k b_{nk} b_k = b^⊤(𝕄_a+𝕄_a^⊤)b,
```
with `(𝕄_a)_{mk} = a_{m/k}(m/k)^{−½}` for `k | m`, `k < m`, and `0` otherwise.
(d) The archimedean part `Arch(F) := (2π)^{−1}∫m|F̂|²` satisfies `Arch(F_b) ≤ (log(1/ε) + C_χ)‖F_b‖²`, where `C_χ`
depends only on `χ`. Consequently
```
λ^A_T(a) ≤ log(1/ε) + C_χ − Q_a(b)/‖b‖² for every b ≠ 0, (1.2)
```
and `λ^W_T(a) ≤ λ^A_T(a)` (P47 l.143).

*Proof.* (a) `A(ψ(·−x)) = e^{x/2}A(ψ) = 0`, and the same for `B`. The support lies in
`(−½log M − ε, ½log M + ε) ⊂ I_T`.

*Separation.* Let `m, k ≤ M` and `n ≥ 1` with `nk ≠ m`. If `nk > m`, then `nk/m ≥ 1 + 1/m`. If `nk < m`, then
`m/(nk) ≥ 1 + 1/(nk)` with `nk < M`. Either way `|log(nk/m)| ≥ log(1 + 1/M) ≥ 1/(2M) ≥ 4ε > 2ε`.

(b) Take `n = 1` in the separation: the translates have disjoint supports.

(c) `c_{F_b}(u) = Σ_{m,k} b_m b_k c_ψ(u − log(m/k))`, and `supp c_ψ ⊂ (−2ε, 2ε)`. At `u = log n` the term is nonzero
only if `m = nk`, by the separation, and then it equals `c_ψ(0) = ‖ψ‖²`. For `n > M`, no `m ≤ M` has the form `nk`.

(d) By `lem:mbounds`(ii) and monotonicity (i), `m(τ) ≤ log(1+|τ|)` for all `τ`. Indeed, for `|τ| ≥ 1` the upper bound
is `≤ log|τ| − log 2π + 1 + ½log(5/4) < log(1+|τ|)`, and for `|τ| < 1`, `m(τ) ≤ m(1) < 0`. Next,
`log(1+|τ|) ≤ log(1/ε) + log(1+ε|τ|) ≤ log(1/ε) + ℓ(ετ) + ½log 2`, where `ℓ(x) := ½log(1+x²)` is smooth and every
derivative of `ℓ` is bounded. Since `|F̂_b|² = |ψ̂|²|Σ_m b_m m^{iτ}|² ≥ 0`, this gives
`Arch(F_b) ≤ (log(1/ε) + ½log 2)‖F_b‖² + Σ_{m,k} b_m b_k J(log(m/k))`, with
`J(u) := (2π)^{−1}∫ℓ(ετ)|ψ̂(τ)|²e^{iτu}dτ = (2π)^{−1}ε^{−3}∫G_ε(x)e^{ixu/ε}dx`, where
`G_ε(x) := ℓ(x)(x²+ε²/4)²|χ̂(x)|²`. The family `{G_ε}_{ε≤1}` is bounded in `W^{2,1}(ℝ)`, since `χ̂` is Schwartz. Put
`M_2 := sup_ε‖G_ε''‖_1` and `D_χ := (2π)^{−1}∫x⁴|χ̂|²`, so that `‖ψ‖² ≥ ε^{−3}D_χ` by (1.1).
* Diagonal: `J(0) ≤ c_χ‖ψ‖²`, with `c_χ := ∫ℓ(x)(x²+1)²|χ̂|² / ∫x⁴|χ̂|²`.
* Off-diagonal: for `m > k`, `log(m/k) ≥ (m−k)/M`, so `ε/|log(m/k)| ≤ εM/|m−k| ≤ 1/(8|m−k|)`, and
  `|J(u)| ≤ (2π)^{−1}ε^{−3}M_2(ε/u)²`. Young's inequality on `ℤ` gives
  `Σ_{m≠k}|b_m b_k||J| ≤ (2π)^{−1}ε^{−3}M_2 · 2ζ(2)/64 · ‖b‖² ≤ c'_χ‖F_b‖²`.

So `C_χ := ½log 2 + c_χ + c'_χ` works. (1.2) follows from `eq:form`, (b), (c) and (d). ∎

**Remark R.1 (where the resonators live).** The spectrum of `F_b` sits at `|τ| ≍ 1/ε ≥ 8M ≍ e^{2T}`. That is inside the
band `[2πe^{2T}, 2πe^{A_T}]` of `prop:band`, far below the threshold `2πe^{A_T}` above which `m` beats the comb
trivially. On these tests the trivial comb bound is `𝖠_T ≈ 4√M`, against an archimedean budget of only
`≈ log M`. Every statement below is therefore genuinely arithmetic.

**Remark R.2 (the multiplicative-Toeplitz reading).** Lemma R says that on `ℛ_M` the Weil form is
`‖ψ‖²[(log(1/ε)+O(1))I − (𝕄_a + 𝕄_a^⊤)]`, up to the off-diagonal archimedean error. So its sign on `ℛ_M` is decided
by the top eigenvalue of the finite multiplicative Toeplitz matrix of the comb, i.e. the matrix of the Dirichlet
series `Σ a_n n^{−½−it}` acting on `ℓ²{1..M}`. This is the object of the GCD-sum literature. Soundararajan's resonator
is its lower-bound tool.

## §2 The structured half, proved: Λ is positive on every resonator subspace (Proposition P)

**Lemma S (Schur bound from Λ∗1 = log; PROVED, using CITED Mertens).** For all `M ≥ 1` and `b ∈ ℝ^M`,
`Q_Λ(b) ≤ (log M + E)‖b‖²`, where `E := sup_{x≥1}(Σ_{j≤x}Λ(j)/j − log x) < ∞` (Mertens 1874, CITED).

*Proof.* `𝕄_Λ + 𝕄_Λ^⊤ =: 𝔸` is symmetric with nonnegative entries and zero diagonal, since `Λ(1) = 0`. By the Schur test
with weights `w_k = k^{−½}`, `λ_max(𝔸) ≤ sup_{m≤M} w_m^{−1}Σ_k 𝔸_{mk}w_k`. For fixed `m`:
* the entries with `k | m` give `m^{½}Σ_{k|m,k<m}Λ(m/k)(m/k)^{−½}k^{−½} = Σ_{d|m}Λ(d) = log m`. This is the **exact
  identity** `Λ∗1 = log`;
* the entries with `m | k`, `k = mj ≤ M`, give `m^{½}Σ_{2≤j≤M/m}Λ(j)j^{−½}(mj)^{−½} = Σ_{j≤M/m}Λ(j)/j ≤ log(M/m) + E`.

The sum is `≤ log M + E`. ∎

**Proposition P (PROVED; unconditional; every `T`; primitive form, hence complete form on the same subspace).**
There are constants `K_0` and `c_0 > 0`, depending only on `χ`, with the following property. Let
`ε = ε_M := 1/(8KM(2 + log M))` with `K ≥ K_0`. Then for every `M ≥ 1`, every `T ≥ ½log M + ε` and every
`F ∈ ℛ_M(ε_M)`,
```
𝔞_T(F) = W_T(F) ≥ ( log(16K) − C'_χ − C''_χ/K − E ) ‖F‖² ≥ c_0 ‖F‖² .
```

*Proof.* By Lemma R(c) and Lemma S, the comb part is `≤ (log M + E)‖F_b‖²`. For the archimedean part we need a
**lower** bound, and two pieces give it.

*Diagonal.* By `lem:mbounds`, `m(τ) ≥ log(|τ|/2π) − 4` for all `τ ≠ 0`. For `|τ| ≥ 1` the lemma gives
`−1/τ − 1/(2τ²) ≥ −3/2`. For `|τ| < 1` the right side is `< −5.84 < C_0 ≤ m(τ)`. Substituting `x = ετ` in (1.1)
gives `Arch(ψ) ≥ (log(1/ε) − C'_χ)‖ψ‖²`, where
`C'_χ := 4 + log 2π + sup_{ε≤1}∫(log|x|)^−(x²+ε²/4)²|χ̂|² / ∫x⁴|χ̂|² < ∞`.

*Off-diagonal, in the time domain.* Polarising `eq:A`, for `u_0 ≥ 4ε`:
`Arch(ψ, ψ(·−u_0)) = −½∫_0^∞[c_ψ(u+u_0) + c_ψ(u_0−u)]K(u)du`. The terms `C_0⟨·,·⟩` and `⟨·,·⟩K` drop out, since
`c_ψ(u_0) = 0`. Only `u ∈ (u_0 − 2ε, u_0 + 2ε) ⊂ (u_0/2, 2u_0)` contributes, and `K(u) ≤ 1/u + ½`, so
`|Arch(ψ, ψ(·−u_0))| ≤ ½‖ψ‖_1²(2/u_0 + ½)`. Now `‖ψ‖_1 ≤ ε^{−1}‖χ''‖_1 + ε‖χ‖_1/4`, and `‖ψ‖² ≥ ε^{−3}D_χ`. So
this ratio is `≤ C(ε/u_0 + ε)`. With `u_0 = |log(m/k)| ≥ |m−k|/M`, Young's inequality gives the off-diagonal sum
`≤ C‖ψ‖²‖b‖²·2(εM(1+log M) + εM) ≤ (C''_χ/K)‖F_b‖²`, by the choice of `ε_M`.

Collecting: `𝔞_T(F_b) ≥ [log(1/ε_M) − C'_χ − C''_χ/K − log M − E]‖F_b‖²`, and
`log(1/ε_M) − log M = log(8K(2+log M)) ≥ log(16K)`. Choose `K_0` so that the bracket is at least `1` for
`K ≥ K_0`. On `P_T`, `W_T = 𝔞_T`. ∎

**Reading.** On the arithmetic tests the positivity of Λ is a theorem, uniform in `T`. It has no margin issue, since
the gap grows like `log log M`, and every contact the tests see is present. It rests on an exact identity of Λ
(`Λ∗1 = log`), which is the Tao "structured" input in its purest form. What the proposition does **not** do is
discussed in §5.

## §3 The structured half, on the comb side: density ceiling and dense models

**Theorem D (density ceiling; PROVED; primitive form, hence complete form).** Let `a` be any real comb with
`λ^A_T(a) ≥ 0` for all `T`. Then for every `M ≥ 1`,
```
G_M(a) := (2/H(M)) Σ_{2≤n≤M} (a_n/n) H(M/n) ≤ log(8M) + C_χ , H(y) := Σ_{k≤y} 1/k .
```
*Proof.* Apply (1.2) with `ε = 1/(8M)`, `T = ½log M + ε` and `b_m = m^{−½}`. Then
`Σ_k b_{nk}b_k = n^{−½}H(M/n)` and `‖b‖² = H(M)`. ∎

**Corollary D1 (PROVED; Karamata CITED: Korevaar, *Tauberian Theory*, Thm I.15.1; Theorem Q′ of G2_B1_R4,
panel-verified).** Let `a ≥ 0` be ∀T-positive (primitive form). Then:
(i) `Σ_{n≤x} a_n/n ≤ 2log x + O(1)`;
(ii) `D_a(s) = Σ a_n n^{−s}` is holomorphic on `Re s > ½` except for at most a **simple** pole at `s = 1`, whose residue
`r` satisfies `0 ≤ r ≤ 1`.
For `a = Λ`, `r = 1`: **the prime comb saturates the ceiling.**

*Proof.* (i) For `n ≤ √M`, `H(M/n) ≥ ½log M`, and `H(M) ≤ log M + 1`. So by Theorem D,
`Σ_{n≤√M} a_n/n ≤ (log M + 1)(log 8M + C_χ)/log M = log M + O(1)`.
(ii) By Theorem Q′ with `κ = 0`, `D_a` is holomorphic on `{Re s > ½} ∖ {1}` with a pole of order `≤ 2` at `1`. Put
`S(x) = Σ_{n≤x}a_n/n`. By (i), `D_a(σ) = (σ−1)∫_1^∞ S(x)x^{−σ}dx ≤ 2/(σ−1) + O(1)` as `σ → 1^+`, so the pole is at
most simple. If its residue is `r > 0`, Karamata's theorem (`a ≥ 0`) gives `S(x) ~ r log x`. Then
`G_M(a) ≥ (2/(log M + 1))∫_1^M S(x)dx/x = (r + o(1))log M`, and Theorem D forces `r ≤ 1`. ∎

**Reading (Tao).** The only "structured" content of a nonnegative comb that the Weil form can use is its pole at 1,
and the archimedean density `log(1/ε)` caps that pole at residue 1. Λ has exactly this residue, so on resonators its
entire polar mass is spent cancelling `m` at leading order (Lemma S against Lemma R(d)). A structured part `s ≥ 0` that
is itself ∀T-positive can carry at most Λ's pole. **There is no structured surplus to pay for the pseudorandom part.**

**Theorem R (dense structured models are not Weil-positive; PROVED given CITED Soundararajan 2008 Thm 2.1).** Let `a`
be a real comb, and suppose there are `c > 0` and `P_0` with `a_n ≥ c` for every squarefree `n > 1` all of whose prime
factors exceed `P_0`. The values of `a` elsewhere are arbitrary. Then, as `T → ∞`,
```
λ^W_T(a) ≤ λ^A_T(a) ≤ − c · exp( (1+o(1)) √(2T / log T) ) .
```
*Proof.* Let `N := ⌊e^{2T−1}⌋`, and let `r ≥ 0` be Soundararajan's resonator for this `N`: multiplicative, supported on
squarefree products of primes in `[L², exp(log²L)]`, with `L² > P_0` for `N` large. Take `b := r·1_{[1,N]}` in (1.2),
with `ε = 1/(8N)`.
* If `Σ_k b_{nk}b_k ≠ 0`, then `nk` and `k` are both in the support, so `n` is a squarefree product of such primes. So
  every `n` that enters has `a_n ≥ c`, and every term is nonnegative.
* Hence `Q_a(b)/‖b‖² ≥ 2c(Ψ_N − 1)`, where
  `Ψ_N := Σ_{nk≤N} r(k)r(nk)n^{−½}/Σ_{m≤N}r(m)² ≥ exp((1+o(1))√(log N/log log N))`. This is Soundararajan's Theorem 2.1,
  lower bound; the index `n = 1` contributes exactly 1.
* (1.2) gives `λ^A_T(a) ≤ log(8N) + C_χ − 2c(Ψ_N − 1)`, and `log N = 2T − 1 + o(1)`. ∎

**Corollary R1 (PROVED).** The following combs have `λ^A_T → −∞`:
* every Cramér/`W`-trick model `s^W_n = (W/φ(W))·1_{(n,W)=1}` (the structured part of G2_B1_R3 Def. G);
* every constant comb `c·1`, `c > 0`;
* every comb `Λ + c·1_{\mathcal R}`, where `c > 0` and `\mathcal R` is the set of squarefree `n` with all prime factors
  `> P_0`.

In the last case the Λ-contribution on the resonator is nonnegative, so it only helps the bound. In particular, at
a fixed window `T`, adding `c·1_{\mathcal R ∩ [1,e^{2T}]}` with
`c ≥ C·T·exp(−(1+o(1))√(2T/log T))` makes the primitive form negative. This is a spread-mass analogue of
`rem:resweights` that needs neither `thm:margin` nor the OPEN non-degeneracy hypothesis.

**Remark R2 (Λ vs the dense model, separated exactly).** Lemma S and Theorem R use the same test functions. For Λ the
top eigenvalue of `𝔸` is `≤ log M + E` (Proposition P). For a dense model it is `≥ exp(c√(log M/log log M))`. The
difference is exactly the **support** of Λ: it vanishes on squarefree numbers with two or more prime factors. So the
resonator subspace sees an exact arithmetic property (F1-type). By §5 it still does not decide a window.

## §4 Analytically structured combs: the Toeplitz collapse, and conservation of RH in the split

**Definition.** A real comb `s` with `Σ|s_n|n^{−σ} < ∞` for `σ > 1` is **analytically structured** if `D_s(z) = Σ_{n≥2}s_nn^{−z}`
continues meromorphically to a neighbourhood of `{Re z ≥ ½}`, is holomorphic there except for a pole of order `≤ 2`
at `z = 1`, and satisfies `|D_s(σ+iτ)| ≤ C(1+|τ|)^{A}` for `½ ≤ σ ≤ 2`, `|τ| ≥ 1`. Examples: finitely supported combs
(prop:finsupp); periodic combs (finite combinations of Hurwitz zeta functions); `s^W`; `−Λ(n)n^{−η}` for `η > ½`. Put
`S_s(τ) := m(τ) − 2Re D_s(½+iτ)`. This is continuous, even, and of polynomial growth.

**Theorem T (Toeplitz collapse; PROVED; primitive form).** Let `s` be analytically structured.
(a) For every `T` and every real or complex `F ∈ P_T ∩ C_c^∞(I_T)`, `𝔞^{(s)}_T(F) = (2π)^{−1}∫S_s(τ)|F̂(τ)|²dτ`.
(b) `T ↦ λ^A_T(s)` is nonincreasing and `λ^A_T(s) ↓ inf_ℝ S_s` as `T → ∞`. In particular
`∀T λ^A_T(s) ≥ 0 ⟺ S_s ≥ 0` on `ℝ`.

*Proof.* (a) Let `F` be real. Put `𝒞(w) := ∫c_F(u)e^{wu}du`, which is entire, with `𝒞(iτ) = |F̂(τ)|²`, and which decays
faster than any power of `|Im w|` uniformly on vertical strips, because `c_F` is smooth with compact support. For
`c > ½`, Laplace inversion and absolute convergence give
`Σ_n s_nn^{−½}c_F(log n) = (2πi)^{−1}∫_{(c)}𝒞(w)D_s(½+w)dw`. Shift to `Re w = 0`; the horizontal segments vanish by the
growth hypothesis. The only pole crossed is `w = ½`, of order `≤ 2`. There
`𝒞(½) = ∫∫F(t)F(v)e^{(t−v)/2} = A(F)B(F) = 0` and `𝒞′(½) = A′B − AB′ = 0`, with `A′ = ∫tFe^{t/2}`, and so on. Both
vanish on `P_T`, so the residue is `0`. Hence the comb part equals `(2π)^{−1}∫2Re D_s(½+iτ)|F̂|²dτ`; the left side is
real. For complex `F = F_1 + iF_2`, both `F_j` lie in `P_T`, because `A` and `B` are real functionals. Both sides are
Hermitian forms with even real symbols, so the cross terms vanish:
`∫σ·Im(F̂_1\overline{F̂_2}) = 0` for even `σ`.
(b) Monotonicity is `lem:monoT`, whose proof holds for any comb. Lower bound: by (a) and density of
`P_T ∩ C_c^∞` in the form domain of `P_T` (G2_B9_R5 Lemma 1.1; G2_B9_R3 Lemma 1.3), `λ^A_T(s) ≥ inf S_s`. Upper
bound: take `g ∈ C_c^∞(−1,1)` and `G_T(t) = e^{−iτ_0t}g(t/T)`, and let `F_T = (−∂²+¼)G_T ∈ P_T` (as in
`prop:finsupp`). Then `F̂_T(τ) = (τ²+¼)Tĝ(T(τ−τ_0))`, and dominated convergence gives
`𝔞^{(s)}_T(F_T)/‖F_T‖² → S_s(τ_0)`. ∎

**Corollary T1.** For `s^W`, `D_s(½+iτ) = (W/φ(W))ζ(½+iτ)Π_{p|W}(1−p^{−½−iτ}) − W/φ(W)`, and `inf S_s = −∞` (by
Theorem R, or by Theorem T with large values of ζ). So **holomorphy of `D_a` on `{Re s > ½}∖{1}` does not bound the
bottoms of a general comb**. The implication of Theorem Q′ is strictly one-way outside ζ. For ζ, Weil's converse uses
the matching of the Γ-factor `m` with the functional equation: `S_Λ` is, formally, the zero measure.

**Corollary T2 (conservation of RH in the split; the step is PROVED, the landing is EQUIVALENT).** Let `Λ = s + r` with `s`
analytically structured. Then:
(i) (PROVED) On `P_T ∩ C_c^∞(I_T)`, exactly, `𝔞_T(F) = (2π)^{−1}∫S_s|F̂|² − Σ_n(2r_n/√n)c_F(log n)`.
(ii) (PROVED; Hardy 1914, CITED) `r` is not analytically structured. `D_r = −ζ′/ζ − D_s` has a pole at every zero of ζ in
`Re ≥ ½`, and infinitely many of these lie on the line itself.
(iii) (EQUIVALENT) `∀T λ^A_T ≥ 0` holds iff the pseudorandom functional of `r` is dominated by the Toeplitz form of
`S_s` on every `P_T`, which is RH. Choosing `s` with `S_s ≥ 0` ("the structured part carries the positivity") changes
nothing in the difficulty. By Cor. D1, when `s ≥ 0` its residue is `≤ 1`, so `s` can take at most Λ's pole, and `r`
takes every zero.

## §6 What is genuinely new

* **Lemma R**: an exact transfer of the Weil window form, on explicit primitive test functions in the decisive band,
  to the multiplicative Toeplitz matrix of the comb. This links row D to the GCD-sum/resonance literature. It is not
  in the record.
* **Proposition P**: the first unconditional, ∀T positivity statement for the prime comb on an explicit
  infinite family of subspaces in the band `[2πe^{2T}, 2πe^{A_T}]`, where the trivial bound fails by `e^T/T`. It is
  proved from the exact identity `Λ∗1 = log`. It is EXCLUDED as a mechanism by `cor:void`, and the memo says so.
* **Theorem D / Corollary D1**: ∀T-positivity caps the polar residue of a nonnegative comb at 1, and Λ saturates the cap
  (a sharpening of Theorem Q′: the pole is simple and has residue `≤ 1`).
* **Theorem R / Corollary R1**: dense structured models, including all `W`-trick/Cramér models, have Weil bottoms
  `≤ −exp((1+o(1))√(2T/log T))`. This is proved by transplanting Soundararajan's resonator into the Weil form.
* **Theorem T / Corollaries T1–T2**: analytically structured combs are T-free Toeplitz forms (`λ^A_T ↓ inf S_s`), and
  the split conserves RH in the pseudorandom part. T1 shows that the converse of Theorem Q′ fails outside ζ.

Not achieved: the ∀T arrow. What the Tao angle leaves is the "pseudorandom" part, meaning test functions far from
the arithmetic lattice `log ℕ` (the complement of `∪_M ℛ_M` in the near-minimiser directions) and the remainder `r`
that carries the zeros. That part is RH (Cor. T2(iii)).
