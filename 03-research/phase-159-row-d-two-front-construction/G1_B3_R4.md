## §1 Setting (G1_B4_R3 §2.1, with the tail hypotheses removed)

* **Primes.** Partition the primes as `P = P_0 ⊔ ⨆_{j≥1} B_j`, each `B_j` finite and nonempty, with infinitely many `j`.
* **Spaces.** `H_0` is a Hilbert space. For `j ≥ 1`, `H_j` is a Hilbert space with unit vector `ξ_j`. Set
  `X := H_0 ⊗ ⊗′_{j≥1}(H_j, ξ_j)`, von Neumann's incomplete tensor product (`CITED` (std.): von Neumann, Compositio
  Math. 6 (1939); Guichardet LNM 261).
* **Operators.** For `p ∈ B_j`, `S_p := T_{j,p}` acting on the `j`-th factor, with `T_{j,p} ∈ 𝔅(H_j)` **arbitrary**. For
  `p ∈ P_0`, `S_p := A_p ⊗ 1` with `A_p ∈ 𝔅(H_0)` arbitrary. Only the Hilbert topology of each factor is used, so any
  additional (indefinite) form is allowed.
* **Local data.** `E_j(γ) := ⋂_{p∈B_j} ker(T_{j,p} − p^{iγ})`, with orthogonal projection `P_j(γ)`, and
  `a_j(γ) := ‖P_j(γ)ξ_j‖²`.
* **Global data.** `Γ(X) := {γ ∈ C : ∃w ≠ 0, S_pw = p^{iγ}w ∀p ∈ P}`. `A(ξ) := {γ : ∃j_0, a_j(γ) > 0 (j ≥ j_0),
  Σ_{j≥j_0}(1 − a_j(γ)) < ∞}`.
* **Gap.** For `γ ≠ γ′` and `p ∈ B_j` with `μ := p^{iγ} ≠ ν := p^{iγ′}`, set `κ_{j,p}(γ,γ′) := |μ − ν| / ‖T_{j,p} − ν‖`.
  (The denominator is nonzero: if `T_{j,p} = ν` then `E_j(γ) = 0`. In that case set `κ_{j,p} := +∞`.) Let
  `κ_j := max_{p∈B_j} κ_{j,p}`, with `κ_j := 0` if `ι_{B_j}(γ) = ι_{B_j}(γ′)`.

## §2 Theorem G

**Lemma G0 (tail criterion without hypotheses; `PROVED`).** For arbitrary bounded `T_{j,p}`, if `w ≠ 0` satisfies
`S_pw = p^{iγ}w` for all tail primes, then `γ ∈ A(ξ)`.

*Proof.* This is G1_B4_R3 Theorem W(i), whose proof uses only three lemmas:
* W1, associativity of the incomplete tensor product (`CITED` (std.));
* W2, `ker(B⊗1) = ker B ⊗ K` for bounded `B` (proved there, with no hypothesis on `B`);
* W4, infinite products of *orthogonal projections onto closed subspaces* (proved there).

`E_j(γ)` is a closed subspace for any bounded `T_{j,p}`, and `P_j(γ)` is its orthogonal projection. The argument then
runs as follows. Apply W1 and W2 to `B = T_{j,p} − p^{iγ}` for every `p ∈ B_j`, which gives `w ∈ E_j(γ) ⊗ X^{(j)}` for
every `j`. W4 then gives `Π_{j≥j_0}a_j(γ) > 0` for some `j_0`. Neither (C) nor (N) enters. ∎

**Lemma G1 (eigenspace gap; `PROVED`).** Let `T ∈ 𝔅(H)` and `μ ≠ ν ∈ C`. For `x ∈ ker(T−μ)` and `y ∈ ker(T−ν)`,
`|μ − ν|·‖x‖ ≤ ‖T − ν‖·‖x − y‖`.

*Proof.* `(T−ν)(x − y) = (μ−ν)x − (T−ν)y = (μ−ν)x`. Take norms. ∎

**Theorem G (`PROVED`).** In the setting of §1, let `γ ≠ γ′ ∈ C`.
* (i) If `γ, γ′ ∈ A(ξ)`, then `Σ_j κ_j(γ,γ′)² < ∞`.
* (ii) Hence, if `Σ_j κ_j(γ,γ′)² = ∞`, then `γ` and `γ′` are not both in `Γ(X)`, and not even both in the tail-only
  joint spectrum.
* (iii) The same holds for eigenvectors of any interpolating family `V_t` with `V_{log p} = S_p` for tail primes, as in
  W(iii).
* (iv) For a countable decomposition `X = ⊕_k X^{(k)}` into `S`-invariant summands, each tail-factorizable and with
  bounded idempotents `E_k` commuting with all `S_p`, `Σ_k E_k = 1` strongly, (ii) applies in each summand.

*Proof.*
* (i) `a_j(γ) → 1` and `a_j(γ′) → 1`. So there is `j_1` with both `≥ ½` for `j ≥ j_1`.
* For such `j` with `κ_j > 0`, pick `p ∈ B_j` attaining the max. Put `x_j := P_j(γ)ξ_j ∈ E_j(γ) ⊂ ker(T_{j,p}−μ)` and
  `y_j := P_j(γ′)ξ_j ∈ ker(T_{j,p}−ν)`.
* `‖ξ_j − x_j‖² = 1 − a_j(γ)` (Pythagoras, `ξ_j − x_j ⊥ x_j`), and likewise for `y_j`. So
  `‖x_j − y_j‖ ≤ (1−a_j(γ))^{1/2} + (1−a_j(γ′))^{1/2}`.
* Lemma G1 gives `κ_j² a_j(γ) = κ_j²‖x_j‖² ≤ ‖x_j − y_j‖² ≤ 2(1−a_j(γ)) + 2(1−a_j(γ′))`.
* Hence `Σ_{j≥j_1} κ_j² ≤ 4Σ_{j≥j_1}(2 − a_j(γ) − a_j(γ′)) < ∞`. (If `κ_{j,p} = +∞` then `E_j(γ) = 0`, so `a_j(γ) = 0`,
  which is excluded for `j ≥ j_1`.)
* (ii) By Lemma G0, a joint eigenvector for `γ` gives `γ ∈ A(ξ)`, and likewise for `γ′`. Apply (i).
* (iii) Same as W(iii).
* (iv) `E_kw` is again a joint eigenvector with the same character, and it is nonzero for some `k`. Apply (ii) inside
  `X^{(k)}`. ∎

**Remark 2.1 (relation to Theorem W; `PROVED` by comparison).** W(ii) under (C) or (N) needs no divergence: there the
eigenspaces are orthogonal, and one exceptional block is harmless even for a sparse tail. Theorem G drops all structure
on the tail operators and pays with the divergence `Σκ_j² = ∞`. The two are complementary. Their union excludes every
tail that is contractive, normal, or has divergent gaps.

## §3 When the gaps diverge

**Lemma PW (prime windows; `PROVED` given PNT, `CITED` (std.)).** Let `δ ∈ R∖{0}`, `c := e^{π/|δ|}` and
`X_k := e^{(2πk+π/2)/|δ|}`.
* (a) Every prime `p ∈ [X_k, cX_k]` satisfies `|p^{iδ} − 1|² ≥ 2`.
* (b) For every `β ∈ [0, ½]`, `Σ_k Σ_{p∈[X_k,cX_k]} p^{−2β} = ∞`.

*Proof.*
* (a) `|δ| log p ∈ [2πk+π/2, 2πk+3π/2]`, so `cos(δ log p) ≤ 0` and `|p^{iδ}−1|² = 2 − 2cos(δ log p) ≥ 2`.
* (b) By PNT, `π(cX) − π(X) ≥ (c−1)X/(2log X)` for `X ≥ X(c)`. So the `k`-th window contributes at least
  `(c−1)X_k^{1−2β}c^{−2β}/(2 log X_k) ≥ c′/log X_k = c″/(k+1)` (using `X_k ≥ 1`, `1 − 2β ≥ 0`). The harmonic series
  diverges. ∎

(For `β = ½` this is the divergence `Σ_p 1/p = ∞` restricted to the windows. `HEURISTIC` reading: the wall at the
threshold is powered by the pole of ζ at `s = 1`.)

**Corollary G1 (`PROVED`).** Assume `P_0` is finite and `|B_j| ≤ b` for all `j`.
* (a) **Weight-bounded tails.** If `‖T_{j,p}‖ ≤ C p^{1/2}` for all tail `p`, then for real `γ ≠ γ′`, `Σκ_j² = ∞`.
  Hence each summand (in the sense of G(iv)) carries at most one critical zero.
* (b) **Bounded tails.** If `‖T_{j,p}‖ ≤ M` for all tail `p`, then:
  * every `γ ∈ Γ(X)` has `Im γ ≥ 0`;
  * for `γ ≠ γ′` with `0 ≤ Im γ, Im γ′ < ½`, `Σκ_j² = ∞`.

  Hence each summand carries at most one zero of the critical strip, on or off the line.

*Proof.*
* (a) Put `δ := γ − γ′ ∈ R∖0`. For every tail `p`, `κ_{j,p} ≥ |p^{iδ}−1| / (Cp^{1/2} + 1) ≥ |p^{iδ}−1| / ((C+1)p^{1/2})`,
  using `|p^{iγ′}| = 1`.
* Each block has at most `b` primes and `P_0` is finite. So
  `Σ_jκ_j² ≥ (1/b)Σ_{p ∉ P_0} κ_{j(p),p}² ≥ (2/(b(C+1)²)) Σ_{k≥k_0} Σ_{p∈[X_k,cX_k]} p^{−1} = ∞` by Lemma PW(a),(b)
  with `β = ½`. Apply Theorem G(ii),(iv).
* (b), first clause. `|p^{iγ}| = p^{−Im γ}` is an eigenvalue of `S_p`, so `p^{−Im γ} ≤ ‖S_p‖ ≤ M` for infinitely many `p`.
  Hence `Im γ ≥ 0`.
* (b), second clause. Let `b_1 := Im γ` and `b_2 := Im γ′`, both in `[0,½)`.
  * If `b_1 ≠ b_2`, say `b_1 < b_2`, then `|p^{iγ} − p^{iγ′}| ≥ p^{−b_1} − p^{−b_2} ≥ p^{−b_1}/2` for large `p`. Also
  `‖T − p^{iγ′}‖ ≤ M+1`. So `Σκ_j² ≥ (1/(4b(M+1)²))Σ_{p large}p^{−2b_1} = ∞`, because `2b_1 < 1`. If `b_1 > b_2`,
  exchange the roles (Theorem G(i) is applied to the pair in either order).
  * If `b_1 = b_2 =: β`, then `|p^{iγ}−p^{iγ′}| = p^{−β}|p^{iδ}−1|` with `δ` real, and Lemma PW with this `β ≤ ½` gives
  divergence. ∎

**Remark 3.1 (`PROVED`).** In (b), the one-sided conclusion `Im γ ≥ 0`, i.e. `Re ρ ≤ ½`, is the bounded-operator form of
Serre's half (compare G1_B5_R3 Prop D). If a bounded-tail summand carried a zero `ρ` together with its functional-equation
partner `1 − ρ̄`, then `Im γ = 0`. This is Lemma T(⇒) in operator form. It is **not** progress: the assumption that the
zeros are carried by a bounded-tail carrier is the Hilbert–Pólya input. By (b), in any case, such a summand carries only
one zero.

## §4 Sharpness

**Proposition S (two characters in one summand; `PROVED`).** Let `γ ≠ γ′ ∈ R`, and let `(p_j)` enumerate the primes,
with `B_j = {p_j}`, `P_0 = ∅`, `H_0 = C`. Let `ε_j ∈ (0, π/2)` with `Σ_jε_j² < ∞`. Put `H_j = C²`, `ξ_j = e_1`,
`μ_j = p_j^{iγ}`, `ν_j = p_j^{iγ′}`, and
`T_j := [[μ_j, (ν_j−μ_j)cot ε_j], [0, ν_j]]`.
Then:
* `γ, γ′ ∈ Γ(X)`;
* `κ_j(γ,γ′) = sin ε_j` whenever `μ_j ≠ ν_j`;
* `‖T_j‖ ≤ 1 + 2cot ε_j`.

*Proof.*
* **Eigenvectors.** `T_je_1 = μ_je_1`. With `v_j := cos ε_j e_1 + sin ε_j e_2`,
  `T_jv_j = (μ_j cos ε_j + (ν_j−μ_j)cos ε_j)e_1 + ν_j sin ε_j e_2 = ν_jv_j`.
* **The vector for `γ`.** `w := ⊗_je_1 = ⊗_jξ_j` is a joint eigenvector for `γ`.
* **The vector for `γ′`.** Let `w_K := v_1⊗⋯⊗v_K⊗e_1⊗e_1⊗⋯ ∈ 𝒟`. For `K < L`,
  `‖w_K − w_L‖² = 2 − 2Re Π_{K<j≤L}⟨v_j, e_1⟩ = 2 − 2Π_{K<j≤L}cos ε_j → 0`, since
  `Σ(1 − cos ε_j) ≤ Σε_j²/2 < ∞`. So `w′ := lim w_K ∈ X` exists, with `‖w′‖ = 1`. `S_{p_j}w_K = ν_jw_K` for `K ≥ j`,
  and `S_{p_j}` is bounded, so `S_{p_j}w′ = ν_jw′`.
* **The gap.** `T_j − ν_j = [[μ_j−ν_j, (ν_j−μ_j)cot ε_j],[0,0]]` has rank one and norm
  `|μ_j−ν_j|(1+cot²ε_j)^{1/2} = |μ_j−ν_j|/sin ε_j`. So `κ_j = sin ε_j`.
* **The norm.** `‖T_j‖ ≤ ‖diag(μ_j,ν_j)‖ + |ν_j−μ_j|cot ε_j ≤ 1 + 2cot ε_j`. ∎

So the condition of Theorem G(i) is also sufficient in this family: `Σκ_j² < ∞` exactly when the two characters
coexist. With `ε_j := (p_j^{1/2}log p_j)^{−1}` one has `Σε_j² = Σ1/(p log²p) < ∞` and `‖T_j‖ ≍ p_j^{1/2}log p_j`.
Corollary G1(a) is therefore sharp up to the factor `log p`.

**Proposition S∞ (countable installation in one summand; `PROVED`).** Let `(γ_k)_{k≥0}` be distinct reals. Take
`B_j = {p_j}` and `P_0 = ∅`. Take any `K_j ↑ ∞` and any `δ_j ∈ (0, π/2)` with `Σδ_j² < ∞`. Put `H_j = ℓ²(N_0)`,
`ξ_j = e_0`, `μ_{j,k} = p_j^{iγ_k}`, and define
* `T_je_0 = μ_{j,0}e_0`;
* `T_je_k = μ_{j,k}e_k + (μ_{j,k}−μ_{j,0})cot δ_j·e_0` for `1 ≤ k ≤ K_j`;
* `T_je_k = μ_{j,k}e_k` for `k > K_j`.

Then `T_j` is bounded with `‖T_j‖ ≤ 1 + 2K_j^{1/2}cot δ_j`, and every `γ_k ∈ Γ(X)`.

*Proof.*
* **Boundedness.** `T_j = D_j + e_0⊗c_j^*`, where `D_j` is a unitary diagonal and `c_j` has `K_j` entries of modulus
  `≤ 2cot δ_j`. So `‖T_j‖ ≤ 1 + 2K_j^{1/2}cot δ_j`.
* **Local eigenvectors.** For `1 ≤ k ≤ K_j`, `v_{j,k} := cos δ_j e_0 + sin δ_j e_k` is an eigenvector with eigenvalue
  `μ_{j,k}` (the computation of Prop S). For `k > K_j`, `v_{j,k} := e_k`. Also `v_{j,0} := e_0`.
* **Global eigenvectors.** Fix `k`. Only the finitely many `j` with `K_j < k` have `v_{j,k} ⊥ ξ_j`. Modify those finitely
  many factors, and on the rest use `⟨v_{j,k}, e_0⟩ = cos δ_j`. The Cauchy argument of Prop S shows that
  `⊗_jv_{j,k} ∈ X`, and it is a joint eigenvector with character `γ_k`. ∎

**Consequence (`PROVED`).** Take `K_j` slowly increasing and `δ_j = (j^{1/2}log j)^{−1}`. Then
`‖T_j‖ = p_j^{1/2+o(1)}`, and one tail-factorizable summand carries **every** zero ordinate. So Theorem W's
conclusion "at least one summand per zero" (Cor W7) is false for non-normal tails past the threshold. The carrier of
S∞ is of course installed: the local data `(μ_{j,k})` are read from the `γ_k`. It fails OT-3 by Lemma T. **Past the
threshold, what excludes a tail-factorizable carrier is OT-3, not a wall.**

## §5 Consequences for the angle and for the residual map

**Corollary F′ (`PROVED` given Theorem G and Corollary G1(a); Hardy 1914 `CITED`).** Let `X = ⊗′_p(H_p, ξ_p)` be any
FF-type product carrier, with Frobenius `φ_p` on the `p`-th factor, `‖φ_p‖ ≤ Cp` for all but finitely many `p`, and
critical zeros realised as joint eigenvectors of `S_p = p^{−1/2}φ_p` with local shape `p^{iγ}`. Then each summand of a
decomposition as in G(iv) carries at most one critical zero. Two critical zeros (Gram) already contradict a
single-summand carrier. A carrier with one summand per zero is installation (Lemma T; OT-3/OT-4).

*Proof.* `P_0` is finite, the blocks are singletons, and `‖S_p‖ ≤ Cp^{1/2}`. Apply Cor G1(a). ∎

This extends my R3 Theorem F from unitary local Frobenius (the Tate-curve `L²` models and `B_∞^{φ=p^d}` of R1 Props
L1–L3) to **every** bounded deformation of those local carriers that respects the local weight bound. Normality is no
longer needed.

**Remark 5.1 (dictionary; `HEURISTIC`).** The bound `‖φ_p‖ ≤ Cp` is the complex-analytic shadow of the local weight
constraint of an `H¹`, whose Frobenius slopes lie in `[0,1]`, i.e. Hodge–Tate weights `{0,1}` (Mazur's inequality,
`CITED` (std.), as a statement about `p`-adic valuations). The analogy is one of shape only: a `p`-adic slope bound gives
no complex operator norm bound. What Theorem G says precisely is this: a local Frobenius that stays below its `H²`
eigenvalue `p` in operator norm, on a set of primes with divergent `Σ1/p` in the windows, cannot entangle two zeros.

**Remark 5.2 (why the residual looks installed; `HEURISTIC`).** Past the threshold, two zeros `γ, γ′` coexist in one
summand only if `Σ_j κ_j(γ,γ′)² < ∞`. By Lemma G1, this means the local eigenspaces for `p^{iγ}` and `p^{iγ′}` are at
angle `≲ p^{−1/2}·(|p^{iδ}−1|/‖T_p‖)^{−1}`, summably, **for every pair** of carried zeros. The local carrier at `p` must
therefore "know" `δ = γ−γ′` modulo `2π/log p`, to precision `p^{−1/2}`, for all pairs. This is the shape of S∞, where
the data are read off the zeros. That every such carrier must read the zeros is **not** proved. It is the
precise open form of (E2′).

## §7 What is genuinely new, what is not

**New to the corpus (`PROVED`).**
* Lemma G0: the observation that Theorem W(i) never used (C) or (N).
* Theorem G: the gap criterion `Σκ_j² < ∞` for coexistence, for arbitrary bounded tail operators.
* Corollary G1: the weight-bounded threshold `‖φ_p‖ ≤ Cp`, and the strip version under bounded tails.
* Propositions S and S∞: sharpness, and single-summand installation past the threshold.
* Corollary F′: my R3 Theorem F without unitarity.

Together these settle the round-3 question "power-bounded tails via mean-ergodic idempotents" (B4_R3 §7). Idempotents are
not needed. Power-boundedness is not needed. Only the operator norm against the prime windows matters.

**Not new.**
* The mathematics is elementary: an eigenspace-gap inequality plus the Kakutani-type product criterion of W4.
* The divergence input is PNT in multiplicative windows.
* It adds a filter, not a route. It does not construct the object, prove a trace formula, or bear on any window `T`.

## §8 Weakest step

* **Scope.** Theorem G covers:
  * Hilbert incomplete tensor products;
  * joint *eigenvectors*, i.e. point spectrum;
  * summands with bounded idempotents commuting with Frobenius.

  It says nothing about quotient or resonance spectrum, non-tail-factorizable (entangled) carriers, Banach carriers, or
  Frobenius realised only as closed orbits.
* **The divergence hypothesis.** It needs `P_0` finite (more generally, a tail that is thick in the windows of Lemma PW)
  and bounded block sizes. A sparse tail, or blocks growing fast enough to beat the `1/b` averaging, is not covered
  unless the tail is contractive or normal (then Thm W applies).
* **The threshold.** Cor G1(a) is sharp only up to `log p`. The exact frontier between `p^{1/2}` and `p^{1/2}log p` (for
  example `‖T_p‖ ≍ p^{1/2}(log p)^{1/2}`) is not settled: it is decided by `Σ_p |p^{iδ}−1|²/‖T_p‖²` over the windows,
  and Theorem G(i) with Prop S is the exact criterion only in the `2×2` family.
* **Rem 5.1 (Mazur) and Rem 5.2 (OT-3 exposure of E2′)** are `HEURISTIC`.
* **The G1 objective is not met.** No carrier, no Lefschetz formula for ζ, no positive form with content, no sign.
