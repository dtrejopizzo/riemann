## §2 Remark 3.4, "PROVED part": the proof is invalid

Claim: if `D_b^+ = ε·2πμ_Λ` (`ε > 0`), then writing `β_b = εu_Λ − σ̌` with `σ ≥ 0` tempered, "support of `β_b` in
`±log ℕ` forces `σ̌ = ε(k_∞ + 2cosh(u/2))` off `±log ℕ`, and `2cosh(u/2)` is not tempered while `σ̌` is: contradiction".

**Counterexample to the inference, from the memo itself.** Under RH, Lemma L's converse says `u_Λ ∈ 𝒮′`, and `u_Λ`
equals `k_∞ + 2cosh(u/2)` (i.e. `−½K(|u|) + 2cosh(u/2)`) off `±log ℕ ∪ {0}`. So a tempered distribution *can* coincide
with an exponentially growing function off `±log ℕ`: the point masses on the comb cancel the growth (this is exactly
von Koch's `ψ(x) − x = O(x^{½+ε})`). The argument of Remark 3.4 would, verbatim, prove that `u_Λ` is not tempered, i.e.
¬RH — while Remark 3.4 itself is set under RH (`μ_Λ ≥ 0` presupposes it). The "local non-temperedness" test fails
because the gaps `log(n+1) − log n ≍ e^{−u}` shrink, so test functions living in the gaps have Schwartz seminorms
`≍ e^{Nu}`, which dominate `e^{u/2}`.

**What the proportional case actually is.** `σ̌ = εu_Λ − β_b = ε u_{Λ + b/ε}`, so `σ ≥ 0` says `Λ + b/ε ∈ 𝒮^W` with
`D_{b/ε} = 2πμ_Λ − σ/ε`, which charges the ordinates; Theorem R′ (hypothesis `|D|(Γ_ζ) = 0`) does not apply. The case
is a rescaling of the general open question R(iv) restricted to `σ ⊥ μ_Λ`, not a case that the pole decides.
**Status: OPEN, not PROVED.** The accompanying reading ("the pole of ζ is what forbids proportionality") is withdrawn
with it. Not load-bearing for Theorem R′ / N. (Panelist 5, G2_P5_R3 §1.4, marked this step VERIFIED; I dissent.)
