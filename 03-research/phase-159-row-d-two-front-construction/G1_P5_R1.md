## §0 Summary

**No candidate constructs an object that passes OT-5′ ∧ OT-1 ∧ OT-2. No candidate claims a sign for ζ, and none proves
a positivity statement that is false for a falsifier.** So the falsifier test refutes no candidate. It passes
vacuously wherever the positivity is conditional on OT-2, or where the carrier is prime-blind. Every positivity that
is actually proved is either classical (`Θ ≤ 1`), or holds on an object that contains no zero. Five of the seven are
restatements by their own account. Two are negative structural results. Their proofs mostly check out, but I found
the four errors listed below.

The errors found:
* **E1 (B2).** For `K = Q`, `κ = −1 ∈ ker ℓ` acts by `−1` on the constant leafwise 1-form `dx`. So `V_c = 0` in
  degree 1 as well, and the suspension of `Y_Q` keeps only `Θ = 0`, not the polar pair. The pair returns only if
  leafwise densities `|dx|` are used instead of forms.
* **E2 (B6).** A uniform bound gives semisimplicity, not simplicity. "RH ∧ simple zeros" needs `H¹` to be cyclic at
  each zero.
* **E3 (B6).** `H_w = L²(C_Q, w dt ⊗ d^*u)` carries every character of `Ẑ^*`. Its cokernel spectrum is the union of
  the zeros of all Dirichlet `L(s,χ)`, so the target of (O2), "Lidskii trace = `W(f)`", is wrong unless one first
  passes to the `Ẑ^*`-invariant part.
* **E4 (B10).** The Ξ_a row is conditional, and a constant is misnormalised:
  * the OT-5 row "passes for `Ξ_a` when `a < ½`" silently assumes `Θ_ζ = ½`. Unconditionally `Θ_{Ξ_a} = Θ_ζ + a`, and
  the unconditional rung for `Ξ_a` is `ε ≥ ½ + a`;
  * in Thm E.5, `c(ε)` should be `2·inf_τ Re ξ′/ξ(½+ε+iτ)`, not `π^{−1}·inf`. Positivity is unaffected.

None of E1–E4 is fatal to what its memo actually claims. Each has to be corrected before integration.

## §1 G1_B2_R1 (Deninger-route laminations; `Y_K = A_K/K`; suspension wall; N-d)

**What carries weight.**
* Prop 1: conformal invariance of the 1-form Dirichlet pairing in leaf dimension 2.
* Construction 3 and Theorem C: `Y_K` and its leafwise L² cohomology.
* Theorem D and Cor D1: suspension along a dense length group keeps only the R-continuous part, and mixing kills it.

**Checks.**
* **Prop 1 (a)–(d): correct.** `ω ∧ ⋆ω̄` is conformally invariant, and `C_ν ∘ m_g^* = δ(g)C_ν` gives `U(g)` unitary.
  Stone's theorem gives `Re = α/2`.
* **Theorem C (i)–(iii): correct.** Pontryagin duality `Ŷ_K = K`. For `v ≠ 0`, `dω = 0` and `d*ω = 0` force
  `\bar v a_v = 0`. And `m_κ^*dz = κ dz`.
* **Theorem D: correct.**
  * (i): `f(t) = u(g)f(t)` for `g ∈ ker ℓ`.
  * (ii): uniform continuity comes from `‖u(g)w − u(g′)w‖ = ‖u(g−g′)w − w‖`.
  * (iii): `P_M` commutes with `u` (M and M^⊥ are invariant, `u` unitary). Strong convergence
  `u(g_n)w_M → w_M` together with weak convergence to 0 forces `w_M = 0`.
* **Cor D1, `v ≠ 0` sector: correct.** `⟨u(κ_n)χ_v e, χ_{v′}e′⟩ ≠ 0` only if `κ_n v = v′`, which happens for at most one
  `n`.
* **Cor D1, `v = 0` sector, `d = 2`: correct.** `u_1(κ) = diag(κ/|κ|, \barκ/|κ|)` and `−1 ↦ −1`.
* **Cor D1, `d = 1` (`K = Q`): error E1.** With 1-forms `f dx` (as defined in Construction 3), `m_{−1}^*dx = −dx` and
  `N(−1) = 1`. So `u_1(−1) = −1` on the constant sector, and `ℓ(−1) = log|−1| = 0`, hence `V_c = 0` in degree 1. The
  claim "`V_c = C` in degrees 0 and 1, `Θ = 0, 1`" is false as written. It becomes true only with leafwise densities
  `|dx|`. The conclusion "no zero" is unaffected; "the polar pair" for `Y_Q` needs the density convention.
* **Prop 2 (Deninger's elliptic example).** This is a reading of the source (math/0204194), and I did not re-read it.
  * The index argument for `μ̃` is consistent with the quoted formula.
  * The identity `|ξ|² = deg ξ = q` for a CM canonical lift is the classical `ππ̄ = q`, and it is correct as a
  citation.
  * **Remark:** what the positivity uses there is the Rosati/degree reason `deg = #ker`, which is exactly N-a
  ("deliver the count"). It does not transfer: `Y_K` has no zeros to count.

**Falsifier test.**
* The carrier `Y_K` and its suspension read neither `Λ` nor the zeros. They are literally the same object for
  `Λ + εδ_{n₀}`, `ζ·E`, Beurling data and `Ξ_Q` (OT-4 FAIL, admitted in §5). The only positivity proved (Prop 1, on
  `H̄¹(Y_K)`) is a tautology `|κ|² = N(κ)` on principal ideals, true for every falsifier. **Nothing false is proved.
  Pass, vacuously.**
* Prop B is conditional on OT-2. Suppose an Epstein lamination existed with rank-one `H⁰, H²`, a modular transverse
  measure and the Epstein explicit formula as Lefschetz formula. Then Prop B would prove RH for `Ξ_Q`, which is false.
  So no such lamination exists. That is a consequence, not a refutation. It confirms that on this route the whole
  content is OT-1 ∧ OT-2, and that the existence proof must use the Euler product: Prop B needs the pole to be the
  single `H²` class, and Epstein has one pole too, so the Euler product is the only separating datum.
* `Ξ_a` is excluded at the object level: there is one modulus, and `Ξ_a` needs two. This is the free pass noted in
  R158_003, and it carries no derivation.

**Verdict: survives, restricted to** Theorem D + Cor D1 for imaginary quadratic `K`, Prop 1, and Theorem C. This is a
negative structural result. **It is not an object** (OT-1, OT-2, OT-12 FAIL). N-d is `PROVED` only for Koopman
representations on compact abelian solenoids, and `HEURISTIC` in general, as the memo says. E1 must be corrected.

## §3 G1_B6_R1 (operator algebras; null inheritance; trace-scaling; Sz.-Nagy bridge; Construction 9)

**Checks.**

* **Thm 4 (trace-scaling): correct.**
  * `μ(λE) = λ^{p+κ/a}μ(E)` with finite total mass `‖x‖_p^p`.

* **Cor 5(b): the sentence "its only operator-algebraic implementation is the core" is stronger than proved.** The

  GNS factor and its core. Scope, not fatal.

  on `log N ⊂ [0,∞)`, while `μ_Z` has atoms at `±γ`.

* **Error E2 (Cor 8.1(iii) and §0 item 6).** `sup_s ‖U_s‖ < ∞` makes the generator similar to a skew-adjoint
  operator. It gives **semisimplicity**: no Jordan blocks, and every zero on the line. It does not give simple zeros.

  zeros" holds only if `H¹` is cyclic at each zero. The memo uses cyclicity correctly in the `S₃` paragraph and drops

* **Error E3 (Construction 9).**
  * **The carrier realises too much.** `H_w = L²(C_Q, w dt ⊗ d^*u)` contains every character `χ` of `Ẑ^*`. The

  * **(P1)–(P2) are correct but incomplete.** They are stated only for the trivial character.
  * **(O2)'s target is wrong.** "Lidskii trace = `W(f)`" is the wrong Lefschetz formula for this `H¹_w`, which gives
  `Σ_χ W_χ(f)`.
  * **Consequences.** Coincident zeros of different `L(s,χ)` would make the eigenspaces non-cyclic, which interacts
  with E2. The repair is to pass to the `Ẑ^*`-invariant part, `L²(R_+^*, w)`. OT-2 as stated is false for the

**Falsifier test.**
* Construction 9 uses Tate/Poisson over `Q`. The combs `Λ + εδ_{n₀}` and the Beurling systems have no `E`, so the

* `Ξ_Q` has a lattice-Poisson analogue (R158_004 row 16). Its (O3) bound would be false (off-line zeros are visible by

  **Pass, vacuously.**
* Thm 3 and Thm 4 are ambient statements with no arithmetic. They are true for every falsifier, and they exclude
  carriers rather than prove positivity. Pass.

**Verdict: restatement.** The route reduces OT-5′ to `sup_s ‖U_s|H¹‖ < ∞` (Thm 8), which implies RH. Salvage:
* **Thm 3 and Thm 4 as proved exclusions:** the II_∞ dual trace is upgraded from RESTATEMENT to EXCLUDED, and
  inheritance from a unitary ambient flow without point spectrum is null;
* Thm 7 (growth type ½ is necessary for OT-2 not to be RH-strength).
Correct E2 and E3 before integration.

## §7 G1_B10_R1 (Cauchy-damped Weil ladder)

**Checks.**
* **Theorem D (ii)⟹(i): correct.** `Re ξ′/ξ = Σ Re(s−ρ)^{−1}` via `Re B = −Σ Re 1/ρ`, and the pair terms
  `2[P_{ε−δ} + P_{ε+δ}] ≥ 0` for `ε ≥ δ`. The boundary case follows by the limit `ε′ ↓ ε`.
* **Theorem D (i)⟹(ii): re-checked line by line, as requested.**
  * The prime part is `−Σ Λ(n)χ(log n)n^{−s} = ζ′/ζ(s) + (finite Dirichlet polynomial over 2 ≤ n ≤ 7)`.
  * The polar part is `∫χ(e^{(1−s)u} + e^{−su}) = 1/(s−1) + (holomorphic)`.
  * The Lévy part is holomorphic on `Re s > 0`.
  * Temperedness of `χG_ε` follows from Bochner–Schwartz, since `χ` is smooth with bounded derivatives.
  * The conclusion holds by the identity theorem.
* **Theorem E.1–E.4: correct.**
* **Theorem E.5, error E4(b).** From the spectral identity,
  `⟨G_ε, F⋆F̃⟩ ≥ (2π)^{−1}·inf S_ε·‖F̂‖² = 2 inf_τ Re ξ′/ξ(½+ε+iτ)·‖F‖²`. So `c(ε) = 2·inf`, not `π^{−1}·inf`.
  Positivity is unaffected.
* **Prop R, R′, C: correct and trivial.**

**Falsifier test (the substantive one of this batch).**
* **Where Theorem D proves unconditional positivity:** only at `ε ≥ ½`, and only through `Θ_ζ ≤ 1`, i.e. through the
  Euler product.
* **Epstein `Ξ_Q` (`h > 1`, `β > 1`).** Its `Θ > 1`, so the unconditional rung fails, and Theorem D says exactly that
  (§5, T2 bullet). Correct.
* **DMV Beurling.** `Θ_P = 1` and there is no archimedean term. The rung `ε < ½` fails for it by D(i)⟹(ii), which
  uses only temperedness. Correct, and it confirms T3.
* **`Ξ_a`, error E4(a).** The OT table's OT-5 row ("passes for `Ξ_a` when `a < ½`") and the OT-4 row ("exists … including
  `Ξ_a`") use `Θ_{Ξ_a} = ½ + a`. That value holds only under RH for ζ. Unconditionally `Θ_{Ξ_a} = Θ_ζ + a ≤ 1 + a`, so
  the proved rung for `Ξ_a` is `ε ≥ ½ + a`. `ε = ½` would need the zero-free half-plane `Re s > 1 − a` for ζ, which is
  unknown for every `a > 0`. So the claim is **conditional and mislabeled**, though not false. Theorem D itself, read
  with the true `Θ`, is correct for `Ξ_a`, and it proves nothing false there.
* **Modified combs `ζ·E`.** Theorem D is proved for ζ's datum `g`. For `g_a` the explicit formula picks up the
  `E`-term, so D does not transfer, and the memo does not claim that it does. At `ε = ½`, `Ĝ^a_½ = S_½ − c·cos(τ log n₀)`
  can stay PD for small `c`. Nothing false is claimed.
* **Pass.** No false positivity: the only unconditional rung is RH-silent, which is `cor:void` behaving exactly as
  predicted.

**Verdict: restatement** (Theorem D = Lagarias-type half-plane criterion on the Weil side, as the memo states). Salvage:
Theorem E, the monotone threshold `ε_*(T)` with `sup_T ε_*(T) = Θ − ½`, which locates `thm:margin` as a phenomenon of
the rung `ε = 0` alone. It is useful bookkeeping and gives no sign. Correct E4 before integration.
