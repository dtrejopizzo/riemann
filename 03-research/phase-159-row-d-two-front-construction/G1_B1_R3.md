## §2 Divisor-level invariance: from `N^×` to `R_+^*`, and the affine cocycle

**Definition 2.1.** A convex `U : Q → R` is *function-invariant* if `U∘m_n = nU` for all `n ∈ N^×` (G1_B1_R1 Def
3.1, there with all `s > 0`). It is *divisor-invariant* if `U∘m_n − nU` is affine for all `n ∈ N^×`, i.e.
`Div(U∘m_n) = Div(nU)` as Hessian measures. `𝓠 := {U convex, divisor-invariant}`, `𝓠_+ := Div(𝓠)` (modulo nothing:
`Div` already kills affine functions). The divisors of the quotient `[0,∞)²⋊N^×` are the divisor-invariant ones: a
divisor is by definition insensitive to affine changes of its potential (107_237 Thm 2.1), so requiring the potential
itself to be equivariant is an extra condition with no divisor meaning.

**Lemma 2.2 (`PROVED`).** Let `U ∈ 𝓠`. Then:
 (i) `U∘m_r − rU` is affine for every real `r > 0`;
 (ii) there are `α = (α₁,α₂) ∈ R²` and `β ∈ R` with `U(rx) − rU(x) = r log r·(α·x) + β(1−r)` for all `r > 0`, `x ∈ Q`;
 (iii) `Ũ := U − (α·x) log x₁ − β` (with `x₁` the first coordinate) is exactly 1-homogeneous and continuous, so
  `Ũ(x,y) = x·ũ(y/x)` with `ũ(ρ) := Ũ(1,ρ)` continuous.

*Proof.* (i) From `n` and `m`: `U(y) = mU(y/m) + A` (affine `A`) gives `U(y/m) − (1/m)U(y)` affine; composing,
`U((n/m)x) − (n/m)U(x)` is affine. So the property holds on `Q_+^*`. For real `r`, take `r_k ∈ Q_+^*`, `r_k → r`.
Convex functions are continuous on the open set `Q`, so `U(r_kx) − r_kU(x) → U(rx) − rU(x)` pointwise; a pointwise
limit of affine functions is affine (the affine functions form a finite-dimensional space, and convergence at three
non-collinear points determines the limit). (ii) Write `U(rx) − rU(x) = a(r)·x + b(r)`. Composing `rs` in two ways:
`a(rs) = s a(r) + r a(s)`, `b(rs) = b(r) + r b(s)`. Symmetrising the second: `b(r)(1−s) = b(s)(1−r)`, so
`b(r) = β(1−r)` for a constant `β` (`b(1) = 0`). For the first, `A(r) := a(r)/r` satisfies `A(rs) = A(r) + A(s)`, and
`A` is continuous (`a(r)` is read off `U(r·) − rU` at three points), hence `A(r) = α log r`. (iii) Direct substitution:
`(α·rx) log(rx₁) = r(α·x)(log r + log x₁)` cancels the cocycle. Continuity is inherited. ∎

**Remark 2.3.** `ũ` need not be convex, and `Ũ` need not be; convexity is a property of `U`, which includes the
smooth terms `(α·x) log x₁`. This is exactly where Theorem B's Definition 3.1 lost generality: it forced `α = 0`.

## §3 Theorem Q — the invariant effective cone

**Notation.** `F₁ := Div(x log x)`, Hessian `diag(1/x, 0)`; `F₂ := Div(y log y)`, Hessian `diag(0, 1/y)`. In the
`(x, ρ = y/x)` description, a matrix measure of the form `x^{−1}τ(ρ)` (with `τ` a matrix-valued Radon measure on
`(0,∞)`, and `dxdy = x dx dρ`) is positive iff `τ ≥ 0`. Since `∇²(x log x) = x^{−1}e₁e₁^T` and
`∇²(y log y) = x^{−1}ρ^{−1}e₂e₂^T`, while `∇²(y log x) = x^{−1}[[−ρ,1],[1,0]] = x^{−1}(−ρ^{−1}v_ρv_ρ^T + ρ^{−1}e₂e₂^T)`,
we have the identity of smooth Hessians

  ∇²(y log x) = ∇²(y log y) − (1/(xρ)) v_ρ v_ρ^T . (3.1)

**Theorem Q (`PROVED`).**
 (i) Every `U ∈ 𝓠` has Hessian measure

  ∇²U = ∫[L_ρ] dσ(ρ) + α₁F₁ + α₂F₂ , σ := ũ'' − (α₂/ρ)dρ , (3.2)

  with `α₁, α₂` from Lemma 2.2, `ũ''` a **positive** Radon measure on `(0,∞)` and `σ` a signed Radon measure.
 (ii) Conversely, a triple `(α₁, α₂, σ)` is of this form for some convex `U` iff

  α₁ ≥ 0, α₂ ≥ 0, and σ + \frac{α₁α₂}{ρ(α₁+α₂ρ)}\,dρ ≥ 0 (σ ≥ 0 if α₁α₂ = 0). (3.3)

  Equivalently: `σ_s ≥ 0` for the singular part, and a.e. `σ_{ac}(ρ) ≥ −α₁α₂/(ρ(α₁+α₂ρ))`.
 (iii) The map `U ↦ (α₁, α₂, σ)` is a bijection from `𝓠` modulo affine functions onto the set (3.3). Hence

  𝓠_+ = { α₁F₁ + α₂F₂ + ∫[L_ρ]dσ : (3.3) } ⊋ 𝓜^ext_+ = { σ ≥ 0 } .

 (iv) In the additive variable, via (1.2) and `α₁ = ae^{c/2}`, `α₂ = ae^{−c/2}` (`a = √(α₁α₂)`, `c = log(α₁/α₂)`),
  (3.3) reads

  E(u) ≥ −\frac{a}{2cosh((u−c)/2)} = −\frac{a}{w_{2K}(u−c)} (E the density of the ray part). (3.4)

*Proof.* (i) By Lemma 2.2(iii), `U = xũ(y/x) + (α₁x + α₂y) log x + β`. Distributional Hessians are additive; the log
terms are smooth on `Q`. For the homogeneous part, for `φ ∈ C_c^∞(Q)`, substituting `y = xρ`:
`⟨∂_{yy}Ũ, φ⟩ = ∫∫ xũ(ρ)·x^{−2}∂_ρ²[φ(x,xρ)]·x dρ dx = ∫⟨ũ'', φ(x, x·)⟩dx`, and similarly for the other entries, which
gives `∇²Ũ = (ũ''(ρ)/x) v_ρv_ρ^T` as distributions, `ũ''` the distributional second derivative. Now `∂_{yy}U` is a
positive Radon measure (`U` convex; std.), and `∂_{yy}[(α₁x+α₂y) log x] = 0`, so `∂_{yy}Ũ = ∂_{yy}U ≥ 0`, i.e. `ũ'' ≥ 0`
is a positive Radon measure. Insert (3.1) into `α₂∇²(y log x)` to get (3.2) with `σ = ũ'' − α₂ρ^{−1}dρ`.
(ii) Write `∇²U = x^{−1}τ` with `τ = σ v_ρv_ρ^T + α₁e₁e₁^T + α₂ρ^{−1}e₂e₂^T`. Positivity of `τ` as a matrix measure
means `ξ^Tτξ ≥ 0` for all `ξ ∈ R²`. Singular part: `ξ^Tτ_sξ = (ξ·v_ρ)²σ_s`, so `σ_s ≥ 0`. Absolutely continuous part:
the density matrix `[[σρ²+α₁, −σρ],[−σρ, σ+α₂/ρ]]` must be psd a.e.; its determinant is

  (σρ²+α₁)(σ+α₂/ρ) − σ²ρ² = σ(α₁+α₂ρ) + α₁α₂/ρ . (3.5)

*Necessity of `α₁ ≥ 0`.* If `α₁ < 0`, the `(1,1)` entry forces `σ ≥ |α₁|/ρ² > 0` a.e.; for `ρ` small enough that
`α₁ + α₂ρ ≤ α₁/2`, (3.5) gives `σ(α₁+α₂ρ) ≤ −|α₁|²/(2ρ²)`, so `det ≤ −|α₁|²/(2ρ²) + α₁α₂/ρ < 0` for small `ρ`
(the second term is `O(1/ρ)`). Contradiction on a set of positive measure. `α₂ ≥ 0` follows symmetrically (large `ρ`,
using the `(2,2)` entry). *With `α₁, α₂ ≥ 0`:* if `α₁α₂ = 0`, (3.5) reads `σ(α₁+α₂ρ) ≥ 0`, so `σ ≥ 0` where
`α₁+α₂ρ > 0`, i.e. everywhere unless `α₁ = α₂ = 0`, where the `(2,2)` entry gives `σ ≥ 0` directly. If `α₁α₂ > 0`,
`det ≥ 0 ⟺ σ ≥ −α₁α₂/(ρ(α₁+α₂ρ))`, and then the diagonal entries are automatically `≥ 0`:
`σ + α₂/ρ ≥ α₂²/(α₁+α₂ρ) ≥ 0` and `σρ² + α₁ ≥ α₁²/(α₁+α₂ρ) ≥ 0`. A symmetric `2×2` matrix with nonnegative diagonal and
nonnegative determinant is psd. So `τ ≥ 0 ⟺ (3.3)`. Conversely, given `(3.3)`, put `g := σ + α₂ρ^{−1}dρ ≥ 0` (indeed
`g ≥ α₂²/(α₁+α₂ρ) ≥ 0`), let `ũ` be a second antiderivative of `g`, and `U := xũ(y/x) + (α₁x+α₂y) log x`. Its
distributional Hessian is `x^{−1}τ ≥ 0`, so `U` is convex (a continuous function with psd distributional Hessian is
convex; std.), and it is divisor-invariant by Lemma 2.2 read backwards. (iii) Injectivity modulo affine: `σ` and
`α₁, α₂` are read off the Hessian (`α₁` from the `e₁e₁^T` coefficient after removing the ray part, etc.; equivalently
from (3.2) by pairing with the three matrix directions). (iv) Substitute `σ = h(ρ)dρ`, `E(u) = e^{3u/2}h(e^u)`:
`e^{3u/2}·α₁α₂/(e^u(α₁+α₂e^u)) = α₁α₂e^{u/2}/(α₁+α₂e^u) = a/(2cosh((u−c)/2))` with the stated `a, c`. ∎

**Corollary Q.1 (the extreme elements are the sum graphs; `PROVED`).** For `α₁, α₂ > 0`,
`Div((α₁x+α₂y) log(α₁x+α₂y)) = α₁F₁ + α₂F₂ − ∫[L_ρ] \frac{α₁α₂}{ρ(α₁+α₂ρ)}dρ`, the equality case of (3.3).
*Proof.* `∇²(ℓ log ℓ) = ℓ^{−1}aa^T` with `a = (α₁,α₂)`, `ℓ = x(α₁+α₂ρ)`. Matching with `x^{−1}[σv_ρv_ρ^T + c₁e₁e₁^T +
(c₂/ρ)e₂e₂^T]`: the off-diagonal entry gives `σ = −α₁α₂/(ρ(α₁+α₂ρ))`; the `(1,1)` entry then gives `c₁ = α₁`, the
`(2,2)` entry `c₂ = α₂`. ∎
The divisor is the family of parallel lines `α₁x + α₂y = const`, each meeting the ray `L_λ` once with tropical
multiplicity `|det((α₂,−α₁),(1,λ))| = α₁ + α₂λ`. These are the tropical graphs of the ordinary sum `α₁x + α₂y`, i.e.
the Maslov `ħ = 1` point of G1_B1_R2 Prop M, and they **are** effective on the square. (The truncations
`U_L := x log x + y log y − x u_L(y/x)`, `u_L'' = 1_{[e^{−L},e^{L}]}/(ρ(1+ρ))`, are convex by (3.5) — `det = (1−1_{[..]})/ρ
≥ 0` — and equal `(x+y)log(x+y)` plus an affine function in the sector `|log(y/x)| ≤ L`, `x log x + y log y` plus an
affine function outside, glued `C¹`.)

## §4 Theorem R — the class map on `𝓠_+` is unique and onto

**Definition 4.1.** `𝓠_+^{fin} := {α₁F₁ + α₂F₂ + ∫[L_ρ]dσ ∈ 𝓠_+ : ∫(1+ρ)d|σ| < ∞}` (finite degree of the ray part).
A *class map* is `cl : 𝓠_+^{fin} → D^W/𝓝_∞` such that
 (A1) on ray superpositions `cl(∫[L_ρ]dσ) = ∫ψ_ρ dσ = ℓ_E` with `E` from (1.2) (the record's dictionary, 107_237 (2.4)
  + 107_239 Def 4.1/Thm 4.2 on test densities, extended by the finite-degree bound as in §1);
 (A2) `cl(F₁)` and `cl(F₂)` pair with every `ψ_λ` to the tropical intersection numbers `F₁·Ψ_λ = 1`, `F₂·Ψ_λ = λ`;
 (A3) `cl(D + D') = cl(D) + cl(D')` for `D, D' ∈ 𝓠_+^{fin}`.
(A3) is the additivity `Div(U+V) = Div U + Div V` of divisors under the class map; (A1) is the only ζ-carrying
choice on rays (the naive tropical count gives `L_ρ·L_λ = 0` for `ρ ≠ λ` on the open chart and is ζ-blind); (A2) is
forced by the geometry of the smeared rulings.

**Lemma 4.2 (`PROVED`).** A class `ℓ_E` is determined by its ray pairings `⟨ℓ_E, ψ_λ⟩ := λ^{1/2}w_E(log λ)`, `λ > 0`.
Consequently (A2) forces `cl(F₁) = e₀`, `cl(F₂) = e₁`.
*Proof.* If `w_E ≡ 0` then `ℓ_E(G) = ∫G w_E = 0` for all `G` (Thm 11.14(i)). For `e₀`: by §1 it is `ℓ_{E₀}` with
`Φ_{E₀}(1) = 1`, `Φ_{E₀}(0) = 0`, `Φ_{E₀}(ρ) = 0 ∀ρ`, so by (11.16) `w_{E₀}(u) = e^{−u/2}` and `λ^{1/2}w_{E₀}(log λ) = 1`.
Similarly `e₁` gives `λ`. ∎

**Theorem R (`PROVED`).**
 (i) *(uniqueness)* There is exactly one class map: for `D = α₁F₁ + α₂F₂ + ∫[L_ρ]dσ ∈ 𝓠_+^{fin}`,
  `cl(D) = α₁e₀ + α₂e₁ + ℓ_E`, `E` the additive density of `σ`.
 (ii) *(surjectivity)* `cl(𝓠_+^{fin}) = D^W/𝓝_∞`. More precisely: for every `E₀ ∈ D^W` there are `α₀ ≥ 0` and, for
  each `α ≥ α₀`, an element `D_α ∈ 𝓠_+^{fin}` with `cl(D_α) = ℓ_{E₀}`, namely

  D_α = αF₁ + αF₂ + ∫[L_ρ]dσ_α , E_α := E₀ − 2α(K ⋆ ψ_A) , ψ_A := 1_{[−A,A]}/(4 sinh(A/2)) ,

  for any fixed `A ≥ A₀ := max(log 3, log(1/(2κ₋)))`, `κ₋ := ∫_0^∞K(w)e^{−w/2}dw > 0`, and
  `α₀ := sup_u max(0, −E₀(u))/B_A(u)`, `B_A(u) := 1/(2cosh(u/2)) − 2(K⋆ψ_A)(u)`.
 (iii) *(consequences)* `cl(𝓠_+^{fin})` is a linear space, not a salient cone; it contains `−ℓ_K` (degree `−1`) and
  every nonzero primitive class (degree `0`). The degree gate (Thm 11.13(i), P47 (21.12): nonzero effective ⟹
  `deg > 0`) **fails** on `𝓠_+`; `2K` is **not ample** on `𝓠_+` in the sense of Thm 11.14(iii); and (SG) of
  G1_B1_R1 §6 holds for `cl(𝓠_+)` trivially.

*Proof.* (i) Write `σ = σ₊ − σ₋` (Jordan). Both `D + ∫[L_ρ]dσ₋` and `α₁F₁ + α₂F₂ + ∫[L_ρ]dσ₊` lie in `𝓠_+^{fin}` (the
first is `D` plus a positive ray superposition, which is in `𝓠_+` by (3.3) since adding a positive measure to `σ`
preserves it; the second has `σ₊ ≥ 0`), and they are equal. By (A3), (A1), Lemma 4.2:
`cl(D) = α₁e₀ + α₂e₁ + ∫ψdσ₊ − ∫ψdσ₋`.
(ii) *Membership.* With `α₁ = α₂ = α`, (3.4) reads `E ≥ −α/(2cosh(u/2))`. `E_α ≥ −α/(2cosh(u/2)) ⟺ E₀ + αB_A ≥ 0`.
We show `B_A > 0` on `R` for `A ≥ A₀`, and `B_A(u) ≥ e^{−|u|/2}/4` for `|u|` large; then `α₀ < ∞` (on a compact set `B_A`
is bounded below by a positive constant, and `E₀ = O(e^{−(1+ε)|u|})` by Def 11.1) and `E₀ + αB_A ≥ 0` for `α ≥ α₀`.
*`B_A > 0`.* `2(K⋆ψ_A)(u) = (2 sinh(A/2))^{−1}∫_{u−A}^{u+A}K`. Need `∫_{u−A}^{u+A}K < sinh(A/2)/cosh(u/2)` for all `u`.
For `|u| ≤ A`: the left side is `≤ ∫_RK = ξ(½)`, and `ξ(½) = ∫K < ½∫K·2cosh(u/2) = ½ deg K = ½` (strict because
`2cosh(u/2) > 2` for `u ≠ 0` and `K > 0`); the right side is `≥ tanh(A/2) ≥ ½` for `A ≥ log 3`. For `u > A` (the case
`u < −A` is symmetric, `K` and `cosh` being even): with `v := u − A > 0`, the left side is `≤ T(v) := ∫_v^∞K`, and
`T(v)e^{v/2} ≤ ∫_v^∞K(w)e^{w/2}dw ≤ ∫_0^∞K(w)e^{w/2}dw =: κ₊`. Since `Φ_K(1) = ½ = κ₊ + κ₋` (split `∫_RKe^{w/2}` at `0`
and use evenness of `K`), `κ₊ = ½ − κ₋`. The right side is `> sinh(A/2)e^{−u/2} = e^{−v/2}(1−e^{−A})/2`. So it suffices
that `½ − κ₋ ≤ (1−e^{−A})/2`, i.e. `e^{−A} ≤ 2κ₋`, which is `A ≥ log(1/(2κ₋))`. *Lower bound for large `|u|`:*
`1/(2cosh(u/2)) ≥ e^{−|u|/2}/2`, while `2(K⋆ψ_A)(u) ≤ (2 sinh(A/2))^{−1}T(|u|−A) = O(e^{−πe^{2(|u|−A)}}·e^{9(|u|−A)/2})`
by Thm 11.7(ii); so `B_A ≥ e^{−|u|/2}/4` for `|u| ≥ u₁(A)`. *Finite degree:* `E_α ∈ D^W` (`E₀ ∈ D^W`; `K⋆ψ_A` is smooth
with the superexponential decay of `K`), so `σ_α` has finite degree.
*Class.* By (i), `cl(D_α) = α(e₀+e₁) + ℓ_{E₀} − 2αℓ_{K⋆ψ_A}`. By Lemma 11.2(iv), `Φ_{K⋆ψ_A}(s) = ξ(s)Φ_{ψ_A}(s)` with
`Φ_{ψ_A}(s) = \frac{2 sinh((s−½)A)}{(s−½)·4 sinh(A/2)}` entire; so `Φ_{K⋆ψ_A}(ρ) = 0` at every zero and
`Φ_{K⋆ψ_A}(0) = Φ_{K⋆ψ_A}(1) = ½·1 = ½`. By (1.1), `ℓ_{K⋆ψ_A} = ½(e₀+e₁)`. Hence `cl(D_α) = ℓ_{E₀}`.
(iii) Take `E₀ = −K`: `cl(D_α) = −ℓ_K`, `deg = −1`, while `D_α` is effective. Take `E₀ = P` primitive real with
`P ∉ 𝓝_∞`: `cl(D_α) = ℓ_P ≠ 0` with `deg = 0`. Since `cl` is onto a linear space, for every `D` there is `D'` with
`cl(D') = −cl(D)`. `I_∞(E_α, 2K) = deg E₀` can be negative, so `2K` is not ample on `𝓠_+`. (SG) asks for
`G + αe₀ + βe₁ ∈ cl(𝓠_+)`, which holds for every `G, α, β`. ∎

**Remark 4.3 (the mechanism, `PROVED`).** Theorem R(ii) is the statement that the canonical/ample class is in the
zero-radical: `Φ_K = ξ` vanishes at every zero, so `K` and all its translates and smoothings `K⋆ψ` carry **only ruling
mass**, `ℓ_{K⋆ψ} = ½(Φ_ψ(1)e₀ + Φ_ψ(0)e₁)`. Ruling mass can therefore be converted into a positive function of any
prescribed flatness, and flatness below the allowance `1/w_{2K}` is all that (3.4) asks. The allowance itself is the
ruling weight: (3.4) says the ray density may go negative by exactly what a ruling of the same degree would
contribute at that point. This is why the trade is free.

## §5 Theorem T — the two horns, and what N-c has to become

**Theorem T (`PROVED`, given the dictionary of §1 and the imports (X19), (E2), (E3d) of G1_B1_R1 Cor C.1).**
Let `𝔈` be the effective cone of the scaling-site square in either of its two invariant forms.
 (i) *(function-invariant)* `𝔈 = 𝓜^ext_+` (G1_B1_R1 Thm B). Then `ℓ_{E_w} ∉ 𝔈` (Cor C.1): Cor 19.25b is not escaped,
  and no `h⁰` with (b′) and (c) exists on it (Cor C.2).
 (ii) *(divisor-invariant)* `𝔈 = cl(𝓠_+^{fin}) = D^W/𝓝_∞` (Thm R). Then `ℓ_{E_w} ∈ 𝔈` — Cor 19.25b **is** escaped
  in the literal sense of (b′) — but the degree gate fails, `2K` is not ample, and the cone is a linear space. The
  Hodge-index route (P47 Thm 12.3; G1_B1_R1 Thm E(i)) requires the gate at its first step (a nonzero class of
  degree `0` must be non-effective), so it does not run, and `h⁰ > 0` on all of `𝔈` carries no information.
 (iii) *(intermediate cones)* Any cone `𝓜^ext_+ ⊊ 𝔈' ⊊ D^W/𝓝_∞` on which the degree gate holds and which contains
  `ℓ_{E_w}` satisfies the hypotheses of G1_B1_R1 Thm E(i) on the slice through `E_w`; extending it to all witnesses is
  (SG) under the gate, which is **equivalent to RH** (Thm E). No structure of the square (convexity, scaling
  invariance, the ray dictionary, the ruling geometry) selects such an `𝔈'`: the finite-PL Cartier divisors of
  107_236 have finite atomic angular second derivative (107_237 Thm 2.1) and lie in `𝓜_+` (horn (i)); the convex
  divisor-invariant ones give horn (ii).

*Proof.* (i) is G1_B1_R1 Thms B, C, Cors C.1–C.2. (ii) is Thm R. (iii): numerically `E_w = tF + dK ≡ tF + (d/2)(e₀+e₁)`,
so `ℓ_{E_w}/t` is a graph class `F + α'e₀ + β'e₁` of the primitive `F` with `α' = β' = d/(2t)`, and the witness
inequality `t²W_F > s_F²d²/2` says these ruling coefficients are *small* relative to `W(F)`. A cone containing this one
class is a statement about one `F`; the cone the Riemann–Roch route needs must contain such a class for **every**
primitive `F` (every witness), and with the gate that is (SG) under the gate, which is RH by G1_B1_R1 Thm E(i)
(the proof of Thm E(i) uses (SG) only at `α = β = 0`, and the gate). Conversely, under RH Thm E(ii) exhibits such a
cone. So the intermediate cone exists iff RH. The finite-PL statement is 107_237 Thm 2.1. ∎

**Corollary T.1 (N-c restated; `PROVED` as a reformulation).** R158_005 §2's N-c ("an effective cone strictly larger
than `𝓔`, containing `+` classes") is satisfied by `𝓠_+` and is vacuous there. The demand a Riemann–Roch route
actually needs is: *a salient effective cone on which `2K` is ample and which contains a class `≡ E_w` for every
witness.* By Thm E this is Prop 21.21 bigness, i.e. RH. So on the square, N-c is not a filter but the statement itself.

**Remark 5.1 (reading; the computations are `PROVED`, the reading `HEURISTIC`).**
* *Kernel count.* In the model, `Γ_{m+nπ}·F₂ = deg(m+nπ) = #ker(m+nπ) < ∞` (G1_B1_R1 Prop D). On the square, the sum
  graph `{α₁x + α₂y = c}` meets the ruling `{x = c'}` in the points `(c', (c−α₁c')/α₂)`, a 2-parameter family modulo the
  1-parameter scaling: one intersection orbit per value of the ratio, `∫d^*ρ = ∞` of them. Under `cl` this is the
  `−∫(1+ρ)α₁α₂/(ρ(α₁+α₂ρ))dρ = −∞` in Cor Q.1: **the tropical kernel of a sum over `Spec Z` is infinite.** Round 2's
  Remark H′.2 said the integral index is linear rather than quadratic; the correct statement is that on the square
  it is not even finite. N-a ("deliver the count") cannot be met by these graphs.
* *No ample class = not a surface.* Thm R(iii) says no class is positive on `𝓠_+`. On a projective surface the
  effective cone is salient and any ample class is positive on it; the failure here is the tropical face of P47 Thm
  22.17 (C3): `Spec Z ×_{Spec Z} Spec Z = Spec Z`, the square is not a surface. It is also the precise content of CC's
  own difficulty with `H¹` on the square (1805.10501: "null elements create unwanted contributions"): the null

* *Both horns are the same fact.* Horn (i) forbids the negative ray density that the sum graphs need; horn (ii) allows

## §8 Weakest steps

1. **(A3) as an axiom.** Theorem R assumes the class map is additive on the cone. Additivity is the defining property
  of divisors of sections (`Div(U+V) = Div U + Div V`), and it is what 107_237 (2.4) and the record's `D_f ↦ ∫fψ` use;
  but CC have not defined intersection numbers on the square beyond ray correspondences (107_239 Def 4.1 says so).
  A non-additive assignment is not a class map in any sense I know; if the CC school defines one, Thm T(ii) does not
  apply to it and Thm T(iii) does (it would have to select an intermediate cone, hence be RH-strength).
2. **(A2) as an axiom.** `cl(F₁) = e₀` rests on `F₁·Ψ_λ = 1` (tropical count of the smeared ruling with a ray) and on
  Lemma 4.2. Thm B(v) of round 1 arrived at the same identification as a limit of normalised rays, so the two
  independent routes agree; I regard this step as solid.
3. **Finite degree.** `𝓠_+^{fin}` restricts to ray parts of finite degree. The extreme elements (sum graphs) have
  `σ` of infinite degree and no class under `cl`; Thm R uses only truncations. If a regularised class for the full sum
  graph were defined, it would have degree `−∞` by monotone convergence of the ray part, which only strengthens
  Thm R(iii).
4. The convex-analysis inputs (convex ⟹ Hessian is a positive matrix Radon measure; psd distributional Hessian ⟹
  convex) are standard (Alexandrov; e.g. Evans–Gariepy §6.3) and `CITED (std.)`.
5. The dictionary `Ψ_λ ↦ ψ_λ` is taken from the record as in rounds 1–2; I re-verified only degrees, rulings and
  (11.16). Everything in §§2–4 that does not mention `w_G` is independent of it.
