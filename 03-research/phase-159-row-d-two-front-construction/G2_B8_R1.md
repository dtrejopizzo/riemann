# G2_B8_R1 — G2 (the mechanism), round 1: stability, Lee–Yang, Pólya–Schur on the Euler factors

Angle: treat each Euler factor as a stable object, combine the local factors by a stability-preserving operation, and
find where the archimedean factor enters. Normalisations are those of Paper 47 (`eq:symbol`, `eq:form`, `eq:W`,
`def:W`):
* `m(τ) = Re ψ(¼+iτ/2) − log π`;
* `v_n = 2Λ(n)/√n`;
* `𝔞_T(F) = (2π)^{-1}∫σ_T|F̂|²`;
* `P_T = {A(F)=B(F)=0}`;
* `C_0 = ψ(¼) − log π`.

For a real weight vector `v ∈ ℝ^{𝒩_T}`, write `V_T(v) = λ_min(A^{(v)}_T | P_T)` as in P47 `lem:degen`, so that
`V_T(v_T(Λ)) = λ^A_T` and `V_T(0) = λ^∞_P(T)`. `𝒱_T = {v : V_T(v) ≥ 0}` (P47 `prop:finite`(ii)).

**Verdict, stated first.** The angle gives **no mechanism** and **no sign at any window**. Its outcome is an obstruction.
The stability data of the finite places are:
* temperedness (`|α_p| = 1`);
* local Lee–Yang stability (the divisor of each local factor on `Re s = 0`);
* the Euler-product shape;
* the zeros and pole of ζ in `Re s > 0`;
* `ψ` up to `O_T(log x)`.

These data are **blind to the Satake phases** `arg α_p`, and the sign depends on those phases. The memo proves three
things:
* **Theorem B (barycentre principle).** An elementary consequence of `prop:finite`(ii) and `lem:degen`.
* **Theorem S (Satake-torus void).** For every `T ≥ 0.60`, a set of Satake phases of positive Haar measure, and a set of
  Kronecker twists `t` of positive density, fail `RD_T`. The failure holds in the primitive form, hence also in the
  complete form. All of these data share every stability property of ζ listed above.
* **Lemma H (local Hermite–Biehler defect).** At the level of the Euler product, the de Branges / Hermite–Biehler
  comparison fails at every single prime, on a set of heights of positive density. This is the Euler-factor form of
  `cor:Qp`.

The archimedean factor is the only local factor that is fixed under the Satake-torus action. It enters **only** through
the functional equation, which ties the phases to Γ_ℝ. A stability-preserving operation on local factors commutes with
the torus action, so it cannot see the functional equation. The Kreĭn continuous stability flow in `T` does see it, but
that flow is a restatement (E1/E3, KEP). The angle is closed at round 1 as **dead end + new obstruction**.

## §1 Definitions

**D1 (local symbols).** For a prime `p` and `α ∈ ℂ` with `|α| ≤ 1`, the local factor is `L_p(s;α) = (1 − α p^{-s})^{-1}`.
It is *locally stable* (Lee–Yang in the variable `x = p^{-s}`): its polar divisor lies in `{|x| = 1/|α|} ⊂ {Re s ≤ 0}`,
and it lies on `Re s = 0` exactly when `|α| = 1` (tempered). The local comb weights are
`v_{p^k}(α) = 2 log p · Re(α^k) / p^{k/2}`. ζ is the point `α_p = 1` for all `p`.

**D2 (Satake torus of a window).** Let `𝒫_T = {p prime : p < e^{2T}}` and `𝕋_T = (ℝ/2πℤ)^{𝒫_T}` with Haar probability
`dθ`. For `θ ∈ 𝕋_T` put `α_p = e^{iθ_p}` for `p ∈ 𝒫_T` and `α_p = 1` otherwise. Then
`v_n(θ) = 2 log p · cos(kθ_p) / p^{k/2}` for `n = p^k ∈ 𝒩_T`, so that `v(0) = v_T(Λ)`. Put `Φ_T(θ) := V_T(v(θ))`.

**D3 (Kronecker twists).** For `t ∈ ℝ`, `θ(t) := (−t log p)_{p∈𝒫_T}`. Then `v_n(θ(t)) = v_n cos(t log n)`.

**D4 (the rotated L-data).** For `θ ∈ 𝕋_T` let
`L_θ(s) := ζ(s) · E_θ(s)` with `E_θ(s) := ∏_{p∈𝒫_T} (1 − p^{-s}) / (1 − e^{iθ_p}p^{-s})`.
Its coefficients are `a_θ(n) = Λ(n) e^{ikθ_p}` for `n = p^k` with `p ∈ 𝒫_T`, and `Λ(n)` otherwise. The window comb
`2 Re a_θ(n)/√n` is `v(θ)`.

## §2 The barycentre principle and the Satake-torus void

**Theorem B (barycentre principle). PROVED.** Fix `T`, and let `μ` be a Borel probability measure on `ℝ^{𝒩_T}` with
compact support and barycentre `b = ∫ v dμ(v)`. Then `∫ V_T dμ ≤ V_T(b)`. In particular, if `b ∉ 𝒱_T`, then
`μ(ℝ^{𝒩_T} ∖ 𝒱_T) > 0`. Form: primitive. The same holds for the complete form with `V^W_T(v) = λ_min(W^{(v)}_T)`.

*Proof.* By `lem:degen`, `V_T` is finite and concave on `ℝ^{𝒩_T}`. It is the infimum of the affine maps
`v ↦ C_0 + Lév(c_F) − Σ v_n c_F(log n)`, so it is continuous, since a finite concave function on `ℝ^N` is continuous.
Jensen's inequality for concave functions and compactly supported `μ` gives `∫V_T dμ ≤ V_T(b)`. If `V_T(b) < 0`, then
`V_T < 0` on a set of positive `μ`-measure. For the complete form, `W^{(v)}_T(F) = 𝔞^{(v)}_T(F) + 2Re(A(F)\overline{B(F)})`
is again affine in `v` for fixed `F`, so the same argument applies to `V^W_T = inf_F`. It is finite because
`V^W_T ≥ C_0 − Σ|v_n| − c` and `2|A||B| ≤ c‖F‖²` on the bounded window. ∎

**Theorem S (Satake-torus void). PROVED.** Let `T ≥ 0.60`.
1. `∫_{𝕋_T} Φ_T(θ) dθ ≤ λ^∞_P(T) < 0`. Hence the failure set `U_T = {θ : λ^A_T(v(θ)) < 0}` is open with Haar measure
  `> 0`. The same holds for `λ^W` in place of `λ^A`.
2. `{t ∈ ℝ : λ^A_T(v(θ(t))) < 0}` has positive lower density. That is, for a positive proportion of `t`, the twisted
  comb `v_n cos(t log n)` with the **unshifted** archimedean symbol `m` fails `RD_T`.
3. Every point `θ ∈ 𝕋_T` (in particular every point of `U_T`) shares the following with ζ:
  * (i) an Euler product of degree 1, every local factor tempered and locally stable (D1);
  * (ii) exactly the zeros and the pole of ζ in `Re s > 0`, since `E_θ` is holomorphic and zero-free on `Re s > 0`;
  * (iii) `ψ_{a_θ}(x) = ψ(x) + O_T(log x)`, with `|ψ_{a_θ}(x) − ψ(x)| ≤ 2π(e^{2T}) log x`, so every statement
  `ψ(x) = x + O(ε(x))` with `ε(x) ≫ log x` transfers, including the RH-strength one;
  * (iv) the same archimedean symbol `m`.

  What it does not share, for `θ ∉ {0}`: the functional equation (`E_θ(s) ≠ E_θ(1−s)`), reality of the
  coefficients, and `a ≥ 0`.

*Proof.*
1. For `n = p^k` with `k ≥ 1`, `∫ cos(kθ_p) dθ_p = 0`. So the push-forward of Haar under `θ ↦ v(θ)` (continuous,
  compact image) has barycentre `0`. By Theorem B, `∫Φ_T ≤ V_T(0) = λ^∞_P(T)`, and `λ^∞_P(T) < 0` for `T ≥ 0.60`
  (P47 `cor:Tarch`, machine-verified). `U_T` is open because `Φ_T = V_T ∘ v` is continuous. It has positive measure
  because otherwise `∫Φ_T ≥ 0`. For `λ^W`, use `V^W_T ≤ V_T`.
2. Since the `log p` are linearly independent over ℚ (unique factorisation), `t ↦ θ(t)` is equidistributed in `𝕋_T`
  (Kronecker–Weyl, CITED). Pick an open box `Q ⊂ U_T`. The density of `{t : θ(t) ∈ Q}` is `|Q| > 0`.
3. (i) is D1 with `|e^{iθ_p}| = 1`. (ii): each factor of `E_θ` has its zeros and poles on `p^{-s} ∈ {1, e^{-iθ_p}}`,
  i.e. on `Re s = 0`. (iii): `ψ_{a_θ}(x) − ψ(x) = Σ_{p∈𝒫_T} log p Σ_{p^k≤x}(e^{ikθ_p} − 1)`, and the inner sum has at
  most `log x / log p` terms of modulus at most `2`. (iv) holds by construction. ∎

**Corollary S′ (what a stability mechanism cannot use). PROVED (method constraint, in the sense of P46 Thm 18.1(ii)).**
Let `T ≥ 0.60`. Suppose the only input a derivation of `RD_T` takes from the finite places is a property `𝒫` that holds
for `v(θ)` for Haar-almost every `θ ∈ 𝕋_T`. Examples of such `𝒫`:
* temperedness;
* local Lee–Yang stability of the Euler factors;
* degree-1 Euler shape;
* the location of the zeros and pole in `Re s > 0` (every zero-free region, every density theorem);
* partial-sum bounds with error `≫ log x`;
* any property of the local divisors taken modulo rotation.

Then the derivation proves a false statement at a point of `U_T`. So no such derivation exists. In particular, **no
stability-preserving operation on the local factors** decides `RD_T`: a Borcea–Brändén / Pólya–Schur / Lee–Yang
preserver sees only the local zero loci `{x = e^{-iθ_p}}` and their stability class, and these are moved within the
class by the torus action.

*Proof.* Theorem S(1) and the argument of `cor:void`. ∎

**What is new relative to `cor:void`.**
* Deletion kills the local factor (`α_p = 0`, not tempered).
* Amplification leaves the unit disc (`|α| > 1`, locally unstable).
* Theorem S stays inside the tempered, locally stable class at every prime and keeps the exact zeros of ζ in
  `Re s > 0`.

So temperedness and local stability are added to the list of blind inputs. The phase information that the sign needs is
exactly `θ = 0`, i.e. `arg α_p = 0` for `p < e^{2T}`.

**Remark S″ (the position of ζ on its torus). PROVED (given the cited inputs).**
* Under RH, `Φ_T(0) = λ^A_T ≥ 0`.
* The Haar mean satisfies `∫Φ_T ≤ λ^∞_P(T) ≤ C_0 + φ((3π/2T)²) → C_0 = −5.372…` (`prop:arch`(ii)).
* `Φ_T(0) ≤ 4·10⁹ T e^{−15.449T}` (`thm:margin`).

So, as `T` grows, the ζ point is pressed onto `∂𝒱_T` while its whole Satake orbit sits, on average, a fixed distance
`≈ |C_0|` inside the failure region. Whether `θ = 0` maximises `Φ_T` on `𝕋_T` is **OPEN** (question P159.B8.1).
`v(0)` dominates `v(θ)` coordinatewise, but `V_T` is not monotone (`lem:cpos`). Even a positive answer gives no sign.

## §3 The local Hermite–Biehler defect: where Γ_ℝ enters

Let `Λ_ℝ(s) = Γ_ℝ(s)ζ(s)`, with `Γ_ℝ(s) = π^{-s/2}Γ(s/2)`. The stability route to RH through de Branges asks for
`|X(1−s)| < |X(s)|` on `Re s > ½`, for a suitable `X` built from `Λ_ℝ` (R157_002 row 39; Lagarias; Lagarias–Suzuki
for Eisenstein zetas, row 53). On the Euler product, this comparison factorises formally place by place.

**Lemma H (local defect). PROVED.** Let `½ < σ < 1`, `s = σ + it`, `a = p^{-σ}`, `b = p^{σ−1}` (so `a < b < 1`). Then
`|1 − p^{s−1}|² − |1 − p^{-s}|² = (b − a)(a + b − 2cos(t log p))`. Hence
`|L_p(s;1)| > |L_p(1−s;1)|` if and only if `cos(t log p) < (p^{-σ} + p^{σ−1})/2`. The comparison fails at **every** prime
on a set of heights `t` of positive density, namely `cos(t log p) > (a+b)/2`, where `(a+b)/2 < 1`.

*Proof.* `p^{-s} = a e^{-iφ}` and `p^{s−1} = b e^{iφ}` with `φ = t log p`. Expand both squared moduli and subtract. ∎

**Reading.** Lemma H is `cor:Qp` (each local prime form is indefinite on `P_T`), transported to the Euler factor:
* no finite place is Hermite–Biehler by itself;
* the archimedean factor is the only local factor that is HB-dominant, since `|Γ_ℝ(s)| > |Γ_ℝ(1−s)|` for `σ > ½` and
  `|t| ≥ t_0` (Spira 1965; Dixon–Schoenfeld 1968; CITED, not re-verified here, and not load-bearing);
* the comparison can hold only collectively.

For `Re s > 1` it does hold collectively: `Re ξ′/ξ(s) > 0`, unconditionally, by the Hadamard product with the zeros in
the strip. In prime terms that positivity reads
`½log(|t|/2π) + Re[1/s + 1/(s−1)] + Re ζ′/ζ(s) + O(1/|t|) > 0`.
Carrying it from `Re s > 1` down to `Re s > ½` is the statement `Θ ≤ ½`, which is row 39 (EQUIV). The input that does
it is the location of the zeros, which is the class `𝒞_zeros`, void by `cor:void`.

**Where the archimedean factor enters, precisely.** Take ζ's local data and apply the rotation
`θ ↦ θ + φ, φ ∈ 𝕋_T`:
* the Γ_ℝ factor is **fixed** by the rotation, while the finite factors move;
* the only relation that ties the finite phases to Γ_ℝ is the functional equation `Λ_ℝ(s) = Λ_ℝ(1−s)`. In the Selberg
  class of degree 1 with Γ-factor Γ_ℝ(s) and conductor 1, the functional equation singles out ζ
  (Kaczorowski–Perelli, Acta Math. 182 (1999); CITED, not load-bearing);
* consistently twisting the archimedean factor as well (the symbol `½[m(τ+t) + m(τ−t)]` with comb `v_n cos(t log n)`)
  gives the Weil form of ζ on modulated tests `F e^{±itx}`. These preserve `L²(I_T)` but not `P_T`, so they are
  controlled by the **complete** form of ζ.

Therefore:
* **(A-entry) PROVED:** among the data of Theorem S(3), the archimedean factor enters the sign only jointly with the
  phases, through the functional equation;
* **(A-entry′) HEURISTIC:** a stability operation that uses the local factors and Γ_ℝ separately, as independent
  "spins" with no coupling, cannot produce the sign.

The Lee–Yang analogy makes this concrete. An Euler product is a system of **non-interacting** spins, one per prime, with
the archimedean spin fixed. Lee–Yang forcing needs a ferromagnetic **interaction**, and the only interaction available
is the functional equation. This is the programme's recurring wall (P46 §28.3, the polar/Frobenius coupling) seen from
the stability side. It is a reading, not a theorem.

## §4 The one stability operation that sees the functional equation: the Kreĭn flow in `T`

Per window, `λ^W_T > 0` holds if and only if the positive-definite extension problem for `W|_{[−2T,2T]}` is solvable
and non-degenerate (P47 `thm:KEP3`). In that case the Kreĭn orthogonal entire functions `E_T(z)` are Hermite–Biehler:
stable in the upper half-plane (Kreĭn; de Branges; CITED).

The family `T ↦ E_T` solves the Kreĭn system `∂_T E_T = izE_T − A(T)E_T^#` (canonical-system form). As long as the
coefficient `A(T)` is finite, this system is a stability-preserving continuous operation. Unlike the discrete Schur
algorithm, it imposes **no constraint** on `A(T)` beyond local integrability. The whole content lies in the map
`W ↦ A`:
* the Gelfand–Levitan / Kreĭn resolvent exists on `[0, T]` if and only if positivity holds up to `T`;
* at a first failure `T_0`, the Gram determinant `D(T) = det(I + K_T)` vanishes, `A(T)` blows up as `T ↑ T_0`, and
  `d/dT log D(T)` is minus a resolvent trace;
* the prime atoms `δ_{log n}` enter `A(T)` only at the regime boundaries `T = ½log n`.

So "the flow never blows up" is **E1 = RH** (EQUIVALENT). Moreover, at each regime boundary one atom enters with no
determined sign (`rem:regimes`), and propagation upward in `T` is excluded as a method (`cor:mono`, W15). **Label:
EQUIVALENT (restatement of E1/E3), not a mechanism.** It is the only stability flow found that sees the functional
equation, because it is built from the complete distribution `W`, which contains the functional equation.

## Weakest step

Theorem S(1) rests on `λ^∞_P(T) < 0` for `T ≥ 0.60` (P47 `cor:Tarch`, machine-verified, imported as PROVED), and on
continuity/concavity of `V_T` from `lem:degen`. The complete-form version needs `V^W_T` finite, argued in Theorem B.
Corollary S′ is a method constraint about derivations whose finite-place input is a.e.-rotation-invariant. It does not
exclude a stability argument that uses the functional equation in a load-bearing way. The only such argument found is
the Kreĭn flow, which is E1. The "non-interacting spins" reading (A-entry′) is HEURISTIC.
