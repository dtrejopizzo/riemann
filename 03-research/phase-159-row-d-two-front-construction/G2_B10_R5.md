## §1 Theorem Γ_f — the growth law for an arbitrary zero set (two-sided proof)

**Setting.** Let `Z` be a multiset of complex numbers ("zeros") with the following properties.
* (Z1) `Θ₀ := sup_{ρ∈Z}|Re ρ − ½| < ∞`.
* (Z2) `#{ρ ∈ Z : |Im ρ| ≤ X} ≪ X log(X+2)`.

Write `w_ρ := ρ − ½`. For real `F ∈ C_c^∞(ℝ)` put `c_ρ(F) := Φ_F(ρ)Φ_F(1−ρ)`. Integrating by parts gives
`|Φ_F(½+a+iγ)| ≤ C_{j,F}(1+|γ|)^{−j}` uniformly for `|a| ≤ Θ₀`, so `S_F := Σ_ρ|c_ρ(F)| < ∞` by (Z2). Define
```
W^Z(G) := Σ_{ρ∈Z} Φ_G(ρ)Φ_G(1−ρ) (real G ∈ C_c^∞),
λ^{Z,W}_T := inf{W^Z(G)/‖G‖² : 0 ≠ G ∈ C_c^∞(I_T) real} ∈ [−∞, ∞),
λ^{Z,A}_T := the same infimum over G ∈ P_T ∩ C_c^∞(I_T).
```
For `Z` = the nontrivial zeros of `ζ`, `W^Z = W_T` on these tests (P46 l.137), and C_c^∞ tests lie in the form
domain. Hence P46's `λ^W_T ≤ λ^{Z,W}_T` and `λ^A_T ≤ λ^{Z,A}_T`, so **lower bounds on P46's bottoms are inherited by
`λ^{Z,•}`** (PROVED). That is the only direction used.

**Lemma 1.1 (translation and the shift function; PROVED).** `Φ_{τ_uG}(s) = e^{−(s−½)u}Φ_G(s)`. Hence
`W^Z(τ_uG) = W^Z(G)`, `A(τ_uG) = e^{−u/2}A(G)` and `B(τ_uG) = e^{u/2}B(G)`, so `τ_u` preserves `{A = B = 0}`. For
real `F` and `b ∈ ℝ`,
```
W^Z(F + bτ_uF) = (1+b²)W^Z(F) + 2b β_F(u), β_F(u) := Σ_ρ c_ρ(F) cosh(w_ρu), (1.1)
```
and the series converges absolutely, with `|β_F(u)| ≤ S_F cosh(Θ₀u)`.
*Proof.* `Φ_{τ_uF}(ρ)Φ_F(1−ρ) = e^{−w_ρu}c_ρ` and `Φ_F(ρ)Φ_{τ_uF}(1−ρ) = e^{w_ρu}c_ρ`. The cross term of the
quadratic form is the sum of these two, times `b`, which is `2bΣc_ρcosh(w_ρu)`. The bound uses
`|cosh(x+iy)| ≤ cosh x`. ∎

**Lemma 1.2 (good tests; PROVED).** Let `ρ₀ ∈ Z` with `a₀ := Re ρ₀ − ½ ≠ 0`, and let `T₀ > 0`.
(i) There is a real `F ∈ C_c^∞(I_{T₀})` with `c_{ρ₀}(F) ≠ 0`.
(ii) If moreover `ρ₀ ∉ {0, 1}`, such an `F` can be taken in `P_{T₀}`.

*Proof.* `c_{ρ₀}(F) = ℓ_+(F)ℓ_−(F)` with `ℓ_±(F) = ∫F(t)e^{±w₀t}dt`. On the real space `V` of real test functions,
the condition `ℓ_+(F) = 0` means that both `Re ℓ_+` and `Im ℓ_+` vanish. Its solution set is a real subspace, and it
is proper because `e^{w₀t} ≢ 0` on `I_{T₀}`. The same holds for `ℓ_−`. A real vector space is not the union of two
proper subspaces, which gives (i).
For (ii), take `V = P_{T₀} ∩ C_c^∞`. If `ℓ_+` vanished on `V`, then its real and imaginary parts, which are real
functionals vanishing on `ker A ∩ ker B`, would lie in `span_ℝ{A, B}`. Then `e^{w₀t} ∈ span_ℂ{e^{t/2}, e^{−t/2}}` as
distributions on `I_{T₀}`. That is false, because `w₀ ∉ {±½}` and distinct exponentials are linearly independent.
Proceed as in (i). ∎

**Theorem Γ_f (PROVED; complete and primitive forms).** Let `Z` satisfy (Z1)–(Z2), and let `κ ≥ 0`, `C ≥ 0`, `T₁`.
(i) If `λ^{Z,W}_T ≥ −Ce^{κT}` for all `T ≥ T₁`, then `|Re ρ − ½| ≤ κ/2` for every `ρ ∈ Z`.
(ii) The same holds with `λ^{Z,A}_T` in place of `λ^{Z,W}_T`, provided `0, 1 ∉ Z`.
(iii) Put `κ^{Z,•} := limsup_{T→∞}T^{−1}log⁺(−λ^{Z,•}_T)`, with the convention `κ = ∞` if `λ = −∞` for some `T`. Then
`κ^{Z,A} ≥ 2Θ_Z − 1` and `κ^{Z,W} ≥ 2Θ_Z − 1`, where `Θ_Z := ½ + Θ₀`.

*Proof.* (i) Suppose `ρ₀ ∈ Z` has `|a₀| > κ/2`. Replacing `ρ₀` by `1−ρ₀` changes neither `c_{ρ₀}` nor the
conclusion (`c_{1−ρ}(F) = c_ρ(F)` identically), so we may assume `a₀ > κ/2`. Fix `T₀ > 0`. By Lemma 1.2(i) choose `F`
with `‖F‖ = 1` and `c_{ρ₀}(F) ≠ 0`.
For `u ≥ 0`, `F ± τ_uF` has support in `(−T₀−u, T₀)`. After translation by `u/2` it lies in `C_c^∞(I_{T₀+u/2})`,
and its norm squared is at most 4. By translation invariance and the hypothesis, for `T₀ + u/2 ≥ T₁`,
```
2W^Z(F) ± 2β_F(u) = W^Z(F ± τ_uF) ≥ −4Ce^{κ(T₀+u/2)} .
```
(If `λ ≥ 0` the right side can be replaced by 0.) Both signs are admissible, so
`|β_F(u)| ≤ |W^Z(F)| + 2Ce^{κT₀}e^{κu/2}` for `u ≥ u₁`. On `[0,u₁]`, `β_F` is continuous, hence bounded. So
`|β_F(u)| ≤ C′e^{κu/2}` on `[0,∞)`.
Hence `L(z) := ∫_0^∞e^{−zu}β_F(u)du` converges absolutely and is holomorphic on `Re z > κ/2`. For `Re z > Θ₀`,
Fubini (justified by `Σ|c_ρ|∫e^{−(Re z−Θ₀)u}du < ∞`) gives
```
L(z) = 𝒢(z) := Σ_ρ c_ρ z/(z² − w_ρ²) .
```
`𝒢` is meromorphic on `ℂ`. On a compact set `K`, all but finitely many terms satisfy `|z² − w_ρ²| ≥ 1`, because
`|Im w_ρ| → ∞` along `Z` by (Z2). Those terms are dominated by `S_F·sup_K|z|`, and the rest are rational. At `z = w₀`
the only contributing terms are those with `w_ρ = ±w₀`, i.e. `ρ = ρ₀` and `ρ = 1−ρ₀`. The function `z/(z² − w²)`
has residue `½` at `z = ±w` when `w ≠ 0`. So
```
Res_{z=w₀}𝒢 = ½(m(ρ₀) + m(1−ρ₀))c_{ρ₀}(F) ≠ 0,
```
where `m(·) ≥ 0` is the multiplicity in `Z` and `m(ρ₀) ≥ 1`.
Thus `𝒢` has a genuine pole at `w₀`, with `Re w₀ = a₀ > κ/2`. But `𝒢 = L` on `Re z > Θ₀`, and `L` is holomorphic on
the connected half-plane `Re z > κ/2`. By the identity theorem, `𝒢` extends holomorphically to `Re z > κ/2` minus its
discrete pole set, and on that set it agrees with `L`. So `𝒢` is bounded near `w₀`, a contradiction.
(ii) is the same argument, with Lemma 1.2(ii) giving `F ∈ P_{T₀}` and Lemma 1.1 keeping `F ± τ_uF` in `P` after
centring.
(iii) If `κ > κ^{Z,•}`, the hypothesis of (i) or (ii) holds for large `T`, so `Θ₀ ≤ κ/2`. Let `κ` decrease to
`κ^{Z,•}`. ∎

**Remarks (PROVED unless marked).**
* **Γ1 (what is not used).** There is no Landau theorem, so the one-sidedness issue and the need for non-real poles
  (R4, weakest step) disappear. There is no functional equation (the residue is nonzero even if `1−ρ₀ ∉ Z`), no
  Euler product, no prime side, and no polar term. The theorem is a statement about **zero multisets**. For `ζ` it
  reproduces the R4 cluster's `2Θ − 1 ≤ κ^A ≤ κ^W`. The upper bound `κ^W_ζ ≤ 1` (R4 Γ(iii), Chebyshev) is the first
  place where arithmetic enters: `v_n = 2Λ(n)/√n ≥ 0` with `Σ_{n<x}v_n ≪ √x`, which is A8 of P47 §18.
* **Γ2 (R4 Remark Γ3 upgraded).** For `Z = Z(Ξ_Q)`, the nontrivial zeros of the completed Epstein function (a strip
  by the Dirichlet series and the FE; `N ≪ T log T` by order 1; `0, 1` are poles, not zeros), Theorem Γ_f applies in
  both forms. With X21 it gives `κ^{Q,A}, κ^{Q,W} ≥ 2β_Q − 1 > 1`, where `β_Q := sup Re ρ > 1`. This was HEURISTIC in
  R4 and is now PROVED, relative to the zero-side definition of the form. The prime-side form of P47 Thm 18.8, if
  one uses it, agrees with the zero side on `C_c^∞` tests by the explicit formula for `Ξ'_Q/Ξ_Q` (Weil 1952,
  CITED). This agreement is not load-bearing, since Γ_f needs only the zero side.
* **Γ3 (Ξ_a).** For `Ξ_a` (all zeros at `Re ρ = ½ ± a`), `κ ≥ 2a`. No false positivity.

## §2 Lemma F — counting is not the parameter (zero side, PROVED)

**Lemma F (PROVED).** Let `𝒮` be any property of zero multisets that is invariant under finite modifications, for
example "`liminf N_0(T)/N(T) ≥ c`", "`N_0(T)/N(T) → 1`", or any zero-density bound `N_off(σ,T) = o(N(T))`. Within the
class of multisets satisfying (Z1)–(Z2) and the symmetry `ρ ↦ 1−ρ, ρ ↦ \bar ρ`, the property `𝒮` does not determine
the sign of the window bottoms, nor whether `κ = 0`.

*Proof.* Let `Z₀ := {½ + iπ(k+½) : k ∈ ℤ}`, the zeros of `cosh(s−½)`. It satisfies (Z1)–(Z2) (the count is linear),
and it is symmetric. It lies on the line, so `W^{Z₀}(G) = Σ|Φ_G(½+iγ)|² ≥ 0` for real `G` (`Φ_G(½−iγ) = \bar Φ_G(½+iγ)`),
and `κ^{Z₀} = 0`. Let `Z₁` be `Z₀` with one symmetric quadruple `{ρ₁, 1−ρ₁, \bar ρ₁, 1−\bar ρ₁}` added, where
`Re ρ₁ = ½ + a`, `a > 0`. Then `𝒮(Z₀) ⟺ 𝒮(Z₁)`, but `κ^{Z₁,•} ≥ 2a > 0` by Γ_f, and in particular
`λ^{Z₁,•}_T < 0` for large `T`. ∎

*Reading.* Lemma F is the zero-side counterpart of `thm:finmod`/`cor:void`. Every output of a mollifier argument is a
count, a proportion or a density, so it cannot by itself decide `E_sub`, still less the sign. The multisets `Z₀, Z₁`
are not zero sets of `L`-functions, so Lemma F alone does not exclude an argument that uses more arithmetic than the
count. Theorem H closes that gap with arithmetic witnesses.

## §3 Theorem H — "T2 for mollifiers" (the output of the mollification method is Euler-product-blind)

**Theorem H (PROVED from CITED inputs; complete form for DH, both forms for `Z_Q`).**
(i) *Davenport–Heilbronn.* `f_DH` is a linear combination of the two odd primitive Dirichlet `L`-functions mod 5,
and it has a Riemann-type functional equation (Titchmarsh §10.25). By Selberg's theorem (CITED via Dousselin,
arXiv:2311.10285, abstract and §1.2), a positive proportion of its nontrivial zeros lie on `Re s = ½`,
unconditionally. It has zeros with `Re s > 1` (Davenport–Heilbronn 1936; Titchmarsh §10.25). Its nontrivial zeros
lie in a strip (Dousselin §1.2) and number `≪ T log T`. By Theorem Γ_f(iii),
`κ^{DH,W} ≥ 2σ_DH − 1 > 1`, where `σ_DH := sup Re ρ > 1`.
(ii) *Epstein.* For `h(−D) > 1`, `Z_Q` has a positive proportion of zeros on the line (Rezvyakova,
arXiv:2411.18492, unconditional) and zeros in `Re s > 1` (X21). By Γ2, `κ^{Q,A}, κ^{Q,W} > 1`.
(iii) *Conditional 100 %.* Under the Bombieri–Hejhal hypotheses (GRH and weak pair correlation for the Hecke
`L`-functions of the class group; CITED as reported), `N_0(T, Z_Q)/N(T, Z_Q) → 1`, while still `κ^{Q,•} > 1`
(unconditionally, by (ii)).
(iv) *Contrast with `ζ`.* `κ^W_ζ ≤ 1` (R4 Γ(iii), Chebyshev), so `κ^A_ζ ≤ 1` too.

*Proof.* (i)–(iii) combine the cited statements with Theorem Γ_f(iii) and Γ2. For (iii), the growth statement comes
from (ii) and does not depend on the hypotheses. (iv) is R4 Γ(iii): `𝔞_T(F) ≥ (C_0 − Σ_{n∈𝒩_T}v_n)‖F‖²` and
`|2AB| ≤ 4sinh T‖F‖²`, so `λ^W_T ≥ −Ce^T`. ∎

**Corollary H1 (METHOD-CONSTRAINT, in the sense of P47 Thm 18.1/18.16).** Let `𝔓` be a set of premises that hold
for `Z_Q` (`h > 1`) or for `f_DH`, with the window form defined through the zero side. Examples: the mollification
method's output (a positive proportion, any constant), FE, a strip, order 1, a Dirichlet series with periodic
coefficients, and (for `Z_Q`) the pole at 1 with the Tate moments. Then there is no derivation from `𝔓` of any of
the following for `ζ`:
* `∀T λ^A_T ≥ 0` or `∀T λ^W_T ≥ 0` (the G2 target);
* `E_sub` (`κ^A = 0`, EQUIVALENT to RH);
* `κ^A ≤ 1 − η` (quasi-RH, R4 Remark Γ2);
* not even `κ^W ≤ 1`.

Conditionally on Bombieri–Hejhal, the same holds if "positive proportion" is replaced by "100 %". *Proof.* Such a
derivation would apply verbatim to the witness, which violates each conclusion by Theorem H. ∎ (PROVED as a
statement about derivations. It says nothing about `ζ` itself.)

**Reading (HEURISTIC, methodological).** In Levinson–Conrey for `ζ`, the Euler product enters through the mollifier
coefficients `μ(n)` (`M ≈ 1/ζ`) and through the twisted second-moment formula. The *output* of that use is again a
count. By Corollary H1, the count is a premise that Epstein also satisfies. So a proof that runs "mollifier ⟹
proportion ⟹ sign or rate" must use A7, A8 or A9 a second time, **after** the counting step, in a form that no count
records. Lemma F explains why: `κ` is not a finite-modification-invariant functional of the zero set. This gives
R157_002 row 20 (Levinson–Conrey outputs, EXCL by `cor:void`) a second, independent reason, which acts at the
growth level and not per window.

## §4 Proposition J — the Levinson–Jensen inequality in H² form

**Setting.** `μ := dt/(2π(¼+t²))` is a probability measure on `ℝ`. The Cayley map `z = (s−1)/s` sends
`{Re s > ½}` onto the unit disc and `s = 1` to `z = 0`. On `Re s = ½` it satisfies `|z| = 1`, and it carries `μ` to
normalised arc length. (Check: `d arg((s−1)/s)/dt = −1/(¼+t²)` on `s = ½+it`, and `∫dt/(¼+t²) = 2π`.) A zero `ρ` with
`Re ρ > ½` goes to `z_ρ`, with `|z_ρ| = |ρ−1|/|ρ| < 1`.

**Lemma J0 (PROVED).** Put `g(s) := ζ(s)(s−1)/s`. Then `g∘(Cayley)^{−1}` belongs to `H²(𝔻)`, and for every
Dirichlet polynomial `M(s) = Σ_{n≤N}a_nn^{−s}`, `g_M := gM` does too.
*Proof.* `f ∈ H²(𝔻)` iff `F(s) = f((s−1)/s)` satisfies `F(s)/s ∈ H²(Re s > ½)`. Here `F/s = ζ(s)(s−1)/s²` is
holomorphic on `Re s > ½`: the pole at 1 is removed. It is continuous up to the line. By the convexity bound
`|ζ(σ+it)| ≪_ε (1+|t|)^{¼+ε}`, uniform for `σ ≥ ½`, `|t| ≥ 1`, together with `|ζ(σ+it)| ≪ 1` for `σ ≥ 2`, we get
`sup_{σ>½}∫|F(σ+it)/(σ+it)|²dt < ∞`. That is the Paley–Wiener characterisation of `H²` of the half-plane. `M` is
bounded on `Re s ≥ ½` by `Σ|a_n|n^{−½}`, and `H^∞·H² ⊂ H²`. ∎

**Proposition J (PROVED; complete-form analogue, zero side of `ζ`).** For every Dirichlet polynomial `M` with
`M(1) = Σa_n/n ≠ 0`,
```
0 ≤ Σ_{ζ(ρ)=0, Re ρ>½} log|ρ/(1−ρ)| ≤ ½ log R(M), R(M) := ∫_ℝ|ζ(½+it)M(½+it)|²dμ(t) / |M(1)|² .
```
Moreover `R(M) > 1` for every `M`, and the sum counts multiplicity.

*Proof.* By Lemma J0, `g_M ∈ H² ⊂ N⁺` (Smirnov class). Factor it as `g_M = B·S·O`, with `B` the Blaschke product of its
zeros in the disc, `S` singular inner (`|S(0)| ≤ 1`) and `O` outer. Then
`log|g_M(0)| = log|B(0)| + log|S(0)| + ∫log|g_M^*|dθ/2π`. The zeros of `g_M` in the disc include the images of the
zeros of `ζ` with `Re ρ > ½`, so `−log|B(0)| ≥ Σ_{Re ρ>½}log|ρ/(1−ρ)|`. At `s = 1`, `g_M(1) = M(1)`, because
`ζ(s)(s−1) → 1`. On the boundary, `|g_M^*| = |ζM(½+it)|`, because `|(s−1)/s| = 1`. Hence
```
log|M(1)| + Σ_{Re ρ>½} log|ρ/(1−ρ)| ≤ ∫log|ζM|dμ ≤ ½ log ∫|ζM|²dμ ,
```
where the second inequality is Jensen's inequality for the concave `log` and the probability measure `μ`.
Rearranging gives the claim. `R(M) > 1`: `g_M(0) = ∫g_M^*dθ/2π`, so `|M(1)|² ≤ ‖g_M‖²_{H²}`, with equality only if
`g_M` is constant. That is impossible, since `ζM` is not constant on the line. ∎

**Consequences (labels as marked).**
* **J1 (PROVED).** `inf_M R(M) = 1 ⟹ RH`, with the infimum over Dirichlet polynomials with `M(1) ≠ 0`.
  Quantitatively, every `M` gives the zero-free region that the inequality encodes: an off-line zero
  `ρ = β + iγ` has `log|ρ/(1−ρ)| ≍ (2β−1)/|ρ|²·½`, so `Σ(2β−1)/|ρ|² ≲ 2log R(M)`. This is weak for large `|γ|`
  because of the weight `μ`.
* **J2 (reading; PROVED structure, HEURISTIC comparison).** Levinson's argument has three steps: Littlewood's lemma
  (an exact identity), then Jensen/AM–GM (lossy), then the twisted second moment (asymptotically exact for
  `θ < 4/7`, Conrey). Prop J is the same chain written on the `μ`-weighted line instead of the vertical segment
  `σ₀ = ½ − R/L`: the BSY functional takes the place of Littlewood's rectangle. "Perfect mollification" (Dousselin
  §1.1) is equality in the Jensen step, i.e. `R(M) → 1`, and that forces **zero** exceptions, not 100 %.
* **J3 (OPEN).** `RH ⟹ inf_M R(M) = 1`? By Hilbert-space geometry, `inf R = 1/‖P_K1‖²_{H²}`, where `K` is the
  closed span of `{g_M}`. So the question is whether `1 ∈ K`. In the disc picture `n^{−s} = n^{−½}e^{−(s−½)log n}` is
  a constant times a singular inner function, so this is a cyclicity question for the *discrete* semigroup
  `{e^{−(s−½)log n}}` acting on `g`. Nyman–Beurling (continuous dilations) and Báez-Duarte (integer dilations of a
  different generating family) are the classical relatives (R157_002 row 43, EQUIV). I have not found this exact
  formulation in the literature and do not claim it. Under RH, `g` has no Blaschke part in `Re s > ½`, and BSY
  (CITED, row 57) show there is no singular inner part either. What remains is whether Dirichlet polynomials suffice
  as multipliers.
* **J4 (falsifier check, PROVED).** Prop J uses no Euler product: its proof holds verbatim for `f_DH(s)` in place of
  `ζ(s)(s−1)/s`, provided `f_DH(1)M(1) ≠ 0`, which holds for generic `M`. For DH the left side is `> 0` (zeros with
  `Re s > 1`), so `inf_M R_{DH}(M) > 1`. The inequality produces no false positivity. By Corollary H1, a proof of
  `inf R = 1` for `ζ` must use A7, A8 or A9.

**Classification.** Prop J is PROVED. It is not a mechanism: its target `inf R = 1` implies RH (J1), its converse
is OPEN (J3), it lies in the EQUIV neighbourhood of rows 43/57, and it is per-window blind (the weight `μ` does not
see `T`). Its only role is to answer the angle's question exactly: **in Levinson's own terms, 100 % is forced by
equality in Jensen, and that equality is an exclusion statement at RH strength, not a proportion.**
