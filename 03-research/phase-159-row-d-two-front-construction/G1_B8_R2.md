## §0 Verdict

1. **Theorem G (the growth law; PROVED).** Let `Θ* := sup{Re ρ : ξ(ρ) = 0} ∈ [½, 1)`. For every `η > 0` the window
  Hankel norms of Suzuki's exponential kernel satisfy
  ```
  limsup_{t→∞} (1/2t) · log⁺ N_t(η) = Θ* − ½ .
  ```
  The rate does not depend on `η`. The upper half needs only `Re ξ′/ξ ≥ 0` on `σ > Θ*`. The lower half is a Schur-test
  and analytic-continuation argument, and it does **not** use `Λ ≥ 0` or any Landau-type positivity lemma.
2. **This refutes my round-1 heuristic (Q1)**, `log N_t ≍ √(ηmt)`. Under ¬RH the obstruction grows **exponentially**, at
  the exact rate `2(β₀ − ½)` set by the rightmost zeros, and not like `e^{√t}`. The √t count had confused the resolution
  of the window with the growth of the kernel.
3. **What the law says about the object.** In canonical-system coordinates, the window at `t` sees `Λ(n)` only for
  `n < e^{2t}` (A6). It reports on the zeros only through `Θ*`, and only at exponential scale. The dictionary `x = e^{2t}`
  turns Theorem G into Landau's `limsup log|ψ(x) − x| / log x = Θ*`. So the canonical-system object is, quantitatively,
  the reduced statement's "`ψ(x) − x ≪ x^{½+ε}`" and nothing more (**EQUIV family**). The "criterion with a gap" hoped
  for in round 1 exists (Cor G.1: `N_t = e^{o(t)} ⟹ N_t ≤ 1 ∀t`), but the gap is the classical one.
4. **Survival time vs Weil window (Cor G.3; PROVED given (A5) of round 1).** Suzuki's survival time
  `τ(η) := sup{t : N_s(η) < 1 ∀ s < t}` satisfies `limsup_{η↓0} τ(η) ≤ T_W := sup{t : λ^W_t ≥ 0}`, which is the
  **complete** form. The reverse inequality is (Q2), still OPEN.
5. **OT-5′ still fails, for a reason that is now proved.** Lemma 4.1 of round 1 (positivity is structural, and survival
  is the content), together with the de Branges inverse theorem, shows that a positive Hamiltonian with Schur function
  `Θ_η` exists ⟺ RH (Prop 5.1, EQUIV). I recommend that the map close the **canonical-system / de Branges angle** with
  Theorem G, Cor G.1–G.4 and Prop 5.1 as its record. **No object is built. Status: partial new result (the growth law),
  dead end for the object.**

## §2 Definitions

Notation as in round 1: `s = ½ − iz`, `ψ(z) = (ξ′/ξ)(½ − iz)`, `Θ_η = exp(−2ηψ)`. `K_η ∈ D′_+` is the unique
distribution supported in `[0,∞)` whose Fourier–Laplace transform `⟨K_η, e^{ixz}⟩` equals `Θ_η(z)` for `Im z` large
(Def 2.1 of R1, via Paley–Wiener–Schwartz, CITED: Vladimirov §9). `K_η` is real, and Prop 2.2 of R1 gives
`K_η = Σ_n b_η(n) n^{−1/2} g_η(· − log n)`.

**Def 2.1 (window Hankel form norm).** For `t ∈ R`,
```
N^H_t(η) := sup { |⟨K_η, f ∗ g⟩| / (‖f‖₂‖g‖₂) : f, g ∈ C_c^∞((−∞, t)), f, g ≠ 0 } ∈ [0, ∞].
```
Here `f ∗ g ∈ C_c^∞((−∞, 2t))`. For `η > 1` this is Suzuki's `‖K_η[t]‖` (R1 Prop 2.4).

**Relation to R1's `N_t`.** Take an admissible symbol `χ` (R1 Def 2.3). Then
`⟨K_η, f∗g⟩ = ⟨F⁻¹χ, f∗g⟩ = (1/2π)∫χ f̂ ĝ`. This gives `N^H_t ≤ N_t` (PROVED, elementary). The equality
`N^H_t = N_t` is Nehari's theorem (CITED: Peller 2003, Ch. 1). Every statement below is proved for `N^H_t`. It transfers
to `N_t` via `N^H_t ≤ N_t` for lower bounds and via Nehari for upper bounds.

**Elementary facts (PROVED).**
* **(E1) Monotonicity.** `t ↦ N^H_t` is nondecreasing, because the test class grows with `t`.
* **(E2) Translation covariance.** Write `τ_a f(x) = f(x − a)`. Then `(τ_a f) ∗ (τ_{−a} g) = f ∗ g`.
* **(E3) Transfer bound.** Let `D ∈ D′_+` have Fourier–Laplace transform `L_D`, which extends to a bounded analytic
  function on `C₊`. Then `|⟨D, F∗G⟩| ≤ ‖L_D‖_{H^∞(C₊)} ‖F‖‖G‖` for all `F, G ∈ C_c^∞(R)`.
  *Proof.* For `P = F∗G`, Parseval on the line `Im z = ε > 0` gives `⟨D, P⟩ = (1/2π)∫_{Im z = ε} L_D(z) P̌(z) dz`, where
  `P̌(z) = ∫P(x)e^{−ixz}dx = F̌(z)Ǧ(z)`. (This is valid because `e^{−εx}D` is tempered, with Fourier transform
  `L_D(· + iε)`.) Cauchy–Schwarz and Plancherel give `|⟨D, P⟩| ≤ ‖L_D‖_∞ ‖e^{εx}F‖‖e^{εx}G‖`. Let `ε ↓ 0`. ∎

## §3 Theorem G (the growth law) — statement and proof

**Theorem G (PROVED).** Let `η > 0` and `Θ* = sup Re ρ`, with `½ ≤ Θ* < 1`.
* **(G1) Upper bound.** For every `δ′ ≥ 0` with `δ′ > Θ* − ½`, and every `t`: `N^H_t(η) ≤ e^{2δ′ t}`.
  By Nehari, `N_t(η) ≤ e^{2δ′t}` as well.
* **(G2) Lower bound.** Suppose that for some `δ ≥ 0` and `A < ∞`, `N^H_t(η) ≤ A e^{2δt}` for all `t ≥ 1`. Then
  `Θ* − ½ ≤ δ`. The same holds with `N_t` in place of `N^H_t`, since `N^H_t ≤ N_t`.
* **(G3) Consequently** `limsup_{t→∞} (2t)^{−1} log⁺ N^H_t(η) = limsup_{t→∞} (2t)^{−1} log⁺ N_t(η) = Θ* − ½`.

### 3.1 Proof of (G1)

1. **The half-plane `Im z > Θ* − ½`.** By Hadamard's product (CITED, Davenport Ch. 12), with conjugate zeros paired,
  `Re ξ′/ξ(s) = Σ_ρ Re (s − ρ)^{−1} = Σ_ρ (σ − β)/|s − ρ|²`. For `σ > Θ*` every term is `> 0`, and `ξ` has no zero
  there. So `ψ` is analytic with `Re ψ ≥ 0` on `{Im z > Θ* − ½}`, and `|Θ_η| ≤ 1` there.
2. **The shifted kernel.** Fix `δ′ ≥ 0` with `δ′ > Θ* − ½`. Put `L̃(z) := Θ_η(z + iδ′)`. It is analytic on `C₊` with
  `|L̃| ≤ 1`. By Paley–Wiener–Schwartz for bounded analytic functions on `C₊` (CITED), `L̃` is the Fourier–Laplace
  transform of some `K̃ ∈ D′_+` with `e^{−εx}K̃` tempered for every `ε > 0`. For `Im z` large,
  `⟨e^{−δ′x}K_η, e^{ixz}⟩ = ⟨K_η, e^{ix(z+iδ′)}⟩ = Θ_η(z + iδ′)`. Injectivity of the Fourier–Laplace transform on
  `D′_+` then gives `K̃ = e^{−δ′x} K_η`.
3. **The estimate.** Let `f, g ∈ C_c^∞((−∞, t))`. Since `e^{δ′(x+y)} = e^{δ′x}e^{δ′y}`,
  `⟨K_η, f∗g⟩ = ⟨K̃, (e^{δ′x}f) ∗ (e^{δ′x}g)⟩`. By (E3) this is bounded by
  `‖L̃‖_∞ ‖e^{δ′x}f‖‖e^{δ′x}g‖ ≤ e^{2δ′t}‖f‖‖g‖`, because `δ′ ≥ 0` and `x < t` on the supports. ∎

### 3.2 Proof of (G2)

Fix `δ′ > δ` (so `δ′ > 0`) and put `α := δ′ − δ > 0`. Let `K̃ := e^{−δ′x}K_η`. The argument has three steps.

**Step 1 (Schur test: the weighted form is bounded on the half-line).** Choose a smooth partition of unity
`(φ_j)_{j≥1}` on `[0,∞)` with `0 ≤ φ_j ≤ 1`, `supp φ_j ⊂ [j−2, j+1)` and `Σ_j φ_j = 1` on `[0,∞)`. Then
`Σ_j φ_j² ≤ 1`.

Let `F, G ∈ C_c^∞((0,∞))`, and put `F_j = φ_jF`, `G_k = φ_kG` (finitely many are nonzero). Write `a_j = ‖F_j‖` and
`b_k = ‖G_k‖`, so that `Σa_j² ≤ ‖F‖²` and `Σb_k² ≤ ‖G‖²`. Then
```
⟨K̃, F∗G⟩ = Σ_{j,k} ⟨K_η, (e^{−δ′x}F_j) ∗ (e^{−δ′x}G_k)⟩ .
```
For each pair, apply (E2) with `a = (k − j)/2`. The functions `τ_a(e^{−δ′x}F_j)` and `τ_{−a}(e^{−δ′x}G_k)` are both
supported in `[(j+k)/2 − 2, (j+k)/2 + 1)`, which lies inside `(−∞, t_{jk})` with `t_{jk} := (j+k)/2 + 1 ≥ 2`. Also
`‖e^{−δ′x}F_j‖ ≤ e^{−δ′(j−2)}a_j`, since `x ≥ j − 2` and `x ≥ 0` on `supp F_j`. By the hypothesis and (E1),
```
|term_{jk}| ≤ A e^{2δ t_{jk}} e^{−δ′(j+k−4)} a_j b_k = A e^{2δ+4δ′} e^{−α(j+k)} a_j b_k .
```
Summing and applying Cauchy–Schwarz,
`|⟨K̃, F∗G⟩| ≤ A e^{2δ+4δ′}(Σ_j e^{−αj}a_j)(Σ_k e^{−αk}b_k) ≤ M ‖F‖‖G‖`, with
`M := A e^{2δ+4δ′}/(e^{2α} − 1)`. The bilinear form `H(F,G) := ⟨K̃, F∗G⟩` therefore extends to a bounded bilinear form
on `L²(0,∞)` with norm `≤ M`.

**Step 2 (the continuation identity).** For `w ∈ C₊` put `e_w(x) := e^{iwx}1_{x>0} ∈ L²(0,∞)`. The map
`w ↦ e_w` is analytic from `C₊` into `L²(0,∞)`, since its derivative `x e^{iwx}1_{x>0}` lies in `L²`. Let
`L̃(z) := Θ_η(z + iδ′)` for `Im z > ½`. On this half-plane `L̃` is analytic and `|L̃| ≤ 1`, because
`Im(z + iδ′) > ½ > Θ* − ½`. It is the Fourier–Laplace transform of `K̃` there (as in 3.1, step 2). **Claim:** for
`Im w, Im w′ > 1`,
```
(★) L̃(w) = L̃(w′) + i(w − w′) · H(e_w, e_{w′}).
```
*Proof.* Take `F_n, G_n ∈ C_c^∞((0,∞))` with `F_n → e_w` and `G_n → e_{w′}` in `L²` and also in `L²(e^{2x}dx)`, which
is possible because `e^{x}e_w ∈ L²` for `Im w > 1`. By Parseval on the line `Im z = 1` (valid since `e^{−x}K̃` is tempered
with transform `L̃(· + i)`, which is bounded):
`H(F_n, G_n) = (1/2π)∫_{Im z=1} L̃(z) F̌_n(z) Ǧ_n(z) dz`.
* On this line, `F̌_n(u + i)` is the Fourier transform of `e^{x}F_n`, which converges in `L²(du)` to the transform of
  `e^{x}e_w`, namely `∫_0^∞ e^{i(w−z)x}dx = i/(w − z)`. The same holds for `G_n`.
* Since `|L̃| ≤ 1`, the integrals converge to `(1/2π)∫_{Im z=1} L̃(z) · (−1)/((w − z)(w′ − z)) dz`, and the left side
  converges to `H(e_w, e_{w′})` by boundedness of `H`.
* Close the contour in `Im z ≥ 1`. The integrand is `O(|z|^{−2})` because `L̃` is bounded, and the positive orientation
  picks up the residues at `z = w` and `z = w′`:
  `Res_{w} = L̃(w)/(w′ − w)` and `Res_{w′} = L̃(w′)/(w − w′)`.
* Hence `H(e_w, e_{w′}) = i(L̃(w) − L̃(w′))/(w′ − w)`, which is (★) (for `w ≠ w′`, and by continuity for `w = w′`). ∎

**Step 3 (contradiction).** Fix `w′` with `Im w′ > 1`. The right side of (★) is analytic in `w` on all of `C₊`,
because `H` is bounded and `w ↦ e_w` is analytic. It is also bounded there by
`|L̃(w′)| + M|w − w′|/(2√(Im w · Im w′))`. So `L̃` extends analytically to `C₊`, and `Θ_η(ζ) = L̃(ζ − iδ′)` extends
analytically from `{Im ζ > ½ + δ′}` to `U′ := {Im ζ > δ′}`.

Let `P` be the pole set of `ψ` (the images of zeros of `ξ`), which is discrete. The set `U′ \ P` is connected and open,
and on it `exp(−2ηψ)` is analytic and agrees with the extension on `{Im ζ > ½ + δ′}`. By the identity theorem they agree
on all of `U′ \ P`.

Suppose a zero `ρ₀ = β₀ + iγ₀` of multiplicity `m` has `β₀ − ½ > δ′`. Then `z₀ = i(ρ₀ − ½) ∈ U′`, and the extension is
analytic at `z₀`, hence bounded near it. But `s − ρ₀ = −i(z − z₀)` gives `ψ(z) = im/(z − z₀) + O(1)`, and along
`z = z₀ − ir` (for small `r > 0`, inside `U′`) we get `−2ηψ = 2ηm/r + O(1) → +∞`, so `|exp(−2ηψ)| → ∞`. This is a
contradiction. Hence `Θ* − ½ ≤ δ′`, and letting `δ′ ↓ δ` gives `Θ* − ½ ≤ δ`. ∎

### 3.3 Proof of (G3)

Let `λ` be the limsup.
* By (G1), `λ ≤ δ′` for every admissible `δ′`, so `λ ≤ Θ* − ½`.
* If `λ < Θ* − ½`, pick `δ` with `λ < δ < Θ* − ½`. Then `δ > 0`, because `λ ≥ 0` by the `log⁺` convention. By the
  definition of the limsup, `N^H_t ≤ A e^{2δt}` for `t ≥ 1` with some `A` (using (E1) and the finiteness of `N^H_t`
  from (G1)). Now (G2) gives `Θ* − ½ ≤ δ`, a contradiction.
* The same argument works for `N_t`. ∎

**Remark 3.1 (what the proof uses).**
* (G1) uses the Hadamard sign `Re ξ′/ξ > 0` on `σ > Θ*`.
* (G2) uses no arithmetic at all: no positivity of `Λ` or `b_η`, and no Euler product. It uses only that `Θ_η` has an
  essential singularity at each zero of `ξ` (exponentiation turns poles of `ψ` into essential singularities; R1 §3.2
  Remark).
* The Schur-test step exploits translation covariance (E2) to move every block pair to its **mean** position. Without
  this rebalancing one loses a factor of 2 in the exponent (`δ′ > 2δ`).

## §4 Corollaries

**Cor G.1 (self-improvement; PROVED).** For every `η > 0` the following are equivalent:
* (a) `log N_t(η) = o(t)`;
* (b) `N_t(η) = O(e^{εt})` for every `ε > 0`;
* (c) `N_t(η) ≤ 1` for all `t`;
* (d) RH.

*Proof.* (c)⇒(a)⇔(b) is trivial. (b)⇒(d) is (G2) with `δ = ε/2` and `ε ↓ 0`. (d)⇒(c) is R1 (A1). ∎

Status: **EQUIV**. It is the canonical-system form of "`ψ(x) − x ≪ x^{½+ε}` ⟹ RH ⟹ `ψ(x) − x ≪ x^{½}log²x`". The
"criterion with a gap" asked for in R1 (Q1) exists, and it is exactly this classical gap. **No weight toward a proof.**

**Cor G.2 (falsifiers; PROVED).** The law applies verbatim to every falsifier that fits R1 Lemma 4.2, with the
falsifier's own `Θ*`:
* **Modified combs** `a` with `D(a) < ∞`: `N_t(η; a)` differs from `N_t(η; Λ)` by a factor in `[e^{−2ηD}, e^{2ηD}]`
  (R1 (A4)). So they have the **same** rate `Θ*_ζ − ½`.
* **`Ξ_a = ξ(s+a)ξ(s−a)`**, `a > 0`: it is entire of order 1, satisfies the functional equation, and has zeros `ρ ± a`,
  so its `Θ* = Θ*_ζ + a`. The proof of (G1)–(G2) goes through unchanged: Hadamard's `Re Ξ_a′/Ξ_a = Σ Re(s − ρ′)^{−1}`,
  and essential singularities at each zero. So its window norms grow at rate **exactly** `2(Θ*_ζ − ½ + a) ≥ 2a`.
* **`Ξ_Q` (Epstein)** and entire-order-1 Beurling `ζ_B` with a functional equation: the same, with their own `Θ*`.

For `Ξ_a` the rate is `≥ 2a`, which is an unconditional, explicit exponential blow-up of the canonical-system object.
Compare the Weil side, where the `Ξ_a` gate fails only by a sign.

**Cor G.3 (survival time and the complete Weil window; PROVED given R1 (A5)).** Let
`τ(η) := sup{t : N^H_s(η) < 1 for all s < t} ∈ [0, ∞]`. For `η > 1` this is Suzuki's (K5) survival time (R1 Prop 2.4).
Let `T_W := sup{t : λ^W_t ≥ 0}` (complete form). Since `λ^W_t` is nonincreasing in `t`, it is negative for every
`t > T_W`. Then
```
limsup_{η↓0} τ(η) ≤ T_W .
```
*Proof.* Let `t > T_W`, so `λ^W_t < 0`. There is a unit `f ∈ C_c^∞(I_t)` with `W_t(f) < 0`. The parity sectors are
`W`-orthogonal (R1 §3.5), so one parity component of `f`, normalised, has `W_t < 0`. Call it `f_ε`, with parity
`ε ∈ {±1}`. R1 (A5) (checked by P2, P3, P5) gives `ε q_η(f_ε) = 1 − η W_t(f_ε) + o(η)`, where
`q_η(f) = ⟨K_η, f ∗ f̄⟩` and `f, f̄ ∈ C_c^∞((−t,t))`. So `N^H_t(η) ≥ |q_η(f_ε)| > 1` for `0 < η < η₀(t)`, which gives
`τ(η) ≤ t`. ∎

Reading: on the Weil side, the first negative window of the complete form is an **upper** bound for the infinitesimal
survival of Suzuki's chain. Equality would need (Q2), the reverse linearisation, which is OPEN. Under ¬RH both sides are
finite. Unconditionally `T_W ≥ 0.8` (Zhu, CITED in the record), and **nothing** here bounds `τ(η)` from below.

**Cor G.4 (the object sees `Θ*` only; PROVED as a statement about Theorem G).**
* The only zero-side invariant the growth law of the window family `(N_t(η))_t` sees is `Θ*`. In particular, no finite
  or random subset of zeros changes the rate unless it contains points of real part arbitrarily close to `Θ*`. This is
  consistent with `thm:finZ` and gives the "100 random zeros" probe a precise answer in this coordinate system:
  the window family is blind to every zero with `β < Θ*`, at exponential scale.
* It is **not** blind at finite `t`: the individual `N_t` depend on all of `Γ` and `(Λ(n))_{n<e^{2t}}`.

## §5 The object test, the record's obstructions, and why the angle closes

**Prop 5.1 (existence of the positive object ⟺ RH; EQUIV, PROVED from CITED de Branges theory).** Fix `η > 0`. There
is a locally integrable Hamiltonian `H : [0,∞) → M₂(R)`, `H ≥ 0`, whose chain of de Branges spaces has
Schur/scattering function `Θ_η`, if and only if RH holds.

*Proof.* (⇐) Under RH, `Θ_η` is a Schur function by R1 (A1). Suzuki (Tohoku Thm 1.3, CITED in R1) builds the chain
with `H = diag(1/γ, γ)`. (⇒) The Weyl function of any positive canonical system is Herglotz, so its Cayley transform is a
Schur function (de Branges theory, as used in Suzuki Tohoku §1, CITED in R1). Hence `|Θ_η| ≤ 1` on `C₊`, and R1 (A2)
gives RH. ∎

This is round-1 Lemma 4.1 and phase-114 D.121 in final form. The positivity of `H` is free, and the existence of `H` on
`[0,∞)` with the right Schur function is RH. Theorem G adds the quantitative closure: when the object fails, the
window-by-window size of the failure is `e^{2(Θ*−½)t(1+o(1))}` (limsup), which is the classical Landau exponent and
nothing finer.

## §6 Open items and the weakest step

* **(Q2, OPEN)** `N_t(η) ≤ 1 − ηλ^W_t + o(η)`. Together with Cor G.3 this would give `lim_{η↓0} τ(η) = T_W`: the
  infinitesimal survival of the canonical system would be exactly the first negative complete Weil window. The
  obstruction is that `Θ_η − 1 + 2ηψ` is not uniformly small as a **symbol** (`ψ` has log growth, and it is unbounded on
  `C₊` under ¬RH). A proof has to work with window-modified symbols. Even if proved, it gives no sign: it moves `T_W` into
  de Branges coordinates.
* **(Q3, OPEN)** An effective finite-`t` version of (G2): given `N_s ≤ Ae^{2δs}` for `s ≤ t` only, exclude zeros with
  `β − ½ > δ + o(1)` up to a height `h(t)`. This would be the canonical-system analogue of an explicit zero-detection
  theorem (in the spirit of `prop:finite`). It is decidable in principle, but it adds nothing to the "for all T" arrow.
* **Recommendation to the map.** Close the canonical-system / de Branges / Suzuki angle for G1. Its record is Prop 5.1
  (EQUIV), Theorem G (PROVED, Landau-type), and Cor G.1–G.4. It must not be resubmitted without a positivity mechanism
  for `N_t = e^{o(t)}` that fails for `Ξ_a`, which by Cor G.2 has rate `≥ 2a`.
