**Status: partial new result (PROVED). Dead end for the mechanism (EQUIVALENT landing).**

1. **Theorem Q (graded converse, primitive form). PROVED.** Let `ε ≥ 0`. If `λ^A_T ≥ −C e^{2εT}` for all `T ≥ T_0`,
  then `ζ(s) ≠ 0` for `Re s > ½ + ε`. Complete form: the same holds with `λ^W_T`, since `λ^W_T ≤ λ^A_T`.
  The exponent is sharp in the sense that a zero at `½ + β + iγ` is detected by a fixed two-bump test family

2. **Corollary Q1 (rate sandwich). PROVED.** With `κ^A := limsup_{T→∞} (2T)^{−1} log⁺(−λ^A_T)`, `κ^W` similarly, and
  `Θ := sup Re ρ`:
  ```
  Θ − ½ ≤ κ^A ≤ κ^W ≤ ½ .
  ```
  Hence **RH ⟺ κ^A = 0 ⟺ κ^W = 0** (EQUIVALENT), i.e. RH ⟺ `−λ^A_T ≤ e^{o(T)}`. Also any unconditional bound
  `κ^A ≤ ½ − c` with `c > 0` implies the quasi-RH `Θ ≤ 1 − c`, which is OPEN. So the state of the art corresponds to the
  trivial bound `κ^A ≤ ½`, and every intermediate exponent is a zero-free strip.
3. **Proposition I (invariance). PROVED.** For every real comb perturbation `b` and every `T`,
  `|λ^A_T(Λ+b) − λ^A_T(Λ)| ≤ 2 S_b(e^{2T})`, where `S_b(X) := Σ_{2≤n<X} |b(n)| n^{−½}`, and the same holds for `λ^W`.
  Consequently `κ^A(Λ+b) = κ^A(Λ)` whenever `S_b(X) = X^{o(1)}`. This covers all the finite modifications of
  `thm:finmod`, the one-term perturbations of `rem:resweights`, and every `b` with `b(n) ≪ n^{−½+o(1)}`.
4. **Consequence for the G2 filters. PROVED as a statement about the targets.** The obstructions O3 (`rem:resweights`),
  `thm:margin`, `cor:void` and `thm:finmod` apply to the *sign* target `∀T λ^A_T ≥ 0`. They do not apply to the
  EQUIVALENT target `κ^A = 0`, which tolerates sub-exponential negativity and is blind to every `b` with
  `S_b = X^{o(1)}`. So the premise in the G2 brief that the argument "must be an exact identity, not an estimate"
  belongs to the sign target, not to RH: a proof of `κ^A = 0` by estimates with arbitrary `e^{o(T)}` slack would give

  translation of the one-sided Landau problem `ψ(x) − x ≥ −O(x^{½+δ})` for all `δ > 0`. That problem is RH (EQUIVALENT,
  classical: Landau 1905, Ingham Ch. V). The mechanism is therefore not constructed.
5. **Theorem K′ (squares with sub-exponential defect). PROVED; EQUIVALENT.** R3's Theorem K is made robust: a family of

  remainder needs a remainder of size `e^{o(T)}` in operator norm on the window. The trivial bound, which is what
  Type I/II estimates currently deliver in this normalisation, is `e^{T(1+o(1))}`.

## §2 The two-bump identity

**Lemma 2 (two-bump identity). PROVED.** Let `f ∈ C_c^∞(−½, ½)` be real, `T ≥ ½`, and put
`F_T(t) := f(t − T) + f(t + T)`. Then `supp F_T ⊂ I_{T+1}`, `‖F_T‖² = 2‖f‖²`, and
```
W(F_T) = 2W(f) + 2 g_f(2T), g_f(x) := (u ∗ c_f)(x) = ⟨u, c_f(· − x)⟩ . (2.1)
```
Moreover `A(F_T) = 2cosh(T/2)Φ_f(1)` and `B(F_T) = 2cosh(T/2)Φ_f(0)`. So `F_T ∈ P_{T+1}` iff `Φ_f(0) = Φ_f(1) = 0`, and
in that case `𝔞(F_T) = W(F_T)`.

*Proof.* The supports of `f(·∓T)` are disjoint for `T ≥ ½`, which gives the norm. Expanding the autocorrelation,
`c_{F_T}(y) = 2c_f(y) + c_f(y − 2T) + c_f(y + 2T)`, because `∫f(t+y−T)f(t+T)dt = c_f(y − 2T)` and symmetrically. Pairing
with `u` and using that `u` and `c_f` are even, `⟨u, c_f(·+2T)⟩ = g_f(−2T) = g_f(2T)`. This gives (2.1). The moments:
`∫f(t−T)e^{t/2}dt = e^{T/2}Φ_f(1)`, `∫f(t+T)e^{t/2}dt = e^{−T/2}Φ_f(1)`, and similarly for `B` with `Φ_f(0)`. ∎

**Lemma 3 (primitive bumps that see a given zero). PROVED.** For every `ρ_0 ∉ {0, 1}` there is a real
`f ∈ C_c^∞(−½, ½)` with `Φ_f(0) = Φ_f(1) = 0` and `Φ_f(ρ_0)Φ_f(1 − ρ_0) ≠ 0`.

*Proof.* Integration by parts gives `Φ_{h''}(z) = (z − ½)²Φ_h(z)`. So `f := h'' − h/4` has `Φ_f(z) = z(z−1)Φ_h(z)`, which
vanishes at `0` and `1`. The real-linear maps `h ↦ Φ_h(ρ_0)` and `h ↦ Φ_h(1−ρ_0)`, from real `C_c^∞(−½,½)` to `ℂ`, are
nonzero (`Φ_h(z) = ∫h(t)e^{(z−½)t}dt`, and bumps concentrated near a point `t_0` make it nonzero). So their kernels are
proper subspaces, and a real vector space is not the union of two proper subspaces. Pick `h` outside both kernels. ∎

**Lemma 4 (the Laplace transform of `g_f`). PROVED.** Let `f` be as in Lemma 2 and `X_0 ≥ 2`. Then `|g_f(x)| ≤ C_f e^{x/2}`
for `x ≥ 2`, and for `Re s > ½`
```
G(s) := ∫_{X_0}^∞ g_f(x)e^{−sx}dx = Φ_f(½+s)Φ_f(½−s)·[ ζ′/ζ(s+½) + 1/(s−½) + H(s) ] + E(s),
```
where `H` is holomorphic on `Re s > −½` and `E` is entire. Hence `G` continues meromorphically to `Re s > −½`. Its only
possible poles there are the points `s = ρ − ½` (`ρ` a nontrivial zero), and none of them is real.

*Proof.* Fix a smooth `θ` with `θ = 0` on `(−∞, ½]` and `θ = 1` on `[1, ∞)`, and put `u_2 := θu`. Since `supp c_f ⊂ (−1,1)`,
for `x ≥ 2` the value `g_f(x)` only involves `u` on `(x−1, x+1) ⊂ (1,∞)`, where `u = u_2`. So `g_f = u_2 ∗ c_f` on `[2,∞)`.
On `[½,∞)`, `u_2` is a smooth function `O(e^{y/2})` (Lemma 1) minus the positive measure `Σ_n θ(log n)Λ(n)n^{−½}δ_{log n}`,
with `∫e^{−σy}d|u_2| < ∞` for `σ > ½` (Chebyshev, `ψ(x) ≪ x`). This gives the growth bound, and by Fubini
`∫_ℝ (u_2∗c_f)(x)e^{−sx}dx = ℒu_2(s)·ℒc_f(s)` for `Re s > ½`. Now `ℒc_f(s) = ∫f(r)e^{−sr}dr·∫f(t)e^{st}dt =
Φ_f(½−s)Φ_f(½+s)`, which is entire. The piece `∫_{−∞}^{X_0}(u_2∗c_f)e^{−sx}` is an integral over the compact set
`[−½, X_0]`, hence entire. Finally
`ℒu_2(s) = ℒ(θk_∞)(s) + ℒ(θ·2cosh(y/2))(s) − Σ_n θ(log n)Λ(n)n^{−½−s}`. Here the first term is holomorphic on `Re s > −½`
(Lemma 1). The second is `1/(s−½) + 1/(s+½) + ` an entire correction supported on `[0,1]`. The third is
`ζ′/ζ(s+½) + ` a finite Dirichlet polynomial, because `θ(log n) = 1` for `n ≥ 3`. The pole of `ζ′/ζ(s+½)` at `s = ½`
has residue `−1` and cancels against `1/(s−½)`. The trivial zeros sit at `s = −2k − ½`. `ζ` has no zeros on `(0,1)`
(`ζ(σ) = η(σ)/(1 − 2^{1−σ})` with `η(σ) > 0`, CITED classical), so no `ρ − ½` is real. ∎

## §3 Theorem Q and its corollaries

**Theorem Q (graded converse). PROVED.** *(Primitive form.)* Let `ε ≥ 0`, `C < ∞`, `T_0 ≥ ½`, and suppose
`λ^A_T ≥ −C e^{2εT}` for all `T ≥ T_0`. Then `ζ(s) ≠ 0` for `Re s > ½ + ε`.
*(Complete form.)* The same conclusion holds under `λ^W_T ≥ −Ce^{2εT}`, since that hypothesis implies the primitive one.

*Proof.* If `ε ≥ ½` there is nothing to prove (`Re ρ < 1`). Let `0 ≤ ε < ½` and suppose `ρ_0` is a zero with
`Re ρ_0 > ½ + ε`. Take `f` from Lemma 3 for `ρ_0`. By Lemma 2, for `T ≥ T_0`,
`2W(f) + 2g_f(2T) = 𝔞(F_T) ≥ λ^A_{T+1}·2‖f‖² ≥ −2C‖f‖²e^{2ε}e^{2εT}`. With `x = 2T` this gives
`g_f(x) ≥ −K e^{εx}` for `x ≥ X_0 := max(2, 2T_0)`, where `K := |W(f)| + C‖f‖²e^{2ε}`. So `φ(x) := g_f(x) + Ke^{εx} ≥ 0`
on `[X_0, ∞)`. For `Re s > ½`,
```
∫_{X_0}^∞ φ(x)e^{−sx}dx = G(s) + K e^{(ε−s)X_0}/(s − ε).
```
By Lemma 4, the right-hand side continues holomorphically to a neighbourhood of every real point `s > ε`: `G` has no
real poles on `(−½, ∞)`, and the second term is singular only at `s = ε`. By **Landau's theorem** (CITED: Widder,
*The Laplace Transform*, Ch. II Thm 5b), the Laplace integral of a nonnegative function has a singularity at its real
abscissa of convergence `σ_c`. Hence `σ_c ≤ ε`, and the integral defines a holomorphic function on `Re s > ε` that agrees
with the right-hand side on `Re s > ½`. By the identity theorem `G` has no poles in `Re s > ε`, so
`Φ_f(½+s)Φ_f(½−s)[ζ′/ζ(s+½) + 1/(s−½)] = G − E − Φ_fΦ_f H` is holomorphic there. At `s_0 = ρ_0 − ½`
(`Re s_0 ∈ (ε, ½)`), `ζ′/ζ(s+½)` has a simple pole with residue equal to the multiplicity of `ρ_0`, while `1/(s−½)` is
regular and `Φ_f(ρ_0)Φ_f(1−ρ_0) ≠ 0`. This is a contradiction. ∎

**Remark Q2 (what the proof uses). PROVED.** The proof uses only the two-bump family, the moment conditions of
Lemma 3, meromorphy of `ζ′/ζ`, the absence of real zeros in `(0,1)`, and Landau. It uses neither `Λ ≥ 0` nor the
functional equation nor Bochner–Schwartz. It applies verbatim to any explicit-formula distribution
`u^{(Z)} = k + 2cosh − (comb)` whose right Laplace transform is meromorphic on `Re s > −½` with non-real poles at
`ρ − ½`. In particular it applies to `Ξ_a = ξ(s+a)ξ(s−a)` (zeros `½ ± a + iγ`), which gives `κ^A(Ξ_a) ≥ a > 0`.

**Remark Q3 (sharpness of the exponent). PROVED.** Under the hypothesis of Q with some `ε < Θ − ½`, the contrapositive
gives `limsup_T (−λ^A_T)e^{−2εT} = ∞`. The detecting family is fixed (one `f`, all `T`), and the negativity is carried by
`g_f(2T) = Σ_ρ Φ_f(ρ)Φ_f(1−ρ)e^{(ρ−½)2T}`, which grows like `e^{2βT}` for a zero at `½ + β`. So the correspondence
"exponent `2ε` in `T` ↔ zero-free half-plane `Re s > ½ + ε`" cannot be improved along this family.
(P5's predicted `e^{4εT}` was pessimistic by a factor 2 in the exponent.) Under RH, (2.1) reads
`W(F_T) = 2Σ_ρ|f̂(γ_ρ)|²(1 + cos 2Tγ_ρ) ≥ 0`, which is consistent with Weil.

**Corollary Q1 (rate sandwich). PROVED.** `Θ − ½ ≤ κ^A ≤ κ^W ≤ ½`.

*Proof.* The first inequality: for every `ε > κ^A` the hypothesis of Q holds, so `Θ ≤ ½ + ε`. The second: `λ^W_T ≤ λ^A_T`.
The third is an unconditional lower bound on `W_T` for `F ∈ L²(I_T)`, `‖F‖ = 1`. The archimedean part is at least
`m(0) > −5.4` (Lemma 1, Plancherel `(2π)^{−1}∫|F̂|² = ‖F‖²`). The comb part: since `|c_F| ≤ ‖F‖² = 1`, it is at least
`−Σ_{n<e^{2T}} 2Λ(n)n^{−½} ≥ −4.2e^{T}` (partial summation and `ψ(x) ≤ 1.04x`, Rosser–Schoenfeld, CITED). The polar part:
`|A|² ≤ ∫_{−T}^T e^t = 2sinh T`, likewise `|B|²`, so `2|A||B| ≤ 2e^{T}`. Hence `λ^W_T ≥ −5.4 − 6.2e^{T}`. ∎

**Corollary Q1′. EQUIVALENT.** RH ⟺ `κ^A = 0` ⟺ `κ^W = 0` ⟺ (for all `δ > 0`: `λ^A_T ≥ −e^{δT}` for large `T`).
*Proof.* (⟸) by Q1. (⟹) Weil: under RH, `W_T ≥ 0`, so `λ^A_T ≥ λ^W_T ≥ 0`. ∎
This strengthens `RH ⟺ ∀T λ^A_T ≥ 0` (P47 §1.1) and B9_R3 N(i) (bounded below ⟹ RH, the case `b = 0`) to
"sub-exponential negativity ⟹ RH".

**Corollary Q1″ (the graded target). PROVED as an implication; its hypothesis is OPEN.** An unconditional bound
`λ^A_T ≥ −Ce^{(1−2c)T}` with `c > 0` implies `ζ(s) ≠ 0` for `Re s > 1 − c`, a quasi-RH. That is beyond every known
zero-free region. So on the exponential scale the record, and the literature, sit at the trivial `κ^A ≤ ½`.

**Question Q2 (upper half of the growth law). OPEN.** Is `κ^W = Θ − ½`? G1_B8_R2 Thm G(G1) proves the analogue for
Suzuki window norms. For the Weil bottoms one needs to control `Σ_ρ Φ_F(ρ)Φ_F(1−ρ)` over the off-line zeros uniformly on
the unit ball of the form domain of `L²(I_T)`. The termwise bound `|Φ_F(ρ)| ≤ e^{βT}(2β)^{−½}` does not sum over
infinitely many off-line zeros. Not attempted further.

## §4 Proposition I and the split of the record's obstructions

**Proposition I (comb invariance of the rate). PROVED.** For a real arithmetic function `b` and `a = Λ + b` (the comb in
`eq:symbol` replaced by `2a(n)/√n`), and every `T`: `|λ^A_T(a) − λ^A_T(Λ)| ≤ 2S_b(e^{2T})` and
`|λ^W_T(a) − λ^W_T(Λ)| ≤ 2S_b(e^{2T})`. Hence `κ(a) ≤ max(κ(Λ), σ_b)` and `κ(Λ) ≤ max(κ(a), σ_b)`, with
`σ_b := limsup_X log⁺ S_b(X)/log X`. In particular `κ(a) = κ(Λ)` whenever `σ_b = 0`.
*Proof.* The two forms differ by `−Σ_{n∈𝒩_T} 2b(n)n^{−½}Re c_F(log n)`, and `|c_F| ≤ ‖F‖²`. The bottoms of two forms on
the same space differ by at most the norm of the difference. ∎

**Reading (PROVED statements about targets, not about ζ).**

| obstruction of record | target `∀T λ^A_T ≥ 0` (sign) | target `κ^A = 0` (EQUIVALENT to RH by Q1′) |
|---|---|---|
| `rem:resweights` / O3 (one `Λ(n_0)` moved by `≈ e^{−14.4T}` flips the sign) | binding | void: `σ_b = 0`, so by Prop I the rate is unchanged |
| `thm:margin` (margin `≤ 4·10⁹ T e^{−15.449T}`) | binding | void: slack `e^{δT}` for every `δ > 0` is allowed |
| `thm:finmod` (i),(ii), `cor:void` (deletion/amplification) | binding | void: finite `b`, `σ_b = 0`. By `thm:finmod`(iii) these combs have the zeros of ζ, so under RH they also satisfy `κ = 0`, and the target does not falsely hold for them |
| `cor:void` for `𝒞_PNT(ε)` | binding | still binding in substance: a `ψ`-error `O(x^{1−c})` gives no exponent below `½` by any known route (Q1″) |
| F4 falsifiers `Ξ_a`, Epstein `Ξ_Q`, DMV/Zhang with off-line zeros | binding | binding: by Remark Q2 their rate is `≥ Θ_* − ½ > 0`, so an argument must separate ζ from them (T1/T2 of P46 apply) |
| `thm:finZ`, `thm:arena` (no finite zero set / truncation carries a certificate) | binding | not applicable as stated (they concern certificates of the sign). The rate `κ` is an asymptotic quantity and no finite object decides it |

So the demand "exact identity, not an estimate" is an artefact of the sign target, and the demand "must fail for modified
combs" should be amended to "must fail for combs whose Dirichlet series has a pole of `−D_a` in `Re s > ½`". The price
is that the target is then literally Landau's. By Lemma 2 and the proof of Q, what an argument must deliver is the
one-sided bound `g_f(x) ≥ −e^{o(x)}` for the smoothed prime error, for all primitive bumps `f`. Up to the smoothing, this is

## §8 Weakest step

The load-bearing analytic step is the Laplace bookkeeping in Lemma 4, specifically:
- the claim that `g_f = u_2 ∗ c_f` on `[2,∞)`, which is a support argument;
- the Fubini exchange for `Re s > ½`, justified by Chebyshev;

`O(e^{−cy})` with `c > 0` suffices. The second point is interpretive: whether the §4 split really licenses estimate-based
routes depends on accepting Q1′ as the operative target. As a mathematical statement Q1′ is PROVED. As a route it is
