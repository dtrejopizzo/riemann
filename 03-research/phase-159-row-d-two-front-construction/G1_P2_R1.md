## §1 G1_B2_R1 — Deninger route, the adelic Riemann-surface solenoid `Y_K = A_K/K`

**What was checked.**
* **Prop 1 (a)–(d).** Correct. The 1-form Dirichlet pairing in leaf dimension 2 depends only on `(c, ν)`, and
  `U(g) = δ(g)^{−1/2}m_g^*` is unitary on `Harm¹`. (d) is Stone's theorem. This is **Lemma T(⇒)** (Serre's argument)
  with the conformal factor carried by the transverse modulus. It adds no RH content. The memo says as much (Prop B
  "carries no new content beyond Lemma T(⇒)").
* **Theorem C (the cohomology of `Y_K`).** Correct by Pontryagin duality. `m_κ^*χ_v = χ_{κv}`. For `v ≠ 0`, the
  harmonic equations force `a_v = b_v = 0`.
* **Theorem D (i)–(iii).** Correct. For (iii): `u(g_n)w → w` strongly and `u(g_n)w_M → 0` weakly, so `w_M = 0`.
* **Cor D1.** Correct for `d = 2`. On the `v ≠ 0` sector the matrix coefficients vanish eventually along distinct
  `κ_n` with `log N(κ_n) → 0`. On the `v = 0`, `j = 1` sector, `−1 ∈ ker ℓ` acts by `−1`. In fact `ker ℓ` also contains
  every norm-one element `α/ᾱ`, which only strengthens `H^{ker ℓ} = 0`.
* **Minor error (non-fatal).** For `d = 1` (`K = Q`), `u_1(κ) = |κ|^{−1}m_κ^*` acts on `dx` by `sgn κ`, so `κ = −1`
  acts by `−1` on the constant 1-form. That gives `V_c = 0` in degree 1 as well, unless leafwise top forms are replaced
  by densities. The claim "`V_c = C` in degrees 0 and 1 with `Θ = 0, 1`" for `Y_Q` then holds only after that
  orientation convention. The conclusion "no zero" is unaffected, since at worst the pole is lost too.

**Obstructions of record.**
* **OT-1 / OT-2: fail.** This is Cor D1 itself (`PROVED` in the memo). The suspended Lefschetz number is `Φ_h(0) + Φ_h(1)`,
  the polar part only.
* **OT-4 / C16: fail.** The object is the same for `Λ + εδ_{n₀}`, `Λ·1_{n≥N}`, `ζ·E`, Beurling data and `Ξ_Q`, because
  it never reads `Λ`. `thm:finmod` / `cor:void` require a break under modified combs, and there is nothing to break.
  This is the C16 zero-blindness of local/polar data.
* **OT-12: fail.** No flow fixed point, hence no `Γ_R` term.
* **OT-5′.** The "PASS, vacuously" is correct but has no content: a positive form on a space without zeros.
* **Lemma T.** Prop 1(d) is Lemma T(⇒).
* `thm:finZ`, `thm:SC`, `cor:Qp`, `thm:margin`, `thm:arena`, `lem:Rrig`, `cor:convfail`, Thm 19.25 / Cor 19.25b, T1,
  T2, T5, T6: not engaged, because no window positivity and no `h⁰` route is used. I found no conflict.

**N-d.** It is proved necessary only for suspensions (Thm D(ii)). It is shown to fail only for Koopman representations
on compact abelian solenoids (Thm D(iii)). As a general necessary condition it is `HEURISTIC`, as the memo labels it.

**Prop 2 (the correction to Doc 130 / R158_004 row 107).** The `μ̃`-invariance argument is internally consistent:
`dx dy` scales by `|ξ|^{−2ν}` and `μ_ξ` by `|ξ|^{2ν}`. I did not re-open math/0204194, so the correction stays at the
memo's `CITED` level. Prop 2(iii) derives `|ξ|² = q` from `deg = |ξ|²`, i.e. from the positivity of the norm form
under the complex embedding. That is Rosati positivity in its simplest form, which should be said. "The example is
Weil-shaped" is a fair reading (`HEURISTIC`).

**Verdict: EXCLUDED** (fails OT-1, OT-2, OT-4, OT-12 by proved statements).
**Salvage:** Theorem D, as a filter lemma: *any suspension along a dense length group keeps only the R-continuous part
of the Frobenius representation.* A round-2 proposal of a solenoid should prove it escapes Theorem D(iii). The
modular/Shimura test the memo proposes is legitimate, but by lens 2 its expected output (Satake/Ramanujan control
from the Petersson norm) is local Frobenius data, which C16 already makes zero-blind.

## §4 G1_B7_R1 — the numerical motive `𝔐_Z`, the exclusion of Ancona's reciprocity

**What was checked.**
* **(P2).** Correct in sign. The archimedean term `(1/2π)∫[Re ψ(¼+iτ/2) − log π]ĥ` of the explicit formula matches
  `τ₁`, and on `F★F^†` it gives `W_T` (complete).
* **Lemma M1.** This is Weil's criterion (E1) and Bombieri/P45 Thm 10.4 (E2). Classical.
* **Prop M3.** Correct. `sign d = (−1)^{s₋}` and `ε_∞ = (−1)^{s₋(s₋−1)/2}` together determine `s₋ mod 4`. The example
  `⟨1,1,1,1⟩` against `⟨−1,−1,−1,−1⟩` shows the bound is sharp.
* **Lemma M5.** Correct. `log p/log q` is irrational, hence transcendental by Gelfond–Schneider, so
  `c(p)/c(q) = β√(q/p)` is transcendental.
* **Lemma M4.** Correct given Conrey. Jensen gives `O(R)` zeros of an exponential-type `g`, while the number of
  distinct ζ-zeros up to height `R` is `≫ R log R`. Note that the argument really needs a positive proportion of
  *distinct* zeros. The multiplicity bound `m ≪ log γ` alone gives only `≫ R`, which is not enough. So the Conrey (or
  Levinson–Selberg-type) input is load-bearing, and it is `CITED`, not re-read.

**Obstructions of record.**
* **Restatement.** M1 is Weil / CCM Cor 6.3 (R158_002 §4.3). **RESTATEMENT.**
* **OT-1: fails.** `H¹` is a Hilbert space iff RH.
* **OT-4: fails** (C8–C10). The definition runs verbatim for every modified comb, `Ξ_Q` and Beurling data. This is
  exactly the configuration `cor:void` forbids as a derivation basis.
* **OT-5′: fails.**
* **The S4 exclusion.** It is correctly scoped: it covers only cycle lattices whose Lefschetz numbers are `c(n)` up to one
  real scale. The period-matrix loophole is OPEN, and the memo says so. The rationality it rules out coincides with
  the place-by-place situation, which is `cor:Qp` / C17. `cor:Qp` says local forms are indefinite on `P_T`, but it does
  **not** forbid a positive sum (R158_003 A9). So M5 excludes *derivations* from local rational structure, not the
  sign. That is the right reading, and the memo uses it.
* `thm:finZ`: consistent. M4′ concerns tests, and `thm:finZ` concerns certificates (distinct statements, as the memo
  says).

**Verdict: RESTATEMENT.**
**Salvage:** M3, M4 and M5 as a recorded exclusion of the reciprocity mechanism (S4) for the Frobenius correspondence
algebra. M4 (no compactly supported test sees only finitely many zeros) is a useful general lemma. It rules out any
"finite isotypic decomposition" proposal in `C_c^∞`.
