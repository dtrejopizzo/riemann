## §1 Setting

Fix the archimedean symbol `m`, the polar term `2Re(A B̄)` and the Tate moments `A, B` of ζ (P47 `eq:symbol`, `eq:form`,
`eq:W`). A **comb** is a real sequence `a = (a(n))_{n≥2}` with `|a(n)| ≤ C n^{C}`. Its forms are
```
𝔞^{(a)}_T(F) = (2π)^{-1}∫m|F̂|² − Σ_{n∈N_T} (2a(n)/√n) c_F(log n), W^{(a)}_T = 𝔞^{(a)}_T + 2Re(A(F)conj B(F)),
```
for real `F` in the form domain of `L²(I_T)`. Here `F̂(τ) = ∫F e^{iτt}` and `c_F(u) = ∫F(t)F(t−u)dt`. The bottoms
`λ^A_T(a)` (on `P_T`) and `λ^W_T(a)` (on `L²(I_T)`) are taken over real unit `F`. This is no loss, because the forms are
real symmetric. The monotonicity `lem:monoT` holds for every real comb: its proof (zero extension) never uses the sign
of a weight. **PROVED.** Put
```
𝒮^A = {a : λ^A_T(a) ≥ 0 ∀T}, 𝒮^W = {a : λ^W_T(a) ≥ 0 ∀T}, ℓ¹_w = {b : Σ_n |b_n| n^{−1/2} < ∞}.
```
Both sets are convex. For `𝒮^A` this is R1 Cor 6(i) without the sign restriction. The proof is the same: `V_T` is
concave by `lem:degen`, and the same argument works for `W`.

For a perturbation `b`, let `β_b = Σ_n b_n n^{−1/2}(δ_{log n} + δ_{−log n})` and `D_b := β̂_b`. For `b ∈ ℓ¹_w`,
`D_b(τ) = 2Σ b_n n^{−1/2}cos(τ log n)` converges absolutely, and `D_b` is a Bohr almost-periodic function.

**Lemma 1.1 (perturbation identity; PROVED; both forms).** For `b ∈ ℓ¹_w` and real `F` in the form domain of `L²(I_T)`:
```
𝔞^{(Λ+b)}_T(F) = 𝔞_T(F) − (2π)^{-1}∫|F̂|² D_b dτ, W^{(Λ+b)}_T(F) = W_T(F) − (2π)^{-1}∫|F̂|² D_b dτ.
```
*Proof.* Since `c_F = 0` on `|u| ≥ 2T`, the sum over `N_T` is the sum over all `n ≥ 2`. For real `F`,
`c_F(u) = (2π)^{-1}∫|F̂(τ)|²cos(τu)dτ`. Also `|F̂|² ∈ L¹` and `Σ|b_n|n^{−1/2} < ∞`, so Fubini applies. ∎

The formula shows that the perturbation `b` is invisible to the Tate moments and to the polar term. It changes only the
symbol, by `−D_b`.

## §2 Lemma B and Theorem R

**Lemma B (spectral admissibility; PROVED, unconditional; complete form, and primitive form in (ii)).**
(i) Let `a ∈ 𝒮^W`. There is a unique positive tempered measure `μ_a` with `W^{(a)}(F) = ∫|F̂|² dμ_a` for all real
`F ∈ C_c^∞(ℝ)`.
(ii) Let `a ∈ 𝒮^A`. There is a unique positive tempered measure `μ^P_a` with `𝔞^{(a)}(F) = ∫|F̂|²dμ^P_a` for all
`F = (−∂²+¼)G` with `G ∈ C_c^∞`.
(iii) For `a ∈ 𝒮^W` and a perturbation `b` with `β_b` tempered and `D_b` a locally finite measure:
`a + b ∈ 𝒮^W ⟺ μ_a − (2π)^{-1}D_b ≥ 0` as measures. The same holds for `𝒮^A`, with `μ^P_a` in place of `μ_a`.

*Proof.* (i) Every `F ∈ C_c^∞` lies in some `L²(I_T)`, so `F ↦ W^{(a)}(F)` is a nonnegative Hermitian form on `C_c^∞`,
and it is translation-covariant. The form is `⟨u_a, F ⋆ F̃⟩`, where `u_a` is the Weil distribution of the comb `a`: the
archimedean kernel plus the polar kernel `2cosh(u/2)` minus `Σ(a(n)/√n)(δ_{log n}+δ_{−log n})`. So `u_a` is a positive
definite distribution. By the Bochner–Schwartz theorem (CITED: L. Schwartz, *Théorie des distributions*, Ch. VII §9;
Gel'fand–Vilenkin, vol. 4, Ch. II §3), `u_a` is tempered and `û_a = 2π μ_a` for a positive tempered measure `μ_a`.
Uniqueness is Fourier uniqueness in `𝒮′`.

(ii) Put `F = (−∂²+¼)G`. Two integrations by parts give `A(F) = B(F) = 0`, so `F ∈ P_T` for large `T`, and
`F̂ = (τ²+¼)Ĝ`. Then `G ↦ 𝔞^{(a)}((−∂²+¼)G)` is a nonnegative translation-covariant form on `C_c^∞`. Bochner–Schwartz
gives a positive tempered `ν` with `𝔞^{(a)}(F) = ∫|Ĝ|²dν`. Put `μ^P_a := (τ²+¼)^{−2}ν`, which is positive, and tempered
because `(τ²+¼)^{−2} ≤ 16`.

(iii) By Lemma 1.1 (which extends from `ℓ¹_w` to tempered `β_b` by the same pairing), `W^{(a+b)}(F) = ∫|F̂|²dν_b` with
`ν_b := μ_a − (2π)^{-1}D_b`.
* (⟸) If `ν_b ≥ 0`, then `W^{(a+b)} ≥ 0` on `C_c^∞`. The form domain of `L²(I_T)` is the closure of `C_c^∞(I_T)` in the
  form norm (P47 `lem:roughEF` setting), so `λ^W_T(a+b) ≥ 0` for every `T`.
* (⟹) The form is nonnegative on `C_c^∞`, so `F^{-1}ν_b` is positive definite. Bochner–Schwartz makes `ν_b` a positive
  measure.
* Primitive form: the same argument, with `F = (−∂²+¼)G` and the positive weight `(τ²+¼)²`. For (⟸), the tests
  `(−∂²+¼)G` must be dense in `P_T` in the form norm. That holds because `P_T ∩ C_c^∞(I_T) = (−∂²+¼)C_c^∞(I_T)`: a test
  in `P_T` has `F̂(±i/2) = 0`, hence `F̂/(τ²+¼)` is entire of exponential type `T` and is `Ĝ` for some `G ∈ C_c^∞(I_T)`
  (Paley–Wiener–Schwartz). ∎

**Lemma 2.1 (the spectral measure of ζ; PROVED under RH).** Under RH, `Λ ∈ 𝒮^W ⊂ 𝒮^A`, and `μ_Λ = μ^P_Λ = Σ_γ m_γ δ_γ`,
the sum over the ordinates with multiplicity. This measure is purely atomic and carried by the countable set `Γ_ζ`.
*Proof.* Weil's criterion (P47 §1, E1–E2). For real `F ∈ C_c^∞`, the explicit formula (P47 `eq:W`) gives
`W(F) = Σ_ρ Φ_F(ρ)Φ_F(1−ρ) = Σ_γ F̂(γ)F̂(−γ) = Σ_γ|F̂(γ)|²` when every `γ` is real. Uniqueness in Lemma B(i) gives the
first identity. `W = 𝔞` on `P_T` gives the second. ∎

**Theorem R (rigidity of the jump weights at `T = ∞`). PROVED under RH.**
(i) *(Complete form.)* Let `b` be a real perturbation with `β_b` tempered and `D_b` a locally finite measure with
`|D_b|(Γ_ζ) = 0`. This holds for every `b ∈ ℓ¹_w`. If `Λ + b ∈ 𝒮^W`, then `b = 0`.
(ii) *(Primitive form.)* The same holds with `𝒮^A` in place of `𝒮^W`.
(iii) *(Sharp slopes.)* For `b ∈ ℓ¹_w`:
```
limsup_{T→∞} λ^W_T(Λ+b) ≤ limsup_{T→∞} λ^A_T(Λ+b) ≤ − sup_τ D_b(τ), and sup_τ D_b(τ) > 0 whenever b ≠ 0.
```
Hence the limiting bottom `L^A(a) := lim_T λ^A_T(a)` satisfies the following. The limit exists in `[−∞,∞)` by
monotonicity. `L^A` is concave, as an infimum of the concave `V_T`. On every line through `Λ`,
```
L^A(Λ + tb) ≤ −t·sup D_b (t > 0), L^A(Λ + tb) ≤ −|t|·sup D_{−b} (t < 0), L^A(Λ) = 0,
```
where `L^A(Λ) = 0` uses RH together with `thm:margin`. So `Λ` is a strict, conical maximiser of `L^A` on `Λ + ℓ¹_w`.
(iv) *(Beyond `ℓ¹_w`.)* Under RH, for `b` as in Lemma B(iii), `Λ + b ∈ 𝒮^W` if and only if `D_b ≤ 2π Σ_γ m_γδ_γ`.
Such a `D_b` has its positive part carried by the ordinates, with atoms of mass `≤ 2πm_γ`. Whether any `b ≠ 0` of this
kind exists (a "Fourier pair" between `±log ℕ` and `Γ_ζ` other than 0) is **OPEN**.

*Proof of (i).*
* By Lemma B(iii) and Lemma 2.1, `ν_b = Σ m_γδ_γ − (2π)^{-1}D_b ≥ 0`.
* Restrict to Borel sets `E ⊂ ℝ∖Γ_ζ`. The atoms give no mass there, so `−D_b(E) ≥ 0`. Since `|D_b|(Γ_ζ) = 0`, `D_b` is
  therefore a *nonpositive* measure on all of `ℝ`.
* Put `σ := −D_b ≥ 0`, a positive tempered measure whose inverse Fourier transform is `β_b` up to a constant, and `β_b`
  vanishes on `(−log 2, log 2)`.
* Take `φ ∈ C_c^∞(−½log2, ½log2)` and `φ̃(x) = conj φ(−x)`. Then `φ⋆φ̃` is supported in `(−log2, log2)`, so
  `0 = ⟨β_b, φ⋆φ̃⟩ = c∫|φ̂|²dσ`.
* `φ̂` is entire and not identically zero, so its real zero set `Z_φ` is discrete, and `σ(ℝ∖Z_φ) = 0`. A second test
  `φ_2 = φ·e^{iκ·}` has `Z_{φ_2} = Z_φ + κ`. For all but countably many `κ` this set is disjoint from `Z_φ`. So `σ = 0`.
* Then `β_b = 0`. The atoms `±log n` are distinct, so `b = 0`.

*Proof of (ii).* The same argument with `μ^P_Λ = Σ m_γδ_γ` (Lemma 2.1).

*Proof of (iii).* Fix `τ_0 > 0` with `τ_0 ∉ Γ_ζ`. Fix a real even `g ∈ C_c^∞(−1,1)`, `g ≠ 0`, and put
`G_T(t) = cos(τ_0 t)g(t/T)` and `F_T = (−∂²+¼)G_T ∈ P_T ∩ C_c^∞(I_T)`.
* Then `F̂_T(τ) = (τ²+¼)(T/2)[ĝ(T(τ−τ_0)) + ĝ(T(τ+τ_0))]`.
* The probability measures `p_T := |F̂_T|²dτ/(2π‖F_T‖²)` converge weakly to `½(δ_{τ_0} + δ_{−τ_0})`. The reason: `ĝ` is
  Schwartz, so the mass outside `|τ ∓ τ_0| ≤ T^{−1/2}` is `O(T^{−N})`, and the polynomial factor `(τ²+¼)²` does not spoil
  this.
* Also `‖F_T‖² = (T/4π)(τ_0²+¼)²‖ĝ‖²_2(1+o(1))`.

*The ζ part.* By Lemma 2.1, `𝔞_T(F_T) = W(F_T) = Σ_γ m_γ|F̂_T(γ)|²`. Let `d = dist(τ_0, ±Γ_ζ) > 0` and use
`|ĝ(s)| ≤ C_N(1+|s|)^{−N}`.
* The finitely many `|γ| ≤ 2τ_0 + 1` contribute `O(T^{2−2N}d^{−2N})`.
* For `|γ| > 2τ_0+1` we have `|γ ∓ τ_0| ≥ |γ|/2`. So those `γ` contribute
  `O(T^{2−2N}Σ_γ m_γ(γ²+¼)²(|γ|/2)^{−2N})`, which is finite for `N ≥ 3` since `N(t) ≪ t log t`.
* Hence `𝔞_T(F_T)/‖F_T‖² = O(T^{1−2N}) → 0`.

*The perturbation.* By Lemma 1.1, `−(2π)^{-1}∫|F̂_T|²D_b/‖F_T‖² = −∫D_b dp_T → −D_b(τ_0)`, because `D_b` is bounded,
continuous and even.
* So `limsup λ^A_T(Λ+b) ≤ −D_b(τ_0)` for every `τ_0 ∉ Γ_ζ`.
* `D_b` is continuous and `Γ_ζ` is discrete, so the bound holds with `sup_τ D_b`.
* `λ^W ≤ λ^A` because the two forms agree on `P_T`.

*Positivity of the slope.* `D_b = Σ_n b_n n^{−1/2}(e^{iτ log n} + e^{−iτ log n})` is uniformly almost periodic. Its
frequencies `±log n` are distinct and nonzero, so its mean is `M(D_b) = 0`, and Parseval gives `M(D_b²) = 2Σ b_n²/n`.
If `sup D_b ≤ 0`, then `M(|D_b|) = −M(D_b) = 0`, so `M(D_b²) ≤ ‖D_b‖_∞M(|D_b|) = 0` and `b = 0`.

*The line bounds and concavity.* `V_T` is concave (`lem:degen`, which holds for real weights), so `L^A = inf_T V_T` is
concave. The slope bounds are (iii) applied to `tb`. ∎

*Proof of (iv).* This is Lemma B(iii) with Lemma 2.1. The support statement is the restriction argument of (i). ∎

**Remark 2.2 (what Theorem R is and is not).**
* It is a statement at `T = ∞`. At finite `T`, the per-window picture is `rem:resweights` (O3): the resolution is
  `e^{−14.4T}`. Theorem R is its limit, where the tolerance becomes zero. The limit is quantified by the sublinear
  functional `b ↦ sup D_b`: a supergradient at `Λ` of `L^A` in the direction `b` is the evaluation `−D_b(τ_0)` at any
  `τ_0 ∉ Γ_ζ`.
* It needs RH only through Lemma 2.1 (`μ_Λ` atomic). It is not a sign for ζ.
* In jump language: a jump of weight `b_n/√n` at `u = log n` transforms into the almost-periodic symbol `D_b`, which has
  no atoms. An atomic spectral measure cannot absorb a perturbation without atoms. Individually and jointly, the jump
  weights `Λ(n)/√n` cannot move while `∀T` positivity is kept.

## §3 Consequences: the unconditional no-go, and the integer Euler-product falsifier

**Corollary R1 (unconditional; PROVED as a statement about derivations, in the sense of `cor:void` and P46
Thm 18.1(ii)).** Let `𝒞` be any class of real combs that contains `Λ` and at least one `Λ + b` with `b ≠ 0` as in
Thm R(i), for instance `b ∈ ℓ¹_w∖{0}`. No derivation of `∀T λ^A_T(a) ≥ 0`, or of `∀T λ^W_T(a) ≥ 0`, whose only prime
input is `a ∈ 𝒞` exists.
*Proof.* Such a derivation would prove the statement for `Λ` and for `Λ+b`.
* If RH fails, the statement for `Λ` is false (E1, E2).
* If RH holds, the statement for `Λ+b` is false (Thm R(i)–(ii)). ∎

Comparison with the record. `cor:void` needs `𝒞` closed under deletion or amplification, and it acts at each window.
R1 Thm 5 needs a monotone jump rule. Corollary R1 needs **two points**, and the second point may be chosen to keep any
property that some summable perturbation keeps. At `T = ∞` it subsumes all of the following, each of which lies in
`Λ + ℓ¹_w`:
* `thm:finmod`(i), deletion (`b = −Λ1_{n<N}`);
* `thm:finmod`(ii), amplification (`b = cδ_{n_0}`);
* G2_B3_R1's `L_2` (`b_{2^k} = ((−1)^k−1)log 2`);
* every `ζ·exp(D)` with `D` a Dirichlet series absolutely convergent on `Re s ≥ ½` (the G2_B10_R2 twist class `A_½`);
* the falsifier `ζ_odd` of Theorem O.

**Theorem O (`ζ_odd`; PROVED).** Put `Λ_odd := Λ·1_{n odd}`, so that `ζ_odd(s) := Σ_{n odd}n^{−s} = (1−2^{−s})ζ(s)` and
`b := Λ_odd − Λ = −log 2·1_{n=2^k}`, which lies in `ℓ¹_w`.
(a) *(What it keeps; PROVED, elementary.)*
* Coefficients in `{0,1}`.
* An Euler product `∏_{p≥3}(1−p^{−s})^{−1}`. It is a genuine Beurling subsystem of the rational primes, and its von
  Mangoldt function `Λ_odd` equals `log p` at `p^k` exactly (weight = position).
* `0 ≤ Λ_odd ≤ Λ`, so it lies in `𝒞_BT`.
* `ψ_odd(x) − ψ(x) = −log 2·⌊log_2 x⌋ = O(log x)`. So `ψ_odd` has the same PNT error term as `ψ`, unconditionally,
  and under RH `ψ_odd(x) = x + O(x^{½}log²x)`. (Not `x + O(log x)`: that would contradict Littlewood's oscillation
  `ψ(x) − x ≠ O(x^{½})`, CITED, Ingham Ch. V.)
* Meromorphic continuation of order 1, the pole at `s = 1`, and every zero of ζ in `0 < Re s < 1`.
* What it does not keep: the new zeros `s = 2πik/log 2` (`k ≠ 0`) on `Re s = 0`, and a Γ-type functional equation.
  The factor `(1−2^{−s})/(1−2^{s−1})` is not a ratio of Γ-factors.
(b) *(Complete form, unconditional.)* `λ^W_T(Λ_odd) < 0` for every `T ≥ 0.4608`.
(c) *(Primitive form, under RH.)* `limsup_T λ^A_T(Λ_odd) ≤ −2(√2−1)log 2 = −0.57422…`. So there is `T_1` with
`λ^A_T(Λ_odd) < 0` for all `T ≥ T_1`.
(d) *(Exact symbol.)* `D_b(τ) = log 2·(1 − P(τ log 2))`, where `P(θ) = (1−r²)/(1−2r cos θ + r²)` and `r = 2^{−1/2}`.
Equivalently,
```
W^{(Λ_odd)}_T(F) = W_T(F) + (log 2/2π)∫|F̂|²(P(τ log 2) − 1)dτ.
```
*Proof.*
(d) `Σ_{k≥1} 2r^k cos(kθ) = P(θ) − 1`, together with Lemma 1.1.
(b) For `T < ½log 3`, `N_T = {2}`, and `Λ_odd(2) = 0`. So `W^{(Λ_odd)}_T` is the archimedean complete form `A_∞`. P47
`prop:archneg` gives `A_∞(F^{odd}_T) ≤ U(T) < 0` at `T = 0.4608`, with `F^{odd} = t·1_{I_T}`. Then `0.4608 < ½log 3`. For
larger `T`, extend the same test by zero (`lem:monoT`, sign-free).
(c) Thm R(iii) with `sup D_b = D_b(π/log 2) = log 2·(1 − (1−r)/(1+r)) = log 2·2r/(1+r) = 2(√2−1)log 2`. The last
number was evaluated in closed form and checked numerically: `0.5742219…`. ∎

**Example 3.3 (the chain family through ζ; PROVED under RH).** For a prime `p` and `|α| < √p`, put
`ζ_{p,α} = ζ(s)(1−p^{−s})/(1−αp^{−s})`. Its chain weights are `α^k log p` at `p^k`, and `b ∈ ℓ¹_w` with
`D_b = log p·[P_{αr}(θ) − P_r(θ)]`, where `θ = τ log p`, `r = p^{−1/2}` and `P_x(θ) = (1−x²)/(1−2x cos θ + x²)`. Then, by
Thm R(iii):
```
limsup_T λ^A_T(ζ_{p,α}) ≤ − log p · 2r(1−α)/((1+r)(1+αr)) (−1 ≤ α < 1, evaluating at θ = π),
limsup_T λ^A_T(ζ_{p,α}) ≤ − log p · 2r(α−1)/((1−r)(1−αr)) (1 < α < √p, evaluating at θ = 0).
```
The case `α = 0` is `ζ_odd`. The case `α = −1`, `p = 2` is `L_2`, with bound `−4r log 2/(1−r²) = −3.921…`. Along this
family, ζ is the only point that survives. The slope at `α = 1` is `2r log p/(1±r)²`, nonzero on both sides: a conical
peak.

## §4 The rigidity reading: which properties of ζ can carry the "for all T" arrow

A property `𝐏` of combs is **ℓ¹_w-rigid at Λ** if no `Λ + b` with `b ∈ ℓ¹_w∖{0}` has `𝐏`. Corollary R1 says, PROVED: a
load-bearing input of any derivation of `∀T` positivity must be ℓ¹_w-rigid at `Λ`. Otherwise the input is shared with
some `Λ + b`, and the case split applies. This is the exact form of F1, sharper than "not preserved by finite
modifications" (P47 `rem:twohalves`(a)).

| property of ζ | rigid? | witness / source |
|---|---|---|
| `a ≥ 0`, `a ≤ Λ`, the PNT error term of ζ (any bound on `ψ − x` that is `≫ log x`, e.g. `O(x^{½+ε})` under RH), zeros of ζ in the strip, zero-free regions, density | **no** | `ζ_odd` (Thm O); `thm:finmod` |
| Euler product over rational primes, weights = positions (`a = log p` at `p^k`), 0/1 or integer coefficients | **no** | `ζ_odd` (Thm O(a)) |
| exact moduli `\|a(n)\| = Λ(n)`, real coefficients | **no** | `L_2` (G2_B3_R1) |
| the size of the jump remainder `E(u)` (R1 Thm 3) at any rate `≫ 1` | **no** | `E_{Λ+b} = E_Λ + O(1)` for `b ∈ ℓ¹_w` |
| Riemann's functional equation (conductor 1, `Γ_ℝ`), finite order | **yes** | Hamburger (G2_B3_R2 Thm H, CITED there) |
| `∀T` positivity itself | **yes, under RH** | Theorem R |

Row 4 answers the diagram, which reads "for all `T` = `ψ(x) − x ≪ x^{½+ε}` = RH". For ζ the equivalence is
true (R1 Prop 4). But the bound on `ψ − x`, *used as an input*, is not rigid. Every `Λ + b` with `b ∈ ℓ¹_w` satisfies the
same bound, and under RH each such comb fails for large `T`. **PROVED** (Thm R(iii) together with
`E_{Λ+b} − E_Λ = O(1)`). The route from the bound to the sign therefore runs through ζ's own analytic continuation,
that is, through the rigid row. It does not run through the size of `ψ − x` as such.

**Consequence for G2 (EQUIVALENT).** A mechanism must derive the rigid property "∀T positivity" from a rigid input. The
only rigid input among the axioms of ζ is Riemann's FE. By Hamburger, the class of combs having it is `{Λ}` (G2_B3_R2
Cor H1). The mechanism would be the implication "Riemann's FE (with an ℕ-Dirichlet series, finite order) ⟹ `∀T`
positivity". On a one-point class, that implication is literally RH. The jump calculus reduces the G2 target to this
statement and adds nothing to it. **EQUIVALENT; no mechanism.**

## §6 What is genuinely new

1. **Lemma B** (PROVED, unconditional). For combs that are positive for all `T`, admissibility of a perturbation is the
  measure inequality `D_b ≤ 2πμ_a`, in the complete and in the primitive form.
2. **Theorem R** (PROVED under RH). `Λ` is the unique point of `𝒮^A` and of `𝒮^W` in `Λ + ℓ¹_w`, and more generally
  among perturbations whose spectral transform puts no mass on `Γ_ζ`. The peak is sharp, with explicit slope
  `sup D_b`. This replaces R1 Cor 6(ii) and removes the OPEN hypothesis (ND).
3. **Corollary R1** (PROVED, unconditional). Every class-based derivation fails once the class holds two points that
  differ by a nonzero summable perturbation. At `T = ∞` this unifies all falsifiers of the record whose difference from
  `Λ` is summable.
4. **Theorem O**: `ζ_odd`, the first falsifier with 0/1 coefficients, a genuine rational Euler product,
  `0 ≤ Λ_odd ≤ Λ`, and exact weights at every odd `n`.
  * The complete form fails for all `T ≥ 0.4608`, unconditionally.
  * The primitive form satisfies `limsup ≤ −2(√2−1)log 2` under RH.
  * This closes the "weight = position" door (G2_B4 salvage, F1′) as a standalone input.
5. **The rigidity table (§4)**. Of the axioms of ζ, only Riemann's FE is rigid. So the G2 target is
  "FE-rigidity ⟹ positivity-rigidity", which is EQUIVALENT to RH.

## §7 Weakest step

* **Theorem R is conditional on RH**, through Lemma 2.1 (`μ_Λ` purely atomic). Only Corollary R1 is unconditional, and
  it is a statement about derivations, not about ζ. The case split should be checked. It is sound because each
  branch refutes the derivation on a member of `𝒞`, which is the same logic as `cor:void`, following the P46 Thm 18.1
  convention.
* **Lemma B(iii), (⟸) direction, primitive form:** the density of `(−∂²+¼)C_c^∞(I_T)` in `P_T` for the form norm. I
  argued it by Paley–Wiener–Schwartz for smooth tests. Passing from smooth tests to the full form domain relies on P47's
  form-domain closure (`lem:roughEF` / the proof of `thm:O`), which I did not re-derive. Theorem R uses only the (⟹)
  direction, which needs no density. So Theorem R is unaffected.
* **Theorem R(iv)**, the existence of nonzero `b` with `D_b ≤ 2πμ_Λ` carried by the ordinates, is **OPEN**. It is a
  Fourier-quasicrystal question between `±log ℕ` and `Γ_ζ`. A positive answer would give a second point of `𝒮` near `Λ`,
  not a proof of RH.

  support `L`, the zeros verified to height `3·10^{12}` (Platt–Trudgian, CITED), and a crude tail bound. It was not done,
  per the rule that numerics are used only when necessary. Corollary R1 does not need it.
