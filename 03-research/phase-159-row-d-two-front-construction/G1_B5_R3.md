## §1 The object: Hilbert Witt data

**1.1 Motivation** (`CITED`). On `W(A)`, the Frobenius `F_n` and Verschiebung `V_n` satisfy `F_nF_m = F_{nm}`,
`V_nV_m = V_{nm}`, `F_nV_n = n`, and `F_nV_m = V_mF_n` for `(n,m) = 1` (Hesselholt, *Lecture notes on Witt vectors*,
§1). In ghost coordinates `(F_na)_k = a_{nk}` and `(V_na)_k = n·a_{k/n}`, where `a_{k/n} := 0` if `n ∤ k`. Borger's
descent datum to `F_1` is the family of commuting Frobenius lifts `ψ_p` (Borger 0906.3146 §1). Weil's positivity on
`C×C` is the Rosati identity `ππ^† = q` for the adjoint of the Castelnuovo form (R158_001 l.122).

**Definition 1.1 (HWD).** A *Hilbert Witt datum* is a separable Hilbert space `H` with bounded operators
`(F_p, V_p)_{p prime}` satisfying
* (W1) `F_pF_q = F_qF_p`;
* (W2) `F_pV_q = V_qF_p` for `p ≠ q`;
* (W3) `F_pV_p = p·I`;
* (R) (Rosati compatibility) `V_p = p·F_p^†`.

Here `†` is the Hilbert adjoint. The positive form is the inner product. It is given **before any spectrum** and uses no
zeros. Put `F_n := ∏F_p^{v_p(n)}`, `S_n := F_n^†`, `Q_n := S_nS_n^†`, and `H_u := ⋂_{n≥1} S_nH`.

**Lemma 1.2** (`PROVED`). In an HWD:
(i) each `S_p` is an isometry and each `F_p` a co-isometry;
(ii) `S_nS_m = S_{nm}`;
(iii) `S_a^†S_b = S_bS_a^†` whenever `(a,b) = 1` (double commutation);
(iv) `Q_n` is the range projection of `S_n`, `Q_n ≤ Q_d` for `d | n`, and `‖F_ny‖ = ‖Q_ny‖`;
(v) `H_u` is reducing for all `S_p`, and `S_p|H_u` is unitary. The Rosati identity `F_p^†F_p = I` holds on a closed
subspace `Y` reducing for `S_p` iff `Y ⊂ ⋂_k S_p^kH`.
Conversely, a representation `n ↦ S_n` of `N^×` by doubly commuting isometries defines an HWD via `F_p := S_p^†`,
`V_p := pS_p`.

*Proof.*
(i) By (R) and (W3), `F_pF_p^† = p^{−1}F_pV_p = I`, so `S_p^†S_p = I`.
(ii) Take the adjoint of (W1).
(iii) (R) and (W2) give `F_pS_q = S_qF_p`, i.e. `S_p^†S_q = S_qS_p^†`, for `p ≠ q`. For coprime `a, b`, induct on the
number of prime factors, using (ii): `S_{pa}^†S_b = S_a^†S_p^†S_b = S_a^†S_bS_p^† = S_bS_a^†S_p^† = S_bS_{pa}^†`.
(iv) `S_n` is an isometry, so `Q_n` is its range projection. `S_nH = S_dS_{n/d}H ⊂ S_dH`. Finally
`‖F_ny‖² = ⟨S_nS_n^†y, y⟩ = ‖Q_ny‖²`.
(v) First, `S_pH_u ⊂ ⋂_n S_pS_nH = ⋂_n S_nS_pH ⊂ H_u`. Next, for `y ∈ H_u` and any `n`, write `y = S_pS_nz`; then
`S_p^†y = S_nz ∈ S_nH`, so `S_p^†H_u ⊂ H_u`. Hence `S_p` maps `H_u` onto `H_u`, isometrically, so `S_p|H_u` is unitary.
Rosati: `F_p^†F_p = S_pS_p^† = Q_p`. So `F_p^†F_p = I` on `Y` iff `Y ⊂ S_pH`. Since `Y` is reducing for `S_p`,
`Y = S_p^kS_p^{†k}Y ⊂ S_p^kH` for all `k`.
The converse is the same algebra read backwards. ∎

**Examples 1.3** (`PROVED`, direct checks).
* (G) *Ghost model.* `H = ℓ²(N)` with `S_nδ_k = δ_{nk}`. Then `F_n = S_n^†` is `(F_na)_k = a_{nk}`, the Witt Frobenius in
  ghost coordinates, and `V_n = nS_n` is the Witt Verschiebung. (R) holds with the unweighted inner product. By
  `a ↦ Σa_kk^{−s}` this is the Dirichlet–Hardy space `𝓗²` of Hedenmalm–Lindqvist–Seip (CITED, Duke 1997), and
  `ℓ²(N) ≅ ⊗′_p ℓ²(Z_{≥0})` with `S_p` the unilateral shift in the `p`-th factor. Here `H_u = 0`, since
  `⋂_n S_nH = {a : a_k = 0 unless n | k for all n} = 0`.
* (T) *Toric λ-ring* `Z[z_1^{±1},…,z_d^{±1}]`, with `ψ_p(z) = z^p`. Take `H = L²(T^d)` with Haar measure and
  `S_p f := f∘ψ_p`, i.e. `S_pe_k = e_{pk}` on characters. This is an isometry because Haar measure is `ψ_p`-invariant.
  `S_p^†e_k = e_{k/p}` if `p | k` and `0` otherwise, so double commutation holds on the basis. Here
  `H_u = closed span{e_k : n | k ∀n} = C·e_0`.
* (Ch) *Chebyshev λ-ring* `Z[x]`, with `ψ_p = T_p` and `x = z + z^{−1}`. `L²([−2,2], arcsine)` is the even part of
  `L²(T)` in (T) with `d = 1`, which is reducing for `S_p` and `S_p^†`. So `H_u = C`.
* (Z) *The λ-ring `Z`.* A ring endomorphism of `Z` is the identity, so `ψ_p = id` and the only λ-structure on `Z` is
  trivial. Every Hilbert realisation has `S_p = I` on the realising space, so `H_u = H` and `u` is trivial.
* (BC) Every Hilbert representation of the Bost–Connes algebra: §4.

## §2 Theorem 1: what suspends lies in the Rosati part

**Definition 2.1.** For `w ∈ H` put `φ_w(m/n) := ⟨S_mw, S_nw⟩`.
* It is well defined on `Q^×_{>0}`, since `⟨S_{km}w, S_{kn}w⟩ = ⟨S_k^†S_kS_mw, S_nw⟩`.
* It is positive definite: for `r_i = m_i/N`, `Σ c_i c̄_j φ_w(r_i/r_j) = ‖Σ c_iS_{m_i}w‖² ≥ 0`.
* `φ_w(1) = ‖w‖²`.

The *suspendable part* is `H_c := {w : φ_w(r) → ‖w‖² as log r → 0}`. On `H_u`, where
`u(m/n) := S_mS_n^{−1}` is a unitary representation of `Q^×_{>0}`, we have `φ_w(r) = ⟨u(r)w, w⟩` and
`‖u(r)w − w‖² = 2‖w‖² − 2Re φ_w(r)`. So `H_c ∩ H_u` is exactly G1_B2_R2's `V_c` for `(H_u, u)`.
`φ_w` is intrinsic: no dilation or extension enters the definition.

**Theorem 1 (Witt–Kronecker; `PROVED`).** In every HWD, `H_c ⊂ H_u`. Consequently `H_c = E(L)H_u`, a closed subspace,
where `E` is the spectral measure of `u` on `(Q^×_{>0})^∧ = T^∞` and `L` is the Kronecker line. On `H_c` the suspended
flow is `∫e^{itγ}dE(ι(γ))`, and each `F_p` acts unitarily as `p^{−iγ}`.

*Proof.* Let `w ∈ H_c` and `n ≥ 2`. Since `(n, n−1) = 1`, Lemma 1.2(iii) gives
`φ_w(n/(n−1)) = ⟨S_{n−1}^†S_nw, w⟩ = ⟨S_nS_{n−1}^†w, w⟩ = ⟨F_{n−1}w, F_nw⟩`.
As `n → ∞`, `log(n/(n−1)) → 0`, so the left side tends to `‖w‖²`. By Cauchy–Schwarz and `‖F_{n−1}‖ ≤ 1`,
`|⟨F_{n−1}w, F_nw⟩| ≤ ‖w‖·‖F_nw‖`. Hence `liminf‖F_nw‖ ≥ ‖w‖`, and since `‖F_n‖ ≤ 1`, `‖Q_nw‖ = ‖F_nw‖ → ‖w‖`
(Lemma 1.2(iv)).
Fix any `d ≥ 1`. Along the multiples `n = jd → ∞`, `Q_n ≤ Q_d` gives `‖Q_dw‖ ≥ ‖Q_{jd}w‖ → ‖w‖`, so `Q_dw = w`, i.e.
`w ∈ S_dH`. Since `d` is arbitrary, `w ∈ H_u`.
Given `H_c ⊂ H_u`, the identity `H_c = E(L)H_u` and the form of the flow are G1_B2_R2 Theorem S(i)–(ii) applied to
`(H_u, u)`. `F_p|H_u = (S_p|H_u)^{−1}` by Lemma 1.2(v). ∎

**Remarks.**
(a) Only the Farey-neighbour sequence `n/(n−1)` was used. So a weaker notion of suspension still forces `H_u`: all that
is needed is `φ_w(n/(n−1)) → ‖w‖²`.
(b) The panel's caveat ("a compression does not inherit the dilation's `V_c`") does not arise, because `φ_w` is
intrinsic and no extension is used.
(c) *Rosati reading.* The Rosati identity `F^†F = 1` fails exactly by the wandering projections `1 − Q_p`
(Lemma 1.2(v)). Theorem 1 says suspension sees only where the identity holds.

## §3 Theorem 2 and Prop D: semigroups, and the one-sided half

**Theorem 2** (`PROVED`). Let `Y ⊂ H` be closed.
(a) Suppose `Y` is invariant under all `F_n` and all `S_n` (a sub-datum), and `T` is **any** C₀-semigroup on `Y` with
`T(log n) = F_n|Y` for all `n`. Then `Y ⊂ H_u`.
(b) Suppose `Y` is `S`-invariant and `T` is a C₀ **contraction** semigroup on `Y` with `T(log n) = S_n|Y`. Then
`Y ⊂ H_c ⊂ H_u`.
(c) Neither `S`-invariance in (a) nor the conclusion extends to merely `F`-invariant subspaces. In (G), the line `C·e_s`
with `e_s := (k^{−s})_k` and `Re s > ½` is `F`-invariant and carries `T(t) = e^{−st}`, while `H_u = 0`.

*Proof.*
(a) Let `y ∈ Y`, `n ≥ 2`, `m = n−1`. Then `S_my ∈ Y`, `T(log m)S_my = F_mS_my = y`, and
`T(log n)S_my = F_nS_my = S_mF_ny` (coprimality, Lemma 1.2(iii)). The semigroup law gives
`T(log(n/m))y = T(log n)S_my = S_mF_ny`. Strong continuity at `0⁺` gives `S_{n−1}F_ny → y`, so
`‖F_ny‖ = ‖S_{n−1}F_ny‖ → ‖y‖`. Conclude as in Theorem 1.
(b) Take `t ≤ log n`. Then `‖y‖ = ‖S_ny‖ = ‖T(log n − t)T(t)y‖ ≤ ‖T(t)y‖ ≤ ‖y‖`, so each `T(t)` is an isometry. For an
isometric semigroup, `T(a)^†T(a+b) = T(b)`. Hence for `n > m`,
`φ_y(n/m) = ⟨T(log n)y, T(log m)y⟩ = ⟨T(log(n/m))y, y⟩ → ‖y‖²` as `n/m → 1`. So `y ∈ H_c`, and Theorem 1 applies.
(c) `e_s ∈ ℓ²` iff `Re s > ½`, and `F_ne_s = n^{−s}e_s`. ∎

**Prop D (spectral dichotomy; `PROVED`).** In any HWD, let `0 ≠ y` satisfy `F_ny = n^{−s}y` for all `n`. Then
`Re s ≥ 0`, and `Re s = 0 ⟺ y ∈ H_u`. In (G) the joint eigenvectors of the form `F_ny = n^{−s}y` are exactly `C·e_s`,
`Re s > ½`, with Gram kernel `⟨e_s, e_w⟩ = ζ(s + w̄)`.

*Proof.* `‖F_n‖ ≤ 1` gives `n^{−Re s} ≤ 1`. If `Re s = 0`, then `‖Q_ny‖ = ‖F_ny‖ = ‖y‖`, so `Q_ny = y` for all `n`
and `y ∈ H_u`. Conversely, on `H_u` each `F_n` is unitary, so `|n^{−s}| = 1`. In (G), `(F_ny)_k = y_{nk} = n^{−s}y_k`
forces `y_k = k^{−s}y_1`. ∎

**Reading** (`HEURISTIC` as interpretation; the statements are `PROVED`).
* Contractivity (the prior positive form) gives Serre's one-sided half, `Re s ≥ 0`, for free. Combined with a functional
  equation `s ↔ −s` on the spectrum it would give the line. This is Weil's mechanism in Witt form.
* But the spectrum that the prior object carries is the half-plane `Re s > ½` in (G). There the Gram kernel is
  `ζ(s + w̄)`, the polar side of the Dirichlet series, exactly as in my R2 Thm F and Prop F.4. The zeros are not
  eigenvalues.
* On the line the eigenvectors are the Rosati part, which is automatic (Lemma T(⇐)).

## §4 Cor 4: the Bost–Connes algebra

**Presentation** (`CITED`: Bost–Connes, Selecta Math. 1 (1995), Prop. 18; Laca–Raeburn, J. London Math. Soc. 54 (1996)).
`C*_BC` is generated by
* isometries `μ_n` (`n ∈ N^×`), with `μ_nμ_m = μ_{nm}` and `μ_n^*μ_m = μ_mμ_n^*` for `(n,m) = 1`;
* unitaries `e(r)` (`r ∈ Q/Z`), with `e(r)e(r′) = e(r + r′)`, `e(0) = 1` and `e(r)^* = e(−r)`;
* the relation `μ_ne(r)μ_n^* = (1/n)Σ_{ns=r}e(s)`.
The time evolution is `σ_t(μ_n) = n^{it}μ_n`. The endomorphisms `ρ_n(x) = μ_nxμ_n^*` are the "Frobenius".

**Cor 4** (`PROVED` modulo the CITED presentation). Let `π` be any representation of `C*_BC` on `H`. Then `S_n := π(μ_n)`
is an HWD (Lemma 1.2, converse). With `H_u = ⋂_nS_nH`:
(i) `H_c ⊂ H_u`, and `π(e(r))ξ = ξ` for every `ξ ∈ H_u` and `r ∈ Q/Z`;
(ii) conversely, every unitary representation `u` of `Q^×_{>0}` defines a representation of `C*_BC` with `μ_n = u(n)`
and `e(r) = 1`. For it, `H_u = H` and `H_c = E(L)H` (Theorem S).
So the suspendable part of any BC representation is supported over the character `0 ∈ Ẑ = (Q/Z)^∧`. There the BC
algebra is the group `Q^×_{>0}` alone, with no input from `Q/Z`, and its Kronecker-line spectrum is unconstrained
(G1_B2_R2 Prop R).

*Proof.*
(i) The first claim is Theorem 1. For the second, fix `ξ ∈ H_u`. On `H_u`, `μ_n` is unitary (Lemma 1.2(v)), so
`μ_nμ_n^*ξ = ξ`. The relation with `r = 0` gives `μ_nμ_n^* = (1/n)Σ_{ns=0}e(s)`, a mean of `n` unitaries. From
`ξ = (1/n)Σ e(s)ξ` and `‖e(s)ξ‖ = ‖ξ‖`, strict convexity of the Hilbert norm forces `e(s)ξ = ξ` for all `s` with
`ns = 0`. Every `r ∈ Q/Z` has finite order.
(ii) All relations hold with `e ≡ 1`. For the last one, both sides equal `1`, because `#{s ∈ Q/Z : ns = r} = n`. ∎

*Reading* (`HEURISTIC`). The natural BC representations (the regular ones on `ℓ²(N)`, the KMS_β GNS representations
for `β > 1`) have `H_u = 0`. In the BC system the arithmetic is entirely in the non-invertible part, and the zeros are not
there either (record A23: partition function `ζ(β)`, `β > 1`). BC's own flow `σ_t` is **covariant** with the Frobenius
(`e^{itH}μ_n = n^{it}μ_ne^{itH}`, `H = log n`) rather than extending it. Its spectrum is `log N`, and its "Lefschetz
formula" is `Tr e^{−βH} = ζ(β)`, the Euler product, not the explicit formula (CITED BC 1995; record A23). The zeros
appear in Connes' programme only as the absorption spectrum on the adèle class space, where positivity is Weil's, EQUIV
(R158_001 l.373, R158_002).

## §6 Prop N: where zeros can enter, and the equivalence

**Prop N** (`PROVED`). In (G), let `g ∈ ℓ²(N)`, `G(s) := Σg_kk^{−s}`, `M_g := closed span{S_ng}` and `Y_g := M_g^⊥`.
Then `Y_g` is `F`-invariant, and for `Re s > ½`: `e_{s̄} ∈ Y_g ⟺ G(s) = 0`. So the joint `F`-point spectrum on `Y_g`
of the form `n^{−s̄}` is the zero set of `G` in `Re s > ½`.

*Proof.* `S`-invariance of `M_g` gives `F`-invariance of `M_g^⊥`. Then
`⟨S_ng, e_{s̄}⟩ = Σ_kg_k(nk)^{−s} = n^{−s}G(s)`. ∎

*Consequence* (`CITED` + record). Selecting the zeros through `Y_g` means choosing `g` from ζ.
* For zeros on the line, the eigenvectors sit on the boundary `Re s = ½`, where `e_s ∉ ℓ²`.
* Zeros off the line would be genuine eigenvalues.
* The corresponding statement "RH ⟺ a cyclicity in `𝓗²`/`L²(0,1)`" is Nyman–Beurling / Báez-Duarte (Hedenmalm–
  Lindqvist–Seip 1997 §; Nikolski, Ann. Inst. Fourier 45 (1995)).

That is R157_002 row 43, **EQUIV**. `Y_g` is defined from `G`, i.e. from ζ, so it fails OT-3.

## §8 New, open, weakest step

**New** (`PROVED`; 0 corpus hits for the mechanism).
1. **Lemma 1.2**: the Witt relations plus Rosati compatibility `V = pF^†` are exactly a representation of `N^×` by
  doubly commuting isometries. The Rosati defect is the wandering projection.
2. **Theorem 1**: the suspendable part of every HWD lies in the joint unitary (Rosati) part, and it equals `E(L)H_u`.
  The proof is a Farey-neighbour argument: coprimality of `n, n−1` turns continuity of the orbit into `‖F_nw‖ → ‖w‖`,
  and divisibility turns that into `w ∈ ⋂S_dH`. No dilation is used.
3. **Theorem 2**: the same holds for arbitrary C₀-semigroups interpolating `F` on sub-data, and for contraction
  semigroups interpolating `S`. Sharpness comes from `F`-invariant eigenlines.
4. **Prop D**: contractivity gives the one-sided half `Re s ≥ 0`, and the line is reached exactly on `H_u`.
5. **Cor 4**: in every representation of the Bost–Connes algebra, the suspension lives over `0 ∈ Ẑ`, where `C*(Q/Z)`
  acts trivially.
6. **Cor 5**: λ-rings `Z`, toric, Chebyshev and Witt give only the pole.
7. **Prop N**: model spaces place Dirichlet-series zeros in the Frobenius spectrum, which leads to Nyman–Beurling
  (EQUIV).

**Excluded.**
* The Borger/λ-ring/Bost–Connes Frobenius as a suspension carrier: G1 via suspension of a non-invertible Frobenius.
* With R1 (function carrier) and R2 (ghost cycles), the Borger angle is closed on all three carriers.

**Open.**
* O-B5.3 (`OPEN`): data where `†` is **not** the Hilbert adjoint, i.e. a Rosati involution for an indefinite or
  degenerate form (a Kreĭn-space HWD). There (R) no longer forces isometries, and Theorem 1's Cauchy–Schwarz step fails.
  This is the only escape from Theorem 1 inside the Witt relations. It is also exactly where the positivity would have to
  be proved rather than given, so it is RH-strength by Lemma T once a zero-carrying `H¹` is exhibited.
* O-B5.4 (`OPEN`): classification of C₀-semigroups on merely `F`-invariant subspaces of a general HWD (Theorem 2(c)).
  In (G) these are the model spaces of Prop N (EQUIV route). For general HWDs I have no classification.
* O-B5.1′ (from R2, `OPEN`): an archimedean completion from `W(R)`. No candidate.

**Weakest step.** The scope of Theorem 1. It covers every datum in which Frobenius compatibility is expressed by the
Witt relations with `V = pF^†` for a **positive definite** inner product, and suspension along `log` (Theorem 1,
Theorem 2(a)/(b)).
* It does not cover Kreĭn-space (indefinite) Rosati data (O-B5.3).
* It does not cover flows that are covariant with Frobenius instead of extending it (BC's `σ_t`, handled only by the
  CITED record A23).
* It does not cover merely `F`-invariant subspaces (O-B5.4, where the known instance is EQUIV).

Two further dependencies:
* Cor 4 depends on the CITED BC/Laca–Raeburn presentation. I did not re-read the primary texts this phase.
* The identification `H_c = E(L)H_u` uses G1_B2_R2 Theorem S(i). All five R2 panelists checked it, and its Borel
  input (Lusin–Souslin) is CITED there.

**Status.** Partial new result, negative/structural. No object passes OT-5′ with content. Row D: no label, no sign.
