# Phase 159 — Two fronts: constructing the object (G1) and the mechanism (G2) for row D

Two ten-track teams, each audited by a five-member panel, worked in parallel on the two remaining
ways to close row D: **G1** — construct a carrier over Spec ℤ (an analogue of Weil's surface C×C)
with a positive form defined before the spectrum, compatible with the flow/Frobenius, whose
Lefschetz formula is ζ's explicit formula; and **G2** — find an argument using the exact values of
Λ(n), uniform in T with no truncation, proving the positivity inequality for all T. Ten angles per
front (scaling sites, Deninger laminations, function fields/condensed, Arakelov, Witt/Bost–Connes,
operator algebras, motives, canonical systems, function-field transport, probabilistic ladders for
G1; structure-vs-randomness, bootstrap-in-T, Hermitian squares, SOS/Positivstellensatz, de Branges
window time, finite/random zero universes, almost periodicity, Lee–Yang, jump calculus, mollifiers
for G2) were run for five rounds each, with panel audits after each round.

## Results

- **G1 (the object): not achieved.** No candidate reached the panel's success threshold (≥4/5); the best score across the run was 1/5, awarded only as "a negative structural result, not an object."
- Four independent angles (B2, B4, B5, B7) converge on the same unconditional theorem — **PROVED**: a tail-factorizable Frobenius carries at most one critical zero per prime-summand (sharp form, Theorem W♯: threshold Σ‖S_p‖⁻² = ∞, B4_R4).
- Further **PROVED** exclusions assembled into one wall: no algebraic (ℚ̄) structure at ≥3 primes carries a zero as joint Frobenius exponent (rationality wall, six-exponentials-CITED); covariant flows have log-N-stable spectrum; canonical operator-algebra functionals have absolutely-continuous flow spectrum (zeros only "installed"); ergodic/finite-trace conformal carriers exclude all but trivial configurations.
- Consequence (HEURISTIC but wall-supported): any OT-5′ object would have to be infinitely entangled across primes, non-algebraic, and non-covariant — a region with no known candidate; the one object on record there (the adèle class space) already has an RH-equivalent trace formula.
- Several claimed theorems were found **false as stated and withdrawn or repaired** during panel audit (e.g. G1_B1_R3 Thm T(iii), G1_B2_R2 Thm E(i), G1_B5_R4 Cor K5(a)).
- **G2 (the mechanism): not achieved.** No candidate scored above 0/5. Every unconditional positivity found is class-level and killed by the standing falsifier corollary (cor:void); every "for all T" statement found is **EQUIVALENT to RH** (the graded Weil converse, von Koch–Landau type, proved independently by five angles at once).
- New unconditional quantitative result, Theorem M (G2_B6_R2) — **PROVED**, not previously in the literature cited: λ^A_T ≤ exp(−e^{(2−ε)T}), i.e. the per-window positivity margin shrinks doubly-exponentially in T — this points away from, not toward, a mechanism.
- A substantial fraction of G2 submissions (angles B8, B10, most of rounds 3 and 5) were **never audited** by the panel; their claims remain self-labels only.
- Honest overall verdict: both fronts reach the same structural boundary from two sides (G1: the object must be entangled/non-algebraic/non-covariant; G2: the argument must not be class-level, twist-covariant, or a resolving SOS rule, and must use the Euler product after any counting step) — repeating either front with the same angles is expected to reproduce the same walls.
