## §1 Setting and definitions

* **Critical ordinates.** `Γ := {γ ∈ ℝ : ζ(½+iγ) = 0}`. For constants `κ ≠ 0` and `β ∈ ℝ` put
  `Γ_{κ,β} := {λ ∈ ℝ : κλ + β ∈ Γ}`. This is the set of flow frequencies that "are zeros" under any affine convention
  (Lemma T's `U_t = e^{−t/2}φ^t`, time rescalings, character twists). Note `0 ∉ Γ` because `ζ(½) ≠ 0`.
* **Standard form** (`CITED` (std.): Araki 1974; Connes 1974; Haagerup, *The standard form of von Neumann algebras*,
  Math. Scand. 37 (1975)). It is a quadruple `(M, H, J, P^♮)`:
  * `M` acts on `H`;
  * `J` is an antiunitary involution with `JMJ = M′`;
  * `P^♮` is a self-dual cone, and it is also the natural cone of `(M′, H, J)`.

  The following facts are used.
  * **(SF1)** Every normal positive functional `ψ` on `M′` has a **unique** representative `η ∈ P^♮` with
  `ψ(y) = ⟨η, yη⟩` for all `y ∈ M′`.
  * **(SF2)** Every automorphism `α` of `M` has a unique unitary `U_α` with `U_α x U_α* = α(x)`, `U_αP^♮ = P^♮` and
  `U_αJ = JU_α`. Moreover `α ↦ U_α` is a homomorphism, and it is strongly continuous for a σ-weakly continuous flow
  `α_t` (Haagerup 1975, Thm 3.2 and Cor. 3.6).
* **W*-dynamical carrier.** A von Neumann algebra `M` in standard form with a σ-weakly continuous flow `α_t`, taken
  with `U_t := U_{α_t}`. Its point spectrum is
  `σ_p(U) := {λ : ∃ξ ≠ 0, U_tξ = e^{iλt}ξ ∀t}`, and its **nontrivial** point spectrum is `σ_p(U)∖{0}`.
* **Commutative instance.** Take `M = L^∞(Ω,m)` acting on `L²(m)`, with `J f = \bar f` and `P^♮ = {f ≥ 0}`. A
  non-singular flow `θ_t` (`m∘θ_t ∼ m`, `ρ_t := d(m∘θ_t)/dm`) gives `α_t(φ) = φ∘θ_t`. Its standard implementation is
  the **half-density Koopman group** `U_t f = ρ_t^{1/2}·f∘θ_t`: it is unitary, preserves `f ≥ 0`, and
  `U_tφU_t* = φ∘θ_t`. The measure-preserving case `ρ ≡ 1` is round 4's setting.
* **Phase.** For an eigenvector `ξ`, the operator `u` of Theorem P(i).

## §2 Theorem P (phase–power law) — `PROVED` modulo (SF1), (SF2)

**Theorem P.** Let `(M, α, U)` be a W*-dynamical carrier in standard form, and let `ξ ≠ 0` satisfy `U_tξ = e^{iλt}ξ` for
all `t`.

(i) **Factorisation.** There are `η ∈ P^♮` and a partial isometry `u ∈ M` such that:
* `ξ = uη`;
* `u*u = e := [M′η]` (the projection onto `cl(M′η)`, which lies in `M`);
* `U_tη = η` for all `t`;
* `α_t(u) = e^{iλt}u` for all `t`.

In particular `ω_η := ⟨η, ·η⟩` is a nonzero normal `α`-invariant positive functional on `M`, and `‖η‖ = ‖ξ‖`.

(ii) **Powers.** For `n ≥ 1`, `u^nη` is either `0` or an eigenvector with eigenvalue `nλ`. Moreover `u^nη = 0` if and
only if `u^n = 0`.

(iii) **Symmetry.** `Jξ` is an eigenvector with eigenvalue `−λ`. So `σ_p(U) = −σ_p(U)`.

(iv) **Normal phases.** If `u` is normal (`u*u = uu*`), in particular if `M` is abelian, then `‖u^nη‖ = ‖η‖` for all
`n ≥ 1`, and hence `λℤ ⊆ σ_p(U)`.

(v) **Pauli form.** `u² = 0` if and only if `q := uu*` and `e = u*u` are orthogonal. Both `e` and `q` lie in the
fixed-point algebra `M^α`.

*Proof.*
(i)
* **An invariant functional on `M′`.** Since `U_tMU_t* = M`, we also have `U_tM′U_t* = M′`. Put
  `ψ(y) := ⟨ξ, yξ⟩` for `y ∈ M′`. This is normal and positive, and
  `ψ(U_t y U_t*) = ⟨U_t*ξ, y U_t*ξ⟩ = |e^{−iλt}|²ψ(y) = ψ(y)`.
* **Its cone representative is fixed.** Let `η ∈ P^♮` represent `ψ` (SF1). Then
  `⟨U_tη, yU_tη⟩ = ψ(U_t* y U_t) = ψ(y)`, and `U_tη ∈ P^♮` by (SF2). Uniqueness in (SF1) gives `U_tη = η`.
* **The phase.** For `y ∈ M′` we have `‖yη‖² = ψ(y*y) = ‖yξ‖²`. So `u₀ : yη ↦ yξ` is well defined and isometric on
  `M′η`. Let `u` be its extension to `eH = cl(M′η)`, set to `0` on `(eH)^⊥`.
* **`u ∈ M`.** Take `z ∈ M′`. On `M′η`, `u z yη = zyξ = z u yη`. The subspace `(eH)^⊥` is `M′`-invariant, because
  `M′` is a `*`-algebra and `eH` is `M′`-invariant, and `u` kills it. So `uz = zu` there as well. Hence
  `u ∈ M″ = M`. It is a partial isometry with `u*u = e`, and `uη = ξ` (take `y = 1`). Finally `e ∈ M`, because `eH`
  is `M′`-invariant.
* **Covariance of the phase.** Since `U_t*η = η` and `U_t*M′U_t = M′`, we get `U_t*(eH) = eH`, and `U_t*` also
  preserves `(eH)^⊥`. For `y ∈ M′`:
  `α_t(u)yη = U_t u U_t* yη = U_t u (U_t*yU_t)η = U_t (U_t*yU_t)ξ = yU_tξ = e^{iλt}yξ = e^{iλt}u yη`.
  On `(eH)^⊥` both `α_t(u) = U_tuU_t*` and `e^{iλt}u` vanish. Hence `α_t(u) = e^{iλt}u`.
* **Invariance of `ω_η`.** `ω_η(α_t(x)) = ⟨U_t*η, xU_t*η⟩ = ω_η(x)`, and `‖η‖² = ψ(1) = ‖ξ‖²`.

(ii)
* `U_t(u^nη) = α_t(u)^nU_tη = e^{inλt}u^nη`.
* If `u^nη = 0`, then for every `y ∈ M′`, `u^n yη = y u^nη = 0`. So `u^n` vanishes on `eH`. Since `u = ue`, we have
  `u^n = u^n e = 0`. The converse is trivial.

(iii) By (SF2), `U_tJξ = JU_tξ = J(e^{iλt}ξ) = e^{−iλt}Jξ`, since `J` is antilinear, and `Jξ ≠ 0`.

(iv)
* If `u*u = uu* = e`, then `e` commutes with `u`: `eu = uu*u = u` and `ue = u`.
* By induction, `(u^n)*u^n = (u*)^{n−1}e u^{n−1} = (u*)^{n−1}u^{n−1}e = e`.
* Hence `‖u^nη‖² = ⟨η, eη⟩ = ‖η‖² ≠ 0` (because `η ∈ eH`). Then (ii) gives `nλ ∈ σ_p` for `n ≥ 1`, and (iii) gives
  it for `n ≤ −1`.

(v)
* `u² = 0` holds iff `ran u ⊆ ker u`, i.e. iff `qH ⊆ (eH)^⊥`, i.e. iff `qe = 0`.
* `α_t(e) = α_t(u)*α_t(u) = e` and likewise `α_t(q) = q`. ∎

**Corollary P.1 (every invariant state of every C*-dynamical system; `PROVED`).**
* *Data.* Let `(A, α)` be a C*-algebra with a strongly continuous flow, `ω` an `α`-invariant state, and
  `(H_ω, π, Ω, U^ω)` its GNS covariant representation, with `U^ω_tπ(x)Ω = π(α_t x)Ω`.
* *Embedding.* Put `M := π(A)″` and `α_t := Ad U^ω_t` on `M`. Then there is an isometry `V : H_ω → L²(M)` (standard
  form) that intertwines `π` with the standard representation and `U^ω` with the standard implementation.
* *Consequences.* Theorem P applies to every eigenvector of `U^ω`, and `σ_p(U^ω) ⊆ σ_p(U^{std})`.

*Proof.*
* `ω̃(x) := ⟨Ω, xΩ⟩` is a normal `α`-invariant state on `M`. Its representative `η_Ω ∈ P^♮` for `M` (the
  `M`-version of (SF1)) is `U^{std}`-fixed, by the argument of P(i) with `M` in place of `M′`.
* `V(xΩ) := xη_Ω` (`x ∈ M`) is isometric, because `‖xΩ‖² = ω̃(x*x) = ‖xη_Ω‖²`. It is `M`-linear, and
  `V U^ω_t xΩ = α_t(x)η_Ω = U^{std}_t x U^{std*}_t η_Ω = U^{std}_t V xΩ`.
* An eigenvector of `U^ω` maps to an eigenvector of `U^{std}`.
* **The power vectors stay in the GNS image.** Let `ξ = Vξ′` be such an eigenvector, with phase `u`. Then
  `u^nη = u^{n−1}(uη) = u^{n−1}ξ ∈ Mξ ⊆ V(H_ω)`, because `V(H_ω) = cl(Mη_Ω)` is `M`-invariant. So the alternative of
  P(ii) ("`nλ` is an eigenvalue, or `u^n = 0`") holds **inside the GNS carrier itself**. That is what Cor Z uses for
  GNS carriers. ∎

**Example P.2 (commutative non-singular).** In the commutative instance, Theorem P(i) reads as follows.

* `u = ξ/|ξ|` on `{ξ ≠ 0}`, with `u∘θ_t = e^{iλt}u` there.

## §3 Corollaries Z and E

**Corollary Z (zeros force nilpotent phases; `PROVED`, with `CITED` [LR] = Li–Radziwiłł, arXiv:1208.2684, Thm 4,
read in round 4).** Let `(M, α, U)` be a W*-dynamical carrier in standard form, or any GNS carrier (Cor P.1), with
`∅ ≠ σ_p(U)∖{0} ⊆ Γ_{κ,β}`. Let `ξ` be an eigenvector with eigenvalue `λ ≠ 0` and phase `u`. Then:
(a) `u` is nilpotent. Precisely, `n₀ := min{n ≥ 2 : nλ ∉ Γ_{κ,β}}` exists and `u^{n₀} = 0`. For
`2 ≤ n < n₀`, `u^nη` is either `0` or an eigenvector with eigenvalue in `Γ_{κ,β}`.
(b′) `u` is not normal: `e = u*u ≠ uu* = q`, both in `M^α`. So `M` is non-abelian.
(c) If `2λ ∉ Γ_{κ,β}`, then `u² = 0`, i.e. `q ⊥ e` in `M^α` (the Pauli rule).
(d) If `M` is abelian, the hypothesis is never satisfied. This recovers round 4's Theorem K(iii) and extends it to
non-singular flows.

*Proof.*
* **`n₀` exists.** Put `α₀ := |κλ| > 0`. Suppose `κnλ + β ∈ Γ` for all `n ≥ 2`.
  * If `κλ > 0`, this says `α₀n + β ∈ Γ` for all `n ≥ 2`.
  * If `κλ < 0`, it says `−α₀n + β ∈ Γ`, i.e. `α₀n − β ∈ Γ` because `Γ = −Γ`.

  Either way, a full vertical AP with real offset lies in `Γ`. This contradicts [LR, Thm 4]: for `α₀ > 0` and every
  real offset, `#{T ≤ n ≤ 2T : ζ(½ + i(α₀n + offset)) ≠ 0} ≥ (⅓ + o(1))T`.
* **(a).** If `u^{n₀}η ≠ 0`, it would be an eigenvector with eigenvalue `n₀λ ≠ 0` outside `Γ_{κ,β}`, which is
  impossible. So `u^{n₀}η = 0`, hence `u^{n₀} = 0` by P(ii), and `u^m = 0` for all `m ≥ n₀`. For `n < n₀`, P(ii)
  gives the stated alternative.
* **(b′).** If `u*u = uu*`, then by P(iv) `u^{n₀}η ≠ 0`, contradicting (a).
* **(c).** Here `n₀ = 2` and P(v) applies.
* **(d).** In the abelian case every partial isometry is normal; use (b′). ∎

*Note.* A first draft also claimed that `λ, …, (n₀−1)λ ∈ σ_p(U)` holds unconditionally, and that `eMe` is
non-abelian. Neither is proved; both were removed. Only (a), (b′), (c) and (d) are claimed.

**Corollary E (no normal invariant functional ⇒ no point spectrum; `PROVED`).**
(a) If `(M, α)` has no nonzero normal `α`-invariant positive functional, then `σ_p(U^{std}) = ∅`. The same holds for
every GNS carrier of such a system, which in fact has none: an invariant state would give such a functional.
(b) **Commutative.** If the non-singular flow `θ` on `(Ω, m)` admits no finite, nonzero, `m`-absolutely continuous
invariant measure, then the half-density Koopman group has empty point spectrum. This holds in particular if `θ` is
ergodic of type II_∞ (the invariant a.c. measure is infinite and unique up to scaling) or of type III, in Krieger's
classification, with any ratio set.
(c) **Every eigenvalue lives on a finite invariant part.** In general, let `E := {ξ ≠ 0}` for an eigenvector `ξ`.
Then `E` carries the finite invariant measure `ν = |ξ|²m`. The map `g ↦ g/|ξ|` is a unitary
`L²(E, m) → L²(E, ν)` that intertwines the half-density Koopman group with the `ν`-measure-preserving Koopman group.
So the eigenvector problem reduces to round 4's measure-preserving setting, on `(E, ν)`.

*Proof.*
* (a) is P(i): `ω_η` would be such a functional.
* (b): normal positive functionals on `L^∞(m)` are the finite a.c. measures, and `α`-invariance of `ω_η` is
  `θ`-invariance of `η²m`. The type statements are the definitions (`CITED` (std.): Krieger; Aaronson, *An
  Introduction to Infinite Ergodic Theory*, Ch. 1). An ergodic type III flow has no σ-finite invariant a.c. measure,
  and an ergodic type II_∞ flow has only infinite ones.
* (c): for `g ∈ L²(E, m)`,
  `U^ν_t(g/|ξ|) = (g∘θ_t)/(|ξ|∘θ_t) = (g∘θ_t)ρ_t^{1/2}/|ξ| = (U_tg)/|ξ|`,
  using `ρ_t^{1/2}|ξ|∘θ_t = |ξ|`. Also `∫|g/|ξ||²dν = ∫|g|²dm`. ∎

## §4 The fermionic residual: Theorem F′, and Proposition B

### 4.1 Theorem F′ (bounded fields) — `PROVED`

*Data.*
* `A` is a C*-algebra, `𝔥` a Hilbert space and `S_t` a strongly continuous unitary group on `𝔥`.
* `c : 𝔥 → A` is linear and bounded (`‖c(f)‖ ≤ C‖f‖`).
* `α_t` is a flow on `A` with `α_t(c(f)) = c(S_tf)`.
* `ω` is any `α`-invariant state, with GNS data `(H_ω, π, Ω, U)`.
* `H_c := cl span{π(c(f))Ω : f ∈ 𝔥}`.

*Claim.* `H_c` is `U`-invariant, and `U|_{H_c}` is unitarily equivalent to `S|_R` for a closed `S`-reducing subspace
`R ⊆ 𝔥`. In particular `σ_p(U|_{H_c}) ⊆ σ_p(S)`, multiplicities do not increase, and the spectral type of `U|_{H_c}`
is absolutely continuous with respect to that of `S`. The same holds for antilinear `c` (annihilators), with `S`
replaced by its conjugate `\bar S` on `\bar𝔥`, which negates the spectrum.

*Proof.*
* **A bounded intertwiner.** Put `Tf := π(c(f))Ω`. Then `T` is linear and `‖Tf‖ ≤ ‖c(f)‖ ≤ C‖f‖`, and
  `U_tTf = π(α_t c(f))Ω = π(c(S_tf))Ω = TS_tf`. So `T ∈ B(𝔥, H_ω)` intertwines `S` and `U`, and its range is dense in
  `H_c`; this also gives the `U`-invariance of `H_c`.
* **`|T|` commutes with `S`.** From `U_tT = TS_t` for all `t`, the adjoint gives `T*U_t = S_tT*` (use `−t`). Hence
  `T*T` commutes with `S_t`, and so does `|T| = (T*T)^{1/2}`.
* **The polar part intertwines.** Write `T = V|T|`, with `V` a partial isometry from `R := cl ran|T| = (ker T)^⊥`
  onto `cl ran T = H_c`. `R` reduces `S`. On `ran|T|`: `U_tV|T|h = TS_th = V|T|S_th = VS_t|T|h`. So `U_tV = VS_t` on
  `R`, by density and boundedness. Hence `V : R → H_c` is a unitary that intertwines `S|_R` with `U|_{H_c}`.
* **Antilinear case.** Apply the above to `f ↦ c(Jf)` on `\bar𝔥`. ∎

**Examples (all `CITED` (std.) for the norm bounds).**
* CAR creators: `‖a*(f)‖ = ‖f‖`.
* Cuntz–Toeplitz (full Fock) creators: `‖ℓ(f)‖ = ‖f‖`.
* `q`-creators, `−1 ≤ q < 1` (Bożejko–Speicher 1991; Bożejko–Kümmerer–Speicher 1997): `‖a_q*(f)‖ = ‖f‖/√(1−q)` for
  `0 ≤ q < 1`, and `= ‖f‖` for `−1 ≤ q ≤ 0`.

In every case the second-quantised flow `α_t(c(f)) = c(S_tf)` exists by functoriality. The **bosonic** case `q = 1`
is excluded: `a*(f)` is unbounded, and the Weyl operators `W(f)` are bounded but not linear.

**Remark F′.1 (what this closes).** Round 4's (F-nqf) asked for a non-quasi-free flow-invariant state on a CAR-type
algebra built from the primes, whose GNS flow has point spectrum `Γ` on a canonically defined sector. For the
canonical degree-one sector, Theorem F′ says the state is irrelevant. The sector is a reducing piece of the
one-particle dynamics, so the zeros must already be eigenvalues of `S` on `𝔥`. That is Hilbert–Pólya one level down,
and Lemma T applies to `(𝔥, S)`. Non-quasi-freeness adds nothing on this sector.

**Remark F′.2 (compatibility with Theorem P).** On a CAR carrier, `a*(e)` for an eigenvector `e` of `S` is an
eigen-operator with `a*(e)² = 0`. This is the nilpotent phase that Cor Z demands. So CAR carriers pass Cor Z, and
Theorem F′ is what then shows the degree-one sector gains nothing.

**Remark F′.3 (the named residual; `OPEN`).**
* *The map.* For `k ≥ 2`, the `k`-linear map `(f₁,…,f_k) ↦ π(c(f₁)⋯c(f_k))Ω` is bounded for the **projective**
  tensor norm. It is not bounded, in general, for the Hilbert tensor norm.
* *Explicit example.* CAR with disjoint pairs, `X = Σ_m c_m a*_{2m}a*_{2m+1}`, evaluated on a product state that
  mixes vacuum and pair at each site. Then `‖XΨ‖ ≳ |Σc_m|/2`, while the Hilbert norm of the coefficient tensor is
  `(Σ|c_m|²)^{1/2}`.
* *Why F′ does not extend.* The polar-decomposition argument therefore fails for `k ≥ 2`. An unbounded invariant form
  can create point spectrum out of continuous one-particle spectrum (Prop B), so no inheritance statement holds a
  priori.
* *The residual.* **Whether a higher sector of a bounded-field system over prime-built one-particle data can carry
  exactly `Γ` is `OPEN`.** There is no candidate, and by Prop B any such sector is governed, in the flow variable, by
  a Bochner measure of its `k`-point function.

### 4.2 Proposition B (creation of point spectrum needs an unbounded form; the form is then Bochner) — `PROVED`, with `CITED` (std.) Bochner–Schwartz

*Setting.* `S` is a unitary flow on `𝔥`, `D ⊆ 𝔥` is a dense `S`-invariant subspace, `B` is a positive `S`-invariant
sesquilinear form on `D`, and `(H_B, U_B)` is its completion with the induced flow.

(a) If `B(f,f) ≤ C‖f‖²`, then `U_B ≅ S|_R` for a reducing `R`. The proof is that of Theorem F′, with `T` the canonical
map `D → H_B`.
(b) Let `𝔥 = L²(ℝ)` with translations and `D = 𝒮(ℝ)`, and let `B` be continuous for the Schwartz topology. Then
`B(f,g) = ∫\overline{f̂(λ)}ĝ(λ)dμ(λ)` for a positive tempered measure `μ`, and `U_B ≅` multiplication by `e^{iλt}` on
`L²(μ)`. So `σ_p(U_B) = {atoms of μ}`, even though `S` has no point spectrum.

*Proof.* (a) is as in F′. (b): `(f,g) ↦ B(f,g)` is a translation-invariant positive continuous form on `𝒮`. So
`B(f,g) = ⟨Tdist, \tilde{\bar f} * g⟩` with `Tdist` a positive-definite tempered distribution, whose Fourier transform
is a positive tempered measure `μ` (Bochner–Schwartz; `CITED` (std.), Gel'fand–Vilenkin IV). Completion and
multiplication form are then immediate. ∎

**Reading (`PROVED` dichotomy, EQUIV in its second branch).** To put the zeros into point spectrum over a prime-built
continuum, `μ` must have atoms exactly at `Γ` on the zero sector, i.e. `μ|_{H¹} = Σ_γ c_γδ_γ`. There are two ways to
define the weights.
* *From the zeros.* Then OT-3 fails.
* *By an explicit formula applied to `w·\bar f̂ ĝ`.* Then its positivity for all `f` is a damped Weil criterion. This
  is round 2's Gaussian-ladder class (RESTATEMENT 5/5), and for `w ≡ 1` it is exactly the Bochner reading of Weil's
  distribution: P46 `thm:Z`; round-4 Cor K.3; Lemma T.

So **Theorem F′ and Prop B together** say:
* bounded fields inherit the one-particle point spectrum (no creation);
* unbounded fields can create point spectrum only through a Bochner measure, which on the zero sector is Weil's.

### 4.3 The ratio-set question (panel R4 salvage), commutative half — `PROVED`

The question (G1_P4_R4 l.87–91 and the other four panelists): can one transverse measure scaled by `e^{−t}` carry
modulus-`p^{−1}` germs at every `p`? Such a lamination would have ratio set `⊇ Q^×_{>0}`, i.e. type III_1.

Cor E answers this for every **function-space** carrier. Take any such space `(S, m)`, with `m = vol_g ⊗ μ` quasi-
invariant, ergodic and properly of type III (any ratio set) or II_∞. Its half-density Koopman group has **no point
spectrum at all** (Cor E(b)). In the non-ergodic case, its eigenvalues live on finite invariant parts, where round 4's
Theorem K (now Cor Z(d)) excludes every zero. So the ratio set is irrelevant for `L²`-function sectors: **no
`L²`-function sector of any Deninger-type lamination or adelic quotient carries even one critical zero as a flow
eigenvalue.**

What is **not** answered: Deninger's `H̄¹` is reduced **leafwise cohomology**, a subquotient of leafwise 1-forms. It is
not a subspace of an `L²` function algebra, and the cup product `H¹ × H¹ → H²` is alternating. Theorem P does not apply
to it. This matches Cor Z: the surviving shape is exterior. The question "is there a type III_1 lamination with
`dim H̄⁰ = dim H̄² = 1`?" stays with G1_B2's residual, `OPEN`, and I make no claim about it.

## §5 The angle's final classification

A candidate from the probabilistic / determinantal angle is a **positive state or covariance**, hence a GNS carrier of
some flow-invariant functional on some (C*- or W*-) algebra built from the primes. By Cor P.1, its zero-carrying
`H¹` is a `U`-invariant subspace of a standard form.

| place of `H¹` | status | proof |
|---|---|---|
| any sector containing an eigenvector with **normal** phase (all commutative carriers, measure-preserving or non-singular, any factor, any entanglement) | **EXCLUDED, unconditional** | Thm P(iv), Cor Z(b′), (d); round-4 Thm K |
| any carrier of a flow with **no normal invariant state** (commutative type II_∞ / III, any ratio set) | **EXCLUDED** (no point spectrum at all) | Cor E |
| degree-one sector of a **bounded-field** system (CAR, Cuntz–Toeplitz, `q ∈ [−1,1)`), **any** invariant state | reduces to the one-particle `(𝔥, S)`, i.e. Lemma T one level down (installation or Λ-spectrum) | Thm F′ |
| linear sector of **unbounded** (bosonic / Gaussian) fields | **EQUIV** (Bochner measure = Weil distribution) | Prop B, round-4 Cor K.3, Lemma T |
| stationary holomorphic RKHS | EXCLUDED (Landau cap) or EQUIV | round-4 Thm S, round-3 Thms 1–3 |
| sector selected by a spectral projection | installation (OT-3 fails) | Lemma T(⇐) |
| **higher sector (`k ≥ 2`) of a bounded-field system with Hilbert-unbounded `k`-point form** | **`OPEN`, no candidate** | Remark F′.3 |
| non-standard (non-unitary, quotient/cokernel) carriers | outside the angle; EQUIV families of record | A17 (Connes), Meyer math/0311468 |

**Necessary condition's N-list (`PROVED`).** Filed as **N-i′ (phase nilpotency)**, superseding my round-4
N-i:
> Realise a zero-carrying flow on a Hilbert space as the GNS space (or standard form) of an invariant state on an
> operator algebra. Then the phase partial isometry of every nontrivial eigenvector is nilpotent. In particular it is
> non-normal, and the algebra is non-commutative on the phase's support (Cor Z). If the flow has no normal invariant
> state, there are no eigenvectors at all (Cor E).

This is consistent with Weil's case (`HEURISTIC` comparison only). There the eigen-objects are classes in `H¹` of an
exterior algebra (`α∧α = 0`). And `B(H¹)`, the minimal operator algebra of a Hilbert–Pólya carrier, has matrix units
`|e_γ⟩⟨e_γ′|` as phases, which are nilpotent for `γ ≠ γ′`. So N-i′ **does not exclude Hilbert–Pólya**. It says only
that the probabilistic positivity (a commutative measure or a quasi-free state) cannot be where the zeros sit.

## §7 What is genuinely new, and what is not

**New at record level (literature novelty `HEURISTIC`):**
1. **Theorem P.** Eigenvector factorisation `ξ = uη` in standard form, for non-ergodic systems, with the exact
  alternative "`nλ ∈ σ_p` or `u^n = 0`". It unifies:
  * round 4's Theorem K (abelian, measure-preserving);
  * its non-singular extension (Example P.2, Cor E(c));
  * the non-commutative case.
2. **Cor Z.** The zeros force nilpotent phases. This makes round 4's `HEURISTIC` exterior/Pauli reading a `PROVED`
  necessary condition (N-i′).
3. **Cor E.** Flows with no normal invariant state have no point spectrum. This gives the commutative-`L²` answer to
  the R4 ratio-set question: ratio set and type are irrelevant, and no `L²`-function sector carries a zero.
4. **Theorem F′ + Prop B.** For any state, bounded fields inherit one-particle spectrum, while unbounded fields create
  point spectrum only through a Bochner measure. This closes round 4's (F-nqf) on the degree-one sector and isolates
  the one remaining sector (Remark F′.3).

**Not new:**
* The standard form, (SF1) and (SF2) (Araki, Connes, Haagerup).
* The ergodic group property (Halmos–von Neumann; the Frobenius theory of arXiv:0911.4434).
* Bochner–Schwartz.
* The norm bounds for CAR, Cuntz–Toeplitz and `q`-creators.
* [LR].
* Prop B(b) is the round-4 Cor K.3 mechanism in statistics-independent form.

**Status for R159_000's success criterion.** No object passes OT-1 ∧ OT-2 ∧ OT-5′ for ζ. The probabilistic /
determinantal angle is closed at the level of the §5 table, except for one sector that is `OPEN` with no candidate:
higher bounded-field sectors with Hilbert-unbounded `k`-point forms. My recommendation is to retire the angle and to
file N-i′ in the N-list.

## §8 Weakest step

1. **(SF1)/(SF2) are `CITED` (std.), not re-derived.** These are uniqueness of the `P^♮`-representative for the
  commutant and the cone-preserving strongly continuous standard implementation. Theorem P(i) rests on the uniqueness
  clause of (SF1), applied to `M′` with the same cone `P^♮`. That is standard (the natural cone of `M′` in `(H, J)`
  is `P^♮`), but I did not re-read Haagerup's proof this phase. In the commutative instance, everything is checked
  directly (Example P.2).
2. **[LR] is load-bearing for Cor Z** (as in round 4). Without it, Cor Z holds only when `σ_p` contains two
  eigenvalues of irrational ratio together with normal phases, a case that is elementary. The sign/offset
  bookkeeping of the AP (§3 proof) uses only `Γ = −Γ` and [LR] for arbitrary real offset.
3. **Two statements were weakened during writing** (Cor Z, Note). The clause `λ, …, (n₀−1)λ ∈ σ_p` and the claim
  that `eMe` is non-abelian are not proved, and were removed.
4. **Scope.** Theorem P needs a standard form, i.e. a unitary flow implementing automorphisms of an operator algebra
  whose GNS space contains the carrier (Cor P.1). Quotient or cokernel carriers (Connes' absorption spectrum, Meyer)
  and leafwise cohomology are outside it. §4.3's answer is therefore only the commutative-`L²` half of the ratio-set
  question.
5. **Remark F′.3 is an honest gap.** Whether a higher bounded-field sector can create exactly `Γ` from continuous
  one-particle spectrum is not decided here.
6. **No positivity statement for ζ is made.** There is no sign to be wrong about.
