## §2 Theorem I: CC's own divisors are on horn (i)

Notation as in G1_B1_R3 §§1–2: `Q = (0,∞)²`, `m_r(x) = rx`, and `𝓠` the set of convex `U` with `U∘m_n − nU` affine for
all `n ∈ N^×`. By Lemma 2.2 of round 3 (`PROVED`; it uses only continuity of convex functions on open sets):

  U(rx) − rU(x) = r log r·(α·x) + β(1−r) for all real r > 0, x ∈ Q, (2.1)

for some `α ∈ R²` and `β ∈ R`.

**Lemma I.1 (`PROVED`).** If `U ∈ 𝓠` is differentiable at `x` and at `rx`, then `∇U(rx) = ∇U(x) + α log r`.

*Proof.* Both sides of (2.1) are differentiable in `x` at such a point. Differentiating gives
`r∇U(rx) − r∇U(x) = r log r·α`. ∎

**Theorem I (`PROVED`).** Let `U ∈ 𝓠`. Suppose one of the following holds:

 (a) *(locally finite PL)* every compact subset of `Q` meets only finitely many maximal domains of affinity of `U`. This
  includes the record's finite-PL sheaf of 107_236 (finite maxima of affine functions, 107_237 l.22–25), with any real
  slopes;
 (b) *(rational slopes)* `∇U(x) ∈ Q²` for a.e. `x`. This includes CC's integral slopes `Z²` (the `Z_max` structure),
  with no finiteness assumption.

Then `α = 0` in (2.1). Consequently `U − β` is 1-homogeneous and `Div U = ∫[L_ρ]dν(ρ)` with `ν ≥ 0`. In case (a) `ν`
is locally finite atomic, with finitely many atoms on each compact `ρ`-interval. In the ray dictionary, `Div U` lies
in `𝓜^ext_+` (G1_B1_R1 Thm B(iv)–(v)).

*Proof.* Convex functions are differentiable off a Lebesgue-null set `N ⊂ Q` (std.). The set
`S := Q_+^* ∩ [1,2]` is countable, so `N' := ⋃_{r∈S} r^{−1}N` is null. Fix `x ∉ N'`. Then `U` is differentiable at `rx`
for every `r ∈ S`, and Lemma I.1 gives

  ∇U(rx) = ∇U(x) + α log r , r ∈ S. (2.2)

(a) The segment `{rx : 1 ≤ r ≤ 2}` is compact in `Q`, so it meets finitely many domains of affinity. Hence `∇U` takes
finitely many values on `{rx : r ∈ S}`. If `α ≠ 0`, the right side of (2.2) takes infinitely many distinct values,
because `r ↦ log r` is injective on the infinite set `S`. So `α = 0`.

(b) Choose `x` also outside the null set where `∇U ∉ Q²`, together with its images `2^{−1}·`, `3^{−1}·`. This is a
countable union of null sets, so it is possible. Apply Lemma I.1 with `r = 2` and `r = 3`. The vectors `α log 2` and
`α log 3` then lie in `Q² − Q² = Q²`. If `α_i ≠ 0`, the quotient `(α_i log 2)/(α_i log 3) = log 2/log 3` is rational.
But `2^q = 3^p` has no solution with `(p,q) ∈ Z² ∖ {0}`. So `α = 0`.

With `α = 0`, (2.1) reads `(U − β)(rx) = r(U − β)(x)`. G1_B1_R1 Thm B(i)–(ii) then gives `U − β = xu(y/x)` with `u`
convex and `Div U = ∫[L_ρ]u''`. In case (a), `u(ρ) = U(1,ρ) − β` is PL with finitely many breaks on every compact
interval, so `u''` is locally finite atomic. Thm B(iv)–(v) places the class in `𝓜^ext_+`. ∎

**Corollary I.2 (`PROVED`, given the imports (X19), (E2), (E3d) of Cor C.1).** On the square of the scaling site with
the record's structure sheaf (finite-PL, any slopes; or `Z_max`-valued), the divisor-level invariant effective cone is
contained in `𝓜^ext_+`. It is therefore the function-level cone of round 1, and the witness class `ℓ_{E_w}` is not in
it (Cor C.1). No `h⁰` with (b′)_ext and (c) exists on it (Cor C.2).

*Proof.* Theorem I and G1_B1_R1 Cors C.1, C.2. ∎

**Remark I.3 (what `α ≠ 0` needs; `PROVED` for the computation).** By (2.2), `α ≠ 0` forces the gradient to grow like
`α·log r` along every ray: `∇U(e^s x) = ∇U(x) + αs`. So the potential has logarithmic slope growth, which is exactly
the smeared rulings `x log x`, `y log y`.

A slope group that contains `log Q_+^*` (the "arithmetic" slopes `Z·log p`) passes test (b) with `α ∈ Z²`. It still
fails test (a), because (2.2) needs a dense set of gradient values on a compact segment. So horn (ii) requires a
potential with infinitely many breaks accumulating on every compact segment. That is a limit of CC's sections, not a
section. Horn (ii) is thus exactly the closure step, and round 3 Thm R shows the closure has **no** salient cone.

**Interpretation (`HEURISTIC`).** The finite structure of CC's square is what keeps it salient, and it is also what
confines it to the measure cone. The closure that admits sum graphs loses salience. Theorem I is the rigorous form of
"the square, as CC define it, has no room between the horns".

## §3 Theorem F: the Riemann–Roch-forced cone

**Setting (P46 §11, as checked in G1_B1_R1 §1).**

* `𝒞 := D^W/𝓝_∞` is the class space, with classes `ℓ_E = I_∞(E,·)`. The form on classes is
  `I(ℓ_E, ℓ_G) := I_∞(E,G)`, well defined because `𝓝_∞` is the radical (Thm 11.11). The degree is
  `deg ℓ_E = I_∞(E,2K)`.
* `e₀ := Φ_·(0)` and `e₁ := Φ_·(1)` are classes (Prop 14.2: `ℓ_{τ_cK} = ½(e^{c/2}e₀ + e^{−c/2}e₁)`).
* `W(F) := −I_∞(F,F)` on primitive real `F`.

**Lemma F.0 (normal form; `PROVED`).** Every real `E ∈ D^W` satisfies `ℓ_E = αe₀ + βe₁ + ℓ_F` with `α = Φ_E(1)`,
`β = Φ_E(0)` and `F ∈ D^W` primitive real. Moreover

  deg ℓ_E = α+β, I(ℓ_E,ℓ_E) = 2αβ − W(F), I_∞(E,K) = ½(α+β),
  R(E) := ½I_∞(E,E) − ½I_∞(E,K) + χ = αβ − ½W(F) − ¼(α+β) + χ, (3.1)

and `ℓ_E(G) = I_∞(F,G)` for every primitive `G`.

*Proof.* Fix `c ≠ 0`. `Φ_{τ_{±c}K}(0) = ½e^{∓c/2}` and `Φ_{τ_{±c}K}(1) = ½e^{±c/2}` (Lemma 11.2(iv), `ξ(0) = ξ(1) = ½`).
The `2×2` system has determinant `¼(e^{c} − e^{−c}) ≠ 0`, so there are real `a, b` with
`F := E − aτ_cK − bτ_{−c}K` primitive. `ℓ_{τ_{±c}K} ∈ span(e₀, e₁)` (Prop 14.2), and comparing values at `Φ(0), Φ(1)`
fixes the coefficients `α = Φ_E(1)`, `β = Φ_E(0)`.

For the form: `I(e_i, e_i) = 0`, `I(e₀, e₁) = 1` and `I(e_i, ℓ_F) = 0`. Indeed, if `e₀ = ℓ_{E₀}` then
`I(e₀, ℓ_G) = Φ_G(0)`, which vanishes on `G = E₀` because `e₀(E₀) = Φ_{E₀}(0) = 0` (from `ℓ_{E₀} = e₀`, the `e₁`-coefficient
of `ℓ_{E₀}` is `Φ_{E₀}(0) = 0`), and on primitive `G`. Similarly for `e₁`. `I_∞(E,K) = ½deg E` is Thm 11.8(i). The last
claim holds because `e_i(G) = 0` for primitive `G`. ∎

**Definitions.** Let `𝔈 ⊆ 𝒞` be a convex cone.

* **(G) gate:** `ℓ ∈ 𝔈 ∖ {0}` implies `deg ℓ > 0` (P46 (21.12), Thm 11.13(i)).
* **(BD) bounded density:** for every primitive real `G ∈ P_c^∞` there is `m_G < ∞` with `|ℓ(G)| ≤ m_G deg ℓ` for all
  `ℓ ∈ 𝔈`. **(BD_frame)** is (BD) with `m_G = C_G` (Thm 11.14(ii)).
* **Adapted `h⁰`:** a function `h⁰ : D^W → R_{≥0}` with **(b′_𝔈)** (`h⁰(E) > 0 ⟹ ℓ_E ∈ 𝔈 ∖ {0}`) and **(c)**
  (P46 (12.1)) for some `χ`. For `𝔈 = 𝓔`, `(b′_𝔈)` is P46's (b′).
* **Forced set:** `𝔉(χ) := {ℓ_E : E ∈ D^W real, deg E > 1, R(E) > 0}`. **Forced cone:**
  `𝔈_F(χ) := 𝓜^ext_+ + cone 𝔉(χ)`, where cone means finite nonnegative combinations.

**Theorem F.**

 (i) *(forcing; `PROVED`)* If `𝔈` satisfies (G) and carries an adapted `h⁰` with constant `χ`, then `𝔉(χ) ⊆ 𝔈`.

 (ii) *(the forced cone is free; `PROVED`, unconditional)* For every `χ`, `𝔈_F(χ)` satisfies (G) and is salient.
  `2K` is positive on it (`I(ℓ,2K) = deg ℓ > 0` for `ℓ ≠ 0`). It contains `𝓜^ext_+ ⊋ 𝓔`, and it contains every
  witness `ℓ_{E_w}` of Cor 19.25b whose parameters satisfy `t²W_F < d²/2 − d/2 + 2χ` with this `χ` (G1_B1_R1 §1).

 (iii) *(BD forces RH; `PROVED`)* If a cone `𝔈 ⊇ 𝔉(χ)` satisfies (BD), then RH holds. (G) is not needed.

 (iv) *(RH gives BD; `PROVED`)* Under RH, `𝔈_F(χ)` satisfies (BD) with
  `m_G = max(C_G, √((½ + 2|χ|)W(G)))`.

 (v) *(the frame's constants fail; `PROVED`, given (X19), (E2), (E3d))* For `χ` large enough to admit a witness,
  `𝔈_F(χ)` violates (BD_frame).

 (vi) *(Thm 12.3 over a cone; `PROVED`)* If `𝔈` satisfies (G) and (BD) and carries an adapted `h⁰`, then RH holds.

 Hence, for each `χ`: **there is a gated cone `⊇ 𝔉(χ)` with (BD) ⟺ RH** (`EQUIV`, by (iii)+(iv)).

*Proof.*

(i) Let `ℓ_E ∈ 𝔉(χ)`. Then `deg ℓ_{K−E} = 1 − deg E < 0`. So `ℓ_{K−E} ≠ 0`, and by (G) `ℓ_{K−E} ∉ 𝔈`. By (b′_𝔈),
`h⁰(K−E) = 0`. Then (c) gives `h⁰(E) ≥ R(E) − h⁰(K−E) = R(E) > 0`, and (b′_𝔈) puts `ℓ_E ∈ 𝔈`.

(ii) Nonzero elements of `𝓜^ext_+` have `deg = ν([−∞,∞]) > 0` (G1_B1_R1 Thm B(v)), and elements of `𝔉(χ)` have
`deg > 1`. A combination `Σc_jℓ_j` with all `c_j > 0` and generators `ℓ_j` of positive degree has degree
`Σc_j deg ℓ_j > 0`. So every element of `𝔈_F(χ)` that is not the empty combination has positive degree, and in
particular is nonzero. This gives (G), and salience: `ℓ, −ℓ ∈ 𝔈_F` forces `deg ℓ > 0` and `deg(−ℓ) > 0`, which is
impossible unless `ℓ = 0`. `2K`-positivity is the same statement. Witnesses: `E_w = tF + dK` has `deg = d > 1` and, by
(3.1) with `α = β = d/2`, `R(E_w) = d²/4 − ½t²W_F − d/4 + χ`. This is `> 0` iff `t²W_F < d²/2 − d/2 + 2χ`, which is
the witness condition. None of this uses RH.

(iii) Suppose RH fails. By P45 Thm 10.4 (as used in G1_B1_R1 Thm E(i)) there is a primitive real `P ∈ P_c^∞` with
`q := I_∞(P,P) > 0`. For `t > 0` put `E_t := tP + 2K ∈ D^W`. Then `deg E_t = 2 > 1`, and by Thm 11.8
(`I_∞(P,K) = 0`, `I_∞(K,K) = ½`) we get `I_∞(E_t,E_t) = t²q + 2` and `I_∞(E_t,K) = 1`. So `R(E_t) = ½t²q + ½ + χ`,
which is `> 0` for `t` large, and `ℓ_{E_t} ∈ 𝔉(χ) ⊆ 𝔈`. But `ℓ_{E_t}(P) = I_∞(E_t,P) = tq` and `deg ℓ_{E_t} = 2`. So
`|ℓ_{E_t}(P)|/deg ℓ_{E_t} = tq/2 → ∞`, and (BD) fails at `G = P`.

(iv) Assume RH. For real primitive `F ∈ D^W`, Thm 11.5 gives `−I_∞(F,F) = Σ_ρ Φ_F(ρ)Φ_F(1−ρ)`. Under RH,
`1 − ρ = ρ̄` and `Φ_F(ρ̄) = \overline{Φ_F(ρ)}` (`F` real). So `W(F) = Σ_ρ|Φ_F(ρ)|² ≥ 0`, with multiplicity and
absolutely convergent by (11.2). Hence `W` is a positive semidefinite quadratic form on real primitive functions, and
Cauchy–Schwarz gives `|I_∞(F,G)| ≤ √(W(F)W(G))`.

Now take a generator `ℓ_E ∈ 𝔉(χ)` in normal form `αe₀ + βe₁ + ℓ_F`. From `R(E) > 0` and `αβ ≤ ((α+β)/2)²` (true for
all reals):

  W(F) < 2αβ − ½(α+β) + 2χ ≤ ½deg² + 2|χ| ≤ (½ + 2|χ|)deg² ,

using `deg > 1` (for `deg > 1` we have `½(α+β) > 0` and `2|χ| ≤ 2|χ|deg²`). By Lemma F.0, for primitive `G`,
`|ℓ_E(G)| = |I_∞(F,G)| ≤ √(½ + 2|χ|)·deg ℓ_E·√W(G)`. On `𝓜^ext_+`, `|ℓ(G)| ≤ C_G deg ℓ` (G1_B1_R1 Thm C). Both bounds
are sublinear-compatible (a sum of elements with `|ℓ_j(G)| ≤ m deg ℓ_j` satisfies it again), which gives (BD) with the
stated `m_G`.

(v) `ℓ_{E_w} ∈ 𝔉(χ)` by (ii). By Thm 19.21 (19.3), `|ℓ_{E_w}(F)| = tW_F`, and the witness choice gives
`tW_F > C_F d = C_F deg ℓ_{E_w}` (G1_B1_R1 Cor C.1).

(vi) By (i), `𝔉(χ) ⊆ 𝔈`. Then (iii) applies. (Equivalently: P46 Thm 12.3 Steps 1–4 run verbatim. Step 1's ampleness of
`F + 2mK` on `𝔈` is (BD) with `m > m_F`, and Step 4 is (G).) ∎

**Corollary F.1 (the forced density constant; `PROVED` under RH, and the lower bound unconditionally).** For
primitive real `G` with `W(G) > 0`,

  lim_{D→∞} sup{ |ℓ(G)|/deg ℓ : ℓ ∈ 𝔉(χ), deg ℓ ≥ D } = √(W(G)/2) .

*Proof.* Lower bound (unconditional): take `ℓ = ℓ_{tG + dK}`. By (3.1) with `α = β = d/2`, `R > 0` iff
`t²W(G) < d²/2 − d/2 + 2χ`. Choose `t` just below `√((d²/2 − d/2 + 2χ)/W(G))`. The ratio is `tW(G)/d`, which tends to
`√(W(G)/2)` as `d → ∞`.

Upper bound (RH): the proof of (iv) gives `W(F) < ½deg² + O(|χ| + deg)`, so
`|ℓ(G)| ≤ √(W(F)W(G)) ≤ (√(½) + o(1))deg·√W(G)`. ∎

This is Thm 19.21 (C4.1) of the record (`C'_F ≥ √(W_F/2)`) together with its sharpness under RH. Lemma 19.25a(v)
(`s_F = C_F√(2/W_F) < 1`) says the frame's constant sits strictly below the forced constant, which is (v) quantified.

**Remark F.2 (why round 3 went wrong).** Round 3 treated "contains a class `≡ E_w` for every witness" as if it were (SG).
It is much weaker. (SG) at `α = β = 0` puts degree-0 classes into the cone, whereas the forced classes all have
`deg > 1`. So containing the witnesses never meets the gate. The information of Thm 12.3 is carried by (BD): the ample
class `F + 2mK` of Step 1, not the gate of Step 4, is where RH enters. Thm E (SG) and Thm F (BD) are two independent
`EQUIV` forms, one per step of Thm 12.3.

## §4 Consequences

### 4.1 Corrected Theorem T′ (replaces round-3 Thm T; `PROVED`)

On the square of the scaling site, with the record's ray dictionary:

 (i) CC's own (finite-PL or `Z_max`) invariant divisors give a cone inside `𝓜^ext_+` (Thm I). (BD_frame) holds there
  (Thm C), and the forced classes are excluded (Cor C.1), so no adapted `h⁰` exists (Cor C.2).
 (ii) The real-convex relaxation (divisor-level, `α ≠ 0` allowed) gives `cl(𝓠_+) = 𝒞` (round-3 Thm R with (A3′), or
  with rational `α`). (G) fails, so neither Thm 12.3 nor Thm F(vi) can start.
 (iii) Any cone on which the Hodge-index transfer runs satisfies (G), (BD) and `⊇ 𝔉(χ)` (Thm F(i),(vi)). Such a cone
  exists iff RH (Thm F(iii),(iv)). Gated salient cones strictly between horns (i) and (ii) exist unconditionally
  (`𝔈_F(χ)`), but by (v) they violate (BD_frame). Without some (BD) they carry no information.

### 4.2 N-c, reworded (`PROVED` as a reformulation; the demand itself is `EQUIV`)

R158_005 §2 N-c should read: *an effective cone containing the Riemann–Roch-forced classes `𝔉(χ)`, satisfying the
gate, with bounded density `m_F < ∞` for every primitive `F`. Necessarily `m_F ≥ √(W_F/2) > C_F` (Cor F.1, Lemma
19.25a(v)).*

Theorem F shows this demand is RH once stated. For a carrier it is therefore not a filter but a restatement of the
target. What a carrier would have to supply is a **reason** for (BD) with those constants that is independent of the
zeros (OT-3/OT-5′). In Weil's `C×C` that reason is geometric: effective divisors meet an ample class positively
because intersections of distinct curves are counts. This is N-a again. Theorem I shows CC's square supplies counts only
on horn (i), where the constants are the frame's.

### 4.3 The `K⋆ψ` trade and CC's null elements (`PROVED` for the tropical computation, `HEURISTIC` as a reading)

Round-3 Remark 4.3 (salvaged by the panel): `ℓ_{K⋆ψ} = ½(Φ_ψ(1)e₀ + Φ_ψ(0)e₁)`, a positive, arbitrarily flat function
carrying only ruling mass. Theorem I locates the trade exactly. It needs the ray density to go negative (round-3
(3.4)), which needs `α ≠ 0`, which needs non-finite-PL potentials. So the trade is invisible in CC's finite sheaf, and
it is what destroys salience in its closure.

Connes–Consani, *The Riemann–Roch strategy, complex lift of the scaling site* (arXiv:1805.10501), leave the tropical
square for a complex lift because of "null elements". I have not re-read that paper this phase (`CITED` as quoted in
R158_001 l.369–370 and by panelist P4_R3). The present computation is a candidate explicit form of those null elements.
The identification is `HEURISTIC`.

### 4.4 The complex-lift question (`OPEN`; not excluded)

Panelist P4_R3 asked whether CC's tropical descent from the complex lift yields a salient cone with an ample class.
Theorem F(ii) answers the literal question **yes, trivially**: such cones exist without any lift. The real question is
whether the lift yields an adapted `h⁰` on a cone with (BD). By Thm F(i),(vi), any such cone contains `𝔉(χ)` and proves
RH. This does **not** exclude the lift (any proof of RH is RH-strength). It fixes what the lift must deliver:

**(L)** a class map from divisors of the complex lift to `𝒞`, and a positivity of their intersections with the ample
classes `F + 2mK`, with `m` of order `√(W_F/2)` rather than `C_F`, proved from the structure of the lift and not from
the zeros.

No record entry and no part of this memo constructs (L). `OPEN`.

## §6 What is genuinely new, and the weakest step

**New.**
* Theorem I: CC's finite-PL / `Z_max` invariant divisors are automatically function-invariant. This settles the
  scope question of the round-3 panel, and it extends 107_237 Thm 2.1 from a single `D_f` to the whole invariant cone.
* Theorem F: the Riemann–Roch-forced cone. It is unconditionally gated and salient and contains the witnesses, and on
  it (BD) is equivalent to RH.
* Cor F.1: the sharp forced density constant `√(W/2)`.
* Remark F.2: the separation of the two steps of Thm 12.3 into two independent `EQUIV` forms, (SG) for Step 4 and (BD)
  for Step 1.
* Corrected T′.

**Not new.** Lemma 2.2 and Theorems Q and R (round 3); G1_B1_R1 Thms B, C, E; P46 Thm 12.3, Thm 19.21, Cor 19.25b;
P45 Thm 10.4.

**Weakest steps.**
1. **Theorem I's scope, i.e. what counts as "CC's own divisors".** I take the record's reading (107_236/107_237: finite
  maxima of affine functions) and, independently, CC's integral slopes. If CC's actual square
  (1507.05818, 1805.10501; not re-read this phase) admits Cartier divisors with **non**-locally-finite breaks **and**
  non-rational slopes, Theorem I does not apply, and horn (ii)'s trivialization (round-3 Thm R) takes over. Either way
  the conclusion "no information-carrying cone" stands, so this is a scope caveat, not a gap in the closure.
2. **(A3′) in Thm T′(ii).** R-homogeneity of the class map. It is natural (`Div(cU) = cDiv U`), and it can be avoided
  entirely by using rational `α` (§1).
3. **Thm F(iii)** uses P45 Thm 10.4 (a failure of RH yields a compactly supported primitive real `P` with
  `I_∞(P,P) > 0`), as G1_B1_R1 Thm E(i) did. This is an import of record, not re-proved here.
4. **The status of Thm F.** It is an equivalence of RH. It closes no route that a genuinely new proof of (BD) could
  take, and such a proof would be (L) of §4.4. Its value is diagnostic: it proves the round-3 intermediate-cone claim
  wrong in the right way, and it pins the RH content of the Riemann–Roch route to Step 1 (ampleness), not to the cone.
