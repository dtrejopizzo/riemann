## §1 Theorem K: flows covariant with Frobenius

**Definition 1.1.** A *covariant system* `(X, U, S, c)` consists of:
* a Banach space `X`;
* a C₀-group `U_t` on `X` whose generator is written `iA` (so `U_t = e^{itA}`, with `A` closed and densely defined);
* bounded **injective** operators `S_n` (`n ∈ N`);
* a real `c ≠ 0`,

such that `U_t S_n = n^{ict} S_n U_t` for all `t ∈ R` and `n ∈ N`.

Examples (`PROVED`, direct checks):
* (BC) `X = ℓ²(N)`, `S_nδ_m = δ_{nm}`, `U_tδ_m = m^{it}δ_m`, `c = 1`. Then
  `U_tS_nU_{−t}δ_m = m^{−it}(nm)^{it}δ_{nm} = n^{it}S_nδ_m`, `A = diag(log m)`.
* Every HWD `(S_n = F_n^†)` of R3 with a unitary group covariant in this sense; in particular BC's `σ_t` in every
  representation where it is spatially implemented. Take `S_n = π(μ_n)` and `U` the implementing group.
* Every Kreĭn HWD (§3) with a J-unitary covariant group. There `S_n` is injective, since `S_n^{[*]}S_n = I`.

**Lemma 1.2** (`PROVED`). For `ψ ∈ Dom(A)` and `n ∈ N`: `S_nψ ∈ Dom(A)` and `AS_nψ = S_n(A + c log n)ψ`.

*Proof.* From covariance, `(U_tS_nψ − S_nψ)/t = S_n(n^{ict}U_tψ − ψ)/t`. As `t → 0`, the right side tends to
`S_n(ic log n·ψ + iAψ)`, because `S_n` is bounded and `ψ ∈ Dom(A)`. So the limit on the left exists. By definition of
the generator, `S_nψ ∈ Dom(A)` and `iAS_nψ = iS_n(A + c log n)ψ`. ∎

**Theorem K** (`PROVED`). Let `(X, U, S, c)` be a covariant system.
(i) *Orbit law.* If `Aψ = λψ` with `ψ ≠ 0`, then `A(S_nψ) = (λ + c log n)S_nψ` and `S_nψ ≠ 0`. `S_n` maps
`ker(A − λ)` injectively into `ker(A − λ − c log n)`, so `m(λ + c log n) ≥ m(λ)` (geometric multiplicities, possibly
infinite). The same holds for generalized eigenspaces `ker(A − λ)^k`.
(ii) *Counting.* If `σ_p(A) ≠ ∅`, then `N_A(R) := #{μ ∈ σ_p(A) : |μ| ≤ R}` (with multiplicity) satisfies
`N_A(R) ≥ ⌊e^{(R − |λ|)/|c|}⌋` for any `λ ∈ σ_p(A)` and all `R ≥ |λ|`.
(iii) *Consequence.* Let `Σ ⊂ C` be any multiset with `#{μ ∈ Σ : |μ| ≤ R} = o(e^{R/|c|})`. Then `σ_p(A) ≠ Σ` unless
`Σ = ∅`, and no `A`-invariant closed subspace `Y` that is also `S`-invariant has `σ_p(A|_Y) = Σ ≠ ∅`. This applies to
every affine image `a + bZ` (`b ≠ 0`) of the multiset `Z` of non-trivial zeros of ζ, since
`#{ρ : |a + bρ| ≤ R} ≪ (R/|b|)log(R/|b|)` (Riemann–von Mangoldt, CITED).
(iv) *Approximate spectrum.* If each `S_n` is bounded below, then `σ_ap(A) + c log N ⊂ σ_ap(A)`.

*Proof.*
(i) Lemma 1.2 with `Aψ = λψ`; `S_n` is injective. For generalized eigenvectors, induct on `k`: `(A − λ − c log n)S_n
= S_n(A − λ)` on `Dom(A)`, and iterating gives `(A − λ − c log n)^kS_n = S_n(A − λ)^k`.
(ii) The points `λ + c log n` for `n = 1, …, ⌊e^{(R−|λ|)/|c|}⌋` are pairwise distinct (since `c ≠ 0` and `log` is
injective). Each satisfies `|λ + c log n| ≤ |λ| + |c| log n ≤ R`. By (i) each is an eigenvalue.
(iii) is immediate from (ii) applied to `A|_Y`: `Y` is invariant under `U` and `S`, so `(Y, U|_Y, S|_Y, c)` is a
covariant system. For the zero count: `|a + bρ| ≤ R` forces `|ρ| ≤ (R + |a|)/|b|`, and
`N(T) = (T/2π)log(T/2π) − T/2π + O(log T)`.
(iv) If `ψ_k` are unit vectors with `(A − λ)ψ_k → 0`, then `(A − λ − c log n)S_nψ_k = S_n(A − λ)ψ_k → 0`, and
`‖S_nψ_k‖ ≥ δ_n > 0`. Normalise. ∎

**Theorem K′ (heat trace; `PROVED`).** Let `X` be Hilbert, `A` self-adjoint and bounded below, `c > 0`, and suppose
`e^{−βA}` is trace class for some `β > 0`. Then for every eigenvalue `λ`: `Tr e^{−βA} ≥ m(λ)e^{−βλ}ζ(cβ)`. In
particular `cβ > 1` is necessary.

*Proof.* `e^{−βA} ≥ 0` is trace class, so `Tr e^{−βA} = Σ_{μ∈σ_p(A)} m(μ)e^{−βμ}`, by the spectral theorem for a
positive compact operator. By (i) the orbit `{λ + c log n}` consists of distinct eigenvalues with multiplicities
`≥ m(λ)`. Hence `Tr ≥ m(λ)Σ_n e^{−β(λ + c log n)} = m(λ)e^{−βλ}ζ(cβ)`. ∎

**Reading** (the implications are `PROVED`; the reading is `HEURISTIC`).
* In R3, Theorem 1 showed that a flow that *extends* the Frobenius lives on the Rosati part, where the spectrum is
  installed.
* Theorem K shows that a flow *covariant* with the Frobenius has a spectrum that is a union of `c log N`-orbits. The
  Verschiebung pushes every eigenvalue along `log N`.
* So the arithmetic of a Witt datum enters a covariant spectrum only as the lattice `log N`, i.e. as the Euler
  product / partition function `ζ(cβ)` (K′). This is BC's phase-transition side, with a pole at `β = 1/c`.

The zeros have counting `≍ R log R`, which is incompatible with any non-empty covariant point spectrum on a
Frobenius-stable carrier. This is the proved form of record A23 ("BC states see `ζ(β)`, `β > 1`, zero-blind").

**Inverse check** (does Theorem K exclude something true?). On Weil's `H¹` of a curve over `F_q`, a covariant flow
`U_tFU_{−t} = q^{ict}F` with `F` invertible would force `dim H¹ = ∞` by (i). So no covariant flow exists there either:
Weil's proof uses an *extending* Frobenius (eigenvalues `q^{1/2}e^{iθ}`, finite-dimensional). Theorem K excludes a
**shape** that Weil's object also lacks. It excludes no true object. ✓

**Falsifier check.** Theorem K proves no positivity, so no falsifier (`Ξ_a`, Epstein, admissible combs) can be
contradicted. It applies verbatim to them: none of their zero sets is a covariant point spectrum. ✓ (It is a
non-existence statement uniform in the zero set, so it is also OT-4-blind. That is fine for a filter and fatal for an
object.)

## §2 Prop K0: degenerate (semidefinite) Rosati forms

**Setting.** `D` is a complex vector space with a positive **semidefinite** Hermitian form `[·,·]` and linear maps
`F_p, S_p` (`S_p := V_p/p`) satisfying (W1)–(W3) of R3 Definition 1.1 on `D`, together with the *form-Rosati relation*
`[F_px, y] = [x, S_py]` for all `x, y ∈ D`. No boundedness is assumed.

**Prop K0** (`PROVED`). Let `N := {x : [x,x] = 0}`.
(i) `N` is the radical `{x : [x, y] = 0 ∀y}`, and `F_pN ⊂ N`, `S_pN ⊂ N`.
(ii) On `D/N`, `S_p` is isometric and `F_p` is contractive for the induced norm. Their continuous extensions to the
Hilbert completion `H := (D/N)^∧` form an HWD in the sense of R3 Definition 1.1.
(iii) Consequently (R3 Theorem 1) the suspendable part of the quotient datum lies in its Rosati part `H_u`. Every vector
of `N` has form-length `0`.

*Proof.*
(i) Cauchy–Schwarz for semidefinite forms: `|[x,y]|² ≤ [x,x][y,y]`, so `N` is the radical. For `x ∈ N` and any `y`:
`[F_px, y] = [x, S_py] = 0`, so `F_px ∈ N`. And `[S_px, S_px] = [F_pS_px, x] = [x, x] = 0` by (W3) (`F_pS_p = I`), so
`S_px ∈ N`.
(ii) The computation just made shows `[S_px, S_px] = [x,x]`. Put `Q_p := S_pF_p`. Then `Q_p² = S_p(F_pS_p)F_p = Q_p`
and `[Q_px, y] = [x, Q_py]`, so `[F_px, F_px] = [Q_px, x] = [Q_px, Q_px]`. By Cauchy–Schwarz,
`[Q_px, Q_px] = [Q_px, x] ≤ [Q_px,Q_px]^{1/2}[x,x]^{1/2}`, hence `[F_px, F_px] ≤ [x,x]`. The maps descend to `D/N` by
(i), are bounded there, and extend to `H`. The relations (W1)–(W3) and `[F_px, y] = [x, S_py]` pass to the limit, and
the last one is (R) with `†` the Hilbert adjoint on `H`.
(iii) R3 Theorem 1 applies to the HWD on `H`. ∎

**Reading.** A degenerate Rosati form is not an escape. Its non-degenerate part is an HWD, where R3 Theorem 1 holds.
Its radical is invisible to the form, so it is exactly where a zero could be installed at no cost and constrained by
nothing (Lemma T, "positivity must be proved, not given").

## §3 Kreĭn–Rosati data: realizability and the Pontryagin bound

**Definition 3.1 (Kreĭn HWD).**
* `(K, [·,·])` is a Kreĭn space with fundamental symmetry `J`, a Hilbert norm `‖·‖_J`, and Kreĭn adjoint `T^{[*]}`.
* The datum is bounded operators `F_p, V_p` satisfying (W1)–(W3) and the Kreĭn–Rosati relation (R_J)
  `V_p = pF_p^{[*]}`.
* `S_n := F_n^{[*]}`, so that `[S_nx, S_ny] = [x, y]`: by (R_J) and (W3), `S_p^{[*]}S_p = F_pF_p^{[*]} = p^{−1}F_pV_p = I`.
* The datum is **J-unitary** if every `S_p` is surjective, hence J-unitary with `F_p = S_p^{−1}`. This is the Kreĭn
  analogue of the Rosati part `H_u`.
* A *suspension* is a C₀-group `T(t)` of J-unitaries with `T(log n) = F_n`.
* Joint eigencharacter: `F_ny = n^{−s}y` for all `n`, with `y ≠ 0`. The exponent `s` is on the line iff `Re s = 0`. (In
  the normalisation of Lemma T, `s = ρ − ½` for `U_t = e^{−t/2}φ^t`.)

The algebra of R3 Lemma 1.2(ii)–(iii) holds verbatim with `†` replaced by `[*]`, because it only used (W1), (W2) and
(R). So `S_nS_m = S_{nm}` and `S_a^{[*]}S_b = S_bS_a^{[*]}` for `(a,b) = 1`.

**Prop K3 (realizability; `PROVED`).** Let `Σ` be a countable multiset in `C` with `Σ = −Σ̄` (the functional-equation
symmetry `ρ ↔ 1 − ρ̄` in this normalisation). Write `Σ = Σ_0 ⊔ Σ_+ ⊔ (−Σ̄_+)`, where `Σ_0 := Σ ∩ iR` and
`Σ_+ := Σ ∩ {Re s > 0}`. Then there is a J-unitary Kreĭn HWD with a suspension whose joint eigencharacters are exactly
`Σ`, with multiplicity. It is built as an orthogonal direct sum of:
* a Hilbert space `ℓ²(Σ_0)` with `T(t)e_s = e^{−st}e_s` (unitary);
* for each `s ∈ Σ_+`, a hyperbolic plane `P_s = span{a_s, b_s}` with `[a_s,a_s] = [b_s,b_s] = 0`, `[a_s, b_s] = 1`,
  and `T(t)a_s = e^{−st}a_s`, `T(t)b_s = e^{s̄t}b_s`, taking the norm `‖·‖_J` in which `a_s, b_s` are orthonormal.

The negative index is `κ = |Σ_+|` (possibly `∞`). If `sup_{s∈Σ_+} Re s < ∞`, each `T(t)` is bounded with
`‖T(t)‖ ≤ e^{|t|·sup Re s}`, and `T` is a C₀-group on `K`.

*Proof.*
*J-unitarity on `P_s`.* `[T(t)a_s, T(t)b_s] = e^{−st}·\overline{e^{s̄t}} = e^{−st}e^{st} = 1 = [a_s, b_s]`, and the
neutral relations are preserved. So `T(t)` is a J-isometry of `P_s` with inverse `T(−t)`, i.e. J-unitary.
*Signature.* `P_s` has signature `(1,1)`: `(a_s ± b_s)/√2` have `[·,·] = ±1`. So the direct sum has negative index
`|Σ_+|`.
*The datum.* Put `F_n := T(log n)` and `S_n := F_n^{[*]} = F_n^{−1}` (J-unitary), `V_p := pS_p`. Then (W1) and (W2)
hold because everything is diagonal. (W3): `F_pV_p = pF_pF_p^{−1} = p`. (R_J) holds by definition.
*Eigencharacters.* `F_na_s = n^{−s}a_s` and `F_nb_s = n^{s̄}b_s = n^{−(−s̄)}b_s`, so `P_s` contributes `{s, −s̄}`. The
diagonal form gives exactly `Σ`, since distinct characters `n ↦ n^{−s}` are linearly independent.
*Boundedness* is read off from the diagonal form. Strong continuity: on finite sums of basis vectors it is clear, and
it extends to `K` by uniform boundedness on compact `t`-sets. ∎

**Theorem K4 (Pontryagin bound; `PROVED` for geometric multiplicity).** Let `(F_p, V_p)` be a J-unitary Kreĭn HWD on a
Pontryagin space `Π_κ` (negative index `κ < ∞`). Let `E_+` be the closed span of all joint eigenvectors with
`Re s > 0`, and `E_−` the same for `Re s < 0`. Then `E_+` and `E_−` are neutral subspaces, so `dim E_± ≤ κ`. Hence at
most `κ` joint eigencharacters (with geometric multiplicity) lie strictly on each side of the line.

*Proof.*
*Neutrality.* Let `F_ny = n^{−s}y` and `F_ny′ = n^{−s′}y′`, with `Re s, Re s′ > 0`. `F_2` is J-unitary, so
`[y, y′] = [F_2y, F_2y′] = 2^{−s−s̄′}[y, y′]`. Since `|2^{−s−s̄′}| = 2^{−Re s − Re s′} < 1`, we get `[y, y′] = 0`. So the
linear span of such eigenvectors is neutral, and by continuity of `[·,·]` so is its closure `E_+`. The same argument
works for `E_−` with `|2^{−s−s̄′}| > 1`.
*Neutral subspaces of `Π_κ` have dimension `≤ κ`.* Let `K = K_+ ⊕ K_−` be a fundamental decomposition, with
`dim K_− = κ`. If `N` is neutral and `x ∈ N ∩ K_+`, then `‖x‖² = [x,x] = 0`. So the projection `N → K_−` along `K_+`
is injective, and `dim N ≤ κ`.
*Counting.* Joint eigenvectors for pairwise distinct characters are linearly independent, so the number of
eigencharacters with `Re s > 0`, counted with geometric multiplicity, is `≤ dim E_+ ≤ κ`. ∎

*Algebraic multiplicities* (`CITED`): Pontryagin's theorem (Pontryagin 1944; Iokhvidov–Kreĭn; Azizov–Iokhvidov,
*Linear Operators in Spaces with an Indefinite Metric*, Wiley 1989). A J-unitary operator on `Π_κ` has at most `κ`
eigenvalues in `|z| < 1` counted with algebraic multiplicity, and there is a `κ`-dimensional maximal non-positive
invariant subspace. Applied to `F_2`, this upgrades K4 to root vectors. I use only the geometric version, which is
proved above.

**Cor K5 (classification of the Kreĭn exit, J-unitary case; the implications are `PROVED`, the classification is
record-based).**
(a) *The form alone constrains only the count.* By K3 and K4, the joint spectra of J-unitary Kreĭn HWDs on `Π_κ` are
**exactly** the `(s ↦ −s̄)`-symmetric multisets with at most `κ` off-line pairs. On a Kreĭn space (`κ = ∞`), every
symmetric multiset with bounded real parts occurs. The Witt relations and the Rosati relation impose nothing beyond the
index.
(b) *For ζ.* Consider any J-unitary Kreĭn HWD whose joint eigencharacters, on a Frobenius-stable carrier, are
`{ρ − ½}` with multiplicity (the analogue of Lemma T's (D2)). It satisfies `#{ρ : Re ρ > ½} ≤ κ`. For `κ = 0` the form
is definite, the datum is R3's Rosati part, and the conclusion is Lemma T(⇒) (Serre). Conversely, K3 builds such a
datum from the zeros for `κ = #{off-line pairs}`. That datum reads the zeros, so it fails OT-3 (Lemma T(⇐)).
(c) *Classification.* A prior definition of a Kreĭn–Rosati datum that did not read the zeros, and whose index could be
computed, would bound the off-line count by that index. Proving the index is `0` is the definite case, i.e. R3/Lemma
T. The record already has this family: phase 16 (de Branges–Pontryagin `H(E_ξ)`, `κ =` off-line count, "proving κ = 0
is RH"), Paper 11 (finite defect), and G1_P1_R3 §7.2 (Lens 1). **So O-B5.3 in the J-unitary case is an equivalent
reformulation (EQUIV family), not an exit.** The new content is only (a): the Witt/Rosati structure is transparent to
the index.

**Falsifier check (`Ξ_a`).** `Ξ_a` has infinitely many zeros on the two lines `Re s = ½ ± a`, hence infinitely many
off-line pairs.
* By K4, no J-unitary Kreĭn HWD on any `Π_κ` with `κ < ∞` carries `Ξ_a`'s zeros as joint eigencharacters.
* By K3, one on a Kreĭn space (`κ = ∞`) does.

So a *finite-index* prior form passes the `Ξ_a` gate automatically. That is consistent with OT-5 of R158_001 (the gate
bites only on the derivation of the form). It proves nothing about ζ, since K4 is a non-existence statement that is
uniform in the zero set. ✓

**Inverse check.** Weil's positive form on `H¹` of a curve is the case `κ = 0`, which is J-unitary with `J = 1`, and K4
gives RH for curves once the form is known to be definite, which is exactly Weil's input (Castelnuovo). ✓

## §5 Why the three remaining exits are not reached, and why that is structural

1. **Quotient carriers.** Theorem K needs `S_n` injective on the carrier. If the zero-carrying space is a quotient
  `X/X′` with `X′` invariant under `U` and `S`, then `S_n` descends, but it may acquire kernel. The orbit
  `λ + c log n` can then die in the quotient.
  * This is precisely the mechanism by which Connes' absorption spectrum escapes the `log N`-lattice: the zeros appear
  in a cokernel of a map built from the Euler/Poisson side.
  * On the record this is EQUIV (the global trace formula is equivalent to RH; R158_003 A17).
  * So Theorem K explains why the only known way to get zeros out of Frobenius covariance is a quotient. `PROVED` as
  the logical contrapositive: the zeros can be a covariant point spectrum only where `S` is not injective.
2. **F-invariant, non-S-invariant carriers (O-B5.4).** On `Y` invariant under `U` and `F` but not `S`, the orbit law
  runs *downwards*: `F_n` maps `ker(A − λ)` to `ker(A − λ + c log n)`, possibly to `0`. There is no lower bound on the
  counting.
  * The instance on (G) is Prop N of R3, i.e. Nyman–Beurling (EQUIV).
  * I have no classification for general HWDs. `OPEN`.
3. **Non-invertible Kreĭn data on `Π_κ` (O-B5.3′).** For a J-isometry `S_p` that is not J-unitary,
  `[F_ny, F_ny′] = [Q_ny, y′]` with `Q_n := S_nF_n` the J-orthogonal projection onto `S_nK`. The neutrality argument of
  K4 fails.
  * The natural conjecture is: `Π_κ` HWD ⟹ suspendable part = (J-unitary part) ⊕ (finite-dimensional part of
  dimension `≤ κ`). Its proof would need a Wold decomposition for doubly commuting J-isometries in `Π_κ` (available
  for a single J-isometry in the Iokhvidov–Kreĭn–Azizov theory, CITED only for that case).
  * Even if true, it lands in K5's classification: the index is the only information.
  * So this exit, if it exists, is of the EQUIV type. `OPEN` (the structure theorem); `HEURISTIC` (that it adds
  nothing beyond `κ`).

## §6 New, open, weakest step

**New** (`PROVED`; 0 corpus hits for these mechanisms):
1. **Theorem K**: the covariant orbit law. On any Frobenius-stable carrier with injective Verschiebung, the point
  spectrum of a Frobenius-covariant flow is a union of `c log N`-orbits with non-decreasing multiplicity. So its
  counting is exponential, and the zeros of ζ (counting `R log R`) are never such a spectrum. Banach-space generality:
  no positivity, no Witt relations, no adjoints are needed.
2. **Theorem K′**: the heat trace of a covariant flow dominates `ζ(cβ)` (the proved form of record A23).
3. **Prop K0**: degenerate Rosati forms reduce to R3's HWDs.
4. **Prop K3 + Theorem K4**: the joint spectra of J-unitary Kreĭn–Rosati data on `Π_κ` are exactly the symmetric
  multisets with at most `κ` off-line pairs. The Witt structure is transparent to the index.
5. **Cor K5**: O-B5.3 (the panel's salvage) is classified as a reformulation inside the record's Pontryagin / de Branges
  family.

**Not new** (corrected per G1_P4_R3):
* R3 Lemma 1.2 is the Laca–Raeburn / Nica-covariant presentation.
* `H_u` is the unitary part of the Wold decomposition for doubly commuting isometries (Słociński; Sarkar).
* The BC–Witt dictionary is Connes–Consani 2014, Borger–de Smit, and Yalkınoğlu.

**Open.**
* O-B5.3′ (non-invertible Kreĭn data on `Π_κ`; §5.3).
* O-B5.4 (`F`-invariant carriers; §5.2).
* O-B5.1′ (archimedean completion from `W(R)`; no candidate).

None of these carries a candidate. Two of them are known to land in EQUIV families if they carry zeros.

**Weakest step.** The scope clause "on a Frobenius-stable carrier" in Theorem K(iii).
* Theorem K is a statement about `S`-invariant subspaces with injective `S`. It says nothing about zero spectra on
  quotients or on merely `F`-invariant subspaces (§5.1, §5.2).
* These are exactly the places where the known equivalences (Connes' cokernel; Nyman–Beurling) live. So the theorem
  does not close them, and it does not claim to.
* In K4, only geometric multiplicities are proved. The algebraic version (Jordan chains) rests on the CITED Pontryagin
  theorem.
* K5(c)'s classification "EQUIV family" is record-based. It relies on the phase-16-surf-witness-variety / Paper-11 identification of `κ`
  with the off-line count, not on a new equivalence proof.

**Status.** Partial new result, negative/structural. The Witt/Borger/BC angle has no remaining exit except the three
labelled ones, each OPEN and without a candidate, two of them inside known EQUIV families. No object, no sign. Row D: no
label.
