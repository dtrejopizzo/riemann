## §2 Theorem A: a countable integral structure cannot carry a continuous flow

**Theorem A (`PROVED`).** Let `V` be a Hausdorff topological vector space, `M ⊂ V` a countable subset, and
`(U_t)_{t∈R}` maps `V → V` with `U_0 = id` and `t ↦ U_t v` continuous for every `v ∈ M`. If `U_t(M) ⊆ M` for all `t`,
then `U_t x = x` for all `x ∈ M` and all `t`.

*Proof.* Fix `x ∈ M` and put `γ(t) = U_t x`. This is a continuous map `R → V` with countable image `γ(R) ⊆ M`. Suppose
`γ(t_1) = y ≠ z = γ(t_2)`. A Hausdorff TVS is completely regular (`CITED` (std.): it is uniformisable). So there is a
continuous `f : V → [0,1]` with `f(y) = 0` and `f(z) = 1`. (If `V` is metrisable, as in every use below, take
`f = min(1, d(·,y)/d(z,y))` and no citation is needed.) Then `f∘γ` is a continuous real function on the interval between
`t_1` and `t_2` that takes the values `0` and `1`. By the intermediate value theorem its image contains `[0,1]`, which is
uncountable, yet the image lies in the countable set `f(M)`. This is a contradiction, so `γ` is constant and equals
`γ(0) = x`. ∎

**Corollary A1 (conformal flows kill FH data; `PROVED`).** Let `Q` be a continuous quadratic form on `V`, and let `(M, ι, h)`
be an FH datum (R1 Def 3.1) with `M` countable and `ι(M)` a subgroup with dense span. Suppose `U_t` is a continuous linear
flow with `U_t ι(M) ⊆ ι(M)` and `Q(U_t v) = e^{ct}Q(v)` for some `c ≠ 0`. Then `Q ≡ 0`.

*Proof.* By Thm A, `U_t` fixes `ι(M)` pointwise, so `Q(ιx) = e^{ct}Q(ιx)` for all `t`, hence `Q(ιx) = 0` for `x ∈ M`.
Since `ι(M)` is a group, `Q` vanishes on `ιx + ιy` too. By polarisation the bilinear form vanishes on `ι(M) × ι(M)`, hence
on the span, hence everywhere by density and continuity. ∎

**Corollary A2 (the translation flow; `PROVED`).** On `L²(R)` (and on `C_c^∞(R)` or `D^W` with any finer Hausdorff vector
topology), the translation flow `τ_t F = F(· − t)` has no nonzero fixed vector: `F = F(· − t)` for all `t` forces `F`
constant, and a constant is `0` in `L²`. So a countable `τ`-stable subset is `{0}`. With the isometric normalisation of
the complete form (`W_T` depends on `F` only through `F ⋆ F̃`, which is translation-invariant), OT-2's flow is a translation.
**No countable integral structure on test functions is stable under the flow of ζ.** This holds whatever the form, since
it is a statement about the carrier.

**Corollary A3 (R1's weakest step closed; `PROVED`).** Let `C/Q` have genus `≥ 1`, and let `V = J(Q̄)⊗_Z R` carry any
Hausdorff vector topology, e.g. the `ĥ`-norm. Let `U_t` be any flow on `V` with `t ↦ U_t v` continuous and `U_t` preserving
the image `M` of `J(Q̄)`. Then `U_t = id` on `M`, and on `V` if `U_t` is linear.

*Proof.* `Q̄` is countable, and `J(Q̄) = ∪_K J(K)` is a countable union of finitely generated groups (Mordell–Weil), so
it is countable, and so is its image `M`. Apply Thm A. `M` spans `V`, so linearity extends the conclusion. ∎

**Reading (`HEURISTIC`; the dichotomy).** In Weil's proof the Frobenius is **one** map `π` acting on the Mordell–Weil group
(R1 Thm 2.1(iii)). For ζ, OT-2 demands a continuous flow, because the orbit lengths `log p` are infinitely generated (C5).
Thm A says a continuous flow and a countable group of Frobenius points exclude each other. There are two horns:
* **(A)** The integral structure is stable only under a countable subgroup `G ⊂ R`, for example `G = log Q_{>0}`. On test
  spaces the compatibility is then automatic (translation invariance), and the whole content is positivity on `M`, which is
  E1 (R1 Cor 3.3).
* **(B)** The Frobenius is realised as a discrete commuting family on an arithmetic lattice. Example E shows that this
  exists in infinite rank and carries nothing.

Horn (A) is where R1's (Q-FH) lives, and Theorem C removes its only arithmetic reading.

## §3 Example E: a conformal family for every prime, and why it carries nothing

**Construction (`PROVED`).**
* `K_∞ := Q(√−p : p prime) ⊂ C`, with `√−p := i√p`. It is the union of the finite multiquadratic fields
  `K_S = Q(√−p : p ∈ S)`.
* `c` is complex conjugation on `K_∞`. It maps `√−p` to `−√−p`.
* `τ : K_∞ → Q` is the normalised trace, `τ(α) = [K:Q]^{−1} Tr_{K/Q}(α)` for any finite `K ∋ α`. It is well defined by
  transitivity of traces.
* The form is `⟨x, y⟩ := τ(x·c(y))`, and `φ_p :=` multiplication by `√−p`.

**Proposition E1 (`PROVED`).**
* (i) `⟨ , ⟩` is a positive definite symmetric `Q`-bilinear form on `K_∞`.
* (ii) The `φ_p` commute pairwise and satisfy `⟨φ_p x, φ_p y⟩ = p⟨x, y⟩` for **every** prime `p`, so `φ_p^†φ_p = p`.
* (iii) Consequently R1 Lemma 4.4 fails without its finite-dimensionality hypothesis, and that hypothesis is sharp.

*Proof.* (i) Each `K_S` (`S ≠ ∅`) is CM:
* every embedding sends `√−p` to `±√−p`, so no embedding is real;
* `K_S^+ = K_S^c` is generated by the products `√−p√−q = −√(pq)` and by `p`, all of which are real in every embedding;
* `c` is central in the abelian group `Gal(K_S/Q)`, so `σ(c(x)) = \overline{σ(x)}` for every embedding `σ`.

Hence `Tr(x c(x)) = Σ_σ |σ(x)|² > 0` for `x ≠ 0`. Symmetry holds because `τ(x c(y))` is fixed by `c` and so is rational,
and `τ∘c = τ`.

(ii) `√−p·c(√−p) = √−p·(−√−p) = p`. Commutativity is clear.

(iii) `K_∞` realises `φ_p^†φ_p = p` for all `p` on an infinite-dimensional polarised `Q`-space. Geometrically, the CM
abelian varieties `A_S = C^{g_S}/Φ_S(O_{K_S})`, with compatible induced CM types, form an ind-system with CM by `K_∞`.
(`CITED` (std.), Shimura–Taniyama. It is used only for this reading; the proposition is the algebraic statement.) ∎

**Proposition E2 (the Lefschetz numbers and their Dirichlet series; `PROVED`).** For `n = Π p^{k_p}`, put
`φ_n := Π φ_p^{k_p}`. Then:
* (i) `τ(φ_n) = λ(m)·m` if `n = m²`, and `τ(φ_n) = 0` otherwise, where `λ` is Liouville's function;
* (ii) `Σ_{n≥1} τ(φ_n) n^{−s} = ζ(4s−2)/ζ(2s−1)` for `Re s > 1`. The right side is meromorphic, with a pole at every `s`
  with `2s − 1 = ρ` a zero of ζ.

*Proof.* (i) `φ_n = Π_p (−p)^{⌊k_p/2⌋} · Π_{k_p odd} √−p`. If `S' = {p : k_p odd} ≠ ∅`, then `β = Π_{p∈S'}√−p` satisfies
`β² = Π_{p∈S'}(−p) =: d`, which is not a rational square because `|d| > 1` is squarefree. So `Q(β)` is quadratic,
`Tr_{Q(β)/Q}(β) = 0`, and `τ(φ_n) = (rational)·τ(β) = 0`. If `S' = ∅`, then `n = m²` and
`φ_n = Π(−p)^{k_p/2} = (−1)^{Ω(m)} m`.
(ii) By (i) the series equals `Σ_m λ(m) m^{1−2s} = ζ(2w)/ζ(w)` with `w = 2s − 1` (`CITED` (std.)), valid for `Re w > 1`. ∎

**Proposition E3 (the positivity is zero-blind and prime-blind; `PROVED`).** Put `u_q := q^{−1/2}φ_q` for `q ∈ Q_{>0}`,
using `φ_p^{−1} = p^{−1}c(√−p)·`. This is a unitary representation of `Q_{>0} ≅ Z^{(∞)}` on the Hilbert completion `H` of
`K_∞ ⊗_Q C`.
* (i) `u_p² = −1`, so `spec(u_p) ⊆ {±i}` for every `p`. The spectrum does not depend on `p`.
* (ii) The matrix coefficient `ω(q) := ⟨u_q 1, 1⟩` equals `E_ε[χ_ε(q)]`, where `χ_ε(p) := ε_p i` and `ε` is Haar-distributed
  on `{±1}^{primes}`. So `ω` is the Fourier transform of a probability measure on the dual of `Q_{>0}`, and it is positive
  definite for a structural reason.
* (iii) For **any** completely multiplicative unimodular `f`, the function `q ↦ f(√q)·1[q ∈ Q_{>0}^2]` is positive definite
  on `Q_{>0}`. This includes `f = λχ` for a Dirichlet character `χ`, and `λ` altered at finitely many primes. Its Dirichlet
  series (`L(2w,χ²)/L(w,χ)` for `f = λχ`) has the zeros of `L(w,χ)` among its poles, or, for the altered `λ`, ζ's zeros
  together with extra poles on `Re w = 0`.

*Proof.* (i) `(√−p/√p)² = −1`. (ii) `E[Π_p(ε_p i)^{k_p}] = Π_p i^{k_p}E[ε_p^{k_p}]`, which is `0` unless every `k_p` is
even and is `Π(−1)^{k_p/2} = λ(√q)` otherwise. This equals `q^{−1/2}τ(φ_q) = ω(q)` by E2(i), extended to `Q_{>0}` by the
same computation. (iii) Replace `ε_p i` by `ε_p f(p)^{1/2}` for a fixed square root. The same computation gives
`f(√q)` on squares and `0` off them. An average of characters is positive definite (Bochner, finite version). ∎

**Consequence (`PROVED` for the facts; the verdicts are inspection).**
* Example E is a carrier with a positive form defined before any spectrum and a proved conformal Frobenius for every
  prime. ζ's zeros even appear in its Lefschetz Dirichlet series.
* Its positivity nonetheless decides nothing about those zeros. It holds verbatim for twisted and modified `f` whose series
  have other poles (E3(iii)), so **OT-4 fails**, of type C16.
* The zeros enter as **poles of a matrix-coefficient Dirichlet series**, not as the spectrum of a flow generator (E3(i)).
  The primes enter through the conformal factors `p`, but the unitarised spectrum `{±i}` forgets them. **OT-2 fails**
  (no `m(τ)`, no `Λ(n)/√n`, no polar pair; C11).
* This is the panel's conservation law (G1_P1 §8; G1_P5 item 1) in its extreme form: here positivity is free, and the
  object carries no content about ζ at all.

## §4 Theorem C: integrality over `Spec Z̄` is an input class closed under deletion

**Setting (`CITED` (std.): Arakelov; Szpiro; Neukirch Ch. III §1).**
* `\hat{Div}(Spec Z̄) = ⊕_p Z·[p] ⊕ R·[∞]`.
* `\hat{deg}(Σ n_p[p] + λ[∞]) = Σ n_p log p + λ`.
* `\hat{div}(r) = Σ_p v_p(r)[p] − log|r|·[∞]` has degree `0` (product formula).
* `Eff = {n_p ≥ 0 ∀p, λ ≥ 0}`. For a hermitian line bundle `(L, ‖·‖)` of rank one over `Z` and `0 ≠ s ∈ L`:
  `\hat{deg} = log #(L/Zs) − log‖s‖`, and the effective sections give `\hat{deg} ≥ 0`.

**Proposition C1 (`PROVED`, elementary).** The dual cone of `Eff`, meaning the linear functionals on finitely supported
divisors that are `≥ 0` on `Eff`, is `{Σ α_p n_p + βλ : α_p ≥ 0, β ≥ 0}`. Every inequality obtained from effectivity is
therefore a nonnegative combination of the coordinate inequalities `n_p ≥ 0` and `λ ≥ 0`, one place at a time. The only
global relation is the product formula, which is an equality.

*Proof.* `Eff` is the product of the half-lines spanned by the basis vectors, and the dual of a product of half-lines is
the product of the dual half-lines. ∎

**Definition C2.** `𝒞_int := {a : N_{≥2} → R_{≥0} : a(n) = 0` unless `n = p^k`, and `a(p^k) ∈ Z_{≥0}·log p}`. It is the set
of prime weights that arise as `\hat{deg}` of effective finite divisors, one per prime power. `Λ ∈ 𝒞_int`.

**Theorem C (`PROVED` as a method constraint; it applies `cor:void`).**
* (i) `𝒞_int` is closed under deletion of finitely many terms, and it contains `Λ + k·log2·1_{n=2}` for every `k ∈ N`.
* (ii) So for every `T > ½log2` some `a ∈ 𝒞_int` fails `RD_T(a)` (primitive form). For that `a`, also `λ^W_T(a) < 0`
  (complete form), because `λ^W_T(a) ≤ λ_min(A_T(a)|P_T)` (P47 l.1292).
* (iii) In the schema of P46 Thm 18.1(ii) and `cor:void`: a derivation of `RD_T` or of `λ^W_T ≥ 0` whose only prime input
  is `Λ ∈ 𝒞_int`, together with any archimedean data, which is shared by every comb, proves a false statement. So no such
  derivation exists at any window `T > ½log2`.

*Proof.* (i) Deleting terms keeps the values in `{0} ∪ Z_{≥0}·log p`. Adding `k log 2` at `n = 2` keeps `a(2) ∈ Z_{≥0}·log 2`.
(ii) Deletion: `thm:finmod`(i) with `N ≥ max(5, e^{2T})` covers every `T ≥ 0.60`. Amplification: `thm:finmod`(ii) with `n_0 = 2` gives `c_*(T, 2) < ∞` for every `T > ½log2`, and
`c = k log 2 > c_*` for `k` large. The complete-form inequality is the one recorded at P47 l.1292. (iii) is the argument of
`cor:void`, verbatim. ∎

**Remark 4.1 (what Thm C does and does not exclude; `HEURISTIC` as a reading, the scope `PROVED`).**
* It **excludes** reading (Q-FH) of R1 §3 as "`W(ιx) = Σ_p n_p(x) log p + a(x) + (≥0)` with `n_p` lengths", **whenever
  the proof that `n_p ≥ 0` and `a ≥ −C` uses Λ only through `𝒞_int`**. That is R1 Rem 3.4 made into a theorem.
* It does **not** exclude a construction in which the lengths are computed by a structure that pins `a(p^k) = log p`
  **with multiplicity exactly one at every prime power**. But then the arithmetic input is `{Λ}` itself, i.e. the Euler
  product, and integrality contributes nothing beyond `a ≥ 0` (A8), which C13 and C14 already show to be insufficient.
* Factorial-ratio (Chebyshev–Landau) integrality is the same phenomenon. Take `Φ(x) = Σ c_j⌊α_j x⌋ ≥ 0` with `Σ c_jα_j = 0`.
  Integrality of `Π((α_jN)!)^{c_j}` gives `Σ_n Λ(n)Φ(N/n) ≥ 0`, which already follows from `Λ ≥ 0`. The information sits
  in the **identity** `Λ * 1 = log` together with Stirling. That identity uses `⌊x⌋`, the additive structure of `Z`
  (§28.4 clause (5)), and belongs to G2 (mechanisms), not to an FH object. (`PROVED` for the implication; the Diamond–Erdős
  limits of Chebyshev's method are `CITED` (std.), not re-read.)

**Remark 4.3 (compatibility with G1_B5_R1).** B5's Theorem B gets `Γ_1·Γ_n = Λ(n)` from the ghost geometry of `W^*(Spec Z)`.
That is a structure pinning multiplicity one, the second bullet of Rem 4.1, so Thm C does not bind it. What Thm C says to
B5 is this: the positivity step must not use the lengths only as elements of `Z_{≥0}·log p`.

## §5 Proposition D: genus 0 has no Hermitian global term

**Proposition D (`PROVED`).** Let `h_W` be the absolute logarithmic Weil height on `Q̄^×`.
* (i) For every `h = h_W + O(1)`: `lim_k h(x^{2^k})/4^k = 0`. So the Tate quadratic canonical height of `(G_m, [2])` is
  identically `0`.
* (ii) The linear canonical height `h_W` (with `h_W(x^n) = |n|h_W(x)`) is a norm on `Q^×/{±1} ⊗ Q` that does **not** come
  from an inner product.

*Proof.* (i) `h(x^{2^k}) = 2^k h_W(x) + O(1)`, and dividing by `4^k` gives `0`.
(ii) `h_W(a/b) = log max(|a|,|b|)` for coprime `a, b`. The parallelogram law fails at `x = 2`, `y = 3`:
* `h_W(6)² + h_W(2/3)² = (log 6)² + (log 3)² = 4.41735…`;
* `2h_W(2)² + 2h_W(3)² = 2(log 2)² + 2(log 3)² = 3.37480…`.

(Allcock–Vaaler, Acta Arith. 136 (2009), realise `h_W` as the `L¹`-norm on a hyperplane of `L¹(Y, λ)`; `CITED`, not needed
for the proof.) ∎

**Consequence.** On `G_m`, the one carrier with a conformal-by-degree family for all `n` (R1 §4.5), the FH global term is
either `0` (quadratic) or an `L¹` norm (linear). There is no Hermitian square, so **OT-8 fails**. The Hermitian global terms
of Faltings–Hriljac come from the theorem of the cube, i.e. from abelian varieties. Those are finite-dimensional (R1
Lemma 4.4, Prop 4.2), or infinite-dimensional and blind to the primes (Example E).

* `W(ιx) ≥ −C` on `M` is proved from a structure that pins exact `Λ` (Thm C) and uses the functional equation (C11)?

By Thm A, `M` cannot be stable under the continuous flow. By Thm C, the proof cannot be integrality alone. By Prop D and
Example E, it cannot be a genus-0 height or a discrete conformal family. I do not know such an `M`, and I do not claim
that one exists.

## §7 What is genuinely new

1. **Thm A with Cors A1–A3.** A countable integral structure is fixed pointwise by any continuous flow. So FH data are
  incompatible with a conformal flow, and `J(Q̄)⊗R` admits no flow that preserves the Mordell–Weil group. This closes R1's
  weakest step and gives the flow/discrete dichotomy of the FH angle.
2. **Example E.** A positive definite, conformal-for-every-prime Frobenius family on `K_∞ = Q(√−p : p)`. It shows that R1
  Lemma 4.4 is sharp. Its Lefschetz series is `ζ(4s−2)/ζ(2s−1)`, and its positivity is a structural Bochner positivity
  that is blind to the zeros (E3). This is a clean counterexample to the idea that "ζ appears in the Lefschetz series of a
  positive conformal object" carries any information.
3. **Thm C.** Arakelov integrality on `Spec Z̄` supplies only the class `𝒞_int`, which is closed under deletion and
  excluded by `cor:void` at every `T > ½log2`, in both forms.
4. **Prop D.** An elementary proof that genus 0 has no Hermitian FH term.

None of these is a sign. None reopens row D.

## §8 Weakest step

* **Theorem C is a method constraint of schema type.** Its force depends on reading "only prime input is `𝒞_int`
  membership" correctly (Rem 4.1). A construction that computes lengths *and* pins multiplicity one escapes it by design.
  Thm C then says only that the pinning, not the integrality, carries the content.
* **Example E(iii)** (the ind-CM-abelian-variety reading) rests on Shimura–Taniyama, which was not re-read. Everything used
  in the verdict is the algebraic Prop E1–E3.
* **Thm A** needs `t ↦ U_t x` continuous for the topology in which `M` is considered. For a flow that is continuous only in
  a topology in which `M` is not countable-discrete-like, Thm A still applies, because it uses only countability and
  Hausdorffness. It does not apply to flows that fail to preserve `M`, and that is horn (A), left as (Q-FH′).
* The angle is closed. Any continuation would be (Q-FH′), which is RH-strength.
