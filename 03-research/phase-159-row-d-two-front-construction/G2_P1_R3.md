## 2. Step-by-step check of the load-bearing chain

### 2.1 Lemma L (Laplace criterion). **PROVED; I re-derived it.** Content: von Koch–Landau (classical), as the memo says.

* Step 1. `θ` has bounded derivatives of every order (`θ′` has compact support), so `θ` multiplies `𝒮′`. So
  `θv, θβ ∈ 𝒮′` with support in `[0.1,∞)`. For `Re s > 0`, `χe^{−s·} ∈ 𝒮`, and it depends holomorphically on `s` in `𝒮`.
  So `ℒ` is holomorphic on `Re s > 0` (CITED, Schwartz Ch. VIII; Hörmander I §7.4). **OK.**
* Step 2, the weakest step flagged by the memo. Write `P := (−∂²+¼)^k`. Then `θPw = Pθw + [θ,P]w`. The commutator has
  coefficients built from `θ^{(j)}`, `j ≥ 1`, which are supported in `[0.1,0.5]`. So `r` is a compactly supported
  distribution and `ℒr` is entire. **OK.**
  It follows that `P(θu_Λ) = θv + P(θβ) − r ∈ 𝒮′`, although `θu_Λ` itself is not known to be tempered. The memo then
  writes `⟨P(θu_Λ), χe^{−s·}⟩ = ⟨θu_Λ, P(χe^{−s·})⟩`. That step pairs a distribution that may not be tempered with a
  non-compactly supported test, and the memo does not justify it. **Gap: routine, and repaired here (PROVED).** Take
  `Re s = σ > ½` and `ψ := χe^{−s·}`, and truncate with `ψ_R := ψ·χ_1(·/R)`.
  * `ψ_R → ψ` in `𝒮`, so `⟨P(θu_Λ), ψ_R⟩ → ⟨P(θu_Λ), ψ⟩`, because `P(θu_Λ)` is tempered.
  * `ψ_R` has compact support, so `⟨P(θu_Λ), ψ_R⟩ = ⟨θu_Λ, Pψ_R⟩`.
  * `Pψ_R = χ_1(·/R)Pψ + E_R`, where `|E_R| ≤ C_k R^{−1}(1+|s|)^{2k}e^{−σu}` and `E_R` is supported in `[R, 2R]`.
  * `θu_Λ` is a measure with `∫e^{−σu}d|θu_Λ| < ∞`, since `σ > ½`. So `⟨θu_Λ, E_R⟩ → 0`, and
  `⟨θu_Λ, χ_1(·/R)Pψ⟩ → ∫Pψ d(θu_Λ)` by dominated convergence.
  * `Pψ = (¼ − s²)^k ψ + (terms supported in [0.02,0.05])`, and `θ = 0` there.

  This gives the displayed identity of step 2. For `θβ` no truncation is needed, since `θβ ∈ 𝒮′`. The constants
  `0.02 < 0.05 < 0.1 < 0.5 < log 2` are consistent. **OK after this repair.**
* Step 3. `ℒ` of the comb part is `−Σ Λ(n)n^{−½−s} = (ζ′/ζ)(½+s)` for `Re s > ½`. The polar part is
  `∫_{0.5}^∞(e^{u/2}+e^{−u/2})e^{−su}du = e^{−(s−½)/2}/(s−½) + e^{−(s+½)/2}/(s+½)`. The archimedean part
  `A(s)` is holomorphic on `Re s > −½`, since `K = O(e^{−u/2})` and `θ` vanishes near 0. **OK.**
* Step 4. Solving for `ℒ(θu_Λ)` gives a meromorphic continuation of `(ζ′/ζ)(½+s)` to `Re s > 0`, with a pole only at
  `s = ½`. So ζ has no zero in `Re w > ½`, and by the FE none in `Re w < ½`. **OK.** Uniqueness of meromorphic
  continuation is used implicitly, and that is fine.
* Converse. Under RH, Weil's criterion together with Bochner–Schwartz gives `u_Λ ∈ 𝒮′` (CITED). This is equivalent to
  the Guinand–Weil formula `û_Λ = 2πμ_Λ` with `μ_Λ` of polynomial growth. **OK.**

### 2.2 Theorem N(i) (robust converse). **PROVED; primitive (k = 2) and complete (k = 0) forms.**

* For `G ∈ C_c^∞`, `F := (−∂²+¼)G` satisfies `A(F) = B(F) = 0` by two integrations by parts. So `F ∈ P_T` once
  `supp G ⊂ I_T`, and every `G` qualifies for `T` large. Only this trivial direction of Lemma 1.3 is load-bearing.
* `c_F = P²(G⋆G̃)`, because the operator is even and has constant coefficients. The bound `λ^A_T(a) ≥ −C` for all `T`
  gives `⟨P²(u_a + Cδ), G⋆G̃⟩ ≥ 0`. Lemma 1.2 (the odd part is annihilated by an even distribution) then gives Bochner
  positive definiteness, so the distribution is tempered (CITED, Schwartz). Lemma L with `k = 2` gives RH. **OK.**
* Cosmetic: "`a = Λ − β` with `β := −β_b`" has a sign slip. The correct statement is `u_{Λ+b} = u_Λ − β_b`, from
  Lemma 1.1. It is immaterial, because Lemma L allows any tempered `β`.
* Uniformity in `T` of the constant `C` is essential and is part of the hypothesis. **OK.**
* Novelty caveat, which the memo already makes in Remark 2.1. "Weil form bounded below ⟹ RH" is a known robustness
  of Weil's criterion: shift by `Cδ`, which gives positive definite, hence tempered, hence Landau. What is new is only the
  primitive form via `P²`, together with the tempered slack. I accept "new to the corpus", not "new to the literature".

### 2.3 Theorem N(ii) (rigid arrow under RH).

This is R2 Theorem R. It was verified 5/5 in round 2, and I re-checked the core. Under RH,
`FT(u_{Λ+b}) = 2πμ_Λ − D_b`. Positivity together with `|D_b|(Γ_ζ) = 0` gives `D_b ≤ 0`. So `−β_b` is positive definite
and vanishes on `(−log 2, log 2)`. Then `∫|φ̂|² d(−D_b) = 0` for every `φ` supported in `(−½log2, ½log2)`. Since `|φ̂|²`
vanishes only on a discrete set, and two such `φ` can be chosen with disjoint zero sets, `D_b = 0` and so `b = 0`. The
primitive case uses the Fourier multiplier `(τ²+¼)²`, which does not vanish on ℝ. **OK (CITED R2, re-checked).**

### 2.5 Remark 3.4, "PROVED part". **REFUTED (the argument is invalid). Not load-bearing.**

The memo argues as follows: `β_b = εu_Λ − σ̌` with `σ ≥ 0` tempered. Off `±log ℕ` this forces
`σ̌ = ε(k_∞ + 2cosh(u/2))`, and "`2cosh(u/2)` is not tempered while `σ̌` is: contradiction".

The inference is false. Agreement with a non-tempered function on the *open complement of `±log ℕ`* does not contradict
temperedness. The gaps `(log n, log(n+1))` have length `≍ 1/n`, so the test functions they admit have seminorms
`≍ n^j`. Those seminorms dominate `e^{u/2} = n^{1/2}`.

There is an explicit counterexample to the inference pattern. Under RH, `σ̌ := εu_Λ` (that is, `σ = ε·2πμ_Λ ≥ 0`) is
tempered by Lemma L's converse. It equals `ε(k_∞ + 2cosh(u/2))` off `±log ℕ ∪ {0}`. So the argument would "prove" that
`u_Λ` is not tempered, which contradicts the memo's own Lemma L.

The argument never uses the only hypothesis that separates the proportional case from `b = 0`, namely
`σ ⊥ μ_Λ` (σ is the negative part). Two further points:

* For `b ∈ ℓ¹_w`, and more generally for `b ∈ 𝒯_meas`, the proportional case is impossible for a trivial reason: `D_b`
  has no atoms, or charges no ordinate.
* So the remark concerns only `b ∈ 𝒯 ∖ 𝒯_meas`, and there its status is **OPEN**, not PROVED.

**Required fix:** relabel Remark 3.4 OPEN, or supply an argument that uses `σ ⊥ μ_Λ`.

## 3. Lens 1: circularity and RH-equivalence

* **Circularity (iii): none in the dishonest sense.** RH, meaning the atomic spectral measure `μ_Λ`, enters only in
  N(ii). N(ii) is used only to prove that something *fails* (R′(i)) or to describe the RH branch. That is legitimate
  for an obstruction theorem.
* **Genuine new implication (i): none toward the target.** G2 asks for an argument "exact Λ ⟹ ∀T λ^A_T ≥ 0". The
  memo proves the converse direction in a robust form, plus an obstruction. Neither yields the target.
* **Equivalent reformulation (ii): the mechanism content.**
  * Theorem N(iii) is `RH ⟺ (Λ+ℓ¹_w)∩𝒮^A ≠ ∅ ⟺ ∃ a ∈ Λ+𝒯 : inf_T λ^A_T(a) > −∞`.
  * The first equivalence is Weil's criterion in primitive form (P45 Thm 10.4 / Bombieri 2000 Thm 1), since the set
  is `{Λ}` or `∅`.
  * The second is Weil's criterion made robust by von Koch–Landau: growth, that is temperedness.
  * The §4 reduction "FE ⟹ ∀T positivity on {ζ}" is RH itself. It rests on Hamburger rigidity (CITED via G2_B3_R2).
  * **EQUIVALENT (Weil / von Koch–Landau).** The memo reports this honestly.
* **Filters.**
  * F1: Theorem R′ is the strongest form of F1, and it is a filter, not a mechanism.
  * O3 (`rem:resweights`): R′ is its unconditional `T = ∞` limit, with zero tolerance, consistent with the record.
  * `cor:void` / `thm:finmod`: R′ fails for the modified combs, as required. That is exactly what it says.
  * `thm:margin`, `thm:finZ`, `thm:arena`: none is violated.

  Passing the filters is necessary, not sufficient. No positivity argument is present.
