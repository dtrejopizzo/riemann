## §0 Verdict

**No mechanism. Status: partial new result (an obstruction), not a sign.** Nothing below gives `λ^W_T ≥ 0` or
`λ^A_T ≥ 0` for any `T > 0.8`.

Door 3 has a canonical SOS realisation. Every windowed Toeplitz SOS is a flat-top certificate `h_T = f_{w_T}` (S2). A
"uniform-in-`T` formula" in this language is then a family of weights `w_T` given by one `T`-free rule. The most natural
rule keeps the flat top and attaches a **fixed edge profile** `φ` beyond `±2T`. With `φ(v) = e^{−εv}`, `ε > ½`, this
gives the Riesz-type certificates
`f_{T,ε}(τ) = C_0 + ∫(1−w cos τu)K − Σ_{n≥2} v_n min(1,(e^{2T}/n)^ε) cos(τ log n) + 2∫ w cosh(u/2) cos(τu) du`.
They use the exact `Λ(n)` for **all** `n`, with no truncation and no margin. Their zero-side identity holds for every
zero exactly because `0 < β < 1`: `β > 0` comes from the functional equation and `β < 1` from the Euler product. This
is the load-bearing FE line the panel asked for.

**Theorem R (PROVED, unconditional).** No fixed edge profile, and no family of profiles that converges, certifies
`W_T ≥ 0` for all large `T`. Under RH the failure recurs with bounded gaps. The reason is structural. For a fixed
profile, `T ↦ f_{w_T}(τ)` is a Bohr almost-periodic function with Bohr spectrum `{±2(τ−γ)}` and **mean zero**, so it
takes negative values. The `T`-dependence of any `T`-uniform formula of this kind is thus an oscillation at the zero
frequencies. A surviving certificate must use its `T`-dependence to cancel every `e^{2iTγ}`, which means it must
encode the ordinates (HEURISTIC reading of a PROVED statement).

This is the SOS form of W15 and `thm:margin`, obtained without computation. It is also the precise sense in which the
 "series equation valid for all `T`" cannot be a fixed formula: it must vary with `T` at the zero frequencies.

## §2 Repairs of round 1

### Lemma P (primitive temperedness; PROVED)

Let `P = {F ∈ C_c^∞(ℝ): M_+(F) = M_−(F) = 0}`, where `M_±(F) = ∫F e^{±t/2}`. There are constants `c, C_N > 0` with the
following property. For every `a ∈ ℝ` with `|a| ≥ A_0` there is `χ_a ∈ P` such that:
* `supp χ_a ⊂ [−1, 8]`;
* `|χ̂_a| ≥ c` on `[a−1,a+1]`;
* `‖χ_a^{(N)}‖_∞ ≤ C_N(1+|a|)^N`.

Moreover, for every compact `K ⊂ ℝ` there are `F_1,…,F_r ∈ P` with `Σ_j|F̂_j|² ≥ c_K > 0` on `K`.

*Proof.*
1. **Base bump.** Fix a real `χ ≥ 0`, `χ ≢ 0`, with `supp χ ⊂ (−1,1)`. For `|ξ| ≤ 1`,
  `Re χ̂(ξ) ≥ cos(1)∫χ =: 2c`.
2. **Correction bumps.** Fix real `ψ_1, ψ_2 ≥ 0`, not identically zero, with supports in `(3,5)` and `(6,8)`. The
  matrix `M = (M_±(ψ_j))` has determinant
  `∫∫ψ_1(s)ψ_2(t)(e^{(s−t)/2} − e^{(t−s)/2}) ds dt < 0`,
  because `t > s` on the supports. So `M` is invertible.
3. **Definition.** Put `χ_a = χe^{−iat} − αψ_1 − βψ_2`, with `(α,β)ᵀ = M^{−1}(M_±(χe^{−iat}))ᵀ`. Then `χ_a ∈ P`.
  Since `|M_±(χe^{−iat})| ≤ e^{1/2}∫χ`, the coefficients satisfy `|α|,|β| ≤ C`, uniformly in `a`.
4. **Lower bound.** `χ̂_a(ξ) = χ̂(ξ−a) − αψ̂_1(ξ) − βψ̂_2(ξ)`. On `[a−1,a+1]` the first term has modulus `≥ 2c`, and
  `|ψ̂_j(ξ)| ≤ C_M(1+|ξ|)^{−M} ≤ C_M|a|^{−M}` for `|a| ≥ 2`. Choose `A_0` so that `2C·C_M A_0^{−M} ≤ c`.
5. **Derivative bounds.** These are immediate from the product rule.
6. **The compact case.** For each `ξ_0` the functional `F ↦ F̂(ξ_0) = ∫F e^{iξ_0t}` is not a combination of `M_±`
  (the functions `e^{iξ_0t}` and `e^{±t/2}` are linearly independent). So some `F ∈ P` has `F̂(ξ_0) ≠ 0`, and by
  continuity `|F̂| > 0` near `ξ_0`. Cover `K` by finitely many such neighbourhoods. ∎

**Use in S1(c), primitive case.** Let `σ ≥ 0` satisfy `W(F) = ∫|F̂|²dσ` on `P`. The compact case of Lemma P makes `σ`
locally finite: `σ(K) ≤ c_K^{−1}Σ_jW(F_j)`. For `|a| ≥ A_0` the functions `c_{χ_a}` are supported in `[−9,9]`, with
`C^N`-norms `≪ (1+|a|)^N`. Since `g` has finite order `N` on `[−9,9]`,
`σ([a−1,a+1]) ≤ c^{−2}|⟨g, c_{χ_a}⟩| ≪ (1+|a|)^{N}`. So `σ` is tempered.

In the uniqueness step, fix `G ∈ P` and put `ν = σ − μ_Z`. The tempered distribution `S` with
`⟨S,F⟩ = ∫F̂ \bar{Ĝ} dν` vanishes on `P`, the common kernel of `M_±`. Hence `S = αe^{t/2} + βe^{−t/2}`, which is tempered
only if `α = β = 0`. Then `∫F̂ d(\bar{Ĝ}ν) = 0` for all `F ∈ C_c^∞`, and `\mathcal F(C_c^∞)` is dense in `𝒮`, so
`\bar{Ĝ}ν = 0`. Finish as in round 1. This closes the gap P1–P5 flagged. ∎

## §3 Door 3 in SOS form: edge-profile certificates

### 3.1 Why this is the right family

By S2, a windowed Toeplitz SOS certificate of `W_T` is a nonnegative `h_T` with `ȟ_T = g` on `(−2T,2T)`. By
`thm:Zexh(i)` it is, up to an arbitrarily small uniform error, `h_T = f_{w}` for some `w ∈ 𝒲_T`, with `√h_T` free. The
**only** free datum is the weight outside the window. So "an SOS family built from Λ(n) by one rule for all `T`" means
"a rule `T ↦ w_T`". The most rigid rule that respects the flat top is a fixed edge profile.

**Definition 3.1 (admissible profile; edge-profile weight).** An *admissible profile* is a function
`φ: [0,∞) → ℝ` with the following properties:
* `φ(0) = 1`;
* `φ` is absolutely continuous, and `φ′` has locally bounded variation;
* for some `δ > 0`, the norm `N_δ(φ) := sup_v e^{(½+δ)v}(|φ(v)| + |φ′(v)|) + ∫_0^∞ e^{(½+δ)v}|dφ′|(v)` is finite.

The *edge-profile weight* is `w^φ_T(u) = 1` for `|u| ≤ 2T` and `w^φ_T(u) = φ(|u|−2T)` for `|u| > 2T`. Then
`w^φ_T ∈ 𝒲_T`. Examples:
* `φ_ε(v) = e^{−εv}` with `ε > ½` (Riesz / exponential type);
* compactly supported `C²` profiles with `φ(0) = 1`.

Put `Φ_1(z) := ∫_0^∞ φ′(v)e^{izv}dv` and `Ψ(z) := iΦ_1(z)/z`. Both are holomorphic in `Im z > −(½+δ)`, except for the
simple pole of `Ψ` at `0`, where `Φ_1(0) = −1`.

**Lemma 3.2 (the transform; PROVED).** For real `x ≠ 0`, `ŵ^φ_T(x) = 2 Re[e^{2iTx}Ψ(x)]`. For `|Im z| ≤ ½ + δ/2`
and `|z| ≥ 1`:
* `|ŵ^φ_T(z)| ≤ C e^{2T|Im z|}N_δ(φ)|z|^{−2}`;
* `|Ψ(z)| ≤ C N_δ(φ)|z|^{−2}`.

For `φ_ε`: `ŵ_T(x) = (2ε/(ε²+x²))[cos 2Tx + (ε/x) sin 2Tx]`, and `ŵ_T(0) = 4T + 2/ε`.

*Proof.* `ŵ_T(x) = 2 sin(2Tx)/x + 2Re[e^{2iTx}Φ(x)]` with `Φ(x) = ∫_0^∞φ e^{ixv}dv`. Integration by parts gives
`Φ = i/x + iΦ_1/x`, and `2 sin(2Tx)/x = 2Re[e^{2iTx}(−i/x)]`, so the `±i/x` terms cancel. A second integration by
parts gives `Φ_1(z) = −φ′(0^+)/(iz) − (iz)^{−1}∫e^{izv}dφ′`, which is `O(N_δ/|z|)` in the strip. The bound on `ŵ` in the
strip follows from `ŵ(z) = −z^{−2}∫e^{izu}d(w′)(u)`, where `w′` has a jump `φ′(0^+)` at `±2T` and is weighted by
`e^{|Im z||u|}`. For `φ_ε`: `Φ_1 = −ε/(ε−ix)`. ∎

**Lemma Z′ (zero side for edge profiles; PROVED).** For every admissible `φ`, every `T > 0` and every `τ ∈ ℝ`,
`f_{w^φ_T}(τ) = Σ_ρ ŵ^φ_T(τ − γ_ρ)`, where `ρ = ½ + iγ_ρ` and the sum over all non-trivial zeros is absolutely
convergent. The function `f_{w^φ_T}` is given by eq:fw.

*Proof.* Let `h(u) = w(u)cos(τu)` and `h_k = (hχ(·/k)) ⋆ η_{1/k}`, where `χ ∈ C_c^∞` equals `1` near `0` and `η_{1/k}`
is a standard mollifier. Each `h_k` is even and in `C_c^∞`, so the explicit formula in the form used in the proof of
`thm:Z(ii)` holds for `h_k` (CITED: Weil 1952; IK Thm 5.12). Pass to `k → ∞` term by term.
* **Zero side.** `(hχ(·/k))″` is a measure whose `e^{(½+δ/2)|u|}`-weighted total variation is bounded uniformly in
  `k`. So `|ĥ_k(z)| ≤ C_τ(1+|z|)^{−2}` on `|Im z| ≤ ½`, uniformly in `k`, and `|η̂(z/k)| ≤ e^{1/2}`. Moreover
  `ĥ_k → ĥ` pointwise, and `Σ_ρ(1+|γ_ρ|)^{−2} < ∞` because `|Im γ_ρ| < ½` and `N(t) ≪ t log t`. Dominated
  convergence applies.
* **Prime side.** `|h_k(u)| ≤ Ce^{−(½+δ)|u|}` uniformly, and `h_k → h` pointwise because `h` is continuous. Dominated
  convergence applies against `Σ v_n e^{−(½+δ)log n} < ∞`.
* **Polar side.** Dominated by `∫e^{−(½+δ)|u|}cosh(u/2)du`.
* **Archimedean side.** Written as `C_0h_k(0) + ∫_0^∞(h_k(0) − h_k(u))K(u)du`, dominated by
  `min(2 sup|h_k|, u sup|h_k′|)K(u)`, both sups being uniformly bounded.

The limit of the right side is eq:fw by `thm:Z(i)`. ∎

**Proposition F (door-3 reading; PROVED).**

(i) For every admissible `φ`, `f_{w^φ_T}` is an **exact, untruncated** prime-side expression:
`Σ_{n≥2} v_n w^φ_T(log n) cos(τ log n)`, over all `n`, absolutely convergent. For `φ_ε` the weights are
`min(1,(e^{2T}/n)^ε)`, which are Riesz-type means.

(ii) `f_{w^φ_T} ≥ c` on `ℝ` implies `W_T ≥ c‖·‖²` on `L²(I_T)`. This is `(ν_w, 2, 0)` dual feasible (def:W),
together with prop:weak and prop:P. **[compl]**

(iii) The identity of Lemma Z′ needs the zero set in the strip `|Im γ_ρ| < ½ + δ` where `ŵ` is holomorphic. That
`|Im γ_ρ| < ½`, i.e. `0 < β < 1`, uses two inputs.
* **A7:** the Euler product and non-vanishing on `σ = 1` give `β < 1`.
* **A3:** the functional equation gives `β > 0` and the symmetry `γ ↦ −γ` used to fold the sum.

For the Beurling falsifiers, the comb side is defined but the zero-side identity has no FE-symmetric Hadamard
structure. For Davenport–Heilbronn, zeros with `β > 1` fall outside the strip whenever `δ < β − 1`, so the identity
fails. This is the load-bearing FE line: it is used, not merely available. It gives no sign.

(iv) As `ε → ∞`, `w^{φ_ε}_T → 1_{[−2T,2T]}`. This is sharp truncation, the prime side is the finite sum over `𝒩_T`,
and it is excluded by `thm:arena` / `prop:finite`. As `ε ↓ ½` the prime series ceases to converge absolutely. So the
family runs between the two excluded ends. *Proof:* direct from Lemma 3.2 and eq:fw. ∎

## §4 Theorem R: no fixed edge profile certifies all large windows

**Theorem R (PROVED).** **[compl]** Let `φ` be an admissible profile.

(a) *(Unconditional.)* There are arbitrarily large `T` such that `inf_τ f_{w^φ_T}(τ) < 0`. So the family `(w^φ_T)_T`
is not a certificate family for `W_T ≥ 0` on any half-line `[T_0,∞)`.

(b) *(Under RH, with quantitative recurrence.)* There are `η > 0` and `L > 0`, depending on `φ`, such that every
interval of length `L` in `(0,∞)` contains a `T` with `inf_τ f_{w^φ_T} ≤ −η`.

*Proof.*
**Case ¬RH.** By Weil's criterion (P47 §1) there is `T_1` with `λ^W_{T_1} < 0`. By `lem:monoT`, `λ^W_T < 0` for every
`T ≥ T_1`. By Prop. F(ii), `inf f_{w^φ_T} ≤ λ^W_T < 0` for every `T ≥ T_1`. This gives (a).

**Case RH.** All `γ_ρ` are real. Let `Ord` be the set of distinct ordinates, with multiplicities `m_γ`. Fix `τ` in the
co-countable set
`E := ℝ ∖ (Ord ∪ ½(Ord + Ord))`.

*Step 1 (almost periodicity in `T`).* By Lemmas Z′ and 3.2, and using `2Re z = z + \bar z`,

`G_τ(T) := f_{w^φ_T}(τ) = Σ_{γ∈Ord} m_γ [Ψ(τ−γ)e^{2iT(τ−γ)} + \overline{Ψ(τ−γ)}e^{−2iT(τ−γ)}]`.

Since `τ ∉ Ord`, `d_τ := min_γ|τ−γ| > 0`. We have `|Ψ(x)| ≤ C N_δ(φ)|x|^{−2}` for `|x| ≥ 1`, and
`|Ψ(x)| ≤ N_δ(φ)/d_τ` for the finitely many `γ` with `|x| < 1`. So the series converges absolutely and **uniformly in
`T ∈ ℝ`**, because `Σ_γ m_γ(1+|τ−γ|)^{−2} < ∞`. Hence `G_τ` is a uniform limit of trigonometric polynomials, i.e. a
Bohr almost-periodic function on `ℝ` (CITED: Besicovitch, *Almost Periodic Functions*, Ch. I).

*Step 2 (the Bohr coefficients).* The exponents are `±2(τ−γ)`, none of which is `0` because `τ ∉ Ord`. Two exponents
from different ordinates coincide only if `2(τ−γ) = −2(τ−γ′)`, i.e. `τ = (γ+γ′)/2`, which `τ ∈ E` excludes. So the
Bohr coefficient of `G_τ` at `2(τ−γ)` is exactly `m_γΨ(τ−γ)`, and the mean value is `M(G_τ) = 0`.

*Step 3 (nonnegativity on a half-line forces `G_τ ≡ 0`).* Suppose `G_τ ≥ 0` on `[T_0,∞)`. For `T ∈ ℝ` and `κ > 0` there
is a `κ`-almost period `p ≥ T_0 − T`, since almost periods are relatively dense in both directions. Then
`G_τ(T) ≥ G_τ(T+p) − κ ≥ −κ`, so `G_τ ≥ 0` on `ℝ`. Now suppose `G_τ(T_2) = 2c > 0`. Then `G_τ ≥ c` on an interval `J`
of length `2r` around `T_2`. By the same recurrence, `G_τ ≥ c/2` on translates of `J` whose gaps are bounded by some
`L`. This gives `M(G_τ) ≥ cr/L > 0`, a contradiction. So `G_τ ≡ 0`, and all its Bohr coefficients vanish:
`Ψ(τ−γ) = 0` for every `γ ∈ Ord`.

*Step 4 (contradiction).* Suppose the family certified `W_T ≥ 0` for all `T ≥ T_0`. Then Step 3 applies to every
`τ ∈ E`, and in particular `Ψ(τ − γ_1) = 0` for all `τ ∈ E`. The set `E − γ_1` is dense and `Ψ` is continuous on
`ℝ∖{0}`, so `Ψ ≡ 0` there. Hence `Φ_1 ≡ 0` on `ℝ`. By Fourier uniqueness in `L¹`, `φ′ = 0` a.e., so `φ ≡ φ(0) = 1`,
which contradicts `N_δ(φ) < ∞`. This proves (a) under RH.

*Step 5 (the recurrence in (b)).* By Step 4 there is some `τ_* ∈ E` with `G_{τ_*} ≢ 0`. By Steps 2–3, `G_{τ_*}` is
negative somewhere, say `G_{τ_*}(T_3) = −2η`. By almost periodicity, the set `{T : G_{τ_*}(T) ≤ −η}` contains a
neighbourhood of `T_3 + p` for every `η`-almost period `p`, and these are relatively dense. Intersect with `(0,∞)`. ∎

**Corollary R2 (convergent profile families; PROVED).** **[compl]** Let `φ_T` be admissible with a common `δ` and
`N_δ(φ_T − φ_∞) → 0` as `T → ∞`, where `φ_∞` is admissible. Then there are arbitrarily large `T` with
`inf f_{w^{φ_T}_T} < 0`.

*Proof.* Under ¬RH, as in Theorem R. Under RH, fix `τ_*, η` for `φ_∞` as in Step 5. The map `φ ↦ G^φ_{τ_*}(T)` is
linear, and by the bounds of Step 1 it satisfies `|G^{φ}_{τ_*}(T) − G^{φ′}_{τ_*}(T)| ≤ C_{τ_*}N_δ(φ−φ′)`,
uniformly in `T`. For `T` large, `C_{τ_*}N_δ(φ_T − φ_∞) < η/2`. Pick such `T` in the relatively dense set where
`G^{φ_∞}_{τ_*}(T) ≤ −η`. ∎

**Remark R3 (zero-tuning; PROVED necessity, OPEN existence).** At the single point `τ = 0` (not in `E`, since `0` is
the midpoint of `±γ`), the frequencies `2γ` and `−2(−γ)` merge. The argument then gives
`G_0(T) = 4Σ_{γ>0}m_γ Re[Ψ(γ)e^{2iTγ}]`. So `f_{w^φ_T}(0) ≥ 0` for all large `T` **forces**
`Φ_1(γ) = ∫_0^∞φ′(v)e^{iγv}dv = 0` at every ordinate. A profile tuned to `τ = 0` must have the ordinates in the zero
set of the Fourier transform of its edge derivative, i.e. it must be built from the zeros. The Blaschke condition on
`Φ_1(z − ia/2)` in the upper half-plane is `Σ_γ 1/γ² < ∞`, which holds, so there is no complex-analytic obstruction to
such profiles. Whether an admissible zero-tuned profile exists is OPEN. By Theorem R, even a zero-tuned profile fails at
generic `τ`.

**Open question Q-R.**
1. Does Theorem R extend to compact families `𝒦` of profiles, with `φ_T ∈ 𝒦` chosen freely for each `T`? The max over
  `𝒦` of mean-zero a.p. functions need not change sign, so Step 3 does not transfer.
2. Does it extend to profiles scaled with `T`, `w_T(u) = φ(|u|/2T)`? Those are not a.p. in `T`.

Both are OPEN. A positive answer to (1) for a `𝒦` containing the optimisers of `thm:Zexh` would be a proof that RH
fails, which is not expected. So (1) must fail for large enough `𝒦` under RH (cor:RH), and the interesting question is
the size of the threshold.

| F3 no truncation (`thm:arena`, `thm:finZ`), not termwise (`lem:Rrig`) | No truncation: `φ_ε` sums over all `n`. `ŵ` is signed (`lem:Rrig`), and `ŵ_T(x)` has negative lobes `−2ε/(ε²+x²)` at `cos 2Tx = −1`, `sin 2Tx = 0`. |
| F4 not Beurling-generic | Theorem R holds for every datum whose zero-side identity has a real, symmetric Bohr spectrum. As an **obstruction** it is meant to be generic. |
| F5 not `h⁰`, not Deligne | not applicable |
| O3 (`rem:resweights`) | Theorem R is exact (a.p. identity plus mean zero), not an estimate |
| OT-5′ (G1) | Remark R3: surviving at `τ = 0` needs the profile to annihilate the ordinates, i.e. zero-input. This is the SOS-side shadow of OT-5′. |
| twist test (P2/P4 round-1 demand) | Under a complex twist the zero side changes, and Lemma Z′ fails when the strip condition fails (`L_2`: zeros and poles on `Re s = 0`). The obstruction depends only on the structure `f = Σ ŵ(τ−γ)`, so it is twist-robust in the direction of an obstruction. |

**Excluded as a mechanism**, by its own Theorem R: the angle's natural uniform family fails. The SOS angle is now
closed on every branch of record:
* covariant: S1;
* windowed with free weight: S2 = problem (D), EQUIV;
* algebraic: S3;
* uniform edge-profile families, including the Riesz/FE door-3 family: Theorem R, Cor. R2.

The remaining branch is the free, `T`-dependent choice of `w_T` (Q-R(1)). That is exactly `thm:Zexh` / `cor:RH`, i.e.
EQUIV.

## §6 What is genuinely new

1. **Theorem R and Corollary R2** (PROVED, unconditional in (a)). The window parameter `T` enters any fixed-shape
  certificate through `e^{2iTγ}`. For a fixed profile, `T ↦ f_{w_T}(τ)` is a mean-zero Bohr a.p. function whose
  spectrum is `2(τ − Ord)`. So no `T`-independent rule of edge type certifies all large windows, and under RH it fails
  with bounded gaps at a fixed depth `η`. To our knowledge this is the first theorem of record about the "for all `T`"
  arrow of a *formula* rather than of a class of combs. It says that a uniform arrow must carry the zero frequencies
  in its `T`-dependence.
2. **Lemma Z′.** The zero-side identity `thm:Z(ii)` for rough, exponentially-tailed flat-top weights. It fills the gap
  between `𝒲_T` and `𝒲^{reg}_T` in P47.
3. **Prop. F(iii).** An explicit load-bearing FE line: the Riesz-type certificates are valid on all zeros precisely
  because `0 < β < 1` (A3 + A7).
4. **Lemma P.** The primitive temperedness of S1, completed. **Correction to S3(a)** (`V_n`, non-prime-powers).
5. **Remark R3.** A "zero-tuned" necessary condition that quantifies how a surviving profile must depend on the zeros.

Not new: Bohr / Besicovitch theory, Weil's criterion, `lem:monoT`, the explicit formula.

## §7 Weakest step

* **Lemma Z′, dominated convergence on the zero side.** The uniform bound `|ĥ_k(z)| ≤ C(1+|z|)^{−2}` on `|Im z| ≤ ½`
  uses the uniform weighted total variation of `(hχ(·/k))″`. The cutoff contributes `h′χ′/k + hχ″/k²`, which is fine,
  and the kinks of `w` at `±2T` contribute atoms of `h″` with fixed mass `φ′(0^+)`. This is standard, but it is the
  one analytic step not already in P47. The citation "IK Thm 5.12" is for the explicit formula on `C_c^∞` tests. The
  P47 `thm:Z(ii)` proof uses the same reference, and I did not re-verify its exact hypotheses.
* **Scope of Theorem R.** It excludes fixed and convergent profiles only. A `T`-dependent profile chosen from a compact
  family is not covered (Q-R(1)). Under RH, `cor:RH` guarantees that *some* `T`-dependent choice works. So the theorem
  cannot be pushed to "all families", and it is an obstruction to uniform formulas, not to certificates.
* **[prim] is not covered.** The primitive multipliers `β_0ĝ_0 + β_1ĝ_1` grow like `e^T` and are not a.p. in `T`.
  Theorem R is a statement about the complete form only, and `λ^W_T ≤ λ^A_T` means that failure of complete
  certificates says nothing about the primitive sign.
