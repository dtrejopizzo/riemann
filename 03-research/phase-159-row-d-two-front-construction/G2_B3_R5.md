## §1 Setting (P46 l.113–146; as in G2_B3_R4 §1, which the R4 panel checked)

`I_T = (−T,T)`, `F̂(τ) = ∫F e^{iτt}`, `c_F(y) = ∫F(t)\overline{F(t−y)}dt`, `v_n = 2Λ(n)/√n`, `A(F) = ∫Fe^{t/2}`,
`B(F) = ∫Fe^{−t/2}`, `P_T = {A = B = 0}`. The archimedean form is `arch(F) := (2π)^{−1}∫m|F̂|²`, with
`m(τ) = Re ψ(¼+iτ/2) − log π` and `m ≥ m(0) = C_0 = −5.3721…`. The prime form is
`comb(F) := Σ_{n∈𝒩_T} v_n Re c_F(log n)`. Then `𝔞_T = arch − comb` on `P_T` and `W_T = arch − comb + 2Re(AB̄)` on
`L²(I_T)`. With `u := k_∞ + 2cosh(y/2) − comb_T`, where `k_∞ = m̌` and
`comb_T := Σ_{n∈𝒩_T} Λ(n)n^{−½}(δ_{log n} + δ_{−log n})`, one has `W_T(F) = ⟨u, c_F⟩` for `F ∈ C_c^∞(I_T)`, and
`𝔞_T(F) = ⟨u, c_F⟩` on `P_T` (the polar pairing is `⟨2cosh(y/2), c_F⟩ = 2Re A(F)\overline{B(F)} = 0` there).
All of this is PROVED in R4 §1. Write `λ^{∞,P}(T) := inf{arch(F)/‖F‖² : 0 ≠ F ∈ P_T}` and
`λ^∞(T) := inf{(arch + 2Re AB̄)(F)/‖F‖² : 0 ≠ F ∈ L²(I_T)}`. These are R155_023's `λ^{∞,P}_min` and `λ^∞_min`.
`C_c^∞` is a form core in both cases (P46 thm:KEP2 proof; `prop:finite`).

**The two kernel classes.** Both are distributions on `(−2T, 2T)`.
* `𝒜_T` (arithmetic): real, even, **purely atomic** Radon measures, i.e. measures carried by a countable set, for
  example by `log ℚ_{>0}`.
* `ℳ_T` (archimedean): even distributions whose restriction to the punctured window `(−2T,2T)∖{0}` is a function in
  `L¹_loc`.

*Why these are the right classes.* A Dirichlet-convolution operator `(D_aF)(t) = Σ_{q∈ℚ_{>0}} a(q)q^{−½}F(t − log q)`
has `‖D_aF‖² = ⟨κ_a, c_F⟩` with `κ_a = Σ_{q,q′} a(q)\overline{a(q′)}(qq′)^{−½}δ_{log(q/q′)}`, which lies in `𝒜_T`. This is
the only way an exact identity among arithmetic functions (Vaughan, Heath-Brown, `Λ·log + Λ∗Λ = μ∗log²`, `Λ = μ∗log`,
Selberg's `(Σ_{d|n}λ_d)²`) can enter a Hermitian form on the window. Sums of such squares, and scalars `cδ_0`, stay in
`𝒜_T`. An archimedean multiplier square `F ↦ (2π)^{−1}∫|h|²|F̂|²` with `|h|² − c` having inverse Fourier transform in
`L¹_loc` off 0 has kernel in `ℳ_T`. Examples are `|h|² = m + C`, the Lévy pieces of G2_B8_R4, and the Gamma factors.
So does the polar function `2cosh(y/2)`, and so does `k_∞`, since `k_∞(y) = −e^{−|y|/2}/(1 − e^{−2|y|})` off 0
(R4 Lemma 1).

**Definition (separated decomposition).** A *primitive separated decomposition at `T`* is a triple
`(κ_ar, κ_∞, ν)` with `κ_ar ∈ 𝒜_T`, `κ_∞ ∈ ℳ_T` and `ν ∈ 𝒩_T^P := {ν : ⟨ν, c_F⟩ = 0 ∀F ∈ P_T ∩ C_c^∞(I_T)}`, such that
`u = κ_ar + κ_∞ + ν` on `(−2T,2T)`, and both forms `Q_ar(F) := ⟨κ_ar, c_F⟩` and `Q_∞(F) := ⟨κ_∞, c_F⟩` are `≥ 0` on
`P_T ∩ C_c^∞(I_T)`. A *complete* separated decomposition is the same with `L²(I_T)` in place of `P_T` and `ν = 0`.
Every decomposition "𝔞_T = (arithmetic sum of squares) + (archimedean sum of squares)" is of this form.

## §2 Two lemmas

**Lemma P (the primitive class is the image of `P = −∂² + ¼`). PROVED.** For every interval `J`,
`{F ∈ C_c^∞(J) : A(F) = B(F) = 0} = P(C_c^∞(J))`. Moreover `c_{PH} = P²c_H`.

*Proof.* `(−∂²+¼)e^{−|t|/2} = δ`. Given `F` with `A = B = 0`, put `H := e^{−|·|/2} ∗ F`, so that `PH = F` and `H` is smooth.
To the right of `supp F`, `H(t) = e^{−t/2}∫e^{s/2}F(s)ds = e^{−t/2}A(F) = 0`. To the left, `H(t) = e^{t/2}B(F) = 0`. So `H` has
compact support inside the convex hull of `supp F`. Conversely, integration by parts gives `A(PH) = (−¼+¼)A(H) = 0`, and
likewise `B(PH) = 0`. On the Fourier side, `\widehat{PH} = (τ²+¼)Ĥ`, hence `\widehat{c_{PH}} = (τ²+¼)²|Ĥ|² = \widehat{P²c_H}`. ∎

**Lemma N (the annihilator is smooth). PROVED.** `𝒩_T^P ⊂ ker P²|_{(−2T,2T)} = span{e^{±y/2}, ye^{±y/2}}`, which consists
of smooth functions. For the complete form the annihilator is `{0}`.

*Proof.* By Lemma P, `ν ∈ 𝒩_T^P` iff `⟨P²ν, c_H⟩ = 0` for all `H ∈ C_c^∞(I_T)` (`P²` is formally self-adjoint). Polarizing
gives `⟨P²ν, H_1 ⋆ \widetilde{H_2}⟩ = 0`. The span of the functions `H_1 ⋆ \widetilde{H_2}`, with `H_i ∈ C_c^∞(I_T)`, is dense in
`C_c^∞(−2T,2T)`. To see this, a `φ` supported near `y_0 ∈ (−2T,2T)` is approximated by `H_1 ⋆ \widetilde{H_2}` with `H_2` an
approximate identity at some `s` for which `s, s + y_0 ∈ I_T`, and `H_1 = φ(· − s)`; a partition of unity finishes it.
So `P²ν = 0` on the window, and the kernel of a constant-coefficient ODE of order 4 is as stated. The complete case is
the same without `P`. ∎

**Lemma A (atom forcing). PROVED.** In any primitive or complete separated decomposition, `κ_ar = cδ_0 − comb_T` on
`(−2T,2T)` for some real `c`.

*Proof.* On the punctured window, `κ_ar + comb_T = (k_∞ + 2cosh(y/2) − κ_∞ − ν)`. The right-hand side is `L¹_loc` there:
`k_∞` by R4 Lemma 1, `κ_∞` by definition, and `ν` by Lemma N. The left-hand side is a purely atomic measure, because
`comb_T` is a finite atomic measure on the window. A measure that is both purely atomic and absolutely continuous is
zero. Hence `κ_ar = −comb_T` on the punctured window. So `κ_ar + comb_T` is a measure supported in `{0}`, i.e. `cδ_0`,
and `c` is real because `κ_ar` is real. ∎

*Reading.* Whatever identity is used, and however the primes cancel among themselves inside the arithmetic block, the
block's kernel on the window is forced to be the prime comb itself plus a mass at the origin. **The only thing the
arithmetic block can exchange with the archimedean block is the scalar `c`.** This is the structural content of
"Λ enters the window exactly" (F1) once one insists on an arithmetic square.

## §3 Theorem S and its corollaries

Put `c_*(T) := sup{comb(F)/‖F‖² : 0 ≠ F ∈ P_T ∩ C_c^∞(I_T)}` and `c_*^W(T) := sup{comb(F)/‖F‖² : 0 ≠ F ∈ C_c^∞(I_T)}`.

**Theorem S (separation criterion). PROVED.**
*(Primitive.)* A primitive separated decomposition at `T` exists iff `c_*(T) ≤ λ^{∞,P}(T)`. In that case the admissible
masses are exactly `c ∈ [c_*(T), λ^{∞,P}(T)]`. Moreover `c_*(T) ≥ 0` for every `T > 0`, so `λ^{∞,P}(T) ≥ 0` is necessary.
*(Complete.)* The same holds with `c_*^W(T)`, `λ^∞(T)` and `L²(I_T)`.

*Proof.* (⟹) By Lemma A, `Q_ar(F) = c‖F‖² − comb(F)`, since `⟨δ_0, c_F⟩ = ‖F‖²`. On `P_T`, `⟨u, c_F⟩ = arch(F) − comb(F)`
and `⟨ν, c_F⟩ = 0`. Hence `Q_∞(F) = ⟨u, c_F⟩ − Q_ar(F) = arch(F) − c‖F‖²`. So `Q_ar ≥ 0` on the core gives
`c ≥ c_*(T)`, and `Q_∞ ≥ 0` on the core gives `c ≤ λ^{∞,P}(T)`, using the form core. (⟸) For `c` in the interval, take
`κ_ar := cδ_0 − comb_T ∈ 𝒜_T`, `κ_∞ := k_∞ + 2cosh(y/2) − cδ_0 ∈ ℳ_T` and `ν = 0`. The same two identities give
`Q_ar, Q_∞ ≥ 0`. For `c_*(T) ≥ 0`: choose an interval `J ⊂ I_T` of length `< min(log 2, 2T)` and `0 ≠ H ∈ C_c^∞(J)`. Then
`F := PH ∈ P_T` (Lemma P) and `F ≠ 0`, because `P` is injective on compactly supported functions. `supp c_F ⊂ (−|J|, |J|)`
contains no `log n` with `n ≥ 2`, so `comb(F) = 0`. The complete case is identical, with the polar term in `κ_∞` and
`c_*^W ≥ 0` shown the same way. ∎

**Corollary S1 (the threshold). PROVED, using CITED record items.** For every `T > T₀(0) = 0.74921`, neither a primitive
nor a complete separated decomposition exists.

*Proof.* R155_023(c) (PROVED there; re-checked in R155_025 row 3): `λ^∞(T) ≤ λ^{∞,P}(T) ≤ C_0 + φ((3π/2T)²)`. Here `φ` is
the Bernstein function of P46 thm:S, so it is strictly increasing, and `C_0 + φ((3π/2T₀)²) = 0` at `T₀ = 0.74921` (P46
thm:SC table, A = 0). So both bottoms are `< 0` for `T > T₀`, while Theorem S needs them `≥ c_* ≥ 0`. ∎

**Remarks on S1.**
(i) *The range is inside the proved windows.* Zhu (CITED, P46 cor:KEP08) gives `λ^W_T > 0` for `T ≤ 0.8`, hence
`λ^A_T ≥ λ^W_T > 0`. On `(0.74921, 0.8]` the windows are positive, and Corollary S1 says no square of the angle's type
can show it. Paper 42's primitive proof at `log 2 = 0.693` lies below `0.74921`, so S1 does not exclude a separated
certificate there. The DIAGNOSTIC thresholds (R155_023 §3, Galerkin upper bounds: `0.5958` primitive, `0.3716`
complete) indicate that Paper 42's certificate is already coupled. That is a DIAGNOSTIC statement, not a PROVED one.
(ii) *Relation to R155_023 Cor 2.* Cor 2 says the prime form must be positive **somewhere** on the negative cone of the
archimedean form. Theorem S says more: no form of the shape `c − comb` can be nonnegative on all of `P_T` while `c` stays
below `λ^{∞,P}`. So the positivity that the primes contribute beyond `T₀` can never be packaged as a nonnegative arithmetic
object. It exists only in the sum, which is coupling.
(iii) *Symbol form.* On the Fourier side, `Q_ar` has symbol `c − Σ_n v_n cos(τ log n)`, an almost-periodic trigonometric
polynomial whose Bohr mean is `c`. Its window-nonnegativity needs `c ≥ c_* ≥ 0`, whereas the archimedean symbol
`m − c` must be window-nonnegative with `c ≤ λ^{∞,P} < 0`. The almost-periodic and the `L¹_loc` parts of any certificate
symbol `f_w` (P46 thm:KEP1) therefore cannot be nonnegative separately beyond `T₀`.

**Corollary S2 (closure of the convolution-identity angle). EXCLUDED for the separated class; EQUIVALENT for the rest.**
(a) Let `Q = Σ_j ‖D_{a_j}F‖² + (archimedean multiplier squares) + cδ_0-term` be any identity of Hermitian forms equal to
`𝔞_T` on `P_T`, or to `W_T` on `L²(I_T)`, where the `a_j` are arbitrary arithmetic functions on `ℚ_{>0}`. This covers
every combination of the Vaughan, Heath-Brown and Selberg identities, `μ∗log`, and Selberg-sieve weights, with any
lengths and any truncations. Such a `Q` is a separated decomposition, so it cannot exist for `T > 0.74921` (S1).
(b) What survives are coupled squares `Σ_j ‖h_j(D)D_{a_j}F‖²`, with symbol `Σ_j|h_j|²|D_{a_j}|²`. Such a symbol is an
arbitrary nonnegative symbol, and an identity with `𝔞_T` or `W_T` is precisely an absolutely continuous solution of
KEP(T) (P46 thm:KEP1; G2_B4_R1 Thm S2). Their existence at every `T` is RH (P46 thm:KEP3(b); G2_B3_R3 Theorem K), which is
EQUIVALENT. Any `T`-family of them converges vaguely to `μ_ζ` (G2_B4_R1 S2(c), CITED). The coupling functions `h_j` are
not arithmetic, and no identity in the group ring `ℤ[ℚ_{>0}]` produces them. So the angle cannot contribute the coupling,
and the coupling is the whole problem.

**Question S3. OPEN.** How fast does `c_*(T)` grow? The main term of `comb` cancels against the polar term on `P_T` (the
PNT main term is killed by `A = B = 0`), so `c_*(T)` measures a one-sided smoothed prime error. A lower bound
`c_*(T) → ∞` would show that separated squares fail even with a bounded defect `E_T`, since `c ≤ λ^{∞,P} + ‖E_T‖` and
`c ≥ c_* − ‖E_T‖`. I have no proof of this. Under R4 Theorem K′ the defect that matters is `e^{o(T)}`, and on that scale
the separated obstruction says nothing, because `λ^{∞,P} ≥ C_0` is bounded.

## §7 Weakest step

Lemma A relies on the class definitions. `𝒜_T` requires the arithmetic kernel to be a purely atomic *measure*. An
"arithmetic" object whose kernel were a non-atomic singular measure (for example a Cantor-type measure on `log ℚ`-closures)
or a distribution of higher order carried by `log ℚ` would fall outside `𝒜_T`. No convolution identity produces such
objects, because finite or absolutely summable identities in `ℤ[ℚ_{>0}]` give atomic measures. Still, the exclusion is
exactly as wide as the class. The second input is R155_023(c), which is CITED from the record: its eigenvalue bound for
the killed subordinate Brownian motion is Song–Vondraček via P46 cor:mono. I did not re-derive it, and S1's numerical
threshold `0.74921` stands or falls with P46 thm:SC's table. The qualitative statement (failure for all large `T`) also
follows from the elementary limit `λ^{∞,P}(T) → C_0 < 0`, which I checked directly: take `F = PH_L` with
`H_L(t) = L^{−½}h(t/L)` and use dominated convergence in `∫m(σ/L)(σ²/L²+¼)²|ĥ(σ)|²dσ`.

**No mechanism is constructed and no sign is proved at any `T`. For this angle, a dead end is reached through a PROVED
exclusion.**
