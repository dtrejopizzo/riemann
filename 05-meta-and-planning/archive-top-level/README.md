# Archived top-level documents

Earlier top-level documents of the repository, moved here when the root was reorganized. They are
kept for the record: counts, phase numbers and status statements reflect the date each one was
written, not the present state. The current overview of the repository is the root `README.md`;
the current record of routes toward the sign is [`../ROUTES-MASTER-INDEX.md`](../ROUTES-MASTER-INDEX.md).

## How to read it

Read `EXPLANATION.md` for the plain-language account, `00-MAP.md` for the logical structure of
the early program, then `NO-GO-LIST.md` before attempting anything already excluded. The other
files are reference material.
