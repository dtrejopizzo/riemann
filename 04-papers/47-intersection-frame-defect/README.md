# An Intersection Frame for the Explicit Formula: Hodge-Index Transfer, a Frame Defect Theorem and a Function-Field Model

The paper equips the bilinear form defined by Weil's explicit formula on a class of exponentially decaying test functions with the structure used in Weil's proof of the Riemann hypothesis for curves on C×C: a degree, an effective cone (pointwise nonnegative functions), a radical, an ample class and an affine duality. It asks whether Hartshorne's proof of the Hodge index theorem can be run in this frame, and compares the result with the frame built in the same way for a curve over a finite field.

What the paper proves:

- The Pólya class K (with Φ_K = ξ) is positive, has degree 1 and computes the degree; the radical is cut out by the polar and zero data, is strictly larger than the ideal generated by ΠK, and meets the compactly supported functions only in 0; the space splits orthogonally into a hyperbolic plane and the primitive sector.
- Hodge-index transfer: a function h⁰ with a positivity clause, an effectivity clause and a Riemann–Roch inequality would give I(F,F) ≤ 0 on every primitive compactly supported test.
- Frame defect: no such h⁰ exists, for any constant χ. The obstruction is a cosh inequality on the effective cone with constant s₁ = 0.99846… < 1 at the first zero of ξ; it gives explicit classes (of degree ≥ 325 when χ = 0) of positive self-intersection with no effective representative. The proof uses the numerically known simplicity and isolation of the first zero (no other zero with 0 < Im ρ ≤ 21) and Trudgian's bound for S(T); the constants s₁ and the explicit witness are computed in 40-digit floating-point arithmetic, not interval arithmetic.
- For Ξ_a(s) = ξ(s+a)ξ(s−a) no h⁰ exists either; the construction of a positive primitive test from an off-line zero is given as an adaptation of Paper 45, Thm. 6.2, with only the changes indicated.
- Function-field model: for a curve of genus g ≥ 1 over F_q with distinct Weil numbers the frame's effective cone is the cone on the normalized Frobenius graphs, K corresponds to half the ample ruling class, and the frame defect theorem holds; for y² + xy = x³ + 1 over F₂ the sharp constant is √(7/11) (exact) with a witness in degree 3, although the Hodge index theorem is true there.

Known and new. Known inputs: Weil's explicit formula, Pólya's integral for ξ, Hartshorne's proof of the Hodge index theorem (V.1.9), and Lefschetz/Tate for curves over finite fields. New here: the frame on D^W, the radical and polar-plane theorems, the transfer theorem, the frame-defect theorem with its explicit witness, and the function-field comparison.
