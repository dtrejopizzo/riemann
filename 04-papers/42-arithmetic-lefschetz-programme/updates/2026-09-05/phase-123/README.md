as written. It also identifies gaps in completed numerical operations.

below records earlier construction claims and is subject to this override.

package under `def:strongrowa`.  It is not retracted.  It is now the input
to a stronger acceptance contract which requires the missing mixed
operations that are load-bearing in Weil's proof.

