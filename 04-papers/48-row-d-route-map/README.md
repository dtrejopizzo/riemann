# Paper 48: A map of the routes to Weil positivity on finite windows

What it is: the reference map of every route tried toward row D (λ_A(T) ≥ 0 on P_T for all T), and exactly where
each one fails. It proves no new sign. Row D is OPEN beyond ½log15 (Mori, cited; ½log5 proved in Paper 47).

Contents: (1) the problem, rows A–C, certified range; (2) the shape of the sign: ≈4T archimedean negative
directions, cancellation by the comb down to the single polar direction, the Dirichlet-sine comb matrix, the
mechanism in four steps, the margin bound 4·10⁹Te^{−15.449T}; (3) barrier theorems with their classes;
(4) certified falsifier battery, structural models, requirements on any proof; (5) route catalogue by method
family, with the updated 8×8 grid (1100 routes through phase 184) and family tables through phase 208;
(6) what is open: the node, exact restatements, weaker-looking residues, the empty cell, the live gate.
