# Paper 45: An explicit formula and a comparison theorem for the canonical trace

**What it proves (row C).** On the carrier of Paper 43: the trace of radial classes (Thm A); Weil's
explicit formula in the normalization of T, proved without moving a contour across a zero (Thm B);
the comparison I_∞(Γ_F,Γ_F) = β_T(M,M) − Σ_ρ Φ_F(ρ)Φ_F(1−ρ) (Thm C); c = 0 is forced (Thm D);
the residues of the Euler-product symbol give the polar term (Thm E); primitive tests detect a zero
off the line (Thm F); nondegeneracy on radial classes (Thm G).

**Status.** Row C closed on the declared carrier. Classical inputs listed in the appendix (CITED).
The Tate terms are realized only as the functionals M = (λ_-, λ_+) into (B_T, β_T); no cohomological
realization. No sign or positivity is claimed.
