# The colligation route to the Riemann Hypothesis: a Kreĭn–Langer index, a Laplace–pole argument, and heuristic reformulations of Weil positivity

The paper studies the de Branges / Lax–Phillips colligation attached to the completed zeta function ξ, and several reformulations of Weil positivity for the Weil matrix on a finite window [0, 2 log λ]. It separates what can be proved about these structures from what is only heuristic.

## Results

- Proposition 2.1: Θ_ω(z) = ξ(½+ω+iz)/ξ(½+ω−iz) has an explicit product factorisation for every ω > 0 and is inner on the upper half-plane for ω ≥ ½ (proved).
- Lemma 3.1 and Theorem 3.2: the transform of a zero off the critical line against a window test function never vanishes; the (0,0) entry of the window Weil matrix, written as an absolutely convergent sum over zeros, is bounded uniformly in λ if and only if RH holds (proved, by a Laplace–pole argument). Remark 3.3: under RH all entries are bounded for fixed N; the analogous pole statement for the other entries is not proved.
- Theorem 4.1 and Corollary 4.2: for ω > 0 the number of negative squares of the kernel of Θ_ω equals the number of poles of Θ_ω in the upper half-plane; outside a countable set of ω this is the number of zeros of ξ with Re ρ > ½ + ω. Hence RH holds iff this index is 0 for every ω > 0 (proved, using the Kreĭn–Langer theorem).
- Theorems 5.2–5.3: the Γ₂ kernel and the CD(0,∞) bound for translation-invariant pure-jump generators with finitely many prime-power jumps (proved; an instance of a known fact, using only Λ ≥ 0).
- Remark 5.1: the tensor form A⊗I + I⊗A − 2ε₀ I⊗I is positive semidefinite for every window, so its signature says nothing about RH.
- Conjecture 2.2 (angle criterion) and Heuristic 6.1 (Birman–Schwinger form): heuristic, not proved. The Perron–Frobenius and ladder properties (H1), (H2) are informal assumptions used only in remarks.

No numerical computations are used.

## Known and new

The Kreĭn–Langer theorem, the de Branges–Rovnyak model theory, Weil's positivity criterion and the CD(0,∞) property of jump generators are known. The new content is the application of the Kreĭn–Langer count to Θ_ω with the factorisation that makes it rigorous, and the Laplace–pole characterisation of RH by the (0,0) window entry.
