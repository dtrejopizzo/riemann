# Paper 43: A correspondence algebra with a canonical trace on the idele class group

**What it proves (row A).** On the semilocal idele class group C_S (S finite, ∞ ∈ S) it builds the
correspondence category with two-sided excision and a half-density involution, the commutative
†-algebra D_A = C_c^∞(C_S), the canonical trace T = Σ_v W_v, its Fourier symbol (bounded above,
→ −∞, poles at height ±½ with residue ∓i), nondegeneracy of I_A(F,G) = T(F⋆G†), the Tate sequence
onto the hyperbolic plane (B_T, β_T), the rulings in a completion, a Banach trace algebra, effectivity,
a Riemann–Roch biextension, and the signature (infinite index of both signs).

**Status.** Row A closed on the declared carrier. PROVED except: excision for σ = id is CITED
(Wodzicki; Brodzki–Lykova); Appendix A (Mertens, limit over S) is auxiliary and outside the
construction. No sign of I_A and no statement about zeta zeros is claimed.

**Series.** 43 (carrier) → 44 (arithmetic family) → 45 (explicit formula) → 47 (window positivity,
row D, OPEN) → 48 (route map).
