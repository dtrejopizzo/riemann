4. TEST DECISIVO: FORZAR sigma = 1/phi Y VER SI EL TEOREMA SOBREVIVE
====================================================================
  115_04:  h0_t - h2_t = N_t * log(1/sigma).
  El teorema pide que eso sea (log2)^2 N_t = t^2 ab, SIN factor espurio.
  Con sigma = e^-(log2)^2 :  log(1/sigma)/(log2)^2 = 1.000000000  (exacto)
  Con sigma = 1/phi       :  log(phi)  /(log2)^2 = 1.001579366
  -> factor espurio de 0.1579 % en cada t.
  Como N_t ~ t^2 ab/(log2)^2, el error ABSOLUTO crece como t^2:
     t=10   -> discrepancia 0.158
     t=100  -> discrepancia 15.794
     t=200  -> discrepancia 63.175   (y diverge)
  El covolumen NO deja elegir: 1/phi rompe la igualdad exacta que
  es todo el contenido de 115_04.  sigma esta forzado, y no es phi.
