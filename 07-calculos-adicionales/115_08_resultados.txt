1. THE TWO NUMBERS, TO FULL PRECISION
====================================================================
  log 2            = 0.69314718055994529
  (log 2)^2        = 0.48045301391820139
  sigma = e^-(l2)^2= 0.61850313780157595
  1/phi            = 0.61803398874989479
  sigma - 1/phi    = 4.691e-04
  relative error   = 7.5910e-04   (0.0759 %)

  sigma = 1/phi  <=>  (log 2)^2 = log phi:
     (log 2)^2 = 0.480453013918201
     log phi   = 0.481211825059603
     differ by 7.588e-04  -> NOT the same number.
  They agree to 3 significant digits; they differ in the 4th.

====================================================================
2. WHERE THE 2 COMES FROM:  N_t counts DIGITS IN BASE 2
====================================================================
  r(m) ~ log m / log b  with b the base of the digital code.
  With a generic base b:  sigma_b = exp(-(log b)^2).
  sigma_2      = 0.618503138
  sigma_b=1/phi at b* = 2.001094601   (not 2, but 2.0011)
  => the golden value is not reached at the base of the code, but
     0.05% further.  The 'appearance' is that log2 ~ sqrt(log phi).

3. CALIBRATION: HOW RARE IS IT TO BE WITHIN 0.076% OF A CONSTANT?
====================================================================
  catalogue A (2201 values: simple combinations of pi,e,phi,
    sqrt2,ln2,gamma,zeta3,...)  -> 3 fall as close to sigma as 1/phi
  catalogue B (4115 values: (p+q*sqrt d)/s, height<=12)
    -> 5 fall as close to sigma as 1/phi

  Neighbours of sigma within 3x that distance (catalogue A):
                2^-ln2 = 0.618503138   rel 0.00e+00
     exp(-gamma/zeta3) = 0.618665854   rel 2.63e-04
             sqrt5-phi = 0.618033989   rel 7.59e-04
       1/sqrt(phi*phi) = 0.618033989   rel 7.59e-04
               1/e-ln3 = 0.617409895   rel 1.77e-03

  That is: at this precision the golden ratio is not a distinguished neighbour.
  It has competition, and the eye picks the one it already knew.

====================================================================
4. DECIDING TEST: FORCE sigma = 1/phi AND SEE WHETHER THE THEOREM SURVIVES
====================================================================
  115_04:  h0_t - h2_t = N_t * log(1/sigma).
  The theorem requires this to be (log2)^2 N_t = t^2 ab, with NO spurious factor.
  With sigma = e^-(log2)^2 :  log(1/sigma)/(log2)^2 = 1.000000000  (exact)
  With sigma = 1/phi       :  log(phi)  /(log2)^2 = 1.001579366
  -> spurious factor of 0.1579 % at every t.
  Since N_t ~ t^2 ab/(log2)^2, the ABSOLUTE error grows like t^2:
     t=10   -> discrepancy 0.158
     t=100  -> discrepancy 15.794
     t=200  -> discrepancy 63.175   (and diverges)
  The covolume leaves NO choice: 1/phi breaks the exact equality that
  is the whole content of 115_04.  sigma is forced, and it is not phi.
